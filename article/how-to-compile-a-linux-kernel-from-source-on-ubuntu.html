How to Compile a Linux Kernel from Source on Ubuntu

Compiling a custom Linux kernel from source code on Ubuntu allows you to tailor your operating system to specific hardware, enable experimental features, or optimize performance by removing unnecessary drivers. This process involves installing the required build tools, downloading the official kernel source tree, configuring the kernel parameters to match your system's needs, compiling the core and its modules, and updating the bootloader to load your newly built kernel.

Step 1: Install Build Dependencies

Before downloading the source code, install the necessary development packages and build utilities:

sudo apt update
sudo apt install -y build-essential libncurses-dev bison flex libssl-dev libelf-dev dwarves bc git

Step 2: Download the Kernel Source Code

Visit the official kernel.org repository to find the latest stable version, or download it directly using wget. Replace the version number with your desired release:

cd /tmp
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.8.tar.xz
tar -xf linux-6.8.tar.xz
cd linux-6.8

Step 3: Configure the Kernel

The easiest way to configure a stable kernel is to use your existing Ubuntu configuration as a baseline:

cp -v /boot/config-$(uname -r) .config

Run the text-based configuration interface to review settings or disable unnecessary modules:

make menuconfig

To avoid signature-checking errors during the build on Ubuntu systems, disable the canonical certificates configuration:

scripts/config --disable SYSTEM_TRUSTED_KEYS
scripts/config --disable SYSTEM_REVOCATION_KEYS

Step 4: Compile the Kernel and Modules

Compile the kernel using all available CPU threads to speed up the process. The -j flag specifies the number of concurrent jobs:

make -j$(nproc)

Depending on your hardware, this step can take anywhere from fifteen minutes to several hours.

Step 5: Install the Kernel Modules

Once the compilation is finished, install the kernel modules to /lib/modules/:

sudo make modules_install

Step 6: Install the Kernel Image

Install the actual kernel image and related system files into the /boot directory:

sudo make install

This step automatically creates the corresponding initramfs image and updates the GRUB bootloader configuration.

Step 7: Verify and Reboot

Ensure GRUB has detected the new kernel:

sudo update-grub

Reboot your system:

sudo reboot

After the system boots up, open a terminal and verify that the custom kernel is active:

uname -r
