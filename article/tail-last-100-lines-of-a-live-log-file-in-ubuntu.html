Tail Last 100 Lines of a Live Log File in Ubuntu

This guide explains how to use the Ubuntu command line to output the last 100 lines of an active log file and monitor new incoming data in real time. By combining standard options of the tail utility, system administrators and developers can efficiently inspect recent history and debug live events simultaneously.

The Basic Command

To view the last 100 lines of a file and keep the session open to stream new additions, use the -n and -f flags:

tail -n 100 -f /path/to/your/logfile.log

You can also use the shorthand syntax:

tail -100f /path/to/your/logfile.log

Breakdown of the Command Options

  • -n 100: Instructs tail to show the last 100 lines instead of the default 10 lines.
  • -f (follow): Instructs tail to keep the file open and continuously append new log entries to the terminal screen as they are written to disk.

Handling Log Rotation with -F

In production Ubuntu environments, services frequently rotate log files (such as via logrotate). If a file is rotated while you are monitoring it, the standard -f flag will stop tracking updates because the original file descriptor is closed.

To prevent this, use uppercase -F:

tail -n 100 -F /path/to/your/logfile.log

The -F flag follows the filename rather than the file descriptor, automatically retrying and reopening the file if it is renamed, truncated, or recreated.

Practical Examples

Monitoring the Ubuntu System Log:

sudo tail -n 100 -f /var/log/syslog

(Note: Root privileges via sudo are typically required to read system-level log files.)

Monitoring Nginx Access Logs:

sudo tail -n 100 -f /var/log/nginx/access.log

Monitoring UFW Firewall Logs:

sudo tail -n 100 -f /var/log/ufw.log

Stopping the Live Output

To stop following the file and return to the standard command prompt, press Ctrl + C.
