What Is the Core20 Base Snap in Ubuntu?

This article provides an overview of the core20 base snap, explaining its role as a fundamental runtime environment in modern Ubuntu snap packaging. Readers will learn what a base snap is, why core20 exists, and how it delivers stability, security, and portability for containerized applications across diverse Linux distributions.

In the Snap packaging ecosystem, a base snap acts as the minimal root filesystem for an application. When a snap is built with base: core20 in its snapcraft.yaml configuration, it relies on a stripped-down runtime environment built directly from Ubuntu 20.04 LTS (Focal Fossa). This filesystem provides standard C libraries, system binaries, compilers, and utilities that the packaged application needs to execute properly.

The primary purpose of core20 is to ensure runtime consistency and isolation. Instead of relying on the host operating system's installed libraries, an application packaged with core20 executes inside a dedicated mount namespace where core20 serves as the root (/). This architecture guarantees that the application runs identically on Ubuntu, Fedora, Arch Linux, openSUSE, or any other distribution supporting snapd, eliminating the classic "dependency hell" caused by mismatched host libraries.

Additionally, core20 introduces a shared dependency model that saves disk space and memory. Multiple snaps that specify core20 as their base share a single read-only installation of the core20 image on the host. This approach combines the dependency isolation of traditional containers with the storage efficiency of shared system components.

Security and lifecycle predictability are also central to the purpose of core20. Because it maps directly to Ubuntu 20.04 LTS, Canonical provides long-term security updates, bug fixes, and maintenance for the underlying system components within the snap. When core20 is patched, every application relying on it automatically inherits the security updates without requiring developers to recompile their software.
