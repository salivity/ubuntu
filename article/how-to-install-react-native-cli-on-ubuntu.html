How to Install React Native CLI on Ubuntu

This guide provides a straightforward walkthrough for setting up the React Native Command Line Interface (CLI) on an Ubuntu workstation. You will learn how to install essential dependencies—including Node.js, OpenJDK, and Android Studio—configure required Android environment variables, and create your first React Native project using the native CLI.

Step 1: Install Node.js and Watchman

React Native requires Node.js. The recommended approach is using Node Version Manager (NVM) to manage Node versions.

  1. Open your terminal and install NVM: 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  2. Reload your shell configuration: 
    source ~/.bashrc
  3. Install the current Long Term Support (LTS) version of Node.js: 
    nvm install --lts
nvm use --lts

Step 2: Install the Java Development Kit (JDK)

React Native Android development currently requires OpenJDK 17.

  1. Update package lists and install OpenJDK 17: 
    sudo apt update
sudo apt install -y openjdk-17-jdk
  2. Verify the installation: 
    javac -version

Step 3: Install Android Studio and SDK Components

  1. Download Android Studio from the official Android developer website or install it via Ubuntu Snap: 
    sudo snap install android-studio --classic
  2. Launch Android Studio to complete the setup wizard. Choose the Standard setup type.
  3. Open SDK Manager from Android Studio settings (More Actions > SDK Manager or Settings > Appearance & Behavior > System Settings > Android SDK).
  4. Under the SDK Platforms tab, check the box next to Show Package Details and select the latest stable Android SDK platform (e.g., Android 14 / UpsideDownCake).
  5. Under the SDK Tools tab, ensure the following are installed:
    • Android SDK Build-Tools
    • Android SDK Command-line Tools (latest)
    • Android Emulator
    • Android SDK Platform-Tools
  6. Click Apply and follow the prompts to complete the download.

Step 4: Configure Environment Variables

You must expose the Android SDK path to your shell environment.

  1. Open your terminal profile file (such as ~/.bashrc or ~/.profile): 
    nano ~/.bashrc
  2. Append the following lines at the end of the file: 
    export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
  3. Save the file (Ctrl+O, then Enter), exit nano (Ctrl+X), and apply the changes: 
    source ~/.bashrc
  4. Confirm adb is recognized: 
    adb --version

Step 5: Initialize a React Native Application

React Native recommends invoking the CLI directly using npx rather than installing it globally.

  1. Generate a new project using the React Native CLI: 
    npx @react-native-community/cli init MyAwesomeProject
  2. Navigate into your project directory: 
    cd MyAwesomeProject
  3. Start the Metro bundler: 
    npm start
  4. In a separate terminal window, launch the app on an active Android emulator or connected device: 
    npm run android
