Securely Transfer Files Between Two Ubuntu Machines

Transferring files securely between two Ubuntu machines over a local network or the internet is primarily achieved using OpenSSH-based tools such as scp, rsync, and sftp. These methods encrypt all data, including passwords, preventing eavesdropping and tampering during transit. This guide outlines the essential prerequisites and provides clear, step-by-step instructions for using the most efficient CLI and GUI tools to copy your files safely.

Prerequisites

Before transferring files, ensure that the remote (destination) Ubuntu machine has an SSH server installed and running.

  1. Install the OpenSSH server on the destination machine: 
    sudo apt update
sudo apt install openssh-server
  2. Check that the SSH service is running: 
    sudo systemctl status ssh
  3. Allow SSH through the UFW firewall if active: 
    sudo ufw allow ssh
  4. Find the local IP address of the destination machine by running hostname -I on that machine.

Method 1: Using SCP (Secure Copy Protocol)

scp is a lightweight, built-in command-line utility designed to copy files and directories securely between hosts.

Copy a single file from local to remote machine:

scp /path/to/local/file.txt username@remote_ip:/path/to/destination/

Copy a file from a remote machine to your local machine:

scp username@remote_ip:/path/to/remote/file.txt /path/to/local/destination/

Copy an entire directory recursively:

scp -r /path/to/local/folder username@remote_ip:/path/to/destination/

Method 2: Using Rsync (Recommended)

rsync is faster and more versatile than scp because it compresses data, displays progress bars, and allows resuming interrupted transfers.

Synchronize a file or directory to a remote machine:

rsync -avzP /path/to/local/folder/ username@remote_ip:/path/to/destination/
  • -a (archive): Preserves file permissions, timestamps, and symlinks.
  • -v (verbose): Shows detailed output.
  • -z (compress): Compresses data during transfer for speed.
  • -P: Shows progress and allows resuming partial transfers.

Method 3: Using SFTP via Command Line

SFTP provides an interactive session for managing and transferring files over SSH.

  1. Connect to the remote machine: 
    sftp username@remote_ip
  2. Navigate remote directories using cd and local directories using lcd.
  3. Upload a file: 
    put localfile.txt
  4. Download a file: 
    get remotefile.txt
  5. Type exit to close the connection.

Method 4: Using the Ubuntu Graphical Interface (Nautilus)

If you prefer a visual drag-and-drop interface:

  1. Open the Files (Nautilus) app on your local Ubuntu machine.
  2. Click Other Locations in the left sidebar.
  3. At the bottom, locate the Connect to Server input field.
  4. Enter the address using the SSH protocol: ssh://username@remote_ip
  5. Click Connect, enter the user password when prompted, and access the remote filesystem directly through the file manager.
