Change Default Audio Output Device in Ubuntu Terminal

Changing the default audio output device in Ubuntu using the command line is a straightforward process that relies on built-in tools like pactl for PulseAudio systems or wpctl for modern PipeWire systems. This guide covers how to list all available audio output devices (sinks), identify the target device, and set it as the system default directly from your terminal.

Method 1: Using pactl (PulseAudio and PipeWire Compatible)

The pactl command is the standard utility for managing audio devices in most Ubuntu installations.

1. List Available Audio Devices

Run the following command to view all connected audio sinks:

pactl list short sinks

This displays a list of available output devices. Note either the sink number (e.g., 0, 1) or the full sink name (e.g., alsa_output.pci-0000_00_1f.3.analog-stereo).

2. Set the Default Audio Output

To change the output device, run:

pactl set-default-sink <SINK_NAME_OR_NUMBER>

Replace <SINK_NAME_OR_NUMBER> with your target device. For example:

pactl set-default-sink alsa_output.pci-0000_00_1f.3.analog-stereo

3. Move Currently Playing Audio Streams

Setting the default sink applies to newly opened audio applications. To immediately switch audio that is currently playing to the new device, run:

for stream in $(pactl list short sink-inputs | cut -f1); do
    pactl move-sink-input "$stream" <SINK_NAME_OR_NUMBER>
done

Method 2: Using wpctl (Ubuntu 22.04+ with PipeWire)

Ubuntu 22.04 and newer releases use PipeWire as the default audio server. You can manage audio using the native wpctl tool.

1. Check Audio System Status

Run the following command to display your audio devices:

wpctl status

Look under the Audio -> Sinks section. Locate the ID number next to the output device you want to use.

2. Set the Default Output Device

Use the identified device ID to set the default sink:

wpctl set-default <ID>

For example, if your desired audio device is assigned ID 45:

wpctl set-default 45
