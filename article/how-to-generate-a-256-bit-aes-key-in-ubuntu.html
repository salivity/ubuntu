How to Generate a 256-Bit AES Key in Ubuntu

Generating a cryptographically secure 256-bit Advanced Encryption Standard (AES) key in Ubuntu is essential for safeguarding sensitive data and configuring secure network services. This guide provides the exact terminal commands required to generate high-entropy 256-bit keys using standard utilities like OpenSSL and the Linux kernel's built-in cryptographic pseudo-random number generator.

Using OpenSSL (Recommended)

The most standard and secure method to generate a 256-bit AES key is using the openssl utility. A 256-bit key consists of 32 bytes of data (256 bits ÷ 8 bits/byte = 32 bytes).

To generate the key in hexadecimal format (a 64-character string):

openssl rand -hex 32

To generate the key in Base64 encoding (suitable for configuration files and environment variables):

openssl rand -base64 32

To output the raw 32-byte binary key directly to a file:

openssl rand -out aes256.key 32

Using /dev/urandom

If OpenSSL is unavailable, you can read bytes directly from /dev/urandom, which draws entropy from the Linux kernel CSPRNG (Cryptographically Secure Pseudo-Random Number Generator).

To generate a 64-character hexadecimal key using /dev/urandom and xxd:

head -c 32 /dev/urandom | xxd -p -c 32

Alternatively, you can extract the binary data and encode it using base64:

head -c 32 /dev/urandom | base64

Securing the Generated Key

If you save the generated key to a file, ensure that the file permissions prevent unauthorized read access by non-root users:

chmod 600 aes256.key
