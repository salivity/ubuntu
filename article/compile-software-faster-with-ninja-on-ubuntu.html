Compile Software Faster with Ninja on Ubuntu

Ninja is a minimalist, speed-focused build system designed to execute builds as quickly as possible by focusing strictly on build file execution rather than high-level configuration. This article explains how to install Ninja on an Ubuntu machine, configure modern build generators like CMake to output Ninja build files, and execute parallel builds to significantly cut down software compilation times.

Step 1: Install Ninja on Ubuntu

Ninja is available directly from the default Ubuntu repositories. Open your terminal and run the following commands to install it:

sudo apt update
sudo apt install ninja-build

Verify the installation and check the installed version:

ninja --version

Step 2: Use Ninja with CMake

Ninja is a low-level build system and does not directly parse configuration files like CMakeLists.txt. Instead, tools like CMake generate the build.ninja configuration file.

  1. Navigate to your project directory containing the CMakeLists.txt file:
cd /path/to/your/project
  1. Generate the build files using the -G Ninja generator flag:
cmake -B build -G Ninja

This tells CMake to create a build directory configured specifically for the Ninja build engine.

Step 3: Compile the Project

Once the build files are generated, you can trigger the compilation using either Ninja directly or via CMake:

Using Ninja directly:

ninja -C build

Using the CMake wrapper:

cmake --build build

Step 4: Optimize Build Performance

Ninja automatically detects the number of available CPU cores and spawns the optimal number of parallel compilation jobs by default, unlike standard GNU Make, which requires the manual -j flag.

However, you can customize execution to fit your system's resources:

  • Specify parallel jobs manually: If you want to limit CPU or memory consumption during a build, specify the number of parallel workers using the -j flag:

    ninja -C build -j 4

  • Clean build targets: To clean previous build artifacts without deleting the configuration:

    ninja -C build -t clean

  • Inspect targets: To view all available build targets defined in the project:

    ninja -C build -t targets

Why Ninja Compiles Faster Than Make

Ninja eliminates file-globbing, configuration evaluation, and complex conditional checks during build execution. By offloading the dependency resolution and generation phase entirely to tools like CMake or Meson, Ninja reads its generated graph into memory almost instantly, resulting in negligible overhead and maximum processor utilization across large codebases.
