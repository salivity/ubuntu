Package a Custom Linux Kernel Using make bindeb-pkg

This guide explains how to compile a custom Linux kernel and package it directly into installable Debian (.deb) packages on Ubuntu using the make bindeb-pkg command. By packaging your kernel into .deb binaries, you can easily manage installations, upgrades, and removals via Ubuntu’s native package manager (dpkg or apt), as well as distribute the compiled kernel to other compatible systems without recompiling.

1. Install Build Dependencies

Before building the kernel, install the necessary build tools, libraries, and compiler packages:

sudo apt update
sudo apt install -y build-essential libncurses-dev bison flex libssl-dev libelf-dev bc dwarves rsync kmod ccache

2. Prepare the Kernel Source and Configuration

Navigate to your downloaded kernel source directory:

cd /path/to/linux-source

To use your current Ubuntu configuration as the baseline:

cp /boot/config-$(uname -r) .config
make olddefconfig

Disable canonical debug certificates to prevent compilation errors caused by missing private keys:

scripts/config --set-str SYSTEM_TRUSTED_KEYS ""
scripts/config --set-str SYSTEM_REVOCATION_KEYS ""

3. Build the Debian Packages

Run the bindeb-pkg target. The bindeb-pkg command compiles the kernel and modules, generating only the binary .deb packages without generating the source package overhead:

make -j$(nproc) bindeb-pkg

The -j$(nproc) flag utilizes all available CPU cores to speed up compilation.

4. Locate and Install the Generated Packages

Once the build finishes successfully, the .deb files are stored in the parent directory (../). You will find several packages:

  • linux-image-<version>_<arch>.deb (the kernel binary and drivers)
  • linux-headers-<version>_<arch>.deb (header files needed for compiling out-of-tree modules)
  • linux-libc-dev_<version>_<arch>.deb (userspace development headers)

Install the kernel image and headers using dpkg:

cd ..
sudo dpkg -i linux-image-*.deb linux-headers-*.deb

5. Update Bootloader and Reboot

The installation script automatically triggers update-initramfs and configures GRUB. To ensure GRUB has registered the new kernel:

sudo update-grub

Reboot your system to run the custom kernel:

sudo reboot

Verify that the system is running your new kernel version:

uname -r
