How to Restart GNOME Shell on Ubuntu Wayland

Restarting GNOME Shell on Ubuntu Wayland without logging out is not natively supported due to how Wayland manages the display server and window compositor. Unlike the older X11 display server, Wayland tightly integrates GNOME Shell directly into the display compositor session, meaning restarting the shell forces the entire desktop session to close. This article explains the technical reasons for this limitation, what happens when you attempt to restart it, and practical alternatives for resolving desktop freezes under Wayland.

Why GNOME Shell Cannot Restart in Wayland

On X11, the display server (Xorg) and the window manager (GNOME Shell) run as separate processes. If GNOME Shell crashes or freezes, you can restart it using the Alt + F2 prompt, typing r, and pressing Enter. Xorg remains running in the background, keeping all your open applications intact.

On Wayland, GNOME Shell is the display server (compositor). Because your applications are directly tied to the GNOME Shell display server process, killing or restarting gnome-shell immediately terminates all running GUI applications and forces a log out back to the GDM login screen.

Commands That Attempt to Restart GNOME Shell (Session Termination)

If your desktop is completely frozen and you are willing to end your current session to regain control without performing a full system reboot, you can run the following commands from a virtual terminal (TTY):

  1. Press Ctrl + Alt + F3 to switch to a TTY command line interface and log in with your credentials.
  2. Execute one of the following commands:
  • Kill the GNOME Shell process: 
    killall -HUP gnome-shell
  • Restart the GNOME Shell user service: 
    systemctl --user restart gnome-shell

Note: Both commands will crash your current GUI session and return you to the GDM login screen, closing all unsaved work.

To return to your graphical desktop without killing the session (if it unfreezes), press Ctrl + Alt + F2 or Ctrl + Alt + F1.

Alternatives for Handling Desktop Freezes in Wayland

If you frequently encounter GNOME Shell freezes and need the ability to restart the shell without losing your workspace, consider the following solutions:

1. Kill Specific Misbehaving Applications

Often, a frozen desktop is caused by a single application or extension rather than GNOME Shell itself.

  • Switch to TTY (Ctrl + Alt + F3), log in, and use top or htop to identify processes consuming excessive CPU or memory.
  • Terminate the specific process: 
    kill -9 <PROCESS_ID>

2. Disable Problematic GNOME Extensions

Buggy extensions are the primary cause of GNOME Shell instability. You can disable all extensions from the terminal to see if stability returns:

gsettings set org.gnome.shell disable-user-extensions true

3. Switch from Wayland to X11 (Xorg)

If you require the ability to restart GNOME Shell seamlessly via Alt + F2 -> r:

  1. Log out of your current Ubuntu session.
  2. On the login screen, click on your username.
  3. Click the gear icon in the bottom-right corner of the screen.
  4. Select Ubuntu on Xorg (or GNOME on Xorg).
  5. Enter your password and log in.

Once logged into an X11 session, pressing Alt + F2, typing r, and hitting Enter will instantly restart GNOME Shell without closing any of your open windows.
