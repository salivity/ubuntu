How to Set Up a WireGuard VPN Server on Ubuntu

Setting up a WireGuard VPN server on an Ubuntu instance provides a fast, modern, and highly secure solution for encrypting your internet traffic and accessing remote network resources. This guide walks you through the straightforward process of installing the WireGuard package, generating cryptographic key pairs, configuring the server interface, enabling IP forwarding, setting up firewall rules, and adding client configurations.

Prerequisites

  • An Ubuntu server instance (20.04 or 22.04 recommended).
  • A user account with sudo privileges.
  • A static public IP address assigned to your server.

Step 1: Update the System and Install WireGuard

Update your package index and install the WireGuard software from the standard Ubuntu repositories.

sudo apt update && sudo apt upgrade -y
sudo apt install wireguard -y

Step 2: Generate Server Private and Public Keys

WireGuard uses public-key cryptography for authentication. Navigate to the WireGuard directory and generate a private/public key pair for the server.

cd /etc/wireguard
umask 077
wg genkey | tee privatekey | wg pubkey > publickey

To view the generated private key (needed in the next step), run:

cat privatekey

Step 3: Configure the WireGuard Server

Identify your active network interface name (commonly eth0 or ens3):

ip -br address show

Create the server configuration file named wg0.conf:

sudo nano /etc/wireguard/wg0.conf

Paste the following configuration, replacing <SERVER_PRIVATE_KEY> with the contents of your privatekey file and eth0 with your actual network interface name:

[Interface]
PrivateKey = <SERVER_PRIVATE_KEY>
Address = 10.8.0.1/24
ListenPort = 51820
PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

Save and close the file (Ctrl+O, Enter, then Ctrl+X).

Step 4: Enable IP Forwarding

To allow the server to route traffic between the WireGuard client and the internet, enable IPv4 packet forwarding.

Open /etc/sysctl.conf:

sudo nano /etc/sysctl.conf

Uncomment or add the following line:

net.ipv4.ip_forward=1

Apply the changes immediately:

sudo sysctl -p

Step 5: Configure Firewall Rules

Open the WireGuard UDP port and ensure SSH access remains enabled before activating the UFW firewall.

sudo ufw allow 51820/udp
sudo ufw allow OpenSSH
sudo ufw enable

Step 6: Start and Enable the WireGuard Service

Start the WireGuard service using the wg-quick utility and set it to launch automatically at system boot.

sudo systemctl start wg-quick@wg0
sudo systemctl enable wg-quick@wg0

Verify that the server is active:

sudo wg show

Step 7: Create Client Configuration and Key Pair

Generate a separate key pair for a client machine:

wg genkey | tee client_privatekey | wg pubkey > client_publickey

Display the client keys:

cat client_privatekey
cat client_publickey

Add the Client to the Server (/etc/wireguard/wg0.conf)

Edit the server configuration to recognize the client:

sudo nano /etc/wireguard/wg0.conf

Append the following lines to the end of the file:

[Peer]
PublicKey = <CLIENT_PUBLIC_KEY>
AllowedIPs = 10.8.0.2/32

Save the file and restart WireGuard to apply the changes:

sudo systemctl restart wg-quick@wg0

Create the Client Configuration File (client.conf)

On the client device, create a configuration file named client.conf with the following structure:

[Interface]
PrivateKey = <CLIENT_PRIVATE_KEY>
Address = 10.8.0.2/32
DNS = 1.1.1.1

[Peer]
PublicKey = <SERVER_PUBLIC_KEY>
Endpoint = <SERVER_PUBLIC_IP>:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25

Replace <CLIENT_PRIVATE_KEY>, <SERVER_PUBLIC_KEY> (from /etc/wireguard/publickey), and <SERVER_PUBLIC_IP> with your actual server data. Import this file into your WireGuard client app to connect.
