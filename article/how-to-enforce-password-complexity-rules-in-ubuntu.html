How to Enforce Password Complexity Rules in Ubuntu

Enforcing strong password rules is essential for securing Ubuntu systems against brute-force attacks and unauthorized access. By leveraging Pluggable Authentication Modules (PAM)—specifically the pam_pwquality module—system administrators can mandate specific password criteria such as minimum length, character diversity, and dictionary checks. This guide provides a direct, step-by-step approach to installing, configuring, and testing PAM password complexity policies on an Ubuntu server or desktop.

Step 1: Install the PAM Quality Module

Ubuntu uses the libpam-pwquality library to evaluate password strength. Install it via the terminal using apt:

sudo apt update
sudo apt install libpam-pwquality -y

Step 2: Configure Password Complexity Policies

The default configuration settings for password quality reside in the /etc/security/pam_pwquality.conf file. Open this file using a text editor with administrative privileges:

sudo nano /etc/security/pam_pwquality.conf

Uncomment and adjust the following parameters to set your password requirements:

  • minlen = 12: Sets the absolute minimum character length for new passwords.
  • dcredit = -1: Requires at least 1 numeric digit. (A negative number sets a mandatory minimum count).
  • ucredit = -1: Requires at least 1 uppercase character.
  • lcredit = -1: Requires at least 1 lowercase character.
  • ocredit = -1: Requires at least 1 special character/symbol.
  • minclass = 3: Mandates characters from a minimum of 3 different classes (uppercase, lowercase, digits, symbols).
  • maxrepeat = 2: Disallows more than 2 consecutive identical characters.
  • gecoscheck = 1: Prevents users from incorporating their full name or user information into the password.
  • reject_username: Rejects passwords that contain the user’s login account name.
  • enforce_for_root: Applies these rules strictly to the root account as well.

Save and close the file after configuring your rules.

Step 3: Verify the PAM File Configuration

Installing libpam-pwquality automatically updates the main PAM password policy file located at /etc/pam.d/common-password. Open this file to verify that the module is referenced correctly:

sudo nano /etc/pam.d/common-password

Ensure the following line is present above the pam_unix.so module line:

password requisite pam_pwquality.so retry=3

The retry=3 directive gives users three opportunities to enter a password that meets the defined complexity requirements before the passwd command exits.

Step 4: Test the Configuration

To verify that the rules are active, attempt to update a user’s password:

passwd

Try entering passwords that violate your rules (such as a short password or one missing special characters). PAM will reject the non-compliant passwords and output explicit error messages detailing why the password was declined.
