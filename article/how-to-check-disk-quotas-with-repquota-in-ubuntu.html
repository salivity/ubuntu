How to Check Disk Quotas with repquota in Ubuntu

Managing storage on a multi-user Ubuntu system requires monitoring disk usage, which is effectively handled using the repquota command. This article provides a straightforward guide on how to use repquota to generate comprehensive reports on user and group disk space usage, understand the command options, and interpret the generated system reports.

Prerequisites

Before running the repquota command, ensure that the quota package is installed on your Ubuntu system and that quotas are enabled on the target filesystem.

To install the quota tools, run:

sudo apt update
sudo apt install quota

Basic Command Syntax

The repquota command summarizes disk usage and quota limits for a specified filesystem. The basic syntax is:

sudo repquota [options] [filesystem]

Running repquota requires superuser privileges (sudo).

Generating a Standard User Quota Report

To generate a disk quota report for all users on a specific filesystem, specify the mount point (such as / or /home):

sudo repquota /home

To generate a report for all mounted filesystems that support quotas simultaneously, use the -a flag:

sudo repquota -a

Displaying Output in Human-Readable Format

By default, repquota displays disk space usage in 1-kilobyte blocks. To view the report in more intuitive units like Megabytes (M) or Gigabytes (G), add the -s (human-readable) flag:

sudo repquota -as

Generating Group Quota Reports

To view disk quota usage organized by user groups rather than individual users, use the -g flag alongside the target filesystem or the -a option:

sudo repquota -ag

To include both user and group reports in a human-readable format, combine the options:

sudo repquota -aug -s

Understanding the repquota Output

The output of repquota displays detailed statistics divided into two main categories: Block Limits (storage space) and File Limits (number of inodes/files).

Key columns in the report include:

  • User/Group: The name of the account being reported.
  • Status Flags (--): Indicates whether limits are exceeded. The first character shows block limit status, and the second shows file limit status (e.g., + indicates an exceeded soft limit).
  • used: Current amount of storage space or number of files used.
  • soft: The soft limit threshold. Exceeding this triggers a grace period before writes are restricted.
  • hard: The absolute limit. Users cannot exceed this value under any circumstances.
  • grace: The remaining time a user has to reduce their usage below the soft limit before write access is revoked.
