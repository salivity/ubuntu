How to Generate a GPG Key Pair in Ubuntu

This guide provides a straightforward walkthrough for generating and using a GPG (GNU Privacy Guard) key pair on Ubuntu. You will learn how to install the required software, generate your public and private cryptographic keys, export your public key for distribution, encrypt local files, and set up key signing for email communications.

1. Install GnuPG

Ubuntu typically comes with GnuPG pre-installed. If it is missing, open your terminal and install it using the Advanced Package Tool (APT):

sudo apt update
sudo apt install gnupg

2. Generate the GPG Key Pair

To generate a key pair with full control over the parameters, execute:

gpg --full-generate-key

Follow the interactive prompts:

  1. Algorithm: Select (1) RSA and RSA (default) by pressing Enter.
  2. Key Size: Enter 4096 for maximum security.
  3. Validity Period: Specify how long the key should be valid (e.g., 1y for one year, or 0 for no expiration). Confirm with y.
  4. User Identification: Enter your Real name and Email address. The email should match the address you plan to sign emails with. You can optionally add a comment. Confirm with O (Okay).
  5. Passphrase: A dialog will appear prompting you for a passphrase. Choose a strong, memorable passphrase to protect your private key.

3. Retrieve Your Key ID

To view the newly created key and identify its ID, run:

gpg --list-secret-keys --keyid-format LONG

Look for the line beginning with sec. The Key ID is the hexadecimal string following the slash in the algorithm line (e.g., in rsa4096/3AA5C34371567BD2, the Key ID is 3AA5C34371567BD2).

4. Export Your Public Key

Others need your public key to encrypt files for you or verify your signed emails. Export your public key to a file using ASCII armor format:

gpg --armor --export YOUR_KEY_ID > public_key.asc

You can share public_key.asc publicly, send it to correspondents, or upload it to public keyservers:

gpg --keyserver keyserver.ubuntu.com --send-keys YOUR_KEY_ID

5. Encrypt and Decrypt Files

Encrypting a File

To encrypt a file for a recipient (or yourself), obtain their public key, import it using gpg --import recipient_key.asc, and run:

gpg --encrypt --recipient recipient@example.com filename.txt

This creates an encrypted file named filename.txt.gpg.

Decrypting a File

To decrypt a file intended for you:

gpg --decrypt filename.txt.gpg > filename.txt

Enter your passphrase when prompted to complete the decryption.

6. Sign Emails Using GPG

Signing an email proves that the message originated from you and was not altered in transit.

Desktop Email Clients (e.g., Mozilla Thunderbird)

  1. Install Thunderbird via Ubuntu Software or run sudo apt install thunderbird.
  2. Open Account Settings and navigate to End-To-End Encryption under your email profile.
  3. Thunderbird automatically detects GPG keys on your system matching your account's email address. Select your generated Key ID under the OpenPGP section.
  4. Check the option to Sign unencrypted messages by default.

Command-Line Message Signing

To manually create a digitally signed text message for an email body:

gpg --clearsign message.txt

This produces a message.txt.asc file containing your original plaintext alongside an ASCII-armored digital signature block that can be copied directly into any email client.
