How to Use tpm2-tools with Hardware TPM on Ubuntu

This guide provides an overview and practical demonstration of using the tpm2-tools package to interact directly with a hardware Trusted Platform Module (TPM 2.0) on Ubuntu. You will learn how to verify hardware support in the Linux kernel, install the required user-space utilities, inspect platform capabilities, read Platform Configuration Registers (PCRs), generate cryptographically secure random numbers, and seal sensitive data directly to the hardware chip.

1. Verify TPM Hardware Detection

Before installing user-space tools, ensure that your motherboard's TPM 2.0 module is enabled in the BIOS/UEFI firmware and detected by the Linux kernel.

Run the following command to check for the TPM device nodes:

ls -l /dev/tpm*

If your hardware is enabled and supported, you should see /dev/tpm0 and /dev/tpmrm0 in the output. You can also inspect kernel boot messages:

dmesg | grep -i tpm

Look for output indicating that a TPM 2.0 device has been initialized by the tpm_tis or tpm_crb driver.

2. Install tpm2-tools

Ubuntu provides the tpm2-tools suite along with its supporting libraries (tpm2-tss) in the default repositories. Install the package using apt:

sudo apt update
sudo apt install tpm2-tools

3. Check TPM Capabilities and Specifications

To query the hardware specifications, manufacturer data, and supported algorithms, use the tpm2_getcap command.

To view fixed hardware properties (such as the manufacturer and firmware version):

tpm2_getcap properties-fixed

To list all available capability queries:

tpm2_getcap -l

4. Read Platform Configuration Registers (PCRs)

Platform Configuration Registers store cryptographic hashes representing the system's boot integrity state. You can read the current state of these registers across all supported hashing algorithms using:

tpm2_pcrread

To inspect specific algorithms (e.g., SHA-256) and specific registers (e.g., PCRs 0, 1, and 2):

tpm2_pcrread sha256:0,1,2

5. Generate Hardware Random Numbers

The TPM includes a true hardware Random Number Generator (TRNG). You can extract cryptographically secure random bytes directly from the module using tpm2_getrandom:

tpm2_getrandom --hex 32

This command outputs 32 bytes of entropy encoded in hexadecimal format.

6. Seal and Unseal Data Using the TPM

One of the primary security functions of a TPM is data sealing, which encrypts data using a key generated inside the TPM hardware so that it can only be decrypted by that specific machine.

Step A: Create a Primary Storage Key

Generate a primary key object under the Owner hierarchy (-C o):

tpm2_createprimary -C o -c primary.ctx

Step B: Seal Sensitive Data

Create a file containing your secret, then use the primary key to encrypt (seal) it:

echo "TopSecretPassword123" > secret.txt
tpm2_create -C primary.ctx -i secret.txt -u sealed_secret.pub -r sealed_secret.priv

This generates a public component (sealed_secret.pub) and an encrypted private component (sealed_secret.priv). The original secret.txt can now be safely deleted.

Step C: Load and Unseal the Data

To recover the data, load the sealed object into the TPM and unseal it:

tpm2_load -C primary.ctx -u sealed_secret.pub -r sealed_secret.priv -c secret.ctx
tpm2_unseal -c secret.ctx

The output will display the original decrypted string: TopSecretPassword123.

7. Manage Loaded Contexts

Loaded objects consume volatile memory inside the TPM. Once operations are complete, remove the transient context handles:

tpm2_flushcontext secret.ctx
tpm2_flushcontext primary.ctx
rm -f primary.ctx secret.ctx
