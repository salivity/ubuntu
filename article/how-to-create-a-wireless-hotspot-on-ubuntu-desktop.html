How to Create a Wireless Hotspot on Ubuntu Desktop

Transforming an Ubuntu desktop into a wireless hotspot allows you to share an existing internet connection with other devices like smartphones, tablets, and laptops. This guide provides direct, step-by-step instructions on configuring a Wi-Fi hotspot in Ubuntu using both the graphical user interface (GUI) and the command terminal.

Prerequisites

  • An Ubuntu desktop with a Wi-Fi network card that supports Access Point (AP) mode.
  • An active internet connection (typically via an Ethernet cable or a secondary network adapter).

Method 1: Create a Hotspot Using Ubuntu Settings (GUI)

This is the fastest and easiest method for most users.

  1. Open Settings: Click the top-right system tray menu and select Settings.
  2. Navigate to Wi-Fi: In the left sidebar, click on Wi-Fi.
  3. Turn On Wi-Fi: Ensure your Wi-Fi toggle switch is turned on.
  4. Open Hotspot Menu: Click the panel menu button (three vertical dots) in the top-right corner of the window and select Turn On Wi-Fi Hotspot…
  5. Configure Network Details:
    • Network Name: Enter your preferred SSID (hotspot name).
    • Password: Enter a secure network key (at least 8 characters).
  6. Activate: Click Turn On.

Ubuntu will now broadcast your wireless network and display a QR code on the screen, which mobile devices can scan to connect instantly.

Method 2: Create a Hotspot Using the Terminal (nmcli)

If you prefer using the command line or are working on a headless setup, use NetworkManager’s command-line tool (nmcli).

Step 1: Identify Your Wi-Fi Interface

Open a terminal (Ctrl + Alt + T) and run:

nmcli device

Look for the device name corresponding to your Wi-Fi card (commonly named wlan0 or wlp3s0).

Step 2: Create and Start the Hotspot

Execute the following command, replacing wlan0, MyUbuntuHotspot, and MySecurePassword with your interface name, desired SSID, and password:

nmcli device wifi hotspot ifname wlan0 ssid MyUbuntuHotspot password MySecurePassword

Step 3: Managing the Hotspot Connection

To stop the hotspot:

nmcli connection down Hotspot

To start an existing hotspot connection again:

nmcli connection up Hotspot

Verification and Troubleshooting

  • Verify AP Mode Support: If the hotspot fails to start, verify that your Wi-Fi adapter supports Access Point mode by running:

    iw list

    Look for AP under the “Supported interface modes” section.

  • Internet Sharing Issues: Ensure your Ethernet connection is active and set to share its connection automatically. Ubuntu handles IP assignment and routing via dnsmasq or iptables automatically upon hotspot creation.
