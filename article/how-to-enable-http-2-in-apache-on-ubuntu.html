How to Enable HTTP/2 in Apache on Ubuntu

Enabling HTTP/2 on an Apache web server running Ubuntu significantly improves website loading speed and resource efficiency through multiplexing, header compression, and prioritized streaming. This guide walks you through the straightforward process of preparing your server environment, switching to an asynchronous multi-processing module, enabling Apache's http2 module, and configuring your virtual hosts to serve traffic over HTTP/2 securely.

Prerequisites

Before proceeding, ensure you have:

  • Ubuntu 18.04 LTS or newer with Apache 2.4.24 or higher installed.
  • An active SSL/TLS certificate, as modern web browsers only support HTTP/2 over encrypted HTTPS connections.
  • Root or sudo administrative access.

Step 1: Switch the MPM to Event

HTTP/2 cannot run efficiently with the default mpm_prefork module because it processes requests using one thread per process. You must switch to mpm_event.

If you use PHP via mod_php, you must first disable it and switch to PHP-FPM, as mod_php requires mpm_prefork.

  1. Install PHP-FPM (replace 8.2 with your installed PHP version, if applicable):

    sudo apt install php-fpm

  2. Enable the required proxy modules for PHP-FPM:

    sudo a2enmod proxy_fcgi setenvif
sudo a2enconf php8.2-fpm

  3. Disable the prefork module and mod_php:

    sudo a2dismod php8.2
sudo a2dismod mpm_prefork

  4. Enable the event MPM:

    sudo a2enmod mpm_event

Step 2: Enable the HTTP/2 Module

Enable the Apache HTTP/2 module by running:

sudo a2enmod http2

Step 3: Configure Apache for HTTP/2

You can enable HTTP/2 globally or on specific virtual hosts.

Option A: Enable Globally

To apply HTTP/2 across all sites on your server, open the main configuration file:

sudo nano /etc/apache2/apache2.conf

Add the following directive at the bottom of the file:

Protocols h2 h2c http/1.1
  • h2: HTTP/2 over TLS (encrypted)
  • h2c: HTTP/2 over cleartext (unencrypted, fallback)
  • http/1.1: Fallback for clients that do not support HTTP/2

Option B: Enable Per Virtual Host

To apply HTTP/2 only to a specific SSL-enabled site, open your site's SSL configuration file (typically in /etc/apache2/sites-available/):

sudo nano /etc/apache2/sites-available/your-domain-le-ssl.conf

Inside the <VirtualHost *:443> block, add the directive:

<VirtualHost *:443>
    ServerName yourdomain.com
    Protocols h2 http/1.1
    
    # Existing SSL and directory configurations...
</VirtualHost>

Save and exit the editor.

Step 4: Test and Restart Apache

  1. Test your configuration for syntax errors:

    sudo apache2ctl configtest

    Ensure the output returns Syntax OK.

  2. Restart Apache to apply all changes:

    sudo systemctl restart apache2

Step 5: Verify HTTP/2 Support

Verify that HTTP/2 is active using curl:

curl -I --http2 -s https://yourdomain.com | grep HTTP

If HTTP/2 is successfully enabled, the output will display:

HTTP/2 200

Alternatively, open your browser's Developer Tools (Network tab), load your website, and check the "Protocol" column to confirm requests are being served over h2.
