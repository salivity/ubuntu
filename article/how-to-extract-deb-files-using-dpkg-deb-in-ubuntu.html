How to Extract DEB Files Using dpkg-deb in Ubuntu

Extracting the contents of a .deb package without installing it allows you to inspect its file structure, retrieve specific configuration files, or examine software binaries without altering your operating system. This guide provides a straightforward walkthrough on using Ubuntu's built-in dpkg-deb command-line tool to unpack both the system files and the control metadata from any .deb archive.

Extract System Files

To extract the files that the package would normally install into your root filesystem (such as binaries, documentation, and libraries), use the -x (extract) flag.

Open your terminal and run the following command:

dpkg-deb -x /path/to/package.deb /path/to/destination/

Replace /path/to/package.deb with the actual path to your package, and /path/to/destination/ with the folder where you want the extracted files placed. If the destination directory does not exist, dpkg-deb will create it automatically.

Extract Control and Metadata Files

Every .deb package contains a control archive that holds package metadata, pre- and post-installation scripts, and dependency definitions. To extract only these administrative files, use the -e (control extract) flag:

dpkg-deb -e /path/to/package.deb /path/to/destination/DEBIAN

This extracts scripts like postinst, prerm, and the control file directly into the specified directory.

Extract Everything (Files and Metadata) Together

If you want to extract the full contents of the package—both the filesystem files and the control metadata—into a single location, use the -R (raw extract) flag:

dpkg-deb -R /path/to/package.deb /path/to/destination/

This command places the control files inside a DEBIAN subfolder within your destination directory, while unpacking the regular filesystem files into their respective standard directory hierarchy alongside it.
