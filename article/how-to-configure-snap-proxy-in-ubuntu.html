How to Configure Snap Proxy in Ubuntu

This guide explains how to configure the snapd background service to route its traffic through a corporate HTTP or HTTPS proxy on Ubuntu. By applying proxy settings directly through the Snap management utility, Ubuntu systems operating inside restricted corporate networks can successfully search, download, and update Snap packages.

Step 1: Set the Proxy Configuration

Snap provides built-in system settings to route network traffic through corporate proxies. Open a terminal and run the following commands, replacing proxy.corp.example.com:8080 with your organization's proxy server address and port:

For HTTP traffic:

sudo snap set system proxy.http="http://proxy.corp.example.com:8080"

For HTTPS traffic:

sudo snap set system proxy.https="http://proxy.corp.example.com:8080"

If your corporate proxy requires authentication, include the credentials in the URL format:

sudo snap set system proxy.http="http://username:password@proxy.corp.example.com:8080"
sudo snap set system proxy.https="http://username:password@proxy.corp.example.com:8080"

Step 2: Verify the Settings

To ensure the settings have been applied correctly to the daemon, query the configuration using snap get:

sudo snap get system proxy

The output should display your configured http and https endpoints.

Step 3: Test the Connection

Verify that snapd can now connect to the Snap Store through the proxy by searching for or installing a package:

snap find hello-world

If the connection is successful, a list of available packages will be returned without connection timeout errors.

Removing Proxy Settings

If the machine is moved out of the corporate network or no longer requires a proxy, remove the configuration using snap unset:

sudo snap unset system proxy.http
sudo snap unset system proxy.https
