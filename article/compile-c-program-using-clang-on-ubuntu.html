Compile C Program Using Clang on Ubuntu

This guide explains how to build C programs on Ubuntu using the Clang compiler rather than the default GCC. You will learn how to install Clang via the official Ubuntu package manager, write a sample source file, compile the code into an executable binary using Clang commands, and apply common compilation flags.

1. Install Clang on Ubuntu

Before compiling, verify whether Clang is already installed on your system. Open the terminal and update the local package index, then install Clang using apt:

sudo apt update
sudo apt install clang -y

Once the installation finishes, confirm it was successful by checking the version:

clang --version

2. Create a Sample C Program

Create a simple C source file to test the compiler. You can use any text editor, such as Nano:

nano hello.c

Add the following standard C code to the file:

#include <stdio.h>

int main(void) {
    printf("Compiled successfully using Clang!\n");
    return 0;
}

Save and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

3. Compile the Program with Clang

To compile the C source file into an executable binary, run the clang command followed by the source filename. Use the -o flag to specify the output binary name:

clang hello.c -o hello

This syntax is virtually identical to GCC (gcc hello.c -o hello), making it straightforward to transition between the two compilers. If you omit the -o flag, Clang will create a default executable named a.out.

4. Execute the Compiled Binary

Run the compiled executable from your terminal:

./hello

You will see the output:

Compiled successfully using Clang!

5. Common Clang Compilation Flags

Clang shares most of its command-line flags with GCC. Here are frequently used options for compiling C code:

  • Enable Warnings: Add -Wall and -Wextra to catch potential bugs and code quality issues: 
    clang -Wall -Wextra hello.c -o hello
  • Optimization Levels: Use -O2 or -O3 to generate optimized production binaries: 
    clang -O2 hello.c -o hello
  • Debugging Information: Use -g to include debug symbols for use with tools like gdb or lldb: 
    clang -g hello.c -o hello
  • Specify C Standards: Use the -std flag to enforce a specific C standard (such as C11 or C17): 
    clang -std=c17 hello.c -o hello
