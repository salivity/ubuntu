How Often Are Non-LTS Ubuntu Versions Released?

Standard non-LTS (Long Term Support) Ubuntu releases, also known as interim releases, follow a strict six-month release cadence. Canonical releases these versions every year in April and October, except during the April of an even-numbered year when a Long Term Support version is issued instead. This article explains the release schedule, support lifecycle, version naming conventions, and the primary purpose of non-LTS Ubuntu versions.

The 6-Month Release Schedule

Ubuntu interim releases are published twice a year:

  • April Release: Launched in month 04 (e.g., 23.04, 25.04).
  • October Release: Launched in month 10 (e.g., 23.10, 24.10, 25.10).

Because LTS releases occur every two years in April of even-numbered years (such as 22.04 LTS or 24.04 LTS), the non-LTS releases fill the three 6-month gaps in between.

Support Lifecycle

Unlike LTS releases, which receive 5 years of standard support, non-LTS releases are supported for 9 months.

This 9-month support window provides a 3-month grace period after the subsequent version is released, giving users enough time to upgrade their systems before the current version reaches its End of Life (EOL). Once a non-LTS release reaches EOL, it no longer receives security patches, bug fixes, or package updates.

Version Naming Convention

Ubuntu versions use a YY.MM format reflecting the year and month of release:

  • 23.10 was released in October 2023 (Non-LTS).
  • 24.04 was released in April 2024 (LTS).
  • 24.10 was released in October 2024 (Non-LTS).
  • 25.04 will be released in April 2025 (Non-LTS).

Purpose of Non-LTS Versions

Standard non-LTS releases serve specific roles within the Ubuntu ecosystem:

  • Latest Features: They ship with the newest Linux kernels, updated desktop environments (like GNOME), and the latest compiler toolchains.
  • Testing Ground: They allow Canonical to introduce and refine new technologies before integrating them into the next rock-solid LTS release.
  • Developer Platform: Developers and enthusiasts who need cutting-edge software and hardware support use non-LTS versions to stay on the leading edge.

Upgrade Path

Users on a non-LTS release must upgrade sequentially every six months to remain supported. For example, a system on 23.10 must upgrade to 24.04 LTS, and then to 24.10. Skipping interim versions during an upgrade path is not officially supported without doing a clean installation.
