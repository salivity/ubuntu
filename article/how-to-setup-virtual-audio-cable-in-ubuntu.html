How to Setup Virtual Audio Cable in Ubuntu

Setting up a virtual audio cable in Ubuntu allows you to route audio output from one application directly into the input of another, which is ideal for streaming, recording, or sound processing. This guide provides a straightforward method to create virtual audio sinks and sources using native audio tools and pavucontrol, enabling flexible inter-app sound routing on both PipeWire and PulseAudio systems.

Step 1: Install PulseAudio Volume Control

While modern Ubuntu versions use PipeWire under the hood, PulseAudio management tools remain fully compatible and provide the easiest GUI for routing audio streams. Install pavucontrol by opening your terminal and running:

sudo apt update
sudo apt install pavucontrol

Step 2: Create the Virtual Audio Device

You can create a temporary virtual audio cable using the pactl command line utility. This command creates a “null sink” that acts as both a virtual speaker (output) and a virtual microphone (input monitor).

Run the following command in your terminal:

pactl load-module module-null-sink sink_name=Virtual_Cable sink_properties=device.description="Virtual_Audio_Cable"

Once executed, system audio settings will register a new output device called Virtual_Audio_Cable and a corresponding capture device named Monitor of Virtual_Audio_Cable.

Step 3: Route Audio Between Applications

  1. Open the application emitting audio (e.g., a media player, browser, or game) and start playing sound.
  2. Open the application receiving audio (e.g., OBS Studio, Audacity, or Discord).
  3. Open PulseAudio Volume Control by entering pavucontrol in your terminal or launching it from your application menu.
  4. Navigate to the Playback tab in pavucontrol. Locate the output application and change its destination dropdown from your default sound card to Virtual_Audio_Cable.
  5. Navigate to the Recording tab in pavucontrol. Locate the input application and set its audio source dropdown to Monitor of Virtual_Audio_Cable.

Audio playing from the source application will now flow directly into the destination application without playing through your physical speakers or capturing background noise from a physical microphone.

Step 4: Make the Virtual Cable Persistent (Optional)

The virtual device created via pactl disappears when you restart your system. To make the virtual audio cable permanent:

  1. Open the PulseAudio configuration file in a text editor:
sudo nano /etc/pulse/default.pa
  1. Scroll to the bottom of the file and add the following line:
load-module module-null-sink sink_name=Virtual_Cable sink_properties=device.description="Virtual_Audio_Cable"
  1. Save the file (Ctrl+O, then Enter) and exit (Ctrl+X).

Step 5: Remove the Virtual Audio Cable

If you created a temporary virtual cable and want to remove it without rebooting, unload the module using:

pactl unload-module module-null-sink
