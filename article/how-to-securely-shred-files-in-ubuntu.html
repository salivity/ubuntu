How to Securely Shred Files in Ubuntu

When you delete a file in Ubuntu using standard commands like rm or by emptying the trash, the underlying data remains on the storage drive until overwritten by new files. To permanently delete sensitive data and prevent recovery by forensic tools, Ubuntu provides the built-in shred command. This guide explains how to use shred to overwrite a file multiple times with random patterns, hide the shredding process, and remove the file completely from your system.

The Standard Shred Command

The primary tool used to securely obliterate files in Ubuntu is the shred utility, which is included by default via GNU coreutils.

To permanently destroy a file, use the following syntax:

shred -u -z -n 3 filename.txt

Explaining the Command Flags

Each option in the command serves a critical role in data destruction:

  • -n 3: Specifies the number of overwrite passes. By default, shred overwrites a file 3 times using pseudo-random data. You can replace 3 with any number (e.g., -n 5 or -n 10) depending on your security requirements.
  • -z: Adds a final overwrite pass using zeros (0x00). This hides the fact that the file was shredded, making it look like normal, blank space rather than suspicious random data.
  • -u: Deletes (unlinks) the file after all overwrite passes are finished. Without this flag, shred will overwrite the contents of the file, but the file name and empty allocation will remain visible in the directory.
  • -v (Optional): Enables verbose mode. Adding -v displays a real-time progress indicator showing each overwrite pass as it happens.

Practical Example

To securely overwrite a file named passwords.txt 5 times, fill it with zeros, and delete it while displaying progress, run:

shred -uvz -n 5 passwords.txt

Shredding Entire Partitions or Drives

The shred command can also target entire storage devices rather than individual files:

sudo shred -v -n 3 /dev/sdX

Note: Replace /dev/sdX with the target drive identifier. Do not use the -u flag on drive devices.

Considerations for Modern SSDs

The shred command is most effective on traditional magnetic hard drives (HDDs) and ext3/ext4 filesystems configured with standard data writeback modes. On modern Solid-State Drives (SSDs) and NVMe storage, hardware-level wear-leveling algorithms distribute writes across different physical blocks, meaning overwritten sectors might not map to the exact physical location of the original data. For total data destruction on SSDs, consider using hardware-level secure erase commands via nvme-cli or hdparm.
