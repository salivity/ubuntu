Monitor GPU Usage with nvidia-smi on Ubuntu

Monitoring your NVIDIA graphics card's metrics on Ubuntu is vital for tracking system health, debugging machine learning workloads, or optimizing graphical tasks. This guide outlines how to track GPU utilization, temperature, and VRAM in real-time using the native nvidia-smi command-line utility, ranging from simple looped displays to customized output formats.

Standard Real-Time Monitoring with nvidia-smi

The easiest way to track metrics continuously is using the built-in loop flag (-l or --loop) within nvidia-smi. This command refreshes the standard status table at a specified second interval:

nvidia-smi -l 1

Replace 1 with any desired interval in seconds. Each refresh displays:

  • Temperature: Current core temperature shown in Celsius under the Temp column.
  • VRAM Usage: Allocated memory versus total capacity under the Memory-Usage column.
  • GPU Utilization: Percentage of time the graphics processor kernel was active under the GPU-Util column.

Using the Ubuntu watch Command

Alternatively, the Linux watch utility provides a clean, flicker-free interface that clears the terminal on each update:

watch -n 1 nvidia-smi

The -n 1 flag configures the terminal to redraw the screen every second. Press Ctrl + C to exit the view.

Displaying Only Usage, Temperature, and VRAM

If you require a clean, minimal output or need to pipe data to a log file, query specific metrics directly using the --query-gpu flag combined with the loop command:

nvidia-smi --query-gpu=timestamp,temperature.gpu,utilization.gpu,memory.used,memory.total --format=csv -l 1

This returns a real-time CSV stream containing:

  • timestamp: Current system time.
  • temperature.gpu: Core GPU temperature in degrees Celsius.
  • utilization.gpu: Real-time percentage of compute load.
  • memory.used: Current VRAM in use (in MiB).
  • memory.total: Total available VRAM on the hardware (in MiB).
