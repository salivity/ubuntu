Mount S3 Bucket as Filesystem in Ubuntu

Mounting an Amazon S3 bucket as a local filesystem in Ubuntu allows you to interact with remote cloud storage just like a local directory using standard file operations. This guide demonstrates how to achieve this using s3fs-fuse, an open-source utility that backed-by-FUSE interface to mount S3 buckets. You will learn how to install s3fs, configure your AWS credentials securely, mount the bucket to a local mount point, and optionally configure automatic mounting at system startup.

Step 1: Install s3fs-fuse

Update your package list and install s3fs via the APT package manager:

sudo apt update
sudo apt install s3fs -y

Step 2: Configure AWS Credentials

You need an AWS Access Key ID and Secret Access Key with read/write permissions for your target S3 bucket.

  1. Create a hidden file to store your credentials:
echo ACCESS_KEY_ID:SECRET_ACCESS_KEY > ~/.passwd-s3fs

Replace ACCESS_KEY_ID and SECRET_ACCESS_KEY with your actual AWS credentials.

  1. Restrict file permissions so only your user can read it:
chmod 600 ~/.passwd-s3fs

To set up system-wide access (for all users), save the credentials to /etc/passwd-s3fs instead and apply chmod 600 /etc/passwd-s3fs.

Step 3: Create a Local Mount Point

Create the local directory where your S3 bucket contents will appear:

mkdir ~/s3bucket

Step 4: Mount the S3 Bucket

Run the s3fs command to mount your bucket to the newly created directory:

s3fs your-bucket-name ~/s3bucket -o passwd_file=~/.passwd-s3fs

Replace your-bucket-name with the exact name of your Amazon S3 bucket.

If your bucket is in a specific AWS region (e.g., us-west-2), specify the endpoint explicitly:

s3fs your-bucket-name ~/s3bucket -o passwd_file=~/.passwd-s3fs -o endpoint=us-west-2 -o url="https://s3.us-west-2.amazonaws.com"

Step 5: Verify the Mount

Check if the filesystem is mounted successfully using the df command:

df -h ~/s3bucket

You can now read, create, edit, and delete files inside ~/s3bucket, and changes will automatically sync to your Amazon S3 bucket.

Step 6: Unmount the Bucket

To unmount the S3 bucket when finished, use fusermount:

fusermount -u ~/s3bucket

Step 7: Mount Automatically at Boot (Optional)

To ensure the bucket automatically mounts whenever the system reboots, add an entry to /etc/fstab.

  1. Open /etc/fstab in a text editor:
sudo nano /etc/fstab
  1. Add the following line at the end of the file:
s3fs#your-bucket-name /home/username/s3bucket fuse _netdev,allow_other,passwd_file=/etc/passwd-s3fs 0 0

Make sure the credential file is placed in /etc/passwd-s3fs with 600 permissions for system-wide boot mounting to work.
