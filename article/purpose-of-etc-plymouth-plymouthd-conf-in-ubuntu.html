Purpose of /etc/plymouth/plymouthd.conf in Ubuntu

The /etc/plymouth/plymouthd.conf file is the primary configuration file for Plymouth, the graphical boot splash screen utility in Ubuntu. It controls how the system visually transitions from the initial bootloader to the desktop login screen by defining key parameters such as the active boot theme, splash delay times, and hardware display timeouts. Customizing this file allows system administrators and users to alter the default boot animation, brand the startup process, or troubleshoot display behavior during system boot and shutdown.

Key Functions of plymouthd.conf

Plymouth runs very early in the Ubuntu boot process inside the initial RAM file system (initramfs) before the main Xorg or Wayland display server loads. The /etc/plymouth/plymouthd.conf file configures the behavior of the plymouthd daemon during this phase.

1. Defining the Active Theme

The most common role of this file is setting the system-wide graphical theme. This is defined using the Theme directive under the [Daemon] configuration section.

[Daemon]
Theme=ubuntu-logo

While theme selection can also be managed via Ubuntu's update-alternatives system, specifying the theme directly in plymouthd.conf ensures Plymouth explicitly loads the designated theme directory from /usr/share/plymouth/themes/.

2. Controlling Splash Display Delay

The ShowDelay parameter determines the time in seconds Plymouth waits before displaying the splash screen graphic.

ShowDelay=0

On fast systems, a default delay prevents the screen from briefly flashing a splash animation for a split second. Setting ShowDelay=0 forces the splash screen to display immediately when Plymouth starts.

3. Setting Device Handling Timeouts

The DeviceTimeout directive controls how long Plymouth waits for graphics drivers and display hardware to initialize before falling back to a text-based output mode.

DeviceTimeout=8

If the graphics drivers fail to initialize within this window, Plymouth switches to text mode to ensure user prompts (such as disk encryption password entry) remain functional.

File Structure Example

A typical /etc/plymouth/plymouthd.conf file looks like this:

[Daemon]
Theme=ubuntu-logo
ShowDelay=0
DeviceTimeout=8

Applying Changes to plymouthd.conf

Because Plymouth runs before the main root filesystem is fully mounted, edits made to /etc/plymouth/plymouthd.conf must be compiled into the boot image to take effect.

  1. Open and edit the file using a text editor with root privileges: sudo nano /etc/plymouth/plymouthd.conf

  2. Rebuild the initramfs image to apply the changes to the boot process: sudo update-initramfs -u

  3. Reboot the machine to verify the boot customization: sudo reboot
