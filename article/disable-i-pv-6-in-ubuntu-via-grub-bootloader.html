Disable IPv6 in Ubuntu via GRUB Bootloader

This guide explains how to permanently and completely disable the IPv6 networking stack on Ubuntu by configuring GRUB boot parameters. While tools like sysctl can disable IPv6 on active network interfaces, passing the disable instruction directly to the Linux kernel via GRUB stops the IPv6 module from loading entirely at boot time. Below are the direct steps required to modify the GRUB configuration, apply the changes, and verify that IPv6 is fully disabled.

Step 1: Open the GRUB Configuration File

Open your terminal and launch the /etc/default/grub configuration file in a text editor with administrative privileges:

sudo nano /etc/default/grub

Step 2: Add the Kernel Parameter

Locate the line that begins with GRUB_CMDLINE_LINUX_DEFAULT. It typically looks like this:

GRUB_CMDLINE_LINUX_DEFAULT="maybe-ubiquity quiet splash"

(Note: Your default parameters inside the quotes may vary slightly depending on your Ubuntu release).

Append ipv6.disable=1 inside the quotation marks:

GRUB_CMDLINE_LINUX_DEFAULT="maybe-ubiquity quiet splash ipv6.disable=1"

If you also have a line named GRUB_CMDLINE_LINUX="", you can place it there instead to ensure it applies even if you boot into recovery mode:

GRUB_CMDLINE_LINUX="ipv6.disable=1"

Save your changes and exit the text editor (in nano, press Ctrl + O, hit Enter, and then press Ctrl + X).

Step 3: Update GRUB

For the bootloader to read your changes on the next boot, regenerate the GRUB configuration file using the following command:

sudo update-grub

Wait for the terminal to confirm that the GRUB configuration file has been generated successfully.

Step 4: Reboot the System

Restart your Ubuntu machine to boot into the kernel with the new parameter applied:

sudo reboot

Step 5: Verify That IPv6 Is Disabled

Once the system restarts, verify that the IPv6 stack has not been loaded.

  1. Check Network Interfaces: Run the address command:

    ip a

    Inspect the output. You should only see inet (IPv4) entries; there should be no inet6 entries listed under any network interface, including the loopback (lo) adapter.

  2. Check the IPv6 System Directory: Alternatively, check for the presence of the IPv6 networking directory:

    ls /proc/sys/net/ipv6

    If IPv6 is successfully disabled at the kernel level, this command will return an error stating No such file or directory.
