How to Manually Update Initramfs in Ubuntu

Updating the initial RAM filesystem (initramfs) in Ubuntu is a critical step whenever you add, remove, or modify kernel modules. This temporary root file system is loaded into memory during the boot process to prepare hardware and load necessary drivers before the main root file system mounts. This guide provides a straightforward, step-by-step process for manually regenerating your initramfs image using the update-initramfs tool to ensure your kernel module changes take effect properly on the next boot.

Step 1: Open the Terminal

Access your Ubuntu command line by pressing Ctrl + Alt + T or opening the Terminal application from your desktop environment.

Step 2: Choose the Appropriate Update Command

Ubuntu provides the update-initramfs utility to manage initramfs images. Depending on your needs, choose one of the following commands:

Option A: Update the Initramfs for the Currently Running Kernel

To update the initramfs for the active kernel version you are currently booted into, run:

sudo update-initramfs -u
  • -u: Flags the tool to update an existing initramfs image.

Option B: Update the Initramfs for a Specific Kernel Version

If you modified modules for a kernel version other than the one currently running, specify that version explicitly:

sudo update-initramfs -u -k <kernel_version>

Replace <kernel_version> with your target kernel (for example, 5.15.0-88-generic):

sudo update-initramfs -u -k 5.15.0-88-generic

Option C: Update the Initramfs for All Installed Kernels

To apply changes across every kernel installed on your system, use the all parameter:

sudo update-initramfs -u -k all

Step 3: Verify the Module Included in Initramfs (Optional)

To confirm that your updated kernel module is present inside the newly generated initramfs image, run lsinitramfs:

lsinitramfs /boot/initrd.img-$(uname -r) | grep <module_name>

Replace <module_name> with the name of the module you added or modified.

Step 4: Reboot Your System

Apply the changes by restarting your machine:

sudo reboot
