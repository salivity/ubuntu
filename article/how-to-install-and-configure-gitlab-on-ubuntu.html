How to Install and Configure GitLab on Ubuntu

This guide provides a step-by-step walk-through for installing and configuring GitLab Community Edition (CE) on an Ubuntu server. You will learn how to update your system, install necessary dependencies, add the official GitLab repository, install the package, set up your external URL, adjust firewall settings, and complete the initial administrator login.

Prerequisites

  • An Ubuntu server (20.04 LTS or 22.04 LTS recommended) with at least 4GB of RAM.
  • A user account with sudo privileges.
  • A domain name or public IP address pointing to your server.

Step 1: Update the System and Install Dependencies

Open your terminal and update your local package index to ensure all existing packages are up to date:

sudo apt update && sudo apt upgrade -y

Next, install the essential packages required by GitLab, including OpenSSH and Postfix (for sending notification emails):

sudo apt install -y curl openssh-server ca-certificates tzdata perl

During the Postfix installation, select Internet Site when prompted, and enter your server's domain name as the System Mail Name.

Step 2: Add the Official GitLab Repository

GitLab provides an automated script to add its repository to your system package sources. Run the following command:

cd /tmp
curl -sS https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.deb.sh | sudo bash

Step 3: Install GitLab Community Edition

To install GitLab and automatically configure it with your domain name or IP address, pass your address using the EXTERNAL_URL environment variable. Replace http://your_domain_or_ip with your actual domain or IP address:

sudo EXTERNAL_URL="http://your_domain_or_ip" apt install gitlab-ce

If you have a domain configured and want to automatically enable HTTPS encryption via Let's Encrypt, use https:// instead:

sudo EXTERNAL_URL="https://your_domain.com" apt install gitlab-ce

The installation process may take several minutes to complete as it configures all required components.

Step 4: Configure Firewall Rules

If you have the UFW firewall enabled, allow HTTP, HTTPS, and SSH traffic through the firewall:

sudo ufw allow OpenSSH
sudo ufw allow http
sudo ufw allow https

Check the status to ensure the rules are active:

sudo ufw status

Step 5: Initial Access and Root Login

Once the installation finishes, GitLab generates an initial administrative password valid for 24 hours. Retrieve the password using:

sudo cat /etc/gitlab/initial_root_password
  1. Open your web browser and navigate to your server's URL (e.g., http://your_domain_or_ip).
  2. Log in using the username root and the password retrieved from the step above.
  3. Go to User Settings -> Password to change the temporary root password immediately.

Step 6: Managing GitLab Services

You can manage the status of GitLab using the gitlab-ctl command-line utility:

  • Reconfigure GitLab: sudo gitlab-ctl reconfigure
  • Check Service Status: sudo gitlab-ctl status
  • Restart Services: sudo gitlab-ctl restart
  • Stop Services: sudo gitlab-ctl stop
