How to Set AppArmor Profile to Complain Mode in Ubuntu

AppArmor is a Linux kernel security module that restricts programs’ capabilities using per-program profiles. Switching an AppArmor profile into “complain” mode allows a program to run without enforcing restrictions, logging any actions that would have been blocked. This article explains the exact command used to switch AppArmor profiles to complain mode in Ubuntu, how to install the required utilities, and how to verify the mode changes.

The Command: aa-complain

To switch an AppArmor profile into complain mode, use the aa-complain command followed by the path to the executable or the profile name:

sudo aa-complain /path/to/executable

For example, to set the Apache web server profile to complain mode:

sudo aa-complain /usr/sbin/apache2

Prerequisites

The aa-complain tool is part of the apparmor-utils package. If the command is not found on your system, install it using apt:

sudo apt update
sudo apt install apparmor-utils

Step-by-Step Usage

1. Identify the Profile

AppArmor profiles are stored in the /etc/apparmor.d/ directory. You can list all active profiles and their current state using:

sudo aa-status

2. Switch to Complain Mode

Run aa-complain with root privileges targeting the application binary or profile file:

sudo aa-complain /usr/bin/ping

Alternatively, pass the profile file directly:

sudo aa-complain /etc/apparmor.d/bin.ping

3. Verify the Change

Check the AppArmor status again to confirm the profile has moved under the “complain mode” section:

sudo aa-status

Any policy violations committed by the application will now be logged to /var/log/syslog or /var/log/audit/audit.log instead of being prevented.

Reverting to Enforce Mode

Once testing or troubleshooting is complete, return the profile to strict security enforcement using the aa-enforce command:

sudo aa-enforce /usr/bin/ping
