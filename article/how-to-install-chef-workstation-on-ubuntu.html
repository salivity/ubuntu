How to Install Chef Workstation on Ubuntu

This guide outlines the process of installing and configuring Chef Workstation on an Ubuntu developer machine. You will learn how to download the official package, install it using the command line, configure your shell environment to utilize Chef's embedded tools, and verify the setup to start developing infrastructure code.

Step 1: Update Your System

Before installing new packages, ensure your system's package list is current:

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget apt-transport-https

Step 2: Download and Install Chef Workstation

The most reliable way to install Chef Workstation on Ubuntu is using the official installation script provided by Chef.

  1. Download and run the automated Omnitruck installation script:
curl -L https://omnitruck.chef.io/install.sh | sudo bash -s -- -P chef-workstation

Alternatively, you can manually download the .deb package from the Chef downloads portal and install it using dpkg:

wget https://packages.chef.io/files/stable/chef-workstation/23.7.1042/ubuntu/22.04/chef-workstation_23.7.1042-1_amd64.deb
sudo dpkg -i chef-workstation_*.deb

Step 3: Verify the Installation

Ensure all components—including Chef Infra Client, Chef InSpec, Cookstyle, and Test Kitchen—installed correctly by checking the version:

chef -v

This command outputs the versions of all integrated tools inside Chef Workstation.

Step 4: Configure the Shell Environment

Chef Workstation includes an isolated Ruby environment and associated command-line tools. Configure your shell to prioritize Chef's embedded binaries over system versions.

  1. Add Chef's shell initialization configuration to your .bashrc file:
echo 'eval "$(chef shell-init bash)"' >> ~/.bashrc
  1. Reload your environment:
source ~/.bashrc
  1. Verify that the active Ruby binary points to the Chef directory:
which ruby

The output should point to /opt/chef-workstation/embedded/bin/ruby.

Step 5: Generate a Chef Repository

Initialize a starter repository to organize your cookbooks, roles, and environments:

chef generate repo chef-repo
cd chef-repo

Step 6: Configure Knife for Chef Infra Server (Optional)

If your workflow requires communicating with a central Chef Infra Server:

  1. Create the configuration directory inside your repository:
mkdir -p .chef
  1. Create a config.rb file inside .chef/:
current_dir = File.dirname(__FILE__)
log_level                :info
log_location             STDOUT
node_name                'your_username'
client_key               "#{current_dir}/your_username.pem"
chef_server_url          'https://api.chef.io/organizations/your_org'
cookbook_path            ["#{current_dir}/../cookbooks"]
  1. Copy your user private key (your_username.pem) into the .chef directory and secure it:
chmod 600 .chef/your_username.pem
  1. Verify the server connection:
knife ssl check
