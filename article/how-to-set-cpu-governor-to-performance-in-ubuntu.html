How to Set CPU Governor to Performance in Ubuntu

This article explains how to configure the CPU frequency scaling governor in Ubuntu to prioritize system performance over energy efficiency. By default, Ubuntu often utilizes governors like powersave or schedutil to conserve battery and reduce heat. Switching to the performance governor forces the CPU cores to run at their maximum clock speeds, reducing execution latency and maximizing throughput for demanding workloads. The steps below cover checking current settings, switching governors immediately, and ensuring the configuration persists across system reboots.

1. Check Available and Active Governors

Before making any changes, verify what governor is currently running and whether the performance governor is supported on your hardware.

Open a terminal and view the active governor across all CPU cores:

cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

Next, check which governors are supported by your kernel driver:

cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_governors

You should see options such as performance, powersave, schedutil, or ondemand.

2. Install Linux Power Management Tools

The easiest and most reliable tool for managing CPU scaling on Ubuntu is cpupower, which is part of the standard Linux kernel tools.

Install the required packages for your current kernel:

sudo apt update
sudo apt install linux-tools-common linux-tools-generic linux-tools-$(uname -r)

3. Switch to the Performance Governor (Temporary)

To set all CPU cores to the performance governor immediately, execute:

sudo cpupower frequency-set -g performance

Alternatively, if you prefer not to install extra packages, you can write directly to the kernel sysfs interface:

echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

This change takes effect immediately, but it will revert back to the default governor upon restarting your computer.

4. Make the Performance Governor Persistent

To ensure the system automatically applies the performance governor on every boot, create a dedicated systemd service.

Step 1: Create a Systemd Service File

Create a new service file using a text editor such as nano:

sudo nano /etc/systemd/system/cpu-governor-performance.service

Step 2: Add the Service Configuration

Paste the following configuration into the file:

[Unit]
Description=Set CPU governor to performance
After=syslog.target

[Service]
Type=oneshot
ExecStart=/usr/bin/cpupower frequency-set -g performance
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target

Save the file and exit the editor (in nano, press Ctrl+O, Enter, and then Ctrl+X).

Step 3: Enable and Start the Service

Reload the systemd daemon to recognize the new file, enable it to run at boot, and start it:

sudo systemctl daemon-reload
sudo systemctl enable cpu-governor-performance.service
sudo systemctl start cpu-governor-performance.service

5. Verify the Changes

Confirm that the service is running and all cores are successfully operating under the performance governor:

cpupower frequency-info

Look for the line displaying current CPU frequency and ensure the active governor is listed as performance. The system will now maintain peak clock rates under all operating conditions.
