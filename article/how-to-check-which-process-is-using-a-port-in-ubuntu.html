How to Check Which Process is Using a Port in Ubuntu

Identifying which process is listening on a specific network port in Ubuntu is a common troubleshooting task for system administrators and developers. This article covers the most efficient terminal commands—lsof, ss, and fuser—to help you quickly find the Process ID (PID) and application name using any given port, along with how to stop those processes if necessary.

Method 1: Using lsof (List Open Files)

The lsof command is the most straightforward tool for finding processes tied to specific ports.

Run the following command, replacing 8080 with your target port number:

sudo lsof -i :8080

Output Breakdown

  • COMMAND: The name of the application (e.g., nginx, node, apache2).
  • PID: The Process ID assigned to the running application.
  • USER: The user account running the process.
  • NODE/NAME: The network protocol and port details.

Method 2: Using ss (Socket Statistics)

The ss command is a modern replacement for the older netstat tool and comes pre-installed on most Ubuntu distributions.

To search for a specific port using ss, combine it with grep:

sudo ss -tulpn | grep :8080

Command Flags Explained

  • -t: Display TCP sockets.
  • -u: Display UDP sockets.
  • -l: Show only listening sockets.
  • -p: Show the process using the socket.
  • -n: Show numerical addresses instead of resolving service names.

Method 3: Using fuser

The fuser utility displays the PIDs of processes using the specified files, file systems, or sockets.

To check a TCP port:

sudo fuser 8080/tcp

To see detailed output including the command name and user, add the -v (verbose) flag:

sudo fuser -v 8080/tcp

Terminating the Identified Process

Once you have identified the Process ID (PID) occupying your port, you can stop it using the kill command.

Replace 1234 with the PID found from the previous commands:

sudo kill 1234

If the process refuses to close gracefully, force it to stop using the -9 flag:

sudo kill -9 1234

Alternatively, you can kill the process directly using fuser by adding the -k flag:

sudo fuser -k 8080/tcp
