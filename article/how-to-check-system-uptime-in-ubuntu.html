How to Check System Uptime in Ubuntu

Checking how long an Ubuntu system has been running without a reboot is a simple task that can be accomplished using built-in terminal commands. The primary command used for this purpose is uptime, which displays the current time, how long the system has been up, the number of currently logged-in users, and the system load averages. This guide covers how to use the uptime command, its various options, and a few alternative commands to monitor your Ubuntu system’s runtime.

The Standard uptime Command

To display the current system uptime in Ubuntu, open your terminal (Ctrl+Alt+T) and execute:

uptime

Example Output:

 14:35:10 up 12 days,  4:22,  2 users,  load average: 0.15, 0.08, 0.05

Understanding the Output:

  • 14:35:10: The current system time.
  • up 12 days, 4:22: The length of time the system has been running (12 days, 4 hours, and 22 minutes).
  • 2 users: The number of currently logged-in user sessions.
  • load average: 0.15, 0.08, 0.05: The average CPU load over the last 1, 5, and 15 minutes, respectively.

Useful uptime Command Flags

The uptime command includes a couple of helpful options to format the output for easier reading or specific use cases.

1. Pretty Print (-p or --pretty)

If you only want to see how long the system has been running in a readable, simplified format, use the -p flag:

uptime -p

Output:

up 1 week, 5 days, 4 hours, 22 minutes

2. System Start Time (-s or --since)

To view the exact date and time the system was last booted, use the -s flag:

uptime -s

Output:

2023-10-15 10:13:10

Alternative Commands to Display Uptime in Ubuntu

Besides the uptime command, several other utilities display system uptime alongside other diagnostic information.

Using the w Command

The w command displays information about currently logged-in users and their processes. The very first line of the output matches the uptime command:

w

Using the top or htop Command

The top command provides a real-time view of running system processes. The top-left corner of the interface displays the system uptime.

top

Using systemd-analyze

If you are interested in how long the system took to boot up into usable userspace, you can use systemd-analyze:

systemd-analyze

Output:

Startup finished in 2.105s (kernel) + 12.410s (userspace) = 14.515s
graphical.target reached after 12.390s in userspace
