Install Google Cloud CLI with apt on Ubuntu

This guide provides the complete, step-by-step process for installing the Google Cloud CLI (gcloud) on Ubuntu using the apt package manager. You will learn how to configure Google's official package repository, import the required security keys, run the installation command, and initialize the CLI for managing your cloud infrastructure.

1. Install Prerequisites

Ensure your package list is current and install the necessary packages for secure repository access:

sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates gnupg curl

2. Import the Google Cloud Public Key

Import Google Cloud's public signing key to verify the integrity of the downloaded packages:

curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg

3. Add the Google Cloud CLI Repository

Add the official Google Cloud SDK repository to your system's package source list:

echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main" | sudo tee -a /etc/apt/sources.list.d/google-cloud-sdk.list

4. Install the Google Cloud CLI

Update your package index to include the newly added repository, then execute the installation command:

sudo apt-get update && sudo apt-get install -y google-cloud-cli

(Note: The command that installs the package itself is sudo apt-get install google-cloud-cli.)

5. Initialize the CLI

Once installed, run the initialization command to authenticate with your Google account, configure default settings, and select your active Google Cloud project:

gcloud init
