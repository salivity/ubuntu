How to Disable Ping in Ubuntu UFW Firewall

This guide provides a straightforward method for completely disabling Internet Control Message Protocol (ICMP) echo requests—commonly known as pings—using the Uncomplicated Firewall (UFW) in Ubuntu. By default, UFW allows incoming ICMP ping packets even when the firewall is active. To block these requests, you must modify UFW's underlying packet-filtering rules file and reload the firewall service.

Step 1: Open the UFW Rules File

UFW manages low-level iptables configurations using rule templates. Open the /etc/ufw/before.rules file in your preferred terminal text editor using root privileges:

sudo nano /etc/ufw/before.rules

Step 2: Locate the ICMP Rules

Scroll down through the file to find the block of rules dedicated to handling ICMP packets. Look for the section commented as:

# ok icmp codes for INPUT

Within this block, locate the line responsible for accepting echo requests:

-A ufw-before-input -p icmp --icmp-type echo-request -j ACCEPT

Step 3: Modify the Echo-Request Rule

To completely ignore ping requests, change the target policy from ACCEPT to DROP.

Modify the line to read:

-A ufw-before-input -p icmp --icmp-type echo-request -j DROP

If you prefer to reject the request and send a notification back to the sender rather than silently dropping it, replace ACCEPT with REJECT. However, DROP is recommended for hiding the server's presence.

(Optional) If your server uses IPv6 and you also want to block IPv6 pings, open the IPv6 rules configuration:

sudo nano /etc/ufw/before6.rules

Find the following line:

-A ufw6-before-input -p icmpv6 --icmpv6-type echo-request -j ACCEPT

Change it to:

-A ufw6-before-input -p icmpv6 --icmpv6-type echo-request -j DROP

Step 4: Save the Changes

In nano, save your edits by pressing Ctrl + O, hitting Enter to confirm the filename, and then exiting the editor with Ctrl + X.

Step 5: Reload UFW

Apply the updated configuration by reloading the UFW firewall:

sudo ufw reload

Step 6: Verify the Configuration

From another machine, attempt to ping the Ubuntu server's IP address:

ping <your_server_ip>

If the configuration was applied properly, the ping requests will time out, confirming that incoming ICMP echo requests are completely blocked.
