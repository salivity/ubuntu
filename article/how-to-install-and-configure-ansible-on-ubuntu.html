How to Install and Configure Ansible on Ubuntu

This guide provides a straightforward walk-through for installing and configuring the Ansible automation tool on an Ubuntu system. You will learn how to update your repository settings, install the Ansible package, configure your inventory file to manage remote nodes, set up SSH authentication, and test your setup using a basic ping command.

Step 1: Update the System and Add Ansible PPA

Open your terminal and update your local package index to ensure you get the latest software versions:

sudo apt update
sudo apt upgrade -y

Install the software-properties-common package, which makes managing software repositories easier:

sudo apt install software-properties-common -y

Add the official Ansible Personal Package Archive (PPA) to your system’s repository list:

sudo add-apt-repository --yes --update ppa:ansible/ansible

Step 2: Install Ansible

With the PPA added, install the Ansible package using apt:

sudo apt install ansible -y

After the installation finishes, verify that Ansible is installed correctly by checking its version:

ansible --version

Step 3: Configure the Ansible Inventory File

Ansible tracks the servers it manages using an inventory file located at /etc/ansible/hosts.

Open this file with your preferred text editor:

sudo nano /etc/ansible/hosts

Add your remote server IP addresses or domain names under group headers. For example:

[webservers]
192.168.1.50
192.168.1.51

[dbservers]
192.168.1.60

Save and close the file.

Step 4: Set Up SSH Key Authentication

Ansible uses SSH to communicate with managed nodes. Generate an SSH key pair on your control machine if you do not already have one:

ssh-keygen -t rsa -b 4076

Press Enter to accept the default file location and optional passphrase options.

Copy your public key to each remote host listed in your inventory:

ssh-copy-id username@remote_host_ip

Replace username with the remote user account name and remote_host_ip with the target server’s IP address.

Step 5: Test the Ansible Configuration

Verify that Ansible can communicate with all target servers by running the built-in ping module:

ansible all -m ping

If the setup is correct, you will receive a JSON response showing "ping": "pong" along with a green SUCCESS status for each configured host.
