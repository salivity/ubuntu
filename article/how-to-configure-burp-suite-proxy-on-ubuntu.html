How to Configure Burp Suite Proxy on Ubuntu

Configuring Burp Suite to intercept HTTP and HTTPS traffic on an Ubuntu desktop allows developers and security analysts to inspect and modify web requests in real time. This guide outlines the necessary steps to configure the local proxy listener, direct web browser traffic through Burp Suite, and install the trusted Certificate Authority (CA) certificate to enable HTTPS inspection without security warnings.

1. Verify the Proxy Listener in Burp Suite

Burp Suite runs an HTTP proxy service on a local port by default. Ensure the listener is active:

  1. Launch Burp Suite on your Ubuntu system.
  2. Navigate to the Proxy tab and select Proxy settings (or the Options tab in older versions).
  3. Under the Proxy Listeners table, verify that an entry exists for 127.0.0.1:8080 and that the Running checkbox is selected.
  4. If the listener is not running or needs modification, select it, click Edit, and configure the port (typically 8080) and bind address (typically 127.0.0.1 or Loopback only).

2. Using the Pre-Configured Embedded Browser (Recommended)

The simplest way to route traffic through Burp Suite without altering system-wide settings is to use the built-in Chromium browser:

  1. Go to the Proxy tab and select the Intercept sub-tab.
  2. Click Open Browser.
  3. The embedded browser will launch automatically configured to route traffic through 127.0.0.1:8080 with the Burp CA certificate already trusted.

3. Configuring an External Browser (e.g., Firefox)

To intercept traffic from an external browser installed on Ubuntu:

  1. Open Firefox and go to Settings.
  2. Scroll to the bottom of the General panel to find Network Settings, then click Settings....
  3. Select Manual proxy configuration.
  4. Set the HTTP Proxy to 127.0.0.1 and the Port to 8080.
  5. Check the box labeled Also use this proxy for HTTPS.
  6. Ensure the No proxy for field does not exclude domains you intend to test.
  7. Click OK to save the configuration.

4. Installing the Burp CA Certificate for HTTPS

To intercept encrypted HTTPS traffic without certificate validation errors, the Burp CA certificate must be imported into the browser's trust store:

  1. With the proxy running and your browser proxy settings enabled, navigate to http://burpsuite in your browser.
  2. Click on CA Certificate in the top-right corner of the web page to download cacert.der.
  3. In Firefox, return to Settings and search for Certificates, then click View Certificates....
  4. In the Authorities tab, click Import....
  5. Select the downloaded cacert.der file.
  6. Check the box labeled Trust this CA to identify websites, then click OK.

5. Intercepting Web Traffic

  1. In Burp Suite, go to the Proxy tab and click Intercept.
  2. Toggle the Intercept is off button to Intercept is on.
  3. In your configured browser, visit any website. The request will pause, allowing you to view and modify headers and parameters in Burp Suite before clicking Forward to release the request to the destination server.
