Configure Network Bonding Active-Backup on Ubuntu

Configuring a network bond in active-backup mode (mode 1) on Ubuntu allows two or more physical network adapters to act as a single logical interface, ensuring high availability and seamless fault tolerance. In this mode, only one slave interface is active at any given time; if the primary interface fails, the backup interface instantly takes over traffic handling without interrupting network connectivity. Modern Ubuntu installations manage this configuration natively using Netplan and systemd-networkd.

Step 1: Identify Physical Network Interfaces

First, discover the names of the physical network interfaces you plan to bond:

ip link show

Note the interface names that will form the bond (for example, enp3s0 and enp4s0). Make sure these interfaces are available and not actively bound to conflicting configurations.

Step 2: Ensure the Bonding Kernel Module Is Loaded

Load the kernel module required for network bonding and ensure it persists across system reboots:

sudo modprobe bonding
echo "bonding" | sudo tee -a /etc/modules

Verify that the module is active:

lsmod | grep bonding

Step 3: Configure Netplan

Netplan configuration files are stored in /etc/netplan/ as YAML files (such as 01-netcfg.yaml or 50-cloud-init.yaml).

  1. Create a backup of your existing configuration:
sudo cp /etc/netplan/*.yaml /etc/netplan/backup-netplan.yaml
  1. Open your Netplan configuration file for editing:
sudo nano /etc/netplan/01-netcfg.yaml
  1. Configure your physical interfaces and define the bonded interface (bond0). Replace the interface names, IP addresses, and gateway with values matching your network topology:
network:
  version: 2
  renderer: networkd
  ethernets:
    enp3s0:
      dhcp4: no
    enp4s0:
      dhcp4: no
  bonds:
    bond0:
      interfaces:
        - enp3s0
        - enp4s0
      addresses:
        - 192.168.1.50/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 1.1.1.1
          - 8.8.8.8
      parameters:
        mode: active-backup
        mii-monitor-interval: 100
        primary: enp3s0

Key Parameters:

  • mode: active-backup: Specifies fault tolerance mode.
  • mii-monitor-interval: 100: Sets the Media Independent Interface (MII) link monitoring frequency to 100 milliseconds to detect link failures quickly.
  • primary: enp3s0: (Optional) Designates the preferred active interface whenever it is online.

Step 4: Apply the Configuration

Test and apply the new configuration. Using netplan try is recommended to automatically revert changes if network connectivity is lost:

sudo netplan try

If the configuration works as expected, apply it permanently:

sudo netplan apply

Step 5: Verify the Bond Status

Check the status of the newly created bond0 interface:

ip link show bond0

Inspect the operational details and current active interface from the proc filesystem:

cat /proc/net/bonding/bond0

The output will confirm the bonding mode as fault-tolerance (active-backup), identify the currently active slave interface, and list all participating physical interfaces.

Step 6: Test Fault Tolerance

To test failover, simulate a link failure on the primary interface:

sudo ip link set enp3s0 down

Check /proc/net/bonding/bond0 again to verify that the backup interface (enp4s0) has taken over traffic without dropping connection state:

cat /proc/net/bonding/bond0

Re-enable the primary interface to verify recovery:

sudo ip link set enp3s0 up
