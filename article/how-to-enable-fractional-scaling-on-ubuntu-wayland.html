How to Enable Fractional Scaling on Ubuntu Wayland

Fractional scaling allows users with high-resolution monitors to scale their user interface by increments such as 125%, 150%, or 175%, avoiding the extremes of elements appearing too small at 100% or excessively large at 200%. On Ubuntu running the Wayland display server, fractional scaling is natively supported and can be configured through both the graphical user interface and the terminal. This guide covers how to enable fractional scaling on Ubuntu Wayland and how to ensure non-native applications render crisply.

Enable Fractional Scaling via Settings (GUI)

The simplest way to enable fractional scaling on Ubuntu Wayland is using the built-in system settings:

  1. Open the Settings application from your application menu or system tray.
  2. Select Displays from the left-hand navigation pane.
  3. Locate the Fractional Scaling toggle switch under the display configuration options and switch it to ON.
  4. Once enabled, new scaling values—such as 125%, 150%, and 175%—will appear alongside the default 100% and 200% options.
  5. Select your preferred scale factor and click the green Apply button in the top-right corner.
  6. A confirmation dialog will appear. Click Keep Changes if the display renders properly.

Enable Fractional Scaling via Terminal

If the fractional scaling toggle is not visible in your settings menu, or if you prefer using the command line, you can enable the feature directly via gsettings:

  1. Open your terminal by pressing Ctrl + Alt + T.
  2. Run the following command to enable Wayland monitor framebuffer scaling:
gsettings set org.gnome.mutter experimental-features "['scale-monitor-framebuffer']"
  1. Restart your session by logging out and logging back in.
  2. Return to Settings > Displays to choose your desired fractional scaling percentage.

To revert this setting via the terminal at any time, run:

gsettings reset org.gnome.mutter experimental-features

Improving Text Rendering on Legacy and Electron Applications

While native Wayland applications scale sharply at fractional values, legacy applications running through Xwayland (including Chrome, Spotify, and VS Code) may appear blurry. You can resolve this issue by forcing applications to run natively on Wayland:

  • For Chromium-based browsers (Chrome, Edge, Brave): Launch the browser with the following flags: 
    google-chrome --enable-features=UseOzonePlatform --ozone-platform=wayland
  • For Electron applications (VS Code, Discord): Append the same flags to their application shortcuts: 
    code --enable-features=UseOzonePlatform --ozone-platform=wayland

Running applications natively under Wayland ensures fonts and interface elements remain sharp regardless of the fractional scale factor chosen.
