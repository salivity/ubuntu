How to Install Rust Programming Language on Ubuntu

Installing the Rust programming language toolchain on Ubuntu is a straightforward process primarily handled through rustup, the official Rust installer and version management tool. This guide covers updating your system, installing required build dependencies, executing the rustup script, configuring your shell environment, and verifying that the Rust compiler (rustc) and package manager (cargo) are ready for development.

Step 1: Update Your Ubuntu System

Open your terminal and update your local package list to ensure your system has the latest software indexes:

sudo apt update && sudo apt upgrade -y

Step 2: Install Required Dependencies

Rust needs a linker and a C compiler to build binaries and native extensions. Install curl and the build-essential meta-package using apt:

sudo apt install curl build-essential gcc make -y

Step 3: Download and Run the Rustup Installer

Use curl to download and execute the standard Rust installation script from the official toolchain installer:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

During the interactive terminal prompt:

  1. Press 1 and hit Enter to select the default installation.

Step 4: Configure Your Shell Environment

Once the script finishes, apply the environment changes to your current terminal session by sourcing the Cargo environment file:

source "$HOME/.cargo/env"

The installer automatically adds the environment variables to your ~/.profile or ~/.bashrc file for future terminal sessions.

Step 5: Verify the Installation

Confirm that the Rust compiler (rustc) and package manager (cargo) are installed correctly by checking their versions:

rustc --version
cargo --version

Both commands should display the currently installed version numbers.

Maintaining Your Rust Toolchain

To update Rust to the latest release at any time, run:

rustup update

If you ever need to remove Rust completely from your system, run:

rustup self uninstall
