How to Install TeX Live Full on Ubuntu

This guide provides a straightforward walkthrough on how to install the complete LaTeX typesetting system, texlive-full, on Ubuntu. You will learn the exact terminal commands required to prepare your package manager, install the comprehensive TeX Live distribution, and verify that the installation succeeded so you can immediately begin compiling documents.

Prerequisites

Before proceeding, ensure you have:

  • An active Ubuntu installation with access to the terminal.
  • A user account with sudo privileges.
  • At least 5 to 7 GB of available disk space, as the complete TeX Live bundle includes all packages, fonts, and language extensions.

Step 1: Update System Repositories

Before installing new packages, update your local APT repository index to ensure you retrieve the latest available versions:

sudo apt update

Step 2: Install the Complete LaTeX System

To install the entire LaTeX environment with all optional utilities, styles, and fonts, execute the following command:

sudo apt install texlive-full

When prompted, press Y and hit Enter to confirm the installation. The download and configuration process may take several minutes depending on your internet connection speed and hardware performance.

Step 3: Verify the Installation

Once the installation process completes, verify that LaTeX is properly installed and accessible from your system path by checking the version of the PDFLaTeX compiler:

pdflatex --version

If the command outputs version information and licensing details for TeX Live, your complete LaTeX typesetting environment is ready for use.
