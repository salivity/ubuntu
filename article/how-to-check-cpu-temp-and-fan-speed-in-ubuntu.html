How to Check CPU Temp and Fan Speed in Ubuntu

Monitoring your hardware metrics helps prevent overheating and ensures your system runs smoothly. This guide provides a straightforward tutorial on how to check your CPU temperature and fan speeds in Ubuntu using the command-line tool lm-sensors and the graphical application Psensor.

Method 1: Using the Terminal (lm-sensors)

lm-sensors is the standard command-line utility for monitoring hardware temperature, voltage, and fan speeds in Linux.

Step 1: Install lm-sensors

Open your terminal (Ctrl + Alt + T) and run the following command:

sudo apt update && sudo apt install lm-sensors

Step 2: Detect Hardware Sensors

After installation, configure the program to detect your system's hardware sensors:

sudo sensors-detect

Press ENTER to accept the default answers for all prompts until the scan is complete.

Step 3: View Temperatures and Fan Speeds

To view your current CPU temperatures and fan speeds, run:

sensors

The output will display the core temperatures and the current RPM (revolutions per minute) of your active system fans.

To monitor these stats continuously in real-time (updating every 2 seconds), use:

watch sensors

Method 2: Using a Graphical Interface (Psensor)

If you prefer a visual interface with graphs and desktop notifications, Psensor is the best choice for Ubuntu.

Step 1: Install Psensor

Ensure lm-sensors is installed first, then install Psensor by running:

sudo apt install psensor

Step 2: Launch Psensor

Open your Ubuntu application menu, search for Psensor, and launch it.

The main window will display a real-time list and graph of your CPU core temperatures, fan speeds, motherboard temperatures, and memory usage. You can customize alarms and visualization settings by opening Psensor -> Preferences.
