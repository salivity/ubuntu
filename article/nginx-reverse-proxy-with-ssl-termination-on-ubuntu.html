Nginx Reverse Proxy with SSL Termination on Ubuntu

Setting up an Nginx reverse proxy with SSL termination on Ubuntu improves application performance and security by offloading encryption processing to Nginx. This step-by-step guide walks you through installing Nginx, configuring it to route traffic to a local backend application, obtaining a free SSL certificate using Let's Encrypt, and enabling automatic SSL certificate renewal.

Step 1: Install Nginx and Certbot

Update your local package index and install Nginx alongside Certbot, which automates the acquisition and renewal of SSL certificates.

sudo apt update
sudo apt install nginx certbot python3-certbot-nginx -y

Verify that Nginx is running:

sudo systemctl status nginx

Step 2: Configure the Reverse Proxy

Create a new Nginx server block file for your domain. Replace example.com with your actual domain name.

sudo nano /etc/nginx/sites-available/example.com

Add the following configuration, adjusting http://127.0.0.1:3000 to point to the address and port where your backend application runs:

server {
    listen 80;
    server_name example.com www.example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable the configuration by creating a symbolic link to the sites-enabled directory:

sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/

Test the configuration syntax and reload Nginx:

sudo nginx -t
sudo systemctl reload nginx

Step 3: Configure Firewall Rules

Allow HTTPS traffic through the UFW firewall:

sudo ufw allow 'Nginx Full'
sudo ufw delete allow 'Nginx HTTP'

Step 4: Obtain the SSL Certificate (SSL Termination)

Run Certbot with the Nginx plugin to obtain an SSL/TLS certificate and automatically configure SSL termination.

sudo certbot --nginx -d example.com -d www.example.com

Follow the prompts:

  1. Enter a valid email address for renewal notices.
  2. Agree to the Terms of Service.
  3. Choose whether to redirect HTTP traffic automatically to HTTPS (recommended).

Certbot updates your Nginx configuration in /etc/nginx/sites-available/example.com automatically. Nginx now handles incoming encrypted HTTPS connections on port 443, decrypts the traffic, and passes it unencrypted to your backend service on port 3000.

Step 5: Verify SSL Auto-Renewal

Let's Encrypt certificates are valid for 90 days. Certbot installs a systemd timer to renew them automatically. Test the renewal process with a dry run:

sudo certbot renew --dry-run

If the dry run completes without errors, your Nginx reverse proxy is successfully set up with SSL termination.
