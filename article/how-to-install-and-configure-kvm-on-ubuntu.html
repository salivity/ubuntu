How to Install and Configure KVM on Ubuntu

This article provides a complete guide on installing and configuring Kernel-based Virtual Machine (KVM) on an Ubuntu system. You will learn how to verify hardware virtualization support, install KVM alongside essential management tools, configure system permissions and networking, and deploy your first virtual machine using both command-line and graphical interfaces.

Step 1: Check Hardware Virtualization Support

Before installing KVM, verify that your CPU supports hardware virtualization (Intel VT-x or AMD-V).

Run the following command in your terminal:

egrep -c '(vmx|svm)' /proc/cpuinfo

If the output is 1 or greater, your system supports virtualization.

Next, install cpu-checker to confirm KVM compatibility:

sudo apt update
sudo apt install -y cpu-checker
kvm-ok

If the output states INFO: /dev/kvm exists and KVM acceleration can be used, proceed to the installation step.

Step 2: Install KVM and Virtualization Packages

Install KVM, the QEMU emulator, libvirt management tools, and related packages:

sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virt-manager

Package breakdown: * qemu-kvm: The underlying backend module for virtualization. * libvirt-daemon-system: System service for managing virtual machines. * libvirt-clients: Command-line software (virsh) to control VMs. * bridge-utils: Tools for configuring network bridges. * virt-manager: A desktop application for managing VMs.

Step 3: Enable and Verify the Libvirtd Service

Ensure the libvirtd service is enabled to start automatically on boot and is currently running:

sudo systemctl enable --now libvirtd
sudo systemctl status libvirtd

Step 4: Configure User Permissions

To manage virtual machines without using sudo, add your user account to the libvirt and kvm groups:

sudo usermod -aG libvirt $USER
sudo usermod -aG kvm $USER

Log out and log back in, or execute the following command to apply the group membership changes to your current terminal session:

newgrp libvirt
newgrp kvm

Step 5: Configure Virtual Networking

By default, KVM provides a NAT-based virtual network interface called virbr0. You can inspect active network interfaces using:

virsh net-list --all

If default is inactive, start it and set it to auto-start:

sudo virsh net-start default
sudo virsh net-autostart default

For direct network access where VMs appear on your physical local network, configure a bridged interface by editing your Netplan configuration file located in /etc/netplan/.

Step 6: Create a Virtual Machine

Option A: Using Virt-Manager (GUI)

  1. Launch Virt-Manager from your terminal or application launcher:

    virt-manager

  2. Click File > New Virtual Machine.

  3. Choose your installation media (e.g., an ISO image), allocate CPU cores, RAM, and disk storage, and finish the setup wizard.

Option B: Using Virt-Install (CLI)

To create a virtual machine directly from the command line, run:

sudo virt-install \
  --name=ubuntu-vm \
  --ram=2048 \
  --vcpus=2 \
  --disk size=20 \
  --os-variant=ubuntu22.04 \
  --network network=default \
  --graphics vnc \
  --cdrom=/path/to/ubuntu.iso

Replace /path/to/ubuntu.iso with the actual path to your operating system installer image.
