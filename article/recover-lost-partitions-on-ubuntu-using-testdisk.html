Recover Lost Partitions on Ubuntu Using TestDisk

TestDisk is a powerful, open-source data recovery utility designed to recover lost storage partitions and make non-booting disks bootable again. This guide provides a straightforward walkthrough on how to install TestDisk on Ubuntu using the standard terminal, configure its scan settings, and safely recover deleted or corrupted partition tables from your hard drives.

Step 1: Install TestDisk on Ubuntu

TestDisk is available directly in the default Ubuntu repositories.

  1. Open your terminal (Ctrl + Alt + T).
  2. Update your local package index: 
    sudo apt update
  3. Install TestDisk by running: 
    sudo apt install testdisk -y

Step 2: Launch TestDisk

Because modifying partition tables requires elevated privileges, you must run TestDisk with sudo.

  1. In your terminal, start the utility: 
    sudo testdisk
  2. You will be prompted to choose a logging option. Select Create to create a new log file (testdisk.log), which records all actions for troubleshooting, and press Enter.

Step 3: Select the Disk to Recover

  1. TestDisk will list all detected drives attached to your system (e.g., /dev/sda, /dev/sdb).
  2. Use the arrow keys to select the hard drive that contains the lost partition.
  3. Select Proceed and press Enter.

Step 4: Choose the Partition Table Type

TestDisk automatically detects and highlights the likely partition table type (such as Intel for MBR or EFI GPT for GPT disks).

  1. Accept the automatically selected default type unless you know your drive specifically uses a different architecture.
  2. Press Enter to continue.

Step 5: Scan for Lost Partitions

  1. From the main action menu, select Analyse and press Enter.
  2. TestDisk displays your current partition layout. Select Quick Search at the bottom and press Enter.
  3. TestDisk will scan the drive for missing or deleted partitions.

Step 6: Inspect and Recover Partitions

  1. Once the scan completes, a list of found partitions will appear.
  2. Highlight a partition and press P to view its files and folders. This confirms whether the partition contains your missing data. Press Q to exit the file preview and return to the partition list.
  3. If your partition is not listed in the initial results, select Deeper Search to perform a comprehensive scan of the drive.
  4. Ensure the correct partition status is assigned:
    • * (Primary Bootable)
    • P (Primary)
    • L (Logical)
    • D (Deleted)
    • Use the left/right arrow keys to switch a deleted (D) partition back to Primary (P) or Logical (L).
  5. Once the partitions are set correctly, press Enter.

Step 7: Write the New Partition Table

  1. Select Write from the bottom menu and press Enter.
  2. Confirm the write operation by typing Y when prompted. This saves the recovered partition structure to the disk.
  3. Select Quit to exit TestDisk.
  4. Restart your Ubuntu system for the kernel to recognize the restored partition table: 
    sudo reboot
