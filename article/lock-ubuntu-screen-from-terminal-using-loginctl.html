Lock Ubuntu Screen from Terminal Using loginctl

Locking your Ubuntu desktop directly from the command line is an efficient way to secure your workstation through scripts, remote SSH sessions, or custom keyboard shortcuts. This guide demonstrates how to use loginctl, the built-in systemd login manager control utility, to quickly lock your Ubuntu screen without needing third-party tools.

The Basic Lock Command

If you are running the command from a terminal emulator inside your active graphical desktop session, lock the screen immediately by running:

loginctl lock-session

This sends a lock signal to your current session via systemd-logind. Because standard Ubuntu installations run GNOME, the desktop environment automatically detects this signal and engages the lock screen.

Locking from an SSH Session or Different TTY

When accessing your system remotely over SSH or from a separate virtual console (TTY), running loginctl lock-session alone may not identify which graphical session you want to secure. In this scenario, target the session explicitly by following these steps:

  1. Identify your active session ID:
loginctl list-sessions

This outputs a table showing the SESSION, UID, USER, and SEAT. Look for the session assigned to your username with a seat identifier (typically seat0).

  1. Lock that specific session using its ID:
loginctl lock-session <SESSION_ID>

Replace <SESSION_ID> with the numeric ID found in the previous step (for example, loginctl lock-session 2).

Locking All Active Sessions

If the machine has multiple active user sessions or if you want to lock every logged-in screen simultaneously, use the plural variant of the command:

loginctl lock-sessions

This broadcasts a lock request across all active seats and displays on the system.
