Deploy Hugo with GitHub Actions on Ubuntu

This guide provides a straightforward walkthrough for setting up a continuous deployment pipeline for a Hugo static site using GitHub Actions and an Ubuntu runner. By automating the build and deployment process, every push to your default branch will automatically compile your Hugo markdown files, process your assets, and deploy the production-ready site to GitHub Pages.

1. Configure GitHub Pages Settings

Before writing the pipeline, set your repository to use GitHub Actions for deployment:

  1. Navigate to your repository on GitHub.
  2. Go to Settings > Pages.
  3. Under Build and deployment > Source, select GitHub Actions.

2. Create the Workflow File

GitHub Actions workflows are defined in YAML files located in the .github/workflows directory of your repository.

Create a new file named .github/workflows/hugo-deploy.yml in your project root.

3. Define the Workflow Configuration

Add the following YAML configuration to .github/workflows/hugo-deploy.yml. This script uses an ubuntu-latest runner to install Hugo, fetch dependencies, build the site, and publish the artifacts to GitHub Pages.

name: Deploy Hugo Site

on:
  push:
    branches:
      - main  # Set this to your default branch (e.g., main or master)
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          submodules: recursive
          fetch-depth: 0

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: 'latest'
          extended: true

      - name: Build Hugo Site
        run: hugo --minify

      - name: Upload Pages Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

4. Key Configuration Elements

  • runs-on: ubuntu-latest: Specifies that the job executes inside an Ubuntu virtual environment.
  • submodules: recursive: Ensures that Git submodules are cloned, which is critical if your Hugo theme is installed as a submodule.
  • fetch-depth: 0: Fetches the full Git history, enabling Hugo's .GitInfo object to correctly display page modification dates.
  • extended: true: Installs the Hugo Extended edition, which includes the LibSass engine required for processing SCSS/SASS stylesheets.
  • hugo --minify: Compiles your site into the ./public directory while minifying HTML, CSS, and JavaScript assets.
  • upload-pages-artifact & deploy-pages: The official GitHub Actions for packaging and deploying modern static sites securely without requiring a dedicated gh-pages branch.

5. Verify the Deployment

Commit and push the .github/workflows/hugo-deploy.yml file to your remote repository. Navigate to the Actions tab in GitHub to watch the workflow run. Once both the build and deploy jobs complete successfully, your site will be live at your designated GitHub Pages URL.
