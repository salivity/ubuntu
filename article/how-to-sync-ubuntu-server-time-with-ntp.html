How to Sync Ubuntu Server Time with NTP

Accurate time synchronization is critical for maintaining valid system logs, security certificates, scheduled cron jobs, and distributed database consistency on a Linux server. This guide demonstrates how to configure an Ubuntu server to synchronize its system time with Network Time Protocol (NTP) servers using both the default, lightweight systemd-timesyncd service and the more advanced chrony tool.

Option 1: Configure Time Sync using systemd-timesyncd

Modern Ubuntu versions come with systemd-timesyncd pre-installed as the default daemon for time synchronization. It is ideal for standard servers.

Step 1: Check Current Time Status

Run the following command to check the current time, timezone, and NTP synchronization status:

timedatectl status

Look for NTP service: active and System clock synchronized: yes in the output.

Step 2: Enable NTP Synchronization

If NTP service is not active, enable it with:

sudo timedatectl set-ntp true

Step 3: Configure Custom NTP Servers (Optional)

To specify preferred NTP servers (such as local pool servers or enterprise NTP servers), edit the configuration file:

sudo nano /etc/systemd/timesyncd.conf

Uncomment the NTP= line and add your desired NTP server addresses separated by spaces:

[Time]
NTP=0.ubuntu.pool.ntp.org 1.ubuntu.pool.ntp.org time.google.com
FallbackNTP=ntp.ubuntu.com

Save the file (Ctrl+O, Enter) and exit (Ctrl+X).

Step 4: Restart the Service

Apply the changes by restarting systemd-timesyncd:

sudo systemctl restart systemd-timesyncd

Verify synchronization using:

timedatectl show-timesync

Option 2: Configure Time Sync using chrony

For servers requiring high accuracy, rapid synchronization, or serving as an NTP server for local clients, chrony is recommended.

Step 1: Install Chrony

Installing chrony will automatically disable systemd-timesyncd to prevent conflicts.

sudo apt update
sudo apt install chrony -y

Step 2: Configure NTP Servers

Open the chrony configuration file:

sudo nano /etc/chrony/chrony.conf

Replace or add your preferred NTP pools or servers using the pool or server directive:

pool pool.ntp.org iburst
server time.cloudflare.com iburst

Save and close the file.

Step 3: Restart and Enable Chrony

Restart the chrony service to apply the configuration:

sudo systemctl restart chrony
sudo systemctl enable chrony

Step 4: Verify Chrony Synchronization

Check the active time sources and offset using chronyc:

chronyc sources

To see detailed tracking info (such as system offset and error bounds), run:

chronyc tracking
