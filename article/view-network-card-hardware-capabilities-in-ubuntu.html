View Network Card Hardware Capabilities in Ubuntu

This article explains how to inspect the detailed hardware capabilities of a network interface card (NIC) in Ubuntu. You will learn how to identify your network device name and use dedicated terminal utilities—primarily ethtool and lshw—to inspect supported link modes, port types, offload features, driver details, and hardware specifications.

Step 1: Identify Your Network Interface Name

Before querying hardware capabilities, identify the logical name of your network card using the ip command:

ip link

Look for interfaces such as eth0, enp3s0, or wlan0. Note down the name of the adapter you want to inspect.

Step 2: Use ethtool to View Detailed Capabilities

The standard and most comprehensive command to view network card hardware capabilities in Ubuntu is ethtool. If it is not installed on your system, install it using:

sudo apt update
sudo apt install ethtool

Basic Hardware and Link Capabilities

Run ethtool followed by your interface name:

sudo ethtool enp3s0

This outputs detailed hardware capabilities, including:

  • Supported link modes: The speeds and duplex configurations your physical card supports (e.g., 1000baseT/Full, 10000baseT/Full).
  • Supported ports: The physical connector types (e.g., Twisted Pair, Fiber).
  • Auto-negotiation: Whether the card supports auto-negotiating speeds.
  • Speed and Duplex: The currently active connection speed and state.

Protocol and Offload Capabilities

Modern network cards can offload tasks from the CPU. To inspect hardware offload capabilities (such as TCP segmentation offload, checksum offloading, and scatter-gather):

ethtool -k enp3s0

Features listed as [fixed] cannot be changed, while those marked on or off can be modified.

Driver and Firmware Information

To view the hardware's driver name, firmware version, and bus location:

ethtool -i enp3s0

Alternative Command: lshw

If you need deeper motherboard-level hardware details, the lshw (List Hardware) utility provides an overview of network hardware properties:

sudo lshw -C network

This displays the hardware vendor, product model, PCI bus information, clock speed, and a condensed capabilities line highlighting features like bus mastering, power management, and bandwidth limits.
