How to Generate an SSH Key Pair in Ubuntu

Generating an SSH key pair in Ubuntu provides a secure, passwordless method for authenticating with remote servers. SSH keys rely on asymmetric cryptography, using a private key kept securely on your local computer and a public key uploaded to the server. This guide walks you through creating your SSH key pair using the terminal, securing it with an optional passphrase, and transferring the public key to a remote system for instant access.

Step 1: Open the Terminal

Launch the terminal on your Ubuntu system by pressing Ctrl + Alt + T or searching for “Terminal” in your applications menu.

Step 2: Run the SSH Key Generation Command

Modern standards recommend using the Ed25519 algorithm for the best combination of security and performance. Run the following command:

ssh-keygen -t ed25519 -C "your_email@example.com"

Note: Replace your_email@example.com with your actual email address or a descriptive comment to help identify the key.

If your target server requires an older RSA key, generate a 4096-bit RSA key pair instead:

ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

Step 3: Choose a Save Location

After running the command, you will see a prompt asking where to save the key:

Enter file in which to save the key (/home/username/.ssh/id_ed25519):

Press Enter to accept the default file location (~/.ssh/id_ed25519). If you already have a key with that name, enter a custom file path to prevent overwriting your existing key.

Step 4: Set a Secure Passphrase

Next, you will be prompted to enter a passphrase:

Enter passphrase (empty for no passphrase):
  • Recommended: Type a strong passphrase for an added layer of security. This prevents unauthorized users from using your key if your local computer is compromised.
  • Optional: Press Enter twice to leave it empty for automatic, passwordless logins.

Step 5: Verify Key Pair Creation

Once complete, the system displays a key fingerprint and a visual randomart image. Your key pair is now saved in the ~/.ssh directory:

  • Private key: ~/.ssh/id_ed25519 (Never share this file)
  • Public key: ~/.ssh/id_ed25519.pub (Safe to share)

You can confirm the files exist by running:

ls -l ~/.ssh

Step 6: Copy the Public Key to a Remote Server

To use your key for remote authentication, upload the public key to your destination server using the ssh-copy-id tool:

ssh-copy-id username@remote_host

Replace username with your remote server’s user account and remote_host with the server’s IP address or domain name. Enter the remote user’s password when prompted.

Step 7: Authenticate Using Your SSH Key

Test your connection to the server:

ssh username@remote_host

If set up correctly, you will connect securely without entering your remote user password. If you set a passphrase in Step 4, you will be prompted to enter it now.
