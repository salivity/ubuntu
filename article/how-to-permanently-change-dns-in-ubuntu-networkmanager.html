How to Permanently Change DNS in Ubuntu NetworkManager

Changing DNS servers in Ubuntu can sometimes be frustrating because default settings often revert back to the router's automatic DNS after a system reboot. NetworkManager, which controls network settings in most modern Ubuntu releases, handles DNS through integration with systemd-resolved. This article explains how to permanently configure your custom DNS servers in Ubuntu using both the graphical interface and the nmcli command-line tool, ensuring your settings persist across reboots.

Method 1: Using NetworkManager Command-Line Tool (nmcli)

The nmcli command-line tool is the fastest and most reliable way to modify NetworkManager settings directly, especially on head-less servers or remote connections.

  1. Identify your active network connection name:

    nmcli connection show

    Note the name under the NAME column for your active connection (e.g., Wired connection 1 or netplan-eth0).

  2. Set your custom IPv4 DNS servers: Replace "Wired connection 1" with your actual connection name and enter your preferred primary and secondary DNS IP addresses separated by a space:

    sudo nmcli connection modify "Wired connection 1" ipv4.dns "1.1.1.1 8.8.8.8"

  3. Ignore automatic DNS provided by DHCP: To prevent your router from overriding your static DNS entries, set ipv4.ignore-auto-dns to yes:

    sudo nmcli connection modify "Wired connection 1" ipv4.ignore-auto-dns yes

  4. Reactivate the connection to apply changes:

    sudo nmcli connection up "Wired connection 1"

Method 2: Using NetworkManager Graphical User Interface (GUI)

If you are using Ubuntu Desktop, you can configure permanent DNS settings visually through the system settings menu.

  1. Open Settings and navigate to Network (for Ethernet) or Wi-Fi.
  2. Click the gear icon next to your active network connection to open its properties.
  3. Switch to the IPv4 tab at the top of the window.
  4. Toggle the Automatic switch next to the DNS section to the OFF position.
  5. In the DNS text field, enter your desired DNS IP addresses separated by a comma (e.g., 1.1.1.1, 8.8.8.8).
  6. Click Apply in the top-right corner.
  7. Turn your network connection off and back on to force NetworkManager to load the new settings.

Method 3: Global Override via systemd-resolved (Alternative)

If you want to apply custom DNS servers globally across all network interfaces instead of per-connection, edit the systemd-resolved configuration file.

  1. Open the configuration file in a text editor:

    sudo nano /etc/systemd/resolved.conf

  2. Uncomment the DNS= line (remove the #) and add your preferred DNS servers:

    [Resolve]
DNS=1.1.1.1 8.8.8.8

  3. Save the file (Ctrl+O, then press Enter) and exit (Ctrl+X).

  4. Restart the systemd-resolved service to activate the new global DNS servers:

    sudo systemctl restart systemd-resolved

Verifying Your New DNS Settings

To verify that your custom DNS servers are active and being used by systemd-resolved and NetworkManager, run:

resolvectl status

Look for the Current DNS Server and DNS Servers sections under your active link interface to confirm that your configured IP addresses are listed.
