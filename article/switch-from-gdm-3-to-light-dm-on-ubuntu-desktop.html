Switch from GDM3 to LightDM on Ubuntu Desktop

Ubuntu uses GDM3 (GNOME Display Manager) by default, but switching to LightDM offers a more lightweight and highly customizable login screen alternative. This guide walks you through the straightforward process of installing LightDM, setting it as your default display manager using Ubuntu's package configuration tools, and restarting the system to apply the changes safely.

Step 1: Update Package Lists

Open your terminal and ensure your local package index is up to date before installing new software:

sudo apt update

Step 2: Install LightDM

Install LightDM along with its default GTK greeter by running:

sudo apt install lightdm lightdm-gtk-greeter

Step 3: Choose LightDM as the Default Display Manager

During the installation process, a package configuration screen will automatically appear in your terminal asking you to choose your default display manager.

  1. Use the Up/Down arrow keys to highlight lightdm.
  2. Press Tab to select .
  3. Press Enter to confirm your selection.

If this prompt does not appear automatically, you can trigger it manually with the following command:

sudo dpkg-reconfigure lightdm

Step 4: Verify the Configuration

To confirm that LightDM is registered as the default display manager, check the contents of the display manager configuration file:

cat /etc/X11/default-display-manager

The output should read /usr/sbin/lightdm.

Step 5: Reboot Your System

To safely apply the changes, close any open work and reboot your machine:

sudo reboot

Upon boot, the system will load the LightDM login screen instead of GDM3.

How to Switch Back to GDM3

If you ever wish to revert to GDM3, run the reconfiguration tool again:

sudo dpkg-reconfigure gdm3

Select gdm3 from the list, press Enter, and reboot your computer.
