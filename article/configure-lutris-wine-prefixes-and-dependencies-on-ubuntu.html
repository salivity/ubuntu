Configure Lutris Wine Prefixes and Dependencies on Ubuntu

Managing Windows software on Ubuntu is streamlined using Lutris, an open-source gaming client that acts as a centralized manager for Wine environments. This guide explains how to configure Lutris to handle isolated Wine prefixes, customize Wine runner versions, and install critical Windows runtime dependencies such as DirectX, Visual C++ Redistributables, and .NET Framework via Winetricks to ensure maximum software compatibility.

1. Install Lutris and Wine Dependencies

Before configuring Lutris, ensure that Ubuntu has the latest graphics drivers and core Wine dependencies installed:

sudo dpkg --add-architecture i386
sudo apt update
sudo apt install wine64 wine32 libasound2-plugins:i386 libsdl2-2.0-0:i386 libdbus-1-3:i386 libsqlite3-0:i386
sudo add-apt-repository ppa:lutris-team/lutris
sudo apt update
sudo apt install lutris

2. Add Your Windows Application to Lutris

  1. Launch Lutris from your application menu.
  2. Click the + (Add) button in the top-left corner and select Add a locally installed game.
  3. Under the Game info tab:
    • Name your software.
    • Set the Runner to Wine (Runs Windows games).
  4. Under the Game options tab:
    • Executable: Browse to and select the .exe file of the installer or program.
    • Wine prefix: Specify a directory where you want this application's isolated Windows environment to live (e.g., /home/username/Games/prefixes/my-app). If the directory does not exist, Lutris will create it automatically.
    • Prefix architecture: Choose Auto, 64-bit, or 32-bit (use 32-bit for older software to improve compatibility).

3. Configure the Wine Runner

Lutris allows you to decouple your system Wine from the version used by your software:

  1. In the main Lutris window, hover over Wine under the "Runners" section in the left sidebar and click the Manage versions icon.
  2. Check and download specialized runners, such as lutris-GE-Proton or custom Wine-GE builds, which contain targeted patches for software and games.
  3. Right-click your application in Lutris, select Configure, and open the Runner options tab.
  4. Set the Wine version to the runner you downloaded.
  5. Enable or disable translation layers depending on your application's requirements:
    • Enable DXVK/VKD3D: Translates DirectX 9/10/11/12 calls to Vulkan (recommended for modern 3D software).
    • Enable Esync / Fsync: Enhances multithreading performance for compatible kernels.

4. Install Dependencies Using Winetricks

Many Windows programs require specific shared libraries to function properly. Lutris provides direct access to Winetricks for prefix management:

  1. Select your application in the Lutris interface.
  2. In the bottom toolbar, click the arrow next to the Wine icon (the wine glass) to open the control menu.
  3. Select Winetricks.
  4. In the Winetricks interface, select Select the default wineprefix and click OK.
  5. Select Install a Windows DLL or component.
  6. Select the dependencies required by your software. Common packages include:
    • vcrun2015, vcrun2019, or vcrun2022 (Visual C++ Runtimes)
    • d3dx9, d3dcompiler_43, d3dcompiler_47 (DirectX runtimes)
    • dotnet48 (.NET Framework)
    • corefonts (Standard Microsoft fonts)
  7. Click OK and follow the automated prompts until the installation completes.

5. Configure Wine and DLL Overrides

If a dependency requires a specific loading order:

  1. Click the Wine icon menu at the bottom and choose Wine configuration (winecfg).
  2. Navigate to the Libraries tab to verify or add DLL overrides (ensuring they are set to native or native, builtin).
  3. In the Applications tab, set the Windows Version (e.g., Windows 10 or Windows 7) based on what the application expects.
  4. Click Apply and OK.

You can now launch the software directly from the Lutris dashboard with all prefix parameters and dependencies preserved independently from other applications on your system.
