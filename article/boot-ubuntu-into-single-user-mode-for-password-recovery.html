Boot Ubuntu into Single-User Mode for Password Recovery

Booting Ubuntu into single-user mode allows administrators to bypass the standard login process and access a root shell for emergency maintenance. This guide explains how to access the GRUB bootloader, modify kernel parameters to initiate a single-user root environment, reset a forgotten user password using the passwd command, and safely reboot the system back into normal operating mode.

Step 1: Access the GRUB Boot Menu

  1. Restart or turn on your computer.
  2. Immediately access the GRUB menu:
    • For BIOS/Legacy systems, press and hold the Shift key as the computer boots.
    • For UEFI systems, tap the Escape (Esc) key repeatedly until the GRUB menu appears.

Step 2: Edit the Boot Parameters

  1. In the GRUB menu, highlight the default Ubuntu entry (usually the top option).
  2. Press the e key on your keyboard to enter edit mode.
  3. Use the arrow keys to scroll down and locate the line starting with linux. It will look similar to this: 
    linux /boot/vmlinuz-... root=UUID=... ro quiet splash $vt_handoff

Step 3: Modify the Kernel Line to Drop into a Root Shell

  1. Move your cursor to the end of the linux line.
  2. Remove the parameters ro, quiet, and splash if present.
  3. Replace them with the following directive to mount the filesystem as read-write and launch a root bash shell directly: 
    rw init=/bin/bash
  4. Press Ctrl + X or F10 to boot with these temporary parameters.

Step 4: Reset the Forgotten Password

Your machine will bypass the standard startup sequence and load directly into a root terminal prompt (root@(none):/#).

  1. Confirm the root filesystem is mounted with write permissions: 
    mount -o remount,rw /
  2. Reset your user password by typing passwd followed by your username: 
    passwd your_username
  3. Enter and confirm the new password when prompted.

Step 5: Reboot into Normal Mode

Once the password has been successfully updated, reboot the computer to return to the standard login screen:

exec /sbin/init

If the system does not restart with that command, force a clean reboot by running:

reboot -f

Your system will boot normally, and you can log in using your newly set password.
