Prioritize Local Users Over LDAP in Ubuntu nsswitch.conf

This guide explains how to configure the /etc/nsswitch.conf file on Ubuntu to ensure the operating system resolves local users and groups before querying an LDAP directory service. Prioritizing local authentication ensures critical system accounts remain accessible during network outages, speeds up local command execution, and prevents directory service latency from affecting system performance.

Understanding the Name Service Switch

The Name Service Switch configuration file, located at /etc/nsswitch.conf, dictates the order in which Ubuntu queries various identity sources.

When resolving user accounts, groups, and passwords, the system looks at three primary databases:

  • passwd: User account information.
  • group: Group membership definitions.
  • shadow: Secure password hashes.

The sources specified for these databases are evaluated from left to right. To prioritize local users over LDAP users, the files directive (representing local files such as /etc/passwd) must precede the LDAP directive (typically sss for SSSD, or ldap for legacy libnss-ldap).

Step-by-Step Configuration

1. Back Up the Existing Configuration

Before editing system configuration files, create a backup to prevent unintended access issues:

sudo cp /etc/nsswitch.conf /etc/nsswitch.conf.bak

2. Edit /etc/nsswitch.conf

Open the file in a text editor with administrative privileges:

sudo nano /etc/nsswitch.conf

3. Reorder the Lookup Sources

Locate the lines beginning with passwd:, group:, and shadow:.

Ensure that files appears before sss or ldap.

For modern Ubuntu systems using SSSD (System Security Services Daemon):

passwd:         files systemd sss
group:          files [SUCCESS=merge] systemd sss
shadow:         files sss
gshadow:        files

Note: The [SUCCESS=merge] entry on the group line ensures that if a group exists both locally and in LDAP, memberships from both sources are merged rather than stopping search evaluation immediately.

For systems using traditional libnss-ldap:

passwd:         files ldap
group:          files ldap
shadow:         files ldap

Save the file and exit the editor (in nano, press CTRL+O, Enter, then CTRL+X).

4. Restart Name Caching Services

Changes to /etc/nsswitch.conf take effect immediately for new processes. However, if a caching daemon such as nscd or sssd is active, clear the cache or restart the service to apply changes consistently.

If using SSSD:

sudo systemctl restart sssd

If using nscd:

sudo systemctl restart nscd

Verification

To verify that local lookups take precedence:

  1. Test user identity resolution for a local user: 
    getent passwd <local_username>
  2. Test resolution for an LDAP user: 
    getent passwd <ldap_username>

Because files is listed first, the operating system will match any user defined in /etc/passwd before reaching out to the LDAP provider across the network.
