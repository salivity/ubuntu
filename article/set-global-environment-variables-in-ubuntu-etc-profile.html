Set Global Environment Variables in Ubuntu /etc/profile

Managing global environment variables in Ubuntu allows you to define system-wide configuration settings accessible by all users and processes. By modifying the /etc/profile file, you can permanently set environment variables that automatically initialize during interactive login shells. This guide provides a step-by-step walk-through on how to edit /etc/profile, export new variables, apply your changes, and verify that they are working correctly across the system.

Step 1: Open /etc/profile in a Text Editor

To set environment variables globally, you need administrative privileges. Open the /etc/profile file using a terminal text editor such as nano:

sudo nano /etc/profile

Step 2: Add Your Environment Variable

Scroll to the bottom of the file and add your variable using the export keyword followed by the variable name and value:

export VARIABLE_NAME="value"

For example, to set a global environment mode or append a custom path:

export APP_ENV="production"
export PATH="$PATH:/opt/my_application/bin"

Save the file in nano by pressing Ctrl + O, pressing Enter, and then exiting with Ctrl + X.

Step 3: Apply the Changes

Modifications to /etc/profile do not automatically take effect in open terminal sessions. To apply the changes to your current session immediately, execute:

source /etc/profile

For other users or system services, the new variables will take effect automatically upon their next login.

Step 4: Verify the Global Variable

To confirm that the environment variable is active and accessible, use the echo command:

echo $APP_ENV

If set correctly, the terminal will print the value assigned to the variable (e.g., production).

Recommended Alternative: Using /etc/profile.d/

While modifying /etc/profile directly works, Ubuntu best practices recommend placing custom environment scripts inside the /etc/profile.d/ directory. This prevents your custom configurations from being overwritten during system upgrades.

  1. Create a new .sh script in /etc/profile.d/:
sudo nano /etc/profile.d/custom_vars.sh
  1. Add your export commands:
export GLOBAL_SETTING="enabled"
  1. Save and close the file. Every script in /etc/profile.d/ ending with .sh is automatically read and executed by /etc/profile when a user logs in.
