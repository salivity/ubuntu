How to Use the Disown Command in Ubuntu

When you close a terminal session in Ubuntu, any processes started within that shell are automatically terminated by a hangup signal (SIGHUP). The disown command prevents this by removing active jobs from the shell’s job table, allowing commands and long-running scripts to continue running uninterrupted in the background even after you exit the session.

Detaching an Already Running Process

If a process is currently running in your foreground, you can detach it using the following steps:

  1. Suspend the process: Press Ctrl + Z to pause the current running task. This returns you to the shell prompt and assigns a job number.
  2. Move the process to the background: Type the following command to resume execution in the background: 
    bg
  3. List active jobs: Confirm the job ID and process ID (PID) by running: 
    jobs -l
    You will see an output similar to: 
    [1]+ 12345 Running    python3 script.py &
  4. Disown the job: Detach the job using its job number: 
    disown %1
    Replace 1 with the corresponding job number displayed by jobs -l.

Once executed, the process will no longer be tracked by your current shell and will not receive the SIGHUP signal when you exit.

Running and Disowning a Process Immediately

To launch a process in the background and immediately detach it in a single command, append & followed by disown:

python3 script.py & disown

This starts script.py in the background and separates it from the shell session without requiring you to manually suspend it.

Useful disown Options

The disown utility provides flags to customize how jobs are detached:

  • Keep in job table but ignore hangup signals (-h): If you want the job to remain visible in your jobs list while still protecting it from session termination, use the -h flag: 
    disown -h %1
  • Disown all background jobs (-a): To detach every currently active job in the shell at once, run: 
    disown -a
  • Disown only running jobs (-r): To detach only jobs that are actively running (ignoring suspended ones): 
    disown -r

Verifying the Process Status

After disowning a process, it will no longer appear when you run the jobs command. To confirm it is still running, query the system process table using ps or pgrep:

ps aux | grep script.py

The process will remain active under the management of the systemd init process (PID 1) after you close the terminal.
