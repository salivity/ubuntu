Install xrdp for Windows Remote Desktop on Ubuntu

This guide provides a straightforward tutorial on how to install and configure the xrdp server on an Ubuntu system, allowing you to connect to your Linux desktop remotely using the built-in Windows Remote Desktop Connection tool. You will learn the necessary commands to update your system, install the package, configure system permissions, adjust firewall rules, and successfully establish a remote session.

Step 1: Update Ubuntu Package Index

Open your terminal on Ubuntu and run the following command to ensure your package list is up to date:

sudo apt update && sudo apt upgrade -y

Step 2: Install xrdp

Install the xrdp package along with the default Ubuntu desktop environment packages if they are not already installed:

sudo apt install xrdp -y

Once the installation completes, verify that the service is running:

sudo systemctl status xrdp

If the service is not active, start and enable it to run on boot:

sudo systemctl enable --now xrdp

Step 3: Grant User Permissions

By default, xrdp uses the /etc/ssl/private/ssl-cert-snakeoil.key file, which is readable only by members of the ssl-cert group. Add the xrdp user to this group:

sudo adduser xrdp ssl-cert

Restart the service to apply the change:

sudo systemctl restart xrdp

Step 4: Configure the Firewall

Allow incoming traffic on port 3389, which is used by the Remote Desktop Protocol (RDP).

To allow access from any IP address:

sudo ufw allow 3389/tcp

To restrict access to a specific local network IP range (for better security, replace 192.168.1.0/24 with your network range):

sudo ufw allow from 192.168.1.0/24 to any port 3389

Reload UFW to apply the rules:

sudo ufw reload

Step 5: Prevent Black Screen Issues

To prevent a black screen upon logging in, log out of any active local session on the Ubuntu machine before connecting remotely. Alternatively, configure the .xsession file for your user if you encounter desktop environment issues:

echo "gnome-session" > ~/.xsession

Step 6: Connect from Windows

  1. Open the Remote Desktop Connection app (mstsc.exe) on your Windows PC.
  2. Enter the IP address of your Ubuntu machine into the Computer field.
  3. Click Connect.
  4. When prompted by the security warning regarding the SSL certificate, click Yes to proceed.
  5. In the xRDP login window, select Xorg as the session type, enter your Ubuntu username and password, and click OK.
