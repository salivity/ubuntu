Install and Configure MongoDB on Ubuntu

Installing and configuring MongoDB on an Ubuntu system allows developers to leverage a powerful, document-oriented NoSQL database for modern web applications. This guide provides a step-by-step walkthrough covering how to import the official MongoDB repository, install the database using the APT package manager, configure basic service settings, and secure your database instance for production use.

Prerequisites

Before starting, ensure you have:

  • An Ubuntu server (20.04 or 22.04 LTS recommended).
  • A user account with sudo privileges.

Step 1: Import the MongoDB Public GPG Key

To ensure the authenticity of the MongoDB packages, import the official MongoDB GPG key using curl and gnupg.

Run the following commands:

sudo apt update
sudo apt install curl gnupg openpgp-keys-mongodb -y
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg --dearmor -o /usr/share/keyrings/mongodb-server-7.0.gpg

Step 2: Add the MongoDB Repository

Add the MongoDB 7.0 repository location to your system's sources list so APT knows where to download the packages.

For Ubuntu 22.04 (Jammy), run:

echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

For Ubuntu 20.04 (Focal), replace jammy with focal:

echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list

Step 3: Install MongoDB

Update the local package database to include the newly added repository, then install the mongodb-org meta-package:

sudo apt update
sudo apt install -y mongodb-org

This package installs the MongoDB server daemon (mongod), administrative scripts, shell (mongosh), and core utilities.

Step 4: Start and Enable MongoDB Service

By default, MongoDB does not start automatically after installation.

  1. Start the MongoDB service:

    sudo systemctl start mongod

  2. Enable MongoDB to launch automatically upon system boot:

    sudo systemctl enable mongod

  3. Verify that the service is running:

    sudo systemctl status mongod

You should see an output indicating that the service is active (running).

Step 5: Configure MongoDB

MongoDB's primary configuration file is located at /etc/mongod.conf.

Configure Network Access (Optional)

By default, MongoDB only listens for connections from 127.0.0.1 (localhost). If your application runs on a separate server, you need to update the binding address.

  1. Open the configuration file:

    sudo nano /etc/mongod.conf

  2. Locate the net section and update bindIp:

    net:
  port: 27017
  bindIp: 127.0.0.1,YOUR_SERVER_IP

  3. Save and close the file (Ctrl+O, Enter, Ctrl+X).

  4. Restart MongoDB to apply the changes:

    sudo systemctl restart mongod

Step 6: Enable Authentication and Secure MongoDB

By default, MongoDB does not require authentication. To secure your instance:

  1. Access the MongoDB Shell:

    mongosh

  2. Switch to the admin database:

    use admin

  3. Create a root administrator user:

    db.createUser({
  user: "adminUser",
  pwd: passwordPrompt(),
  roles: [ { role: "userAdminAnyDatabase", db: "admin" }, "readWriteAnyDatabase" ]
})

    Type a secure password when prompted, then exit the shell:

    exit

  4. Edit /etc/mongod.conf to enable authorization:

    sudo nano /etc/mongod.conf

  5. Find the security section and uncomment/update it to match:

    security:
  authorization: enabled

  6. Restart the MongoDB service:

    sudo systemctl restart mongod

Step 7: Test Authentication

Verify that access restrictions are working by logging in with the administrative credentials created earlier:

mongosh -u adminUser -p --authenticationDatabase admin

After entering your password, you will have authenticated access to the MongoDB server environment.
