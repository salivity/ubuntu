How to Generate WireGuard Keys on Ubuntu

This article explains how to generate the public and private cryptographic key pairs required to configure a secure WireGuard VPN interface on Ubuntu. WireGuard relies on asymmetric encryption, requiring each peer to possess a private key for decrypting incoming traffic and a corresponding public key shared across the network to establish authenticated handshakes.

Prerequisites

Ensure the WireGuard tools are installed on your Ubuntu system by running:

sudo apt update && sudo apt install wireguard -y

The Key Generation Command

The standard command used to generate both the private and public keys simultaneously is:

umask 077 && wg genkey | tee privatekey | wg pubkey > publickey

How the Command Works

  • umask 077: Sets the file creation mask so that only the current user has read and write permissions, preventing unauthorized users on the system from viewing the private key.
  • wg genkey: Generates a secure, random, base64-encoded private key.
  • tee privatekey: Saves the generated private key to a file named privatekey while passing the output along the pipeline.
  • wg pubkey: Reads the private key from standard input and derives the matching base64-encoded public key.
  • > publickey: Writes the derived public key to a file named publickey.

Generating Keys Separately

Alternatively, you can generate the keys in two distinct steps.

Generate the private key:

wg genkey > privatekey
chmod 600 privatekey

Derive the public key from the generated private key:

wg pubkey < privatekey > publickey

Once generated, view the contents of the files using cat privatekey and cat publickey to paste them into your WireGuard interface configuration file (typically located at /etc/wireguard/wg0.conf).
