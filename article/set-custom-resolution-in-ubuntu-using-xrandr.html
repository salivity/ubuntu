Set Custom Resolution in Ubuntu Using xrandr

Setting a custom display resolution in Ubuntu running an X11 session allows you to use unsupported monitor modes or improve visual clarity on unique displays. By using the built-in xrandr command-line utility along with cvt, you can calculate new display timings, create a custom mode, attach it to your output, and apply it immediately. This guide explains the step-by-step process to configure your custom resolution and ensure it persists across reboots.

Step 1: Identify Your Display Output

Open your terminal (Ctrl+Alt+T) and list your connected displays and active resolutions:

xrandr

Look for the connected output interface in the list (such as HDMI-1, eDP-1, or DP-1). Note this exact output name for the following steps.

Step 2: Generate Resolution Timings

Use the cvt command followed by your desired width, height, and refresh rate (in Hz) to generate a modeline string. For example, to create a resolution of 1920x1080 at 60Hz:

cvt 1920 1080 60

The terminal will output a line similar to this:

# 1920x1080 59.96 Hz (CVT 2.07M9) hsync: 67.16 kHz; pclk: 173.00 MHz
Modeline "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync

Copy everything after the word Modeline (including the quotes).

Step 3: Create the New Display Mode

Pass the copied modeline string to xrandr using the --newmode flag:

xrandr --newmode "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync

Step 4: Associate the New Mode with Your Display Output

Link the newly created mode to your active display interface (replace HDMI-1 with your actual output name):

xrandr --addmode HDMI-1 "1920x1080_60.00"

Step 5: Apply the Custom Resolution

Switch your display to the new resolution immediately:

xrandr --output HDMI-1 --mode "1920x1080_60.00"

Step 6: Make the Changes Permanent

Changes made via xrandr reset when you reboot or log out. To automatically apply the custom resolution upon login:

  1. Open or create the ~/.xprofile file in your home directory: 
    nano ~/.xprofile
  2. Add the commands used in Steps 3, 4, and 5 to the file: 
    xrandr --newmode "1920x1080_60.00"  173.00  1920 2048 2248 2576  1080 1083 1088 1120 -hsync +vsync
xrandr --addmode HDMI-1 "1920x1080_60.00"
xrandr --output HDMI-1 --mode "1920x1080_60.00"
  3. Save and close the file (Ctrl+O, Enter, then Ctrl+X).

The system will now execute these commands automatically whenever you log into your X11 session.
