How to Mount tmpfs on Boot in Ubuntu fstab

Mounting a tmpfs filesystem on boot in Ubuntu allows you to store temporary files in volatile memory (RAM) rather than on your hard drive or SSD. This process significantly improves read and write performance for temporary operations and reduces wear on physical storage devices. This guide details the exact steps required to edit the /etc/fstab file, define your target directory, assign size limits, and safely test your configuration.

Step 1: Create the Mount Point Directory

Before configuring the fstab file, create the directory where the temporary file system will reside.

Open your terminal and run:

sudo mkdir -p /mnt/ramdisk

Replace /mnt/ramdisk with your preferred directory path.

Step 2: Open the fstab File

The /etc/fstab file contains system configuration for drive mounts. Open it using a text editor with administrative privileges:

sudo nano /etc/fstab

Step 3: Add the tmpfs Entry

Navigate to the bottom of the file and add a new line for your tmpfs mount using the following syntax:

tmpfs   /mnt/ramdisk   tmpfs   defaults,nodev,nosuid,size=2G   0   0

Explanation of the Parameters:

  • File System (tmpfs): Specifies the source type.
  • Mount Point (/mnt/ramdisk): The directory created in Step 1.
  • Type (tmpfs): Specifies the filesystem driver.
  • Options (defaults,nodev,nosuid,size=2G):
    • defaults: Applies standard mount options (rw, suid, dev, exec, auto, nouser, async).
    • nodev: Prevents character or special devices from being interpreted on the filesystem (security best practice).
    • nosuid: Disallows set-user-identifier or set-group-identifier bits from taking effect (security best practice).
    • size=2G: Sets the maximum RAM limit allocated to this mount. You can specify size in megabytes (size=512M) or as a percentage of total RAM (size=20%).
  • Dump (0): Set to 0 so the dump backup utility ignores this filesystem.
  • Pass (0): Set to 0 so fsck skips checking this filesystem on boot.

Save and exit the file (in Nano, press Ctrl + O, Enter, then Ctrl + X).

Step 4: Test the Configuration

To verify that there are no syntax errors in your /etc/fstab file, run the mount command to mount all filesystems listed in fstab:

sudo mount -a

If no errors appear in the terminal, the configuration is valid.

Step 5: Verify the Mount

Confirm that your tmpfs directory is actively mounted and utilizing RAM by running:

df -h /mnt/ramdisk

The output will display the size, used space, and available space for your newly mounted tmpfs filesystem. The directory will now automatically mount every time the Ubuntu system boots.
