How to Install and Configure htop on Ubuntu

The htop utility is an interactive, real-time process monitoring tool for Linux systems that provides a color-coded, user-friendly alternative to the default top command. This guide walks you through the steps to install htop on Ubuntu using the standard APT package manager, launch the application, and configure its layout, color schemes, and display options to optimize your system resource management.

Step 1: Update System Packages and Install htop

Open your terminal and refresh your system’s package list to ensure you pull the latest version from the official Ubuntu repositories:

sudo apt update

Next, install htop by running the following command:

sudo apt install htop -y

Once the installation process completes, verify that htop is installed properly by checking its version:

htop --version

Step 2: Launch htop

To start the process monitor, type:

htop

The terminal interface will display three main sections: * Header (Top): Displays per-core CPU usage, RAM usage, Swap usage, tasks, load average, and uptime. * Body (Middle): Shows the active process list, including Process ID (PID), User, CPU percentage, Memory percentage, and the executing Command. * Footer (Bottom): Displays function key shortcuts (F1 through F10) for quick actions.

Step 3: Configure htop Settings

Customizing htop allows you to tailor the interface to your specific monitoring needs.

  1. Press F2 (or Shift + C) on your keyboard to enter the Setup menu.
  2. Use the Arrow keys to navigate through the four configuration columns:

Display Options

Under the Display Options column, you can toggle key settings using the Spacebar: * Hide kernel threads: Keeps background system threads from cluttering your process list. * Hide userland process threads: Groups sub-threads under their main parent process. * Display process tree by default: Organizes running tasks into a parent-child visual hierarchy. * Show custom thread names: Displays distinct names for individual process threads.

Meters Customization

The Meters section allows you to change how CPU, Memory, and Swap data are displayed in the top header. 1. Select Meters in the Setup menu. 2. Choose between Left column or Right column. 3. Scroll to the bottom list, select a meter (e.g., Memory, Hostname, Clock), and press F5 to add it, or F6 to change its style (Bar, Text, Graph, or LED).

Colors

Navigate to Colors in the Setup menu to select from predefined visual themes, such as Default, Monochrome, Black on White, or Night.

After configuring your preferences, press F10 or Esc to save your changes and exit the Setup menu. Settings are saved to ~/.config/htop/htoprc.

Step 4: Essential Keyboard Shortcuts for Managing Processes

  • F3 (or /): Search for a specific process by name.
  • F4 (or ): Filter processes dynamically based on typed criteria.
  • F5 (or t): Toggle between standard list view and tree view.
  • F6 (or >): Sort processes by specific columns like CPU%, MEM%, or PID.
  • F9 (or k): Send a signal to a selected process. Select the process, press F9, choose a signal (such as 15 SIGTERM or 9 SIGKILL), and press Enter to terminate it.
  • Space: Tag individual processes to apply actions to multiple tasks at once.
  • U: Filter processes by a specific system user.
  • F10 (or q): Quit htop and return to the command prompt.
