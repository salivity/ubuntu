Disable Transparent Huge Pages for MongoDB on Ubuntu

Transparent Huge Pages (THP) is a Linux memory management system that frequently causes performance degradation, high memory fragmentation, and unexpected latency spikes when running database workloads such as MongoDB. Because MongoDB performs best with standard 4KB memory pages, the vendor officially recommends completely disabling THP across your Ubuntu systems. This guide provides a direct, step-by-step procedure to check your current THP settings and create a persistent systemd service to disable THP permanently on Ubuntu.

1. Check Current THP Status

To verify if Transparent Huge Pages are currently active, run the following commands in your terminal:

cat /sys/kernel/mm/transparent_hugepage/enabled
cat /sys/kernel/mm/transparent_hugepage/defrag

If the output shows [always] or [madvise] enclosed in brackets, THP is active. To optimize for MongoDB, the value must be set to [never].

2. Create a Persistent systemd Service

Because changes made via sysfs do not persist across reboots, the most reliable method on Ubuntu is creating a systemd unit file that sets THP to never during system initialization.

Create a new service file:

sudo nano /etc/systemd/system/disable-transparent-huge-pages.service

Add the following configuration:

[Unit]
Description=Disable Transparent Huge Pages (THP) for MongoDB
DefaultDependencies=no
After=sysinit.target local-fs.target
Before=mongod.service

[Service]
Type=oneshot
ExecStart=/bin/sh -c 'echo never > /sys/kernel/mm/transparent_hugepage/enabled && echo never > /sys/kernel/mm/transparent_hugepage/defrag'

[Install]
WantedBy=basic.target

Save and exit the text editor (Ctrl+O, Enter, then Ctrl+X).

3. Enable and Start the Service

Reload the systemd daemon to register the new service, enable it to run automatically at boot, and start it immediately:

sudo systemctl daemon-reload
sudo systemctl enable disable-transparent-huge-pages.service
sudo systemctl start disable-transparent-huge-pages.service

4. Verify the New Settings

Run the check commands again to ensure the changes took effect:

cat /sys/kernel/mm/transparent_hugepage/enabled
cat /sys/kernel/mm/transparent_hugepage/defrag

The output for both should now appear as:

always madvise [never]

Once [never] is highlighted, THP is properly disabled, preventing memory allocation delays and ensuring optimal throughput and stability for MongoDB on Ubuntu.
