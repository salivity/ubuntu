How to Split Terminal Panes Using Byobu on Ubuntu

Multiplexing a terminal window allows developers and system administrators to run multiple command-line sessions within a single display. This guide demonstrates how to install, launch, and utilize Byobu on Ubuntu to split a terminal into multiple horizontal and vertical panes, navigate between them, resize layouts, and manage active sessions using straightforward keyboard shortcuts.

Step 1: Install Byobu

Byobu is included in the default Ubuntu repositories. Open your terminal and install it using the apt package manager:

sudo apt update
sudo apt install byobu

Step 2: Start Byobu

Launch the multiplexer by entering:

byobu

By default, Byobu uses tmux as its backend. If prompted to select a backend, choose tmux to ensure compatibility with standard Byobu keybindings.

Step 3: Split the Terminal into Panes

Once inside Byobu, you can split your terminal window into multiple panes using predefined function keys:

  • Horizontal Split (splits the pane top and bottom): Press Shift + F2.
  • Vertical Split (splits the pane side by side): Press Ctrl + F2.

Each new pane operates as an independent shell session where you can execute commands concurrently.

Step 4: Navigate Between Panes

To move the cursor and focus between different active panes:

  • Press Shift + Up, Down, Left, or Right arrow keys to jump directly to the adjacent pane.

Step 5: Resize Panes

To adjust the dimensions of the currently active pane:

  • Press Alt + Up, Down, Left, or Right arrow keys to expand or shrink the pane boundary in that direction.

Step 6: Zoom and Close Panes

  • Toggle Fullscreen (Zoom): Press Shift + F11 to temporarily maximize the active pane. Press Shift + F11 again to restore the multi-pane layout.
  • Close a Pane: Type exit within the pane's shell and press Enter, or press Ctrl + F6 to terminate the current pane. Once all split panes are closed, Byobu returns to a single window.
