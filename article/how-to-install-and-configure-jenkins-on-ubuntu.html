How to Install and Configure Jenkins on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring the Jenkins continuous integration server on an Ubuntu system. You will learn how to install the required Java runtime, add the official Jenkins repository, install the software, adjust your firewall settings, and complete the initial Web UI setup wizard to get your CI/CD pipeline operational.

Step 1: Install Java

Jenkins requires the Java Runtime Environment (JRE) to run. Jenkins supports Java 17 and Java 21 LTS releases.

Update your system package index and install OpenJDK 17:

sudo apt update
sudo apt install fontconfig openjdk-17-jre -y

Verify the installation by checking the Java version:

java -version

Step 2: Add the Jenkins Repository

Import the official Jenkins GPG key to verify package integrity:

sudo wget -O /usr/share/keyrings/jenkins-keyring.asc \
  https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key

Add the Jenkins Debian package repository to your system’s software sources:

echo "deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
  https://pkg.jenkins.io/debian-stable binary/" | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null

Step 3: Install Jenkins

Update the package list to include the newly added repository, then install Jenkins:

sudo apt update
sudo apt install jenkins -y

Step 4: Start and Enable Jenkins

Once installed, start the Jenkins service and set it to run automatically on system boot:

sudo systemctl enable --now jenkins

Check the status of the service to ensure it is active and running:

sudo systemctl status jenkins

Step 5: Adjust the Firewall

Jenkins runs on port 8080 by default. If you are using the UFW firewall, open port 8080 to allow web access:

sudo ufw allow 8080
sudo ufw reload

Verify that the firewall rule has been applied:

sudo ufw status

Step 6: Complete the Setup Wizard

Open a web browser and navigate to your server’s IP address or domain name on port 8080:

http://your_server_ip:8080

To unlock Jenkins, retrieve the automatically generated administrator password from the server terminal:

sudo cat /var/lib/jenkins/secrets/initialAdminPassword

Copy the 32-character alphanumeric password, paste it into the Administrator password field in your web browser, and click Continue.

On the customization page: 1. Select Install suggested plugins to automatically download and configure essential CI/CD plugins. 2. Once plugin installation finishes, fill out the form to create your First Admin User account. 3. Confirm the Instance Configuration URL settings and click Save and Finish.

Jenkins is now fully installed, configured, and ready for use on your Ubuntu server.
