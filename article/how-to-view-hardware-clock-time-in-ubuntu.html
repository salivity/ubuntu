How to View Hardware Clock Time in Ubuntu

Checking the hardware clock—also known as the Real-Time Clock (RTC)—in Ubuntu is crucial for ensuring accurate system time, troubleshooting time drift, and managing dual-boot setups. Modern Ubuntu systems rely on built-in utilities like timedatectl and the traditional hwclock command to inspect the BIOS/UEFI hardware time. This article demonstrates the exact commands needed to view your RTC time quickly and efficiently from the terminal.

Option 1: Using timedatectl (Recommended)

The primary and simplest command to view the hardware clock in modern Ubuntu releases is timedatectl. It displays system time, UTC time, RTC time, and time zone configurations in a single output.

Run the following command in your terminal:

timedatectl

Example Output:

               Local time: Mon 2026-03-30 14:22:10 EDT
           Universal time: Mon 2026-03-30 18:22:10 UTC
                 RTC time: Mon 2026-03-30 18:22:10
                Time zone: America/New_York (EDT, -0400)
System clock synchronized: yes
              NTP service: active
          RTC in local TZ: no

Look for the RTC time line to see the current time stored on your motherboard's hardware clock.

Option 2: Using hwclock

If you need to query the hardware clock device directly (/dev/rtc0), use the hwclock utility. Because it accesses hardware directly, it requires root privileges.

Run either of the following commands:

sudo hwclock --show

or using the short flag:

sudo hwclock -r

Example Output:

2026-03-30 18:22:10.123456-04:00

Summary of Differences

  • timedatectl: Best for a quick overview of all time settings without requiring sudo.
  • hwclock --show: Best for directly querying the physical RTC hardware interface.
