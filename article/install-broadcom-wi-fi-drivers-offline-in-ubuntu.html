Install Broadcom WiFi Drivers Offline in Ubuntu

This guide explains how to manually install proprietary Broadcom wireless drivers on an Ubuntu system without an active internet connection. The offline installation process involves identifying your exact Broadcom chipset, retrieving the necessary .deb driver and dependency packages using an installation media or a secondary connected machine, transferring the files via USB drive, and installing them using Ubuntu's native package management tools.

Step 1: Identify the Broadcom Chipset

Open the terminal on your offline Ubuntu machine and run the following command to detect your network controller model:

lspci -nn -d 14e4:

This command filters for Broadcom PCI vendor ID (14e4). Note the PCI ID inside the brackets (such as [14e4:43a0] or [14e4:4312]). Most modern Broadcom chips (including BCM43142, BCM43224, BCM4352, and BCM4360) require the bcmwl-kernel-source package, which provides the Broadcom 802.11 Linux STA driver (wl).

Step 2: Retrieve the Driver Packages

You need the bcmwl-kernel-source package and its core dependency, dkms, along with any required development tools. You can acquire these using one of two methods.

Method A: From the Ubuntu Installation USB (Recommended)

If you still have the Ubuntu USB drive used to install the OS, insert it into the offline machine. The installation media contains the required offline packages inside the pool directory:

  1. Open a terminal and navigate to the mounted USB drive: 
    cd /media/$USER/*/pool/main/
  2. Locate the required packages inside the d/dkms and b/bcmwl subdirectories.

Method B: Download from Another Computer

If you do not have the installation drive, download the .deb files from an internet-connected computer using the official Ubuntu Package repository:

  1. Find your exact Ubuntu release name by running lsb_release -c on your offline machine (e.g., jammy, focal, noble).
  2. Search and download the corresponding .deb packages for your Ubuntu version:
    • dkms
    • bcmwl-kernel-source
  3. If not already present on the system, you may also need:
    • libc6-dev
    • linux-libc-dev
  4. Copy these .deb files onto a USB drive and plug it into your offline Ubuntu computer.

Step 3: Install the Packages

  1. On the offline Ubuntu system, copy all the .deb files to a dedicated local directory:

    mkdir ~/broadcom-offline
cp /path/to/usb/*.deb ~/broadcom-offline/
cd ~/broadcom-offline/

  2. Install all the packages simultaneously using dpkg:

    sudo dpkg -i *.deb

The system will automatically configure DKMS, compile the kernel module for your active kernel, and install the wireless driver.

Step 4: Load the Driver Module

Once the installation finishes without errors, remove any conflicting open-source drivers and load the proprietary wl module into the kernel:

sudo modprobe -r b43 b44 b43legacy ssb bcma brcm80211 brcmsmac brcmfmac
sudo modprobe wl

Step 5: Verify Wireless Connectivity

Check that the driver has registered the wireless network interface:

ip link

Look for a wireless interface name starting with wlan or wlp. Once visible, the network manager will automatically detect nearby Wi-Fi networks in your system settings. A system restart is recommended to ensure the module loads automatically at boot.
