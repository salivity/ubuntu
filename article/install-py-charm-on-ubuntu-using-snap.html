Install PyCharm on Ubuntu Using Snap

This guide outlines the quick and straightforward process of installing the PyCharm IDE on an Ubuntu system using the Snap package manager. You will learn how to verify your Snap environment, choose between the free Community and paid Professional editions, execute the single-line installation command with classic confinement, and launch the newly installed IDE on your desktop.

Step 1: Ensure Snap is Up to Date

Snap comes pre-installed on modern Ubuntu versions (16.04 LTS and newer). To ensure your package manager is ready, open your terminal (Ctrl + Alt + T) and refresh your installed snaps:

sudo snap refresh

Step 2: Choose Your PyCharm Edition

JetBrains offers two primary versions of PyCharm via Snap:

  • PyCharm Community Edition: A free, open-source IDE ideal for pure Python development.
  • PyCharm Professional Edition: A paid, full-featured IDE that adds support for web development (Django, Flask), database tools, and remote development capabilities.

Step 3: Run the Installation Command

PyCharm requires full access to your system to handle interpreters and external tools. Because of this, you must append the --classic flag to the installation command.

To install the Community Edition, run:

sudo snap install pycharm-community --classic

To install the Professional Edition, run:

sudo snap install pycharm-professional --classic

Once the download and installation complete, the terminal will display a confirmation message indicating the installed version.

Step 4: Launch PyCharm

You can launch PyCharm in two ways:

  1. Via the Application Menu: Press the Super key (Windows key), type "PyCharm" into the search bar, and click the application icon.
  2. Via the Terminal: Enter the command corresponding to your installed version:
    • Community: pycharm-community
    • Professional: pycharm-professional

On the first launch, accept the JetBrains user agreement and complete the initial setup wizard to configure your preferred theme and plugins.
