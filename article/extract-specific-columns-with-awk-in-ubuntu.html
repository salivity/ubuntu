Extract Specific Columns with Awk in Ubuntu

The awk command is a standard, versatile text-processing utility in Ubuntu designed to parse and manipulate structured data. Its primary role in column extraction is reading input line by line, automatically dividing each line into fields based on delimiters, and allowing users to select, reorder, or format specific columns using simple commands. This article covers how awk identifies fields, the basic syntax for extracting data, and practical examples for handling common column-extraction tasks.

How Awk Identifies Columns

By default, awk treats whitespace (spaces and tabs) as the delimiter separating columns. When it processes a line, it automatically assigns each column to a built-in variable:

  • $0 represents the entire line.
  • $1 represents the first column.
  • $2 represents the second column, and so on.
  • $NF represents the last column of the line.

Basic Syntax for Column Extraction

To print a single column from a file, use the following syntax:

awk '{print $1}' filename.txt

To extract multiple columns, separate the field variables with commas:

awk '{print $1, $3}' filename.txt

The comma ensures the output preserves space between the selected columns.

Handling Custom Delimiters

If a file uses a character other than whitespace to separate columns—such as a comma in a CSV file or a colon in a system file—the -F option specifies the custom delimiter.

To extract usernames (column 1) and user IDs (column 3) from the Ubuntu /etc/passwd file:

awk -F':' '{print $1, $3}' /etc/passwd

For comma-separated values (data.csv):

awk -F',' '{print $2}' data.csv

Formatting Output

You can insert custom strings or formatting directly into the extraction command:

awk '{print "User: " $1 "\tID: " $2}' users.txt

This prefixes the first column with "User: ", places a tab space, and prefixes the second column with "ID: ".

Extracting Columns Based on Conditions

awk also allows conditional filtering, meaning it only extracts columns from lines that meet specific criteria:

awk '$3 > 50 {print $1, $3}' scores.txt

This command inspects the third column and only prints the first and third columns if the value in the third column exceeds 50.

Extracting the Last Column

When working with lines containing varying numbers of columns, $NF dynamically targets the final column without needing to know the exact column count:

awk '{print $NF}' filename.txt

Through these features, awk provides a lightweight, dependency-free solution for stream processing and column extraction directly from the Ubuntu terminal.
