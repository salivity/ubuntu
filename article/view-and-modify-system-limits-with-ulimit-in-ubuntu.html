View and Modify System Limits with ulimit in Ubuntu

The ulimit command in Ubuntu allows administrators and users to control the system resources available to the shell and processes launched by it, such as open file descriptors, maximum user processes, and memory allocation. Managing these limits is essential for preventing runaway processes from exhausting system resources and for ensuring resource-intensive applications, like databases or web servers, operate without hitting arbitrary restriction caps. This article covers how to view your current resource limits, understand the difference between soft and hard limits, and apply both temporary and permanent changes to your Ubuntu system.

Understanding Soft vs. Hard Limits

Resource limits in Ubuntu are categorized into two types:

  • Soft Limits: The actual limit enforced by the operating system for a process. Unprivileged users can increase their soft limit up to the maximum set by the hard limit.
  • Hard Limits: The absolute ceiling for the soft limit. Only the root user or users with sudo privileges can increase hard limits.

Viewing Current Limits

To check the resource limits applied to your current shell session, run the following commands:

  • View all soft limits: 
    ulimit -a
  • View all hard limits: 
    ulimit -Ha
  • View specific limits (e.g., open files limit):
    • Soft limit for open files: ulimit -n
    • Hard limit for open files: ulimit -Hn
    • Maximum user processes limit: ulimit -u

Modifying Limits Temporarily

You can adjust limits for your active shell session directly from the command line. These changes will apply immediately to any process started within that specific terminal session, but they will revert once the session closes.

  • Increase the soft limit for open files to 4096: 
    ulimit -n 4096
  • Set both soft and hard limits for open files: 
    ulimit -Sn 4096
sudo ulimit -Hn 8192

Modifying Limits Permanently

To apply system limits permanently across reboots and user sessions, configure the limits file system-wide.

1. Edit the Limits Configuration File

Open /etc/security/limits.conf using a text editor with root permissions:

sudo nano /etc/security/limits.conf

Add your custom rules at the end of the file using the standard syntax: <domain> <type> <item> <value>

  • <domain>: Can be a specific username, a group name (prefixed with @), or * for all users.
  • <type>: soft or hard.
  • <item>: The resource limit type (e.g., nofile for open files, nproc for process limits).
  • <value>: The limit size.

Example Configuration:

*          soft    nofile          65536
*          hard    nofile          65536
*          soft    nproc           4096
*          hard    nproc           4096

2. Verify PAM Module Configuration

Ensure that Ubuntu applies the defined limits when users authenticate. Open /etc/pam.d/common-session:

sudo nano /etc/pam.d/common-session

Verify that the following line exists. If it is missing, add it:

session required pam_limits.so

Save the file and restart your system or re-login for the permanent settings to take effect. Verify the changes by running ulimit -a.
