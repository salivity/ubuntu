Run Cron Job on the First Monday of the Month in Ubuntu

Setting up a cron job in Ubuntu to run specifically on the first Monday of every month requires a shell condition, as native cron syntax evaluates day-of-month and day-of-week with an OR operator rather than an AND operator. This guide demonstrates how to configure crontab using an inline conditional check to reliably trigger your script only on the first Monday of each month.

The Cron Limitation

In standard crontab, if you specify both a day-of-month range (such as 1-7) and a day-of-week (such as 1 for Monday), the job runs if either condition matches. Consequently, defining 0 9 1-7 * 1 would execute the job every day from the 1st through the 7th, plus every Monday of the month.

To solve this, configure cron to run on a schedule and use an inline test condition to verify the complementary date parameter before launching the script.

Step 1: Open the Crontab Editor

Open the current user's crontab by running:

crontab -e

If prompted, select your preferred text editor (e.g., nano).

Step 2: Add the Cron Entry

Add the following entry to the bottom of the file:

0 9 1-7 * * [ "$(date +\%u)" -eq 1 ] && /path/to/your-script.sh

Alternatively, you can schedule it to run every Monday and verify that the day of the month is 7 or less:

0 9 * * 1 [ $(date +\%d) -le 7 ] && /path/to/your-script.sh

Syntax Breakdown

  • 0 9 1-7 * *: Schedules the cron daemon to evaluate the command at 09:00 AM on the 1st through the 7th day of every month.
  • [ "$(date +\%u)" -eq 1 ]: Evaluates whether the current day of the week is Monday (1). In cron, the percent sign (%) must be escaped with a backslash (\%) to prevent it from being interpreted as a newline character.
  • &&: A logical operator ensuring the script executes only if the preceding test command returns an exit status of 0 (true).
  • /path/to/your-script.sh: The absolute path to the executable script you want to run.

Step 3: Ensure Script Permissions

Ensure your target script has executable permissions assigned:

chmod +x /path/to/your-script.sh

Save and exit the crontab editor. The cron daemon will automatically detect the changes and apply the new schedule.
