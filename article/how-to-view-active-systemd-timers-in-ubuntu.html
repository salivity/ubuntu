How to View Active Systemd Timers in Ubuntu

Systemd timers are modern replacements for traditional cron jobs in Ubuntu, used to schedule routine system maintenance, backups, and service executions. This article provides the exact terminal command required to view all active systemd timers on an Ubuntu system, explains how to read the command output, and highlights a few useful variations for managing scheduled tasks.

The Command to View Active Systemd Timers

To view all currently active systemd timers on Ubuntu, open your terminal and run the following command:

systemctl list-timers

This command queries the systemd manager and displays a list of all active timers sorted by the time they are next scheduled to run.

Understanding the Command Output

Running systemctl list-timers outputs a table with six main columns:

  • NEXT: The date and time when the timer will execute next.
  • LEFT: The time remaining until the next execution (e.g., "2h 15min left").
  • LAST: The date and time when the timer last ran.
  • PASSED: How much time has elapsed since the timer last ran.
  • UNIT: The name of the timer unit file (ending in .timer).
  • ACTIVATES: The service unit file that gets triggered when the timer runs (ending in .service).

Useful Command Variations

View All Timers (Active and Inactive)

By default, systemctl list-timers only shows active timers. To view all installed timers, including inactive or unloaded ones, add the --all flag:

systemctl list-timers --all

Filter Output for Specific Timers

If you want to check the status of a specific systemd timer, you can append the timer unit name to the status command:

systemctl status example.timer

Replacing example.timer with the actual name of the timer will show its current state, recent logs, and activation history.
