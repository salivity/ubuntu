How to View Command History in Ubuntu Terminal

Viewing the command history in the Ubuntu terminal allows you to track past actions, reuse complex commands, and audit system administration tasks. This guide covers the essential methods for displaying, searching, and managing your bash command history using the built-in history tool, keyboard shortcuts, and history files.

1. Using the history Command

The fastest way to see your previous commands is by using the history command itself.

Open your terminal (Ctrl + Alt + T) and type:

history

This displays a numbered list of all recently executed commands stored in your current session’s memory and history file.

Limit the Number of Output Lines

To view only the last few commands, append a number to the command. For example, to view the last 10 commands:

history 10

Page Through Long Lists

If your history list is long, pipe the output into less to scroll through it easily:

history | less

Press Enter to scroll down line by line, Space to move down by page, and q to exit.

2. Searching Your Command History

Instead of scrolling through hundreds of lines, you can search for specific commands.

Search Using grep

Filter your command history for a specific keyword or program name:

history | grep "apt"

This returns every line in your history that contains the word “apt”.

Interactive Reverse Search (Ctrl + R)

Use the reverse-i-search feature to search interactively while typing:

  1. Press Ctrl + R in the terminal.
  2. Start typing any part of the command you want to find.
  3. Press Ctrl + R repeatedly to cycle through matching older commands.
  4. Press Enter to run the found command, or press the Right Arrow key to edit it.

3. Viewing the History File Directly

Ubuntu saves your terminal session history in a hidden text file located in your home directory.

To view the raw history file, run:

cat ~/.bash_history

You can also open this file in a text editor like nano:

nano ~/.bash_history

Note: Commands executed in the current active terminal session are written to ~/.bash_history only after the session is closed.

4. Re-executing Commands from History

You can run previous commands directly without retyping them:

  • Run the very last command:

    !!

  • Run a command by its line number:

    !150

    (Replaces 150 with the line number shown in the history output).

  • Run the last command starting with specific letters:

    !sudo

    (Runs the most recent command that started with sudo).

5. Clearing Command History

If you need to delete your command history:

  • Clear current session history:

    history -c

  • Clear the history file completely:

    cat /dev/null > ~/.bash_history
