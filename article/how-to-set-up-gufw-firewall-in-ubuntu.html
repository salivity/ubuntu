How to Set Up Gufw Firewall in Ubuntu

Setting up a firewall on Ubuntu is one of the most effective ways to secure your system from unauthorized network access. While Ubuntu includes Uncomplicated Firewall (UFW) by default, managing it through the command line can be intimidating for some users. This guide demonstrates how to install, configure, and manage your network security effortlessly using Gufw, a graphical user interface (GUI) designed for UFW.

What is Gufw?

Gufw stands for Graphical Uncomplicated Firewall. It provides an intuitive interface to control UFW, allowing you to turn the firewall on or off, select pre-set security profiles, and create custom rules for allowing or blocking specific traffic without typing terminal commands.

Step 1: Install Gufw on Ubuntu

Gufw is available in the standard Ubuntu repositories and can be installed via the terminal or the Ubuntu Software Center.

Option A: Using the Terminal

  1. Open your terminal (Ctrl + Alt + T).

  2. Update your package list:

    sudo apt update

  3. Install Gufw:

    sudo apt install gufw

Option B: Using Ubuntu Software Center

  1. Open the Ubuntu Software app.
  2. Search for Gufw or Firewall Configuration.
  3. Click Install and enter your administrative password.

Step 2: Launch Gufw

  1. Open your applications menu by clicking Activities or pressing the Super (Windows) key.
  2. Search for Firewall Configuration.
  3. Click the icon to launch the application.
  4. Enter your system password when prompted to grant administrative privileges.

Step 3: Enable the Firewall

By default, Ubuntu’s firewall is disabled. To activate it in Gufw:

  1. Locate the Status toggle switch near the top left of the window.
  2. Click the toggle switch to change the status from OFF to ON.

Once enabled, the shield icon will change color, indicating that your system is actively protected.

Step 4: Choose a Profile and Set Default Rules

Gufw offers built-in profiles tailored for different network environments:

  • Home: Allows outgoing connections and blocks incoming connections by default.
  • Work: Similar to Home, tailored for office environments.
  • Public: Stricter rules intended for untrusted networks like public Wi-Fi.

Default Policies

Below the profile selection, you can adjust the default behavior for incoming and outgoing connections: * Incoming: Set to Reject or Deny (Deny silently drops traffic, while Reject sends an error response back). * Outgoing: Set to Allow so your web browsing and normal application traffic work without interruption.

Step 5: Add Custom Rules

If you need to allow specific services (like a web server or SSH) or block certain IP addresses, you can create custom rules.

  1. Click the Rules tab at the top of the interface.
  2. Click the + (Plus) button at the bottom left to open the “Add a Firewall Rule” window.

You will see three tabs for adding rules:

1. Preconfigured Tab

This is the easiest option for common services and applications. * Allow/Deny: Select whether to allow or block traffic. * Category: Choose a category (e.g., Network, Service, Game). * Subcategory & Application: Select the specific app (e.g., SSH, Transmission, Plex). * Click Add.

2. Simple Tab

Use this tab if you know the port number or protocol. * Name: Enter a custom label for the rule. * Action: Select Allow, Deny, Reject, or Limit. * Protocol: Choose TCP, UDP, or Both. * Port: Enter the port number (e.g., port 80 for HTTP or 22 for SSH). * Click Add.

3. Advanced Tab

Use this tab for complex configurations, such as filtering by specific IP addresses or subnet ranges. * Set the From IP address (source) and To IP address (destination). * Specify custom ports and protocols as needed. * Click Add.

Step 6: Managing and Deleting Rules

  1. Go to the Rules tab in the main Gufw window.
  2. Click on the rule you wish to modify or remove.
  3. Click the - (Minus) button at the bottom to delete the selected rule.
  4. Click the Gear icon to edit an existing rule.

Step 7: Viewing Logs and Active Connections

Gufw allows you to monitor network activity directly within the application:

  • Log Tab: View blocked or allowed traffic attempts in real time. This is useful for troubleshooting network issues.
  • Listening Report Tab: See which applications and ports are currently listening for network connections on your system.
