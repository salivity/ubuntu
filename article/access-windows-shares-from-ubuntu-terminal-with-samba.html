Access Windows Shares from Ubuntu Terminal with Samba

Accessing shared Windows folders from an Ubuntu command line is straightforward when using the Samba client suite. This guide covers how to install the necessary packages, list available network shares on a Windows host, interact with those shares using an interactive shell, and permanently mount them to your local Ubuntu filesystem.

Step 1: Install the Samba Client Packages

Ubuntu requires smbclient to browse and interact with SMB shares directly, and cifs-utils to mount network folders into the Linux file tree.

Update your package index and install both tools by running:

sudo apt update
sudo apt install smbclient cifs-utils -y

Step 2: Discover and List Network Shares

Before connecting, query the target Windows machine to see which shares are available. Replace WINDOWS_HOST with the IP address or hostname of the Windows system, and username with your Windows user account.

smbclient -L //WINDOWS_HOST -U username

Enter the Windows user password when prompted. The terminal will display a list of available share names, share types, and comments.

Step 3: Browse Shares Interactively with smbclient

To explore a specific folder using an FTP-like command-line interface, connect directly to the share:

smbclient //WINDOWS_HOST/ShareName -U username

Once authenticated, you enter the smb: \> shell. Useful internal commands include:

  • ls : List files in the current remote directory.
  • cd folder_name : Change directory on the remote share.
  • get filename : Download a file from the Windows share to your local directory.
  • put filename : Upload a local file to the Windows share.
  • exit : Terminate the session and return to the terminal.

Step 4: Mount the Share to the Local Filesystem

To browse files using standard Linux commands (cat, nano, cp, find), mount the share locally.

  1. Create a local mount point:
sudo mkdir -p /mnt/winshare
  1. Mount the share:
sudo mount -t cifs //WINDOWS_HOST/ShareName /mnt/winshare -o username=username

If your Windows host is part of a domain, append the domain name:

sudo mount -t cifs //WINDOWS_HOST/ShareName /mnt/winshare -o username=username,domain=DOMAIN_NAME
  1. Verify the mount:
ls -l /mnt/winshare

When you are finished using the share, unmount it with:

sudo umount /mnt/winshare

Step 5: Mount Shares Automatically at Boot (Optional)

To mount the share automatically without entering a password each time, store the credentials in a protected file.

  1. Create a credentials file:
sudo nano /etc/smbcredentials
  1. Add your Windows login details:
username=your_windows_user
password=your_windows_password
domain=WORKGROUP
  1. Secure the credentials file permissions:
sudo chmod 600 /etc/smbcredentials
  1. Edit /etc/fstab:
sudo nano /etc/fstab
  1. Add the following entry at the bottom of the file:
//WINDOWS_HOST/ShareName /mnt/winshare cifs credentials=/etc/smbcredentials,iocharset=utf8,nofail 0 0
  1. Test the configuration without rebooting:
sudo mount -a

If no errors appear, the Windows share will now mount automatically upon boot.
