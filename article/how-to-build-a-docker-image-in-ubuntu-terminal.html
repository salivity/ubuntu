How to Build a Docker Image in Ubuntu Terminal

Building a Docker image from a Dockerfile allows you to package an application and its dependencies into a standardized, portable container. This guide provides a straightforward walkthrough on creating a Dockerfile, using the docker build command within the Ubuntu terminal, tagging the image, and verifying that the final container image is ready for deployment.

Prerequisites

Ensure you have Docker installed and running on your Ubuntu system. You can verify this by checking the Docker service status:

sudo systemctl status docker

To run Docker commands without prepending sudo, ensure your user is part of the docker group:

sudo usermod -aG docker $USER

(Log out and log back in if you recently added your user to the group.)

Step 1: Create a Project Directory

Create a dedicated workspace for your project to avoid sending unnecessary files to the Docker daemon during the build process.

mkdir ~/my-docker-project
cd ~/my-docker-project

Step 2: Create the Dockerfile

Inside your project directory, create a file named Dockerfile (with a capital D and no file extension):

nano Dockerfile

Add your container configuration instructions. Below is an example of a simple Nginx web server:

# Use an official base image
FROM ubuntu:22.04

# Update packages and install Nginx
RUN apt-get update && \
    apt-get install -y nginx && \
    rm -rf /var/lib/apt/lists/*

# Expose port 80
EXPOSE 80

# Set the default command to run Nginx in the foreground
CMD ["nginx", "-g", "daemon off;"]

Save and exit the text editor (in nano, press CTRL+O, Enter, then CTRL+X).

Step 3: Build the Image

Use the docker build command in your terminal. Use the -t (tag) flag to assign a name and an optional version tag to your image, followed by the build context (use . to denote the current directory):

docker build -t my-custom-nginx:1.0 .

Docker will execute each step defined in the Dockerfile sequentially, caching layers for faster future builds.

Step 4: Verify the Built Image

Once the build finishes with a success message, list the available Docker images on your Ubuntu system to verify its creation:

docker images

You will see my-custom-nginx listed with the tag 1.0, its unique Image ID, and its file size.

Step 5: Test the Container (Optional)

Run a container instance using your newly built image to confirm it functions correctly:

docker run -d -p 8080:80 --name test-nginx my-custom-nginx:1.0

Access the service using curl http://localhost:8080 in your terminal or by opening http://localhost:8080 in a web browser. Stop and remove the test container when finished:

docker stop test-nginx
docker rm test-nginx
