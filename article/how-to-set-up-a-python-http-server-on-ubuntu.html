How to Set Up a Python HTTP Server on Ubuntu

Setting up a basic Python HTTP server is the fastest way to share files from a directory on Ubuntu across your local network without installing complex software like Apache or Nginx. This guide explains how to use Python's built-in web server module to expose a directory, identify your network address, access the hosted files from any connected device, and safely stop the service.

1. Verify Python Installation

Ubuntu typically comes with Python 3 pre-installed. Open your terminal and verify its presence by running:

python3 --version

If Python 3 is not installed, install it using the Advanced Package Tool:

sudo apt update
sudo apt install python3

2. Navigate to the Target Directory

Use the cd command to move into the directory containing the files you wish to share:

cd /path/to/your/folder

Whatever directory you are in when you run the server will act as the root directory for all incoming HTTP requests.

3. Start the HTTP Server

Run Python's built-in http.server module to start serving files:

python3 -m http.server 8000

By default, the server listens on port 8000. You can replace 8000 with any open port number of your choice (such as 8080 or 5000). If you wish to use port 80, you must run the command with sudo privileges.

4. Find Your Ubuntu IP Address

To access the files from another device on the same local network, you need the host machine's local IP address. Open a new terminal window and run:

hostname -I

The first IP address listed (typically starting with 192.168. or 10.) is your local network address.

5. Access the Shared Files

Other devices connected to the same local area network (LAN) can now access the files through a web browser:

  1. Open a web browser on another computer, smartphone, or tablet.
  2. Enter the host IP address followed by the port number into the address bar: 
    http://YOUR_LOCAL_IP:8000
  3. Click on any file to view or download it directly.

If the directory contains an index.html file, Python will render that page automatically instead of showing the directory file list.

6. Adjust Firewall Settings (If Necessary)

If other devices cannot connect, the Ubuntu Uncomplicated Firewall (UFW) may be blocking the incoming traffic. Allow traffic on the chosen port by running:

sudo ufw allow 8000/tcp

7. Stop the Server

To stop sharing files and shut down the server, return to the terminal running the Python command and press:

Ctrl + C
