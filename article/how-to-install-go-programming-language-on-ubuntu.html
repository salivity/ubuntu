How to Install Go Programming Language on Ubuntu

Installing the Go programming language (Golang) on Ubuntu is a simple process that can be completed using either the official Go binary package or Ubuntu’s package manager. This guide provides a straightforward, step-by-step walkthrough to download, install, and configure the latest official version of Go on your Ubuntu system, ensuring your environment is ready for development.

Step 1: Update System Packages

Open your terminal and update your local package index to ensure your system is up to date:

sudo apt update && sudo apt upgrade -y

Step 2: Download the Latest Go Binary

To get the latest version of Go, visit the official Go downloads page or use wget to download the tarball directly. Replace 1.22.1 with the latest version number if a newer release is available:

wget https://go.dev/dl/go1.22.1.linux-amd64.tar.gz

Step 3: Extract the Go Archive

Remove any previous Go installation and extract the downloaded archive into the /usr/local directory:

sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.22.1.linux-amd64.tar.gz

Step 4: Configure Environment Variables

To execute Go commands from any terminal location, add the Go binary path to your environment variables.

Open your ~/.profile or ~/.bashrc file in a text editor:

nano ~/.profile

Add the following line at the end of the file:

export PATH=$PATH:/usr/local/go/bin

Save and close the file (in nano, press Ctrl+O, then Enter, and Ctrl+X).

Apply the changes to your current terminal session:

source ~/.profile

Step 5: Verify the Installation

Confirm that Go is installed correctly by checking its version:

go version

If the installation was successful, the terminal will display the installed Go version details.
