How to Install and Configure Nginx on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring the Nginx web server on an Ubuntu system. You will learn how to update package indexes, install Nginx via the APT package manager, adjust firewall settings, manage the Nginx system service, and set up server blocks (virtual hosts) to host custom websites efficiently.

Step 1: Install Nginx

Update your local package index to ensure you have access to the latest package lists, then install Nginx using the apt package manager:

sudo apt update
sudo apt install nginx -y

Once the installation completes, Nginx will automatically start running on your system.

Step 2: Configure the UFW Firewall

If you have the Uncomplicated Firewall (UFW) enabled, you must allow HTTP and HTTPS traffic so users can access your web server.

  1. Check available UFW application profiles:
sudo ufw app list
  1. Enable the Nginx Full profile to allow both HTTP (Port 80) and HTTPS (Port 443) traffic:
sudo ufw allow 'Nginx Full'
  1. Verify the changes:
sudo ufw status

Step 3: Check the Nginx Web Server Status

Verify that the Nginx service is active and running using systemctl:

sudo systemctl status nginx

You can also confirm that the web server is reachable by navigating to your server’s IP address in a web browser:

http://your_server_ip

If successful, you will see the default “Welcome to nginx!” landing page.

Step 4: Manage the Nginx Process

Use standard systemctl commands to manage the Nginx service:

  • Stop the web server: sudo systemctl stop nginx
  • Start the web server: sudo systemctl start nginx
  • Restart the web server: sudo systemctl restart nginx
  • Reload configuration changes without dropping connections: sudo systemctl reload nginx
  • Disable Nginx from booting automatically: sudo systemctl disable nginx
  • Enable Nginx to start on boot: sudo systemctl enable nginx

Step 5: Configure Server Blocks (Virtual Hosts)

Server blocks allow you to host multiple domains from a single Nginx server.

1. Create the Directory Structure

Create a root web directory for your domain, replacing example.com with your domain name:

sudo mkdir -p /var/www/example.com/html
sudo chown -R $USER:$USER /var/www/example.com/html
sudo chmod -R 755 /var/www/example.com

2. Create a Sample Web Page

Create a basic index.html page to test the configuration:

nano /var/www/example.com/html/index.html

Paste the following HTML content:

<!DOCTYPE html>
<html>
<head>
    <title>Welcome to Example.com</title>
</head>
<body>
    <h1>Success! The example.com Nginx server block is working!</h1>
</body>
</html>

Save and close the file.

3. Create a Server Block Configuration File

Create a new configuration file in /etc/nginx/sites-available/:

sudo nano /etc/nginx/sites-available/example.com

Add the following block:

server {
    listen 80;
    listen [::]:80;

    root /var/www/example.com/html;
    index index.html index.htm;

    server_name example.com www.example.com;

    location / {
        try_files $uri $uri/ =404;
    }
}

Save and close the file.

4. Enable the Server Block and Apply Changes

Link the configuration file to the sites-enabled directory to enable it:

sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/

To avoid potential domain name memory issues, open /etc/nginx/nginx.conf and uncomment the server_names_hash_bucket_size directive if necessary:

sudo nano /etc/nginx/nginx.conf

Find # server_names_hash_bucket_size 64; and remove the # symbol.

5. Test and Restart Nginx

Ensure there are no syntax errors in any of your Nginx files:

sudo nginx -t

If the test passes, reload Nginx to apply the new configuration:

sudo systemctl reload nginx

Your Nginx server is now configured and serving your custom domain directory.
