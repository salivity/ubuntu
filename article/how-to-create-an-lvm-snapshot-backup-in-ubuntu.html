How to Create an LVM Snapshot Backup in Ubuntu

Logical Volume Manager (LVM) snapshots allow you to create a point-in-time copy of a logical volume without taking your system or services offline. This article provides a step-by-step guide on how to safely create, mount, back up, and remove an LVM snapshot in Ubuntu. By leveraging snapshots, you can perform consistent backups of active systems, such as database servers or web hosts, with minimal downtime and zero data corruption risks.

Prerequisites

Before creating an LVM snapshot, ensure you have:

  • An operational Ubuntu system with LVM configured.
  • Root or sudo access.
  • Available free space in the Volume Group (VG) hosting your target Logical Volume (LV).

Step 1: Check Available Space in the Volume Group

An LVM snapshot requires free space in the Volume Group to store changes made to the original volume while the snapshot exists.

Run the following command to check your Volume Group's unallocated space:

sudo vgs

Look at the VFree column. Make sure you have enough unallocated space to handle the changes expected during the backup process.

Step 2: Create the LVM Snapshot

To create a snapshot, use the lvcreate command with the -s (or --snapshot) flag.

sudo lvcreate --size 5G --snapshot --name myvol_snapshot /dev/vg_name/lv_name
  • Replace 5G with the size you want to allocate for snapshot changes.
  • Replace myvol_snapshot with your preferred snapshot name.
  • Replace /dev/vg_name/lv_name with the path to your target logical volume.

Step 3: Mount the LVM Snapshot

Once created, mount the snapshot to access its files and perform the backup.

  1. Create a mount point directory:

    sudo mkdir -p /mnt/snapshot

  2. Mount the snapshot volume:

    sudo mount /dev/vg_name/myvol_snapshot /mnt/snapshot

Note for XFS filesystems: If your volume uses the XFS filesystem, add the -o nouuid flag to avoid UUID conflict errors:

sudo mount -o nouuid /dev/vg_name/myvol_snapshot /mnt/snapshot

Step 4: Back Up the Data

With the snapshot mounted at /mnt/snapshot, you can safely copy the point-in-time data to an external drive, remote server, or backup directory using tools like tar or rsync.

Example using tar:

sudo tar -czvf /backups/system_backup.tar.gz -C /mnt/snapshot .

Example using rsync:

sudo rsync -aAXv /mnt/snapshot/ /path/to/backup/destination/

Step 5: Unmount and Remove the Snapshot

After completing the backup, unmount and remove the snapshot. Keeping snapshots indefinitely is not recommended, as filling up the snapshot space will corrupt the snapshot and degrade system performance.

  1. Unmount the snapshot directory:

    sudo umount /mnt/snapshot

  2. Delete the snapshot volume:

    sudo lvremove /dev/vg_name/myvol_snapshot

  3. Confirm the removal when prompted by typing y.
