How to Set Up an OpenVPN Server on Ubuntu

Setting up an OpenVPN server on an Ubuntu machine allows you to route your internet traffic securely through an encrypted tunnel, protecting your data on public networks and granting remote access to your private local network. This guide provides a direct, step-by-step procedure to install OpenVPN, configure a Certificate Authority (CA) using Easy-RSA, build the necessary encryption keys, and start the VPN service on Ubuntu.

Step 1: Update the System and Install OpenVPN

First, update your package lists and install OpenVPN along with Easy-RSA, a tool used to manage your Public Key Infrastructure (PKI) certificates.

sudo apt update
sudo apt install openvpn easy-rsa -y

Step 2: Set Up the PKI Environment

Create a directory for Easy-RSA to manage your Certificate Authority certificates.

make-cadir ~/openvpn-ca
cd ~/openvpn-ca

Initialize the Public Key Infrastructure (PKI) and build the Certificate Authority (CA).

./easyrsa init-pki
./easyrsa build-ca nopass

Follow the prompts to enter a common name for your CA.

Step 3: Generate Server Certificates and Keys

Generate the server key pair and certificate request, then sign the request using your CA.

./easyrsa gen-req server nopass
./easyrsa sign-req server server

Generate Diffie-Hellman parameters for key exchange and a TLS-Auth signature to mitigate DoS attacks and port scanning.

./easyrsa gen-dh
openvpn --genkey secret ta.key

Step 4: Configure the OpenVPN Service

Copy all the generated keys and certificates to the OpenVPN configuration directory.

sudo cp pki/ca.crt pki/issued/server.crt pki/private/server.key pki/dh.pem ta.key /etc/openvpn/server/

Copy and extract the sample OpenVPN server configuration file to set up your server rules.

zcat /usr/share/doc/openvpn/examples/sample-config-files/server.conf.gz | sudo tee /etc/openvpn/server/server.conf > /dev/null

Edit /etc/openvpn/server/server.conf using your preferred text editor to ensure the key and certificate file paths match where you placed them:

  • ca ca.crt
  • cert server.crt
  • key server.key
  • dh dh.pem
  • tls-auth ta.key 0

Ensure the tls-auth line uses 0 for the server configuration.

Step 5: Enable IP Forwarding and Configure Firewall Rules

Enable network traffic routing on the Ubuntu server by editing /etc/sysctl.conf.

sudo nano /etc/sysctl.conf

Uncomment the following line:

net.ipv4.ip_forward=1

Apply the changes:

sudo sysctl -p

Next, configure UFW (Uncomplicated Firewall) to allow OpenVPN traffic and route it properly. Find your primary network interface using ip route. Then, edit /etc/ufw/before.rules and add the following lines at the top of the file (replace eth0 with your actual network interface name):

# START OPENVPN RULES
*nat
:POSTROUTING ACCEPT [0:0]
-A POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE
COMMIT
# END OPENVPN RULES

Allow UDP traffic on port 1194 and reload UFW:

sudo ufw allow 1194/udp
sudo ufw allow OpenSSH
sudo ufw disable
sudo ufw enable

Step 6: Start and Enable the OpenVPN Server

Start the OpenVPN service pointing to your server.conf configuration file and enable it to run at boot.

sudo systemctl start openvpn-server@server
sudo systemctl enable openvpn-server@server

Verify that the service is running:

sudo systemctl status openvpn-server@server

Step 7: Generate Client Certificates

To connect a device to the server, generate a client certificate and key inside your ~/openvpn-ca directory:

cd ~/openvpn-ca
./easyrsa gen-req client1 nopass
./easyrsa sign-req client client1

Combine ca.crt, client1.crt, client1.key, and ta.key (with key-direction 1) into a single .ovpn profile file to import into your client application.
