How to Install and Configure OSSEC on Ubuntu

OSSEC is a powerful, open-source Host-based Intrusion Detection System (HIDS) that provides log analysis, integrity checking, Windows registry monitoring, rootkit detection, time-based alerting, and active response. This guide provides a straightforward walkthrough for installing OSSEC from source on an Ubuntu system, configuring its core settings in ossec.conf, and starting the service to protect your server environment.

Prerequisites

Before beginning, update your package lists and install the build tools required to compile OSSEC from source:

sudo apt update
sudo apt install -y build-essential gcc make libssl-dev libz-dev libpcre2-dev libevent-dev wget tar

Step 1: Download OSSEC Source Code

Download the latest stable release of OSSEC from official releases or repository archives using wget:

wget https://github.com/ossec/ossec-hids/archive/3.7.0.tar.gz -O ossec-hids.tar.gz

Extract the downloaded archive and navigate to the directory:

tar -xvzf ossec-hids.tar.gz
cd ossec-hids-3.7.0

Step 2: Install OSSEC

Run the interactive installation script:

sudo ./install.sh

During the installation prompt, select your preferred options:

  1. Language: Select your preferred language (default is en).
  2. Installation Type: Choose local to monitor the current machine, server for a centralized manager, or agent for a client node. (Choose local for single-system monitoring).
  3. Installation Location: Press Enter to accept the default path (/var/ossec).
  4. Notification Settings: Enter an email address to receive alerts, or disable email notifications if not required.
  5. Integrity Check Daemon (syscheck): Enable (recommended).
  6. Rootkit Detection Engine (rootcheck): Enable (recommended).
  7. Active Response: Enable if you want OSSEC to automatically block detected threats (e.g., via iptables).
  8. White List: Add any IP addresses that should never be blocked by active response.

The installer will compile the binaries and complete the installation setup.

Step 3: Configure OSSEC

The primary configuration file is located at /var/ossec/etc/ossec.conf. Open it in your preferred text editor:

sudo nano /var/ossec/etc/ossec.conf

Configure Email Alerts

To send alerts via email, locate the <global> section and ensure your SMTP server and email addresses are correctly defined:

<global>
  <email_notification>yes</email_notification>
  <email_to>admin@example.com</email_to>
  <smtp_server>127.0.0.1</smtp_server>
  <email_from>ossec@example.com</email_from>
</global>

Configure Directory Monitoring (Syscheck)

To add or modify directories monitored for file modifications, edit the <syscheck> section:

<syscheck>
  <frequency>79200</frequency>
  <directories check_all="yes">/etc,/usr/bin,/usr/sbin</directories>
  <directories check_all="yes">/var/www</directories>
  <ignore>/etc/hosts.deny</ignore>
</syscheck>

Add Custom Log Files

To monitor specific log files (such as web server logs), append a <localfile> block:

<localfile>
  <log_format>apache</log_format>
  <location>/var/log/apache2/access.log</location>
</localfile>

Save and close the file after making changes.

Step 4: Manage the OSSEC Service

Start the OSSEC service using the management control script:

sudo /var/ossec/bin/ossec-control start

To check the current running status of OSSEC processes:

sudo /var/ossec/bin/ossec-control status

To stop or restart the service after making configuration updates:

sudo /var/ossec/bin/ossec-control restart

Step 5: Verify Log Output

OSSEC stores alerts and logs within /var/ossec/logs/alerts/alerts.log. You can view active alerts in real-time by running:

sudo tail -f /var/ossec/logs/alerts/alerts.log
