How to Set Up Apt-Cacher NG on Ubuntu

Setting up an Apt-Cacher NG server allows you to create a local HTTP caching proxy for Debian and Ubuntu packages, drastically reducing internet bandwidth usage and cutting down package installation times across a local network. This guide covers how to install and configure the Apt-Cacher NG package on a dedicated Ubuntu server, enable HTTPS support, configure client machines to route package requests through the proxy, and verify that the caching mechanism is working properly.

Step 1: Install Apt-Cacher NG on the Server

Choose an Ubuntu machine on your network to act as the central caching server. Ensure the system is updated, then install the package:

sudo apt update
sudo apt install apt-cacher-ng -y

During installation, the service starts automatically and listens on TCP port 3142 by default.

Step 2: Configure Apt-Cacher NG

The default configuration file is located at /etc/apt-cacher-ng/acng.conf. For most environments, the default settings work out of the box. However, if you need to fetch repositories over HTTPS (which is common for third-party PPAs and repositories like Docker), enable HTTPS tunneling.

Open the configuration file:

sudo nano /etc/apt-cacher-ng/acng.conf

Find the following line:

# PassThroughPattern: .*

Uncomment it to allow raw HTTPS pass-through traffic:

PassThroughPattern: .*

Save and exit the file (press CTRL+O, Enter, then CTRL+X).

Restart the Apt-Cacher NG service to apply changes:

sudo systemctl restart apt-cacher-ng
sudo systemctl enable apt-cacher-ng

If your server has an active firewall (UFW), allow incoming connections on port 3142:

sudo ufw allow 3142/tcp

Step 3: Configure Client Machines

On each Ubuntu client machine that will use the cache, create a proxy configuration file for the APT package manager:

sudo nano /etc/apt/apt.conf.d/00aptproxy

Add the following line, replacing YOUR_SERVER_IP with the local IP address of your Apt-Cacher NG server:

Acquire::http::Proxy "http://YOUR_SERVER_IP:3142";
Acquire::https::Proxy "http://YOUR_SERVER_IP:3142";

Save and close the file.

Step 4: Verify the Setup

To verify that the proxy works, run a package update and installation on a configured client:

sudo apt update
sudo apt install curl -y

Next, open a web browser on any machine within the local network and navigate to the Apt-Cacher NG reporting dashboard:

http://YOUR_SERVER_IP:3142/acng-report.html

Click Count Data to view transfer statistics, cache hit rates, and total bandwidth saved. The first time a package is requested by any client, the server downloads and stores it; subsequent requests from other clients will be served instantly from local storage.
