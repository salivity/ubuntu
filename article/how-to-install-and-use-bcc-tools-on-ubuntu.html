How to Install and Use BCC Tools on Ubuntu

The BPF Compiler Collection (BCC) provides a powerful suite of performance analysis and system tracing tools built on Linux extended BPF (eBPF). This guide covers the complete process of installing BCC on Ubuntu, configuring the environment, and utilizing essential tracing tools to inspect file access, monitor process execution, and debug system latency in real time.

Step 1: Install BCC Tools and Kernel Headers

Ubuntu packages BCC directly in its official repositories. To ensure the tools can compile eBPF programs against your current kernel, you must install the BCC utilities along with the corresponding Linux kernel headers.

Open your terminal and run the following commands:

sudo apt update
sudo apt install bpfcc-tools linux-headers-$(uname -r) python3-bpfcc

Step 2: Understand BCC Command Locations

On Ubuntu, BCC utilities are installed to /sbin and /usr/sbin with a -bpfcc suffix to prevent naming collisions with other system utilities. For example, the opensnoop tool is executed as opensnoop-bpfcc.

Alternative versions of the raw scripts are also located in /usr/share/bcc/tools/. You can append this directory to your PATH variable if you prefer running tools without the -bpfcc suffix:

echo 'export PATH=$PATH:/usr/share/bcc/tools' >> ~/.bashrc
source ~/.bashrc

Step 3: Run Common Tracing Tools

All BCC tools require administrative privileges to attach eBPF programs to kernel tracepoints, kprobes, or uprobes.

1. Trace New Processes with execsnoop

execsnoop-bpfcc displays new processes created via exec() syscalls, displaying the parent process, process name, arguments, and return values.

sudo execsnoop-bpfcc

2. Monitor File Opens with opensnoop

opensnoop-bpfcc traces open() and openat() syscalls, helping detect configuration file reads, missing log files, or excessive file polling.

sudo opensnoop-bpfcc

To limit tracing to a specific Process ID (PID):

sudo opensnoop-bpfcc -p 1234

3. Analyze Disk I/O Latency with biolatency

biolatency-bpfcc measures the time taken by storage devices to complete I/O requests and outputs a histogram upon termination (via Ctrl+C).

sudo biolatency-bpfcc

To display disk latency with millisecond resolution and timestamps:

sudo biolatency-bpfcc -m -T

4. Trace TCP Connections with tcplife

tcplife-bpfcc records completed TCP sessions, providing details on local and remote endpoints, throughput, and connection duration in milliseconds.

sudo tcplife-bpfcc

Step 4: Verification and Troubleshooting

If a BCC tool fails to launch:

  1. Verify that kernel headers match your active kernel by running uname -r and checking the contents of /lib/modules/$(uname -r)/build.
  2. Confirm the Linux kernel version is 4.9 or higher by executing uname -a. Modern Ubuntu releases meet this requirement by default.
  3. Ensure eBPF is enabled in the running kernel configuration by checking for CONFIG_BPF=y and CONFIG_BPF_SYSCALL=y in /boot/config-$(uname -r).
