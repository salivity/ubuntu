How to Install Helm on Ubuntu

This guide provides a straightforward walkthrough for installing Helm, the package manager for Kubernetes, on an Ubuntu operating system. Helm simplifies the deployment, versioning, and management of containerized applications on Kubernetes clusters using packages called charts. The following sections outline the necessary prerequisites, the primary installation method using the official Apt repository, an alternative script-based method, and the steps to verify a successful installation.

Prerequisites

Before installing Helm, ensure your system meets the following requirements:

  • An updated Ubuntu system (20.04 LTS, 22.04 LTS, or newer).
  • A user account with sudo privileges.
  • curl and apt-transport-https installed on your machine.
  • An existing Kubernetes cluster and an active kubectl configuration pointing to it.

Method 1: Install Helm via the Official Apt Repository

Using the official Apt repository is the recommended method on Ubuntu because it allows for easy updates via standard package management commands.

Step 1: Install Dependencies

Ensure prerequisites such as curl and gpg are installed:

sudo apt-get update
sudo apt-get install apt-transport-https curl gnupg -y

Step 2: Add the Helm GPG Key

Download and store the official Helm signing key to ensure package authenticity:

curl https://baltocdn.com/helm/signing.asc | gpg --dearmor | sudo tee /usr/share/keyrings/helm.gpg > /dev/null

Step 3: Add the Helm Repository

Add the Helm repository to your system's package sources list:

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/helm.gpg] https://baltocdn.com/helm/stable/debian/ all main" | sudo tee /etc/apt/sources.list.d/helm-stable-debian.list

Step 4: Install Helm

Update your package index to include the newly added repository and install Helm:

sudo apt-get update
sudo apt-get install helm -y

Method 2: Install Helm via the Automated Script

If you prefer an automated installation without configuring APT sources, Helm provides an official shell script that detects your system architecture and fetches the latest binary.

  1. Download the script:

    curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3

  2. Make the script executable:

    chmod 700 get_helm.sh

  3. Run the installer:

    ./get_helm.sh

Verifying the Installation

To confirm that Helm is correctly installed on your Ubuntu machine, check the client version:

helm version

If the installation was successful, the command outputs the version details:

version.BuildInfo{Version:"v3.x.x", GitCommit:"...", GitTreeState:"clean", GoVersion:"..."}

Basic Configuration

To begin using Helm, add an official chart repository such as Bitnami to discover and install packages:

helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update

You can now search for and deploy charts directly to your Kubernetes cluster.
