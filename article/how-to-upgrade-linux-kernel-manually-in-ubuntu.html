How to Upgrade Linux Kernel Manually in Ubuntu

Manually upgrading the Linux kernel in Ubuntu allows users to access the latest hardware support, performance improvements, and security fixes before they are officially rolled out to standard system updates. The recommended and safest way to perform a manual upgrade is by using the Mainline Kernel Tool, a utility that automatically fetches and installs builds directly from the Ubuntu Mainline Kernel PPA. Alternatively, users can manually download and install .deb kernel packages via the command line.

Option 1: Using the Mainline Tool (Recommended)

The Mainline tool provides both a graphical interface and a CLI utility, simplifying the process of installing mainline kernels without manually managing individual package files.

Step 1: Add the Mainline PPA Repository

Open your terminal (Ctrl+Alt+T) and run the following command to add the repository:

sudo add-apt-repository ppa:cappelikan/ppa

Step 2: Update Package Lists and Install Mainline

Update your local software repository list and install the application:

sudo apt update
sudo apt install mainline

Step 3: Install the Desired Kernel

Launch the application from your desktop app menu or run mainline in the terminal. The tool will display a list of available Linux kernels.

Select the kernel version you want to install, click Install, and authenticate when prompted. Once the process completes, restart your computer.

Option 2: Manual CLI Method via Ubuntu Kernel PPA

If you prefer using pure command-line steps, you can download kernel packages directly from the Ubuntu Mainline PPA archive.

Step 1: Download Kernel Packages

Navigate to the Ubuntu Mainline Kernel PPA archive online. Select your desired version folder and download the four required .deb files for your system architecture (typically amd64):

  1. linux-headers-X.X.X-xxxxxx_X.X.X-xxxxxx_all.deb (Header package)
  2. linux-headers-X.X.X-xxxxxx-generic_X.X.X-xxxxxx_amd64.deb (Architecture-specific header)
  3. linux-image-unsigned-X.X.X-xxxxxx-generic_X.X.X-xxxxxx_amd64.deb (Kernel image)
  4. linux-modules-X.X.X-xxxxxx-generic_X.X.X-xxxxxx_amd64.deb (Kernel modules)

Step 2: Install the Packages

Place all downloaded .deb files into a single empty directory, navigate into that directory using your terminal, and install them:

sudo dpkg -i *.deb

Verifying the Installation

After completing either method, reboot your system:

sudo reboot

Once the system restarts, verify that the new kernel is running:

uname -r

If your system encounters boot issues with the new kernel, restart, press Esc or hold Shift during startup to open the GRUB menu, select Advanced options for Ubuntu, and boot into your previous kernel version.
