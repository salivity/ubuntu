How to Install ELK Stack on Ubuntu

Setting up the ELK Stack (Elasticsearch, Logstash, and Kibana) on Ubuntu enables centralized log management, real-time data analysis, and visual monitoring across your infrastructure. This guide covers the step-by-step process of preparing your Ubuntu system, adding the official Elastic repository, installing each component, and configuring the basic pipeline to get your stack operational.

Step 1: Update System and Install Prerequisites

Ensure your Ubuntu system is up to date and install the necessary dependencies for downloading and managing repository keys.

sudo apt update && sudo apt upgrade -y
sudo apt install wget apt-transport-https gnupg lsb-release -y

Step 2: Add the Elastic Repository

Elastic packages are not included in default Ubuntu repositories. Add the official GPG key and APT repository to your system.

  1. Download and import the Elastic GPG signing key:
wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg
  1. Add the Elastic 8.x repository to your package sources list:
echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list
  1. Update the package list:
sudo apt update

Step 3: Install and Configure Elasticsearch

Elasticsearch is the search and analytics engine at the core of the stack.

  1. Install Elasticsearch:
sudo apt install elasticsearch -y
  1. Open the main configuration file:
sudo nano /etc/elasticsearch/elasticsearch.yml
  1. Configure basic settings:
    • Set network.host: localhost (or your server’s IP address).
    • For single-node setups, set discovery.type: single-node.
  2. Enable and start the Elasticsearch service:
sudo systemctl daemon-reload
sudo systemctl enable --now elasticsearch
  1. Verify Elasticsearch is running:
curl -X GET "localhost:9200"

(Note: In Elasticsearch 8+, security features are enabled by default. You may need to reset the default elastic superuser password using sudo /usr/share/elasticsearch/bin/elasticsearch-reset-password -u elastic to authenticate requests.)

Step 4: Install and Configure Kibana

Kibana provides a web-based interface for visualizing data stored in Elasticsearch.

  1. Install Kibana:
sudo apt install kibana -y
  1. Open the Kibana configuration file:
sudo nano /etc/kibana/kibana.yml
  1. Update the following lines:
server.port: 5601
server.host: "0.0.0.0"
elasticsearch.hosts: ["http://localhost:9200"]
  1. Enable and start the Kibana service:
sudo systemctl enable --now kibana
  1. Generate an enrollment token from Elasticsearch to bind Kibana:
sudo /usr/share/elasticsearch/bin/elasticsearch-create-enrollment-token -s kibana
  1. Access Kibana by navigating to http://<your-server-ip>:5601 in your browser and enter the generated token to complete setup.

Step 5: Install and Configure Logstash

Logstash processes incoming log data and sends it to Elasticsearch.

  1. Install Logstash:
sudo apt install logstash -y
  1. Create a basic processing pipeline configuration file:
sudo nano /etc/logstash/conf.d/02-beats-input.conf
  1. Define an input, filter, and output configuration:
input {
  beats {
    port => 5044
  }
}

output {
  elasticsearch {
    hosts => ["http://localhost:9200"]
    index => "%{[@metadata][beat]}-%{[@metadata][version]}-%{+YYYY.MM.dd}"
  }
}
  1. Enable and start the Logstash service:
sudo systemctl enable --now logstash

Step 6: Verify the ELK Stack

Confirm that all services are active and running properly:

sudo systemctl status elasticsearch kibana logstash

With all components active, log collectors like Filebeat can now be configured on client machines to ship data to Logstash on port 5044, which will index the records into Elasticsearch for visual analysis within Kibana.
