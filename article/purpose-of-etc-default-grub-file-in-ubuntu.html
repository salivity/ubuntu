Purpose of /etc/default/grub File in Ubuntu

The /etc/default/grub file serves as the primary configuration file for customizing the GRUB 2 bootloader on Ubuntu and other Debian-based Linux distributions. It allows system administrators to safely modify essential boot parameters—such as default operating systems, kernel command-line options, menu timeouts, and visual display settings—without directly editing the complex scripts generated by the system.

Primary Role of /etc/default/grub

When an Ubuntu system boots, the GRUB 2 bootloader reads its runtime settings from a compiled configuration file located at /boot/grub/grub.cfg. However, users are discouraged from editing /boot/grub/grub.cfg directly because system updates frequently overwrite it.

Instead, Ubuntu uses /etc/default/grub as a user-friendly abstraction layer. You edit settings in /etc/default/grub, and then run the update-grub command. This command parses /etc/default/grub along with helper scripts in /etc/grub.d/ to safely build the final /boot/grub/grub.cfg file.

Key Settings Configured in the File

The file consists of simple key-value pairs that control boot behavior:

  • GRUB_DEFAULT: Specifies which operating system or kernel to boot by default. It can accept a numerical index (e.g., 0 for the first entry), an exact menu title string, or saved to automatically boot the last chosen operating system.
  • GRUB_TIMEOUT_STYLE: Controls whether the boot menu appears. Common values include menu (shows the menu), hidden (hides the menu unless a key is pressed), and countdown (shows a simple timer).
  • GRUB_TIMEOUT: Defines how many seconds GRUB waits before automatically loading the default entry. Setting this to 0 boots immediately, while -1 waits indefinitely until a selection is made.
  • GRUB_CMDLINE_LINUX_DEFAULT: Passes arguments to the Linux kernel during standard boots. By default, Ubuntu includes quiet splash to hide detailed kernel boot messages and present a graphical splash screen. Removing these options enables verbose boot logging for troubleshooting.
  • GRUB_CMDLINE_LINUX: Applies kernel parameters to both standard and recovery boot modes.
  • GRUB_GFXMODE: Defines the screen resolution of the GRUB menu (e.g., 1024x768 or 1924x1080).

Applying Changes

Modifying /etc/default/grub requires root privileges (e.g., using sudo nano /etc/default/grub). Any changes made to this file remain inactive until you generate a new boot script by running:

sudo update-grub

Once this command executes successfully, the updated configuration takes effect on the next system restart.
