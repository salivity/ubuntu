How to Install and Configure Squid Proxy on Ubuntu

Setting up a dedicated proxy server allows you to manage network traffic, enhance security, and cache web content to save bandwidth. This guide provides a straightforward, step-by-step walkthrough on how to install, configure, and secure the Squid proxy server on an Ubuntu system, covering essential configuration tweaks, Access Control Lists (ACLs), and basic user authentication.

Step 1: Update System Packages and Install Squid

Before installing any new software, ensure your package lists are up to date:

sudo apt update && sudo apt upgrade -y

Install the Squid proxy package using the apt package manager:

sudo apt install squid -y

Once installed, the Squid service starts automatically. Verify its status to ensure it is running:

sudo systemctl status squid

Step 2: Backup the Default Squid Configuration

The default configuration file is located at /etc/squid/squid.conf. Before making changes, create a backup copy:

sudo cp /etc/squid/squid.conf /etc/squid/squid.conf.bak

Step 3: Configure Access Control Lists (ACLs)

Open the Squid configuration file in a text editor:

sudo nano /etc/squid/squid.conf

By default, Squid denies all incoming connections from external networks. To allow specific IP addresses or local networks to use the proxy, you need to define an ACL.

  1. Locate the section handling ACLs or scroll to the top of the file.
  2. Define your local IP range using the acl directive:
acl localnet_proxy src 192.168.1.0/24

(Replace 192.168.1.0/24 with your network's actual IP subnet).

  1. Scroll down to the http_access directives and add a rule allowing your newly defined ACL. Place this above the http_access deny all rule:
http_access allow localnet_proxy

Step 4: Change Default Port (Optional)

By default, Squid listens on port 3128. If you want to change this port for security or network compliance, locate the http_port line in /etc/squid/squid.conf and modify it:

http_port 8080

Save and close the file (Ctrl+O, Enter, then Ctrl+X in Nano).

Step 5: Set Up Basic User Authentication

To restrict access so that users must log in with a username and password:

  1. Install the Apache utilities package to generate password files:
sudo apt install apache2-utils -y
  1. Create a passwords file and generate a user (replace proxyuser with your desired username):
sudo htpasswd -c /etc/squid/passwords proxyuser

You will be prompted to enter and confirm a password.

  1. Reopen /etc/squid/squid.conf:
sudo nano /etc/squid/squid.conf
  1. Add the following authentication configuration lines above the http_access rules:
auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwords
auth_param basic realm Squid Proxy Password Authentication
acl authenticated proxy_auth REQUIRED
http_access allow authenticated

Step 6: Configure Firewall and Restart Squid

If Uncomplicated Firewall (UFW) is active on your server, allow traffic on your configured Squid port (e.g., port 3128):

sudo ufw allow 3128/tcp

Restart the Squid service to apply all configuration changes:

sudo systemctl restart squid

Step 7: Test the Proxy Server

You can test your proxy server using a curl command from a client machine within your allowed network list:

curl -x http://proxyuser:password@YOUR_SERVER_IP:3128 https://httpbin.org/ip

If configured correctly, the output will display your Squid server's IP address instead of your local machine's public IP address.
