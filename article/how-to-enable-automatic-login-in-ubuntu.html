How to Enable Automatic Login in Ubuntu

Enabling automatic login in Ubuntu allows your computer to boot directly to the desktop without prompting for a password, streamlining the startup process for personal or single-user devices. This guide covers how to configure automatic login using the built-in Ubuntu Graphical User Interface (GUI) settings as well as through the command line for advanced users or display manager configurations.

Method 1: Enable Automatic Login via GUI Settings

The easiest way to enable automatic login is through the standard Ubuntu system settings menu.

  1. Open the Applications menu and search for Settings, or click the system menu in the top-right corner of the screen and select Settings.
  2. Scroll down the left sidebar and click on Users.
  3. Click the Unlock button located in the top-right corner of the window and enter your administrator password.
  4. Locate the Automatic Login toggle switch.
  5. Switch the toggle to the ON position.
  6. Close the Settings window.

The next time your system restarts, Ubuntu will log straight into your account without requiring a password.

Method 2: Enable Automatic Login via the Terminal

If you prefer using the terminal or are operating on a system where the GUI settings are unavailable, you can edit the GDM3 (GNOME Display Manager) configuration file directly.

  1. Open the Terminal by pressing Ctrl + Alt + T.

  2. Open the display manager configuration file in a text editor with administrative privileges:

    sudo nano /etc/gdm3/custom.conf

  3. Look for the section labeled [daemon].

  4. Locate or add the following lines under the [daemon] section (replace your_username with your actual Ubuntu username):

    AutomaticLoginEnable = true
AutomaticLogin = your_username

    Note: If these lines already exist but have a # symbol at the beginning, remove the # to uncomment them.

  5. Save the file by pressing Ctrl + O, hit Enter, and exit the editor by pressing Ctrl + X.

  6. Reboot your system to apply the changes:

    sudo reboot

Security Considerations

While automatic login offers convenience, it removes an essential layer of security. Anyone with physical access to your device can access your files, browsing history, and saved credentials. Avoid enabling this feature on laptops or computers located in shared or public environments.
