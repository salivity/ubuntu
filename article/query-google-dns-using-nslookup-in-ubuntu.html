Query Google DNS Using nslookup in Ubuntu

This article demonstrates how to query a hostname against Google's Public DNS servers using the nslookup utility in Ubuntu. By targeting Google's DNS servers directly, you can verify DNS propagation, troubleshoot local resolution failures, and confirm IP address mappings independent of your default system or router settings. The following sections cover the required package installation, the core command syntax, and how to interpret the command output.

1. Install nslookup (If Missing)

The nslookup tool is packaged within the bind9-dnsutils (or legacy dnsutils) package in Ubuntu. To ensure it is installed, open your terminal and run:

sudo apt update
sudo apt install bind9-dnsutils -y

2. Basic Command Syntax

To query a specific DNS server using nslookup, provide the target hostname followed by the IP address of the DNS server you wish to target:

nslookup <hostname> <dns-server-ip>

Google provides the following public DNS IP addresses:

  • IPv4 Primary: 8.8.8.8
  • IPv4 Secondary: 8.8.4.4
  • IPv6 Primary: 2001:4860:4860::8888
  • IPv6 Secondary: 2001:4860:4860::8844

3. Querying Google DNS

To resolve a hostname (such as example.com) specifically through Google's primary IPv4 DNS server, execute:

nslookup example.com 8.8.8.8

To run the query using Google's IPv6 DNS server, use:

nslookup example.com 2001:4860:4860::8888

4. Interpreting the Output

When you run the command, nslookup returns two distinct sections:

Server:     8.8.8.8
Address:    8.8.8.8#53

Non-authoritative answer:
Name:   example.com
Address: 93.184.216.34
Name:   example.com
Address: 2606:2800:220:1:248:1893:25c8:1946
  • Server & Address (top section): Confirms that the request was processed by Google's DNS server (8.8.8.8) on port 53.
  • Non-authoritative answer: Indicates that the results were fetched from cache rather than directly from the primary authoritative nameservers for that domain.
  • Name & Address (bottom section): Displays the corresponding IPv4 (A record) and IPv6 (AAAA record) addresses tied to the queried hostname.

5. Using nslookup in Interactive Mode

You can also switch to Google's DNS inside nslookup's interactive shell if you need to perform multiple lookups:

  1. Launch interactive mode: 
    nslookup
  2. Set the server to Google DNS: 
    > server 8.8.8.8
Default server: 8.8.8.8
Address: 8.8.8.8#53
  3. Type the domain names you want to resolve: 
    > example.com
> ubuntu.com
  4. Type exit to return to your normal bash prompt.
