Auto-Mount External Drives with udisksctl in Ubuntu

This guide explains how to automatically mount external drives in Ubuntu using udisksctl and udev rules. By combining a lightweight shell script with the system device manager, you can mount removable storage directly into your user's /media directory without requiring manual intervention, administrative privileges, or static /etc/fstab entries.

Step 1: Create the Auto-Mount Script

udisksctl requires access to a standard user session bus to mount partitions without root authentication prompts. Create a script that captures device attachment events and executes udisksctl under your specific user environment.

Create the script file:

sudo nano /usr/local/bin/udisks-automount.sh

Paste the following script, replacing your_username with your actual Ubuntu username:

#!/bin/bash
ACTION=$1
DEVNAME=$2
TARGET_USER="your_username"
USER_ID=$(id -u "$TARGET_USER")

# Ensure required environment variables for the user session are set
export XDG_RUNTIME_DIR="/run/user/$USER_ID"
export DBUS_SESSION_BUS_ADDRESS="unix:path=/run/user/$USER_ID/bus"

if [ "$ACTION" = "add" ]; then
    # Allow the kernel to finish initializing the partition tables
    sleep 2
    su - "$TARGET_USER" -c "udisksctl mount -b $DEVNAME --no-user-interaction"
fi

Save and exit the file (press Ctrl+O, Enter, then Ctrl+X).

Make the script executable:

sudo chmod +x /usr/local/bin/udisks-automount.sh

Step 2: Create a Udev Rule

To trigger the script whenever an external block device is plugged in, set up a custom udev rule.

Create the rule file:

sudo nano /etc/udev/rules.d/99-udisks-automount.rules

Add the following rule:

KERNEL=="sd[a-z][0-9]*", SUBSYSTEM=="block", ACTION=="add", RUN+="/usr/local/bin/udisks-automount.sh add %N"

This rule matches partition blocks (such as sdb1, sdc1) on an add event and passes the device node path directly to your script.

Save and exit the editor.

Step 3: Reload Udev Rules

Reload the udev daemon to apply the new configuration immediately:

sudo udevadm control --reload-rules
sudo udevadm trigger

Step 4: Verify the Setup

  1. Insert an external USB storage drive into an available port.
  2. Verify the mount status using lsblk:
lsblk

The partition should appear mounted under /media/your_username/[Volume_Label_or_UUID] with full read and write permissions assigned to your user account.
