How to Install and Configure DHCP Server on Ubuntu

Setting up a Dynamic Host Configuration Protocol (DHCP) server on Ubuntu allows you to automatically assign IP addresses, subnet masks, default gateways, and DNS settings to network devices. This guide covers the complete step-by-step process of installing the isc-dhcp-server package, selecting the target network interface, configuring the IP address pool, and starting the service to ensure seamless automated network address allocation.

Step 1: Update System Packages

Update your local package repository to ensure you are installing the latest software versions:

sudo apt update && sudo apt upgrade -y

Step 2: Set a Static IP Address for the Server

A DHCP server requires a static IP address to function correctly on the network. Open your Netplan configuration file:

sudo nano /etc/netplan/01-netcfg.yaml

Configure your primary network interface (e.g., eth0) with a static IP address:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      addresses:
        - 192.168.1.10/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]

Apply the new network settings:

sudo netplan apply

Step 3: Install the DHCP Server Package

Install the standard ISC DHCP server package using the APT package manager:

sudo apt install isc-dhcp-server -y

Note: The installation process may throw an error when starting the service automatically; this is expected because the default configuration is not yet tailored to your network.

Step 4: Define the Network Interface

Specify which network interface the DHCP server should monitor for incoming requests:

sudo nano /etc/default/isc-dhcp-server

Locate the INTERFACESv4 variable and insert your network interface name:

INTERFACESv4="eth0"

Save and exit the file.

Step 5: Configure the DHCP Server Rules

Open the main DHCP configuration file:

sudo nano /etc/dhcp/dhcpd.conf

Set the global lease parameters and define the subnet, IP address range, gateway, and DNS servers. Add or modify the configuration block as follows:

default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.100 192.168.1.200;
    option routers 192.168.1.1;
    option subnet-mask 255.255.255.0;
    option domain-name-servers 8.8.8.8, 8.8.4.4;
    option domain-name "example.local";
}

Save and exit the file.

Step 6: Start and Enable the DHCP Service

Start the DHCP server and set it to launch automatically at boot:

sudo systemctl start isc-dhcp-server
sudo systemctl enable isc-dhcp-server

Verify that the service is running properly:

sudo systemctl status isc-dhcp-server

Step 7: Adjust Firewall Settings

If UFW (Uncomplicated Firewall) is active on your server, allow incoming UDP traffic on port 67:

sudo ufw allow 67/udp
