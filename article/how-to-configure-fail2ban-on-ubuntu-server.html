How to Configure Fail2ban on Ubuntu Server

Fail2ban is an essential security tool that monitors server log files for automated brute-force attacks and dynamically updates firewall rules to block offending IP addresses. This guide walks you through installing Fail2ban, creating custom configuration files, defining ban rules for SSH, and managing banned IP addresses to secure your Ubuntu server.

Step 1: Install Fail2ban

Update your local package index and install Fail2ban using the APT package manager:

sudo apt update
sudo apt install fail2ban -y

Fail2ban starts automatically after installation. You can verify its status by running:

sudo systemctl status fail2ban

Step 2: Create a Local Configuration File

Fail2ban stores its default configuration in /etc/fail2ban/jail.conf. Instead of modifying this file directly—which can be overwritten during package updates—copy it to a new file named jail.local:

sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

Open the new configuration file in a text editor:

sudo nano /etc/fail2ban/jail.local

Step 3: Configure Global Default Settings

Locate the [DEFAULT] section inside /etc/fail2ban/jail.local to adjust general security parameters:

  • ignoreip: Add your own IP address or subnets to prevent accidentally locking yourself out. Separate multiple IPs with spaces. 
    ignoreip = 127.0.0.1/8 ::1 YOUR_OFFICE_OR_HOME_IP
  • bantime: Set the duration an IP address remains blocked. You can use values like 1h (one hour), 1d (one day), or 10m (ten minutes). 
    bantime = 1h
  • findtime: Define the time frame during which repeated failed attempts are counted. 
    findtime = 10m
  • maxretry: Set the maximum number of failed connection attempts allowed within the findtime window before an IP is banned. 
    maxretry = 5

Step 4: Configure the SSH Jail

Scroll down to the [sshd] section in /etc/fail2ban/jail.local to configure protection specifically for SSH connections. Make sure the section looks similar to this:

[sshd]
enabled = true
port = ssh
logpath = %(sshd_log)s
backend = %(sshd_backend)s
maxretry = 3
bantime = 1d

Note: If you changed your default SSH port, update the port directive to match your custom port number.

Save the file and exit the text editor (in nano, press Ctrl + O, Enter, then Ctrl + X).

Step 5: Restart and Enable Fail2ban

Apply your new settings by restarting the Fail2ban service:

sudo systemctl restart fail2ban

Ensure Fail2ban starts automatically on system boot:

sudo systemctl enable fail2ban

Step 6: Verify and Manage Fail2ban

To verify that Fail2ban is active and protecting your SSH service, check the overall jail status:

sudo fail2ban-client status

To view detailed information about the SSH jail, including total banned IPs and currently blocked addresses, run:

sudo fail2ban-client status sshd

If an IP address gets blocked by mistake, remove it from the ban list using the following command:

sudo fail2ban-client set sshd unbanip IP_ADDRESS
