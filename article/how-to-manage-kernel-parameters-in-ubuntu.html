How to Manage Kernel Parameters in Ubuntu

Kernel parameters dictate core operational behaviors in Ubuntu, including networking functionality, system security, and memory management. The standard command used to view, modify, and manage these parameters dynamically at runtime—without requiring a system reboot—is sysctl. This guide explains how to use the sysctl command to view active kernel settings, modify them temporarily on the fly, and apply configuration changes permanently across system restarts.

Viewing Kernel Parameters

The sysctl command queries and modifies kernel parameters exported through the /proc/sys/ interface.

To list all available kernel parameters and their current values, run:

sysctl -a

To view the value of a specific parameter, pass the parameter name to sysctl:

sysctl net.ipv4.ip_forward

You can also view parameters directly by reading their corresponding files inside the /proc/sys/ directory using cat:

cat /proc/sys/net/ipv4/ip_forward

Modifying Parameters Dynamically (Temporary Changes)

To change a kernel parameter immediately at runtime, use sysctl with the -w flag followed by the parameter and its new value:

sudo sysctl -w net.ipv4.ip_forward=1

Alternatively, write the value directly to the virtual file in /proc/sys/:

echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward

Changes made using either of these dynamic methods take effect immediately. However, these adjustments are non-persistent and will reset to their default values when the system reboots.

Making Kernel Changes Permanent

To ensure parameter modifications persist after a system reboot, configuration files must be updated. Ubuntu reads kernel configuration files from /etc/sysctl.conf and any .conf files located in the /etc/sysctl.d/ directory.

Step 1: Add the Parameter to a Configuration File

It is best practice to create a dedicated configuration file inside /etc/sysctl.d/ rather than modifying the main /etc/sysctl.conf file directly:

sudo nano /etc/sysctl.d/99-custom.conf

Add your desired settings to the file:

net.ipv4.ip_forward = 1
vm.swappiness = 10

Step 2: Apply the Settings Without Rebooting

After saving the configuration file, reload the sysctl settings to apply the changes immediately:

sudo sysctl --system

Alternatively, to reload settings specifically from /etc/sysctl.conf, run:

sudo sysctl -p
