How to Test Disk Read and Write Speed in Ubuntu

Testing disk performance on Ubuntu is essential for monitoring server health, troubleshooting performance bottlenecks, and evaluating storage hardware. This article covers the primary command-line tools used to measure disk read and write speeds in Ubuntu, including the built-in dd command, hdparm for quick read tests, and fio for detailed benchmarking.

Using the dd Command

The dd command is the most standard, pre-installed tool available in Ubuntu for performing basic disk speed tests. It works by copying data from an input source to an output destination while measuring the time taken.

1. Test Write Speed

To measure the disk write speed, run the following command in your terminal:

dd if=/dev/zero of=./test.tmp bs=1G count=1 oflag=dsync

Explanation of parameters:

  • if=/dev/zero: Reads a stream of null bytes as input data.
  • of=./test.tmp: Writes the output to a temporary file named test.tmp.
  • bs=1G: Sets the block size to 1 Gigabyte.
  • count=1: Writes one block of data.
  • oflag=dsync: Forces synchronized I/O, bypassing the system memory cache to ensure accurate write speeds directly to the physical disk.

2. Test Read Speed

To measure the disk read speed, clear the buffer cache first so the system does not read from RAM, then read the temporary file:

sudo sh -c "sync && echo 3 > /proc/sys/vm/drop_caches"
dd if=./test.tmp of=/dev/null bs=1G count=1 status=progress

Explanation of parameters:

  • drop_caches: Clears the Linux kernel page cache to ensure a true disk read.
  • of=/dev/null: Discards the read data output.
  • status=progress: Displays real-time speed statistics during execution.

3. Clean Up

After completing the tests, remove the temporary file to free up disk space:

rm ./test.tmp

Using hdparm for Quick Read Speed Tests

hdparm is a lightweight command-line utility designed to evaluate drive performance, specifically optimized for SATA and NVMe drives.

  1. Install hdparm (if not already installed):

    sudo apt update && sudo apt install hdparm -y

  2. Run Read Speed Test: Specify your drive path (e.g., /dev/sda or /dev/nvme0n1):

    sudo hdparm -Tt /dev/sda

Output Details:

  • -T: Tests cached read speed (performance of system RAM, CPU, and buffer).
  • -t: Tests buffered disk read speed (direct reading speed of the physical disk).

Using fio for Advanced Benchmarking

For comprehensive I/O performance analysis, fio (Flexible I/O Tester) provides precise measurements for random and sequential reads and writes.

  1. Install fio:

    sudo apt update && sudo apt install fio -y

  2. Run a Combined Read/Write Test:

    fio --name=random-rw --ioengine=libaio --rw=randrw --bs=4k --numjobs=1 --size=1G --runtime=60 --time_based --end_fsync=1

This command generates a 1GB test file and performs random 4KB read and write operations for 60 seconds, outputting overall IOPS (Input/Output Operations Per Second) and bandwidth rates.
