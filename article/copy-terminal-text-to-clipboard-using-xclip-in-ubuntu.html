Copy Terminal Text to Clipboard Using xclip in Ubuntu

Using the xclip command-line utility in Ubuntu allows you to seamlessly copy text and command outputs directly from your terminal to the system clipboard. This guide covers how to install xclip, copy file contents or command outputs using standard piping, and set up simple aliases to streamline your command-line workflow.

Installing xclip

Before using xclip, install it via the default package manager:

sudo apt update
sudo apt install xclip

Copying Command Output to Clipboard

To copy the output of any terminal command to the system clipboard (allowing you to paste it anywhere using Ctrl+V), pipe the output into xclip with the -selection clipboard argument:

echo "Text to copy" | xclip -selection clipboard

Examples of practical usage:

  • Copy current directory path:

    pwd | xclip -selection clipboard

  • Copy SSH public key:

    cat ~/.ssh/id_rsa.pub | xclip -selection clipboard

Copying File Contents Directly

You can pass a file directly to xclip without using cat:

xclip -selection clipboard filename.txt

Understanding Clipboard Selections

xclip manages two primary X11 clipboard selections:

  • -selection clipboard: Maps to the standard system clipboard used for standard copy/paste shortcuts (Ctrl+C / Ctrl+V).
  • -selection primary (default): Maps to the primary selection, which pastes text using the middle mouse button.

If you omit the -selection flag, xclip defaults to the primary selection.

Creating a Useful Alias

To avoid typing -selection clipboard repeatedly, add an alias to your ~/.bashrc or ~/.zshrc file:

alias setclip='xclip -selection clipboard'
alias getclip='xclip -selection clipboard -o'

Apply the changes:

source ~/.bashrc

Now you can copy and paste using your new aliases:

# Copy to clipboard
date | setclip

# Output clipboard contents to terminal
getclip
