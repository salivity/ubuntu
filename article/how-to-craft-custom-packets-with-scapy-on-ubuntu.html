How to Craft Custom Packets with Scapy on Ubuntu

This article explains how to craft, manipulate, and transmit custom network packets on Ubuntu using the Scapy Python library. You will learn how to install Scapy, assemble network protocol layers using Scapy's stacking syntax, inspect packet contents, and transmit the crafted frames across a network using root privileges.

Installing Scapy on Ubuntu

To get started, install Scapy and its dependencies using the Ubuntu package manager or Python's package installer. Open a terminal and run:

sudo apt update
sudo apt install python3-scapy -y

Alternatively, you can install the latest release inside a virtual environment using pip:

sudo apt install python3-pip -y
pip3 install scapy

Understanding Scapy's Layer Stacking

Scapy represents network protocols as Python classes. Individual protocol layers—such as Ethernet, IP, TCP, and UDP—are combined sequentially using the slash (/) operator. In this syntax, the leftmost layer represents the lowest protocol layer, and each subsequent layer is encapsulated inside the previous one.

Creating and Sending an ICMP Echo Request

A basic example is an ICMP "Ping" packet, which consists of an IP layer stacked with an ICMP layer.

Create a file named ping_packet.py:

from scapy.all import IP, ICMP, sr1

# Define the target IP address
target_ip = "8.8.8.8"

# Stack the IP and ICMP layers
packet = IP(dst=target_ip) / ICMP()

# Display packet details
packet.show()

# Send the packet at Layer 3 and wait for a single response
response = sr1(packet, timeout=2)

if response:
    response.show()
else:
    print("No response received.")

Crafting raw sockets requires elevated privileges on Linux. Run the script with sudo:

sudo python3 ping_packet.py

Crafting a Custom TCP SYN Packet

Scapy allows full control over TCP flags, sequence numbers, and port configurations. To craft a TCP SYN packet targeted at an HTTP service:

from scapy.all import IP, TCP, sr1

# Define layers with custom attributes
ip_layer = IP(dst="192.168.1.1")
tcp_layer = TCP(dport=80, sport=44444, flags="S", seq=1000)

# Assemble the packet
syn_packet = ip_layer / tcp_layer

# Transmit and capture the response (SYN-ACK or RST)
reply = sr1(syn_packet, timeout=2)

if reply and reply.haslayer(TCP):
    if reply[TCP].flags == "SA":
        print("Port 80 is open (SYN-ACK received).")
    elif reply[TCP].flags == "RA":
        print("Port 80 is closed (RST-ACK received).")

Adding Custom Payloads

You can attach raw text or binary data to any packet by appending the Raw layer or passing a string directly into the stack:

from scapy.all import IP, UDP, Raw, send

# Construct a UDP packet with custom data
payload_packet = IP(dst="192.168.1.50") / UDP(dport=9999, sport=5555) / Raw(load="CustomDiagnosticPayload")

# Send the packet without waiting for a reply
send(payload_packet)

Sending Functions Overview

Scapy provides distinct functions depending on the network layer and whether you expect a reply:

  • send(): Transmits packets at Layer 3 (IP) without listening for responses.
  • sendp(): Transmits packets at Layer 2 (Ethernet). Requires defining an Ether() header.
  • sr(): Transmits Layer 3 packets and returns all answered and unanswered responses.
  • sr1(): Transmits a Layer 3 packet and stops listening after receiving the first reply.
  • srp() / srp1(): Same as sr() and sr1(), but operating at Layer 2.
