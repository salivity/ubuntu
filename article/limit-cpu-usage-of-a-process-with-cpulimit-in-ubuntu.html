Limit CPU Usage of a Process with cpulimit in Ubuntu

Managing system resources in Ubuntu is essential for maintaining optimal performance, especially when running resource-intensive applications. The cpulimit command-line utility allows you to restrict the CPU usage of a specific process by monitoring and controlling its execution. This step-by-step guide covers how to install cpulimit, find target processes, and apply CPU percentage limits by process ID, executable name, or direct command execution.

Step 1: Install cpulimit

The cpulimit tool is available in the official Ubuntu repositories. Open your terminal and run the following commands to update your package list and install the tool:

sudo apt update
sudo apt install cpulimit

Step 2: Identify the Target Process

Before limiting CPU usage, you need to identify the process you want to target. You can find running processes using top, htop, or pgrep.

To find the Process ID (PID) or exact name of a running application:

pgrep process_name

(Replace process_name with the actual program name, such as firefox or ffmpeg.)

Alternatively, use top to view real-time CPU usage and note the PID in the left-most column.

Step 3: Limit CPU Usage

The limit specified with the -l flag is a percentage ranging from 1 up to 100 times the number of CPU cores available on your system (e.g., 200% on a quad-core machine represents two full cores).

Method A: Limit by Process ID (PID)

If the process is already running and you know its PID, use the -p flag:

sudo cpulimit -p 1234 -l 50

This restricts process 1234 to a maximum of 50% CPU utilization.

Method B: Limit by Executable Name

To target a process by its binary executable name, use the -e flag:

sudo cpulimit -e process_name -l 40

This command will monitor and limit any running process matching the specified name to 40% CPU usage.

Method C: Launch a Process with a CPU Limit

You can launch a program directly under a CPU restriction by using -- followed by the command:

cpulimit -l 30 -- heavy-script.sh

Step 4: Run cpulimit in the Background

By default, cpulimit remains active in your current terminal session. To detach it and run it in the background, add the -b flag:

sudo cpulimit -p 1234 -l 50 -b

How to Stop cpulimit

If you ran cpulimit in the foreground, press Ctrl + C in the terminal to stop limiting the process. If it is running in the background, find its PID and kill the process:

sudo pkill cpulimit

Stopping cpulimit restores the target process to its normal, unrestricted execution state without terminating the process itself.
