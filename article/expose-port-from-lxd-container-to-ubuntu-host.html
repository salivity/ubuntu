Expose Port from LXD Container to Ubuntu Host

Exposing a specific network port from an LXD container to its Ubuntu host allows external traffic to access services running inside the containerized environment. This guide explains how to map ports directly using LXD's native proxy device mechanism, which acts as a built-in TCP/UDP forwarding layer without requiring manual iptables or NAT firewall configurations.

Prerequisites

Ensure you have the following ready before configuring port forwarding:

  • An active LXD container running on an Ubuntu host.
  • The name of the container and the port number the service is listening on inside the container.
  • Administrative (sudo or lxd group) access to the host.

Step 1: Add a Proxy Device

The standard and recommended method to expose a port in LXD is the proxy device type. This device binds a port on the host and forwards incoming traffic directly to a designated port inside the container.

Run the following command on the Ubuntu host:

lxc config device add <container_name> <device_name> proxy listen=tcp:<host_ip>:<host_port> connect=tcp:127.0.0.1:<container_port>

Parameter Breakdown:

  • <container_name>: The name of your running LXD container.
  • <device_name>: A unique name for this device configuration (e.g., web-proxy or port8080).
  • listen=tcp:<host_ip>:<host_port>: The protocol, IP address, and port on the Ubuntu host. To listen on all network interfaces of the host, use 0.0.0.0 (e.g., listen=tcp:0.0.0.0:80).
  • connect=tcp:127.0.0.1:<container_port>: The address and port within the container that handles the traffic. Using 127.0.0.1 forwards traffic to the container's localhost interface.

Example: Forwarding HTTP Traffic

To forward traffic from port 80 on the host to port 80 inside a container named web-server:

lxc config device add web-server http-proxy proxy listen=tcp:0.0.0.0:80 connect=tcp:127.0.0.1:80

Step 2: Verify the Configuration

  1. Verify the device was added to the container configuration:
lxc config device show <container_name>
  1. Check that the host is listening on the configured port:
sudo ss -tulpn | grep <host_port>

You should see a process owned by LXD listening on that port.

  1. Test connectivity: Send a request to the host IP on the exposed port from a remote machine or the host itself:
curl http://<host_ip>:<host_port>

Step 3: Removing the Port Forwarding (Optional)

If you no longer need the port exposed to the host, delete the proxy device using the device name you defined:

lxc config device remove <container_name> <device_name>

For example:

lxc config device remove web-server http-proxy
