How to Install Ghidra on Ubuntu

This guide provides a straightforward walkthrough for installing and configuring the NSA's Ghidra software reverse engineering suite on Ubuntu. You will learn how to prepare the necessary Java runtime environment, download and unpack the latest Ghidra release, configure system variables, and set up a desktop shortcut for quick launching.

Step 1: Install Java Development Kit (JDK)

Ghidra requires Java 17 or later (64-bit). The recommended version is OpenJDK 17 or OpenJDK 21.

  1. Open your terminal (Ctrl + Alt + T) and update your package lists: 
    sudo apt update
  2. Install OpenJDK 21 JDK: 
    sudo apt install openjdk-21-jdk -y
  3. Verify the installation: 
    java -version
    Ensure the output displays Java version 17 or higher.

Step 2: Download Ghidra

  1. Navigate to the official Ghidra repository on GitHub (github.com/NationalSecurityAgency/ghidra/releases) to identify the latest release.
  2. Download the latest release archive using wget (replace the URL below with the latest release version if needed): 
    wget https://github.com/NationalSecurityAgency/ghidra/releases/download/Ghidra_11.1.2_build/ghidra_11.1.2_PUBLIC_20240709.zip

Step 3: Extract and Install Ghidra

  1. Install unzip if it is not already installed: 
    sudo apt install unzip -y
  2. Extract the downloaded zip file to the /opt directory for system-wide access: 
    sudo unzip ghidra_*_PUBLIC_*.zip -d /opt/
  3. Rename the extracted folder to a simplified directory name: 
    sudo mv /opt/ghidra_*_PUBLIC /opt/ghidra
  4. Adjust ownership of the directory to your current user: 
    sudo chown -R $USER:$USER /opt/ghidra

Step 4: Configure Environment Variables

While Ghidra automatically detects Java in most Ubuntu installations, setting JAVA_HOME ensures stability.

  1. Check your Java path: 
    readlink -f $(which java)
  2. Open your shell configuration file: 
    nano ~/.bashrc
  3. Add the following lines to the end of the file: 
    export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
export PATH=$PATH:/opt/ghidra
  4. Apply the changes: 
    source ~/.bashrc

Step 5: Create a Desktop Shortcut

To launch Ghidra from your Ubuntu application menu without using the terminal:

  1. Create a .desktop launcher file: 
    nano ~/.local/share/applications/ghidra.desktop
  2. Paste the following configuration: 
    [Desktop Entry]
Version=1.0
Name=Ghidra
GenericName=Reverse Engineering Suite
Comment=NSA Software Reverse Engineering Suite
Exec=/opt/ghidra/ghidraRun
Icon=/opt/ghidra/support/ghidra.png
Terminal=false
Type=Application
Categories=Development;Security;
  3. Save and close the file (Ctrl + O, then Enter, then Ctrl + X).
  4. Make the desktop file executable: 
    chmod +x ~/.local/share/applications/ghidra.desktop

Step 6: Launch Ghidra

You can now start Ghidra in one of two ways:

  • Run ghidraRun directly from any terminal prompt.
  • Open your Ubuntu application menu by pressing the Super (Windows) key and search for Ghidra.

Upon first launch, accept the user agreement to open the main Ghidra project window.
