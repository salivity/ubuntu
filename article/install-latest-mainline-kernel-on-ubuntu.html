Install Latest Mainline Kernel on Ubuntu

Installing the latest mainline Linux kernel on Ubuntu allows you to access new features, performance enhancements, and support for newer hardware ahead of standard distribution updates. This guide outlines the complete process for updating your system’s kernel using both a user-friendly Graphical User Interface (GUI) tool and traditional command-line terminal methods, along with instructions on how to safely verify and roll back your changes.

Important Considerations Before Upgrading

Mainline kernels are built directly from Linux source trees provided by kernel developers without Ubuntu-specific patches or testing. Keep the following in mind:

  • Secure Boot: Mainline kernel packages are unsigned. If Secure Boot is enabled in your BIOS/UEFI, you must disable it before booting into a mainline kernel.
  • Proprietary Drivers: Third-party modules like NVIDIA graphics drivers or proprietary Wi-Fi drivers may fail to build or load with brand-new kernel versions.
  • Backups: Always back up critical data before modifying core system components.

Method 1: Using the Ubuntu Mainline Kernel Installer (GUI)

The simplest and recommended way to manage mainline kernels is using the mainline open-source tool.

1. Add the Mainline PPA

Open your terminal (Ctrl+Alt+T) and add the repository:

sudo add-apt-repository ppa:cappelikan/ppa

2. Update Package Lists and Install the Tool

sudo apt update
sudo apt install mainline

3. Install the Kernel

  1. Launch Ubuntu Mainline Kernel Installer from your application menu.
  2. Browse the list of available versions for the latest stable release.
  3. Select the desired kernel version and click Install.
  4. Once the installation process completes, restart your computer.

Method 2: Manual Installation via Terminal (CLI)

If you prefer to install packages manually without third-party tools, download the official kernel packages directly.

1. Download Kernel Packages

Navigate to the official Ubuntu Mainline PPA archive in your web browser (kernel.ubuntu.com/~kernel-ppa/mainline/), select the target version folder, and download the four required .deb files for your system architecture (typically amd64):

  • linux-headers-[version]_all.deb
  • linux-headers-[version]-generic_[version]_amd64.deb
  • linux-image-unsigned-[version]-generic_[version]_amd64.deb
  • linux-modules-[version]-generic_[version]_amd64.deb

2. Install the Packages

Open a terminal, navigate to the folder containing the downloaded .deb files, and run:

sudo dpkg -i *.deb

3. Reboot Your System

sudo reboot

Verifying the Kernel Update

After rebooting, confirm that the system is running the new kernel by executing:

uname -r

The terminal output should reflect the newly installed kernel version number.

Reverting to the Default Kernel

If you experience hardware instability or driver failures:

  1. Restart your machine and hold the Shift key (or press Esc) during startup to display the GRUB boot menu.
  2. Select Advanced options for Ubuntu.
  3. Choose to boot into your original, standard Ubuntu kernel.
  4. Once logged in, launch the Ubuntu Mainline Kernel Installer tool to uninstall the mainline kernel, or remove it manually via sudo apt remove linux-image-[version]-generic.
