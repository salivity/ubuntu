How to List PCI Devices in Ubuntu

Managing and troubleshooting hardware on an Ubuntu system often requires inspecting connected Peripheral Component Interconnect (PCI) devices, such as graphics cards, network adapters, storage controllers, and sound cards. The primary command used to display these devices is lspci, a built-in utility provided by the pciutils package. This article provides a straightforward guide on how to use the lspci command and its most useful flags to view connected PCI hardware on your Ubuntu system.

The lspci Command

The lspci command displays detailed information about all PCI buses and devices connected to your system motherboard.

Basic Usage

To list all connected PCI devices in a brief, one-line summary per device, open your terminal and run:

lspci

This output displays the device domain, bus, slot, function number, vendor name, device type, and model name.

Common lspci Command Options

You can modify the output of lspci using various flags depending on the level of detail you need:

  • Show Kernel Drivers (-k): Displays the kernel driver currently handling each device and the kernel modules available for it.

    lspci -k

  • Verbose Output (-v, -vv, or -vvv): Displays detailed information about all devices, including memory addresses, IRQs, and capabilities.

    lspci -v

  • Numeric Hardware IDs (-n): Displays vendor and device codes as numbers instead of looking up their names in the database.

    lspci -n

  • Tree View (-t): Displays a diagram showing the connection relationships between buses, bridges, and devices.

    lspci -t

Filtering Specific PCI Devices

If you want to find a specific piece of hardware, pipe the output into the grep command.

  • Find Graphics/Video Cards:

    lspci | grep -i vga

  • Find Network Controllers (Wi-Fi/Ethernet):

    lspci | grep -i network

    or

    lspci | grep -i ethernet

  • Find Audio Controllers:

    lspci | grep -i audio

Installing pciutils

If the lspci command is not available on your system, install the pciutils package using apt:

sudo apt update
sudo apt install pciutils
