How to Install and Configure Gitea on Ubuntu

This article provides a complete step-by-step guide to installing and configuring Gitea, a lightweight, self-hosted Git service, on an Ubuntu system. You will learn how to prepare the server, set up the required environment and database, install the Gitea binary, configure a systemd service for automated management, and complete the initial web installation.

Step 1: Update the System and Install Dependencies

Start by updating your system packages and installing Git, which Gitea requires to operate.

sudo apt update && sudo apt upgrade -y
sudo apt install git sqlite3 -y

Step 2: Create a Dedicated Git User

For security reasons, Gitea should run under its own service user account. Create a user named git:

sudo adduser --system --group --disabled-password --shell /bin/bash --home /home/git git

Step 3: Download and Install Gitea

Download the latest Gitea binary executable from the official releases page.

wget -O gitea https://dl.gitea.com/gitea/1.21.7/gitea-1.21.7-linux-amd64

Move the executable binary to /usr/local/bin and make it executable:

sudo mv gitea /usr/local/bin/
sudo chmod +x /usr/local/bin/gitea

Step 4: Create Required Directory Structure

Gitea requires specific directories for its configuration files, repositories, logs, and data.

sudo mkdir -p /var/lib/gitea/{custom,data,log}
sudo chown -R git:git /var/lib/gitea/
sudo chmod -R 750 /var/lib/gitea/

sudo mkdir /etc/gitea
sudo chown root:git /etc/gitea
sudo chmod 770 /etc/gitea

Step 5: Configure the Systemd Service

Create a systemd unit file to manage the Gitea process automatically on boot.

Create the file using a text editor:

sudo nano /etc/systemd/system/gitea.service

Add the following configuration:

[Unit]
Description=Gitea (Git with a cup of tea)
After=syslog.target
After=network.target

[Service]
RestartSec=2s
Type=simple
User=git
Group=git
WorkingDirectory=/var/lib/gitea/
ExecStart=/usr/local/bin/gitea web --config /etc/gitea/app.ini
Restart=always
Environment=USER=git HOME=/home/git GITEA_WORK_DIR=/var/lib/gitea

[Install]
WantedBy=multi-user.target

Save and close the file. Then, enable and start the Gitea service:

sudo systemctl daemon-reload
sudo systemctl enable --now gitea

Verify that the service is running:

sudo systemctl status gitea

Step 6: Complete Web Configuration

  1. Open your web browser and navigate to http://your_server_ip:3000.
  2. Fill out the initial configuration form:
    • Database Type: Select SQLite3 (for simple setups) or configure MySQL/PostgreSQL if already installed.
    • Path: Set to /var/lib/gitea/data/gitea.db.
    • Site Title: Enter your desired platform name.
    • Server Domain: Enter your server’s IP address or domain.
    • SSH Server Port: Default is 22.
    • HTTP Port: Default is 3000.
    • Gitea Base URL: Set to http://your_server_ip:3000/.
  3. Expand Administrator Account Settings and create the primary admin user.
  4. Click Install Gitea.

Once completed, secure the configuration file permissions:

sudo chmod 660 /etc/gitea/app.ini
