How to Install DaVinci Resolve on Ubuntu

This guide provides a straightforward walkthrough for installing Blackmagic Design's DaVinci Resolve on an Ubuntu workstation. You will learn how to verify hardware requirements, install essential system dependencies and GPU drivers, unpack the official installer, and resolve common runtime library conflicts to ensure the software runs smoothly.

1. Verify GPU Drivers and OpenCL/CUDA Support

DaVinci Resolve strictly requires a dedicated GPU with proprietary drivers supporting OpenCL or CUDA.

For NVIDIA users, ensure the proprietary driver and CUDA toolkit are installed:

sudo apt update
sudo apt install nvidia-driver-535 nvidia-cuda-toolkit

For AMD users, install the proprietary AMDGPU-PRO driver with OpenCL support following AMD's official ROCm/AMDGPU deployment instructions for your specific GPU architecture.

Reboot your system after driver installation to ensure all modules load properly:

sudo reboot

2. Install Required System Dependencies

DaVinci Resolve relies on several legacy libraries that may not be present on modern Ubuntu installations. Install them using the terminal:

sudo apt update
sudo apt install libapr1 libaprutil1 libasound2 libgl1-mesa-glx libxcb-xinerama0 libxcb-shape0 libxcb-render0 libglu1-mesa

3. Download and Extract the Installer

  1. Navigate to the official Blackmagic Design website and download the Linux version of DaVinci Resolve (it will download as a .zip archive).
  2. Open your terminal, navigate to your Downloads directory, and extract the installer:
cd ~/Downloads
unzip DaVinci_Resolve_*_Linux.zip
  1. Make the extracted .run file executable:
chmod +x DaVinci_Resolve_*_Linux.run

4. Run the Installation Script

Execute the installer with root privileges:

sudo ./DaVinci_Resolve_*_Linux.run -i

Follow the on-screen graphical prompts to complete the installation. The software will be installed into the /opt/resolve/ directory.

5. Fix Common Library Conflicts (If Needed)

Modern Ubuntu versions often ship with newer versions of certain libraries (such as glib) that conflict with the bundled libraries packaged inside DaVinci Resolve. If the application fails to launch, move the conflicting bundled libraries out of the way so Resolve uses your system's versions:

cd /opt/resolve/libs
sudo mkdir disabled-libraries
sudo mv libglib-2.0.so* disabled-libraries/
sudo mv libgio-2.0.so* disabled-libraries/
sudo mv libgmodule-2.0.so* disabled-libraries/

6. Launch DaVinci Resolve

Once the installation is complete and library conflicts are addressed, you can launch DaVinci Resolve from your Ubuntu application menu or by running the following command in the terminal:

/opt/resolve/bin/resolve
