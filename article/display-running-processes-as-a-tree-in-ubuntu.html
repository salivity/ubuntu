Display Running Processes as a Tree in Ubuntu

In Ubuntu Linux, visualizing running processes in a hierarchical structure helps system administrators and users understand parent-child relationships between active tasks. The primary command used to display the hierarchy of running processes as a tree is pstree. This guide explains how to use pstree, highlights its most useful flags, and provides alternative commands for viewing process trees in Ubuntu.

Using the pstree Command

The pstree command merges identical branches by placing them in square brackets and prefixing them with the repetition count, making the process tree clean and easy to read.

To display the complete process tree, open your terminal and run:

pstree

Useful pstree Command Options

  • Show Process IDs (PIDs): Include the -p flag to display the PID for each process name.

    pstree -p

  • Show Command-Line Arguments: Include the -a flag to display command-line arguments for running processes.

    pstree -a

  • Highlight Specific Process: Include the -h flag to highlight the current process and its ancestors, or -H [PID] to highlight a specific PID.

    pstree -H 1234

  • Show Process Ownership: Include the -u flag to show user name transitions whenever the owner of a process changes.

    pstree -u

  • Combine Flags: You can combine multiple options for a detailed view.

    pstree -pau

Display a Tree for a Specific User or Process

To view the process hierarchy belonging to a specific user, pass the username as an argument:

pstree username

To display a hierarchy rooted at a specific process, pass the PID:

pstree 1234

How to Install pstree

The pstree tool is part of the psmisc package. It is installed by default on most Ubuntu systems. If it is missing, install it using the Advanced Package Tool (APT):

sudo apt update
sudo apt install psmisc

Alternative Commands for Process Trees in Ubuntu

If you prefer using other built-in tools or interactive interfaces, consider these alternatives:

1. The ps Command with Forest Output

You can use the standard ps command with the axforest option to view a process tree:

ps axforest

2. Interactive Tree View with htop

htop is an interactive process viewer. If installed, run it and switch to tree view:

  1. Launch htop: 
    htop
  2. Press F5 (or Shift + T) to toggle the tree hierarchy view.
