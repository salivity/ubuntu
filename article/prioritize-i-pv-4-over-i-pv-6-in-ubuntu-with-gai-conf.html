Prioritize IPv4 Over IPv6 in Ubuntu with gai.conf

This article explains the role of the /etc/gai.conf configuration file in Ubuntu, specifically how it controls network address resolution order. By modifying this file, system administrators can instruct the system resolver to favor IPv4 connections over IPv6 without completely disabling IPv6, effectively resolving latency issues and connection timeouts caused by misconfigured dual-stack networks.

The Role of /etc/gai.conf

The /etc/gai.conf file is the configuration file for getaddrinfo(3), the standard C library function used by Linux network applications to translate domain names into IP addresses.

Modern operating systems, including Ubuntu, follow RFC 6724 standards for default address selection. Under these standards, the system prioritizes IPv6 addresses over IPv4 addresses whenever a dual-stack domain name provides both record types (AAAA and A).

The /etc/gai.conf file allows administrators to alter this default sorting order. When an application queries a hostname, getaddrinfo() references this file to determine the precedence of the returned IP addresses.

Why Prioritize IPv4 Over IPv6?

While IPv6 is the modern standard, many local networks or ISPs still have incomplete, unoptimized, or misconfigured IPv6 routing. In such environments, systems prioritizing IPv6 often suffer from noticeable performance degradation:

  • Connection Timeouts: Applications attempt to establish a connection via IPv6 first, wait for a timeout to occur, and only then fall back to IPv4.
  • Slow Updates: Package managers like apt may hang or crawl when attempting to download packages from mirrors via broken IPv6 routes.
  • Application Delays: CLI tools like curl, wget, or remote services like SSH experience multi-second delays during initial handshakes.

Rather than completely disabling the IPv6 stack—which can break local services or software that requires the IPv6 loopback interface (::1)—adjusting precedence through /etc/gai.conf solves the issue gracefully.

How the Precedence Mechanism Works

Inside /etc/gai.conf, the sorting order is managed using precedence rules. Each rule assigns a priority value to a specific network prefix. The higher the precedence value, the higher the sorting priority.

By default, standard IPv6 addresses (::/0) hold a higher precedence than IPv4-mapped IPv6 addresses (::ffff:0:0/96).

To make IPv4 preferred, you change the precedence value of IPv4-mapped addresses so it ranks higher than native IPv6 traffic.

Step-by-Step Configuration

To configure Ubuntu to prefer IPv4:

  1. Open /etc/gai.conf in a text editor with administrative privileges:

    sudo nano /etc/gai.conf

  2. Scroll through the file to locate the precedence table. Look for the following commented line:

    #precedence ::ffff:0:0/96  100

  3. Uncomment the line by removing the # symbol:

    precedence ::ffff:0:0/96  100

  4. Save the file and exit the editor.

Applying and Verifying the Changes

Changes made to /etc/gai.conf take effect immediately for any new process that calls getaddrinfo(). A system reboot or service restart is not required.

To verify that the change is active, run a test query using ping or curl against a dual-stack host:

ping -c 1 google.com

If the configuration is working as intended, the host will resolve to an IPv4 address by default instead of an IPv6 address. IPv6 remains fully functional and will still be used as a fallback if a destination host only provides an AAAA record.
