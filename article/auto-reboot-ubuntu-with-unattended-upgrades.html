Auto Reboot Ubuntu with Unattended-Upgrades

This guide explains how to configure the unattended-upgrades package on an Ubuntu server to automatically reboot the system whenever a security or kernel update requires it. By making a few adjustments to the package configuration files, administrators can ensure security patches are fully applied while choosing whether to reboot immediately or schedule the restart during off-peak hours.

Step 1: Install Required Packages

First, ensure that unattended-upgrades and update-notifier-common are installed on your Ubuntu system. The update-notifier-common package is necessary because it detects whether a reboot is required after updates are applied.

sudo apt update
sudo apt install unattended-upgrades update-notifier-common

To enable unattended upgrades, run the reconfiguration wizard:

sudo dpkg-reconfigure --priority=low unattended-upgrades

Select Yes when prompted to automatically download and install stable updates.

Step 2: Configure Automatic Reboots

Open the primary configuration file for unattended upgrades in a text editor:

sudo nano /etc/apt/apt.conf.d/50unattended-upgrades

Scroll through the file to find the reboot configuration lines. By default, these lines are commented out with double slashes (//).

Locate the Automatic-Reboot directive, uncomment it by removing //, and set its value to "true":

Unattended-Upgrade::Automatic-Reboot "true";

Step 3: Set a Scheduled Reboot Time (Recommended)

To prevent the server from rebooting unexpectedly in the middle of a business day, specify a maintenance window by setting Automatic-Reboot-Time. Uncomment the line and specify your preferred time in 24-hour format:

Unattended-Upgrade::Automatic-Reboot-Time "03:00";

With this setting, if a kernel update installs at 2:00 PM, the server will postpone the reboot until 3:00 AM.

Step 4: Handle Logged-In Users (Optional)

If users or automated sessions remain logged into the server, the system can be forced to reboot anyway by enabling Automatic-Reboot-WithUsers:

Unattended-Upgrade::Automatic-Reboot-WithUsers "true";

Save and exit the file (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 5: Test the Configuration

To confirm that the syntax of your configuration is valid and that unattended upgrades can run without errors, execute a dry run in debug mode:

sudo unattended-upgrades --dry-run --debug

Review the output to verify that your settings are detected properly. Once configured, Ubuntu will automatically apply security updates and safely reboot when required by kernel installations.
