How to Map Mouse Buttons in Ubuntu Using xbindkeys

This guide explains how to remap mouse buttons to custom keyboard shortcuts, system commands, or scripts in Ubuntu using xbindkeys. By pairing xbindkeys with an automation utility like xdotool or xautomation, you can detect button presses on any multi-button mouse and assign them to specific desktop actions.

1. Install Required Packages

Open your terminal and install xbindkeys along with xdotool (used to simulate key presses) and x11-utils (used to detect button numbers):

sudo apt update
sudo apt install xbindkeys xdotool x11-utils

2. Identify Your Mouse Button Number

To map a button, you need to find its hardware event number. Run the following command in your terminal:

xev -event button

A small white window will appear. Move your cursor into this window and click the mouse button you want to map. Watch the terminal output for lines containing ButtonPress or ButtonRelease. Note the button number displayed after the button field (for example, button 8 or button 9). Once identified, close the xev window or press Ctrl + C in the terminal.

3. Generate the Configuration File

Create a default .xbindkeysrc file in your home directory:

xbindkeys --defaults > ~/.xbindkeysrc

4. Edit the Configuration File

Open the configuration file in a text editor:

nano ~/.xbindkeysrc

Scroll to the bottom of the file and add your custom mapping. The syntax consists of the command to execute enclosed in double quotes on the first line, followed by the mouse button identifier on the next line (written as b: followed by the button number).

Example: Map Button 8 to the Back command (Alt + Left Arrow)

"xdotool key alt+Left"
  b:8

Example: Map Button 9 to open the terminal (Ctrl + Alt + T)

"xdotool key ctrl+alt+t"
  b:9

Example: Map a button to launch a specific application

"firefox"
  b:10

Save and exit the editor (in nano, press Ctrl + O, then Enter, and Ctrl + X).

5. Start and Test xbindkeys

If an instance of xbindkeys is already running, reload it:

killall xbindkeys
xbindkeys

Test your mouse buttons to ensure the actions trigger as expected. If you need to debug any issues, run xbindkeys -n -v in a terminal to see verbose output of button presses and triggered commands in real time.

6. Enable Automatic Startup

Ubuntu may not launch xbindkeys on boot by default. To make it persistent across reboots:

  1. Open the Startup Applications utility from the application menu.
  2. Click Add.
  3. Set the name to xbindkeys.
  4. Set the command to /usr/bin/xbindkeys.
  5. Click Save.
