Monitor Pipe Data Progress Using PV in Ubuntu

The pv (Pipe Viewer) command-line utility allows users to monitor the progress of data passing through a pipe on Ubuntu Linux. It provides a visual display showing elapsed time, percentage completed, current throughput rate, total data transferred, and estimated completion time (ETA). This guide covers how to install pv and use it to monitor file transfers, compression tasks, and streamed data pipelines effectively.

Installing PV on Ubuntu

Install pv using the standard apt package manager:

sudo apt update
sudo apt install pv

Basic Command Syntax

The pv tool is placed between two commands in a pipeline or wrapped around a file stream:

command1 | pv | command2

Common Usage Examples

1. Monitor File Copy Operations

To see progress while copying a file from one location to another:

pv source_file.iso > destination_file.iso

2. Monitor Data Compression

Insert pv into a compression pipeline to track progress in real time:

cat raw_data.log | pv | gzip > raw_data.log.gz

3. Specify Total File Size for Accurate ETA

When piping data where pv cannot automatically calculate the total size, use the -s option to enable accurate progress bars and ETAs:

cat large_file.txt | pv -s 2G | gzip > large_file.txt.gz

4. Monitor Directory Archiving

Track progress when creating a compressed tar archive:

tar -cf - /path/to/directory | pv | gzip > backup.tar.gz

5. Limit Data Transfer Speed

Use the -L flag to throttle the data throughput rate (e.g., limit rate to 2 megabytes per second):

pv -L 2M source_file.zip > destination_file.zip

Useful PV Options

  • -p (--progress): Enables the progress bar.
  • -t (--timer): Shows the total elapsed time.
  • -e (--eta): Shows the estimated time remaining.
  • -r (--rate): Displays the current transfer rate.
  • -b (--bytes): Displays the total bytes transferred.
  • -s (--size): Sets expected size (accepts K, M, G, T suffixes).
  • -L (--rate-limit): Limits throughput rate in bytes per second.
