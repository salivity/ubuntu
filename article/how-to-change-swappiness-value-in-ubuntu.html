How to Change Swappiness Value in Ubuntu

Swappiness is an Ubuntu kernel parameter that determines how frequently your system moves data from physical memory (RAM) to the swap space on your hard drive or SSD. By default, Ubuntu sets this value to 60, which often results in premature swapping on modern hardware with ample RAM. This guide provides a direct, step-by-step walkthrough on how to check your current swappiness setting, test lower values temporarily, and permanently apply new settings to boost system responsiveness and optimize memory usage.

What is Swappiness?

Swappiness is defined on a scale from 0 to 100:

  • A low value (e.g., 10 or 20): Tells the kernel to avoid swapping process data out of RAM for as long as possible, keeping active applications in fast physical memory.
  • A high value (e.g., 60 or higher): Instructs the kernel to aggressively swap inactive memory pages out to the disk, freeing up RAM for disk caching.

For desktop systems with 8 GB of RAM or more, reducing swappiness typically results in a faster, more responsive user experience.

Check Your Current Swappiness Value

Open a terminal (Ctrl+Alt+T) and run one of the following commands to display the active swappiness setting:

cat /proc/sys/vm/swappiness

Alternatively, you can use sysctl:

sysctl vm.swappiness

The output will likely display 60, which is the standard default for Ubuntu installations.

Change Swappiness Value Temporarily

Before making permanent modifications, test a new value to see how your system performs. To set the swappiness value to 10 temporarily, enter:

sudo sysctl vm.swappiness=10

This change takes effect immediately, but it will revert back to the default value of 60 after you restart your system.

Change Swappiness Value Permanently

To ensure your preferred swappiness setting persists after a system reboot, edit the system configuration file /etc/sysctl.conf.

  1. Open /etc/sysctl.conf in a text editor with root privileges:
sudo nano /etc/sysctl.conf
  1. Scroll to the bottom of the file and add the following line:
vm.swappiness=10

(If vm.swappiness already exists in the file, simply update its numerical value.)

  1. Save the file and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

  2. Load the new settings immediately without rebooting by running:

sudo sysctl -p

Optimal Swappiness Guidelines

  • Desktops with 8 GB+ RAM: Set swappiness to 10 or 20. This keeps user applications loaded in fast RAM.
  • Database Servers: Set swappiness to 1 or 10 to prevent latency caused by disk swapping.
  • Systems with Low RAM (2 GB or less): Keep the default value at 60 or slightly lower to ensure system stability under heavy loads.
