How to List Active Network Interfaces in Ubuntu

Finding active network interfaces in Ubuntu is a fundamental task for system administration, network configuration, and troubleshooting. This guide provides the most effective terminal commands to quickly display all currently active network interfaces on an Ubuntu system, covering the modern ip tool, the legacy ifconfig command, and nmcli for NetworkManager users.

1. The ip Command (Recommended)

The ip tool is the default and standard utility for network configuration in modern Ubuntu versions.

To list all active (UP) network interfaces in a detailed format, run:

ip link show up

To view active interfaces along with their associated IP addresses:

ip -br addr show state UP

The -br flag formats the output into a clean, easy-to-read, one-line summary per interface.

2. The ifconfig Command

By default, running ifconfig without any arguments only displays active network interfaces.

ifconfig

Note: In newer Ubuntu releases, ifconfig may not be pre-installed. You can install it via sudo apt install net-tools if needed.

3. The nmcli Command

If your Ubuntu system uses NetworkManager, you can use the nmcli command-line tool to check active interface states.

To list the status of all network devices:

nmcli device status

To list only the active network connections:

nmcli connection show --active
