How to Install Elixir and Phoenix on Ubuntu

This guide covers the complete installation of the Elixir programming language and the Phoenix web framework on an Ubuntu operating system. You will learn how to update your system, install the Erlang runtime and Elixir compiler, configure the PostgreSQL database, and install the Hex package manager along with the Phoenix project generators.

Prerequisites and System Update

Begin by updating your package lists and installing core build dependencies.

sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential curl git unzip libssl-dev

Install Erlang and Elixir

Elixir runs on the Erlang Virtual Machine (BEAM), requiring Erlang to be installed. Ubuntu includes Erlang and Elixir in its official package repositories.

Run the following command to install both packages:

sudo apt install -y erlang elixir

After installation completes, verify the installation and version numbers:

elixir --version

Install PostgreSQL

Phoenix defaults to using PostgreSQL for database storage. Install the PostgreSQL server and its client tools:

sudo apt install -y postgresql postgresql-contrib

Start the service and enable it to run on boot:

sudo systemctl enable postgresql
sudo systemctl start postgresql

Set a password for the default postgres user to allow Phoenix to connect:

sudo -u postgres psql -c "ALTER USER postgres WITH PASSWORD 'postgres';"

Install Hex and Rebar

Hex is the package manager for the Elixir ecosystem, and Rebar is used to build Erlang packages. Install both via the Mix build tool:

mix local.hex --force
mix local.rebar --force

Install the Phoenix Project Generator

Install the phx_new archive from Hex, which provides the command-line tool needed to generate new Phoenix applications:

mix archive.install hex phx_new --force

Verify that the Phoenix installer is ready for use:

mix phx.new -v

Create and Verify a Phoenix Application

To ensure everything is functioning correctly, create a new sample application:

mix phx.new hello_world

When prompted to fetch and install dependencies, type Y and press Enter.

Navigate to the project folder, set up the database, and launch the development server:

cd hello_world
mix ecto.create
mix phx.server

Open a web browser and navigate to http://localhost:4000 to view the running Phoenix welcome page.
