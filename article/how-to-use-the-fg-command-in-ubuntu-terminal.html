How to Use the fg Command in Ubuntu Terminal

Managing multitasking directly from the command line is an essential skill for Linux users. This guide explains how to use the fg (foreground) command in the Ubuntu terminal to resume and bring background or suspended tasks back into your active workspace. You will learn how to identify active jobs, select specific tasks, and seamlessly switch between background and foreground processes.

Managing Processes: Background to Foreground

When you run a command in Ubuntu, it occupies the terminal in the foreground by default. If a command runs for a long time or if you need to use the terminal prompt immediately, you can send the process to the background or pause it. The fg command is the standard built-in shell utility used to return these tasks to the active screen.

Step 1: Pausing or Backgrounding a Task

To move a running task out of the foreground:

  • Suspend a running task: Press Ctrl + Z. This pauses the process and assigns it a job number.
  • Start a process in the background: Append an ampersand (&) to the end of the command (e.g., sleep 100 &).

Step 2: Listing Current Background Jobs

Before bringing a process back to the foreground, identify its job ID using the jobs command:

jobs

The output will display the status of your tasks:

[1]-  Stopped                 nano document.txt
[2]+  Stopped                 ping google.com
  • The number inside the brackets ([1], [2]) is the Job ID.
  • The plus sign (+) indicates the default job that fg will target if run without arguments.
  • The minus sign (-) indicates the job that would become the default if the current default job finishes.

Step 3: Bringing the Job to the Foreground

To restore a job to active control, use fg:

  • Bring the most recent job back:

    fg

    Running fg without flags automatically restores the job marked with the + symbol.

  • Bring a specific job back by Job ID:

    fg %1

    Replace 1 with the specific Job ID shown in your jobs output. You can also omit the percent sign in most standard Ubuntu bash shells:

    fg 1

  • Bring a job back by command name: If you know the name of the command, you can use the command prefix:

    fg %nano

Practical Walkthrough

  1. Open a text file in nano: 
    nano notes.txt
  2. Suspend the editor to return to the shell prompt by pressing Ctrl + Z.
  3. Check the job list: 
    jobs -l
  4. Return to your editing session: 
    fg %1

Once executed, nano reopens in the terminal exactly where you left off, giving you full interactive control again.
