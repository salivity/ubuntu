How to Set Up JupyterHub for Multiple Users on Ubuntu

Setting up JupyterHub on an Ubuntu machine provides a centralized, multi-user environment where individuals can access independent Jupyter notebook workspaces via a web browser. This guide walks through the complete setup process, including installing required system dependencies, setting up Python and Node.js, configuring the proxy, generating the JupyterHub configuration, and managing system user accounts.

Prerequisites

  • A server running Ubuntu 20.04 LTS or 22.04 LTS.
  • A user account with sudo administrative privileges.
  • A static IP address or domain pointing to the server.

Step 1: Update the System and Install Dependencies

Begin by updating the local package index and installing Python, pip, Node.js, and npm.

sudo apt update && sudo apt upgrade -y
sudo apt install -y python3-pip python3-dev nodejs npm

Ensure nodejs and npm are properly installed:

node -v
npm -v

Step 2: Install Configurable HTTP Proxy

JupyterHub relies on configurable-http-proxy to direct incoming network traffic to specific user notebook servers. Install it globally using npm:

sudo npm install -g configurable-http-proxy

Step 3: Install JupyterHub and JupyterLab

Install JupyterHub along with JupyterLab or the traditional Jupyter notebook package. Using a global installation ensures all system users can execute the core software.

sudo python3 -m pip install --upgrade pip
sudo python3 -m pip install jupyterhub jupyterlab notebook

Step 4: Generate Configuration Files

Create a dedicated directory to store the JupyterHub configuration and runtime data:

sudo mkdir -p /etc/jupyterhub
cd /etc/jupyterhub
sudo jupyterhub --generate-config

This creates the default configuration file at /etc/jupyterhub/jupyterhub_config.py.

Step 5: Configure the Server

Open the configuration file to define system behavior:

sudo nano /etc/jupyterhub/jupyterhub_config.py

Set JupyterLab as the default interface by adding or uncommenting this line:

c.Spawner.default_url = '/lab'

By default, JupyterHub uses PAM (Pluggable Authentication Modules), meaning any standard Linux user with an account on the Ubuntu system can log in. To specify an administrator user, append:

c.Authenticator.admin_users = {'admin_username'}
c.JupyterHub.admin_access = True

Save and exit the file (Ctrl+O, Enter, Ctrl+X).

Step 6: Create System Users

Because JupyterHub uses PAM authentication by default, create local Linux accounts for every user who needs access:

sudo adduser user1
sudo adduser user2

Follow the prompts to set passwords for each account. These credentials will be used to log in through the web browser.

Step 7: Configure JupyterHub as a Systemd Service

To ensure JupyterHub starts on boot and runs continuously in the background, create a systemd service unit:

sudo nano /etc/systemd/system/jupyterhub.service

Paste the following configuration:

[Unit]
Description=JupyterHub
After=network.target

[Service]
User=root
Environment="PATH=/bin:/usr/local/bin:/usr/bin"
WorkingDirectory=/etc/jupyterhub
ExecStart=/usr/local/bin/jupyterhub -f /etc/jupyterhub/jupyterhub_config.py
Restart=always

[Install]
WantedBy=multi-user.target

Reload systemd to register the new service, then start and enable it:

sudo systemctl daemon-reload
sudo systemctl start jupyterhub
sudo systemctl enable jupyterhub

Check the status to ensure the service is running:

sudo systemctl status jupyterhub

Step 8: Access the Server

Open a web browser and navigate to:

http://<server-ip-or-domain>:8000

Users can now log in using their Ubuntu username and password. JupyterHub automatically creates isolated user home directories and notebook environments.
