How to Edit GRUB Boot Parameters in Ubuntu

This guide explains how to pass custom boot parameters to the Linux kernel in Ubuntu by modifying the Grand Unified Bootloader (GRUB) configuration. You will learn how to make permanent modifications by editing the system's primary GRUB configuration file, regenerate the bootloader files, and test parameters temporarily during the boot process for troubleshooting.

Method 1: Applying Permanent Kernel Boot Parameters

To ensure kernel parameters persist across system updates and reboots, you must edit the /etc/default/grub configuration file.

Step 1: Open the Terminal and Back Up the Configuration

Before making any modifications, create a backup copy of the current GRUB configuration:

sudo cp /etc/default/grub /etc/default/grub.bak

Step 2: Edit the GRUB Configuration File

Open the file using a terminal text editor such as nano:

sudo nano /etc/default/grub

Step 3: Modify the Kernel Parameter Line

Locate the line beginning with GRUB_CMDLINE_LINUX_DEFAULT. By default, it usually looks like this:

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"

Add your custom parameters inside the quotation marks, separated by spaces. For example, to add nomodeset and set the log level:

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nomodeset loglevel=3"

Note: If you want parameters to apply to both normal and recovery mode boots, add them to GRUB_CMDLINE_LINUX instead.

Step 4: Save and Exit

In nano, save the file by pressing Ctrl + O, confirm with Enter, and exit using Ctrl + X.

Step 5: Update GRUB

Ubuntu will not apply these changes until the main /boot/grub/grub.cfg file is regenerated. Run:

sudo update-grub

Step 6: Reboot and Verify

Restart your system:

sudo reboot

Once the system boots, verify that the custom parameters were applied by checking the kernel command line:

cat /proc/cmdline

Method 2: Applying Temporary Boot Parameters

If you need to test a parameter or cannot boot due to a driver issue, apply parameters temporarily at the GRUB boot menu without modifying configuration files.

  1. Reboot the system.
  2. Access the GRUB menu:
    • On BIOS systems: Hold down the Shift key immediately after the machine powers on.
    • On UEFI systems: Tap the Esc key repeatedly after power-on.
  3. Edit the boot entry: Use the arrow keys to highlight the default Ubuntu entry and press e.
  4. Append the parameter:
    • Scroll down to the line that begins with linux.
    • Move the cursor to the end of that line.
    • Add a space and type your custom parameter (e.g., nomodeset or single).
  5. Boot the system: Press Ctrl + X or F10 to boot immediately with the modified parameters.

Parameters passed via this method are active only for the current session and will revert upon the next reboot.
