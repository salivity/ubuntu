Bash For Loop to Rename Files Sequentially in Ubuntu

This article explains how to use a standard Bash for loop to rename multiple files sequentially within an Ubuntu directory. Automating file renaming natively in the terminal allows you to standardize messy file names into an organized, numbered sequence quickly without installing extra tools.

Basic Sequential Renaming Loop

To rename files in a sequence, initialize a counter variable before the loop, iterate through your target files, rename each file with the mv command, and increment the counter with each iteration.

Navigate to the directory containing your files and run:

i=1
for file in *.jpg; do
    mv "$file" "photo_$i.jpg"
    ((i++))
done

In this example:

  • i=1 sets the starting number for the sequence.
  • for file in *.jpg targets all .jpg files in the current folder.
  • mv "$file" "photo_$i.jpg" renames the file to photo_1.jpg, photo_2.jpg, etc.
  • ((i++)) increments the counter by 1 on every pass.

Sequential Renaming with Zero-Padding

When dealing with more than nine files, using zero-padded numbers (such as 01, 02... or 001, 002...) ensures files sort chronologically and alphabetically across file managers and terminal listings. Use printf inside the loop to format the index number.

i=1
for file in *.png; do
    new_name=$(printf "image_%03d.png" "$i")
    mv "$file" "$new_name"
    ((i++))
done

In this script, %03d formats the number to be three digits wide with leading zeros (e.g., image_001.png, image_002.png). For two digits, use %02d.

Maintaining Original File Extensions Automatically

If the target directory contains files with various extensions, extract the extension dynamically to prevent overwriting it:

i=1
for file in *; do
    if [ -f "$file" ]; then
        extension="${file##*.}"
        new_name=$(printf "file_%02d.%s" "$i" "$extension")
        mv "$file" "$new_name"
        ((i++))
    fi
done
  • if [ -f "$file" ] ensures directories are ignored.
  • ${file##*.} extracts only the extension from the file name.

Running a Dry Run Before Renaming

To avoid accidental file overwrites, always perform a dry run by inserting echo in front of mv. This prints the proposed changes to the terminal without modifying your files:

i=1
for file in *.txt; do
    new_name=$(printf "document_%02d.txt" "$i")
    echo mv "$file" "$new_name"
    ((i++))
done

Once the terminal output reflects your desired naming convention, remove echo to apply the changes permanently.
