Install Vulkan Drivers on Ubuntu for Gaming

Vulkan is a low-overhead, cross-platform graphics API that maximizes hardware performance for modern Linux gaming. This guide covers how to install and configure the necessary Vulkan packages and proprietary or open-source drivers on Ubuntu for AMD, Intel, and NVIDIA graphics hardware. Following these steps will prepare your system to run modern native Linux games, Steam Proton, and Wine with optimal graphical performance.

1. Update Your System

Before installing new graphics packages, ensure your system packages are up to date:

sudo apt update && sudo apt upgrade -y

Enable 32-bit architecture support, which is essential for many Steam and Wine/Proton games:

sudo dpkg --add-architecture i386
sudo apt update

2. Install Drivers Based on Your GPU

For AMD and Intel GPUs (Mesa Drivers)

Both AMD and modern Intel integrated or discrete GPUs use the open-source Mesa drivers, which provide fully conformant Vulkan implementations (RADV for AMD, ANV for Intel).

Install the 64-bit and 32-bit Vulkan packages:

sudo apt install libvulkan1 libvulkan1:i386 mesa-vulkan-drivers mesa-vulkan-drivers:i386 -y

For NVIDIA GPUs (Proprietary Drivers)

NVIDIA handles Vulkan support directly through its proprietary driver stack.

  1. Identify the recommended driver for your card: 
    ubuntu-drivers devices
  2. Install the recommended proprietary driver (replace XXX with the recommended version number, such as 535 or 550): 
    sudo apt install nvidia-driver-XXX -y
  3. Install the 32-bit driver libraries and Vulkan support packages: 
    sudo apt install libvulkan1 libvulkan1:i386 -y
  4. Reboot your system to apply the driver changes: 
    sudo reboot

3. Install Vulkan Verification Utilities

Install vulkan-tools to test and inspect your Vulkan setup:

sudo apt install vulkan-tools -y

4. Verify the Installation

Run vkcube to ensure hardware acceleration is active:

vkcube

A window rendering a rotating 3D cube should appear. If it runs smoothly without errors, your Vulkan installation is working properly.

To inspect detailed device specifications and supported API extensions, run:

vulkaninfo --summary

Check the output to confirm that your primary GPU name and correct driver versions are displayed under the device section.

5. Configure for Gaming

Most modern gaming environments on Ubuntu, such as Steam, utilize translation layers like DXVK (DirectX 9/10/11 to Vulkan) and VKD3D (DirectX 12 to Vulkan).

  • Steam Proton: Open Steam, go to Settings > Compatibility, and check Enable Steam Play for supported titles and Enable Steam Play for all other titles. Proton automatically targets your installed Vulkan runtime.
  • Lutris / Heroic Games Launcher: Ensure that the Vulkan ICD loader detects your specific driver. In system preferences within these launchers, confirm your discrete GPU is selected under Vulkan ICD options.
