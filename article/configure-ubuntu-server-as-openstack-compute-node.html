Configure Ubuntu Server as OpenStack Compute Node

This guide provides a step-by-step walkthrough for configuring an Ubuntu server to function as an OpenStack compute node using Nova and Neutron services. You will learn how to prepare the operating system, install the necessary OpenStack packages, configure hardware virtualization, set up tenant networking, and register the node with your OpenStack controller.

Step 1: System Preparation and Prerequisites

Before installing OpenStack components, ensure your Ubuntu server is updated and properly configured to communicate with the management network.

  1. Update the package repository and system packages:

    sudo apt update && sudo apt dist-upgrade -y

  2. Install and configure Chrony for Network Time Protocol (NTP) synchronization with your controller node:

    sudo apt install chrony -y

    Edit /etc/chrony/chrony.conf to point to your controller node’s IP address as the time server, then restart Chrony:

    sudo systemctl restart chrony

  3. Ensure host resolution works by adding the controller node’s hostname and IP to /etc/hosts:

    10.0.0.11 controller
10.0.0.31 compute1

Step 2: Install OpenStack Packages

Enable the OpenStack repository corresponding to your target release (e.g., Yoga, Zed, or Antelope) and install the core compute packages.

  1. Install the OpenStack release repository enabler:

    sudo apt install software-properties-common -y
sudo add-apt-repository cloud-archive:yoga -y
sudo apt update

  2. Install the Nova compute component:

    sudo apt install nova-compute -y

Step 3: Configure Nova Compute

Edit /etc/nova/nova.conf to set up communication with the message queue, database, and authentication services running on the controller node.

  1. Open the configuration file:

    sudo nano /etc/nova/nova.conf

  2. Add or update the following sections:

    [DEFAULT]
transport_url = rabbit://openstack:RABBIT_PASS@controller
my_ip = 10.0.0.31
use_neutron = true
firewall_driver = nova.virt.firewall.NoopFirewallDriver

[api]
auth_strategy = keystone

[keystone_authtoken]
www_authenticate_uri = http://controller:5000
auth_url = http://controller:5000
memcached_servers = controller:11211
auth_type = password
project_domain_name = Default
user_domain_name = Default
project_name = service
username = nova
password = NOVA_PASS

[vnc]
enabled = true
server_listen = 0.0.0.0
server_proxyclient_address = $my_ip
novncproxy_base_url = http://controller:6080/vnc_auto.html

[glance]
api_servers = http://controller:9292

[oslo_concurrency]
lock_path = /var/lib/nova/tmp

  3. Determine hardware acceleration support:

    egrep -c '(vmx|svm)' /proc/cpuinfo

    If the output is 0, your hardware does not support hardware acceleration and you must configure QEMU instead of KVM. Edit /etc/nova/nova-compute.conf:

    [libvirt]
virt_type = qemu

    If the output is 1 or greater, leave virt_type = kvm.

  4. Restart the Nova compute service:

    sudo systemctl restart nova-compute

Step 4: Install and Configure Networking (Neutron)

Configure the compute node’s networking service to manage virtual machine networks.

  1. Install the Neutron OpenvSwitch agent:

    sudo apt install neutron-openvswitch-agent -y

  2. Edit /etc/neutron/neutron.conf:

    [DEFAULT]
transport_url = rabbit://openstack:RABBIT_PASS@controller
auth_strategy = keystone

[keystone_authtoken]
www_authenticate_uri = http://controller:5000
auth_url = http://controller:5000
memcached_servers = controller:11211
auth_type = password
project_domain_name = Default
user_domain_name = Default
project_name = service
username = neutron
password = NEUTRON_PASS

[oslo_concurrency]
lock_path = /var/lib/neutron/tmp

  3. Configure the OpenvSwitch agent in /etc/neutron/plugins/ml2/openvswitch_agent.ini:

    [ovs]
local_ip = 10.0.0.31
bridge_mappings = provider:br-ex

[agent]
tunnel_types = vxlan
l2_population = true

[securitygroup]
enable_security_group = true
firewall_driver = neutron.agent.linux.iptables_firewall.OVSIptablesFirewallDriver

  4. Restart network services:

    sudo systemctl restart openvswitch-switch
sudo systemctl restart neutron-openvswitch-agent
sudo systemctl restart nova-compute

Step 5: Discover the Compute Node on Controller

Log in to your OpenStack Controller node to discover the newly added compute node and confirm the registration.

  1. Run the cell discovery command on the controller node:

    su -s /bin/sh -c "nova-manage cell_v2 discover_hosts --verbose" nova

  2. Verify that the compute node is active:

    openstack compute service list

    The output should display nova-compute for your Ubuntu compute node with a status of enabled and state up.
