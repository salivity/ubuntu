Check AppArmor Status and Profiles in Ubuntu

This article explains how to view the current operational status of AppArmor and inspect its loaded security profiles on Ubuntu. You will learn the exact terminal command required, what permissions are needed to run it, and how to interpret the resulting output to ensure your system and applications are properly secured.

The Primary Command: aa-status

The standard command used to view the current AppArmor status and loaded profiles in Ubuntu is:

sudo aa-status

Alternatively, you can run sudo apparmor_status, which functions as an alias for the same utility. Administrative privileges (sudo) are required because standard users do not have permission to query the AppArmor security module in the Linux kernel.

Understanding the Command Output

Running sudo aa-status provides a structured summary divided into three key sections:

1. Module Status

The first section confirms whether AppArmor is active and running on your system. It displays:

  • Whether the AppArmor kernel module is loaded.
  • The total number of profiles currently loaded into memory.
  • The count of profiles running in enforce mode (actively blocking unauthorized actions).
  • The count of profiles running in complain mode (logging policy violations without blocking them).

2. Loaded Profiles

This section lists the specific names of all loaded profiles grouped by their operational mode. Profiles typically correspond to system binaries, such as /usr/bin/man or /usr/sbin/mysqld.

3. Running Processes

The final section shows active system processes that are currently constrained by AppArmor. It lists the process names alongside their Process IDs (PIDs), categorized by whether the profile is enforcing rules or merely logging complaints.

Useful Command Flags

You can append flags to aa-status to filter the output for scripts or quick checks:

  • Check if enabled:
    sudo aa-status --enabled
    Exits with a status code of 0 if AppArmor is active, making it useful in bash scripts.

  • Count loaded profiles only:
    sudo aa-status --profiled
    Prints only the number of loaded profiles.

  • View enforcing profiles only:
    sudo aa-status --enforced
    Displays the list of profiles actively enforcing security policies.

  • View complaining profiles only:
    sudo aa-status --complaining
    Displays only the profiles running in test/complain mode.
