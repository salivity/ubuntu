How to Change Hostname Resolution Order in Ubuntu

Changing the hostname resolution order in Ubuntu allows you to control how your system looks up IP addresses, determining whether it checks local files, DNS servers, or Multicast DNS first. This guide provides a straightforward process for modifying the /etc/nsswitch.conf file to prioritize your preferred name resolution services on Ubuntu.

Understanding nsswitch.conf

The Name Service Switch configuration file, located at /etc/nsswitch.conf, controls how Linux databases—including hostnames—are queried. The hosts: line in this file dictates the order of service modules used to convert domain names into IP addresses.

Step 1: Open the Configuration File

Open your terminal and edit /etc/nsswitch.conf using a text editor with superuser privileges:

sudo nano /etc/nsswitch.conf

Step 2: Locate the “hosts” Line

Find the line beginning with hosts:. On a standard Ubuntu installation, it typically looks like this:

hosts:          files mdns4_minimal [NOTFOUND=return] dns

The system processes these sources from left to right:

  • files: Checks the local /etc/hosts file first.
  • mdns4_minimal: Handles local Multicast DNS lookups (e.g., .local domains).
  • [NOTFOUND=return]: Stops searching if mDNS fails to find a .local address.
  • dns: Queries configured network DNS servers.
  • myhostname: Resolves the local system name automatically.

Step 3: Rearrange the Resolution Priority

Move the keywords to match your desired resolution order.

For example, if you want your system to query standard DNS servers before checking mDNS, update the line to:

hosts:          files dns mdns4_minimal [NOTFOUND=return] myhostname

If you want to check the /etc/hosts file only after attempting a DNS lookup:

hosts:          dns files mdns4_minimal [NOTFOUND=return] myhostname

Step 4: Save and Test

  1. Save the file in nano by pressing Ctrl + O, hitting Enter, and exiting with Ctrl + X.
  2. Changes to /etc/nsswitch.conf take effect immediately without needing to restart network services.

To test the new resolution behavior, query a domain using getent:

getent hosts example.com
