Enable High Contrast and Large Text in Ubuntu

Ubuntu includes built-in accessibility features designed to assist users with visual impairments by improving interface visibility and readability. This guide explains how to quickly enable High Contrast mode and Large Text using both the system graphical settings and command-line options for a more accessible desktop experience.

Enabling High Contrast and Large Text via GUI Settings

  1. Open Settings: Click the system menu in the top-right corner of the screen (the area displaying network, sound, and battery indicators) and select Settings.
  2. Select Accessibility: In the left sidebar of the Settings window, click on the Accessibility panel.
  3. Configure High Contrast: Locate the Seeing section. Find the High Contrast toggle switch and turn it ON. This increases color contrast across system windows, buttons, and text borders.
  4. Configure Large Text: In the same Seeing section, toggle the Large Text switch to ON. This increases the default font size across all desktop elements and supported applications.

Adding the Accessibility Menu to the Top Bar

To easily toggle these visual features on and off without opening Settings each time:

  1. In the Accessibility settings panel, scroll to the bottom.
  2. Toggle the Always Show Accessibility Menu option to ON.
  3. A person-shaped icon will appear on the top panel, allowing quick toggling of High Contrast, Large Text, and other accessibility tools with a single click.

Customizing Text Scaling via Terminal

If the default "Large Text" option is either too large or not large enough, you can fine-tune text scaling using the terminal:

  1. Open the Terminal by pressing Ctrl + Alt + T.
  2. Increase text scaling to a custom factor (the default is 1.0, while Ubuntu's Large Text is 1.25): 
    gsettings set org.gnome.desktop.interface text-scaling-factor 1.5
    (Replace 1.5 with your preferred value, such as 1.3 or 1.75.)
  3. To reset the scaling factor back to default, run: 
    gsettings reset org.gnome.desktop.interface text-scaling-factor

Enabling High Contrast via Terminal

You can also toggle High Contrast mode directly from the command line:

  • Enable High Contrast: 
    gsettings set org.gnome.desktop.interface high-contrast true
  • Disable High Contrast: 
    gsettings set org.gnome.desktop.interface high-contrast false
