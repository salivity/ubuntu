Install and Configure Nagios Core on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring the Nagios Core monitoring engine on an Ubuntu system. You will learn how to install the required dependencies, compile Nagios Core and its essential plugins from source, configure the Apache web interface, create an administrative user, and verify your installation to begin monitoring network infrastructure and services.

Step 1: Install Required Dependencies

Update the local package index and install the build tools, web server, PHP, and development libraries required to compile and run Nagios Core:

sudo apt update
sudo apt install -y autoconf gcc libc6 make wget unzip apache2 apache2-utils php libgd-dev libmcrypt-dev libssl-dev bc gawk dc build-essential snmp libnet-snmp-perl gettext

Step 2: Download and Extract Nagios Core

Navigate to the /tmp directory, download the latest stable release of Nagios Core from source, and extract the archive:

cd /tmp
wget -O nagioscore.tar.gz https://github.com/NagiosEnterprises/nagioscore/archive/nagios-4.4.14.tar.gz
tar xzf nagioscore.tar.gz
cd nagioscore-nagios-4.4.14

Step 3: Compile and Install Nagios Core

Run the configuration script to prepare the source code for your system:

./configure --with-httpd-conf=/etc/apache2/sites-enabled

Compile the main program and CGIs:

make all

Create the required system user and group, and add the Apache user (www-data) to the Nagios group:

sudo make install-groups-users
sudo usermod -a -G nagios www-data

Install the binary files, service/daemon files, command mode, and sample configuration files:

sudo make install
sudo make install-daemoninit
sudo make install-commandmode
sudo make install-config

Step 4: Configure Apache Web Interface

Install the Apache configuration files provided by Nagios:

sudo make install-webconf

Enable the Apache rewrite and CGI modules required by the Nagios web console:

sudo a2enmod rewrite
sudo a2enmod cgi

Create an administrative user named nagiosadmin to log into the web interface. You will be prompted to set a password:

sudo htpasswd -c /usr/local/nagios/etc/htpasswd.users nagiosadmin

Restart Apache to apply the configuration:

sudo systemctl restart apache2

Step 5: Install Nagios Plugins

Nagios Core requires plugins to execute health and status checks against hosts and services.

Download and extract the Nagios Plugins archive:

cd /tmp
wget --no-check-certificate -O nagios-plugins.tar.gz https://github.com/nagios-plugins/nagios-plugins/archive/release-2.4.6.tar.gz
tar xzf nagios-plugins.tar.gz
cd nagios-plugins-release-2.4.6

Compile and install the plugins:

./tools/setup
./configure
make
sudo make install

Step 6: Verify Configuration and Start Nagios

Before starting the service, verify that the configuration files contain no syntax errors:

sudo /usr/local/nagios/bin/nagios -v /usr/local/nagios/etc/nagios.cfg

Ensure the output reports Total Warnings: 0 and Total Errors: 0.

Start and enable the Nagios service to run on system boot:

sudo systemctl enable --now nagios

Step 7: Access the Web Interface

Open a web browser and navigate to:

http://<your_server_ip>/nagios

Log in using the username nagiosadmin and the password created in Step 4. The Nagios Core dashboard will load, displaying the status of the local Ubuntu host and default monitored services.
