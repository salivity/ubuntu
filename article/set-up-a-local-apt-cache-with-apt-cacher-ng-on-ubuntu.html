Set Up a Local APT Cache with apt-cacher-ng on Ubuntu

Setting up a local APT cache using apt-cacher-ng on Ubuntu allows you to download software updates once on a central server and distribute them to multiple client machines across your local network. This significantly saves internet bandwidth and reduces the time required to update multiple Ubuntu instances. This guide covers the installation of apt-cacher-ng on the host server, configuring network clients to route APT traffic through the cache, and verifying that the caching service is working properly.

Step 1: Install apt-cacher-ng on the Server

Select an Ubuntu machine on your network to act as the central caching server. Update the package list and install apt-cacher-ng:

sudo apt update
sudo apt install apt-cacher-ng -y

Once installed, the apt-cacher-ng service starts automatically and listens on TCP port 3142. Verify that the service is running:

sudo systemctl status apt-cacher-ng

Step 2: Access the Web Interface

apt-cacher-ng includes a web-based dashboard for monitoring cache reports and configuration settings. Open a web browser and navigate to:

http://<server-ip-address>:3142/acng-report.html

Replace <server-ip-address> with the actual local IP address of your caching server.

Step 3: Configure Client Machines to Use the Cache

To route APT requests from client machines through the apt-cacher-ng server, you must configure the APT proxy settings on each client machine.

  1. Log in to a client Ubuntu machine.
  2. Create a new configuration file in /etc/apt/apt.conf.d/:
sudo nano /etc/apt/apt.conf.d/01proxy
  1. Add the following line to the file, replacing <server-ip-address> with your APT cache server's IP address:
Acquire::http::Proxy "http://<server-ip-address>:3142";
  1. If your clients fetch packages over HTTPS repositories, add an additional directive:
Acquire::https::Proxy "http://<server-ip-address>:3142";
  1. Save and close the file.

Step 4: Test the Configuration

To confirm that the client is using the cache, run a package update and installation command on the client machine:

sudo apt update
sudo apt install curl -y

To verify that files are cached:

  1. Refresh the report page at http://<server-ip-address>:3142/acng-report.html and check the transfer statistics.
  2. Inspect the local cache folder on the server located at /var/cache/apt-cacher-ng/.
