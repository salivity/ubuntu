How to Configure IPv6 Address with Netplan in Ubuntu

Configuring an IPv6 address in Ubuntu using Netplan involves identifying your network interface, modifying the appropriate YAML configuration file in /etc/netplan/, defining your IPv6 addresses and routing, and applying the changes. This step-by-step guide covers how to set up both static and dynamic (DHCPv6) IPv6 configurations quickly and accurately.

Step 1: Identify Your Network Interface Name

Open your terminal and list the available network interfaces to find the name of the device you want to configure:

ip link

Note down the interface name (for example, eth0 or enp3s0).

Step 2: Locate and Backup the Netplan Configuration File

Netplan configuration files reside in the /etc/netplan/ directory. List the files to find your active configuration:

ls /etc/netplan/

Common filenames include 01-netcfg.yaml, 50-cloud-init.yaml, or 00-installer-config.yaml. Before making changes, create a backup:

sudo cp /etc/netplan/01-netcfg.yaml /etc/netplan/01-netcfg.yaml.bak

Step 3: Edit the Configuration File

Open the Netplan YAML file in a text editor:

sudo nano /etc/netplan/01-netcfg.yaml

Note: YAML formatting is strictly sensitive to indentation. Use spaces, not tabs.

Option A: Configure a Static IPv6 Address

Replace the interface name (eth0), IPv6 address, default gateway, and DNS servers with your specific network details:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      addresses:
        - "2001:db8:1::100/64"
      routes:
        - to: "::/0"
          via: "2001:db8:1::1"
      nameservers:
        addresses:
          - "2606:4700:4700::1111"
          - "2001:4860:4860::8888"

If you also need an IPv4 address on the same interface, append it to the addresses list alongside the IPv6 entry.

Option B: Configure Dynamic IPv6 (DHCPv6)

If your network automatically assigns IPv6 addresses via DHCPv6, use the following configuration:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp6: true

Save and close the file (Ctrl+O, Enter, then Ctrl+X in nano).

Step 4: Test and Apply the Netplan Configuration

Test the configuration for syntax errors without applying it permanently:

sudo netplan try

If the syntax is correct and no errors are thrown, press Enter to keep the settings. To apply the settings immediately, run:

sudo netplan apply

Step 5: Verify the IPv6 Address

Check that your IPv6 address is properly assigned to the interface:

ip -6 addr show eth0

Test network connectivity over IPv6 by pinging an IPv6 address or domain:

ping -6 google.com
