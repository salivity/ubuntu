How to Generate a Makefile with CMake on Ubuntu

This article explains the exact command used to generate a standard Makefile for a C++ project using CMake on Ubuntu. It covers the necessary prerequisites, details the primary CMake command and its generator options, and demonstrates how to execute the build process to produce a compiled binary.

Prerequisites

Ensure you have CMake and the standard C++ compilation tools installed on your Ubuntu system by running:

sudo apt update
sudo apt install cmake build-essential

The Generation Command

On Ubuntu and other Linux distributions, CMake defaults to generating Unix Makefiles. The modern and recommended command to configure your project and generate the Makefile into a dedicated build directory is:

cmake -B build -S .
  • -S . specifies the source directory (where your root CMakeLists.txt is located).
  • -B build specifies the build directory where the Makefile and temporary build artifacts will be written.

Alternatively, you can explicitly define the generator using the -G flag:

cmake -G "Unix Makefiles" -B build -S .

Classic In-Directory Approach

If you prefer the traditional out-of-source build approach, you can create a build directory, navigate into it, and pass the path to the source directory:

mkdir build
cd build
cmake ..

This generates a Makefile directly inside your build directory.

Compiling the Project

Once the Makefile has been generated inside the build directory, compile the C++ project using standard make or CMake's build tool interface:

Using make:

cd build
make

Using CMake's build command:

cmake --build build

This compiles your source files according to the rules defined in CMakeLists.txt and outputs the executable binary.
