Configure ZooKeeper Ensemble for Kafka on Ubuntu

This article provides a step-by-step guide to configuring a production-ready, three-node Apache ZooKeeper ensemble (quorum) on Ubuntu to manage an Apache Kafka cluster. You will learn how to prepare the Ubuntu environment, install the required dependencies, set up the ZooKeeper configuration files across multiple nodes, initialize the cluster state, and link your Kafka brokers to the newly created ensemble for fault-tolerant metadata management.

Prerequisites

A reliable ZooKeeper ensemble requires an odd number of nodes to avoid split-brain scenarios; three nodes is the standard minimum. Ensure you have:

  • Three Ubuntu servers (e.g., Ubuntu 20.04 or 22.04 LTS).
  • Static IP addresses or resolved hostnames for all nodes.
  • A user account with sudo privileges on each node.

Assign hostnames and map them in /etc/hosts on all three servers:

192.168.1.10 zk1
192.168.1.11 zk2
192.168.1.12 zk3

Step 1: Install Java OpenJDK

ZooKeeper runs on the JVM. Install OpenJDK 11 or 17 on all three nodes:

sudo apt update
sudo apt install -y openjdk-11-jdk
java -version

Step 2: Create a Dedicated ZooKeeper User and Directories

Run these commands on all nodes to run ZooKeeper under an unprivileged system user:

sudo useradd -r -d /opt/zookeeper -s /bin/false zookeeper
sudo mkdir -p /var/lib/zookeeper /var/log/zookeeper
sudo chown -R zookeeper:zookeeper /var/lib/zookeeper /var/log/zookeeper

Step 3: Download and Extract ZooKeeper

Download the stable Apache ZooKeeper release on each node (adjust the version number as needed):

cd /tmp
wget https://archive.apache.org/dist/zookeeper/zookeeper-3.8.4/apache-zookeeper-3.8.4-bin.tar.gz
sudo tar -xzf apache-zookeeper-3.8.4-bin.tar.gz -C /opt
sudo mv /opt/apache-zookeeper-3.8.4-bin /opt/zookeeper
sudo chown -R zookeeper:zookeeper /opt/zookeeper

Step 4: Configure the Ensemble (zoo.cfg)

Create the main configuration file at /opt/zookeeper/conf/zoo.cfg on all three nodes:

sudo nano /opt/zookeeper/conf/zoo.cfg

Add the following configuration:

# Time unit in milliseconds
tickTime=2000

# Time allowed for initial synchronization
initLimit=10

# Time allowed for sync between follower and leader
syncLimit=5

# ZooKeeper data directory
dataDir=/var/lib/zookeeper

# Client port
clientPort=2181

# Limit on concurrent connections
maxClientCnxns=60

# Automatic snapshot purge settings
autopurge.snapRetainCount=3
autopurge.purgeInterval=24

# Ensemble members: server.ID=IP:leader_port:election_port
server.1=zk1:2888:3888
server.2=zk2:2888:3888
server.3=zk3:2888:3888
  • Port 2888 is used for communication between followers and the leader.
  • Port 3888 is used for leader election.

Ensure local firewalls (ufw) allow traffic on ports 2181, 2888, and 3888 between these nodes.

Step 5: Assign the myid File

Each node in the ensemble must have a unique identifier stored in a file named myid inside the dataDir.

  • On Node 1 (zk1):

    echo "1" | sudo tee /var/lib/zookeeper/myid

  • On Node 2 (zk2):

    echo "2" | sudo tee /var/lib/zookeeper/myid

  • On Node 3 (zk3):

    echo "3" | sudo tee /var/lib/zookeeper/myid

Ensure correct permissions:

sudo chown zookeeper:zookeeper /var/lib/zookeeper/myid

Step 6: Create Systemd Service and Start ZooKeeper

Create a systemd service file to manage the ZooKeeper daemon on all nodes:

sudo nano /etc/systemd/system/zookeeper.service

Insert the following content:

[Unit]
Description=Apache ZooKeeper
Documentation=https://zookeeper.apache.org
After=network.target

[Service]
Type=forking
User=zookeeper
Group=zookeeper
ExecStart=/opt/zookeeper/bin/zkServer.sh start
ExecStop=/opt/zookeeper/bin/zkServer.sh stop
ExecReload=/opt/zookeeper/bin/zkServer.sh restart
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

Reload the systemd daemon, enable, and start the service on all nodes:

sudo systemctl daemon-reload
sudo systemctl enable zookeeper
sudo systemctl start zookeeper

Step 7: Verify Ensemble Health

Check the status of each node using the zkServer.sh utility:

/opt/zookeeper/bin/zkServer.sh status

In a functioning three-node ensemble, one node will report Mode: leader and the other two will report Mode: follower.

You can also send the four-letter word command:

echo stat | nc localhost 2181

Step 8: Configure Kafka Brokers to Connect

To point an Apache Kafka broker to this ZooKeeper ensemble, edit Kafka’s configuration file (server.properties) on each Kafka broker:

# Connect string pointing to all nodes in the ensemble
zookeeper.connect=zk1:2181,zk2:2181,zk3:2181

# Optional: Dedicated chroot path for Kafka metadata isolation
# zookeeper.connect=zk1:2181,zk2:2181,zk3:2181/kafka

# Timeout for ZooKeeper connection
zookeeper.connection.timeout.ms=18000

Restart the Kafka service after updating this configuration. Kafka will automatically create its metadata structure across the ZooKeeper ensemble.
