How to Set Hardware Clock to UTC in Ubuntu

This guide explains how to configure your Ubuntu system's hardware clock (Real-Time Clock, or RTC) to use Coordinated Universal Time (UTC) rather than local time. Managing your RTC in UTC is standard practice for Linux systems to avoid time-shift errors during daylight saving transitions and to maintain accurate timekeeping, particularly when resolving conflicts in dual-boot environments.

Step 1: Check the Current Clock Configuration

Before making any changes, verify how your system currently manages the hardware clock. Open your terminal and run:

timedatectl

In the output, look for the line that reads:

RTC in local TZ: yes

If it says yes, your hardware clock is currently configured to use local time. If it says no, your system is already set to UTC.

Step 2: Set the Hardware Clock to UTC

To change the hardware clock setting to UTC, use the timedatectl command with the set-local-rtc flag set to 0:

sudo timedatectl set-local-rtc 0

This command immediately updates systemd's time management settings and configures the kernel to interpret the hardware clock as UTC.

Step 3: Verify the Changes

Confirm that the new setting has taken effect by querying the status again:

timedatectl

Review the updated output and ensure the following line appears:

RTC in local TZ: no

Additionally, check that the Universal time and RTC time fields show matching timestamps, confirming that your hardware clock is correctly synchronized to UTC.
