How to Lock a User Account in Ubuntu

Locking a user account in Ubuntu is a fundamental administrative task used to temporarily or permanently prevent a user from logging into the system. This article provides a straightforward guide on the exact commands used to lock a user account, explains how these commands alter system files, offers alternative methods for blocking access, and demonstrates how to unlock the account when necessary.

The Primary Command: passwd -l

The most common and standard command to lock a user account in Ubuntu is:

sudo passwd -l username

Replace username with the actual name of the account you want to lock.

How It Works

The -l (lock) option disables a password by changing the encrypted password entry in the /etc/shadow file. Specifically, it places an exclamation mark (!) at the beginning of the password hash. Because no valid password hash starts with !, the system refuses authentication for that password.

Alternative Command: usermod -L

You can also use the usermod utility to achieve the same result:

sudo usermod -L username

Similar to passwd -l, the -L option locks the user’s password by prepending an exclamation point to the encrypted password field in /etc/shadow.

Preventing SSH Key Access (Disabling the Shell)

While passwd -l and usermod -L prevent password-based logins, a user might still be able to log in via SSH if they have set up SSH key authentication. To completely block a user from accessing a terminal session, change their default shell to /usr/sbin/nologin or /bin/false:

sudo usermod -s /usr/sbin/nologin username

This prevents the user from acquiring an interactive shell even if they authenticate via SSH keys.

How to Unlock a User Account

If you need to restore login privileges to the account later, you can unlock it using either of the following commands:

  • Using passwd:

    sudo passwd -u username

  • Using usermod:

    sudo usermod -U username

If you also disabled their shell, restore their default shell (usually Bash):

sudo usermod -s /bin/bash username
