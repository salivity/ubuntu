Auto-Start Docker on Boot in Ubuntu using systemd

This guide explains how to configure the Docker daemon to launch automatically upon system boot in Ubuntu using systemd. You will learn the exact systemctl commands required to enable the Docker service, how to verify that the service is properly configured to start at boot time, and how to apply restart policies so your individual containers also launch automatically.

1. Enable Docker with systemd

Ubuntu uses systemd as its default init system. To configure Docker to start automatically when the operating system boots, enable both the docker and containerd services by running:

sudo systemctl enable docker.service
sudo systemctl enable containerd.service

Enabling containerd.service ensures the underlying container runtime starts alongside the core Docker daemon.

2. Start the Docker Service

If Docker is not currently active, start it immediately without needing to reboot:

sudo systemctl start docker

3. Verify the Service Status

To confirm that Docker is configured to start on boot, check its enabled state:

sudo systemctl is-enabled docker

If configured correctly, the command output will return:

enabled

To view the current operational status of the service, run:

sudo systemctl status docker

Look for Active: active (running) in the output to confirm that Docker is currently running.

4. Configure Containers to Start on Boot

Configuring the Docker daemon to start on boot does not automatically start existing containers. Containers must be configured with a restart policy.

When launching a new container, append the --restart flag:

docker run -d --restart unless-stopped <image_name>

Available restart policies include:

  • no: The default policy. Containers do not automatically restart.
  • on-failure: Restarts the container only if it exits with a non-zero exit code.
  • always: Always restarts the container regardless of exit status, including after a system reboot.
  • unless-stopped: Similar to always, but prevents the container from starting on boot if it was explicitly stopped before the system shut down.

To update the restart policy on an already existing container without recreating it, run:

docker update --restart unless-stopped <container_name_or_id>

5. Disable Docker on Boot

If you need to prevent Docker from starting automatically on boot in the future, disable the service:

sudo systemctl disable docker.service
sudo systemctl disable containerd.service
