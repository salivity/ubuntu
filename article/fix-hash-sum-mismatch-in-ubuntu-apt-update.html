Fix Hash Sum Mismatch in Ubuntu apt update

The "Hash Sum mismatch" error in Ubuntu occurs when the checksum of a downloaded repository package list does not match the expected value declared by the repository metadata. This issue is typically caused by local APT cache corruption, intermediary caching proxies (such as those run by ISPs or local networks), or desynchronized mirror servers during package updates. This guide provides a straightforward, step-by-step process to clear your system's package cache, bypass proxy issues, and resolve the error permanently.

Step 1: Clear the Local APT Cache and Lists

In the majority of cases, outdated or corrupted metadata files stored on your local drive cause the mismatch. Clearing these files forces APT to download a fresh copy of the repository lists.

  1. Open your terminal.
  2. Remove the existing package list cache: 
    sudo rm -rf /var/lib/apt/lists/*
  3. Create a clean partial directory (required by APT to store temporary files): 
    sudo mkdir -p /var/lib/apt/lists/partial
  4. Clean the downloaded package archive cache: 
    sudo apt-get clean
  5. Run the update command again: 
    sudo apt-get update

Step 2: Bypass Caching Proxies and Pipelining

If clearing the local cache does not work, an upstream proxy server or network cache might be delivering stale files. You can force APT to bypass cache headers and disable HTTP pipelining during the fetch process.

Run the update with no-cache flags:

sudo apt-get update -o Acquire::http::No-Cache=True -o Acquire::http::Pipeline-Depth=0

If this resolves the issue, you can make the settings permanent by creating a dedicated configuration file:

  1. Create a new configuration file: 
    sudo nano /etc/apt/apt.conf.d/99fix-bad-proxy
  2. Add the following lines: 
    Acquire::http::No-Cache "true";
Acquire::http::Pipeline-Depth "0";
  3. Save the file and exit the editor (Ctrl + O, Enter, then Ctrl + X).

Step 3: Switch to a Different Mirror

If a specific mirror server is actively synchronizing when you request an update, its metadata and packages may temporarily mismatch. Switching to the main archive or another geographical mirror resolves the issue.

  1. Open /etc/apt/sources.list in a text editor: 
    sudo nano /etc/apt/sources.list
  2. Locate the repository URLs generating the error (for example, country-specific mirrors like us.archive.ubuntu.com or gb.archive.ubuntu.com).
  3. Replace the regional prefix with the main server address (archive.ubuntu.com) or select a different regional mirror.
  4. Save the file and run: 
    sudo apt-get update

Step 4: Fix Potential Network and MTU Issues

A poorly configured Maximum Transmission Unit (MTU) on your network interface can cause packet fragmentation, leading to truncated or altered files that fail hash validation.

  1. Check your current MTU size: 
    ip link
  2. Temporarily lower the MTU (e.g., to 1400 or 1492) on your primary network interface (replace eth0 with your actual interface name): 
    sudo ip link set dev eth0 mtu 1400
  3. Retry running sudo apt-get update.
