Configure LACP Link Aggregation in Ubuntu Netplan

Link aggregation combines multiple physical network interfaces into a single logical channel to increase throughput and provide redundancy. Using the Link Aggregation Control Protocol (LACP), defined under IEEE 802.3ad, Ubuntu systems dynamically negotiate bonded connections with supporting switch hardware. This guide provides a straightforward process for configuring LACP bonding in Ubuntu using Netplan, from identifying interfaces and editing the YAML configuration to applying and verifying the setup.

Prerequisites

  • An Ubuntu system using Netplan (Ubuntu 18.04 LTS and newer).
  • Two or more physical network interfaces connected to a switch configured for LACP (802.3ad).
  • Root or sudo access.

Step 1: Identify Physical Network Interfaces

List all available network interfaces on your system to identify the devices you plan to bond:

ip link show

Note the interface names you intend to aggregate (for example, eth0 and eth1, or enp2s0 and enp3s0).

Step 2: Ensure the Bonding Kernel Module Is Loaded

Check if the bonding driver is active:

lsmod | grep bonding

If it is not loaded, load it manually:

sudo modprobe bonding

To ensure the module loads automatically on boot, add bonding to /etc/modules:

echo "bonding" | sudo tee -a /etc/modules

Step 3: Create or Edit the Netplan Configuration File

Netplan configuration files reside in /etc/netplan/. Locate the existing file or create a new one (e.g., /etc/netplan/01-netcfg.yaml).

Open the file in an editor:

sudo nano /etc/netplan/01-netcfg.yaml

Add the following configuration, replacing interface names, IP addresses, and gateway details with your network settings:

network:
  version: 2
  renderer: networkd
  ethernets:
    enp2s0:
      dhcp4: no
    enp3s0:
      dhcp4: no
  bonds:
    bond0:
      interfaces:
        - enp2s0
        - enp3s0
      addresses:
        - 192.168.1.50/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 1.1.1.1
          - 8.8.8.8
      parameters:
        mode: 802.3ad
        mii-monitor-interval: 100
        transmit-hash-policy: layer3+4

Key Parameters Explained:

  • mode: 802.3ad: Enables dynamic link aggregation (LACP).
  • mii-monitor-interval: 100: Sets the Media Independent Interface (MII) monitoring interval to 100 milliseconds to detect link failure.
  • transmit-hash-policy: layer3+4: Uses Layer 3 and Layer 4 protocol information (IP and Port) to distribute traffic across the bonded links efficiently.

Step 4: Validate and Apply the Configuration

Test the configuration for syntax errors without applying it permanently:

sudo netplan try

If the test succeeds and connection is maintained, press Enter to accept. Alternatively, apply the changes directly:

sudo netplan apply

Step 5: Verify the LACP Bond Status

Check the status of the newly created bond interface using ip link:

ip link show bond0

To view detailed LACP status and verify that both slave interfaces are actively communicating with the switch, inspect the kernel bonding status file:

cat /proc/net/bonding/bond0

Look for Bonding Mode: IEEE 802.3ad Dynamic link aggregation and ensure the status of each slave interface shows as MII Status: up.
