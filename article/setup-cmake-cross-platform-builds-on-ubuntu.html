Setup CMake Cross-Platform Builds on Ubuntu

Setting up CMake on Ubuntu for cross-platform development allows you to compile software for various target operating systems, such as Windows, macOS, or embedded ARM devices, directly from your Linux system. This guide covers installing CMake and necessary compilers, configuring CMake toolchain files for cross-compilation, and executing multi-platform builds efficiently from the Ubuntu command line.

Step 1: Install CMake and Core Build Tools

Open your terminal and update the package index, then install CMake along with native build utilities:

sudo apt update
sudo apt install cmake build-essential

Verify the installation by checking the installed version:

cmake --version

Step 2: Install Cross-Compilers

To build binaries for operating systems other than host Linux, you must install the appropriate target compilers.

  • For targeting 64-bit Windows: Install MinGW-w64.

    sudo apt install gcc-mingw-w64 g++-mingw-w64

  • For targeting ARM/Linux (32-bit/64-bit): Install the corresponding GNU toolchain.

    sudo apt install gcc-arm-linux-gnueabihf g++-arm-linux-gnueabihf

Step 3: Create a CMake Toolchain File

CMake uses toolchain files to override default system paths and compiler definitions for cross-compilation. Create a file named toolchain-windows.cmake in your project root:

set(CMAKE_SYSTEM_NAME Windows)
set(CMAKE_SYSTEM_PROCESSOR x86_64)

# Define target cross-compilers
set(CMAKE_C_COMPILER x86_64-w64-mingw32-gcc)
set(CMAKE_CXX_COMPILER x86_64-w64-mingw32-g++)

# Define root paths for the target environment
set(CMAKE_FIND_ROOT_PATH /usr/x86_64-w64-mingw32)

# Control search behaviors for libraries, includes, and programs
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY ONLY)
set(CMAKE_FIND_ROOT_PATH_MODE_INCLUDE ONLY)

Step 4: Configure the Build Environment

In your project directory containing the CMakeLists.txt file, generate build configurations into designated directories for each target platform.

  • Configure for Windows (Cross-Compilation):

    cmake -B build-win -S . -DCMAKE_TOOLCHAIN_FILE=toolchain-windows.cmake

  • Configure for Native Linux:

    cmake -B build-linux -S .

Step 5: Build the Targets

Compile the binaries independently using CMake’s build command:

  • Compile Windows Executables (.exe):

    cmake --build build-win

  • Compile Linux Executables:

    cmake --build build-linux

Using dedicated build directories alongside platform-specific toolchain files allows you to maintain clean, reproducible cross-platform builds directly on Ubuntu.
