Hardware Accelerated Video Encoding with FFmpeg on Ubuntu

This guide provides a straightforward walkthrough for configuring hardware-accelerated video encoding with FFmpeg on Ubuntu. By offloading video processing tasks to a dedicated GPU or integrated graphics processor—such as NVIDIA NVENC, Intel Quick Sync Video (QSV), or generic VA-API (Intel/AMD)—you can drastically reduce CPU load and achieve significantly faster encoding speeds. You will learn how to verify your hardware, install the necessary drivers and packages, and run hardware-accelerated encoding commands.

1. Identify Your Graphics Hardware

Before configuring FFmpeg, identify your graphics vendor using the following terminal command:

lspci -nn | grep -E "VGA|3D"

Depending on whether you have an NVIDIA card, an Intel processor with integrated graphics, or an AMD GPU, the driver requirements and FFmpeg parameters will differ.

2. Setting Up NVIDIA Hardware Acceleration (NVENC)

NVIDIA cards use the proprietary NVENC engine, which is supported by default in Ubuntu's standard FFmpeg packages starting with Ubuntu 20.04 and later.

Step 1: Install NVIDIA Drivers

Ensure the proprietary NVIDIA drivers are installed on your system:

sudo ubuntu-drivers autoinstall

Reboot your machine to apply the driver changes:

sudo reboot

Verify that the driver is functioning correctly:

nvidia-smi

Step 2: Install FFmpeg

Install the default FFmpeg package, which includes NVENC support:

sudo apt update
sudo apt install ffmpeg

Check if NVENC encoders are available:

ffmpeg -encoders | grep nvenc

You should see encoders such as h264_nvenc and hevc_nvenc in the output.

Step 3: Run NVENC Encoding

To encode a video to H.264 using your NVIDIA GPU, execute:

ffmpeg -i input.mp4 -c:v h264_nvenc -preset p4 -b:v 5M output.mp4

For HEVC (H.265) encoding:

ffmpeg -i input.mp4 -c:v hevc_nvenc -preset p4 -b:v 5M output.mp4

3. Setting Up Intel and AMD Acceleration (VA-API)

VA-API (Video Acceleration API) is the open-source standard for hardware acceleration across Intel and AMD hardware on Linux.

Step 1: Install Required Libraries and Drivers

Install VA-API utilities and driver libraries:

sudo apt update
sudo apt install vainfo mesa-va-drivers
  • For modern Intel integrated graphics (Broadwell and newer), install the non-free media driver: 
    sudo apt install intel-media-va-driver-non-free

Step 2: Add User to the Video Group

Grant your user permission to access the rendering hardware directly:

sudo usermod -aG video,render $USER

Note: Log out and log back in for group changes to take effect.

Step 3: Verify VA-API Capabilities

Check supported profiles and entry points with:

vainfo

Ensure your output displays VAEntrypointEncSlice alongside codecs like VAProfileH264 or VAProfileHEVC.

Step 4: Run VA-API Encoding

To encode using VA-API, initialize the hardware device, format the pixel pipeline, and upload frames to the GPU:

ffmpeg -vaapi_device /dev/dri/renderD128 -i input.mp4 -vf 'format=nv12,hwupload' -c:v h264_vaapi -b:v 5M output.mp4

For HEVC (H.265):

ffmpeg -vaapi_device /dev/dri/renderD128 -i input.mp4 -vf 'format=nv12,hwupload' -c:v hevc_vaapi -b:v 5M output.mp4

4. Verifying Hardware Utilization

To confirm that the hardware encoder is actively working rather than the CPU:

  • For NVIDIA: Open another terminal window during an encoding task and run watch -n 1 nvidia-smi. Look at the Encoder column to see active utilization.
  • For Intel: Install intel-gpu-tools (sudo apt install intel-gpu-tools) and run sudo intel_gpu_top to monitor the Video engine.
  • For AMD: Install radeontop (sudo apt install radeontop) and run sudo radeontop to monitor pipeline activity.
