How to Set Up OpenConnect VPN Client on Ubuntu

This guide provides a straightforward tutorial on how to install and configure the OpenConnect VPN client on an Ubuntu system. OpenConnect is an open-source client primarily used to connect to Cisco AnyConnect, Palo Alto GlobalProtect, and other enterprise SSL VPN servers. You will learn how to set up OpenConnect using both the command-line interface (CLI) and the NetworkManager graphical user interface (GUI) to establish a secure network connection quickly.

Step 1: Update the System Package Index

Open your terminal (Ctrl+Alt+T) and update your local package list to ensure you install the latest available versions:

sudo apt update

Step 2: Install OpenConnect

You can install OpenConnect for terminal use, GUI use, or both.

Option A: Install Terminal (CLI) Version

To use OpenConnect exclusively through the terminal, run:

sudo apt install openconnect

Option B: Install Graphical (GUI) Version

If you use Ubuntu's default GNOME desktop and prefer controlling your VPN via system settings, install the NetworkManager integration package:

sudo apt install network-manager-openconnect-gnome

After the installation completes, restart NetworkManager to register the plugin:

sudo systemctl restart NetworkManager

Step 3: Connect to the VPN

Method 1: Using the Terminal (CLI)

  1. Execute the openconnect command followed by your VPN server gateway address:

    sudo openconnect vpn.example.com

  2. If your server requires a specific protocol (such as Palo Alto or Juniper), specify it using the --protocol flag:

    sudo openconnect --protocol=gp vpn.example.com

  3. Enter your username, password, and two-factor authentication (2FA) prompt when requested.

  4. Keep the terminal window open to maintain the connection. Press Ctrl+C to terminate the VPN session.

Method 2: Using the Graphical User Interface (GUI)

  1. Open Settings on Ubuntu and navigate to the Network tab (or Wi-Fi depending on your connection).
  2. Find the VPN section and click the + (plus) icon.
  3. Select Multi-protocol VPN client (openconnect) from the list.
  4. Fill in the configuration details:
    • Name: Enter a recognizable name for your connection.
    • Gateway: Enter your VPN server URL or IP address (e.g., vpn.example.com).
  5. Click Add in the top-right corner.
  6. Toggle the switch next to the newly created VPN to turn it on. A prompt will appear asking for your authentication credentials. Enter your details to finalize the connection.
