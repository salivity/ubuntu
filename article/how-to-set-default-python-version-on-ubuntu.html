How to Set Default Python Version on Ubuntu

This article explains how to configure a specific version of Python as the default interpreter on an Ubuntu server. You will learn how to verify your installed Python versions, register them with the system's alternatives manager, and switch between versions safely. Using the built-in update-alternatives tool allows you to establish a system-wide default while preserving the flexibility to change versions whenever needed.

Step 1: Check Installed Python Versions

Open your terminal and check which Python versions are currently installed on your Ubuntu system by running:

ls /usr/bin/python*

To see the current default version for python3, execute:

python3 --version

Step 2: Install Additional Python Versions (Optional)

If the version you need is not installed, install it using the deadsnakes PPA or the default package repositories:

sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.11

(Replace python3.11 with your desired version).

Step 3: Configure update-alternatives

Ubuntu uses update-alternatives to handle multiple system commands with the same name. You must register each installed Python version as an alternative under the python3 group.

Assign a priority to each version (higher numbers indicate higher priority):

sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.10 1
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 2

In this example, /usr/bin/python3.11 has priority 2, making it the automatic default over /usr/bin/python3.10 with priority 1.

Step 4: Select the Default Python Version

To manually choose or change the active default version, run:

sudo update-alternatives --config python3

You will see an interactive menu similar to this:

  Selection    Path                 Priority   Status
------------------------------------------------------------
* 0            /usr/bin/python3.11   2         auto mode
  1            /usr/bin/python3.10   1         manual mode
  2            /usr/bin/python3.11   2         manual mode

Press <enter> to keep the current choice[*], or type selection number:

Type the number corresponding to your preferred Python version and press Enter.

Step 5: Verify the Change

Verify that the active version has been updated:

python3 --version

The output should now display the selected version as your default interpreter.

Important Note on System Stability

Crucial Ubuntu system tools (such as apt and software-properties-common) depend on the specific Python version distributed with your Ubuntu release. If system commands fail after switching defaults, use sudo update-alternatives --config python3 to revert to the original system Python version, or consider using Python virtual environments (venv) for your specific application requirements.
