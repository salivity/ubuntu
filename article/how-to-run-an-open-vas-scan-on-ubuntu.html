How to Run an OpenVAS Scan on Ubuntu

This article explains how to initiate and automate a vulnerability scan against a target using OpenVAS and the Greenbone Vulnerability Management (GVM) framework on Ubuntu. It covers the primary command-line tool, gvm-cli, which interacts with the management daemon to define targets, create scan tasks, and execute security assessments.

Understanding OpenVAS Command-Line Scanning

In modern installations of OpenVAS (now part of Greenbone Community Edition / GVM), the scanner runs as a background service managed by the Greenbone Vulnerability Manager (gvmd). Direct command-line scanning is performed using the gvm-tools suite, specifically the gvm-cli command, which communicates with gvmd via the Greenbone Management Protocol (GMP).

Prerequisites

Ensure gvm-tools is installed on your Ubuntu system:

sudo apt update
sudo apt install gvm-tools

Ensure the GVM services are running and that you have valid administrator credentials configured.

Step 1: Create a Scan Target

To scan a remote host, first define the target using GMP via gvm-cli.

Run the following command, replacing <admin_user>, <password>, and <target_ip> with your details:

gvm-cli socket --xml "<create_target><name>Target Host</name><hosts><target_ip></hosts></create_target>" --gmp-username <admin_user> --gmp-password <password>

This returns an XML response containing the newly created target's unique ID (target_id).

Step 2: Retrieve the Scan Configuration ID

A scan task requires a configuration profile (such as "Full and fast"). List the available scan configs to retrieve their IDs:

gvm-cli socket --xml "<get_configs/>" --gmp-username <admin_user> --gmp-password <password>

Identify the id attribute of the configuration you intend to use.

Step 3: Create the Scan Task

Combine the target_id and config_id to generate a new scan task:

gvm-cli socket --xml "<create_task><name>Ubuntu Audit</name><config id=\"<config_id>\"/><target id=\"<target_id>\"/></create_task>" --gmp-username <admin_user> --gmp-password <password>

The output will contain a task_id.

Step 4: Execute the Scan

To launch the vulnerability scan against the target, run:

gvm-cli socket --xml "<start_task task_id=\"<task_id>\"/>" --gmp-username <admin_user> --gmp-password <password>

Step 5: Monitor Scan Progress

To check the execution status and completion percentage of the running scan, query the task:

gvm-cli socket --xml "<get_tasks task_id=\"<task_id>\"/>" --gmp-username <admin_user> --gmp-password <password>

The response includes the task's current status (such as Requested, Running, or Done) along with the progress percentage.
