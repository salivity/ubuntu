How to Install Apache Kafka on Ubuntu

This guide provides a comprehensive, step-by-step walkthrough for installing and configuring the Apache Kafka distributed streaming platform on Ubuntu. You will learn how to prepare your system prerequisites by installing Java, download and configure the official Kafka binaries, set up systemd services for automated management, and verify the installation by creating a topic to publish and consume messages.

Step 1: Update the System and Install Java

Apache Kafka requires Java to run. Open your terminal and update the package index, then install the OpenJDK runtime environment:

sudo apt update
sudo apt install default-jdk -y

Verify the installation by checking the Java version:

java -version

Step 2: Create a Dedicated User for Kafka

Running Kafka under a non-root user enhances system security. Create a dedicated system user named kafka:

sudo adduser --system --no-create-home --group kafka

Step 3: Download and Extract Apache Kafka

Navigate to the /tmp directory and download the latest stable release of Apache Kafka using wget. Replace the version number below with the desired version if necessary:

cd /tmp
wget https://downloads.apache.org/kafka/3.7.0/kafka_2.13-3.7.0.tgz

Create a directory for the Kafka installation and extract the downloaded archive into /opt/kafka:

sudo mkdir -p /opt/kafka
sudo tar -xvzf kafka_2.13-3.7.0.tgz -C /opt/kafka --strip-components=1

Set the ownership of the Kafka directory to the kafka user:

sudo chown -R kafka:kafka /opt/kafka

Step 4: Create Systemd Unit Files

To manage Kafka and ZooKeeper using standard system service commands, configure systemd unit files for both components.

1. ZooKeeper Service

Create /etc/systemd/system/zookeeper.service:

sudo nano /etc/systemd/system/zookeeper.service

Add the following configuration:

[Unit]
Description=Apache ZooKeeper service
Documentation=http://zookeeper.apache.org
Requires=network.target remote-fs.target
After=network.target remote-fs.target

[Service]
Type=simple
User=kafka
Group=kafka
ExecStart=/opt/kafka/bin/zookeeper-server-start.sh /opt/kafka/config/zookeeper.properties
ExecStop=/opt/kafka/bin/zookeeper-server-stop.sh
Restart=on-abnormal

[Install]
WantedBy=multi-user.target

2. Kafka Service

Create /etc/systemd/system/kafka.service:

sudo nano /etc/systemd/system/kafka.service

Add the following configuration:

[Unit]
Description=Apache Kafka Server
Documentation=http://kafka.apache.org/documentation.html
Requires=zookeeper.service
After=zookeeper.service

[Service]
Type=simple
User=kafka
Group=kafka
ExecStart=/opt/kafka/bin/kafka-server-start.sh /opt/kafka/config/server.properties
ExecStop=/opt/kafka/bin/kafka-server-stop.sh
Restart=on-abnormal

[Install]
WantedBy=multi-user.target

Step 5: Start and Enable the Services

Reload the systemd daemon to recognize the new unit files:

sudo systemctl daemon-reload

Start ZooKeeper and Kafka, and enable them to automatically start upon system boot:

sudo systemctl enable --now zookeeper
sudo systemctl enable --now kafka

Check the status of both services to verify they are running:

sudo systemctl status zookeeper
sudo systemctl status kafka

Step 6: Verify the Installation

To verify that Kafka is functioning correctly, create a test topic, send a message using the producer console, and read it back with the consumer console.

  1. Create a test topic named test-topic:
/opt/kafka/bin/kafka-topics.sh --create --topic test-topic --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
  1. Start the console producer to publish messages:
/opt/kafka/bin/kafka-console-producer.sh --topic test-topic --bootstrap-server localhost:9092

Type a message (e.g., Hello, Kafka!) and press Enter. Press Ctrl+C to exit the producer.

  1. Start the console consumer to read messages from the beginning:
/opt/kafka/bin/kafka-console-consumer.sh --topic test-topic --from-beginning --bootstrap-server localhost:9092

The message sent from the producer will appear in the terminal, confirming that Apache Kafka is operational.
