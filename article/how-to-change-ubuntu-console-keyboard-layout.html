How to Change Ubuntu Console Keyboard Layout

This guide explains how to permanently change the keyboard layout mapping in the Ubuntu console (TTY) environment. While graphical desktop environments manage keyboard settings through their own control panels, the virtual console relies on core system configuration files. You will learn the standard interactive method, the systemd command-line tool approach, and how to edit the configuration files directly to ensure your layout changes persist across system reboots.

Method 1: Using the Interactive Configuration Tool

The most reliable and standard way to configure the keyboard layout for the Ubuntu console is using the dpkg-reconfigure package management tool.

  1. Open your terminal or switch to a virtual console (using Ctrl + Alt + F3).
  2. Run the keyboard configuration wizard: 
    sudo dpkg-reconfigure keyboard-configuration
  3. Follow the on-screen prompts:
    • Select your hardware keyboard model (the default Generic 105-key PC works for most systems).
    • Choose the country of origin for the layout.
    • Select the specific layout variant (e.g., standard, alternate, or international).
    • Choose a key to function as the AltGr key.
    • Choose a key to serve as the Compose key (optional).
  4. After completing the wizard, apply the changes immediately without rebooting: 
    sudo setupcon

Method 2: Using localectl

For headless servers or automated scripts, localectl is a systemd utility that manages system locale and keyboard mapping settings permanently.

  1. Check your current keyboard configuration: 
    localectl status
  2. Search for your desired console keymap code: 
    localectl list-keymaps | grep -i "us\|uk\|de\|fr"
  3. Set the new console keymap: 
    sudo localectl set-keymap <keymap_code>
    (For example: sudo localectl set-keymap de for standard German)

This command automatically updates the console configuration and persists across system restarts.

Method 3: Manually Editing the Configuration File

You can directly modify the centralized keyboard configuration file read by the console subsystem at boot.

  1. Open /etc/default/keyboard in your preferred text editor:

    sudo nano /etc/default/keyboard

  2. Modify the relevant variables to match your desired layout:

    XKBMODEL="pc105"
XKBLAYOUT="us"
XKBVARIANT=""
XKBOPTIONS=""

    To set multiple layouts or specific variants, adjust XKBLAYOUT (e.g., XKBLAYOUT="gb" for United Kingdom, XKBLAYOUT="fr" for French).

  3. Save the file and exit the editor.

  4. Reload the configuration in the current console session:

    sudo setupcon

To ensure the new settings are built into the initial RAM filesystem for early boot availability, update initramfs:

sudo update-initramfs -u
