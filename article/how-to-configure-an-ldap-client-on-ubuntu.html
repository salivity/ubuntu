How to Configure an LDAP Client on Ubuntu

Centralized authentication simplifies user management across multiple servers by allowing a single Lightweight Directory Access Protocol (LDAP) server to handle credentials. This guide provides a straightforward process for setting up an LDAP client on an Ubuntu system. You will learn how to install the necessary LDAP client packages, configure the Name Service Switch (NSS) and Pluggable Authentication Modules (PAM) for directory-based logins, and verify that user authentication functions correctly.

Step 1: Update System and Install LDAP Packages

Begin by updating your package index and installing the required LDAP authentication packages.

sudo apt update
sudo apt install libnss-ldap libpam-ldap ldap-utils

During the installation, interactive prompts will ask for your LDAP configuration details:

  • LDAP server URI: Enter the server protocol and address (e.g., ldap://192.168.1.100).
  • Distinguished name of the search base: Enter your domain base (e.g., dc=example,dc=com).
  • LDAP version: Select 3.
  • Make local root Database admin: Select Yes.
  • Does the LDAP database require login? Select No (unless mandatory for your setup).
  • LDAP administrative account: Enter the admin DN (e.g., cn=admin,dc=example,dc=com).
  • LDAP administrative password: Enter the corresponding admin password.

Step 2: Configure Name Service Switch (NSS)

The Name Service Switch controls how system databases like user accounts and passwords are retrieved.

Open /etc/nsswitch.conf in a text editor:

sudo nano /etc/nsswitch.conf

Modify the passwd, group, and shadow lines to append ldap:

passwd:         files ldap
group:          files ldap
shadow:         files ldap

Save and close the file.

Step 3: Configure PAM for Automatic Home Directory Creation

To automatically generate a home directory when an LDAP user logs in for the first time, add the pam_mkhomedir module to your PAM configuration.

Open /etc/pam.d/common-session:

sudo nano /etc/pam.d/common-session

Add the following line to the end of the file:

session required pam_mkhomedir.so skel=/etc/skel/ umask=0022

Save and close the file.

To apply and ensure LDAP authentication is active in PAM, run:

sudo pam-auth-update

Select LDAP Authentication using the spacebar if it is not already checked, then press Tab to select OK and press Enter.

Step 4: Test LDAP Authentication

Verify that the client can communicate with the server and retrieve directory user accounts.

  1. Query user details from the LDAP server:

    getent passwd <ldap_username>

    If configured properly, the command returns the specified user account information from the LDAP server.

  2. Test switching to the LDAP user account:

    su - <ldap_username>

    Enter the LDAP account password when prompted. You should successfully log in, and the system will create the user's home directory automatically.
