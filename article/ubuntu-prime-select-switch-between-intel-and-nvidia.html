Ubuntu prime-select: Switch Between Intel and NVIDIA

The prime-select command is a built-in Ubuntu utility designed for laptops with hybrid graphics configurations, allowing users to toggle between power-saving integrated Intel graphics and high-performance dedicated NVIDIA GPUs. This article explains the primary function of prime-select, outlines the operational modes it provides, and demonstrates how to use the command to optimize battery life or maximize system performance.

Understanding prime-select

Modern laptops featuring NVIDIA Optimus technology contain two graphics processors: an integrated Intel GPU built into the CPU and a discrete NVIDIA GPU. While the integrated graphics consume minimal power, the discrete card provides the processing power required for 3D rendering, gaming, and compute tasks.

The prime-select command-line tool serves as the switch mechanism for the NVIDIA Prime framework on Ubuntu. It configures the display server and driver subsystem to direct graphical workloads to the desired GPU, preventing unnecessary power drain or performance bottlenecks.

Available prime-select Profiles

The tool operates by switching the system between three distinct profiles:

  • intel: This mode forces the system to use only the integrated Intel processor for display and rendering tasks. The NVIDIA GPU is powered down, resulting in maximum battery life and reduced heat output. This setting is optimal for general office tasks, web browsing, and travel.
  • nvidia: This mode forces all rendering and display operations through the dedicated NVIDIA GPU. It delivers maximum graphics performance across the entire desktop environment and all applications, but significantly increases power consumption and reduces battery life.
  • on-demand: Introduced in modern driver versions, this hybrid profile runs the desktop environment and standard applications on the power-efficient Intel GPU by default. When a demanding application requires heavy 3D rendering, it can be dynamically offloaded to the NVIDIA GPU without switching profiles or restarting the system.

How to Use prime-select

Using prime-select requires administrative privileges via sudo.

Checking the Current Active GPU

To check which graphics configuration is currently active, run:

prime-select query

The output will return intel, nvidia, or on-demand.

Switching GPU Profiles

To change the active graphics profile, run the command with the chosen mode:

  • To switch entirely to NVIDIA: 
    sudo prime-select nvidia
  • To switch entirely to Intel: 
    sudo prime-select intel
  • To enable dynamic offloading: 
    sudo prime-select on-demand

Applying Changes

Unlike dynamic switching on some other operating systems, switching profiles completely with prime-select alters how the X display server and kernel modules initialize hardware. After executing the command to switch to intel or nvidia mode, you must reboot your computer (or completely log out and restart the display manager) for the changes to take effect.
