Purpose of /etc/X11/xorg.conf.d in Ubuntu

The /etc/X11/xorg.conf.d directory in Ubuntu serves as a modular configuration repository for the Xorg display server, allowing system administrators to customize hardware settings using isolated, topic-specific configuration snippets rather than a single monolithic configuration file. This directory enables cleaner system management, easier package updates, and targeted overrides for graphics cards, monitors, keyboards, touchpads, and other input devices.

The Shift to Modular Configuration

Traditionally, the Xorg display server relied on a single, complex file located at /etc/X11/xorg.conf. Managing all graphics, monitor, and input device settings within one file was prone to syntax errors and difficult to maintain, especially when updating software drivers.

Modern Ubuntu systems use automatic hardware detection combined with modular configuration files. The /etc/X11/xorg.conf.d directory allows users to supply small, dedicated configuration snippets that modify specific hardware behavior without needing a full /etc/X11/xorg.conf file.

Key Functions of /etc/X11/xorg.conf.d

1. Snippet-Based File Structure

Configurations inside /etc/X11/xorg.conf.d are split into individual files ending with the .conf extension.

  • Files are read and parsed in numerical and alphabetical order.
  • Prefixes such as 10-, 20-, or 90- control the order in which settings are applied.
  • Settings processed later in the sequence overwrite conflicting settings loaded earlier.

2. Custom Overrides vs. System Defaults

Ubuntu separates system-managed defaults from user-defined overrides using two distinct directory paths:

  • /usr/share/X11/xorg.conf.d/: Contains default configurations provided by Ubuntu packages, graphics drivers, and input libraries (such as libinput). Files in this directory should not be manually edited, as package updates can overwrite them.
  • /etc/X11/xorg.conf.d/: Reserved exclusively for user and administrator customizations. Any .conf file placed here overrides matching settings from /usr/share/X11/xorg.conf.d/ and persists safely across system updates.

3. Modular Troubleshooting and Maintenance

Because each configuration file targets a specific device or setting, troubleshooting display or input issues is straightforward:

  • Device Isolation: You can create dedicated files such as 20-nvidia.conf for GPU options or 40-touchpad.conf for touchpad tapping and scrolling preferences.
  • Easy Rollbacks: If a new configuration causes the Xorg server to crash or malfunction, removing or renaming that specific .conf file restores default functionality without risking other working configurations.

Common Use Cases

  • Graphics Drivers: Setting specific options for NVIDIA, AMD, or Intel GPUs (e.g., enabling TearFree rendering or composition pipelines).
  • Input Customization: Enabling natural scrolling, adjusting pointer speed, or changing touchpad tap-to-click settings via InputClass blocks.
  • Monitor Configuration: Defining custom DPI settings, screen orientation, or display layouts for legacy monitors.
