How to Install Metasploit on Ubuntu

This guide provides a straightforward walkthrough for installing and configuring the Metasploit Framework on an Ubuntu Linux system. You will learn how to prepare the operating system, run the official installer, configure the backend database for tracking assessment data, and verify that the framework operates correctly.

Prerequisites

Ensure your Ubuntu system is updated and that you have administrative (sudo) privileges before proceeding. Open a terminal and update the package index:

sudo apt update && sudo apt upgrade -y

Install necessary dependencies, including curl and PostgreSQL (used by Metasploit to store workspace data and scan results):

sudo apt install -y curl postgresql postgresql-contrib

Step 1: Download and Run the Official Installer

Rapid7 provides an automated installer script that handles package dependencies, framework binaries, and environment path configurations.

  1. Download the installer script using curl:
curl https://raw.githubusercontent.com/rapid7/metasploit-omnibus/master/config/templates/metasploit-framework-wrappers/msfupdate.erb > msfinstall
  1. Grant execute permissions to the downloaded script:
chmod +x msfinstall
  1. Execute the script with administrative privileges:
sudo ./msfinstall

The script will add the official Rapid7 repository to your system's package sources and install the Metasploit Framework package.

Step 2: Initialize the Database

Metasploit utilizes PostgreSQL to speed up module searches, store credentials, and organize scan results.

  1. Start and enable the PostgreSQL service:
sudo systemctl start postgresql
sudo systemctl enable postgresql
  1. Initialize the Metasploit database. Run this command as a standard user (do not use sudo):
msfdb init

This command automatically creates the necessary database users, tables, and connection configuration files.

Step 3: Launch and Verify the Installation

Once the database initialization completes, verify the installation by launching the Metasploit console:

msfconsole

After the console loads, check that the database connection is active by running:

msf6 > db_status

If configured correctly, the output will confirm a successful connection:

[*] Connected to msf. Connection type: postgresql.

To exit the console, type exit.

Keeping Metasploit Updated

Because vulnerabilities and framework modules change frequently, keep the installation up to date by running:

sudo apt update && sudo apt --only-upgrade install metasploit-framework

Alternatively, use the built-in update utility:

sudo msfupdate
