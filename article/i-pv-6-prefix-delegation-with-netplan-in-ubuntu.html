IPv6 Prefix Delegation with Netplan in Ubuntu

IPv6 Prefix Delegation (DHCPv6-PD) allows an upstream router or ISP to assign an entire IPv6 prefix to a downstream router, which then distributes subnets to local network segments. In Ubuntu, Netplan operates alongside systemd-networkd to request a prefix on an upstream WAN interface, assign a sliced subnet to a downstream LAN interface, and advertise that prefix to local clients using Router Advertisements (RA). This guide provides the complete configuration to achieve IPv6 prefix delegation using Netplan and systemd-networkd.

Step 1: Set the Renderer to systemd-networkd

Netplan requires the networkd backend to handle advanced IPv6 lifecycle features such as Prefix Delegation. Open your primary Netplan configuration file, typically located in /etc/netplan/:

sudo nano /etc/netplan/01-netcfg.yaml

Ensure the renderer directive is set to networkd at the top level:

network:
  version: 2
  renderer: networkd
  ethernets:
    # Interfaces will be configured below

Step 2: Configure Upstream (WAN) and Downstream (LAN) Interfaces

Define your WAN interface to request an IPv6 prefix via DHCPv6, and configure your LAN interface to wait for delegation. Replace eth0 (WAN) and eth1 (LAN) with your actual interface names.

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: true
      dhcp6: true
      ipv6-privacy: true
    eth1:
      dhcp4: false
      dhcp6: false
      link-local: [ ipv6 ]

Save and exit the file.

Step 3: Enable Downstream Prefix Delegation via systemd-networkd

Because Netplan does not yet expose every granular systemd-networkd prefix delegation directive natively in YAML, you must supply drop-in configuration files to complete the assignment and router advertisements.

Create the systemd-networkd drop-in directory for the WAN interface (eth0):

sudo mkdir -p /etc/systemd/network/10-netplan-eth0.network.d

Create /etc/systemd/network/10-netplan-eth0.network.d/pd.conf:

[DHCPv6]
PrefixDelegationHint=::/56
WithoutRA=solicit

Note: Change ::/56 to the prefix size requested by your ISP, or omit PrefixDelegationHint to accept whatever size the provider assigns.

Next, create the drop-in directory for the downstream LAN interface (eth1):

sudo mkdir -p /etc/systemd/network/10-netplan-eth1.network.d

Create /etc/systemd/network/10-netplan-eth1.network.d/pd.conf:

[Network]
IPv6SendRA=yes
DHCPPrefixDelegation=yes

[IPv6PrefixDelegation]
SubnetId=1
Announce=yes

[IPv6SendRA]
Managed=no
OtherInformation=no
  • DHCPPrefixDelegation=yes assigns a sub-prefix from the upstream delegated pool to this interface.
  • SubnetId=1 specifies which subnet index to bind to this interface.
  • IPv6SendRA=yes and Announce=yes enable Router Advertisements (SLAAC) to connected downstream hosts.

Step 4: Enable IPv6 Forwarding

Downstream routing requires kernel-level packet forwarding. Enable IPv6 forwarding by creating or editing /etc/sysctl.d/99-ipv6-forwarding.conf:

net.ipv6.conf.all.forwarding=1
net.ipv6.conf.default.forwarding=1

Apply the sysctl configuration immediately:

sudo sysctl --system

Step 5: Apply and Verify Configuration

Apply the Netplan settings and reload systemd-networkd:

sudo netplan apply
sudo systemctl restart systemd-networkd

Verify that the upstream interface obtained a prefix and that the downstream interface acquired a delegated IPv6 address:

networkctl status eth0
networkctl status eth1
ip -6 addr show dev eth1

Under eth1, you should see a global IPv6 address derived from the delegated prefix with a /64 subnet mask. Downstream clients connected to eth1 will receive SLAAC configuration and route through the Ubuntu host.
