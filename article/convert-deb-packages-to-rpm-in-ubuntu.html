Convert DEB Packages to RPM in Ubuntu

Converting a .deb package to an .rpm format on Ubuntu is simple using a command-line tool named Alien. This guide walks you through installing Alien and converting Debian packages into Red Hat-compatible packages using basic terminal commands.

Step 1: Install Alien in Ubuntu

Alien is available in the official Ubuntu universe repository. Open your terminal and run the following commands to update your package list and install Alien:

sudo apt update
sudo apt install alien

Step 2: Convert the DEB Package to RPM

Navigate to the directory containing your .deb package using the cd command:

cd /path/to/your/package

To convert the .deb package into an .rpm package, run the alien command with the --to-rpm (or -r) flag:

sudo alien --to-rpm package_name.deb

For example, if your file is named app_1.0_amd64.deb:

sudo alien -r app_1.0_amd64.deb

Step 3: Include Package Scripts (Optional)

By default, Alien converts the package contents but may omit installation scripts embedded inside the .deb file. If you want to include these scripts during conversion, add the -c (or --scripts) flag:

sudo alien -r -c package_name.deb

Step 4: Verify the Generated File

Once Alien finishes the conversion process, it will generate an .rpm file in the same directory. You can confirm the creation of the new file by listing the directory contents:

ls *.rpm
