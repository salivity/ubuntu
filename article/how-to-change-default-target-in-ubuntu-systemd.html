How to Change Default Target in Ubuntu Systemd

In modern Ubuntu systems using systemd, traditional SysVinit runlevels have been replaced by systemd targets. This guide provides a straightforward walkthrough on how to check your current default target, change the default target permanently using systemctl set-default, and switch targets temporarily for your current session using systemctl isolate.

Understanding Systemd Targets and Runlevels

Systemd uses target units instead of numerical runlevels to define the state of the system. The two most commonly used targets on Ubuntu are:

  • multi-user.target: Sets up a multi-user, non-graphical system (equivalent to traditional runlevel 3).
  • graphical.target: Sets up a full graphical interface with networking and multi-user support (equivalent to traditional runlevel 5).

Step 1: Check the Current Default Target

To determine which target your Ubuntu system is configured to load on boot, run the following command in your terminal:

systemctl get-default

The output will display the active default target, such as graphical.target or multi-user.target.

Step 2: Change the Default Target Permanently

To set a new default boot target that persists across system reboots, use the set-default sub-command with sudo.

  • To set the command line interface (CLI) as default:

    sudo systemctl set-default multi-user.target

  • To set the graphical user interface (GUI) as default:

    sudo systemctl set-default graphical.target

This command creates a symbolic link at /etc/systemd/system/default.target pointing to the selected target unit file.

Step 3: Change the Target Temporarily

If you want to switch to a different target immediately without altering the boot configuration for future restarts, use the isolate command:

  • Switch to CLI immediately:

    sudo systemctl isolate multi-user.target

  • Switch to GUI immediately:

    sudo systemctl isolate graphical.target

Isolating a target stops all services not included in the target unit and starts any missing services needed by the target.
