Configure WireGuard VPN Between Ubuntu and pfSense

This guide details how to establish a secure, high-performance site-to-site WireGuard VPN tunnel connecting an Ubuntu server network to a pfSense router network. By following these steps, you will generate the necessary cryptographic key pairs, configure the tunnel interfaces on both platforms, adjust firewall rules, and configure routing to enable transparent, bidirectional communication between both local subnets.

Network Architecture Example

To follow this setup smoothly, assume the following network layout:

  • pfSense LAN Subnet: 192.168.1.0/24
  • pfSense Tunnel IP: 10.10.0.1/24
  • pfSense WAN IP/Hostname: 203.0.113.1 (UDP Port 51820)
  • Ubuntu Server LAN Subnet: 192.168.2.0/24
  • Ubuntu Tunnel IP: 10.10.0.2/24
  • Ubuntu WAN IP: Dynamic or Static (Initiator)

Step 1: Install WireGuard and Generate Keys

On Ubuntu:

  1. Update package repositories and install WireGuard: 
    sudo apt update && sudo apt install -y wireguard
  2. Generate public and private keys: 
    cd /etc/wireguard
umask 077
wg genkey | tee ubuntu_private.key | wg pubkey > ubuntu_public.key
  3. View the keys using cat ubuntu_private.key and cat ubuntu_public.key.

On pfSense:

  1. Navigate to System > Package Manager > Available Packages.
  2. Search for WireGuard and click Install.
  3. Navigate to VPN > WireGuard > Tunnels and click Add Tunnel.
  4. Set Description to Site-to-Site Ubuntu.
  5. Set Listen Port to 51820.
  6. Click Generate Keys to create the pfSense public and private keys. Note the pfSense Public Key for the Ubuntu configuration.
  7. Click Save Tunnel.

Step 2: Configure pfSense

1. Assign the Tunnel Address

  • Edit the created tunnel.
  • Under Interface Addresses, add 10.10.0.1/24.
  • Click Save Tunnel.

2. Add the Ubuntu Peer

  1. Navigate to the Peers tab under VPN > WireGuard and click Add Peer.
  2. Select the tunnel you created (tun_wg0).
  3. Set Description to Ubuntu-Server.
  4. Enter the Ubuntu Public Key generated earlier.
  5. In Allowed IPs, add:
    • 10.10.0.2/32 (Ubuntu tunnel address)
    • 192.168.2.0/24 (Ubuntu remote LAN subnet)
  6. Check Keep Alive and set the interval to 25 seconds if Ubuntu is behind NAT.
  7. Click Save.

3. Enable the WireGuard Service

  • Go to the Settings tab in VPN > WireGuard.
  • Check Enable WireGuard and click Save.

4. Configure Firewall Rules

  1. Navigate to Firewall > Rules > WAN:
    • Add a rule: Protocol UDP, Destination WAN Address, Destination Port Range 51820 to 51820.
  2. Navigate to Firewall > Rules > WireGuard:
    • Add a rule allowing traffic from the Ubuntu subnets:
      • Protocol: Any
      • Source: Network 192.168.2.0/24 (or 10.10.0.0/24)
      • Destination: Network 192.168.1.0/24 (pfSense LAN)

Step 3: Configure the Ubuntu Server

1. Enable IP Forwarding

To allow Ubuntu to route traffic between its local subnet and the VPN:

sudo sed -i 's/#net.ipv4.ip_forward=1/net.ipv4.ip_forward=1/' /etc/sysctl.conf
sudo sysctl -p

2. Create the Configuration File

Create /etc/wireguard/wg0.conf:

[Interface]
Address = 10.10.0.2/24
PrivateKey = <PASTE_UBUNTU_PRIVATE_KEY>
ListenPort = 51820

# Optional: Set up NAT routing if Ubuntu acts as a gateway
# PostUp = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
# PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

[Peer]
PublicKey = <PASTE_PFSENSE_PUBLIC_KEY>
Endpoint = 203.0.113.1:51820
AllowedIPs = 10.10.0.0/24, 192.168.1.0/24
PersistentKeepalive = 25

3. Start WireGuard

Start and enable the interface on boot:

sudo systemctl enable --now wg-quick@wg0

Step 4: Verification and Routing

  1. Verify Handshake:

    • On Ubuntu, run: 
      sudo wg show
    • Ensure that the latest handshake displays a recent timestamp and data transfer counters are incrementing.
    • On pfSense, check Status > WireGuard to confirm the peer handshake status.

  2. Test Connectivity:

    • Ping the pfSense tunnel interface from Ubuntu: 
      ping 10.10.0.1
    • Ping a device on the remote pfSense LAN: 
      ping 192.168.1.1

  3. Ensure LAN Return Routes:

    • Devices on the pfSense LAN must send traffic destined for 192.168.2.0/24 through pfSense (default gateway).
    • Devices on the Ubuntu LAN must route traffic destined for 192.168.1.0/24 through the Ubuntu server's LAN IP address.
