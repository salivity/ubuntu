Deploy TensorFlow Serving with Docker on Ubuntu

Deploying a machine learning model using TensorFlow Serving inside a Docker container on Ubuntu provides a robust, scalable environment for serving predictions via RESTful and gRPC APIs. This guide walks you through installing Docker, organizing your TensorFlow SavedModel directory, running the official TensorFlow Serving container, and querying the active endpoint for real-time inference.

1. Install Docker on Ubuntu

Ensure your package index is updated and install Docker:

sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker

To run Docker commands without root privileges, add your user to the Docker group:

sudo usermod -aG docker $USER
newgrp docker

2. Prepare the Model Directory

TensorFlow Serving requires your model to be stored in the SavedModel format with a specific directory hierarchy that includes a numerical version folder.

Organize your files as follows:

/home/ubuntu/models/my_model/
└── 1/
    ├── saved_model.pb
    └── variables/
        ├── variables.data-00000-of-00001
        └── variables.index

Create this directory structure on your system and move your model assets into the version folder (1).

3. Pull the TensorFlow Serving Docker Image

Fetch the official TensorFlow Serving image from Docker Hub:

docker pull tensorflow/serving

For GPU-accelerated inference (requiring NVIDIA drivers and the NVIDIA Container Toolkit), pull tensorflow/serving:latest-gpu instead.

4. Run the TensorFlow Serving Container

Run the container, mounting your local model directory to the target path inside the container and binding the appropriate ports:

docker run -d --name tf_serving_model \
  -p 8501:8501 \
  -p 8500:8500 \
  -v /home/ubuntu/models/my_model:/models/my_model \
  -e MODEL_NAME=my_model \
  tensorflow/serving

Key arguments explained:

  • -p 8501:8501: Exposes the REST API port.
  • -p 8500:8500: Exposes the gRPC API port.
  • -v /home/ubuntu/models/my_model:/models/my_model: Binds your host model directory to the container path.
  • -e MODEL_NAME=my_model: Sets the model identifier used in endpoint URLs.

Verify the container is active:

docker ps

5. Verify and Test the Deployment

Check the container logs to ensure the model loaded successfully:

docker logs tf_serving_model

Look for the log entry: Exporting HTTP/REST API at:localhost:8501 ... Done.

Check model status using the REST API:

curl http://localhost:8501/v1/models/my_model

Send a sample prediction request using curl:

curl -X POST http://localhost:8501/v1/models/my_model:predict \
  -d '{"instances": [[1.0, 2.0, 3.0, 4.0]]}' \
  -H "Content-Type: application/json"

The server will return a JSON response containing the model's generated predictions.
