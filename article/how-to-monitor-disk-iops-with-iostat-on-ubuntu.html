How to Monitor Disk IOPS with iostat on Ubuntu

This guide explains how to monitor your storage drive's Input/Output Operations Per Second (IOPS) on Ubuntu using the iostat utility. You will learn how to install the required package, execute the relevant monitoring commands, interpret read and write metrics, and filter the output for continuous real-time analysis.

1. Install the sysstat Package

The iostat tool is part of the sysstat package. It is not always installed by default on Ubuntu systems. Open your terminal and run the following commands to install it:

sudo apt update
sudo apt install sysstat -y

2. Basic Command to View Disk IOPS

IOPS represents the number of read and write requests a drive handles per second. In iostat, IOPS is broken down into two primary fields:

  • r/s: Read operations per second (Read IOPS)
  • w/s: Write operations per second (Write IOPS)

To display disk statistics, use the -d (disks only) and -x (extended statistics) flags:

iostat -dx

The output will list all detected storage devices along with historical averages since the system's last boot.

3. Real-Time Continuous Monitoring

To monitor live performance rather than historical averages, provide an update interval (in seconds) and optionally a total count of reports.

Run the following command to update stats every 2 seconds indefinitely:

iostat -dx 2

To limit the output to a specific number of intervals (for example, every 2 seconds for 5 reports):

iostat -dx 2 5

Note: The first report printed will always reflect averages since system startup; subsequent reports reflect activity occurring within the specified interval.

4. Monitor a Specific Disk

If you only want to monitor a specific drive (such as sda or an NVMe drive like nvme0n1), specify the device name at the end of the command:

iostat -dx sda 2

For NVMe storage:

iostat -dx nvme0n1 2

5. Interpreting the Output

When evaluating disk performance, focus on these critical columns:

  • Device: The name of the storage drive.
  • r/s: Number of read transfers issued per second.
  • w/s: Number of write transfers issued per second.
  • Total IOPS: Sum of r/s and w/s.
  • rMB/s & wMB/s: The amount of data read and written in megabytes per second (throughput).
  • await: The average time (in milliseconds) for I/O requests to be served, including queue time and service time.
  • %util: Device saturation level. Values approaching 100% indicate that the drive is operating at maximum capacity and may become a bottleneck.
