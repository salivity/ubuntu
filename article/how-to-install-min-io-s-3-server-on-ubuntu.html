How to Install MinIO S3 Server on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring MinIO, a high-performance, S3-compatible object storage server, on an Ubuntu system. You will learn how to download the standalone binary, create a dedicated system user, configure a persistent storage volume, set up a systemd service for process management, and access the MinIO web console.

Step 1: Update the System and Download MinIO

Update your package index to ensure your system packages are up to date:

sudo apt update && sudo apt upgrade -y

Download the latest MinIO server binary using wget:

wget https://dl.min.io/server/minio/release/linux-amd64/minio

Make the downloaded binary executable and move it to your system's binary directory:

chmod +x minio
sudo mv minio /usr/local/bin/

Verify the installation by checking the MinIO version:

minio --version

Step 2: Create a Dedicated User and Data Directory

Running MinIO under a non-root system user improves security. Create a dedicated system user and group named minio-user:

sudo useradd -r minio-user -s /sbin/nologin

Next, create the directory where MinIO will store object data. In this example, /mnt/data is used:

sudo mkdir -p /mnt/data

Grant ownership of the data directory to minio-user:

sudo chown -R minio-user:minio-user /mnt/data

Step 3: Configure Environment Variables

MinIO uses an environment file to load operational parameters, including credentials and ports. Create the configuration file at /etc/default/minio:

sudo nano /etc/default/minio

Add the following configuration, replacing StrongAdminUser and StrongAdminPassword123! with your own secure credentials:

# Volume to be used for object storage
MINIO_VOLUMES="/mnt/data"

# API and Web Console ports
MINIO_OPTS="--address :9000 --console-address :9001"

# Root administrative credentials
MINIO_ROOT_USER="StrongAdminUser"
MINIO_ROOT_PASSWORD="StrongAdminPassword123!"

Save and exit the file (Ctrl+O, Enter, then Ctrl+X).

Step 4: Create a Systemd Service

To ensure MinIO starts automatically on boot and runs reliably in the background, create a systemd service file:

sudo nano /etc/systemd/system/minio.service

Insert the following service definition:

[Unit]
Description=MinIO Object Storage
Documentation=https://min.io/docs/minio/linux/index.html
Wants=network-online.target
After=network-online.target
AssertFileIsExecutable=/usr/local/bin/minio

[Service]
WorkingDirectory=/usr/local/bin

User=minio-user
Group=minio-user
ProtectProc=invisible

EnvironmentFile=-/etc/default/minio
ExecStart=/usr/local/bin/minio server $MINIO_OPTS $MINIO_VOLUMES

Restart=always
LimitNOFILE=65536
TasksMax=infinity
TimeoutStopSec=infinity
SendSIGKILL=no

[Install]
WantedBy=multi-user.target

Save and close the file.

Step 5: Start and Enable the MinIO Service

Reload the systemd daemon to register the new service:

sudo systemctl daemon-reload

Start the MinIO service and enable it to launch automatically at boot:

sudo systemctl start minio
sudo systemctl enable minio

Verify that the service is running properly:

sudo systemctl status minio

Step 6: Configure Firewall and Access the Console

If you are running the Uncomplicated Firewall (UFW), allow traffic on ports 9000 (S3 API) and 9001 (Web Console):

sudo ufw allow 9000/tcp
sudo ufw allow 9001/tcp
sudo ufw reload

Open a web browser and navigate to http://your_server_ip:9001. Log in using the MINIO_ROOT_USER and MINIO_ROOT_PASSWORD configured in /etc/default/minio. Once logged in, you can create buckets, manage access keys, and interact with the storage server via any standard AWS S3 SDK using http://your_server_ip:9000 as the endpoint URL.
