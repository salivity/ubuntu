How to Block an IP Address Using UFW in Ubuntu

Uncomplicated Firewall (UFW) is the default network security management tool in Ubuntu. This guide explains how to block a specific IP address from accessing your server, restrict traffic on specific ports, verify your active firewall rules, and delete a block rule if necessary.

Prerequisites

Ensure UFW is enabled on your Ubuntu system before applying rules. Check the status using:

sudo ufw status

If the status is inactive, enable UFW by running:

sudo ufw enable

Block a Specific IP Address

To block all incoming connections from a specific IP address, use the deny from command syntax:

sudo ufw deny from 192.168.1.100

Replace 192.168.1.100 with the actual IP address you wish to block.

Block an IP Address on a Specific Port

To block an IP address from accessing a specific port (such as SSH on port 22 or HTTP on port 80), specify the port and protocol:

sudo ufw deny from 192.168.1.100 to any port 22

Verify the Block Rule

Confirm that the rule was applied successfully by checking the active rules list:

sudo ufw status numbered

This command displays a numbered list of all active firewall rules, allowing you to easily verify that the IP is blocked.

Remove an IP Block

To unblock an IP address and remove the rule, run:

sudo ufw delete deny from 192.168.1.100

Alternatively, delete the rule using its rule number from the sudo ufw status numbered output:

sudo ufw delete 1
