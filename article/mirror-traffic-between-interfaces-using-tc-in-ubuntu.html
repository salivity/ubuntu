Mirror Traffic Between Interfaces Using tc in Ubuntu

This article provides a direct, step-by-step guide on how to mirror all incoming (ingress) and outgoing (egress) network traffic from one network interface to another on an Ubuntu system. By utilizing the Linux tc (Traffic Control) subsystem alongside the clsact queueing discipline and the mirred action, you can capture full packet streams for network monitoring, intrusion detection, or analysis without disrupting host communications.

1. Identify Network Interfaces

First, determine the names of your source interface (the interface carrying the traffic to be monitored) and your target interface (the destination interface where mirrored packets will be sent).

Run the following command:

ip link show

For the remainder of this guide:

  • Source interface: eth0
  • Destination interface: eth1

Ensure both interfaces are active and up:

sudo ip link set dev eth0 up
sudo ip link set dev eth1 up

2. Add the clsact Qdisc to the Source Interface

The clsact (classifier action) queueing discipline allows attaching filters directly to both the ingress and egress hooks of an interface simultaneously without creating classful hierarchies.

Attach clsact to the source interface:

sudo tc qdisc add dev eth0 clsact

3. Mirror Ingress (Incoming) Traffic

To mirror all incoming traffic entering eth0 to eth1, attach a filter using the matchall classifier and the mirred action:

sudo tc filter add dev eth0 ingress matchall action mirred egress mirror dev eth1
  • ingress: Targets packets entering eth0.
  • matchall: Matches all packets regardless of protocol, IP, or port.
  • action mirred egress mirror dev eth1: Copies the packet and transmits it out of eth1.

4. Mirror Egress (Outgoing) Traffic

To mirror all outgoing traffic leaving eth0 to eth1, add a matching filter to the egress hook:

sudo tc filter add dev eth0 egress matchall action mirred egress mirror dev eth1
  • egress: Targets packets leaving eth0.
  • action mirred egress mirror dev eth1: Directs a copy of each outgoing packet to eth1.

5. Verify Active Configuration

Check the configured filters on both paths to ensure the rules are applied:

sudo tc filter show dev eth0 ingress
sudo tc filter show dev eth0 egress

To verify packet replication in real time, run tcpdump on the destination interface:

sudo tcpdump -n -i eth1

You should see both incoming and outgoing packets from eth0 duplicated on eth1.

6. Remove Traffic Mirroring

To delete the mirroring configuration, remove the clsact qdisc from the source interface. This will automatically remove all attached ingress and egress filters:

sudo tc qdisc del dev eth0 clsact
