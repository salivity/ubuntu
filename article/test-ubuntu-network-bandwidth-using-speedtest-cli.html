Test Ubuntu Network Bandwidth Using speedtest-cli

Testing the network bandwidth of an Ubuntu server is essential for diagnosing connection bottlenecks, verifying internet service provider speeds, and ensuring optimal server performance. This guide covers how to install and use speedtest-cli, a lightweight command-line interface for testing internet bandwidth using Speedtest.net servers. You will learn basic test execution, how to view speeds in different units, how to target specific test servers, and how to format the output for scripting or logging.

Step 1: Update Server Packages

Update your system’s package index to ensure you retrieve the correct version from the repositories:

sudo apt update

Step 2: Install speedtest-cli

Install speedtest-cli using Ubuntu’s standard package manager:

sudo apt install speedtest-cli -y

Alternatively, you can install the tool using Python’s package manager (pip):

sudo apt install python3-pip -y
pip3 install speedtest-cli

Step 3: Run a Basic Bandwidth Test

To run a standard speed test, execute the command without any flags. The tool automatically selects the nearest server based on latency:

speedtest-cli

The terminal will output your IP address, the test server location, ping latency, download speed, and upload speed.

Step 4: Advanced Command Usage

Display Speed in Bytes

By default, results are displayed in Megabits per second (Mbit/s). To display results in Megabytes per second (MB/s), run:

speedtest-cli --bytes

Simplify the Output

To return only the ping, download speed, and upload speed without extra metadata:

speedtest-cli --simple

Generate a Results Link

To generate a URL containing a summary image of your test results:

speedtest-cli --share

Export Output as JSON

For automated scripts and data logging, output the results in JSON format:

speedtest-cli --json

Step 5: Test Against a Specific Server

  1. List nearby servers along with their distance and server ID numbers:
speedtest-cli --list
  1. Filter the server list by location (e.g., searching for servers in London):
speedtest-cli --list | grep -i "London"
  1. Run the test against a specific server by replacing SERVER_ID with the number from the list:
speedtest-cli --server SERVER_ID
