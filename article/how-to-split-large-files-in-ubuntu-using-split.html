How to Split Large Files in Ubuntu Using Split

Splitting large files into smaller parts in Ubuntu is a straightforward process using the built-in split command-line utility. This guide covers how to divide files based on file size or line count, customize the output file names, and rejoin the split pieces back into the original file using the cat command.

Basic Syntax

The general syntax for the split command is:

split [options] filename [prefix]

If no prefix is provided, Ubuntu defaults to using x followed by letters (e.g., xaa, xab, xac).

Split a File by Size

To split a file based on a specific size, use the -b option followed by the desired size and unit (such as K for kilobytes, M for megabytes, or G for gigabytes).

Example (splitting a 1GB file into 200MB chunks):

split -b 200M largefile.zip chunk_

This creates files named chunk_aa, chunk_ab, chunk_ac, and so on.

Split a File by Line Count

For text files, you can split by a specific number of lines using the -l option.

Example (splitting a text file every 1,000 lines):

split -l 1000 large_list.txt list_part_

This generates smaller text files containing 1,000 lines each.

Use Numeric Suffixes

By default, split appends alphabetical suffixes (aa, ab). To use numeric suffixes (00, 01, 02), add the -d option.

Example:

split -b 100M -d largefile.iso chunk_

This produces files named chunk_00, chunk_01, chunk_02, etc.

To specify the number of digits in the suffix, use --additional-suffix or set the length with -a:

split -b 100M -d -a 3 largefile.iso chunk_

This formats the output files as chunk_000, chunk_001, chunk_002.

Rejoining Split Files

To combine the split pieces back into the original file, use the standard cat command:

cat chunk_* > originalfile.iso

This reads all matching split files in order and merges them into originalfile.iso.
