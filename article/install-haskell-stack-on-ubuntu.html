Install Haskell Stack on Ubuntu

This guide outlines the streamlined process for installing the Haskell Stack build tool on an Ubuntu developer machine. By following these steps, you will install the necessary system dependencies, run the official Stack installation script, configure your environment path, and verify that the build tool is fully functional for Haskell development.

1. Install System Dependencies

Open your terminal and update the package index. Stack requires curl to fetch the installation script and standard C compiler libraries to build native dependencies.

sudo apt update
sudo apt install -y curl build-essential libgmp-dev libffi-dev libtinfo-dev zlib1g-dev make

2. Run the Official Stack Installer

Download and execute the official Stack installation script using curl:

curl -sSL https://get.haskellstack.org/ | sh

This script detects your operating system, downloads the appropriate binary release, and installs the stack executable directly to /usr/local/bin (or prompts for sudo access if required).

3. Verify Path Configuration

Stack installs user-level binaries to ~/.local/bin. Ensure this directory is in your shell's PATH.

Open your shell configuration file (such as ~/.bashrc or ~/.zshrc) and add the following line if it does not already exist:

export PATH="$HOME/.local/bin:$PATH"

Apply the changes to your current session:

source ~/.bashrc

4. Verify the Installation

Confirm that the installation succeeded by checking the version of Stack:

stack --version

You should see output detailing the installed version, Git revision, and architecture.

5. Initialize the Environment

To prepare Stack for building projects, run the setup command. This downloads an isolated Glasgow Haskell Compiler (GHC) environment that will not conflict with system-wide packages:

stack setup

Once complete, your Ubuntu system is ready to create, build, and run Haskell applications using Stack.
