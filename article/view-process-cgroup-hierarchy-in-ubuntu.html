View Process Cgroup Hierarchy in Ubuntu

Control groups (cgroups) regulate system resources like CPU, memory, and I/O for processes running in Linux. This guide outlines the essential commands used in Ubuntu to inspect the exact cgroup hierarchy and slice limiting a specific running process.

Method 1: Inspecting /proc/<PID>/cgroup

The most direct and standard way to check which control groups constrain a specific process is by inspecting its entry in the proc filesystem.

Run the following command, replacing <PID> with the target process ID:

cat /proc/<PID>/cgroup

Understanding the Output

  • Cgroups v2 (Modern Ubuntu releases): You will see a single line formatted as 0::<cgroup-path>, such as:

    0::/user.slice/user-1000.slice/user@1000.service/app.slice/app-gnome-terminal.scope

    This indicates the unified hierarchy path from the root slice down to the leaf node governing the process.

  • Cgroups v1 (Older releases): The output lists separate entries for individual controllers (such as memory, cpu, and pids):

    12:memory:/user.slice/user-1000.slice
11:cpu,cpuacct:/user.slice

Method 2: Using systemctl status

Because modern Ubuntu uses systemd to manage cgroup hierarchies, running systemctl status with a process ID directly displays its position within the system's service and slice hierarchy.

systemctl status <PID>

In the output, locate the CGroup field:

CGroup: /user.slice/user-1000.slice/user@1000.service/app.slice/app-firefox.scope
        ├─2540 /usr/lib/firefox/firefox
        └─2685 /usr/lib/firefox/firefox -contentproc ...

Method 3: Using systemd-cgls

To see the visual tree structure of the entire control group tree or a specific branch, use the systemd-cgls tool.

To view the hierarchy directly associated with a specific unit or path:

systemd-cgls /sys/fs/cgroup/user.slice/user-1000.slice

You can also combine systemd-cgls with grep to locate a specific PID inside the overall tree:

systemd-cgls | grep -B 2 -A 2 <PID>

Method 4: Using the ps Command

To quickly view the cgroup path of a process alongside other process information in a tabular view, use the custom formatting options of ps:

ps -o pid,cgroup,args -p <PID>
