How to Create a Network Bridge in Ubuntu

Setting up a software network bridge in Ubuntu allows you to connect multiple network interfaces together so they share a single network segment, which is essential for virtual machines, containers, and complex networking setups. This guide provides a quick, step-by-step walkthrough for configuring a bridge using both the modern iproute2 command-line utility and the traditional brctl tool.

Prerequisites

Before creating a bridge, identify the names of your network interfaces using:

ip link show

For the examples below, we will create a bridge named br0 and attach an interface named eth0.

Method 1: Using iproute2 (Recommended)

iproute2 is pre-installed on modern Ubuntu releases and is the standard tool for managing network interfaces.

Step 1: Create the Bridge Interface

Create a new bridge device named br0:

sudo ip link add name br0 type bridge

Step 2: Attach an Interface to the Bridge

Assign your physical or virtual network interface (eth0) to the bridge:

sudo ip link set dev eth0 master br0

Step 3: Bring Up the Interfaces

Activate both the physical interface and the bridge interface:

sudo ip link set dev eth0 up
sudo ip link set dev br0 up

Step 4: Verify the Configuration

Check if the bridge is active and displaying the attached interface:

ip link show type bridge

Method 2: Using brctl (bridge-utils)

The brctl command comes from the legacy bridge-utils package.

Step 1: Install bridge-utils

If brctl is not available on your system, install it via apt:

sudo apt update
sudo apt install bridge-utils

Step 2: Create the Bridge Interface

Add a new software bridge:

sudo brctl addbr br0

Step 3: Attach an Interface to the Bridge

Add your desired interface (eth0) to br0:

sudo brctl addif br0 eth0

Step 4: Bring Up the Interfaces

Turn on the bridge interface:

sudo ip link set dev eth0 up
sudo ip link set dev br0 up

Step 5: Verify the Configuration

Display the status of all existing bridges:

brctl show

Assigning an IP Address to the Bridge

Once the bridge is active, assign an IP address directly to br0 (not to the attached interfaces).

  • Static IP Address:

    sudo ip addr add 192.168.1.100/24 dev br0

  • Dynamic IP (DHCP):

    sudo dhclient br0

Making Configuration Persistent

Commands executed via iproute2 or brctl are temporary and will reset upon reboot. To make a network bridge permanent in modern Ubuntu (18.04 LTS and later), configure it using Netplan in /etc/netplan/01-netcfg.yaml:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: no
  bridges:
    br0:
      interfaces: [eth0]
      dhcp4: yes

Apply the changes with:

sudo netplan apply
