How to Set Up Wake-on-LAN on Ubuntu

Setting up Wake-on-LAN (WoL) on an Ubuntu system allows you to remotely power on your computer over a local network by sending a specialized network message called a "magic packet." This guide covers enabling Wake-on-LAN in your system's motherboard firmware, installing necessary software packages on Ubuntu, configuring your network interface to accept power-on signals, and ensuring the configuration remains active after system reboots.

Step 1: Enable Wake-on-LAN in BIOS/UEFI

Before configuring Ubuntu, Wake-on-LAN must be enabled at the hardware level.

  1. Restart your computer and press the designated key (usually F2, F10, F12, or Delete) to enter the BIOS/UEFI setup menu.
  2. Navigate to the Power Management or Advanced settings tab.
  3. Locate options named Wake-on-LAN, Power On by PCI-E, or Resume by LAN and set them to Enabled.
  4. Save your changes and exit to boot back into Ubuntu.

Step 2: Install Ethtool and Identify Your Network Interface

Ubuntu requires the ethtool utility to manage network card features.

  1. Open a terminal (Ctrl+Alt+T) and run: 
    sudo apt update
sudo apt install ethtool net-tools -y
  2. Find the name of your network interface by listing active connections: 
    ip link show
    Look for your Ethernet card name (e.g., enp3s0 or eth0). Note this name as well as your hardware MAC address listed next to link/ether.

Step 3: Check and Enable WoL Support

Verify if your network card supports Wake-on-LAN commands.

  1. Run the following command (replace enp3s0 with your interface name):

    sudo ethtool enp3s0

  2. Look for these two specific lines in the output:

    • Supports Wake-on: If this includes g, your hardware supports magic packets.
    • Wake-on: If set to d, WoL is disabled. If set to g, WoL is active.

  3. Enable Wake-on-LAN temporarily by running:

    sudo ethtool -s enp3s0 wol g

Step 4: Make the Wake-on-LAN Configuration Persistent

Changes made with ethtool reset upon reboot. Create a systemd service to automatically enable WoL every time Ubuntu boots.

  1. Create a new service file using a text editor: 
    sudo nano /etc/systemd/system/wol.service
  2. Add the following contents to the file, replacing enp3s0 with your network interface name: 
    [Unit]
Description=Enable Wake-on-LAN
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
ExecStart=/sbin/ethtool -s enp3s0 wol g

[Install]
WantedBy=multi-user.target
  3. Save and close the file (Ctrl+O, Enter, then Ctrl+X).
  4. Enable and start the newly created service: 
    sudo systemctl daemon-reload
sudo systemctl enable wol.service
sudo systemctl start wol.service

Step 5: Test the Setup

To turn on your Ubuntu system remotely, send a magic packet from another machine on the same local network using the target machine's MAC address.

  • From another Linux machine:

    sudo apt install wakeonlan
wakeonlan AA:BB:CC:DD:EE:FF

    (Replace AA:BB:CC:DD:EE:FF with the target machine's actual MAC address).

  • From a Windows machine: Download a WoL utility or use PowerShell scripts to broadcast the magic packet to the target MAC address.
