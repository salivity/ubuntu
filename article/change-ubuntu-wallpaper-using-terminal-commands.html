Change Ubuntu Wallpaper Using Terminal Commands

Changing your desktop wallpaper using the Ubuntu terminal is a fast and efficient process that utilizes the built-in gsettings tool. This article provides a straightforward guide on how to update your desktop background image directly from the command line, customize how the image displays, and apply settings across different color schemes like light and dark modes.

Step 1: Locate the Absolute Path of Your Image

Before running the command, you need the exact file path of the image you want to use.

For example, if your image is named background.jpg and sits in your Pictures folder, your file path will look like this:

/home/your_username/Pictures/background.jpg

You can verify the path by opening your terminal and running:

realpath ~/Pictures/background.jpg

Step 2: Run the Command to Change the Wallpaper

Ubuntu uses the GNOME desktop environment, which handles wallpaper settings through gsettings.

For Default / Light Mode

To set the wallpaper in standard or light mode, execute the following command (replace the path with your actual image path):

gsettings set org.gnome.desktop.background picture-uri 'file:///home/your_username/Pictures/background.jpg'

For Dark Mode (Ubuntu 22.04 and Newer)

If you are using Dark Mode, Ubuntu uses a separate key for the dark wallpaper. Run this command:

gsettings set org.gnome.desktop.background picture-uri-dark 'file:///home/your_username/Pictures/background.jpg'

Note: Ensure you keep file:// at the beginning of the path string.

Step 3: Adjust the Picture Display Options (Optional)

You can control how the image scales on your display using the picture-options setting.

Available options include: zoom, centered, scaled, stretched, spanned, and none.

To set the wallpaper to zoom and fill the screen, run:

gsettings set org.gnome.desktop.background picture-options 'zoom'

Step 4: Verify the Current Wallpaper Settings

If you want to check which image is currently set as your desktop background, run the matching get command:

gsettings get org.gnome.desktop.background picture-uri
