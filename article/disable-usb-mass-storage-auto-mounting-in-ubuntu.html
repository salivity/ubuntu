Disable USB Mass Storage Auto Mounting in Ubuntu

Disabling automatic USB mass storage mounting in Ubuntu is an essential step for improving system security, preventing unauthorized data transfers, and managing external drives efficiently. This guide provides clear, step-by-step methods to stop USB drives from auto-mounting, covering desktop-level settings via GNOME, system-wide rules using Udev, and complete driver restriction via kernel module blacklisting.

Method 1: Disable Automount via GNOME Desktop Settings

If you are using the default Ubuntu GNOME desktop environment, you can prevent plugged-in USB drives from mounting automatically while still allowing users to mount them manually when needed.

Using the Terminal

Run the following commands in your terminal to disable automounting and auto-opening of removable media:

gsettings set org.gnome.desktop.media-handling automount false
gsettings set org.gnome.desktop.media-handling automount-open false

To re-enable automounting in the future, set the values back to true:

gsettings set org.gnome.desktop.media-handling automount true
gsettings set org.gnome.desktop.media-handling automount-open true

Using Dconf Editor (GUI)

  1. Install Dconf Editor: 
    sudo apt update
sudo apt install dconf-editor -y
  2. Open dconf Editor from your applications menu.
  3. Navigate to /org/gnome/desktop/media-handling/.
  4. Turn off the switches for automount and automount-open.

Method 2: Disable Automount System-Wide Using Udev Rules

To prevent Udisks from automatically mounting USB storage devices across the entire operating system, you can create a custom udev rule.

  1. Create a new Udev rule file:

    sudo nano /etc/udev/rules.d/99-prevent-automount.rules

  2. Add the following line to the file:

    SUBSYSTEM=="block", ACTION=="add", ENV{ID_BUS}=="usb", ENV{UDISKS_AUTO}="0"

  3. Save and close the file (press Ctrl+O, Enter, then Ctrl+X).

  4. Reload the Udev rules:

    sudo udevadm control --reload-rules
sudo udevadm trigger

This configuration flags inserted USB drives so Udisks ignores them for auto-mounting, but users can still mount them manually via command line or file manager.

Method 3: Blacklist the USB Mass Storage Kernel Module

For high-security environments where USB storage devices must be completely disabled, you can blacklist the usb-storage kernel module. This prevents Ubuntu from recognizing USB mass storage devices entirely.

  1. Open the blacklist configuration file in a text editor:

    sudo nano /etc/modprobe.d/blacklist-usbstorage.conf

  2. Add the following line to the file:

    blacklist usb-storage

  3. Save and exit the file.

  4. Apply the changes by updating the initial RAM filesystem:

    sudo update-initramfs -u

  5. Reboot your computer for the changes to take full effect:

    sudo reboot

Once rebooted, inserted USB mass storage drives will not be read or mounted by the system. USB keyboards, mice, and other non-storage peripherals will continue to work normally.
