Check passwd File Integrity Using pwck in Ubuntu

Maintaining system security and account consistency in Ubuntu requires regular verification of critical authentication files. This guide details how to use the built-in pwck (password check) utility to scan the /etc/passwd and /etc/shadow files for formatting errors, duplicate entries, invalid user identifiers, and missing home directories. By following this process, administrators can identify and resolve user database corruption safely.

What is the pwck Utility?

The pwck command verifies the integrity of user authentication files. It checks each entry in /etc/passwd and /etc/shadow to ensure valid field formatting, unique user IDs (UIDs), correct group assignments, and the existence of designated home directories and login shells.

Step 1: Run pwck in Read-Only Mode

Before making any changes, run pwck in read-only mode to scan for errors without being prompted to make automatic modifications. Open your terminal and execute:

sudo pwck -r

If the files are error-free, the command exits silently and returns to the prompt. If issues exist, pwck displays specific error messages describing the misconfigurations, such as invalid shells or non-existent directories.

Step 2: Run pwck in Interactive Mode to Fix Errors

To fix detected issues interactively, execute the command with superuser privileges and without the read-only flag:

sudo pwck

When pwck encounters an invalid or duplicate entry, it prompts you with a question, such as asking whether to delete the corrupted entry:

user 'testuser': directory '/home/testuser' does not exist
delete member 'testuser'? [y/N]

Type y and press Enter to accept the proposed fix, or press n to leave the record unchanged for manual inspection later.

Step 3: Check Alternate Files

If you are staging changes or working on a backup file, you can specify custom paths for both the passwd and shadow files instead of checking the live system files:

sudo pwck /path/to/custom_passwd /path/to/custom_shadow

This prevents accidental modifications to active system accounts during testing.

Common Checks Performed by pwck

The utility flags several standard configuration errors:

  • Field Count: Verifies that every line contains exactly seven colon-separated fields.
  • Unique User Names and UIDs: Identifies duplicated usernames or duplicate numerical IDs.
  • Valid Groups: Confirms that the primary Group ID (GID) listed in /etc/passwd exists in /etc/group.
  • Home Directory Verification: Confirms that specified home directories exist on the filesystem.
  • Login Shell Validation: Ensures that the designated login shell exists and is executable.

Exit Status Codes

You can verify the result of the pwck run programmatically in shell scripts using its exit status (echo $?):

  • 0: Success; no errors were found.
  • 1: Syntax errors found in the password file.
  • 2: One or more bad password entries found.
  • 3: Unable to open the password files.
  • 4: Unable to lock the password files.
  • 5: Unable to update the password files.
