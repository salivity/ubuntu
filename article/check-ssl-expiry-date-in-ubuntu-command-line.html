Check SSL Expiry Date in Ubuntu Command Line

Monitoring your SSL/TLS certificate validity is essential for maintaining secure connections and preventing unexpected service downtime. This guide demonstrates how to quickly check the expiration date of both remote website certificates and local certificate files directly from the Ubuntu terminal using built-in utilities like OpenSSL and cURL.

Method 1: Check a Remote Website's SSL Expiry Date

To check the expiration date of an SSL certificate for a live website, use the openssl command-line tool.

Run the following command, replacing example.com with your target domain name:

echo | openssl s_client -servername example.com -connect example.com:443 2>/dev/null | openssl x509 -noout -dates

Display Only the Expiration Date

If you only want to see the end date (expiration date) without the start date, use -enddate:

echo | openssl s_client -servername example.com -connect example.com:443 2>/dev/null | openssl x509 -noout -enddate

Check Expiry in Seconds or Days

To check if a certificate will expire within a specific timeframe (for example, within 30 days / 2592000 seconds), run:

echo | openssl s_client -servername example.com -connect example.com:443 2>/dev/null | openssl x509 -noout -checkend 2592000
  • If the certificate will not expire in 30 days, the output will read: Certificate will not expire.
  • If the certificate will expire within 30 days, it will return: Certificate will expire.

Method 2: Check a Local SSL Certificate File

If you have a certificate file (.pem, .crt, or .cer) stored locally on your Ubuntu system, you can view its expiration details using OpenSSL.

Run the command below, substituting the path to your file:

openssl x509 -enddate -noout -in /path/to/certificate.crt

To view full details of the local certificate, including the issuer and validity dates, run:

openssl x509 -text -noout -in /path/to/certificate.crt

Method 3: Check SSL Expiry Date Using cURL

You can also use curl to fetch SSL information from a web server.

Execute the following command:

curl -vI https://example.com 2>&1 | grep "expire date"

This returns a single line indicating when the SSL certificate installed on the server is scheduled to expire.
