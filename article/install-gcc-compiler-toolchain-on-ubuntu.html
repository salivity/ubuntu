Install GCC Compiler Toolchain on Ubuntu

Setting up a C/C++ development environment on Ubuntu requires installing the GNU Compiler Collection (GCC) toolchain. This guide covers how to install the standard build-essential package—which includes the GCC C compiler, G++ C++ compiler, Make, and essential libraries—verify your installation, and compile a test program efficiently.

Update System Packages

Before installing new software, update your local package list to ensure you receive the latest software versions and security patches:

sudo apt update

Install the Build-Essential Package

Ubuntu provides a convenient meta-package called build-essential that contains everything required for C/C++ compiling, including gcc, g++, make, and dpkg-dev.

Run the following command to install it:

sudo apt install build-essential

Type Y and press Enter when prompted to confirm the installation.

Verify the Installation

Check the installed versions of the GCC and G++ compilers to confirm successful installation:

Check the C compiler:

gcc --version

Check the C++ compiler:

g++ --version

Test the GCC Compiler

To confirm that the environment is functioning correctly, build and execute a simple C program.

  1. Create a file named main.c:
nano main.c
  1. Add the following code:
#include <stdio.h>

int main() {
    printf("GCC compiler is working correctly.\n");
    return 0;
}

  1. Save and close the file (Ctrl+O, Enter, then Ctrl+X).

  2. Compile the source file into an executable named main:

gcc main.c -o main
  1. Run the compiled program:
./main

Configure Multiple GCC Versions (Optional)

If you require specific versions of GCC for different projects, install them alongside the default version:

sudo apt install gcc-11 g++-11 gcc-12 g++-12

Use update-alternatives to configure shortcut switches between versions:

sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-11 110 --slave /usr/bin/g++ g++ /usr/bin/g++-11
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-12 120 --slave /usr/bin/g++ g++ /usr/bin/g++-12

To switch the active default version, run:

sudo update-alternatives --config gcc

Enter the selection number corresponding to the version you wish to use.
