How to Configure Ubuntu Preseed for Automation

Preseed files provide a mechanism to automate the legacy Debian-Installer (d-i) historically used by Ubuntu, allowing administrators to perform unattended, reproducible operating system installations. This guide details how to construct a preseed.cfg file, configure essential installation directives—including network setup, disk partitioning, user creation, and package installation—and pass the configuration to the installer at boot.

Anatomy of a Preseed File

A preseed configuration file is a plain text file containing instructions that answer debconf prompts automatically. Each configuration line follows a strict format with four fields separated by whitespace:

<owner> <question-name> <type> <value>
  • Owner: Identifies the subsystem or package handling the prompt (typically d-i for standard Debian installer questions).
  • Question Name: The specific prompt being answered.
  • Type: The data type of the answer (e.g., string, boolean, select, multiselect).
  • Value: The desired configuration value.

Essential Preseed Configuration Sections

1. Localization and Time Zone

Define the language, country, keyboard keymap, and time zone to eliminate initial interactive setup prompts:

d-i debian-installer/locale string en_US.UTF-8
d-i console-setup/ask_detect boolean false
d-i keyboard-configuration/xkb-keymap select us

d-i time/zone string UTC
d-i clock-setup/utc boolean true
d-i clock-setup/ntp boolean true

2. Network Configuration

Set network interfaces to automatically acquire addresses via DHCP or configure static addressing, along with the system hostname:

d-i netcfg/choose_interface select auto
d-i netcfg/get_hostname string ubuntu-node
d-i netcfg/get_domain string local

3. Mirror Settings

Specify the archive mirrors for package retrieval during installation:

d-i mirror/country string manual
d-i mirror/http/hostname string archive.ubuntu.com
d-i mirror/http/directory string /ubuntu
d-i mirror/http/proxy string

4. Automated Disk Partitioning

Automate disk wiping and layout using partman. The following configures standard LVM partitioning across the first available disk without manual confirmation:

d-i partman-auto/method string lvm
d-i partman-auto-lvm/guided_size string max
d-i partman-lvm/device_remove_lvm boolean true
d-i partman-md/device_remove_md boolean true
d-i partman-lvm/confirm boolean true
d-i partman-lvm/confirm_nooverwrite boolean true

d-i partman-auto/choose_recipe select atomic
d-i partman-partitioning/confirm_write_new_label boolean true
d-i partman/choose_partition select finish
d-i partman/confirm boolean true
d-i partman/confirm_nooverwrite boolean true

5. User and Root Account Setup

Configure the administrative user account and set credentials:

d-i passwd/root-login boolean false
d-i passwd/make-user boolean true
d-i passwd/user-fullname string Admin User
d-i passwd/username string adminuser
d-i passwd/user-password password SecurePassword123!
d-i passwd/user-password-again password SecurePassword123!
d-i user-setup/allow-password-weak boolean false
d-i user-setup/encrypt-home boolean false

6. Package Selection and Updates

Select standard server tasks, include extra utility packages, and automate security update behavior:

tasksel tasksel/first multiselect standard, server
d-i pkgsel/include string openssh-server curl vim
d-i pkgsel/upgrade select full-upgrade
d-i pkgsel/update-policy select unattended-upgrades

7. Bootloader and Reboot

Install GRUB to the Master Boot Record (MBR) automatically and reboot upon completion:

d-i grub-installer/only_debian boolean true
d-i grub-installer/with_other_os boolean true
d-i grub-installer/bootdev string default

d-i finish-install/reboot_in_progress note

8. Custom Post-Installation Scripts

Execute arbitrary shell commands in the newly installed environment before the system reboots using preseed/late_command:

d-i preseed/late_command string \
    in-target sed -i 's/#PermitRootLogin prohibit-password/PermitRootLogin no/' /etc/ssh/sshd_config; \
    in-target systemctl enable ssh

Applying the Preseed File

Host the resulting preseed.cfg file on an accessible HTTP server (e.g., http://192.168.1.50/preseed.cfg).

To instruct the installer to fetch and execute the file, append the following kernel parameters to the bootloader (PXE, GRUB, or Syslinux):

auto=true priority=critical url=http://192.168.1.50/preseed.cfg
  • auto=true: Suppresses non-essential prompts.
  • priority=critical: Ensures only questions of critical priority pause the installer if they are missing from the preseed file.
  • url=...: Points to the network location hosting the configuration.
