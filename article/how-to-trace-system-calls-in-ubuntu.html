How to Trace System Calls in Ubuntu

In Ubuntu and other Linux distributions, the primary tool used to trace system calls made by a process is strace. System calls are the fundamental interface between a user-space application and the Linux kernel, handling low-level operations such as reading files, opening network sockets, and allocating memory. Using strace allows system administrators and developers to diagnose software crashes, identify missing dependencies or configuration files, and analyze performance bottlenecks without requiring access to the application's source code.

Installing strace

strace is often pre-installed on Ubuntu. If it is not available on your system, install it using the default package manager:

sudo apt update
sudo apt install strace

Basic Command Syntax

To trace a process, run strace followed by the command you want to monitor:

strace <command>

For example, to trace the ls command:

strace ls

Tracing a Running Process

If a process is already running, you can attach strace to it using its Process ID (PID):

sudo strace -p <PID>

To detach from the process without killing it, press Ctrl+C.

Useful Command Options

Save Output to a File

Because strace generates a large volume of data, redirecting the output to a text file is often useful:

strace -o output.txt <command>

Trace Child Processes

By default, strace only traces the specified process. To follow child processes created via fork or vfork, use the -f flag:

strace -f <command>

Filter Specific System Calls

To focus on specific operations, such as file opening or network activity, use the -e trace= flag:

# Trace only open and openat system calls
strace -e trace=open,openat <command>

# Trace network-related system calls
strace -e trace=network <command>

# Trace file-related system calls
strace -e trace=file <command>

Generate a Summary Profile

To get a high-level summary showing the time spent, call count, and errors for each system call rather than a line-by-line log, use the -c flag:

strace -c <command>
