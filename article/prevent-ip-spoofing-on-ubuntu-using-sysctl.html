Prevent IP Spoofing on Ubuntu Using Sysctl

This guide explains how to secure an Ubuntu-based router against IP spoofing attacks using the Linux kernel's sysctl parameters. By enabling Reverse Path Filtering (rp_filter), the router automatically drops packets arriving on an interface if the return path to the packet's source IP address does not route back through that same interface. Below are the precise steps and directives needed to configure, persist, and verify these anti-spoofing settings.

Understanding Reverse Path Filtering

The primary defense against IP spoofing in the Linux kernel is Reverse Path Filtering (RFC 3704). When enabled in strict mode, the kernel tests incoming packets against the routing table. If the interface receiving the packet is not the best reverse path to the source address, the packet is discarded as spoofed traffic.

The configuration relies on the rp_filter directive, which accepts three values:

  • 0: Disabled (no source validation).
  • 1: Strict mode (recommended for routers to strictly mitigate spoofing).
  • 2: Loose mode (validates that a route exists via any interface; used for asymmetric routing).

Step 1: Create a Dedicated Sysctl Configuration

While you can modify /etc/sysctl.conf directly, best practice on modern Ubuntu releases is to add a dedicated configuration file inside /etc/sysctl.d/.

Open a new configuration file using a text editor with root privileges:

sudo nano /etc/sysctl.d/99-anti-spoofing.conf

Add the following configuration lines:

# Enable strict Reverse Path Filtering across all current and future interfaces
net.ipv4.conf.default.rp_filter = 1
net.ipv4.conf.all.rp_filter = 1

# Disable Source Routing (prevents attackers from dictating packet paths)
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0

# Log spoofed or impossible packets (martians) to syslog
net.ipv4.conf.all.log_martians = 1
net.ipv4.conf.default.log_martians = 1

Save and exit the editor.

Step 2: Apply the Changes

Load and apply the new settings immediately without rebooting the router by executing:

sudo sysctl --system

This command reloads all sysctl configurations across system directories, including the newly created anti-spoofing configuration.

Step 3: Verify the Configuration

Verify that the kernel applied the values correctly:

sysctl net.ipv4.conf.all.rp_filter
sysctl net.ipv4.conf.default.rp_filter

Both commands should return:

net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1

You can also check specific physical interfaces (such as eth0 or enp1s0) to ensure inheritance:

sysctl net.ipv4.conf.<interface_name>.rp_filter

If an individual interface shows 0, you can explicitly enforce it in your configuration file by adding:

net.ipv4.conf.<interface_name>.rp_filter = 1

Once configured, the Ubuntu router will actively reject forged incoming packets, logging dropped martian addresses to /var/log/syslog or the systemd journal via journalctl -k.
