How to Tunnel RDP Through an Ubuntu SSH Server

This guide explains how to securely access a Windows Remote Desktop (RDP) session by tunneling traffic through an intermediate Ubuntu SSH server. By utilizing SSH local port forwarding, you can safely connect to a Windows machine on a private network without exposing the default RDP port (3389) directly to the public internet.

Prerequisites

  • An Ubuntu server configured with OpenSSH Server (sshd) and reachable from your client.
  • A target Windows machine on the same private network as the Ubuntu server, with Remote Desktop enabled.
  • An SSH client and an RDP client installed on your local machine.

Step 1: Establish the SSH Tunnel

Local port forwarding directs a port on your local machine across the encrypted SSH connection to a specified address and port reachable by the remote SSH server.

Run the following command in your local machine's terminal or PowerShell:

ssh -N -L 33389:WINDOWS_LOCAL_IP:3389 ubuntu_user@UBUNTU_SERVER_IP

Breakdown of the parameters:

  • -N: Tells SSH not to execute a remote command, which is ideal when you only need to forward ports.
  • -L: Specifies local port forwarding in the format local_port:destination_ip:destination_port.
  • 33389: An arbitrary, unused local port on your client device.
  • WINDOWS_LOCAL_IP: The internal/private IP address of the target Windows host (e.g., 192.168.1.50).
  • 3389: The default listening port for Windows Remote Desktop.
  • ubuntu_user@UBUNTU_SERVER_IP: The username and public IP address (or domain) of your Ubuntu SSH server.

Keep this terminal window open for the duration of your session to maintain the tunnel.

Step 2: Connect via Your RDP Client

Once the tunnel is active, connect your local RDP client to the local end of the tunnel rather than the remote machine directly.

  1. Open your Remote Desktop client (e.g., Remote Desktop Connection (mstsc.exe) on Windows, Microsoft Remote Desktop on macOS, or Remmina on Linux).
  2. In the computer/host field, enter: 
    127.0.0.1:33389
    (or localhost:33389)
  3. Click Connect.
  4. When prompted, enter your Windows user credentials. If a certificate warning appears regarding the host name mismatch, confirm to proceed.

Step 3: Hardening SSH Security

To ensure maximum security when using your Ubuntu server as a jump host:

  • Use SSH Keys: Disable password authentication on the Ubuntu host by setting PasswordAuthentication no in /etc/ssh/sshd_config and authenticating exclusively with SSH key pairs.
  • Disable Root Login: Ensure PermitRootLogin no is set in /etc/ssh/sshd_config.
  • Firewall Configuration: Ensure the Windows firewall allows inbound traffic on port 3389 only from the Ubuntu server's subnet or specific private IP address. Ensure the Ubuntu firewall (ufw) only permits incoming traffic on the SSH port.
