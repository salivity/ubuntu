How to Configure Open vSwitch Bridge on Ubuntu

Configuring an Open vSwitch (OVS) bridge on an Ubuntu hypervisor enables advanced virtual network management, allowing virtual machines to communicate efficiently with each other and external networks. This guide outlines the step-by-step process to install Open vSwitch, create a virtual bridge, attach physical network interfaces, and ensure persistent configuration across system reboots using Netplan.

Step 1: Install Open vSwitch

Update your system’s package list and install the Open vSwitch package using the APT package manager:

sudo apt update
sudo apt install -y openvswitch-switch

Verify that the Open vSwitch service is running:

sudo systemctl status openvswitch-switch

Step 2: Create an Open vSwitch Bridge

Use the ovs-vsctl utility to create a new OVS bridge. In this example, the bridge is named br0:

sudo ovs-vsctl add-br br0

Step 3: Attach a Physical Network Interface to the Bridge

To route external traffic through the bridge, attach a physical network interface (e.g., eth0 or enp3s0) to br0:

sudo ovs-vsctl add-port br0 eth0

Note: Replace eth0 with the actual name of your network interface.

Step 4: Configure Network Persistence with Netplan

Ubuntu uses Netplan for network configuration. To ensure the bridge and IP assignments persist after a reboot, edit your Netplan configuration file (typically located in /etc/netplan/).

Open the configuration file:

sudo nano /etc/netplan/01-netcfg.yaml

Modify the YAML configuration to define the physical interface, the OVS bridge, and the IP address assignment:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: no
      dhcp6: no
  bridges:
    br0:
      openvswitch: {}
      interfaces: [eth0]
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1

Replace the interface names, IP addresses, gateway (via), and DNS servers with your network’s specific parameters.

Apply the new configuration:

sudo netplan apply

Step 5: Verify the Configuration

Check the status of the Open vSwitch bridge to confirm that the port was added successfully:

sudo ovs-vsctl show

Verify the network interface and IP configuration:

ip addr show br0
