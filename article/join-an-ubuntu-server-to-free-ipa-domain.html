Join an Ubuntu Server to FreeIPA Domain

Joining an Ubuntu server to a FreeIPA domain allows you to centralize authentication, enforce identity policies, and manage access using centralized credentials. This guide walks you through the essential steps to enroll an Ubuntu client into an existing FreeIPA realm, including setting up network prerequisites, installing the client software, running the automated enrollment installer, and enabling automatic home directory creation for domain users.

Prerequisites

Before starting, ensure your Ubuntu server meets the following requirements:

  • A static IP address configured.
  • A fully qualified domain name (FQDN) that resolves properly.
  • Network access to the FreeIPA server over required ports (e.g., 80, 443, 389, 636, 88, 464).
  • The system clock synchronized via NTP with the FreeIPA server.

Step 1: Set the Hostname and Configure DNS

The client system's hostname must match its FQDN. Set your hostname by running:

sudo hostnamectl set-hostname client.example.com

Ensure your /etc/resolv.conf points to the FreeIPA server as its primary DNS resolver, or configure your local network's DNS server to resolve FreeIPA records (specifically SRV records for Kerberos and LDAP).

You can verify name resolution using dig or host:

host -t SRV _kerberos._udp.example.com

Step 2: Install the FreeIPA Client

Ubuntu provides the FreeIPA client package in the default repositories. Update your package lists and install the client software:

sudo apt update
sudo apt install freeipa-client -y

Step 3: Run the FreeIPA Client Installer

To join the domain, execute the ipa-client-install command. Including the --mkhomedir flag configures PAM to automatically create user home directories upon initial login:

sudo ipa-client-install --mkhomedir

The installer will attempt to auto-discover the realm and domain via DNS. If discovery succeeds, confirm the detected settings. You will be prompted to provide:

  1. Domain Name: (e.g., example.com)
  2. Realm Name: (e.g., EXAMPLE.COM)
  3. IPA Admin Username: Typically admin
  4. IPA Admin Password: The password for the specified admin user

If you prefer an unattended installation without interactive prompts, specify the parameters directly:

sudo ipa-client-install --server=ipa.example.com --domain=example.com --realm=EXAMPLE.COM -U -p admin -w YourAdminPassword --mkhomedir

Step 4: Configure PAM for Home Directory Creation

If you did not use the --mkhomedir option during installation, enable automatic home directory generation manually:

sudo pam-auth-update --enable mkhomedir

Ensure the "Create home directory on login" option is selected, then save and exit.

Step 5: Verify Domain Join

Confirm that your Ubuntu server can retrieve user information from the FreeIPA directory:

id admin

If the enrollment was successful, the command will return the UID, GID, and group memberships of the FreeIPA admin account.

Next, test Kerberos authentication by obtaining a Kerberos ticket:

kinit admin
klist

You can now log in to the Ubuntu server using credentials managed by your FreeIPA domain.
