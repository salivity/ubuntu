Mount Android Filesystem using jmtpfs in Ubuntu

This guide provides a straightforward walkthrough for mounting an Android device's filesystem on Ubuntu using jmtpfs. You will learn how to install the necessary software, configure your Android device, create a local directory, mount the device via Media Transfer Protocol (MTP), and safely unmount it when finished.

Step 1: Install jmtpfs

Open your terminal (Ctrl+Alt+T) and update your package list, then install jmtpfs:

sudo apt update
sudo apt install jmtpfs

Step 2: Create a Mount Point

Create a folder in your home directory where the Android filesystem will be accessed:

mkdir ~/androiddevice

Step 3: Connect and Configure Your Android Device

  1. Connect your Android phone or tablet to your Ubuntu machine using a USB cable.
  2. Unlock your Android device screen.
  3. Swipe down from the top of the screen to open the notification shade.
  4. Tap the USB options notification and select File Transfer or MTP (Media Transfer Protocol) mode.

Step 4: Mount the Android Device

Run the following command in your terminal to mount the filesystem to the directory created earlier:

jmtpfs ~/androiddevice

If successful, the terminal will indicate that the device has been attached.

Step 5: Access Your Files

You can now browse your Android device's internal storage and SD card through the Ubuntu File Manager (Nautilus) by navigating to the androiddevice folder, or via the command line:

cd ~/androiddevice
ls -l

Step 6: Unmount the Device

Before disconnecting the USB cable, safely unmount the device using fusermount:

fusermount -u ~/androiddevice
