Monitor Live HTTP Traffic on Ubuntu Server

Monitoring real-time HTTP requests on an Ubuntu web server is essential for troubleshooting traffic spikes, debugging application errors, and identifying malicious requests. While standard access logs record this data, several command-line utilities allow administrators to inspect incoming and outgoing HTTP traffic as it happens. This guide covers the most effective commands for live HTTP traffic monitoring on Ubuntu, ranging from dedicated HTTP packet sniffers like httpry and raw packet analyzers like tcpdump to real-time log viewers.

1. Using httpry (Dedicated HTTP Sniffer)

The httpry utility is a specialized packet sniffer designed explicitly for displaying and logging HTTP traffic. It captures network packets, parses the HTTP protocol, and prints requests to the terminal in a clean, human-readable format.

To install httpry on Ubuntu:

sudo apt update
sudo apt install httpry

To start monitoring HTTP traffic on all interfaces:

sudo httpry -i any

To filter for specific HTTP methods (such as GET and POST):

sudo httpry -m get,post

2. Using tcpdump (Network Packet Inspection)

The tcpdump command is a powerful, native network analysis tool pre-installed or readily available on almost all Linux systems. You can configure it to capture ASCII-encoded HTTP payloads on standard web ports (port 80).

Run the following command to monitor live HTTP requests:

sudo tcpdump -i any -n -s 0 -A 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12:2]&0xf0)>>2)) != 0)'
  • -i any: Listens on all available network interfaces.
  • -n: Disables DNS lookups to keep output fast.
  • -s 0: Captures the full packet size (snapshot length).
  • -A: Outputs packet contents in ASCII text, allowing you to read HTTP headers directly.

3. Streaming Web Server Logs with tail -f

If your traffic is encrypted via HTTPS (port 443), packet sniffers like tcpdump and httpry will only display encrypted payloads unless configured with decryption keys. In production environments, the most common way to monitor live decrypted HTTP and HTTPS traffic is to tail your web server's access logs.

For Nginx:

sudo tail -f /var/log/nginx/access.log

For Apache:

sudo tail -f /var/log/apache2/access.log

You can combine this with grep to monitor requests to a specific endpoint or from a specific IP address:

sudo tail -f /var/log/nginx/access.log | grep "POST /api/v1"

4. Using goaccess for Interactive Real-Time Monitoring

GoAccess is an interactive real-time web log analyzer that parses your server logs and outputs a visual dashboard directly within the terminal.

To install goaccess:

sudo apt install goaccess

To run goaccess interactively on your Nginx access log:

sudo goaccess /var/log/nginx/access.log --log-format=COMBINED

This interface tracks hits, visitor numbers, requested URLs, referrers, and HTTP response codes in real time.
