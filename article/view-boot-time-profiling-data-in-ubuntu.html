View Boot Time Profiling Data in Ubuntu

To view system boot time profiling data in Ubuntu, use the systemd-analyze command. This built-in utility measures startup performance, pinpoints slow boot processes, and provides detailed breakdowns of individual services that impact overall system startup time.

Using systemd-analyze Commands

Running the base command provides a quick summary of the total time taken to boot:

systemd-analyze

This output displays the breakdown of time consumed by the kernel, initrd, and userspace during the boot process.

Finding Slow Services

To see a list of all active services sorted by the time they took to initialize, run:

systemd-analyze blame

This identifies specific background tasks or services causing delays during startup.

Analyzing the Critical Chain

To inspect the time-critical chain of services that directly impacted the boot duration, use:

systemd-analyze critical-chain

This outputs a tree structure showing service dependencies and highlights where bottlenecks occurred along the boot sequence.

Exporting Graphical Boot Data

For a detailed visual chart of the entire boot process, export the profiling data into an SVG vector file:

systemd-analyze plot > boot_analysis.svg

You can open the resulting boot_analysis.svg file in any web browser or image viewer to analyze a timeline of every process during startup.
