How to Install and Configure tmux on Ubuntu

tmux is a powerful terminal multiplexer for Ubuntu that allows you to manage multiple terminal sessions within a single window, detach running processes, and keep remote sessions alive in the background. This guide covers the quick installation of tmux via Ubuntu’s package manager, essential commands to start using it immediately, and practical configuration tweaks to customize key bindings and enable mouse support.

Installing tmux on Ubuntu

Ubuntu includes tmux in its standard software repositories. You can install it using the apt package manager.

  1. Open your terminal and update your local package index:

    sudo apt update

  2. Install tmux:

    sudo apt install tmux

  3. Verify that tmux was installed correctly by checking its version:

    tmux -V

Essential tmux Commands and Usage

tmux relies on a “prefix key” combination to trigger command modes. By default, the prefix key is Ctrl + b. You must press this prefix before pressing any secondary command key.

Session Management

  • Start a new default session:

    tmux

  • Start a named session:

    tmux new -s session_name

  • Detach from the current session: Press Ctrl + b, then press d.

  • List existing sessions:

    tmux ls

  • Reattach to a session:

    tmux attach -t session_name

  • Kill a specific session:

    tmux kill-session -t session_name

Managing Windows and Panes

Inside an active tmux session:

  • Split window horizontally: Press Ctrl + b, then "
  • Split window vertically: Press Ctrl + b, then %
  • Navigate between panes: Press Ctrl + b, then use the Arrow keys
  • Close current pane: Press Ctrl + b, then x (confirm with y)
  • Create a new window: Press Ctrl + b, then c
  • Switch between windows: Press Ctrl + b, then the window number (e.g., 0, 1)

Configuring tmux

You can customize tmux by creating a .tmux.conf file in your home directory.

  1. Create and open the file using a text editor:

    nano ~/.tmux.conf

  2. Add your preferred configurations. Here is a recommended starter configuration:

    # Enable mouse support (scrolling, selecting panes/windows)
set -g mouse on

# Start window and pane numbering at 1 instead of 0
set -g base-index 1
setw -g pane-base-index 1

# Change the prefix key from Ctrl+b to Ctrl+a
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# Use intuitive split keys (| for vertical, - for horizontal)
bind | split-window -h
bind - split-window -v
unbind '"'
unbind %

# Reload configuration file quickly
bind r source-file ~/.tmux.conf \; display "Config reloaded!"

  3. Save and exit the file (in nano, press Ctrl + O, Enter, then Ctrl + X).

  4. Apply the configuration changes immediately without restarting tmux:

    tmux source-file ~/.tmux.conf
