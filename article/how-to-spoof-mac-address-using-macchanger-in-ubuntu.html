How to Spoof MAC Address Using Macchanger in Ubuntu

Spoofing your Media Access Control (MAC) address is an effective way to enhance online privacy, bypass network access controls, and prevent device tracking on public Wi-Fi networks. In Ubuntu, the utility macchanger allows you to quickly view, randomize, or temporarily change your network interface's MAC address. This guide provides a straightforward, step-by-step walkthrough on how to install macchanger and use it to spoof your MAC address on an Ubuntu system.

Step 1: Install Macchanger

Open your terminal (Ctrl+Alt+T) and update your package list, then install macchanger:

sudo apt update
sudo apt install macchanger

During installation, a prompt will ask if you want macchanger to set a random MAC address automatically every time a network interface is brought up or down. Choose Yes for automatic spoofing, or No if you prefer to change it manually.

Step 2: Identify Your Network Interface

List all available network interfaces on your system to identify the name of the device you want to spoof (e.g., wlan0 for Wi-Fi or eth0/enp3s0 for Ethernet):

ip link show

Note down the name of your target interface.

Step 3: Disable the Network Interface

Before changing the MAC address, you must temporarily disable the network interface:

sudo ip link set dev <interface_name> down

(Replace <interface_name> with your actual interface, such as wlan0.)

Step 4: Change Your MAC Address

  • Option A: Assign a completely random MAC address

    sudo macchanger -r <interface_name>

  • Option B: Assign a specific MAC address

    sudo macchanger -m XX:XX:XX:XX:XX:XX <interface_name>

    (Replace XX:XX:XX:XX:XX:XX with your desired MAC address.)

  • Option C: Set a random MAC address of the same vendor

    sudo macchanger -e <interface_name>

Step 5: Enable the Network Interface

Once the MAC address is changed, bring the network interface back up:

sudo ip link set dev <interface_name> up

Step 6: Verify the Changes

To confirm that your MAC address has been successfully spoofed, check the status using:

macchanger -s <interface_name>

The output will display both your permanent (original) hardware MAC address and your current (spoofed) MAC address.

Resetting to the Original MAC Address

If you want to restore your device's original hardware MAC address, bring the interface down, run the reset command, and bring it back up:

sudo ip link set dev <interface_name> down
sudo macchanger -p <interface_name>
sudo ip link set dev <interface_name> up

All changes made by macchanger are temporary and will automatically revert to the original hardware MAC address upon reboot unless configured to run automatically at startup.
