Manage Snap Packages and Permissions in Ubuntu

Managing Snap packages in Ubuntu allows users to easily install, update, and remove sandboxed applications, while control over package permissions ensures system security. This guide provides a clear walkthrough on using both the Command Line Interface (CLI) and Graphical User Interface (GUI) to view installed snaps, check their access permissions, and modify what system resources they can access.

Managing Snap Packages via Terminal

The command-line interface provides the fastest way to manage your installed Snap packages.

1. View Installed Snaps

To see a complete list of all Snap packages installed on your Ubuntu system, open your terminal and run:

snap list

This command outputs a table showing the package name, version, revision number, tracking channel, publisher, and notes (such as strict or classic confinement).

2. Update Installed Snaps

Snap packages usually update automatically in the background. However, you can manually check for and apply updates for all packages using:

sudo snap refresh

To update a single specific application, append its name to the command:

sudo snap refresh package-name

3. Remove a Snap Package

To completely remove a Snap application along with its data, use:

sudo snap remove package-name

4. Enable or Disable a Snap

If you want to stop an application from running without deleting its files, you can disable it:

sudo snap disable package-name

To re-enable it later, run:

sudo snap enable package-name

Viewing and Managing Snap Permissions via Terminal

Snaps use "interfaces" (plugs and slots) to control access to system hardware and features like the camera, network, home directory, or removable storage.

1. View Permissions for a Specific Snap

To view all available connections and permission statuses for a specific application, use the snap connections command:

snap connections package-name

This shows three main columns:

  • Interface: The type of access requested (e.g., camera, home, network).
  • Plug: The application requesting access.
  • Slot: The system resource providing access. A blank slot means the permission is currently disconnected/denied.

2. Grant a Permission (Connect)

To grant an application access to a specific system resource, connect the corresponding plug to its slot:

sudo snap connect package-name:plug-name

Example (Granting VLC access to removable storage):

sudo snap connect vlc:removable-media

3. Revoke a Permission (Disconnect)

To revoke a permission and block an application from accessing a resource, disconnect the plug:

sudo snap disconnect package-name:plug-name

Example (Revoking VLC access to removable storage):

sudo snap disconnect vlc:removable-media

Managing Snaps and Permissions via GUI

If you prefer a graphical interface, you can manage both packages and permissions through the desktop software manager.

  1. Open the Software Center: Launch the App Center or Ubuntu Software application from your app grid.
  2. View Installed Apps: Click on the Installed tab at the top to see all installed applications, including Snaps.
  3. Manage Permissions:
    • Click on the specific application you want to configure.
    • Look for the Permissions button or section on the application details page.
    • Toggle the switches on or off for individual access rights, such as access to the microphone, web camera, print system, or host files.
