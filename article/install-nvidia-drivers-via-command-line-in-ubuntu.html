Install NVIDIA Drivers via Command Line in Ubuntu

Installing proprietary NVIDIA drivers via the command line in Ubuntu ensures optimal graphics performance, stability, and hardware acceleration for gaming, video editing, and deep learning tasks. This guide covers the complete terminal-based process, including identifying your graphics card model, updating system repositories, automatically installing the recommended driver version using the ubuntu-drivers tool, and verifying that the driver is functioning correctly after a reboot.

Step 1: Check Your NVIDIA GPU Information

Before installing any drivers, verify that your system recognizes your NVIDIA graphics card and check which driver versions are recommended for your specific hardware.

Open your terminal (Ctrl+Alt+T) and run:

ubuntu-drivers devices

This command outputs details about your GPU model along with a list of compatible drivers. Look for the line containing recommended next to a driver version (for example, nvidia-driver-535 - driver device recommended).

Step 2: Update System Packages

Ensure your local package repository index and installed software are fully up to date to avoid installation conflicts.

sudo apt update && sudo apt upgrade -y

Step 3: Install the NVIDIA Driver

You can choose to let Ubuntu automatically install the recommended driver, or manually select a specific driver version.

Option A: Automatic Installation (Recommended)

To automatically install the driver best suited for your GPU, execute:

sudo ubuntu-drivers install

(Note: On older Ubuntu releases, the command may be sudo ubuntu-drivers autoinstall).

Option B: Manual Installation of a Specific Driver Version

If you require a specific driver version (e.g., version 535), install it directly using apt:

sudo apt install nvidia-driver-535

Replace 535 with your desired version number as identified in Step 1.

Step 4: Secure Boot Configuration (If Applicable)

If your computer has Secure Boot enabled in the BIOS/UEFI, the installation prompt will ask you to create a password for MOK (Machine Owner Key).

  1. Enter a temporary password when prompted in the terminal.
  2. Reboot your system.
  3. Upon restarting, a blue screen (MOK Management) will appear.
  4. Select Enroll MOK > Continue > Yes.
  5. Enter the temporary password you created to complete driver signing.

Step 5: Reboot Your System

For the kernel modules to load properly, restart your system:

sudo reboot

Step 6: Verify the Installation

After logging back into Ubuntu, confirm that the NVIDIA driver is active and running correctly by checking the System Management Interface tool:

nvidia-smi

If successful, this command displays a table showing your GPU model, driver version, CUDA version, and current memory usage.
