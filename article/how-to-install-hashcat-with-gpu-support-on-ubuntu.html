How to Install Hashcat with GPU Support on Ubuntu

This guide provides a straightforward walkthrough for installing the Hashcat advanced password recovery utility on an Ubuntu system with dedicated GPU acceleration. You will learn how to prepare your system, install the correct proprietary drivers and OpenCL/CUDA runtimes for NVIDIA or AMD hardware, install the Hashcat package, and verify that your graphics hardware is properly detected for maximum cracking performance.

Step 1: Update Your System

Open your terminal and ensure your system package lists and installed packages are fully updated.

sudo apt update && sudo apt upgrade -y

Install the core utilities required for compiling and managing drivers:

sudo apt install -y build-essential linux-headers-$(uname -r)

Step 2: Install GPU Drivers and Runtimes

Hashcat relies on OpenCL or CUDA to offload compute tasks to your graphics processor. Choose the instructions matching your hardware.

For NVIDIA GPUs

NVIDIA hardware can utilize either CUDA or OpenCL. Installing the proprietary NVIDIA driver along with the CUDA toolkit provides the best performance.

  1. Detect your GPU model and recommended driver version:

    ubuntu-drivers devices

  2. Install the recommended driver (replace <version> with the recommended version number, such as 535 or 550):

    sudo apt install -y nvidia-driver-<version> nvidia-cuda-toolkit

  3. Reboot your system to load the proprietary drivers:

    sudo reboot

For AMD GPUs

AMD graphics cards require the ROCm stack or the proprietary OpenCL runtime.

  1. Install the base OpenCL packages from the Ubuntu repositories:

    sudo apt install -y clinfo opencl-headers

  2. For full compute support, download and install the AMD ROCm driver stack using the official AMD installer script, or install the standard compute runtime:

    sudo apt install -y rocm-opencl-runtime

  3. Add your current user to the render and video groups to grant hardware access:

    sudo usermod -aG render $USER
sudo usermod -aG video $USER

  4. Reboot your system to apply permissions and load kernel modules:

    sudo reboot

Step 3: Install Hashcat

Hashcat is available directly in the official Ubuntu repositories.

sudo apt install -y hashcat

If you require the absolute latest release with support for newer hash modes, download the pre-compiled binary package directly from the Hashcat release repository:

wget https://hashcat.net/files/hashcat-6.2.6.7z
sudo apt install -y p7zip-full
7z x hashcat-6.2.6.7z
cd hashcat-6.2.6/

Step 4: Verify GPU Detection

Once installed, check that Hashcat recognizes your graphics card and compute runtimes.

hashcat -I

The output should display an "OpenCL Info" or "CUDA Info" section listing your GPU model, available device memory, and driver version. Ensure the device type displays as GPU rather than CPU.

Step 5: Test Performance with a Benchmark

Validate that the GPU functions under a processing load by running Hashcat's built-in benchmarking tool:

hashcat -b

To test a specific, common algorithm such as NTLM (mode 1000) or SHA-256 (mode 1400):

hashcat -b -m 1000

The benchmark will display your device's recovery speed in hashes per second (H/s, MH/s, or GH/s), confirming that GPU-accelerated password recovery is active and operational.
