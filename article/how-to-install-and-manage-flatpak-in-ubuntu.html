How to Install and Manage Flatpak in Ubuntu

Flatpak is a universal package management system for Linux that allows users to run sandboxed applications safely and consistently across different distributions. This guide provides a straightforward walkthrough on how to install Flatpak on Ubuntu, enable the Flathub repository, and effectively manage applications using both the terminal and graphical user interfaces.

1. Install Flatpak on Ubuntu

Open your terminal (Ctrl+Alt+T) and run the following commands to update your package list and install Flatpak:

sudo apt update
sudo apt install flatpak

2. Add the Flathub Repository

Flathub is the central repository where most Flatpak applications are hosted. To add Flathub to your system, run:

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

3. Enable Software Center Support (Optional)

If you prefer installing applications via a graphical interface rather than the command line, install the Flatpak plugin for the GNOME Software center:

sudo apt install gnome-software-plugin-flatpak

Note: Restart your system after completing these steps to ensure environment paths update properly.

4. Manage Flatpak Applications

Searching for Applications

To search for an application, use the search command followed by the app name:

flatpak search <application_name>

Installing Applications

To install an application from Flathub, use its Application ID:

flatpak install flathub <application_id>

Example: flatpak install flathub org.gimp.GIMP

Running Applications

To launch an installed Flatpak application from the terminal:

flatpak run <application_id>

You can also launch installed applications directly from your Ubuntu application menu.

Listing Installed Applications

To see all Flatpak packages installed on your system:

flatpak list

Updating Applications

To update all your installed Flatpak applications to their latest versions:

flatpak update

Removing Applications

To uninstall a Flatpak application:

flatpak uninstall <application_id>

To remove unused runtime dependencies left behind after uninstalling apps:

flatpak uninstall --unused
