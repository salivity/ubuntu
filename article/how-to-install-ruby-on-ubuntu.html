How to Install Ruby on Ubuntu

Installing the Ruby programming language on Ubuntu can be done through several methods depending on your development needs. This guide provides clear, step-by-step instructions for the three most common ways to install Ruby: using Ubuntu's standard apt package manager for a quick setup, using rbenv for flexible version management, and using RVM (Ruby Version Manager) for isolated development environments.

Method 1: Install Ruby Using APT (Easiest)

Using Ubuntu's default package manager is the fastest way to get Ruby up and running, though it may not always provide the absolute latest version.

  1. Update the package index:

    sudo apt update

  2. Install Ruby:

    sudo apt install ruby-full

  3. Verify the installation:

    ruby -v

Method 2: Install Ruby Using Rbenv (Recommended)

Rbenv allows you to install and switch between multiple versions of Ruby easily. This is ideal for active Ruby developers.

  1. Install required dependencies:

    sudo apt update
sudo apt install git curl libssl-dev libreadline-dev zlib1g-dev base-devel libffi-dev libyaml-dev

  2. Run the Rbenv installer script:

    curl -fsSL https://github.com/rbenv/rbenv-installer/raw/HEAD/bin/rbenv-installer | bash

  3. Add Rbenv to your path: Run the following commands to configure your environment:

    echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init -)"' >> ~/.bashrc
source ~/.bashrc

  4. Install a specific Ruby version: List available versions:

    rbenv install -l

    Install your chosen version (e.g., 3.3.0):

    rbenv install 3.3.0

  5. Set the global Ruby version:

    rbenv global 3.3.0

  6. Verify the installation:

    ruby -v

Method 3: Install Ruby Using RVM

RVM is another popular version manager that manages both Ruby versions and gemsets.

  1. Install required dependencies:

    sudo apt update
sudo apt install curl gpg software-properties-common

  2. Import the GPG keys:

    gpg --keyserver hkp://keyserver.ubuntu.com --recv-keys 409B6B1796C275462A1703113804BB82D39DC0E3 7D2BAF1CF37B13E2069D6956105BD0E739499BDB

  3. Install RVM:

    curl -sSL https://get.rvm.io | bash -s stable

  4. Load RVM into your shell session:

    source ~/.rvm/scripts/rvm

  5. Install Ruby:

    rvm install 3.3.0

  6. Set the default version and verify:

    rvm use 3.3.0 --default
ruby -v
