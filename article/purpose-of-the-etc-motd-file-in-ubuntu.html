Purpose of the /etc/motd File in Ubuntu

The /etc/motd (Message of the Day) file in Ubuntu is used to display system information, administrative announcements, or welcome messages to users immediately after they log into a command-line interface via SSH or a local terminal session. It serves as a central notification mechanism for administrators to communicate critical updates, usage policies, and real-time system stats to anyone accessing the server.

Primary Functions of /etc/motd

The main purpose of the Message of the Day is to inform users about the state of the system the moment their session begins. Its key functions include:

  • System Notifications: Informing users about scheduled downtime, upcoming maintenance, or policy changes.
  • System Status Summaries: Displaying live metrics such as CPU usage, memory usage, swap space, disk health, and current system load.
  • Security and Compliance: Presenting legal disclaimers, unauthorized access warnings, or details regarding security patches and pending system reboots.
  • Package and Update Alerts: Notifying administrators about available software updates or critical security fixes requiring installation.

Static vs. Dynamic MOTD in Ubuntu

Older Linux distributions relied on a static text file located directly at /etc/motd. Modern Ubuntu systems use a dynamic framework managed by PAM (Pluggable Authentication Modules) and the update-motd utility.

  1. Dynamic Generation: In Ubuntu, /etc/motd is typically a symbolic link pointing to a file in /run/motd.dynamic. Every time a user logs in, the system executes a series of scripts stored in the /etc/update-motd.d/ directory.
  2. Script Execution: The scripts in /etc/update-motd.d/ run in numerical order (e.g., 00-header, 10-sysinfo, 90-updates-available). These scripts gather current system data and output the combined text into the dynamic MOTD file.

How to Customize or Disable MOTD

Administrators can easily modify what appears during the login process:

  • Add Custom Messages: Create a new executable shell script in /etc/update-motd.d/ with a prefixed number (such as 99-custom) to append custom information to the login screen.
  • Disable Specific Information: Remove execution permissions from any script in /etc/update-motd.d/ using chmod -x /etc/update-motd.d/SCRIPT_NAME to hide specific sections, such as update alerts or documentation links.
  • Disable MOTD Entirely: Edit /etc/pam.d/sshd and comment out the lines referencing pam_motd.so to prevent any message from showing upon SSH login.
