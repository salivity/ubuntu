How to Install and Configure Atop on Ubuntu

atop is an advanced, full-screen performance monitor for Linux that tracks system resource utilization, process activity, and historical data over time. This guide provides a straightforward walkthrough on how to install atop on Ubuntu, configure its background logging service to capture past performance metrics, modify recording intervals, and use basic commands to analyze real-time and historical system performance.

Installing Atop on Ubuntu

atop is available directly from the default Ubuntu package repositories.

  1. Update your local package index:

    sudo apt update

  2. Install the atop package:

    sudo apt install atop -y

  3. Verify the installation by checking the installed version:

    atop -V

Configuring the Atop Service

When installed, atop sets up a system daemon that automatically records system statistics in the background. This allows you to inspect system behavior during past high-load events or crashes.

1. Enable and Start the Background Service

Ensure the service is running and configured to start automatically on system boot:

sudo systemctl enable --now atop

To check the status of the daemon:

sudo systemctl status atop

2. Adjust Log Collection Interval

By default, atop captures system snapshots every 600 seconds (10 minutes). To record logs more frequently (e.g., every 120 seconds):

  1. Open the configuration file in a text editor:

    sudo nano /etc/default/atop

  2. Locate the line defining the interval and update INTERVAL:

    INTERVAL=120

  3. Save the file and restart the service to apply changes:

    sudo systemctl restart atop

Log files are automatically stored in /var/log/atop/ using the naming convention atop_YYYYMMDD.

Using Atop

Real-Time Monitoring

To launch the real-time interactive monitor, run:

atop

While inside the interface, use these key bindings to sort and filter process information:

  • m: Sort processes by memory consumption.
  • d: Sort processes by disk activity.
  • c: Display the full command line for each process.
  • p: Display cumulative resource usage per process name.
  • q: Quit the application.

Reading Historical Log Files

To view recorded data from a specific day, pass the log file to atop using the -r flag:

atop -r /var/log/atop/atop_20231025

Navigate through the historical data using the following keys:

  • t: Advance forward to the next time sample.
  • T: Move backward to the previous time sample.
  • b: Jump directly to a specific time (e.g., enter 14:30).
