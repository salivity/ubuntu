How to Install and Configure MariaDB on Ubuntu

This guide provides a straightforward tutorial on installing and configuring the MariaDB database server on an Ubuntu system. You will learn how to update your package index, install the MariaDB server packages, execute the security script to protect your database, create administrative users, and modify basic configuration settings to ensure your database runs smoothly.

Step 1: Update System Packages

Before installing new software, update your package list to ensure you receive the latest version available in the Ubuntu repository.

sudo apt update && sudo apt upgrade -y

Step 2: Install MariaDB Server

Install the MariaDB server package along with essential utilities using the APT package manager.

sudo apt install mariadb-server mariadb-client -y

Once the installation is complete, the MariaDB service will start automatically. You can verify its status with:

sudo systemctl status mariadb

If it is not running, start and enable it to launch on boot:

sudo systemctl start mariadb
sudo systemctl enable mariadb

Step 3: Secure the MariaDB Installation

MariaDB includes a security script that modifies default settings, such as remote root logins and sample databases. Run the script:

sudo mariadb-secure-installation

Follow the interactive prompts: 1. Enter current password for root: Press Enter (since no password is set initially). 2. Switch to unix_socket authentication: Type N (socket authentication is enabled by default for root on Ubuntu). 3. Change the root password? Type Y and enter a strong password. 4. Remove anonymous users? Type Y. 5. Disallow root login remotely? Type Y. 6. Remove test database and access to it? Type Y. 7. Reload privilege tables now? Type Y.

Step 4: Test Database Access and Create a User

By default, the root MariaDB user on Ubuntu uses the unix_socket plugin, allowing you to log in using system sudo permissions.

Log in to the MariaDB console:

sudo mariadb

Create a new database and a dedicated user account with appropriate permissions:

CREATE DATABASE my_database;
CREATE USER 'my_user'@'localhost' IDENTIFIED BY 'strong_password';
GRANT ALL PRIVILEGES ON my_database.* TO 'my_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Test logging in with the newly created user:

mariadb -u my_user -p

Enter the password when prompted, then type EXIT; to log out.

Step 5: Configure MariaDB Settings

MariaDB’s main configuration file on Ubuntu is located at /etc/mysql/mariadb.conf.d/50-server.cnf.

To edit the configuration file, open it in a text editor:

sudo nano /etc/mysql/mariadb.conf.d/50-server.cnf

Common Configuration Tweaks:

  • Configure Network Access: By default, MariaDB only listens for connections on 127.0.0.1 (localhost). To allow remote connections, locate the bind-address line and set it to your server’s IP address, or 0.0.0.0 to listen on all interfaces:

    bind-address = 0.0.0.0

  • Adjust Character Set: To ensure full UTF-8 support (including emojis), locate or add the following lines under the [mysqld] section:

    character-set-server  = utf8mb4
collation-server      = utf8mb4_general_ci

Save and exit the file (press CTRL+O, Enter, then CTRL+X in Nano).

Step 6: Restart MariaDB

Apply any changes made to the configuration file by restarting the MariaDB service:

sudo systemctl restart mariadb
