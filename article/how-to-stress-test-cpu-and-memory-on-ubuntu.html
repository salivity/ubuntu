How to Stress Test CPU and Memory on Ubuntu

Stress testing your Ubuntu system helps verify system stability, monitor thermal performance under heavy loads, and identify potential hardware failures. This guide covers how to install and use stress-ng, a powerful command-line utility, to safely push your system's CPU and RAM to their limits while monitoring system behavior.

Installing stress-ng

The most reliable tool for stress testing on Ubuntu is stress-ng. It is an updated version of the classic stress tool and is available directly in the official Ubuntu repositories.

Open your terminal and install it using:

sudo apt update
sudo apt install stress-ng

How to Stress Test the CPU

To test the CPU, specify the number of CPU worker threads and the duration of the test.

Test All Available CPU Cores

To stress all available CPU cores for 60 seconds and display a summary at the end:

stress-ng --cpu 0 --timeout 60s --metrics-brief

Setting --cpu 0 automatically detects and uses every CPU core on your machine.

Test a Specific Number of Cores

To stress a specific number of CPU cores (for example, 4 cores) for 2 minutes:

stress-ng --cpu 4 --timeout 2m

How to Stress Test Memory (RAM)

Memory stress testing works by spawning virtual memory stress workers that allocate, write to, and free memory repeatedly.

Stress Test a Percentage of RAM

To test 80% of your total RAM using 2 memory workers for 60 seconds:

stress-ng --vm 2 --vm-bytes 80% --timeout 60s --metrics-brief

Stress Test a Fixed Amount of Memory

To stress test a specific amount of RAM, such as 4 Gigabytes:

stress-ng --vm 2 --vm-bytes 4G --timeout 60s

Combined CPU and RAM Stress Test

To simulate maximum system load, you can run CPU and memory stress operations simultaneously:

stress-ng --cpu 0 --vm 2 --vm-bytes 80% --timeout 5m --metrics-brief

Monitoring System Performance During Tests

While the stress test runs, open a second terminal window to monitor system resource usage and thermal metrics:

  • Resource Usage: Install and run htop to watch real-time CPU core usage and RAM usage: 
    sudo apt install htop
htop
  • Thermal Monitoring: Install lm-sensors to track CPU temperatures: 
    sudo apt install lm-sensors
sensors

If your CPU temperatures exceed your hardware's safe thermal limits (typically around 85°C to 90°C), you can stop the test immediately by pressing Ctrl + C in the terminal running stress-ng.
