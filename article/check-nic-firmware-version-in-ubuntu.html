Check NIC Firmware Version in Ubuntu

Checking the firmware version of a network interface controller (NIC) in Ubuntu is an essential task for system administration, hardware compatibility verification, and network troubleshooting. This guide covers the primary terminal commands used to query your network hardware, focusing on the standard ethtool utility as well as built-in system alternatives like lshw and kernel log inspection.

Step 1: Identify the Network Interface Name

Before querying the firmware, you need the logical name of your network adapter. List all available interfaces by running:

ip link

Look for interface names such as eth0, enp3s0, or wlan0.

Step 2: Check Firmware Version with ethtool

The primary and most reliable command to retrieve NIC firmware information is ethtool using the -i (or --driver) flag.

If ethtool is not installed on your system, install it via APT:

sudo apt update
sudo apt install ethtool

Run the following command, replacing <interface_name> with your actual interface:

sudo ethtool -i <interface_name>

Example:

sudo ethtool -i enp3s0

Sample Output:

driver: r8169
version: 5.15.0-88-generic
firmware-version: rtl8168h-2_0.0.2 02/26/15
expansion-rom-version: 
bus-info: 0000:03:00.0
supports-statistics: yes
supports-test: no
supports-eeprom-access: no
supports-register-dump: no
supports-priv-flags: no

The firmware-version field displays the active firmware release loaded on the controller.

Alternative Method: Using lshw

If you prefer not to install additional packages, the lshw (list hardware) utility can display network configuration details, including driver and firmware metadata:

sudo lshw -C network

Locate your interface in the output and examine the configuration: line for the firmware parameter.

Alternative Method: Using Kernel Logs (dmesg)

During the boot process, the Linux kernel initializes the network controller and logs the detected firmware version. You can filter the kernel ring buffer to view this information:

sudo dmesg | grep -i firmware

Or target network-specific messages:

sudo dmesg | grep -i <interface_name>
