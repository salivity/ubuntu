How to Upgrade an Edubuntu Installation

Upgrading an Edubuntu system ensures access to the latest educational software, Linux kernel updates, and security patches. The recommended method for upgrading an Edubuntu installation is utilizing Ubuntu’s native release upgrade utility, which is available through both the command-line interface (CLI) and the graphical user interface (GUI). This article covers the essential preparation steps, the standard terminal-based upgrade process, and alternative desktop methods to safely transition your system to the newest version.

Step 1: Prepare the System and Back Up Data

Before initiating an upgrade, back up all critical student data, configuration files, and personal documents to an external drive or cloud storage. Next, update and upgrade all existing packages to their latest versions:

sudo apt update
sudo apt full-upgrade -y
sudo apt autoremove -y

Restart your computer if any kernel or system-level updates were installed during this process.

Step 2: Configure the Release Target

Ensure the release upgrader is configured to check for the correct release type (either Long Term Support (LTS) releases or normal point releases).

Open the configuration file:

sudo nano /etc/update-manager/release-upgrades

Set the Prompt= line to:

  • lts if you only want to upgrade to the next Long Term Support version (recommended for schools and production environments).
  • normal if you wish to upgrade to any newer interim release.

Save the file and exit the editor.

Step 3: Run the Command-Line Upgrade (Recommended)

The terminal method is the most reliable approach for upgrading Edubuntu, as it minimizes graphical desktop crashes during the package migration.

  1. Ensure the update-manager-core package is installed:

    sudo apt install update-manager-core

  2. Start the upgrade process:

    sudo do-release-upgrade

    (Note: If you are upgrading shortly after a new release is published and it has not yet been enabled globally, you can force the check using sudo do-release-upgrade -d.)

  3. Follow the on-screen instructions. The installer will calculate dependencies, prompt for confirmation, and notify you of any configuration files that require manual input.

  4. When prompted to remove obsolete packages, select y (Yes) to clean up legacy dependencies.

  5. Once the process completes, confirm the system reboot.

Alternative Method: Graphical User Interface Upgrade

If you prefer using the desktop interface:

  1. Open the terminal and launch the graphical update manager: 
    update-manager -c
  2. The Software Updater window will appear, checking for updates.
  3. If a new Edubuntu version is available, a prompt will state that a new distribution release is ready.
  4. Click Upgrade... and follow the step-by-step wizard.
  5. Restart the computer once the installation finishes.

Step 4: Verify the Upgrade

After rebooting, log in to your Edubuntu desktop and confirm that the system successfully upgraded by running:

lsb_release -a

The output should reflect the target version of Ubuntu/Edubuntu. Verify that Edubuntu educational desktop meta-packages (such as edubuntu-desktop-minimal or edubuntu-desktop) remain intact and functioning properly.
