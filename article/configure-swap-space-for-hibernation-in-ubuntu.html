Configure Swap Space for Hibernation in Ubuntu

Hibernating Ubuntu requires saving the current contents of your RAM directly into swap space so the system can safely power down and restore your active session upon reboot. To make hibernation function properly, your swap space must be properly sized—generally equal to or slightly larger than your total physical memory—and the Linux kernel must be explicitly configured with the swap location and file offset via GRUB and initramfs.

1. Calculate Required Swap Size

For hibernation to succeed, your swap allocation must at least match your system's installed RAM. If your system has 16 GB of RAM, you should allocate at least 16 GB (or ideally 18–20 GB to account for existing swap usage) to prevent out-of-memory errors during the hibernation write process.

Check your current RAM and swap capacity by running:

free -h

2. Create or Resize the Swap File

If you are using a standard swap file (/swapfile), turn it off and allocate a new file using dd to ensure a contiguous block of space without fragmentation holes:

sudo swapoff -v /swapfile
sudo dd if=/dev/zero of=/swapfile bs=1G count=16 status=progress
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

(Replace count=16 with the gigabyte value that matches or exceeds your RAM).

Ensure your /etc/fstab contains the entry to mount the swap file automatically:

/swapfile none swap sw 0 0

3. Determine the Resume Device UUID and File Offset

The kernel needs the partition's Universally Unique Identifier (UUID) and the exact physical sector offset where the swap file begins.

Find the UUID of the drive hosting /swapfile:

findmnt -no UUID -T /swapfile

Find the physical swap offset:

sudo filefrag -v /swapfile | awk '{if($1=="0:"){print substr($4, 1, length($4)-2)}}'

Note both the UUID string and the numerical offset generated by these commands. (If using a dedicated swap partition instead of a swap file, you only need the partition's UUID, and the offset parameter is omitted).

4. Configure GRUB Boot Parameters

Pass the resume target to the kernel during boot:

  1. Open the GRUB configuration file:

    sudo nano /etc/default/grub

  2. Locate the line starting with GRUB_CMDLINE_LINUX_DEFAULT.

  3. Append resume=UUID=<YOUR_UUID> and resume_offset=<YOUR_OFFSET> inside the quotes:

    GRUB_CMDLINE_LINUX_DEFAULT="quiet splash resume=UUID=12345678-abcd-1234-abcd-1234567890ab resume_offset=34816"

  4. Save the file and update GRUB:

    sudo update-grub

5. Update the Initramfs Configuration

The initial RAM filesystem must be alerted to resume from the specified location:

  1. Edit or create the resume configuration file:

    sudo nano /etc/initramfs-tools/conf.d/resume

  2. Add your resume parameters:

    RESUME=UUID=12345678-abcd-1234-abcd-1234567890ab resume_offset=34816

  3. Rebuild the initramfs images for all installed kernels:

    sudo update-initramfs -u -k all

6. Test Hibernation

Reboot your computer to ensure all new boot parameters and initramfs images are loaded into the active kernel:

sudo reboot

Once rebooted, trigger hibernation via systemd:

sudo systemctl hibernate

When you power the machine back on, the bootloader will read the saved state from your swap space and restore your running applications and open files.
