Install .NET SDK on Ubuntu via Microsoft Repository

This guide provides a straightforward walkthrough for installing the .NET SDK on Ubuntu using Microsoft’s official package repository. You will learn how to add the repository to your system, run the specific command required to install the SDK, and verify that the installation was successful.

1. Register the Microsoft Package Repository

Before installing the SDK, add the Microsoft package signing key to your list of trusted keys and register the package repository.

Run the following commands according to your Ubuntu version (example using Ubuntu 22.04):

# Get Ubuntu version
declare repo_version=$(if command -v lsb_release &> /dev/null; then lsb_release -r -s; else grep -oP '(?<=^VERSION_ID=).+' /etc/os-release | tr -d '"'; fi)

# Download the Microsoft repository GPG keys
wget https://packages.microsoft.com/config/ubuntu/$repo_version/packages-microsoft-prod.deb -O packages-microsoft-prod.deb

# Register the Microsoft repository GPG keys
sudo dpkg -i packages-microsoft-prod.deb

# Delete the downloaded package file
rm packages-microsoft-prod.deb

2. Update the Package List

Refresh your local package index to include the newly added Microsoft repository:

sudo apt-get update

3. Install the .NET SDK

The command that installs the .NET SDK from the repository is apt-get install targeting the specific SDK version package, such as dotnet-sdk-8.0 for .NET 8:

sudo apt-get install -y dotnet-sdk-8.0

(Note: Replace 8.0 with your required version, such as 7.0 or 6.0, if you are targeting an older release.)

4. Verify the Installation

To confirm that the .NET SDK has been installed correctly and is accessible in your environment, run:

dotnet --version

If installed properly, this command outputs the installed version number of the .NET SDK.
