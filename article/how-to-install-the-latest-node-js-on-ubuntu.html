How to Install the Latest Node.js on Ubuntu

Installing the latest version of Node.js on Ubuntu requires using an updated repository or a version manager, as the default Ubuntu repositories often contain outdated releases. This guide provides clear, step-by-step instructions to install the current version of Node.js on Ubuntu using either the NodeSource PPA for system-wide installation or Node Version Manager (NVM) for flexible version management.

Method 1: Install Node.js via NodeSource PPA

Using the NodeSource PPA allows you to install up-to-date versions of Node.js using the standard Ubuntu apt package manager.

Step 1: Update System Packages

Open your terminal and update your local package index:

sudo apt update

Step 2: Install Prerequisites

Ensure curl is installed on your system:

sudo apt install -y curl

Step 3: Add the NodeSource Repository

Download and execute the NodeSource setup script for the current Node.js release:

curl -fsSL https://deb.nodesource.com/setup_current.x | sudo -E bash -

Step 4: Install Node.js

Install Node.js (which includes npm) using apt:

sudo apt install -y nodejs

Method 2: Install Node.js Using NVM (Recommended)

Node Version Manager (NVM) allows you to install and manage multiple Node.js versions on the same system without requiring sudo privileges.

Step 1: Install NVM

Run the official NVM installation script:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

Step 2: Update Your Environment

Activate NVM in your current terminal session:

source ~/.bashrc

(If you are using Zsh, run source ~/.zshrc instead.)

Step 3: Install the Latest Node.js Version

Install the latest available release by running:

nvm install node

To set this version as your default:

nvm use node

Verify the Installation

To confirm that Node.js and npm were installed successfully, check their version numbers:

node -v
npm -v

If the commands return version numbers, your installation is complete and ready for use.
