Redirect stdout and stderr to a File in Ubuntu

Redirecting both standard output (stdout) and standard error (stderr) to a single log file is a standard practice in Ubuntu shell scripting for debugging and auditing. By default, standard output handles regular program output, while standard error handles errors and warnings. This guide explains the core redirection operators in Bash, showing you how to combine both streams into a single destination, whether for an individual command or an entire script.

Understanding File Descriptors

In Linux, standard data streams are represented by numerical file descriptors:

  • 1: Standard Output (stdout)
  • 2: Standard Error (stderr)

When redirecting streams, you tell the shell where to route the data using these descriptors.

Method 1: The Modern Bash Operator (&>)

In modern Ubuntu environments running Bash, the simplest method to redirect both streams simultaneously is using the &> operator.

To overwrite the target file:

command &> output.log

To append to the target file without overwriting existing data:

command &>> output.log

Method 2: The POSIX-Compliant Method (> file 2>&1)

If your script uses standard sh (#!/bin/sh) or requires compatibility across different POSIX-compliant shells, use the traditional > file 2>&1 syntax.

To overwrite the target file:

command > output.log 2>&1

To append to the target file:

command >> output.log 2>&1

How it works:

  1. > output.log (or 1> output.log) redirects standard output (1) to output.log.
  2. 2>&1 redirects standard error (2) to wherever standard output (1) is currently pointing.

Note: Order matters. If you write command 2>&1 > output.log, stderr will point to the terminal (the original target of stdout) before stdout is redirected to the file.

Method 3: Redirecting an Entire Shell Script

If you want every command in an Ubuntu shell script to log both stdout and stderr automatically, place the exec command near the top of the file:

#!/bin/bash

# Overwrite log file for every command that follows
exec > /var/log/myscript.log 2>&1

echo "This message goes to the log file."
ls /nonexistent_directory # This error also goes to the log file.

To append instead of overwrite for the entire script, use:

exec >> /var/log/myscript.log 2>&1
