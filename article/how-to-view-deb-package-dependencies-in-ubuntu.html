How to View Deb Package Dependencies in Ubuntu

Understanding package dependencies is essential for managing software, troubleshooting installation errors, and maintaining a clean system in Ubuntu. This guide explains the primary command line utilities—such as apt-cache, apt, and dpkg—that allow you to view the required, recommended, and conflicting dependencies for any .deb package, whether it is in the official repositories or downloaded as a local file.

1. View Dependencies for Repository Packages (apt-cache depends)

To check the dependencies of a package available in the Ubuntu repositories before installing it, use the apt-cache depends command:

apt-cache depends <package_name>

Example:

apt-cache depends curl

This command outputs: * Depends: Packages that must be installed for the software to run. * Recommends: Packages that are optional but recommended for standard functionality. * Suggests: Optional packages that add extended features. * Conflicts/Replaces: Packages that cannot coexist with the target package.

2. Modern Alternative (apt depends)

You can also use the streamlined apt command to get a similar detailed list of dependencies:

apt depends <package_name>

Example:

apt depends vlc

3. View Dependencies for a Local .deb File (dpkg-deb)

If you have downloaded a standalone .deb package file and want to check its dependencies before installing it, use dpkg-deb with the -I (info) flag:

dpkg-deb -I /path/to/package.deb

To extract only the dependency line specifically, combine dpkg-deb with the -f flag:

dpkg-deb -f /path/to/package.deb Depends

4. View Dependencies for an Installed Package (dpkg -s)

To check the dependency details of a package that is already installed on your system, query the local dpkg database:

dpkg -s <package_name> | grep Depends

Example:

dpkg -s git | grep Depends

Summary of Commands

  • Uninstalled repository package: apt-cache depends <package>
  • Local .deb file: dpkg-deb -f <file.deb> Depends
  • Installed package: dpkg -s <package> | grep Depends
