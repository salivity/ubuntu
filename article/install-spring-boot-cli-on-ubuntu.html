Install Spring Boot CLI on Ubuntu

This guide explains how to install and configure the Spring Boot Command Line Interface (CLI) on Ubuntu to enable rapid application prototyping. By using the CLI, developers can run Groovy scripts directly from the terminal, bypassing boilerplate configuration to quickly test and deploy Spring applications.

Prerequisites

Spring Boot requires the Java Development Kit (JDK). Ensure OpenJDK 17 or later is installed on your Ubuntu system before proceeding.

Open your terminal and run:

sudo apt update
sudo apt install openjdk-17-jdk -y

Verify your Java installation:

java -version

Method 1: Install Using SDKMAN! (Recommended)

SDKMAN! is the easiest and officially recommended way to manage Spring Boot CLI versions on Unix-based systems.

  1. Install the required archive utilities:
sudo apt install curl zip unzip -y
  1. Download and install SDKMAN!:
curl -s "https://get.sdkman.io" | bash
  1. Initialize the SDKMAN! environment in your current shell:
source "$HOME/.sdkman/bin/sdkman-init.sh"
  1. Install the Spring Boot CLI:
sdk install springboot
  1. Confirm the installation was successful:
spring --version

Method 2: Manual Installation via Tarball

If you prefer not to use SDKMAN!, you can install the CLI manually using the official distribution archive.

  1. Download the latest Spring Boot CLI binary distribution:
wget https://repo.spring.io/release/org/springframework/boot/spring-boot-cli/3.2.0/spring-boot-cli-3.2.0-bin.tar.gz
  1. Extract the archive:
tar -xzf spring-boot-cli-3.2.0-bin.tar.gz
  1. Move the extracted directory to /opt:
sudo mv spring-3.2.0 /opt/spring
  1. Create a symbolic link to add the spring executable to your system's PATH:
sudo ln -s /opt/spring/bin/spring /usr/local/bin/spring
  1. Verify the installation:
spring --version

Testing Rapid Prototyping

To test your new setup, create a single-file REST application using Groovy.

  1. Create a file named app.groovy:
cat <<EOF > app.groovy
@RestController
class HelloController {
    @GetMapping("/")
    String hello() {
        return "Spring Boot CLI is running successfully on Ubuntu!"
    }
}
EOF
  1. Run the application using the Spring Boot CLI:
spring run app.groovy

The CLI automatically handles dependencies, downloads necessary embedded containers, and boots the application. Open a web browser or run curl http://localhost:8080 in another terminal window to view the running application.
