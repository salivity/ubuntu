How to View Process Memory Mapping in Ubuntu

In Ubuntu Linux, analyzing how an active process allocates and uses system memory is crucial for debugging and system administration. The dedicated command to view the detailed memory mapping of a specific process is pmap. This article explains how to use pmap effectively, locate process IDs, and read alternative raw memory files directly from the Linux /proc filesystem.

Using the pmap Command

The pmap utility displays the memory map of a running process, showing its virtual memory allocation, shared libraries, heap, and stack usage.

To view a standard memory map:

pmap <PID>

To view a detailed output showing Extended memory usage (including Resident Set Size, Dirty memory, and Swapped memory):

pmap -x <PID>

To display maximum detail on modern Linux systems:

pmap -XX <PID>

Replace <PID> with the actual Process ID of the application you want to inspect.

Finding the Process ID (PID)

Before running pmap, you need the target process’s PID. You can find it using pgrep or ps:

pgrep <process_name>

Alternatively:

ps aux | grep <process_name>

Alternative Method: Using the /proc Filesystem

The pmap tool fetches its information directly from the /proc virtual filesystem. You can view this data manually without using pmap.

To view basic memory mappings:

cat /proc/<PID>/maps

To view a highly detailed breakdown for each mapping range (including page sizes, shared memory, and private memory):

cat /proc/<PID>/smaps

Key Output Fields Explained

When reading detailed output from pmap -x, key columns include:

  • Address: The starting memory address of the allocated segment.
  • Kbytes: The total size of the memory segment in kilobytes.
  • RSS (Resident Set Size): The actual amount of physical RAM allocated to this segment.
  • Dirty: Modified memory pages that differ from what is stored on disk.
  • Mode: Permissions for the memory segment (r for read, w for write, x for execute, s for shared, p for private).
  • Mapping: The shared library, binary file, stack, or heap associated with the memory address.
