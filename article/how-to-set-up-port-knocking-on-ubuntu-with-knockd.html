How to Set Up Port Knocking on Ubuntu with knockd

This guide explains how to secure an Ubuntu server by hiding the SSH port behind a port-knocking sequence using knockd. Port knocking keeps your SSH port closed to public scans until a specific sequence of network connection attempts (knocks) is received from a client IP address. Once the correct sequence is processed, knockd temporarily opens the firewall for that IP address, drastically reducing brute-force attacks and port discovery by automated bots.

Step 1: Install knockd

Update your package index and install knockd on your Ubuntu server:

sudo apt update
sudo apt install knockd -y

Step 2: Identify the Network Interface

knockd needs to listen to your server's active network interface. Run the following command to find it:

ip -br link

Note the interface name connected to your public or local network (commonly eth0, ens3, or enp0s3).

Step 3: Configure knockd

Open the configuration file /etc/knockd.conf in your preferred text editor:

sudo nano /etc/knockd.conf

Replace or adjust the default configuration to define your custom knock sequences and firewall rules. Below is a standard configuration using iptables:

[options]
    UseSyslog

[openSSH]
    sequence    = 7000,8000,9000
    seq_timeout = 10
    command     = /sbin/iptables -I INPUT -s %IP% -p tcp --dport 22 -j ACCEPT
    tcpflags    = syn

[closeSSH]
    sequence    = 9000,8000,7000
    seq_timeout = 10
    command     = /sbin/iptables -D INPUT -s %IP% -p tcp --dport 22 -j ACCEPT
    tcpflags    = syn
  • sequence: The sequence of ports to knock (change these to secret numbers of your choosing between 1 and 65535).
  • seq_timeout: The duration in seconds within which the entire knock sequence must be completed.
  • command: The firewall command executed when the sequence succeeds. %IP% is automatically replaced with the client's IP address.
  • tcpflags: The TCP flag type to listen for (typically syn).

Save and close the file.

Step 4: Enable the Daemon

Edit the /etc/default/knockd file to allow the service to start automatically:

sudo nano /etc/default/knockd

Update the configuration to enable the service and set your network interface:

START_KNOCKD=1
KNOCKD_OPTS="-i eth0"

(Replace eth0 with the network interface identified in Step 2.)

Save the file and start the service:

sudo systemctl daemon-reload
sudo systemctl enable knockd
sudo systemctl restart knockd

Check the status to ensure it is running properly:

sudo systemctl status knockd

Step 5: Lock Down Port 22

Before modifying firewall rules, keep your current SSH session open in case of configuration errors.

If using UFW (Uncomplicated Firewall), delete any existing rule that allows SSH globally:

sudo ufw delete allow 22/tcp
sudo ufw delete allow OpenSSH

Ensure UFW is enabled and default incoming traffic is denied:

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw reload

If you are managing raw iptables directly instead of UFW, block inbound SSH by default:

sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 22 -j DROP

Step 6: Test from a Client Machine

On your client device, install a knock utility:

  • Debian/Ubuntu: sudo apt install knockd
  • macOS: brew install knock

Send the opening sequence to your server's IP:

knock <server_ip_address> 7000 8000 9000

Connect to your server via SSH:

ssh user@<server_ip_address>

When you finish your session, close the port by sending the closing knock sequence:

knock <server_ip_address> 9000 8000 7000
