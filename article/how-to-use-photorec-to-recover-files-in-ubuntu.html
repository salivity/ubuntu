How to Use PhotoRec to Recover Files in Ubuntu

PhotoRec is a powerful, open-source data recovery tool designed to carve deleted files from damaged, corrupted, or reformatted storage devices in Ubuntu. Unlike traditional recovery tools that rely on the operating system’s file system metadata, PhotoRec scans the underlying raw data sectors directly to identify and restore lost files based on known file signatures. This article explains the core role of PhotoRec in file carving, how it bypasses corrupted file systems, and the essential steps to execute file recovery on an Ubuntu system.

What Is File Carving in PhotoRec?

File carving is a recovery technique that extracts raw data from a disk without utilizing the file system’s structure. When a disk becomes corrupted, the file system metadata—such as the inode table in ext4 or the Master File Table (MFT) in NTFS—often becomes unreadable or overwritten. PhotoRec ignores these damaged allocation structures entirely. Instead, it reads the disk block by block, searching for specific byte patterns, known as file headers and footers, that mark the beginning and end of recognized file types.

The Role of PhotoRec on Corrupted Disks

PhotoRec plays a critical role in data recovery on Ubuntu when normal drive mounting or directory browsing fails. Its primary roles include:

  • Bypassing File System Corruption: Because PhotoRec treats the drive as a raw stream of bytes, severe file system corruption, partition loss, or accidental reformatting does not prevent it from extracting data.
  • Read-Only Safety: PhotoRec accesses the target drive or disk image in read-only mode. It strictly requires you to save recovered files to a separate, healthy drive, preventing accidental overwriting of unrecovered data.
  • Extensive File Type Support: It recognizes hundreds of file extensions across over 300 file families, including documents, archives, multimedia files, and databases.

How to Run PhotoRec in Ubuntu

Using PhotoRec in Ubuntu involves a terminal-based interface requiring administrative privileges to access raw block devices:

  1. Install PhotoRec: PhotoRec is bundled with the testdisk package. Install it via the terminal: sudo apt update && sudo apt install testdisk

  2. Launch the Tool: Open the interface with root access: sudo photorec

  3. Select the Disk: Choose the corrupted drive from the list of detected storage devices.

  4. Select the Partition and File System: Choose the corrupted partition, then specify the file system type (select ext2/ext3/ext4 for native Linux partitions or Other for FAT/NTFS/exFAT).

  5. Choose Search Options: Decide whether to scan only unallocated space (for recently deleted files) or the entire partition (for corrupted file systems).

  6. Set Destination: Select a directory on a different, non-corrupted storage device to store the carved output.

  7. Execute Recovery: Start the process. PhotoRec will continuously scan sectors, carve out recognized files, and place them into the designated destination directory.
