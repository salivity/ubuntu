Export NFS Share Immediately in Ubuntu Without Reboot

This guide explains how to dynamically export a directory as a Network File System (NFS) share in Ubuntu without rebooting the system or interrupting active client connections. By using the built-in exportfs utility, administrators can update the kernel's export table instantly, ensuring newly configured directories and modified access permissions take effect immediately.

The Immediate Export Command

To export all configured directories immediately without rebooting, run the following command with root privileges:

sudo exportfs -ra

How the Command Works

The exportfs command maintains the table of local physical file systems exported to NFS clients:

  • -r (Re-export): Re-exports all directories by synchronizing /etc/exports and files in /etc/exports.d/ with /var/lib/nfs/etab. It removes stale entries that no longer exist in the configuration and applies any modifications to existing shares.
  • -a (All): Causes all directories listed in the exports configuration to be exported or unexported.
  • -v (Verbose - optional): You can append v (i.e., sudo exportfs -rav) to display a detailed list of shares and their active options as they are being exported.

Step-by-Step Implementation

  1. Define the Share: Open the exports configuration file:

    sudo nano /etc/exports

    Add the directory path, client IP/subnet, and desired permissions:

    /mnt/data 192.168.1.0/24(rw,sync,no_subtree_check)

  2. Apply the Changes: Run the reload command to export the directory immediately:

    sudo exportfs -ra

  3. Verify the Export: Confirm that the directory is actively shared by running:

    sudo exportfs -v

    This displays the complete list of active exports along with their applied NFS parameters. Active client mounts remain intact during this process, avoiding service disruption.
