Change Ubuntu Hostname Without Reboot Using hostnamectl

Changing the hostname on an Ubuntu system allows you to identify your machine easily across a network without causing downtime. By using the hostnamectl command, part of the systemd suite, you can instantly update the static, transient, and pretty hostnames in real-time. This guide explains how to check your current hostname, apply a new hostname immediately without rebooting, and update the necessary configuration files to maintain local system stability.

Step 1: Check Your Current Hostname

Before making any changes, verify your current hostname settings by running the following command in your terminal:

hostnamectl

This command displays your active static hostname along with details about your operating system, kernel version, and architecture.

Step 2: Set the New Hostname

To change the system hostname dynamically, use the set-hostname option followed by your new desired hostname. Replace new-hostname with your preferred name:

sudo hostnamectl set-hostname new-hostname

Executing this command instantly updates the static hostname in the /etc/hostname file as well as the transient hostname stored in system memory, eliminating the need for a system reboot.

Step 3: Update the /etc/hosts File

To prevent networking issues, command execution delays, or sudo errors, you must map the new hostname locally in your hosts file.

  1. Open the /etc/hosts file using a text editor:
sudo nano /etc/hosts
  1. Find the entry associated with 127.0.1.1 (or 127.0.0.1):
127.0.1.1   old-hostname

  1. Replace old-hostname with your new-hostname.

  2. Save the file and exit the editor (in Nano, press Ctrl+O, hit Enter, and then press Ctrl+X).

Step 4: Verify the Update

Confirm that your new hostname is active by running the verification command:

hostnamectl

To see the updated hostname reflected in your command prompt line, simply log out and log back in, or open a new terminal session.
