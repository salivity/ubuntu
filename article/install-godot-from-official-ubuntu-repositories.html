Install Godot from Official Ubuntu Repositories

This guide provides a straightforward walkthrough on how to install the Godot game engine directly from the official Ubuntu repositories using the APT package manager. You will learn the terminal commands necessary to enable the required repository, update your system index, install the Godot package, launch the editor, and remove the software if desired.

Step 1: Enable the Universe Repository

Godot is hosted in Ubuntu's "Universe" repository, which contains community-maintained open-source software. To ensure this repository is enabled on your system, open your terminal (Ctrl+Alt+T) and run:

sudo add-apt-repository universe

Step 2: Update Package Lists

Before installing any new software, refresh your local package index to ensure you retrieve the latest version information available in the repositories:

sudo apt update

Step 3: Install Godot

Ubuntu repositories typically package the stable 3.x branch under the package name godot3. To install the Godot engine along with all necessary dependencies, execute the following command:

sudo apt install godot3

Confirm the installation by pressing Y and hitting Enter when prompted.

Step 4: Launch the Godot Engine

Once the installation is complete, you can launch Godot in two ways:

  1. From the Terminal: Type the command below and press Enter: 
    godot3
  2. From the Desktop Environment: Open your system's application menu (press the Super/Windows key), type Godot, and click on the Godot application icon.

How to Uninstall Godot

If you ever need to remove the Godot engine from your Ubuntu system, run:

sudo apt remove godot3

To also remove any unused dependencies that were installed with Godot, run:

sudo apt autoremove
