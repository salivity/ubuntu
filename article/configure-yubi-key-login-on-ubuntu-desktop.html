Configure YubiKey Login on Ubuntu Desktop

Securing your Ubuntu workstation with multi-factor authentication significantly reduces the risk of unauthorized physical access. This guide provides a step-by-step walkthrough for configuring Pluggable Authentication Modules (PAM) to require a hardware YubiKey via the FIDO2/U2F standard alongside your password to log in to the Ubuntu desktop environment.

Prerequisites

  • An Ubuntu desktop installation (20.04 LTS, 22.04 LTS, or newer).
  • A functional YubiKey supporting FIDO/U2F.
  • Sudo privileges on the machine.

Step 1: Install Required Dependencies

Ubuntu provides the Universal 2nd Factor (U2F) PAM module within its default repositories. Open a terminal and install the module:

sudo apt update
sudo apt install libpam-u2f -y

Step 2: Register Your YubiKey

You must associate your YubiKey with your Ubuntu user account by creating an authentication configuration file.

  1. Insert your YubiKey into an available USB port.
  2. Create the configuration directory:
mkdir -p ~/.config/Yubico
  1. Generate the key mapping using the pamu2fcfg utility:
pamu2fcfg > ~/.config/Yubico/u2f_keys

When your YubiKey begins flashing, touch the metal contact to complete the registration.

(Optional) If you have a backup YubiKey, insert it and append its credentials to the same file:

pamu2fcfg -n >> ~/.config/Yubico/u2f_keys

Step 3: Test PAM Configuration with Sudo

Before altering the desktop login manager, test the configuration on the sudo service to ensure your key works properly and prevent accidental lockouts.

  1. Open /etc/pam.d/sudo in a text editor:
sudo nano /etc/pam.d/sudo
  1. Add the following line directly after @include common-auth:
auth required pam_u2f.so
  1. Save and exit (Ctrl+O, Enter, Ctrl+X).
  2. Open a new terminal window (keep the original open) and run:
sudo -k
sudo ls

Enter your password. When prompted (or when the key flashes), touch your YubiKey. If authentication succeeds, the module is working correctly.

Step 4: Enforce YubiKey for Desktop Login

Ubuntu uses the GNOME Display Manager (GDM) by default. To require the YubiKey at the desktop login screen:

  1. Open the GDM password configuration file:
sudo nano /etc/pam.d/gdm-password
  1. Locate the line containing @include common-auth. Add the U2F module line immediately below it:
auth required pam_u2f.so

Note: Placing auth required pam_u2f.so after @include common-auth ensures the system prompts for your user password first, followed by a request to touch the YubiKey.

  1. Save and close the file.

Step 5: Verify the Setup

  1. Keep a terminal session open with root or sudo access.
  2. Lock your desktop screen (Super + L).
  3. Enter your password to unlock. The YubiKey should flash; tap it to gain access.
  4. If authentication fails, switch to a virtual terminal (Ctrl + Alt + F3), log in, and revert changes in /etc/pam.d/gdm-password.
