How to Set Up a Dummy Network Interface in Ubuntu

Configuring a dummy network interface in Ubuntu provides a virtual network device useful for testing, routing, local service binding, and isolating traffic without requiring physical network hardware. This guide outlines the exact process for creating a temporary dummy interface using the ip tool, as well as making the interface configuration persistent across system reboots using Netplan and kernel module configurations.

Step 1: Load the Dummy Kernel Module

Before creating a dummy interface, ensure the Linux kernel dummy module is loaded.

Run the following command to load the module:

sudo modprobe dummy

To ensure the dummy module automatically loads upon boot, append dummy to the /etc/modules file:

echo "dummy" | sudo tee -a /etc/modules

Step 2: Create a Temporary Dummy Interface

If you only need a temporary virtual interface that does not survive a system restart, use the iproute2 toolset.

  1. Create the dummy interface:

    sudo ip link add dummy0 type dummy

  2. Assign an IP address to the interface:

    sudo ip addr add 192.168.50.1/24 dev dummy0

  3. Bring the interface online:

    sudo ip link set dev dummy0 up

  4. Verify the configuration:

    ip addr show dummy0

Step 3: Configure a Persistent Dummy Interface with Netplan

Modern Ubuntu versions use Netplan for network configuration. To ensure your dummy interface persists after a reboot, configure it in Netplan.

  1. Create or edit a Netplan configuration file:

    sudo nano /etc/netplan/99-dummy-interface.yaml

  2. Add the following YAML configuration:

    network:
  version: 2
  renderer: networkd
  ethernets:
    dummy0:
      addresses:
        - 10.10.10.1/24

  3. Set the correct permissions on the file:

    sudo chmod 600 /etc/netplan/99-dummy-interface.yaml

  4. Apply the configuration:

    sudo netplan apply

Step 4: Verify the Setup

Check that the dummy interface is active and properly configured with your assigned IP address:

ip a show dev dummy0

You can test local connectivity to the interface by pinging the configured IP address:

ping -c 3 10.10.10.1

Removing a Dummy Interface

To manually delete a temporary dummy interface, run:

sudo ip link delete dummy0 type dummy

To remove a persistent dummy interface, delete the created Netplan file (/etc/netplan/99-dummy-interface.yaml) and run sudo netplan apply.
