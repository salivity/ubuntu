How to Change Process Priority with Renice in Ubuntu

The renice command in Ubuntu allows users and system administrators to modify the scheduling priority of already running processes. By altering a process’s “nice” value, you can dynamically adjust how much CPU time the kernel allocates to it without restarting the application. This guide covers the fundamentals of process priority in Linux, the syntax of the renice command, and practical examples for changing priorities by Process ID (PID), user, or process group.

Understanding Nice Values

In Ubuntu and other Linux distributions, process priority is represented by a “nice” value ranging from -20 to 19:

  • -20: Highest priority (the process gets the most CPU time).
  • 0: Default priority for newly launched processes.
  • 19: Lowest priority (the process yields CPU time to other tasks).

Note: Regular users can only lower a process’s priority (increase its nice value). Assigning a higher priority (a lower or negative nice value) requires root privileges using sudo.

Step 1: Find the Process ID (PID)

Before changing a process’s priority, you need its PID. You can find running processes using tools like ps, pgrep, or top.

To find the PID of a specific program (e.g., firefox), run:

pgrep firefox

Alternatively, list all running processes with their current nice values (NI column):

ps -eo pid,ni,comm | grep firefox

Step 2: Use the Renice Command

The basic syntax for the renice command is:

renice [priority_value] -p [PID]

Example 1: Lower Process Priority (Increase Nice Value)

To set the nice value of PID 1234 to 10 (making it less of a CPU priority):

renice 10 -p 1234

Example 2: Raise Process Priority (Decrease Nice Value)

To give a process higher CPU priority (e.g., setting the nice value to -5), use sudo:

sudo renice -5 -p 1234

Advanced Usage of Renice

Change Priority for All Processes of a Specific User

To change the priority of every process owned by a specific user, use the -u flag:

sudo renice 5 -u username

Change Priority for a Process Group

To alter the priority for an entire process group ID (PGID), use the -g flag:

sudo renice 5 -g 5678

Verifying the Priority Change

To confirm that the priority has been successfully updated, check the process status again:

ps -o pid,ni,cmd -p 1234

The output will display the updated nice value in the NI column.
