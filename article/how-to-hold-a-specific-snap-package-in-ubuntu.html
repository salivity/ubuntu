How to Hold a Specific Snap Package in Ubuntu

By default, Ubuntu's Snap daemon (snapd) automatically refreshes installed packages in the background multiple times per day to ensure system security and stability. However, you can prevent specific snap packages from updating automatically by using the native hold functionality available in modern versions of snapd. This guide outlines how to hold individual snaps indefinitely, hold them for a temporary duration, check their hold status, and release the hold when you are ready to resume updates.

Check Your snapd Version

The ability to hold snap updates requires snapd version 2.58 or later. Verify your current version by running:

snap version

Ensure the snapd version listed is 2.58 or higher. If it is outdated, update your system using standard package manager commands before proceeding.

Hold a Specific Snap Indefinitely

To indefinitely prevent a specific snap from receiving automatic updates, run the snap refresh command with the --hold flag:

sudo snap refresh --hold <package-name>

Replace <package-name> with the actual name of the snap you wish to pin (for example, sudo snap refresh --hold firefox). This halts automatic background updates for that package until you explicitly unhold it.

Hold a Specific Snap for a Specified Time

If you only want to freeze a snap temporarily (for example, to test stability or bypass a known bug), you can define a specific hold duration using hours (h) or days (d):

sudo snap refresh --hold=72h <package-name>

or

sudo snap refresh --hold=14d <package-name>

Once the designated duration expires, snapd will automatically resume regular updates for the package.

Verify the Hold Status

To confirm that the package is held and see when updates will resume, check the snap's information details:

snap info <package-name>

Look for the hold: line in the output. If the package is held indefinitely, it will display forever. If it has a timed hold, it will state the exact timestamp when the hold will expire.

Alternatively, to see an overview of refresh timers and all held packages across your system, run:

snap refresh --time

Unhold a Snap Package

When you are ready to allow the package to update automatically again, remove the hold with the --unhold flag:

sudo snap refresh --unhold <package-name>

Once released, the snap will return to its standard update schedule and refresh during the next automated cycle, or immediately if you execute a manual sudo snap refresh <package-name>.
