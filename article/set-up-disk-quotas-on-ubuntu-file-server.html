Set Up Disk Quotas on Ubuntu File Server

Setting up a quota system on an Ubuntu file server allows administrators to control and limit the amount of storage space and the total number of files individual users or groups can consume. This guide walks through installing the necessary quota tools, modifying filesystem mount options, turning on quota tracking, and setting hard and soft storage limits for specific accounts.

Step 1: Install Quota Tools

Update your package list and install the Linux quota management packages:

sudo apt update
sudo apt install quota quota-doc -y

Step 2: Configure Filesystem Mount Options

To track disk usage, you must enable quotas on the specific partition where your user data resides (e.g., / or /home).

  1. Open the filesystem table file:

    sudo nano /etc/fstab

  2. Locate the partition line you want to manage. Add usrquota (for user quotas) and/or grpquota (for group quotas) to the mount options.

    Example default entry:

    UUID=xxxx-xxxx-xxxx / ext4 defaults 0 1

    Modified entry:

    UUID=xxxx-xxxx-xxxx / ext4 defaults,usrquota,grpquota 0 1

  3. Save and close the file.

Step 3: Remount the Filesystem

Apply the changes by remounting the modified partition without rebooting:

sudo mount -o remount /

Verify that the options are active:

cat /proc/mounts | grep quota

Step 4: Initialize and Turn On Quotas

  1. Create the database files (aquota.user and aquota.group) used to track usage:

    sudo quotacheck -ugm /
    • -u: Checks user quotas
    • -g: Checks group quotas
    • -m: Forces check on a read-write mounted filesystem

  2. Enable the quota system:

    sudo quotaon -v /

Step 5: Assign Disk Quotas to Users

You can set disk space limits (block usage) and file number limits (inodes) using edquota or setquota.

Method A: Interactive Setup

Open the quota editor for a specific user:

sudo edquota -u username

You will see a text interface similar to this:

Disk quotas for user username (uid 1001):
  Filesystem  blocks  soft  hard  inodes  soft  hard
  /dev/sda1    100      0     0       15     0     0
  • blocks: Current space used (in 1K blocks).
  • soft (space): The limit a user can exceed temporarily during a grace period (e.g., 5000000 for ~5GB).
  • hard (space): The absolute maximum space allowed (e.g., 5242880 for 5GB).
  • soft/hard (inodes): The soft and hard limits for total number of files created.

Set your desired limits in the soft and hard columns, then save and exit.

Method B: Command-Line Setup

To set quota limits directly without opening an editor:

sudo setquota -u username <soft_block> <hard_block> <soft_inode> <hard_inode> /

Example (sets a 5GB hard limit and 4.5GB soft limit, with no file count limit):

sudo setquota -u username 4718592 5242880 0 0 /

Step 6: Verify Quota Configurations

  • View a summary of usage and limits for a single user:

    sudo quota -vs username

  • View a full report of all users on a specific filesystem:

    sudo repquota -s /
