Format Azure Resource Disk with waagent on Ubuntu

This article explains how to configure the Azure Linux Agent (waagent) to automatically format, partition, and mount the ephemeral resource disk on an Ubuntu virtual machine. By modifying the agent's configuration file, administrators can specify their preferred filesystem, custom mount points, and swap file sizes to ensure consistent disk setup across VM reboots and reprovisioning events.

Understanding the Azure Resource Disk

Azure Virtual Machines include a temporary resource disk (typically recognized as /dev/sdb). This storage is non-persistent and intended for temporary data, page files, or swap space. Because this disk resets whenever a VM is stopped (deallocated) or resized, configuring the Azure Linux Agent to manage it dynamically ensures it is automatically mounted and formatted with the desired parameters upon every boot.

Step 1: Back Up Current Mounts

Before altering the agent configuration, check if the resource disk is currently mounted by default (usually at /mnt or /mnt/resource) and unmount it to prevent conflicts.

  1. Check current disk usage: 
    df -h
  2. If mounted to /mnt, unmount the filesystem: 
    sudo umount /mnt

Step 2: Configure waagent.conf

The behavior of the resource disk is governed by the configuration file located at /etc/waagent.conf.

Open the file in a text editor with administrative privileges:

sudo nano /etc/waagent.conf

Locate and update the following directives to match your storage requirements:

  • ResourceDisk.Format: Set to y to allow the agent to format the disk. 
    ResourceDisk.Format=y
  • ResourceDisk.Filesystem: Define the filesystem type (e.g., ext4 or xfs). 
    ResourceDisk.Filesystem=ext4
  • ResourceDisk.MountPoint: Set the target directory path where the disk will be mounted. 
    ResourceDisk.MountPoint=/mnt/resource
  • ResourceDisk.MountOptions: Specify mount options if required (optional, defaults to standard options). 
    ResourceDisk.MountOptions=None
  • ResourceDisk.EnableSwap: Enable swap creation on the resource disk if needed. 
    ResourceDisk.EnableSwap=y
  • ResourceDisk.SwapSizeMB: Specify the swap file size in megabytes (e.g., 4096 for 4 GB). 
    ResourceDisk.SwapSizeMB=4096

Save and close the file.

Step 3: Apply the Configuration

For the changes to take effect without rebooting the system, restart the Azure Linux Agent service:

sudo systemctl restart walinuxagent.service

Alternatively, you can restart the virtual machine:

sudo reboot

Step 4: Verify the Configuration

Once the agent restarts, verify that the resource disk is partitioned, formatted, and mounted to the specified path:

lsblk

Inspect the mount point and available space:

df -h -T /mnt/resource

If swap was configured, confirm that the swap file is active:

swapon --show
