Setup Weekly Automated Rsync Backup in Ubuntu

Automating system backups is essential for data security and disaster recovery on any Linux system. This guide demonstrates how to create a custom shell script utilizing rsync to sync data between directories or to a remote destination, and how to schedule this script to run automatically every week using Ubuntu's built-in cron daemon.

Step 1: Ensure Rsync is Installed

Rsync is usually pre-installed on Ubuntu. Verify its presence or install it by opening your terminal and running:

sudo apt update
sudo apt install rsync -y

Step 2: Create the Backup Script

Create a directory to store your custom maintenance scripts, then generate a new bash script file:

sudo nano /usr/local/bin/weekly_rsync_backup.sh

Paste the following script into the editor. Replace /path/to/source/ with the directory you want to back up, and /path/to/destination/ with your target backup directory (such as a mounted external drive or network share):

#!/bin/bash

# Configuration variables
SOURCE="/path/to/source/"
DESTINATION="/path/to/destination/"
LOGFILE="/var/log/rsync_backup.log"

# Create a timestamp
echo "=== Backup started on $(date) ===" >> "$LOGFILE"

# Execute rsync
# -a: archive mode (preserves permissions, symlinks, timestamps)
# -v: verbose output
# -z: compress file data during the transfer
# --delete: remove files in destination that no longer exist in source
rsync -avz --delete "$SOURCE" "$DESTINATION" >> "$LOGFILE" 2>&1

# Completion status
if [ $? -eq 0 ]; then
    echo "Backup completed successfully on $(date)" >> "$LOGFILE"
else
    echo "Backup failed on $(date)" >> "$LOGFILE"
fi

echo "==========================================" >> "$LOGFILE"

Save the file and exit the editor (in nano, press CTRL + O, Enter, then CTRL + X).

Step 3: Grant Execution Permissions

Make the script executable by running:

sudo chmod +x /usr/local/bin/weekly_rsync_backup.sh

Test the script manually to ensure there are no syntax or path errors:

sudo /usr/local/bin/weekly_rsync_backup.sh

Verify that the files were copied to the destination folder and check /var/log/rsync_backup.log to review the output.

Step 4: Schedule the Script with Cron

To automate the script to run once a week, edit the root crontab:

sudo crontab -e

If prompted, select your preferred text editor.

Add the following line to the bottom of the file to schedule the backup every Sunday at 02:00 AM:

0 2 * * 0 /usr/local/bin/weekly_rsync_backup.sh

Alternatively, you can use the predefined cron keyword:

@weekly /usr/local/bin/weekly_rsync_backup.sh

Save and exit the crontab editor. The cron service will immediately pick up the schedule, executing your rsync backup weekly without requiring a system restart.
