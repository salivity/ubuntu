How to Patch the Linux Kernel on Ubuntu

Applying a kernel patch on Ubuntu involves downloading the Linux kernel source code, matching it with the appropriate patch file, testing the patch safely using a dry run, and applying the changes using the patch command. Once the modifications are cleanly incorporated into the source tree, you can configure and compile your custom kernel binary. This guide outlines the exact terminal commands required to prepare the environment, apply the patch, and build the modified kernel.

Step 1: Install Required Dependencies

Ensure your package list is updated and install the essential build utilities and libraries required to compile the Linux kernel:

sudo apt update
sudo apt install build-essential libncurses-dev bison flex libssl-dev libelf-dev bc git

Step 2: Acquire the Kernel Source and Patch File

Navigate to your working directory and obtain the matching kernel source tree. For example, if you are downloading directly from kernel.org:

cd /usr/src
sudo wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.8.tar.xz
sudo tar -xf linux-6.8.tar.xz
cd linux-6.8

Place your patch file (e.g., feature-fix.patch) in an accessible directory, such as ~ or within the root of the source directory.

Step 3: Test the Patch (Dry Run)

Before modifying the code, run a dry run to ensure the patch applies cleanly without conflicts:

patch -p1 --dry-run < /path/to/feature-fix.patch
  • -p1: Instructs the patch command to strip the first leading directory slash from file paths specified in the patch file, which is standard for kernel source trees.
  • If the output reports no failed hunks (FAILED), the patch is compatible with your source tree.

Step 4: Apply the Patch

Run the command without the --dry-run flag to permanently apply the modifications:

patch -p1 < /path/to/feature-fix.patch

If you encounter any .rej (rejected) files, the patch failed to apply to specific sections of the code, indicating a version mismatch that requires manual resolution.

Step 5: Configure and Compile the Kernel

  1. Copy Existing Kernel Configuration: Reuse your active Ubuntu configuration to maintain hardware compatibility:

    cp /boot/config-$(uname -r) .config
make olddefconfig

  2. Disable Debug Signatures (Ubuntu-Specific): Ubuntu's default config requires signing keys that do not exist in standard source trees. Disable them to prevent build errors:

    scripts/config --disable SYSTEM_TRUSTED_KEYS
scripts/config --disable SYSTEM_REVOCATION_KEYS

  3. Compile the Kernel: Build the kernel and modules using all available CPU threads:

    make -j$(nproc)

  4. Install the Modules and Kernel: After the compilation completes successfully, install the modules and copy the new kernel images into /boot:

    sudo make modules_install
sudo make install

  5. Update Bootloader and Reboot: Refresh GRUB so it detects your newly patched kernel, then restart the system:

    sudo update-grub
sudo reboot

After rebooting, run uname -r or uname -a to confirm your system is running the newly compiled, patched kernel.
