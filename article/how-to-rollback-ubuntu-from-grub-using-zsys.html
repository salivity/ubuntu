How to Rollback Ubuntu from GRUB Using Zsys

Ubuntu installations configured with ZFS on root automatically manage system states using zsys, a background tool that takes snapshots before and after major operations like system updates. If an update causes system instability, driver issues, or failure to boot, you can revert the entire operating system to a previous, fully functional snapshot directly from the GRUB boot menu without needing external rescue media.

Prerequisites

To perform this rollback, your system must have been installed using the ZFS file system (available via the advanced features section during Ubuntu installation). If your installation uses the standard ext4 file system, zsys snapshots will not be available in GRUB.

Step 1: Access the GRUB Boot Menu

  1. Restart or power on your computer.
  2. Immediately access the GRUB menu:
    • For UEFI systems: Tap the Esc key repeatedly right after the motherboard logo appears.
    • For BIOS/Legacy systems: Hold down the Shift key immediately as the system starts.
  3. Keep tapping until the GNU GRUB menu appears on the screen.

Step 2: Navigate to History Snapshots

  1. In the GRUB menu, use the arrow keys to navigate down to History for Ubuntu ... and press Enter.
  2. You will see a chronological list of saved states labeled with the kernel version, date, and timestamp of when the snapshot was taken.
  3. Identify the state you wish to restore:
    • Select a state taken before the issue or update occurred.
    • Highlight that entry and press Enter.

Step 3: Choose the Rollback Type

After selecting a point in time, GRUB provides two distinct rollback choices:

  • Revert system state only: Restores the system files, packages, and kernel back to that point in time while keeping your personal user files in /home completely untouched. This is the recommended option for fixing broken updates.
  • Revert system state and user data: Restores both the operating system and all files in /home to the exact state they were in when the snapshot was created. Any documents, downloads, or settings created after that snapshot will be lost.

Highlight your preferred choice and press Enter. Ubuntu will boot into the selected snapshot.

Step 4: Verify the System State

Once the desktop or login screen loads:

  1. Log in to your account.
  2. Open the terminal and verify that the system is operating properly under the restored environment.
  3. You can inspect your active and past system states using the zsysctl command: 
    zsysctl state list

Because zsys automatically promotes the booted snapshot to the primary boot environment, the system will continue to boot into this restored state on subsequent restarts. You can now investigate the cause of the failure or run updates selectively.
