Configure IP Forwarding on Ubuntu to Act as a Router

Configuring an Ubuntu system as a router involves enabling IPv4 packet forwarding in the Linux kernel, identifying your network interfaces, and setting up Network Address Translation (NAT) using firewall rules. This guide covers how to enable kernel IP forwarding both temporarily and permanently, configure iptables rules to route traffic between network interfaces, and ensure these network settings persist across system reboots.

Step 1: Enable Kernel IP Forwarding

By default, Ubuntu disables packet forwarding between network interfaces for security reasons. You must enable this feature in the Linux kernel.

Enable IP Forwarding Temporarily

To activate IP forwarding immediately without rebooting, run:

sudo sysctl -w net.ipv4.ip_forward=1

Enable IP Forwarding Permanently

To ensure IP forwarding remains enabled after a system reboot, edit the system control configuration file:

  1. Open /etc/sysctl.conf in a text editor:

    sudo nano /etc/sysctl.conf

  2. Locate the following line and remove the leading # to uncomment it:

    net.ipv4.ip_forward=1

  3. Save and close the file.

  4. Apply the changes immediately:

    sudo sysctl -p

Step 2: Identify Network Interfaces

Determine which network interfaces connect to your external network (WAN) and internal network (LAN).

List all available interfaces:

ip link show

For this guide: * eth0 represents the WAN interface (connected to the Internet). * eth1 represents the LAN interface (connected to the internal network).

Replace these names with your actual interface names in the following steps.

Step 3: Configure NAT with Iptables

Network Address Translation (NAT) allows devices on your internal network to share your Ubuntu server’s single public or external IP address.

  1. Enable IP Masquerading on the WAN interface:

    sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

  2. Allow traffic forwarding from LAN to WAN:

    sudo iptables -A FORWARD -i eth1 -o eth0 -j ACCEPT

  3. Allow established and related returning traffic from WAN to LAN:

    sudo iptables -A FORWARD -i eth0 -o eth1 -m state --state RELATED,ESTABLISHED -j ACCEPT

Step 4: Make Iptables Rules Persistent

Standard iptables rules reset when the system reboots. Use iptables-persistent to save them automatically.

  1. Install the persistence package:

    sudo apt update
sudo apt install iptables-persistent -y

  2. During installation, select Yes when prompted to save current IPv4 rules.

  3. If you make changes to your iptables rules later, update the saved rules by running:

    sudo netfilter-persistent save

Step 5: Configure Client Devices

For client devices on your internal network to route traffic through your Ubuntu router:

  1. Set the client’s IP address within the same subnet as your Ubuntu LAN interface (eth1).
  2. Set the client’s Default Gateway to the IP address of your Ubuntu router’s LAN interface (eth1).
  3. Set a public DNS server on the client, such as 8.8.8.8 or 1.1.1.1.
