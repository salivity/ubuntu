How to Set Up CoovaChilli Captive Portal on Ubuntu

Setting up a captive portal is an effective way to authenticate and manage users on a public or corporate Wi-Fi network. This guide provides a step-by-step walkthrough for installing, configuring, and deploying CoovaChilli—an open-source access controller—on an Ubuntu gateway server to route traffic and manage guest network access seamlessly.

Prerequisites

Before beginning, ensure your system meets the following requirements:

  • An Ubuntu Server installation (Ubuntu 20.04 or 22.04 recommended).
  • Two network interfaces:
    • WAN Interface (eth0): Connected to the internet.
    • LAN Interface (eth1): Connected to the access point or client network.
  • Root or sudo access.

Step 1: Install Required Packages

Update your package repositories and install the necessary build tools and dependencies.

sudo apt update
sudo apt install -y build-essential libssl-dev libcurl4-openssl-dev gengetopt libcoova-dev devscripts debhelper iptables git

Step 2: Download, Compile, and Install CoovaChilli

  1. Clone the official CoovaChilli repository from GitHub:
git clone https://github.com/coovachilli/coova-chilli.git
cd coova-chilli
  1. Generate the configuration scripts and build the binary:
./bootstrap
./configure --prefix=/usr --sysconfdir=/etc --localstatedir=/var
make
sudo make install

Step 3: Configure CoovaChilli

CoovaChilli uses a central configuration file located at /etc/chilli/config.

  1. Open the configuration file in a text editor:
sudo nano /etc/chilli/config
  1. Modify the core parameters to match your network topology:
# Network Interfaces
HS_WANIF=eth0           # Internet-facing interface
HS_LANIF=eth1           # Interface connected to internal clients

# Subnet Configurations
HS_NETWORK=10.1.0.0     # Internal network IP range
HS_NETMASK=255.255.255.0
HS_UAMLISTEN=10.1.0.1   # IP address assigned to CoovaChilli gateway

# RADIUS / Authentication Server Settings
HS_RADIUS=127.0.0.1
HS_RADIUS2=127.0.0.1
HS_RADSECRET=testing123

# Portal Redirection Settings
HS_UAMSERVER=http://10.1.0.1/www/login.chi
HS_UAMHOMEPAGE=http://10.1.0.1/www/coovachilli.html
HS_UAMSECRET=uamsecret

# Allowed domains/IPs before authentication (Walled Garden)
HS_UAMALLOW="www.example.com"
  1. Save and close the file.

Step 4: Enable IP Forwarding

To allow authenticated users to pass traffic through the gateway to the internet, enable IPv4 packet forwarding.

  1. Edit /etc/sysctl.conf:
sudo nano /etc/sysctl.conf
  1. Uncomment or add the following line:
net.ipv4.ip_forward=1
  1. Apply the changes immediately:
sudo sysctl -p

Step 5: Configure NAT with IPTables

Set up Network Address Translation (NAT) to route traffic from the internal interface (eth1) through the external interface (eth0).

sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables-save | sudo tee /etc/iptables/rules.v4

Step 6: Start and Test CoovaChilli

  1. Enable and start the CoovaChilli service:
sudo systemctl enable chilli
sudo systemctl start chilli
  1. Verify that the service is running and the tun0 interface has been created:
ip addr show tun0
  1. Connect a device to the network interface assigned to HS_LANIF (eth1). Obtain an IP address via DHCP from CoovaChilli (in the 10.1.0.0/24 subnet), open a web browser, and attempt to visit any website. You should automatically be redirected to the captive portal login screen specified in HS_UAMSERVER.
