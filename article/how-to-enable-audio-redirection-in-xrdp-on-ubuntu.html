How to Enable Audio Redirection in XRDP on Ubuntu

Setting up audio redirection for an XRDP remote desktop session on Ubuntu allows system sound from your remote Linux server to play directly on your local client device. By default, XRDP does not transmit audio, but you can enable this functionality by building and installing the XRDP audio module for PulseAudio or PipeWire. This guide provides the step-by-step process to compile the required module and configure audio output for your remote sessions.

Step 1: Install Required Build Dependencies

Before compiling the audio module, you must install the necessary build tools and header files. Open a terminal on your Ubuntu system and run:

sudo apt update
sudo apt install -y git libpulse-dev autoconf m4 intltool build-essential dpkg-dev

Step 2: Enable Ubuntu Source Repositories

The compilation process requires the source code for the exact version of PulseAudio running on your system.

  1. Open your system sources file:

    sudo nano /etc/apt/sources.list

  2. Ensure that lines starting with deb-src are uncommented (remove the # symbol at the beginning of those lines).

  3. Save and close the file, then update your repository list:

    sudo apt update

Step 3: Download and Prepare PulseAudio Source Code

  1. Navigate to the temporary directory:

    cd /tmp

  2. Download the source code for your current PulseAudio installation:

    apt source pulseaudio

  3. Navigate into the downloaded PulseAudio directory and configure it:

    cd pulseaudio-*
./configure

Step 4: Compile and Install the XRDP Audio Module

  1. Return to the /tmp directory and clone the official XRDP audio module repository:

    cd /tmp
git clone https://github.com/neutrinolabs/pulseaudio-module-xrdp.git

  2. Navigate into the cloned directory:

    cd pulseaudio-module-xrdp

  3. Initialize the build configuration and compile the module using the prepared PulseAudio source directory:

    ./bootstrap && ./configure PULSE_DIR=/tmp/pulseaudio-*
make

  4. Install the compiled .so modules into your system’s PulseAudio module directory:

    sudo make install

Step 5: Restart the XRDP Service and Test Audio

  1. Restart the XRDP service to apply the changes:

    sudo systemctl restart xrdp

  2. Log out of any active XRDP sessions.

  3. Reconnect to your Ubuntu machine using your Remote Desktop Client (such as RDP on Windows or FreeRDP). Ensure that local audio playback is enabled in your RDP client settings.

  4. Open Settings > Sound on the remote Ubuntu desktop and select xrdp output as the output device.
