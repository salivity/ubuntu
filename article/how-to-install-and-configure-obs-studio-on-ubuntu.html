How to Install and Configure OBS Studio on Ubuntu

OBS Studio is a powerful, free, and open-source software for video recording and live streaming. This guide provides a step-by-step walkthrough for installing OBS Studio on Ubuntu Linux using the official PPA repository, followed by essential configuration settings for optimal video, audio, and encoding performance.

Step 1: Install OBS Studio on Ubuntu

Before installing OBS Studio, ensure your system has FFmpeg installed, as OBS relies on it for audio and video encoding.

  1. Open your terminal (Ctrl+Alt+T).
  2. Update your package list and install FFmpeg by running: 
    sudo apt update
sudo apt install ffmpeg
  3. Add the official OBS Studio PPA to your system: 
    sudo add-apt-repository ppa:obsproject/obs-studio
  4. Press Enter to confirm adding the repository.
  5. Update your system package index and install OBS Studio: 
    sudo apt update
sudo apt install obs-studio

Step 2: Initial Setup with the Auto-Configuration Wizard

  1. Launch OBS Studio from your application menu.
  2. On the first launch, the Auto-Configuration Wizard will appear.
  3. Choose your primary usage mode:
    • Optimize for streaming, recording is secondary: Best if you plan to broadcast live on Twitch, YouTube, etc.
    • Optimize just for recording, I will not be streaming: Best for video tutorials, gameplay recording, or local recording.
  4. Select your preferred base canvas resolution (typically 1920x1080) and frame rate (usually 60 or 30 FPS).
  5. Click Apply Settings.

Step 3: Configure Video and Output Settings

To fine-tune performance and quality manually, open Settings from the bottom right panel.

Video Settings

  • Navigate to the Video tab.
  • Base (Canvas) Resolution: Set this to your monitor's native resolution (e.g., 1920x1080).
  • Output (Scaled) Resolution: Set the final output resolution. If your hardware is less powerful, downscale to 1280x720 to reduce CPU/GPU load.
  • Common FPS Values: Set to 60 for smooth motion or 30 for standard video and lower resource usage.

Output Settings

  • Navigate to the Output tab and change Output Mode to Advanced.
  • Under the Recording tab:
    • Recording Path: Choose the folder where your videos will save.
    • Recording Format: Change to mkv or mp4 (MKV is safer against crashes).
    • Encoder: Select x264 for CPU encoding, or NVENC (NVIDIA) / VAAPI (AMD/Intel) for hardware-accelerated encoding.
    • Rate Control: Select CBR for streaming or CQP / CRF for local recording.
    • Bitrate: Set between 4000 Kbps and 6000 Kbps for 1080p 60fps video.

Step 4: Configure Audio Devices

  1. Go to Settings > Audio.
  2. Desktop Audio: Select Default or your specific sound output device to record system sounds.
  3. Mic/Auxiliary Audio: Select your external or built-in microphone.
  4. Click Apply and OK.

Step 5: Add Scenes and Capture Sources

  1. Look at the Scenes panel at the bottom left and click the + button to create a new scene.
  2. In the Sources panel next to it, click the + button to add a capture input:
    • Screen Capture (PipeWire): Ideal if running Ubuntu on the default Wayland display server.
    • Screen Capture (XSHM): Ideal if running Ubuntu on an X11 session.
    • Window Capture: Captures a single application window.
    • Audio Input Capture: Adds a specific microphone source.
  3. Adjust the captured box size in the preview window to fit your canvas.

Click Start Recording or Start Streaming in the lower right controls panel to begin.
