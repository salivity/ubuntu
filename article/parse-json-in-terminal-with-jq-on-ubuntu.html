Parse JSON in Terminal with jq on Ubuntu

Parsing JSON directly within the command line is an essential skill for Linux administrators and developers working with APIs, configuration files, and log streams. This guide covers the complete process of using jq—a powerful, lightweight command-line JSON processor—on Ubuntu. You will learn how to install the utility, format unorganized JSON, extract specific keys and nested values, slice arrays, and filter outputs efficiently using native shell commands.

Installing jq on Ubuntu

The jq utility is available in Ubuntu’s default package repositories. Update your package index and install the tool using the apt package manager:

sudo apt update
sudo apt install jq -y

Verify that the installation was successful by checking the version:

jq --version

Basic Syntax and Pretty-Printing

The simplest use of jq is standardizing and colorizing minified JSON output (known as "pretty-printing"). The identity filter . takes the input and outputs it unchanged, but formatted with proper indentation.

You can pipe data directly from a file or another command:

echo '{"name":"Ubuntu","type":"OS","active":true}' | jq .

To pretty-print a file directly:

jq . data.json

Extracting Specific Properties

To read a specific key from a JSON object, append the key name to the identity operator:

echo '{"title":"Server","status":"running"}' | jq '.status'

Output:

"running"

To get the raw value without quotes (useful when assigning JSON values to shell variables), pass the -r or --raw-output flag:

echo '{"title":"Server","status":"running"}' | jq -r '.status'

Output:

running

Navigating Nested Objects

Access nested attributes by chaining keys together with periods:

echo '{"server":{"network":{"ip":"192.168.1.1"}}}' | jq -r '.server.network.ip'

Output:

192.168.1.1

Parsing Arrays

When dealing with JSON lists, use brackets [] to iterate through array elements or select specific indexes.

Given this array:

echo '[{"id":1,"user":"alice"},{"id":2,"user":"bob"}]' > users.json

  • Print all items:

    jq '.[]' users.json

  • Select an element by index (0-based):

    jq '.[0]' users.json

  • Extract a specific field from all objects in an array:

    jq '.[].user' users.json

Filtering Data with select()

The select() function allows you to filter elements based on boolean conditions, similar to an SQL WHERE clause:

echo '[{"name":"app","port":80},{"name":"db","port":5432},{"name":"cache","port":6379}]' | jq '.[] | select(.port > 1000)'

This pipes the array elements into select(), returning only the objects where the port value exceeds 1000.

Combining jq with curl

jq is commonly used to parse real-time data from web APIs. Combine curl with jq via standard pipes:

curl -s https://api.github.com/repos/stedolan/jq | jq '{name: .name, stars: .stargazers_count}'

This fetches the repository metadata, selects only the name and stargazers_count fields, and constructs a new JSON object directly in your terminal.
