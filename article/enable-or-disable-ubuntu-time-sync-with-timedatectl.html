Enable or Disable Ubuntu Time Sync with timedatectl

In Ubuntu, keeping an accurate system clock is essential for security certificates, scheduled tasks, and log accuracy. The timedatectl utility, built into systemd, provides a straightforward way to manage time and date settings directly from the terminal. This guide covers how to check your current system clock status and use the timedatectl command to enable or disable automatic Network Time Protocol (NTP) synchronization.

Check Current Time Synchronization Status

Before making changes, verify your current time synchronization settings. Open your terminal and run:

timedatectl

Review the output fields:

  • System clock synchronized: Displays yes if the time is currently synced, or no if it is not.
  • NTP service: Shows active if background synchronization is currently running, or inactive if it is disabled.

Enable Automatic Time Synchronization

To turn on automatic time synchronization via NTP, execute:

sudo timedatectl set-ntp true

Note: You can also use yes, on, or 1 in place of true.

This command enables and starts the underlying synchronization daemon (typically systemd-timesyncd).

To verify that it is active, run:

timedatectl

Ensure that the NTP service line now reads active.

Disable Automatic Time Synchronization

If you need to manually set the system time or use an external service without interference, disable synchronization with:

sudo timedatectl set-ntp false

Note: You can also use no, off, or 0 in place of false.

Confirm the change by checking the status:

timedatectl

The NTP service line should now show inactive. Once disabled, you can manually set the system date and time using:

sudo timedatectl set-time "YYYY-MM-DD HH:MM:SS"
