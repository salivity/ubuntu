How to Use edquota to Modify Disk Quotas in Ubuntu

The edquota command in Ubuntu is a system administration tool used to manage and enforce storage limits for individual users or groups. This article provides a clear overview of the purpose of edquota, how soft and hard limits work, and the straightforward steps required to modify disk space and file creation restrictions on an Ubuntu system.

The Purpose of the edquota Command

The primary purpose of the edquota (edit quota) command is to prevent individual users or groups from consuming excessive storage space on a shared file system. On multi-user Ubuntu systems, an unrestricted user could accidentally or intentionally fill up the entire hard drive, leading to system instability, service crashes, or denial of service for other users.

Using edquota allows system administrators to assign precise storage boundaries, maintaining fair resource distribution and server health.

Key Features and Quota Types

When you execute edquota for a specific user, the command opens a temporary file in the default system text editor (such as Nano or Vim). This file displays current usage and allows you to set two main categories of limits across specific file systems:

  1. Block Limits (Disk Space): Controls the actual amount of disk space a user can occupy, usually measured in 1-KB blocks.
  2. Inode Limits (File Count): Controls the total number of files and directories a user can create, regardless of file size.

Soft Limits vs. Hard Limits

For both blocks and inodes, edquota allows you to set two thresholds:

  • Soft Limit: The maximum amount of disk space or files a user should normally use. Users can temporarily exceed this limit during a system-defined "grace period" (typically 7 days by default). This allows users to finish temporary tasks, but they receive warnings to reduce their usage.
  • Hard Limit: The absolute maximum restriction. Once a user hits the hard limit, the system immediately blocks any further data creation or file writing until space is freed.

How to Modify Disk Limits for a User

To modify the quota limits for a specific user in Ubuntu, follow these steps:

Step 1: Open the User's Quota Configuration

Run the edquota command with root privileges, specifying the target username with the -u flag:

sudo edquota -u username

Step 2: Edit the Quota Values

The command opens a file structured similarly to this:

Disk quotas for user username (uid 1001):
  Filesystem  blocks  soft  hard  inodes  soft  hard
  /dev/sda1     1024  5000  6000      15   100   120

To modify limits:

  • Change the soft block value to set the flexible disk space limit.
  • Change the hard block value to set the maximum allowed disk space.
  • Change the soft and hard inode values to restrict the total number of files.

Note: Leaving a limit set to 0 disables that specific restriction, giving the user unlimited access for that metric.

Step 3: Save and Exit

Save the changes and exit the editor (e.g., press Ctrl + O and Ctrl + X in Nano). The changes take effect immediately; no service restarts are required.

Additional Functionality

  • Modifying Grace Periods: You can adjust the grace period duration for soft limits across the system using: 
    sudo edquota -t
  • Copying Quotas: If you need to apply the exact same quota settings from one user to multiple other users, use the -p (prototype) flag: 
    sudo edquota -p source_user target_user1 target_user2

By utilizing edquota, Ubuntu administrators maintain precise control over storage consumption, preventing single users from exhausting server resources.
