How to Install Fish Shell as Default on Ubuntu

This guide provides step-by-step instructions on how to install the Friendly Interactive Shell (Fish) on Ubuntu, set it as your user’s default shell, and perform basic initial configurations. By following these straightforward commands, you will replace your standard Bash interface with a feature-rich shell that includes smart autosuggestions, syntax highlighting, and easy web-based configuration out of the box.

Step 1: Add the Fish PPA and Install Fish

While Ubuntu repositories contain Fish, adding the official Personal Package Archive (PPA) ensures you get the latest stable version.

  1. Open your terminal and run the following command to add the official repository:
sudo add-apt-repository ppa:fish-shell/release-3
  1. Update your package list:
sudo apt update
  1. Install Fish:
sudo apt install fish

Step 2: Verify the Installation

Confirm that Fish is installed correctly by checking its version:

fish --version

You can test the shell temporarily by typing:

fish

Type exit to return to your standard shell before proceeding.

Step 3: Set Fish as the Default Shell

To make Fish your default shell every time you open a terminal or start an SSH session, use the chsh (change shell) command.

  1. Locate the path of the installed Fish binary:
which fish

(The standard output is usually /usr/bin/fish)

  1. Change your user’s default shell to Fish:
chsh -s $(which fish)
  1. Log out of your Ubuntu user account and log back in, or restart your terminal. Open a new terminal window, and Fish will load automatically.

Step 4: Configure Fish Shell

Unlike traditional shells like Bash or Zsh, Fish uses a web-based configuration interface alongside standard text configuration files.

Option A: Web-Based Configuration

Fish includes a built-in web interface that allows you to change prompts, color schemes, and view aliases/variables directly in your browser.

Launch the interface by running:

fish_config

Select your preferred theme and prompt layout, then save the changes and close the browser window.

Option B: File-Based Configuration

For manual configurations, environment variables, or custom functions, edit or create the config.fish file located in your user’s home directory.

  1. Create the configuration directory if it does not exist:
mkdir -p ~/.config/fish
  1. Open the file in a text editor:
nano ~/.config/fish/config.fish
  1. Add your custom configurations. For example, to hide the default greeting message when opening the terminal, add:
set -g fish_greeting ""

To set custom aliases, add lines like:

alias ll='ls -la'
  1. Save and exit the editor (Ctrl+O, Enter, Ctrl+X in Nano).

How to Revert to Bash

If you ever need to restore Bash as your default shell, run:

chsh -s /bin/bash

Log out and back in for the changes to take effect.
