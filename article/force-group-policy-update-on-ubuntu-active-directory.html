Force Group Policy Update on Ubuntu Active Directory

Updating Group Policy Objects (GPOs) on an Ubuntu machine joined to Active Directory depends directly on the integration tool managing the domain join. While Windows natively uses gpupdate /force, Ubuntu relies on client utilities such as Canonical's ADsys, SSSD, or PBIS Open to fetch and enforce policy changes. This guide provides the exact commands required to force an immediate policy refresh across each common configuration.

1. Ubuntu Systems Using ADsys (Default for Modern Ubuntu)

For Ubuntu Desktop and Server (version 20.04 LTS and newer) using Canonical's native Active Directory integration tool, ADsys, the command to manually force a policy update is:

sudo adsysctl policy update

To update policies for both the computer and all active users immediately, use:

sudo adsysctl update --all

You can verify the applied policies and check for errors by reviewing the status:

adsysctl policy status

2. Systems Using SSSD (GPO Access Control)

If your Ubuntu machine is joined via realmd and SSSD (System Security Services Daemon), SSSD primarily evaluates GPOs for access control rules (such as logon rights). SSSD does not have a standalone GPO engine command, but you can force an immediate refresh by purging the local cache:

sudo sss_cache -E

After expiring the cache, restart the SSSD service to fetch the newest rules from the domain controller:

sudo systemctl restart sssd

3. Systems Using PBIS Open (BeyondTrust / Likewise)

If the system was integrated into the domain using PBIS Open (formerly PowerBroker Identity Services), a native command mimicking the Windows tool is available:

sudo /opt/pbis/bin/gpupdate
