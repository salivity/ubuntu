How to Verify an Ubuntu ISO Signature

Verifying the cryptographic signature of an Ubuntu ISO ensures that the downloaded image is authentic, complete, and has not been altered by a third party. This process involves downloading the ISO alongside its checksum and signature files, importing Ubuntu’s official GPG signing keys, verifying the signature of the checksum file, and finally validating the ISO file against that checksum.

Step 1: Download the Required Files

To complete the verification, you need three files from the official Ubuntu release server for your specific version: 1. The Ubuntu ISO file (e.g., ubuntu-24.04-desktop-amd64.iso) 2. The SHA256SUMS file 3. The SHA256SUMS.gpg file

Ensure all three files are saved in the same directory.

Step 2: Import Ubuntu Signing Keys

Ubuntu signs its checksum files using specific GPG keys. Open your terminal, navigate to the directory containing your downloaded files, and import the official Ubuntu key using the following command:

gpg --keyid-format long --keyserver hkps://keyserver.ubuntu.com --recv-keys 843938DF228D22F7B3742BC0D94AA3F0EFE21092 822A9F8E45499298B0F2A8EF283FF426C1CA6CBA

Step 3: Verify the Key Fingerprints

Confirm that the imported keys match Ubuntu’s official key fingerprints by running:

gpg --keyid-format long --list-keys 843938DF228D22F7B3742BC0D94AA3F0EFE21092 822A9F8E45499298B0F2A8EF283FF426C1CA6CBA

Ensure the output contains the correct key fingerprints: * 8439 38DF 228D 22F7 B374 2BC0 D94A A3F0 EFE2 1092 * 822A 9F8E 4549 9298 B0F2 A8EF 283F F426 C1CA 6CBA

Step 4: Verify the SHA256SUMS Signature

Next, check that the SHA256SUMS file was authentically signed by Ubuntu’s GPG key:

gpg --verify SHA256SUMS.gpg SHA256SUMS

Look for “Good signature” in the output. If you see a warning stating that the key is not certified with a trusted signature, this is normal unless you have manually established a web of trust with the Ubuntu key holder.

Step 5: Validate the ISO Checksum

Finally, generate the SHA-256 hash of your downloaded ISO file and compare it against the verified SHA256SUMS file:

sha256sum -c SHA256SUMS 2>&1 | grep OK

If the ISO is authentic and free of corruption, the terminal will output the name of your ISO file followed by OK (e.g., ubuntu-24.04-desktop-amd64.iso: OK).
