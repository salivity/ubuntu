How to Use taskset for CPU Affinity in Ubuntu

This article explores the purpose and utility of the taskset command in Ubuntu, focusing on how it manages CPU affinity by binding processes to specific processor cores. By reading this guide, you will understand how taskset controls CPU allocation, why process pinning is critical for optimizing system performance, and the practical commands used to retrieve or set CPU masks for both new and running processes.

In Ubuntu Linux, the taskset command is part of the util-linux package and is used to set or retrieve the CPU affinity of a running process, or to launch a new command with a defined CPU affinity. CPU affinity is a scheduler feature that binds a process to a specific set of CPUs or cores on the system. By default, the Linux kernel scheduler dynamically assigns processes to available CPU cores to balance system load. However, using taskset overrides this behavior, forcing the system to execute a designated process strictly on chosen cores.

The primary purpose of using taskset to pin a process to specific CPU cores involves several key optimization benefits:

  • Cache Locality Optimization: When a process moves between different CPU cores, it invalidates the CPU L1 and L2 caches, causing latency as data is reloaded into the new core’s cache. Pinning a process to a dedicated core keeps the cache warm, drastically reducing memory access latency for cache-sensitive applications.
  • Workload Isolation: In multi-tenant environments or high-performance computing setups, pinning prevents resource-heavy processes from competing with critical system tasks. For example, database engines or real-time trading software can be assigned to dedicated cores, while background tasks run on remaining cores.
  • NUMA Architecture Efficiency: On Non-Uniform Memory Access (NUMA) systems with multiple physical CPUs, assigning a process to cores local to its allocated RAM prevents slow cross-node memory access.
  • Consistent Benchmarking: Pinning a thread to a single core eliminates scheduling variability, allowing developers to measure precise execution time and hardware performance metrics.

To check the current CPU affinity of an existing process using its Process ID (PID), use the following syntax:

taskset -cp <PID>

To launch a new process restricted to specific CPU cores (for example, cores 0 and 2), use the -c flag followed by the core list and command:

taskset -c 0,2 application_name

To modify the CPU affinity of an already running process to use specific cores (such as cores 1 through 3), execute:

taskset -cp 1-3 <PID>

By leveraging taskset, system administrators and developers in Ubuntu gain granular control over hardware resources, ensuring predictable performance, reduced cache thrashing, and optimized resource allocation for demanding applications.
