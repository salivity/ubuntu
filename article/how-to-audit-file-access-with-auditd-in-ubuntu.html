How to Audit File Access with auditd in Ubuntu

Monitoring file access is critical for system security and compliance. In Ubuntu, the primary command used to audit file access attempts within the Linux Audit framework (auditd) is auditctl. This article covers how to configure auditctl to monitor read, write, execute, and attribute changes on specific files, how to verify active rules, and how to analyze the resulting audit logs using ausearch.

Installing auditd

Before setting up file watches, ensure the audit framework is installed and running on your Ubuntu system:

sudo apt update
sudo apt install auditd
sudo systemctl enable --now auditd

The Command to Audit File Access

To configure a file watch in real-time, use the auditctl command with the following syntax:

sudo auditctl -w /path/to/file -p rwxa -k file_access_monitor

Breakdown of the Command Options

  • -w /path/to/file: Defines the path to the file or directory you want to monitor.
  • -p rwxa: Specifies the permission access types that trigger an audit event:
    • r: Read access
    • w: Write access
    • x: Execute access
    • a: Attribute changes (e.g., changes to file ownership, permissions, or timestamps)
  • -k file_access_monitor: Assigns a unique identifier (key) to the rule, making it easier to filter and search the logs later.

For example, to log every time a user reads or modifies /etc/shadow, run:

sudo auditctl -w /etc/shadow -p rw -k shadow_access

Verifying Configured Audit Rules

To list all currently active audit rules on the system, run:

sudo auditctl -l

Viewing and Searching File Access Logs

Events captured by auditd are written to /var/log/audit/audit.log. Rather than inspecting this file manually, use ausearch to query the logs:

  • Search by key:

    sudo ausearch -k shadow_access

  • Search by file path:

    sudo ausearch -f /etc/shadow

  • Format the output into a readable report:

    sudo aureport -f -i

Making Audit Rules Persistent

Rules added with auditctl are temporary and will not survive a system reboot. To make a rule permanent:

  1. Open the audit rules configuration file in a text editor:

    sudo nano /etc/audit/rules.d/audit.rules

  2. Add your rule at the bottom of the file:

    -w /etc/shadow -p rw -k shadow_access

  3. Reload the rules into the running audit daemon:

    sudo augenrules --load
