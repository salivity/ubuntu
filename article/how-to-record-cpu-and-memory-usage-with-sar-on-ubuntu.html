How to Record CPU and Memory Usage with sar on Ubuntu

This article provides a step-by-step guide on how to install, configure, and use the sar (System Activity Reporter) tool on Ubuntu to continuously monitor and log system performance. By configuring the sysstat package, you will learn how to enable background data collection, adjust collection intervals, and query historical CPU and memory utilization data for troubleshooting and performance analysis.

Step 1: Install the Sysstat Package

The sar command is provided by the sysstat package. Update your local package index and install sysstat using the following commands:

sudo apt update
sudo apt install sysstat -y

Step 2: Enable Data Collection

The historical data collection daemon in sysstat is disabled by default on Ubuntu. You must explicitly enable it to log metrics over time.

  1. Open the configuration file in a text editor:

    sudo nano /etc/default/sysstat

  2. Change the ENABLED setting from "false" to "true":

    ENABLED="true"

  3. Save and close the file.

Step 3: Start and Enable the Sysstat Service

Restart the service to apply the configuration changes and enable it to start automatically on system boot:

sudo systemctl restart sysstat
sudo systemctl enable sysstat

Step 4: Configure Data Collection Intervals (Optional)

By default, sysstat collects performance metrics every 10 minutes. You can adjust this frequency by editing its cron configuration file.

  1. Open the cron file:

    sudo nano /etc/cron.d/sysstat

  2. Modify the schedule line. For example, to change the interval to every 2 minutes, update the cron expression to:

    */2 * * * * root command -v debian-sysstat > /dev/null && debian-sysstat --dsa

  3. Save and close the file.

Step 5: View CPU Usage Statistics

To view CPU usage stats collected throughout the current day:

sar -u

To monitor real-time CPU usage (e.g., updated every 2 seconds, 5 times):

sar -u 2 5

To view CPU statistics from a specific day in the past (replace DD with the day of the month, such as 05 or 12):

sar -u -f /var/log/sysstat/saDD

Step 6: View Memory Usage Statistics

To view memory usage stats collected throughout the current day:

sar -r

To monitor real-time memory usage (e.g., updated every 2 seconds, 5 times):

sar -r 2 5

To view historical memory statistics from a specific day of the month:

sar -r -f /var/log/sysstat/saDD
