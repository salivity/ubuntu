How to Monitor Ubuntu with Datadog Agent

Monitoring an Ubuntu server with the Datadog Infrastructure Agent provides real-time visibility into vital system performance metrics such as CPU usage, memory consumption, disk I/O, and network traffic. This guide outlines the essential steps to get started, from obtaining your API credentials to running the automated installation script, verifying the agent's status, and viewing your server's telemetry inside the Datadog platform.

Prerequisites

Before beginning, ensure you have:

  • An active Datadog account.
  • An Ubuntu server (version 18.04 LTS, 20.04 LTS, 22.04 LTS, or newer).
  • Root or sudo privileges on the server.
  • Outbound internet access via port 443.

Step 1: Retrieve Your Datadog API Key and Site

  1. Log in to your Datadog account.
  2. Navigate to Organization Settings > API Keys.
  3. Copy an existing API key or generate a new one.
  4. Identify your Datadog site region (e.g., datadoghq.com for US1, datadoghq.eu for EU, or us5.datadoghq.com for US5).

Step 2: Install the Datadog Agent

Datadog provides a single-line installation command that downloads the package repository, adds the GPG keys, and installs the agent via apt.

Run the following command in your Ubuntu terminal, replacing <YOUR_DATADOG_API_KEY> with your actual key and <YOUR_DATADOG_SITE> with your site domain:

DD_API_KEY="<YOUR_DATADOG_API_KEY>" DD_SITE="<YOUR_DATADOG_SITE>" bash -c "$(curl -L https://s3.amazonaws.com/dd-agent/scripts/install_script_agent7.sh)"

Once the script completes, the installer automatically configures the agent and starts the background service.

Step 3: Manage the Agent Service

The Datadog Agent runs as a systemd service under the name datadog-agent. You can control its lifecycle using standard systemctl commands:

  • Check service status: 
    sudo systemctl status datadog-agent
  • Restart the agent: 
    sudo systemctl restart datadog-agent
  • Stop the agent: 
    sudo systemctl stop datadog-agent

Step 4: Verify the Installation

To verify that the agent is actively collecting and transmitting metrics, run the built-in status command:

sudo datadog-agent status

This output displays the running agent version, configured checks, and network connectivity status. Look for the Collector section to confirm that core checks (like CPU, disk, memory, and uptime) are reporting no errors.

Step 5: View Metrics in Datadog

  1. Open your Datadog web console.
  2. Navigate to Infrastructure > Host Map or Infrastructure List.
  3. Search for your Ubuntu server’s hostname.

Within a few minutes of installation, your server will appear in the dashboard, where you can monitor real-time system health, configure threshold alerts, and build custom dashboards.
