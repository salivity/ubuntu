Install FreeIPA Client on Ubuntu Workstation

This guide explains how to install and configure the FreeIPA client on an Ubuntu workstation to enable centralized authentication and identity management. You will learn the required prerequisites, how to set a fully qualified domain name (FQDN), the installation of the necessary client packages, joining the system to the FreeIPA domain, and enabling automatic home directory creation for network users.

Step 1: Set Up Prerequisites and Hostname

FreeIPA requires a properly configured Fully Qualified Domain Name (FQDN) that resolves accurately, along with synchronized system time.

  1. Set the static hostname to match your domain's FQDN:

    sudo hostnamectl set-hostname workstation.example.com

  2. Open /etc/hosts and map your local IP address to your FQDN:

    127.0.1.1 workstation.example.com workstation

  3. Ensure time synchronization is active, as Kerberos authentication will fail if clock drift exceeds five minutes:

    sudo timedatectl set-ntp true

Step 2: Install the FreeIPA Client Package

Ubuntu repositories include the FreeIPA client package (freeipa-client). Update your package cache and install it:

sudo apt update
sudo apt install freeipa-client -y

Step 3: Run the FreeIPA Client Installation Script

Run the automated installer utility to enroll the Ubuntu workstation into your FreeIPA realm:

sudo ipa-client-install --mkhomedir

The script will prompt for the following details:

  • IPA Server: The FQDN of your primary FreeIPA server (e.g., ipa.example.com).
  • IPA Domain: The DNS domain name (e.g., example.com).
  • IPA Realm: The Kerberos realm, typically the domain in uppercase (e.g., EXAMPLE.COM).
  • Principal: An authorized administrative account with permission to enroll hosts (e.g., admin).
  • Password: The password for the specified administrative user.

Alternatively, provide these details in a single non-interactive command:

sudo ipa-client-install \
  --server=ipa.example.com \
  --domain=example.com \
  --realm=EXAMPLE.COM \
  --principal=admin \
  --password=YourAdminPassword \
  --mkhomedir \
  --unattended

Step 4: Configure Automatic Home Directory Creation

If --mkhomedir was not applied or network users do not have home directories generated on their initial login, configure PAM explicitly:

sudo pam-auth-update --enable mkhomedir

Step 5: Verify FreeIPA Authentication

  1. Confirm that the workstation can retrieve user records from the FreeIPA directory:

    getent passwd ipauser

  2. Test Kerberos ticket granting:

    kinit ipauser
klist

  3. Switch to the domain user account to verify home directory generation and local session initialization:

    su - ipauser

The Ubuntu workstation is now integrated with the FreeIPA domain for centralized authentication and access control.
