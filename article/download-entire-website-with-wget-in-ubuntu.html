Download Entire Website with Wget in Ubuntu

This guide explains how to download an entire website for offline viewing on Ubuntu using the command-line utility wget. By utilizing specific recursive mirroring flags, you can save web pages, stylesheets, scripts, and images directly to your local drive while modifying internal links so the site functions seamlessly without an active internet connection.

Step 1: Install Wget

Wget is pre-installed on most Ubuntu systems. If it is missing, open your terminal and install it using the apt package manager:

sudo apt update
sudo apt install wget

Step 2: Run the Mirror Command

To download a website completely and prepare it for offline browsing, navigate to the directory where you want to store the files and run the following command:

wget --mirror --convert-links --adjust-extension --page-requisites --no-parent https://example.com

Explanation of Command Options

  • --mirror (or -m): Turns on recursion, sets infinite recursion depth, and preserves timestamps.
  • --convert-links (or -k): Converts the links inside the HTML and CSS documents so they point to local files instead of web URLs.
  • --adjust-extension (or -E): Appends .html to downloaded files that lack an extension, ensuring your browser renders them correctly.
  • --page-requisites (or -p): Downloads all necessary inline assets (images, CSS styles, JavaScript files) required to display the page properly.
  • --no-parent (or -np): Restricts the download to the specified directory hierarchy and prevents wget from following links to parent directories.

Step 3: Handle Rate Limiting and User Agents (Optional)

Some web servers block automated scraping tools or throttle aggressive downloading. To make requests appear more natural and reduce server load, add these additional flags:

wget --mirror --convert-links --adjust-extension --page-requisites --no-parent \
     --wait=1 \
     --random-wait \
     --user-agent="Mozilla/5.0 (X11; Ubuntu; Linux x86_64; rv:109.0) Gecko/20100101 Firefox/119.0" \
     https://example.com
  • --wait=1 and --random-wait: Pauses between 0.5 and 1.5 seconds between each request to prevent getting blocked by the server.
  • --user-agent="...": Spoofs a standard web browser header, bypassing basic anti-bot filters.

Step 4: Browse the Website Offline

Once the process finishes, wget creates a folder named after the website's domain in your current working directory. Open the folder and launch the index.html file in any web browser:

cd example.com
xdg-open index.html

The site will now open and navigate locally through your default web browser without requiring internet access.
