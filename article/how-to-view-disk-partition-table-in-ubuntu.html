How to View Disk Partition Table in Ubuntu

Viewing the partition table of a disk in Ubuntu is a fundamental task for system administration, storage management, and troubleshooting. Ubuntu provides several powerful command-line utilities—such as fdisk, lsblk, parted, and blkid—that allow users to inspect disk layouts, partition types, and storage sizes quickly. This guide covers the most effective commands to display partition tables in Ubuntu along with practical examples for using each tool.

1. Using the fdisk Command

The fdisk utility is the standard and most commonly used command-line tool for displaying and managing disk partition tables in Linux.

To view the partition tables of all connected drives, run:

sudo fdisk -l

To view the partition table of a specific disk (for example, /dev/sda or /dev/nvme0n1), specify the device path:

sudo fdisk -l /dev/sda

The output displays essential information, including the disk size, sector information, disk identifier, partition type (such as GPT or MBR), and a list of individual partitions with their filesystem types.

2. Using the lsblk Command

The lsblk (list block devices) command provides a clear, tree-like structure of all block devices and their corresponding partitions. It does not require root privileges for basic views.

To view a summary of all block devices:

lsblk

To display additional filesystem details, including UUIDs and mount points, use the -f flag:

lsblk -f

3. Using the parted Command

The parted utility supports both MBR (Master Boot Record) and GPT (GUID Partition Table) disk layouts and is useful for detailed disk analysis.

To view the partition layout of all available storage devices:

sudo parted -l

To inspect a specific disk using parted:

sudo parted /dev/sda print

4. Using the gdisk Command

If your disk uses the GPT layout, gdisk (GPT fdisk) provides specialized details that standard fdisk tools might not show.

To view the GPT partition table of a specific drive:

sudo gdisk -l /dev/sda

5. Using the blkid Command

To view information about block devices, including their globally unique identifiers (UUIDs) and filesystem types, use blkid:

sudo blkid

This command is particularly helpful when editing the /etc/fstab file to configure automatic drive mounting on boot.
