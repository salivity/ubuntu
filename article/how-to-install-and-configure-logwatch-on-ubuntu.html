How to Install and Configure Logwatch on Ubuntu

Logwatch is an open-source log parser and analyzer that collects and summarizes your system logs into clear, actionable daily reports. This guide provides step-by-step instructions on how to install Logwatch on an Ubuntu system, configure its settings to customize report detail levels, and set up automated daily email deliveries to keep track of server performance and security events.

Step 1: Update Packages and Install Logwatch

Update your local package index and install Logwatch along with postfix (or an equivalent Mail Transfer Agent) to handle email delivery.

sudo apt update
sudo apt install logwatch postfix -y

During the Postfix installation wizard, select Internet Site and enter your system's fully qualified domain name (FQDN) or hostname.

Step 2: Configure Logwatch Settings

Avoid editing the default configuration file directly. Copy the default configuration to the local override directory so your custom settings persist across software updates.

sudo cp /usr/share/logwatch/default.conf/logwatch.conf /etc/logwatch/conf/logwatch.conf

Open the configuration file in a text editor:

sudo nano /etc/logwatch/conf/logwatch.conf

Locate and modify the following parameters to suit your needs:

  • Output: Change from stdout to mail so reports are automatically emailed. 
    Output = mail
  • Format: Set to html for formatted web-style reports, or keep as text. 
    Format = html
  • MailTo: Enter the destination email address where reports should be delivered. 
    MailTo = admin@example.com
  • Detail: Adjust the verbosity level (Low, Medium, or High). 
    Detail = High
  • Range: Specify the date range for logs to include in the report (typically yesterday). 
    Range = yesterday

Save and close the file when finished.

Step 3: Test Logwatch Manually

To verify that Logwatch parses logs and sends mail correctly, trigger a report manually:

sudo logwatch --output mail

To display a report directly in your terminal without sending an email, execute:

sudo logwatch --detail Low --range yesterday

Step 4: Verify Daily Automation

Logwatch automatically creates a executable script in /etc/cron.daily/00logwatch upon installation. Ubuntu's default cron system runs all scripts in /etc/cron.daily/ once per day. The script will automatically read your custom configuration in /etc/logwatch/conf/logwatch.conf and send the summary report to your specified email address without requiring additional setup.
