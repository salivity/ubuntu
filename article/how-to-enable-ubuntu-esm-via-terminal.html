How to Enable Ubuntu ESM via Terminal

Ubuntu Expanded Security Maintenance (ESM) provides critical security updates for LTS releases after their standard five-year maintenance window ends. This guide provides a direct, step-by-step procedure to connect your system to an Ubuntu Pro account and enable ESM support for both main system packages and universe repository applications using the terminal.

Step 1: Obtain Your Ubuntu Pro Token

To access ESM, you need a free or paid Ubuntu Pro subscription.

  1. Visit the official Ubuntu Pro website and sign in.
  2. Retrieve your free personal token (available for up to 5 machines) or your enterprise token from the dashboard.

Step 2: Install or Update the Ubuntu Pro Client

Ensure your system has the latest version of the Ubuntu Advantage/Pro client installed. Open your terminal and run:

sudo apt update
sudo apt install ubuntu-advantage-tools

Step 3: Attach Your Token to the System

Link your machine to your account by attaching the token you retrieved in Step 1. Replace YOUR_TOKEN_HERE with your actual token:

sudo pro attach YOUR_TOKEN_HERE

Attaching the token automatically enables esm-infra on supported systems.

Step 4: Enable ESM Services

Ubuntu ESM offers two main streams: ESM-Infra (for base OS security updates) and ESM-Apps (for third-party open-source software in the Universe repository).

To enable ESM for main system packages:

sudo pro enable esm-infra

To enable ESM for applications (Universe repository):

sudo pro enable esm-apps

Step 5: Verify ESM Status

To confirm that ESM services are active on your system, run:

pro status

Check the output to ensure esm-infra and esm-apps display enabled under the Status column.

Step 6: Apply Security Updates

Once ESM is enabled, update your package lists and upgrade your system to install available security patches:

sudo apt update
sudo apt upgrade
