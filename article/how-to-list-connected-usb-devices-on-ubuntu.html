How to List Connected USB Devices on Ubuntu

To display USB devices connected to an Ubuntu system, the standard command used is lsusb. This lightweight command-line utility lists all USB buses and the devices attached to them, making it essential for hardware identification and troubleshooting. This guide covers how to use lsusb, its most helpful options, and alternative Linux commands for viewing connected USB hardware in Ubuntu.

Using the lsusb Command

Open your terminal by pressing Ctrl+Alt+T and enter the following command:

lsusb

Understanding the Output

Running lsusb returns a list of connected USB hardware. A typical output entry looks like this:

Bus 001 Device 003: ID 046d:c52b Logitech, Inc. Unifying Receiver

  • Bus: The USB bus number the device is attached to.
  • Device: The temporary device number assigned by the operating system.
  • ID: The Vendor ID and Product ID formatted as xxxx:yyyy (e.g., 046d identifies Logitech).
  • Description: The manufacturer name and device model.

Useful lsusb Flags

  • Display USB Tree Structure (lsusb -t): Shows the USB connections in a physical tree format, displaying port numbers, speeds, and associated drivers:

    lsusb -t

  • Detailed Device Information (lsusb -v): Displays verbose output including power usage, endpoints, and device capabilities. It is best run with sudo:

    sudo lsusb -v

  • Inspect a Specific Device: Filter the detailed output for a single device using its ID number:

    lsusb -d 046d:c52b -v

Alternative Commands for Viewing USB Information

  • usb-devices: A built-in shell script that provides a summary of connected USB devices, including details like active drivers and transfer speeds, formatted in an easy-to-read block layout:

    usb-devices

  • dmesg (Kernel Logs): To see live status updates and detection logs when a USB device is plugged in or disconnected:

    sudo dmesg | grep -i usb

  • lsblk (For USB Storage Devices): If you specifically need to view connected USB flash drives or external hard drives and their mount points, use:

    lsblk
