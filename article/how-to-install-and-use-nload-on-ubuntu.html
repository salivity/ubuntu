How to Install and Use nload on Ubuntu

This guide provides a quick walkthrough on how to install and use the nload command-line utility in Ubuntu. nload is a lightweight, real-time network monitoring tool that visualizes incoming and outgoing network traffic using two separate graphs directly in your terminal, making it simple to track bandwidth usage, current speeds, and data transfer totals.

Installing nload on Ubuntu

nload is available in Ubuntu’s default universe repository, so you can install it using the standard apt package manager.

  1. Update your local package list:

    sudo apt update

  2. Install the nload package:

    sudo apt install nload

Launching nload

To start monitoring your network immediately with default settings, run:

nload

Once launched, the terminal displays two graphs:

  • Incoming: Visualizes incoming traffic (downloads).
  • Outgoing: Visualizes outgoing traffic (uploads).

Below each graph, nload provides key statistics including current transfer rate (Curr), average transfer rate (Avg), minimum observed rate (Min), maximum observed rate (Max), and total data transferred (Ttl).

Navigation and Controls

While inside the nload interface:

  • Press the Left and Right arrow keys (or Page Up / Page Down) to switch between different network interfaces (e.g., eth0, wlan0, lo).
  • Press F2 to access the configuration options menu.
  • Press q or Ctrl + C to exit the tool.

Useful Command Options

You can customize nload behavior directly from the terminal using flags:

  • Monitor a specific interface: Specify the interface name at the end of the command to monitor only that device:

    nload eth0

  • Display multiple devices simultaneously: Use the -m flag to view multiple network interfaces at once without the graph visualization:

    nload -m

  • Change display units: By default, bandwidth is shown in kbit/s. Use the -u flag to change this to other units such as megabits (m), megabytes (M), or kilobytes (K):

    nload -u M

  • Adjust the refresh interval: Use the -t flag to set the update interval in milliseconds (default is 500 ms):

    nload -t 1000
