Securely Erase an SSD Using hdparm in Ubuntu

Securely erasing a Solid-State Drive (SSD) in Ubuntu ensures that all data is permanently destroyed while restoring the drive to its original factory performance levels. This guide explains how to use the hdparm command-line utility to execute a hardware-level ATA Secure Erase on SATA SSDs. By following a few straightforward terminal commands to unfreeze the drive, set a temporary password, and issue the erase command, you can safely wipe your storage device.

Step 1: Install hdparm and Identify Your SSD

Open your terminal and install hdparm if it is not already installed:

sudo apt update && sudo apt install hdparm

Next, list your storage devices to identify the correct drive identifier for your target SATA SSD:

lsblk

Note: Replace /dev/sdX in all subsequent commands with your actual drive identifier (such as /dev/sdb). Make sure you select the correct drive, as this process permanently deletes all data.

Step 2: Check the SSD Security Status

Inspect the current security state of your drive:

sudo hdparm -I /dev/sdX

Scroll down to the Security section near the bottom of the output and check the status:

  • not frozen: The drive must display not frozen to accept secure erase commands. If it shows frozen, put your computer to sleep (suspend) and wake it up to unlock the drive.
  • not enabled: Drive security should be disabled before starting.

Step 3: Set a Temporary Security Password

ATA Secure Erase requires a temporary security password to be assigned to the drive before performing the operation. Set the password to NULL using the following command:

sudo hdparm --user-pass p NULL /dev/sdX

Step 4: Execute the Secure Erase Command

Once the temporary password is set, run the command to securely erase the drive:

sudo hdparm --user-pass p NULL --security-erase NULL /dev/sdX

If your drive supports Enhanced Secure Erase (as indicated in the hdparm -I output), you can use this command instead:

sudo hdparm --user-pass p NULL --security-erase-enhanced NULL /dev/sdX

This process typically finishes within a few seconds to a couple of minutes.

Step 5: Verify the Erase Process

After the command finishes, verify that the temporary password was removed automatically and the drive is no longer locked:

sudo hdparm -I /dev/sdX

Under the Security section, the status should now show not enabled. The SSD is now completely wiped, reset to factory settings, and ready to be partitioned or reformatted.
