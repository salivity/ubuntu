How to Enable SELinux on Ubuntu Instead of AppArmor

Ubuntu systems utilize AppArmor by default to provide Mandatory Access Control (MAC), but administrators can replace it with Security-Enhanced Linux (SELinux) to meet specific enterprise compliance or operational standards. This transition requires disabling the existing AppArmor service, installing the necessary SELinux policy and utility packages, configuring GRUB boot parameters, relabeling the entire filesystem, and switching the SELinux operational mode from permissive to enforcing.

Step 1: Remove and Disable AppArmor

Before enabling SELinux, the running AppArmor service must be stopped and prevented from starting at boot to prevent conflicts between the two security frameworks.

Stop the AppArmor systemd service:

sudo systemctl stop apparmor

Disable the service and unload its profiles:

sudo systemctl disable apparmor
sudo systemctl mask apparmor

To prevent AppArmor from initializing during the kernel boot phase, remove the package:

sudo apt purge apparmor -y

Step 2: Install SELinux Utilities and Policies

Ubuntu provides SELinux packages through its standard repositories. Install the base utilities, core policies, and the audit daemon.

Update package lists and install the packages:

sudo apt update
sudo apt install policycoreutils selinux-utils selinux-basics selinux-policy-default auditd -y

Step 3: Activate the SELinux Configuration

Run the activation script provided by the selinux-basics package. This utility configures the bootloader and prepares the system for SELinux initialization:

sudo selinux-activate

This command automatically modifies the GRUB configuration to pass the required kernel parameters (security=selinux selinux=1) and sets the initial state to permissive in /etc/selinux/config.

Step 4: Relabel the Filesystem

Filesystems transitioning to SELinux must have extended attributes (security contexts) applied to all files. To trigger an automatic relabel during the next boot, create a flag file in the root directory:

sudo touch /.autorelabel

Reboot the system to begin the relabeling process:

sudo reboot

The system will relabel all files during startup. Depending on the size and speed of the disk storage, this process may take several minutes. Once complete, the machine will automatically reboot into the operating system.

Step 5: Verify Permissive Operation

After the system boots, log in and verify that SELinux is running:

sestatus

The output should confirm:

  • SELinux status: enabled
  • Current mode: permissive
  • Mode from config file: permissive

Check the audit logs to ensure that no critical system services are generating excessive access denials (AVCs):

sudo ausearch -m AVC,USER_AVC -ts recent

Step 6: Switch SELinux to Enforcing Mode

Once satisfied that the system is operating normally without breaking required services, switch SELinux to enforcing mode.

Open the SELinux configuration file:

sudo nano /etc/selinux/config

Locate the SELINUX= directive and change its value from permissive to enforcing:

SELINUX=enforcing
SELINUXTYPE=default

Save the file and exit the editor. You can apply the change immediately without a reboot:

sudo setenforce 1

Confirm the active state by running:

getenforce

The command will output Enforcing, confirming that SELinux is actively governing access control policies on your Ubuntu system.
