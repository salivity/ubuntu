Install and Configure Cockpit on Ubuntu Server

This guide explains how to install and configure Cockpit, an intuitive web-based management interface, on an Ubuntu server. You will learn how to prepare your system, install the necessary Cockpit packages using the default repositories, configure the UFW firewall to allow secure web traffic, and access the web console to monitor resources and manage system services remotely.

Prerequisites

  • A server running Ubuntu 20.04, 22.04, or 24.04 LTS.
  • A user account with sudo administrative privileges.
  • Access to a terminal session or SSH connection.

Step 1: Update the System Packages

Ensure your package index is up to date before installing new software. Open your terminal and run:

sudo apt update && sudo apt upgrade -y

Step 2: Install Cockpit

Cockpit is available in the official Ubuntu repositories. Install the base package with the following command:

sudo apt install cockpit -y

Step 3: Enable and Start the Cockpit Service

Cockpit relies on systemd socket activation to run. Start and enable the Cockpit socket so it automatically loads upon system reboot:

sudo systemctl start cockpit.socket
sudo systemctl enable cockpit.socket

Verify that the socket is active:

sudo systemctl status cockpit.socket

You should see an output indicating the status is active (listening).

Step 4: Configure the Firewall

Cockpit communicates over port 9090 via HTTPS. If you have the Uncomplicated Firewall (UFW) enabled, you must open this port to allow incoming connections:

sudo ufw allow 9090/tcp
sudo ufw reload

Verify that the rule has been added:

sudo ufw status

Step 5: Access the Cockpit Web Interface

  1. Open a web browser on your local computer.
  2. Navigate to your server's IP address or domain name followed by port 9090: 
    https://your_server_ip:9090
  3. Your browser may display an SSL warning because Cockpit generates a self-signed certificate by default. Proceed past the warning (e.g., click "Advanced" and then "Proceed to site").
  4. Enter your Ubuntu user credentials at the login prompt. Check the box to reuse your password for administrative tasks if prompted.

Step 6: Install Additional Cockpit Modules (Optional)

Cockpit's functionality can be extended using modular plugins for storage management, network configuration, and virtual machine management:

  • Storage Management: 
    sudo apt install cockpit-storaged -y
  • Virtual Machine Management (KVM/QEMU): 
    sudo apt install cockpit-machines -y
  • Container Management (Podman): 
    sudo apt install cockpit-podman -y

After installing any extension, refresh your browser session to access the new tabs in the left sidebar menu.
