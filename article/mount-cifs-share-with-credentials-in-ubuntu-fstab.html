Mount CIFS Share with Credentials in Ubuntu fstab

This guide outlines how to automatically mount a remote Common Internet File System (CIFS) or SMB network share using the /etc/fstab file on Ubuntu. By storing explicit authentication credentials in a secured local file, you ensure persistent access to the network share upon system reboot without exposing sensitive account passwords to unprivileged system users.

Step 1: Install Required Utilities

Ubuntu requires the cifs-utils package to handle CIFS and SMB file systems. Open a terminal and install it using:

sudo apt update
sudo apt install cifs-utils -y

Step 2: Create the Mount Point

Create a local directory where the remote share will be mounted:

sudo mkdir -p /mnt/networkshare

Step 3: Securely Store User Credentials

Rather than writing credentials in plain text directly in /etc/fstab, store them in a protected credentials file.

  1. Create a credentials file (for example, at /etc/cifs-credentials):
sudo nano /etc/cifs-credentials
  1. Add your remote share credentials in the following format:
username=your_username
password=your_password
domain=your_domain_or_workgroup

(Note: Omit the domain line if your setup does not use a domain or workgroup).

  1. Restrict permissions so that only the root user can read the file:
sudo chmod 600 /etc/cifs-credentials

Step 4: Find Your Local User and Group IDs

To ensure your regular Ubuntu user has permission to read and write to the mounted share, determine your local User ID (uid) and Group ID (gid):

id

Make note of the numerical uid and gid values (usually 1000 for the first created user).

Step 5: Edit the fstab File

Open /etc/fstab in a text editor with administrative privileges:

sudo nano /etc/fstab

Append a new line to the end of the file with the following format:

//server_ip_or_hostname/share_name /mnt/networkshare cifs credentials=/etc/cifs-credentials,uid=1000,gid=1000,file_mode=0775,dir_mode=0775,_netdev,nofail 0 0

Key options explained:

  • cifs: Specifies the filesystem type.
  • credentials=/etc/cifs-credentials: Points to the file containing the login details.
  • uid=1000,gid=1000: Maps the ownership of the files to your local user and group.
  • file_mode=0775,dir_mode=0775: Sets the read/write/execute permissions for files and directories.
  • _netdev: Waits until network services are active before attempting to mount the drive.
  • nofail: Allows the operating system to finish booting even if the remote share is unreachable.

Save the file and exit the text editor.

Step 6: Test the Mount Configuration

Test the configuration without rebooting to verify there are no syntax errors or authentication failures:

sudo mount -a

If the command executes without displaying errors, check the mount point to confirm access to the remote files:

ls -l /mnt/networkshare

The share will now mount automatically whenever the system boots.
