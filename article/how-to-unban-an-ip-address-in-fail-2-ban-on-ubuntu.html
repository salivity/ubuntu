How to Unban an IP Address in Fail2ban on Ubuntu

Fail2ban secures Ubuntu servers by monitoring log files and banning IP addresses that show malicious signs, such as too many failed login attempts. However, legitimate users are occasionally locked out due to accidental credential errors. This guide provides the direct commands required to check banned IP lists, identify the relevant jail, and immediately unban an IP address using the Fail2ban client.

Step 1: Identify the Jail Name

Fail2ban organizes its firewall rules into "jails" based on the service being protected (such as SSH, Nginx, or Postfix). Before unbanning an IP, you must identify which jail triggered the ban.

Run the following command to see all active jails:

sudo fail2ban-client status

The output will list the active jails under Jail list. For example:

`- Jail list:   sshd, nginx-http-auth

Step 2: Confirm the Banned IP Address

To see the list of banned IPs within a specific jail (for instance, sshd), execute:

sudo fail2ban-client status sshd

Locate the Banned IP list in the output to confirm that the target IP address is present.

Step 3: Unban the IP Address

Once you know the jail name and the banned IP, you can remove the ban using the set unbanip command.

Use the following syntax:

sudo fail2ban-client set <jail_name> unbanip <ip_address>

For example, to unban the IP 192.0.2.1 from the sshd jail:

sudo fail2ban-client set sshd unbanip 192.0.2.1

If the unban is successful, the terminal will return the unbanned IP address:

192.0.2.1

Alternative: Unban an IP Across All Jails

If you do not know which jail banned the IP address, or if it was banned across multiple services, you can issue a universal unban command:

sudo fail2ban-client unban 192.0.2.1

Fail2ban will automatically search through all active jails and lift the ban for that address.

Step 4: Verify the Removal

Confirm that the IP address has been successfully removed by querying the jail's status again:

sudo fail2ban-client status sshd

The IP address should no longer appear in the Banned IP list.
