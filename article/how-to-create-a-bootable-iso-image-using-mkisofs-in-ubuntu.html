How to Create a Bootable ISO Image Using mkisofs in Ubuntu

Creating a bootable ISO image from a directory in Ubuntu allows you to package custom system files, live environments, or installation media into a single deployable file. This guide provides the exact mkisofs command syntax required to generate an El Torito bootable ISO image from a local folder, along with an explanation of each essential flag used in the process.

Installing the Required Tools

On modern Ubuntu systems, the original mkisofs tool is provided by the genisoimage package, which maintains full command-line compatibility with mkisofs. To install it, open your terminal and run:

sudo apt update
sudo apt install genisoimage

Once installed, running mkisofs will automatically call genisoimage.

The Command to Create a Bootable ISO

To create a bootable ISO image using the standard El Torito boot record (commonly used by ISOLINUX or GRUB bootloaders), use the following command structure:

mkisofs -o output.iso \
  -b isolinux/isolinux.bin \
  -c isolinux/boot.cat \
  -no-emul-boot \
  -boot-load-size 4 \
  -boot-info-table \
  -J -R -V "CUSTOM_BOOT_ISO" \
  /path/to/source_directory

Command Parameters Explained

  • -o output.iso: Specifies the path and file name of the generated ISO image.
  • -b isolinux/isolinux.bin: Specifies the location of the boot image relative to the root of the source directory (do not use an absolute path).
  • -c isolinux/boot.cat: Specifies the location of the boot catalog file relative to the root of the source directory.
  • -no-emul-boot: Indicates that the boot image is loaded directly without floppy or hard disk emulation.
  • -boot-load-size 4: Sets the number of virtual (512-byte) sectors to load in non-emulated boot mode (4 is standard for BIOS bootloaders).
  • -boot-info-table: Modifies the boot image at build time by adding a 56-byte table containing layout information mandatory for bootloaders like ISOLINUX.
  • -J: Generates Joliet directory records for compatibility with Windows systems.
  • -R: Generates Rock Ridge records to preserve Linux file permissions, ownership, and long filenames.
  • -V "CUSTOM_BOOT_ISO": Assigns a volume label to the generated ISO.
  • /path/to/source_directory: The directory containing all the extracted files and the bootloader binaries.

Example Usage

If your bootable files are located in a folder named my_iso_root inside your home directory, and you want to save the final file as custom_boot.iso on your Desktop:

mkisofs -o ~/Desktop/custom_boot.iso \
  -b isolinux/isolinux.bin \
  -c isolinux/boot.cat \
  -no-emul-boot \
  -boot-load-size 4 \
  -boot-info-table \
  -J -R -V "Ubuntu_Custom" \
  ~/my_iso_root

After the command executes, the custom_boot.iso file will be ready to be burned to media or booted inside a virtual machine.
