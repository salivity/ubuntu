Share Ubuntu Terminal in Real-Time Using tmate

Sharing a live terminal session is an essential capability for remote troubleshooting, pair programming, and technical demonstrations. This guide explains how to use tmate, an open-source terminal multiplexer built on top of tmux, to instantly broadcast your active Ubuntu command-line session over the internet. You will learn how to install tmate on Ubuntu, launch a session, retrieve secure connection links for remote viewers, and terminate the session safely.

Step 1: Install tmate on Ubuntu

tmate is available in the official Ubuntu repositories. Open your terminal and run the following commands to update your package lists and install the tool:

sudo apt update
sudo apt install tmate -y

Step 2: Launch a tmate Session

To start a new session, run:

tmate

When tmate starts, it launches a new terminal environment and connects to the official tmate cloud servers in the background to generate unique SSH and web access credentials.

Step 3: Retrieve Session Sharing Links

Upon launch, connection links temporarily appear at the bottom of the screen. To view them at any time, run:

tmate show-messages

You will see several connection strings:

  • SSH (read-write): Allows the remote user to view and run commands. 
    ssh session-token@lon1.tmate.io
  • Web URL (read-write): Allows the remote user to interact with the terminal via a web browser. 
    https://tmate.io/t/session-token
  • SSH (read-only): Allows the remote user to view output only without executing commands. 
    ssh ro-session-token@lon1.tmate.io
  • Web URL (read-only): Allows read-only viewing in a browser. 
    https://tmate.io/t/ro-session-token

Choose the appropriate link depending on whether you want your collaborator to have interactive control or view-only access, then share it with them.

Step 4: Access the Session from a Remote Client

Remote collaborators do not need tmate installed on their machines to connect.

  • Using SSH: The collaborator pastes the provided SSH command directly into their local terminal: 
    ssh session-token@lon1.tmate.io
  • Using a Browser: The collaborator pastes the web link into any modern web browser to interact with or view the terminal.

All keystrokes and outputs synchronize instantly across all connected users.

Step 5: End the Session

To disconnect all collaborators and terminate the session, type exit in the tmate shell or press Ctrl + D. Once the shell exits, the generated session tokens immediately become invalid.
