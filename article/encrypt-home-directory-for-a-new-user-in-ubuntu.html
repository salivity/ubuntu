Encrypt Home Directory for a New User in Ubuntu

Encrypting a home directory in Ubuntu adds an essential layer of security by protecting personal files and sensitive data from unauthorized physical or offline access. This article provides a clear, step-by-step guide on how to install the necessary encryption utilities and create a brand-new user account with an automatically encrypted home directory using the Ubuntu terminal.

Step 1: Install Required Encryption Utilities

Before creating an encrypted user, you must install the ecryptfs-utils and pam_ecryptfs packages, which provide the underlying software for directory encryption.

Open your terminal and run the following command:

sudo apt update && sudo apt install ecryptfs-utils pam-ecryptfs

Step 2: Create the New User with an Encrypted Home Directory

To create a new user account with an encrypted home directory, use the adduser command along with the --encrypthome flag.

Replace newuser with your preferred username:

sudo adduser --encrypthome newuser

During this process, you will be prompted to:

  1. Enter and confirm a password for the new account.
  2. Enter optional user information (Full Name, Room Number, etc.).
  3. Confirm that the information is correct by typing Y.

Step 3: Record the Encrypted Passphrase

After creating the user, log in as the newly created user to generate and view the unique recovery passphrase. This passphrase is critical for recovering data if the system crashes or if you need to access the home directory from a live CD.

  1. Switch to the new user account:
su - newuser
  1. Display the automatic recovery passphrase:
ecryptfs-unwrap-passphrase
  1. Enter the account password when prompted. Save the displayed passphrase in a secure, offline location.

Step 4: Verify the Encryption

To confirm that the home directory is successfully encrypted:

  1. Log out of the new user account:
exit
  1. Check the mount status while logged in as a different user:
ls -la /home/newuser

When the user is logged out, the contents of /home/newuser will appear as encrypted files or restricted directories. Once the user logs in, the directory is automatically decrypted and mounted for transparent use.
