How to Set Up HAProxy Reverse Proxy on Ubuntu

Setting up a reverse proxy with HAProxy on Ubuntu involves updating your system packages, installing the HAProxy service, configuring the frontend and backend settings in the main configuration file, verifying the configuration syntax, and enabling the service to manage incoming web traffic efficiently across target backend servers.

Step 1: Update System Packages and Install HAProxy

Open your terminal and update the local package index to ensure access to the latest software repositories:

sudo apt update
sudo apt upgrade -y

Install HAProxy using the default package manager:

sudo apt install haproxy -y

Confirm the installation and verify the installed version:

haproxy -v

Step 2: Configure HAProxy as a Reverse Proxy

Create a backup of the original configuration file before making modifications:

sudo cp /etc/haproxy/haproxy.cfg /etc/haproxy/haproxy.cfg.bak

Open the primary configuration file using a text editor:

sudo nano /etc/haproxy/haproxy.cfg

Append the frontend and backend sections at the bottom of the file. The frontend section defines how HAProxy listens for incoming connections, while the backend section specifies the destination servers:

frontend main_frontend
    bind *:80
    mode http
    default_backend main_backend

backend main_backend
    mode http
    balance roundrobin
    server web1 192.168.1.10:80 check
    server web2 192.168.1.11:80 check

Replace 192.168.1.10 and 192.168.1.11 with the actual IP addresses or hostnames of your backend servers.

Save and exit the text editor.

Step 3: Validate the Configuration File

Check the configuration file for any syntax errors before restarting the service:

sudo haproxy -c -f /etc/haproxy/haproxy.cfg

If the syntax is correct, the output will display Configuration file is valid.

Step 4: Restart and Enable HAProxy

Restart HAProxy to apply the configuration changes:

sudo systemctl restart haproxy

Set the service to launch automatically upon system startup:

sudo systemctl enable haproxy

Verify that the service is active and running:

sudo systemctl status haproxy

Step 5: Configure Firewall Rules

If UFW (Uncomplicated Firewall) is enabled on your Ubuntu server, allow HTTP traffic through port 80:

sudo ufw allow 80/tcp
sudo ufw reload

Step 6: Test the Reverse Proxy

Test the connection by sending an HTTP request to the HAProxy server’s IP address:

curl http://YOUR_SERVER_IP

HAProxy will handle the incoming request and forward it to one of the backend servers defined in the backend block.
