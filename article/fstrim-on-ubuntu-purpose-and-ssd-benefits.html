fstrim on Ubuntu: Purpose and SSD Benefits

The fstrim command is an essential Linux utility designed to optimize the performance and longevity of Solid State Drives (SSDs). This article explains what the fstrim command does, the mechanics of how it handles discarded filesystem blocks, and the specific benefits it delivers to SSDs running on an Ubuntu operating system.

What is the fstrim Command?

The fstrim command is used on a mounted filesystem to discard (or "trim") blocks that are no longer in use by the operating system. When you delete a file in Ubuntu, the operating system marks the storage space occupied by that file as available, but it does not immediately inform the underlying storage hardware. The fstrim tool queries the filesystem and passes this list of unused memory blocks directly to the SSD via the ATA or NVMe TRIM command.

Why SSDs Require TRIM

Unlike traditional mechanical hard drives, which can overwrite existing sectors in a single operation, SSDs use NAND flash memory that cannot overwrite existing data directly. Data on an SSD is written in smaller units called pages, but can only be erased in larger groups called blocks.

Without TRIM support, an SSD does not know a deleted file's pages are invalid. When the drive runs out of empty blocks, it must perform a "read-erase-modify-write" cycle: reading the entire block into cache, erasing the entire block on the drive, and then writing the new data alongside the old valid data. This process creates high latency and causes significant performance degradation over time.

Benefits of fstrim on Ubuntu

Running fstrim provides several distinct advantages for Ubuntu systems installed on SSDs:

  • Restored Write Performance: By periodically notifying the SSD of unused pages, the drive's background garbage collection can clear entire blocks ahead of time. This ensures that new write operations write directly to empty pages without wait cycles.
  • Reduced Write Amplification: Write amplification occurs when the drive writes more physical data to the flash cells than the host system requested. Clearing deleted blocks prevents the SSD controller from needlessly moving stale data during internal maintenance cycles.
  • Extended Drive Lifespan: NAND flash memory cells have a finite number of program/erase (P/E) cycles. By lowering write amplification and minimizing unnecessary block rewrites, fstrim helps preserve the physical lifespan of the drive.

Periodic Trimming vs. Continuous Discard

Ubuntu utilizes periodic trimming via fstrim rather than continuous trimming (the discard mount option in /etc/fstab). Continuous trimming issues a TRIM command every time a file is deleted, which can introduce noticeable I/O bottlenecks during routine file operations. Periodic trimming batches this maintenance into an efficient background task.

In modern Ubuntu releases, this process is automated through a systemd service and timer unit named fstrim.timer. By default, this service executes the fstrim -av command once a week, scanning all mounted and supported filesystems, trimming unused space, and maintaining drive health without requiring manual user intervention.
