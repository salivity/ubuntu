Launch Primary Multipass Instance on macOS

This guide explains how to initialize and configure a primary Ubuntu virtual machine on a macOS host using Canonical's Multipass. You will learn how to deploy the instance using standard terminal commands, allocate specific system resources, access the shell, and leverage the built-in host integration features unique to the primary instance.

Step 1: Open the Terminal

Launch your preferred macOS terminal application (such as Terminal or iTerm2). Ensure Multipass is installed and running on your system by verifying its version:

multipass version

Step 2: Launch the Primary Instance

In Multipass, the name primary is reserved for a special default instance that integrates seamlessly with your host system.

To launch the primary instance with default settings (1 CPU, 1 GB RAM, 5 GB storage), run:

multipass launch --name primary

Alternatively, you can customize the hardware allocation by specifying CPU cores, memory, and disk space flags:

multipass launch --name primary --cpus 2 --memory 4G --disk 20G

Note: If no primary instance exists, simply executing multipass shell will automatically launch a standard primary instance and log you in immediately.

Step 3: Access the Primary Instance

Once the initialization process finishes, connect to the primary instance's command line using the shell command without needing to specify an instance name:

multipass shell

You are now logged into the Ubuntu environment as the default ubuntu user.

Step 4: Mount Host Directories (Optional)

The primary instance allows automatic integration with your macOS environment. You can map your macOS user home directory into the primary instance using:

multipass mount $HOME primary

Inside the instance, your macOS files will be accessible under the mounted path.

Step 5: Managing the Instance

You can manage the lifecycle of your primary instance from the macOS terminal with the following standard commands:

  • View status: multipass list
  • Stop the instance: multipass stop primary
  • Start the instance: multipass start primary
  • Delete the instance: multipass delete primary
  • Permanently remove deleted instances: multipass purge
