Encrypt a File with GPG Symmetric Encryption on Ubuntu

This guide provides a straightforward walkthrough on how to protect a single file on Ubuntu using GnuPG's built-in symmetric encryption feature. Symmetric encryption uses a single password or passphrase to both lock and unlock data, eliminating the need to generate or manage public and private key pairs. Below, you will find the step-by-step commands to install the required tools, encrypt a file with a secure passphrase, and decrypt it when needed.

1. Install GnuPG

GnuPG (gpg) is installed by default on most Ubuntu installations. If it is missing from your system, update your package list and install it using the terminal:

sudo apt update
sudo apt install gnupg

2. Encrypt the File

To encrypt a file symmetrically, use the gpg command with the -c (or --symmetric) flag.

Run the following command, replacing example.txt with the name of your file:

gpg -c example.txt

A prompt will appear asking you to enter and confirm a passphrase. Choose a strong, memorable passphrase; if you lose it, the encrypted data cannot be recovered.

Once complete, GnuPG creates a new file in the same directory with the .gpg extension (for example, example.txt.gpg). By default, modern versions of GnuPG use the AES-256 cipher for symmetric encryption.

If you want to explicitly specify the AES-256 cipher, run:

gpg --symmetric --cipher-algo AES256 example.txt

3. Secure the Original File

Encrypting a file does not automatically delete the unencrypted original. Once you verify that the .gpg file has been created, remove the plain text file:

rm example.txt

(Optional) For sensitive data, you can overwrite the file before deleting it using shred:

shred -u -z example.txt

4. Decrypt the File

To restore the original file from the encrypted .gpg file, use the -d (or --decrypt) flag:

gpg -d example.txt.gpg > example.txt

You will be prompted to enter the passphrase you set during encryption. Once entered correctly, GnuPG decrypts the content and writes it back to example.txt. Alternatively, running gpg example.txt.gpg will decrypt the file and automatically restore it to its original filename without requiring output redirection.
