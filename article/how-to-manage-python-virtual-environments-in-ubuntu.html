How to Manage Python Virtual Environments in Ubuntu

Python virtual environments allow developers to create isolated spaces for project dependencies, preventing conflicts between package versions across different projects on Ubuntu. This guide explains how to install the required tools, create and activate a virtual environment, manage packages with pip, deactivate the environment, and remove it completely using the Ubuntu command line.

1. Install python3-venv

Before creating a virtual environment, ensure your system package list is updated and install the python3-venv package, which provides the standard library module for creating virtual environments.

sudo apt update
sudo apt install python3-venv python3-pip -y

2. Create a Virtual Environment

Navigate to your project directory in the terminal, then run the venv module. Replace myenv with your preferred environment name.

cd /path/to/your/project
python3 -m venv myenv

This creates a directory named myenv containing a standalone Python executable and package structure.

3. Activate the Virtual Environment

To start using the isolated environment, activate it using the source command:

source myenv/bin/activate

Once activated, your terminal prompt will display the environment name in parentheses, indicating that any Python or Pip commands will execute within this isolated context.

4. Install Packages

With the environment activated, install dependencies using pip. These packages will remain inside the virtual environment directory and will not affect the system-wide Python installation.

pip install package_name

To save your installed dependencies to a file for reproducibility, run:

pip freeze > requirements.txt

To install packages from an existing requirements file in another environment, use:

pip install -r requirements.txt

5. Deactivate the Environment

When you are finished working on your project, turn off the virtual environment by running:

deactivate

Your shell prompt will return to its standard display, and system-wide commands will resume.

6. Delete a Virtual Environment

To completely remove a virtual environment, simply delete its directory using the command line:

rm -rf myenv
