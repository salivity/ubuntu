How to Help Translate the Ubuntu Interface

Translating the Ubuntu interface into different languages is an open, community-driven process that allows anyone to contribute to making the operating system accessible worldwide. By creating a Launchpad account, joining a language-specific translation team, and using Canonical's web-based localization tools, volunteers can easily translate untranslated text strings, suggest improvements, and review submissions for upcoming Ubuntu releases.

Step 1: Create a Launchpad Account

All Ubuntu translation work is managed through Launchpad, Canonical's collaboration platform. To get started, create a free Launchpad account. This account serves as your profile for all contributions across the Ubuntu ecosystem.

Step 2: Find and Join Your Language Team

Ubuntu relies on dedicated localization teams for individual languages to maintain translation quality.

  • Navigate to the main Ubuntu Translations section on Launchpad.
  • Locate your target language in the list of active translation teams.
  • Request to join the team or review their specific guidelines for new contributors. Most language teams maintain style guides and glossaries to ensure consistency across the operating system.

Step 3: Select a Software Package

Once logged in, you can browse the software packages that need translation for active or upcoming Ubuntu releases.

  • Select the current development release or a supported Long Term Support (LTS) version.
  • Filter packages by translation status to view those with untranslated or untrusted strings.
  • Choose a package to open its web-based translation interface.

Step 4: Submit Text Translations

The translation interface displays the original English source string alongside an input field for your target language.

  • Type the accurate translation into the field provided.
  • Maintain special characters, system variables (such as %s or {0}), and punctuation exactly as they appear in the source string.
  • Submit the translation. If you do not have direct permission to commit translations for your team, your entry will be submitted as a suggestion for review.

Step 5: Peer Review and Quality Assurance

To maintain high standards, members of the specific language team review new suggestions. Reviewers check for proper grammar, contextual accuracy, and adherence to the language style guide. Once approved, your translations are packaged into system updates and delivered directly to millions of Ubuntu users worldwide.
