Speed Up C/C++ Compilation on Ubuntu with ccache

This article explores the role of ccache (compiler cache) in accelerating C and C++ build times on Ubuntu systems. By capturing and storing the results of previous compilations, ccache detects identical source files and compiler flags, retrieving cached object files instead of recompiling code from scratch. Below, you will learn how ccache works behind the scenes, how to install and enable it on Ubuntu, and how to integrate it seamlessly into modern build systems to significantly reduce development cycle times.

How ccache Works

When building C or C++ projects, the compiler converts source files into object files—a computationally expensive process involving preprocessing, parsing, optimization, and code generation. Often, developers only modify a small subset of files between builds, or switch between Git branches where previous states are restored. Standard build systems like make rely primarily on file modification timestamps to decide what needs rebuilding, often triggering unnecessary recompilations if timestamps change.

ccache acts as a wrapper around your compiler (such as GCC or Clang). When a compilation command is invoked, ccache performs the following steps:

  1. Hashing the Input: It hashes the preprocessed source code, compiler options, compiler binary hash, and environment settings.
  2. Cache Lookup: It checks its local storage (usually located in ~/.cache/ccache or ~/.ccache) for a matching hash.
  3. Cache Hit: If an identical compilation exists, ccache immediately produces the cached object code and replays any stored compiler warnings, bypassing the actual compilation entirely.
  4. Cache Miss: If the hash is new, ccache executes the real compiler, writes the output to the destination, and stores a copy of the object file in the cache for future use.

Because cache hits avoid parsing and optimization steps entirely, recompilation times can drop by 5x to 10x or more for unchanged compilation units.

Installing and Activating ccache on Ubuntu

Ubuntu includes ccache in its standard package repositories. You can install it using apt:

sudo apt update
sudo apt install ccache

Once installed, Ubuntu provides compiler symlinks in /usr/lib/ccache. To enable ccache system-wide for your user session, prepend this directory to your PATH environment variable by adding the following line to your ~/.bashrc or ~/.profile:

export PATH="/usr/lib/ccache:$PATH"

After reloading your shell (source ~/.bashrc), running which gcc or which g++ should point to /usr/lib/ccache/gcc and /usr/lib/ccache/g++.

Integration with Build Systems

CMake

For projects using CMake, you can enable ccache without altering system-wide symlinks by setting the compiler launcher variables:

cmake -B build -DCMAKE_C_COMPILER_LAUNCHER=ccache -DCMAKE_CXX_COMPILER_LAUNCHER=ccache

Alternatively, add the configuration directly inside your CMakeLists.txt:

find_program(CCACHE_PROGRAM ccache)
if(CCACHE_PROGRAM)
    set(CMAKE_C_COMPILER_LAUNCHER "${CCACHE_PROGRAM}")
    set(CMAKE_CXX_COMPILER_LAUNCHER "${CCACHE_PROGRAM}")
endif()

Make

For standard Makefiles, define the CC and CXX variables explicitly:

make CC="ccache gcc" CXX="ccache g++"

Monitoring and Managing the Cache

ccache includes a command-line interface to monitor cache usage and verify performance gains.

  • View Statistics: Run ccache -s to view your hit rate, miss rate, and cache size.
  • Set Cache Size: By default, ccache limits storage to 5 GB. For large codebases, increase this limit (for example, to 20 GB) using: 
    ccache -M 20G
  • Clear Statistics: Reset the counters with ccache -z to measure stats for a single build.
  • Clear Cache: Remove all cached objects with ccache -C.

By skipping redundant compilation passes, ccache dramatically shortens incremental build times and context-switching overhead on Ubuntu development environments.
