How to Install and Configure HAProxy on Ubuntu

HAProxy (High Availability Proxy) is a fast, reliable, open-source solution for load balancing and proxying TCP and HTTP-based applications. This guide covers the process of installing HAProxy on an Ubuntu server, configuring basic HTTP load balancing using a round-robin algorithm, and verifying that incoming traffic is distributed across backend servers.

Prerequisites

  • An Ubuntu server (20.04 or 22.04 recommended) with sudo privileges.
  • At least two backend web servers (e.g., running Nginx or Apache) with distinct IP addresses to test load balancing.

Step 1: Update the System and Install HAProxy

Update your local package index and install HAProxy directly from the default Ubuntu repositories.

sudo apt update
sudo apt install haproxy -y

Once installed, verify that the HAProxy service is running:

sudo systemctl status haproxy

Step 2: Backup the Original Configuration

Before modifying the main configuration file, create a backup copy:

sudo cp /etc/haproxy/haproxy.cfg /etc/haproxy/haproxy.cfg.bak

Step 3: Configure HAProxy for Load Balancing

Open /etc/haproxy/haproxy.cfg in your preferred text editor:

sudo nano /etc/haproxy/haproxy.cfg

The configuration file consists of four main sections:

  • global: Sets system-wide parameters (log locations, user/group privileges).
  • defaults: Defines default settings applied to all frontend and backend sections.
  • frontend: Defines how requests are received (IP addresses, ports).
  • backend: Defines the pool of servers that process requests.

Add or modify the frontend and backend sections at the bottom of the file. Replace backend_server_1_IP and backend_server_2_IP with your actual backend server IP addresses:

frontend http_front
    bind *:80
    mode http
    default_backend http_back

backend http_back
    mode http
    balance roundrobin
    server web1 backend_server_1_IP:80 check
    server web2 backend_server_2_IP:80 check
  • bind *:80: Instructs HAProxy to listen on port 80 for all incoming network interfaces.
  • balance roundrobin: Distributes traffic sequentially among backend servers.
  • check: Enables health checks to ensure traffic is only sent to healthy servers.

Step 4: (Optional) Enable HAProxy Statistics

To monitor traffic through a web interface, add a listen section to /etc/haproxy/haproxy.cfg:

listen stats
    bind *:8404
    mode http
    stats enable
    stats uri /
    stats refresh 10s
    stats admin if LOCALHOST

Save and close the file.

Step 5: Test and Restart HAProxy

  1. Validate the configuration file for syntax errors:
sudo haproxy -c -f /etc/haproxy/haproxy.cfg

If the output displays Configuration file is valid, proceed to restart the service.

  1. Restart HAProxy to apply the changes:
sudo systemctl restart haproxy
  1. Enable HAProxy to start automatically on system boot:
sudo systemctl enable haproxy

Step 6: Test the Load Balancer

  1. Open a web browser or use curl to send requests to your HAProxy server's IP address:
curl http://your_haproxy_server_ip

  1. Run the command multiple times. If your backend web servers return unique content (e.g., displaying "Server 1" and "Server 2"), you will see the response alternate between the backend servers.

  2. If you enabled the statistics page, access http://your_haproxy_server_ip:8404 in a browser to view real-time traffic details and backend status.
