Configure Static DNS Using Netplan on Ubuntu

Configuring a static DNS server on Ubuntu using Netplan ensures your system consistently uses specific, reliable domain name resolvers instead of relying on dynamically assigned addresses from DHCP. This guide provides a straightforward process to locate your Netplan configuration file, update the YAML network settings with custom DNS server IP addresses, apply the changes, and verify your new DNS configuration.

Step 1: Locate Your Netplan Configuration File

Netplan stores its configuration files in the /etc/netplan/ directory. These files use the .yaml extension.

Open your terminal and list the contents of the directory to identify your configuration file:

ls /etc/netplan/

You will typically see a file named something like 01-netcfg.yaml, 50-cloud-init.yaml, or 00-installer-config.yaml.

Step 2: Edit the Netplan YAML File

Open the configuration file in a text editor using sudo. Replace 01-netcfg.yaml with the actual filename found in Step 1:

sudo nano /etc/netplan/01-netcfg.yaml

Locate the target network interface (such as eth0, enp0s3, or wlan0) under the ethernets or wifis section. Add the nameservers block under your specific network interface.

Here is an example configuration specifying Google DNS (8.8.8.8 and 8.8.4.4) and Cloudflare DNS (1.1.1.1):

network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: true
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
          - 1.1.1.1

Note: YAML files require strict indentation using spaces, not tabs. Align elements precisely as shown above.

Save the file and exit the text editor (in Nano, press Ctrl + O, Enter, then Ctrl + X).

Step 3: Test and Apply the Changes

Before permanently applying the configuration, test it for syntax errors using the netplan try command. This will automatically roll back changes after a timeout if network connectivity is lost.

sudo netplan try

If the test passes without errors, press Enter to accept the configuration. Alternatively, apply the changes directly with:

sudo netplan apply

Step 4: Verify the DNS Settings

To confirm that your system is actively using the newly configured static DNS servers, run the resolvectl command:

resolvectl status

Look for your active network interface in the output. The DNS Servers section should list the static IP addresses you defined in your Netplan file.
