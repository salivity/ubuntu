How to Set Up iBGP Session Using FRRouting on Ubuntu

Setting up an internal Border Gateway Protocol (iBGP) session using FRRouting (FRR) on Ubuntu allows routers within the same Autonomous System (AS) to exchange routing information efficiently. This guide covers installing FRRouting, enabling the BGP daemon, configuring node settings, and establishing a functional iBGP session between two Ubuntu systems.

1. Install FRRouting on Ubuntu

Update your system's package list and install FRRouting:

sudo apt update
sudo apt install frr frr-pythontools -y

2. Enable the BGP Daemon

By default, the BGP daemon in FRR is disabled. Open the daemons configuration file:

sudo nano /etc/frr/daemons

Find the line bgpd=no and change it to:

bgpd=yes

Save the file and restart FRR to apply the changes:

sudo systemctl restart frr

3. Configure Node A (Router A)

Assume Node A has IP 192.168.1.1 and Node B has IP 192.168.1.2. Both routers will use the same Autonomous System Number (ASN 65000).

Access the FRR shell interface on Node A:

sudo vtysh

Enter configuration mode and set up the iBGP session:

configure terminal
router bgp 65000
 bgp router-id 1.1.1.1
 neighbor 192.168.1.2 remote-as 65000
 address-family ipv4 unicast
  neighbor 192.168.1.2 activate
 exit-address-family
exit
write memory

4. Configure Node B (Router B)

Access the FRR shell interface on Node B:

sudo vtysh

Enter configuration mode and set up the reciprocal iBGP configuration targeting Node A:

configure terminal
router bgp 65000
 bgp router-id 2.2.2.2
 neighbor 192.168.1.1 remote-as 65000
 address-family ipv4 unicast
  neighbor 192.168.1.1 activate
 exit-address-family
exit
write memory

5. Verify the iBGP Connection Status

To check if the iBGP session has been established successfully, run the following command inside vtysh on either node:

show bgp summary

Look for the state column under the IPv4 Unicast neighbor list. If the connection is successful, the state will display Established or show a number under the MsgRcvd and MsgSent fields indicating prefix exchanges.
