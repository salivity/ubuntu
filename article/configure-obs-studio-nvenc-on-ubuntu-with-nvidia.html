Configure OBS Studio NVENC on Ubuntu with NVIDIA

Configuring the NVIDIA NVENC encoder in OBS Studio on Ubuntu allows you to leverage your NVIDIA GPU for hardware-accelerated video encoding, significantly reducing CPU load during streaming and recording. This guide provides a straightforward process to install the required proprietary NVIDIA drivers, install a fully compatible version of OBS Studio, and adjust the encoder settings within the application for optimal performance.

1. Install Proprietary NVIDIA Drivers

Hardware encoding requires the official proprietary NVIDIA drivers rather than the default open-source Nouveau drivers.

  1. Open your terminal and check for recommended drivers: 
    ubuntu-drivers devices
  2. Install the recommended proprietary driver automatically: 
    sudo ubuntu-drivers autoinstall
    (Alternatively, install a specific version: sudo apt install nvidia-driver-535)
  3. Reboot your system to load the driver: 
    sudo reboot
  4. After restarting, verify the installation by checking GPU status: 
    nvidia-smi

2. Install OBS Studio

To avoid sandboxing issues that may block access to the NVENC libraries, install OBS Studio via the official PPA rather than Snap or Flatpak.

  1. Add the official OBS Studio PPA: 
    sudo add-apt-repository ppa:obsproject/obs-studio
sudo apt update
  2. Install OBS Studio and the required FFmpeg dependencies: 
    sudo apt install ffmpeg obs-studio

3. Configure NVENC in OBS Studio

  1. Launch OBS Studio.
  2. Open Settings (located in the bottom right corner or via File > Settings).
  3. Select the Output tab from the left sidebar.
  4. Set the Output Mode dropdown at the top to Advanced.
  5. Configure the Streaming tab:
    • Video Encoder: Select NVIDIA NVENC H.264 (or HEVC / AV1 if your card supports it).
    • Rate Control: Set to CBR (Constant Bitrate).
    • Bitrate: Enter your desired target bitrate (e.g., 6000 Kbps for 1080p60 on standard platforms).
    • Keyframe Interval: Set to 2 s.
    • Preset: Choose based on quality needs (e.g., P5: Slow (Good Quality) or P6: Slower (Better Quality)).
    • Tuning: Set to High Quality.
  6. Configure the Recording tab (optional):
    • Video Encoder: Select NVIDIA NVENC H.264 or HEVC.
    • Rate Control: Set to CQP (Constant Quantization Parameter) for local recording.
    • CQ Level: Set between 18 (high quality) and 23 (standard quality).
  7. Click Apply, then OK.

4. Test the Configuration

Click Start Recording in the OBS main interface. To verify that your GPU is actively handling the encoding workload, open a terminal window and run:

watch -n 1 nvidia-smi

Look at the Enc column under the GPU utilization section; a non-zero percentage confirms that NVENC is actively encoding your session.
