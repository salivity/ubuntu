View Raw SMART Attributes of a Disk in Ubuntu

Monitoring the health of your storage drives is essential for preventing unexpected data loss and identifying failing hardware early. In Ubuntu, the primary command to view the raw Self-Monitoring, Analysis, and Reporting Technology (SMART) attributes of a disk is smartctl, which is provided by the smartmontools package. This guide covers how to install the package, execute the command to display raw SMART attributes, and target both traditional SATA drives and modern NVMe SSDs.

Installing smartmontools

The smartctl command is part of the smartmontools package. If it is not already installed on your Ubuntu system, install it using the package manager:

sudo apt update
sudo apt install smartmontools

Running the SMART Attribute Command

To view only the raw SMART attributes table for a specific disk, run smartctl with the -A (or --attributes) option:

sudo smartctl -A /dev/sda

To view complete SMART details—including drive model, firmware version, raw attributes, and error logs—use the -a option:

sudo smartctl -a /dev/sda

Checking NVMe SSDs

NVMe drives use a different device naming convention and SMART format. To view the SMART health information and raw attributes for an NVMe drive, run:

sudo smartctl -A /dev/nvme0n1

Finding Your Disk Device Name

If you do not know the identifier for your target disk, list all available storage devices using lsblk:

lsblk

Identify the main disk identifier from the list (such as sda, sdb, or nvme0n1) and append it to /dev/ when running smartctl.

Interpreting the Output

When viewing attributes for SATA drives, smartctl -A outputs a structured table. Key columns include:

  • ATTRIBUTE_NAME: The metric being evaluated (e.g., Reallocated_Sector_Ct, Power_On_Hours, Current_Pending_Sector).
  • VALUE: A normalized score set by the manufacturer (typically starts at 100 or 200 and decreases over time).
  • WORST: The lowest normalized value ever recorded for that drive.
  • THRESH: The critical threshold. If VALUE drops to or below THRESH, the drive is considered failing.
  • RAW_VALUE: The actual raw count reported by the hardware firmware, providing exact numbers for temperature, bad sectors, power cycles, and operating time.
