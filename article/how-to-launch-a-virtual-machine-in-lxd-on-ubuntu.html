How to Launch a Virtual Machine in LXD on Ubuntu

LXD is a next-generation system container and virtual machine manager that offers a unified user experience for both containers and VMs. While LXD was traditionally known for containerization, it natively supports running full hardware-assisted virtual machines using QEMU on Ubuntu. This guide details the exact steps required to initialize LXD, launch a virtual machine, manage its lifecycle, and access its command line.

Step 1: Install and Initialize LXD

Ubuntu typically comes with LXD pre-installed via Snap. If it is not present on your system, install it using the following command:

sudo snap install lxd

Once installed, initialize the LXD daemon to configure storage pools and network bridges. Run the initialization wizard and accept the default settings (or customize them based on your infrastructure requirements):

lxd init

Step 2: Launch a Virtual Machine

To launch a virtual machine instead of a standard container, pass the --vm flag to the lxc launch command. For example, to download, configure, and boot an Ubuntu 22.04 LTS VM named my-ubuntu-vm:

lxc launch ubuntu:22.04 my-ubuntu-vm --vm

LXD will download the official VM image, provision the dedicated storage volume, assign CPU and RAM resources, and start the virtual machine.

Step 3: Verify the Virtual Machine Status

To verify that the virtual machine is running and view its IP address, list all active LXD instances:

lxc list

In the output table, the TYPE column will state VIRTUAL-MACHINE, and the STATE column will show RUNNING.

Step 4: Access the Virtual Machine

To execute commands or open a root shell session inside the virtual machine, use the lxc exec command:

lxc exec my-ubuntu-vm -- bash

If you need full access to the VM's serial console (useful for viewing the system boot sequence or troubleshooting network issues), run:

lxc console my-ubuntu-vm

To exit the console session, press Ctrl+a followed by q.

Step 5: Stop and Delete the Virtual Machine

Manage the VM lifecycle using standard LXD operational commands.

To shut down the virtual machine cleanly:

lxc stop my-ubuntu-vm

To permanently remove the virtual machine and delete its associated storage disk:

lxc delete my-ubuntu-vm
