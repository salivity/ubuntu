Resize ext4 Filesystem on Active Ubuntu Partition

Resizing an ext4 filesystem on an active, mounted Ubuntu partition allows you to expand your available disk space without experiencing system downtime. While Linux supports online expansion (growing a mounted ext4 filesystem), it is important to note that shrinking an ext4 partition cannot be done online and requires unmounting the drive. This guide outlines the safe, step-by-step process to expand an active ext4 partition on Ubuntu using standard command-line utilities.

Step 1: Back Up Your Data

Before modifying partition tables or filesystems, create a full backup of critical data. Although online expansion of ext4 filesystems is highly reliable, hardware failures or accidental command errors can cause data loss.

Step 2: Check Current Disk Usage and Layout

Identify the target partition, its filesystem type, and whether it uses standard partitions or Logical Volume Management (LVM).

Run the following command to check mounted filesystems:

df -hT

To view the disk structure and block devices, run:

lsblk

Note the device name (e.g., /dev/sda3 or /dev/mapper/ubuntu--vg-ubuntu--lv) and the mount point (usually /).

Step 3: Expand the Underlying Storage

Depending on whether your system uses standard disk partitions or LVM, follow the appropriate method below.

Option A: Standard Disk Partitioning

If you expanded a virtual disk or added unallocated space right after your active partition, use growpart to expand the partition boundary.

  1. Install the cloud-guest-utils package if growpart is not present:

    sudo apt update && sudo apt install -y cloud-guest-utils

  2. Resize the partition (replace /dev/sda and 3 with your specific disk and partition number):

    sudo growpart /dev/sda 3

Option B: LVM (Logical Volume Manager)

If your Ubuntu installation uses LVM, you can extend the volume group and logical volume.

  1. If you added a new physical disk, initialize it and add it to your Volume Group:

    sudo pvcreate /dev/sdb
sudo vgextend ubuntu-vg /dev/sdb

  2. Extend the Logical Volume to fill all remaining free space:

    sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv

Step 4: Resize the ext4 Filesystem Online

Once the partition or logical volume has been enlarged, expand the ext4 filesystem to occupy the newly available space.

If using standard partitioning or separate lvextend steps, run resize2fs directly on the mounted partition:

sudo resize2fs /dev/sda3

(For LVM users, you can also pass the -r flag during lvextend to automatically resize the underlying ext4 filesystem in one command: sudo lvextend -r -l +100%FREE /dev/ubuntu-vg/ubuntu-lv).

The resize2fs tool automatically detects that the ext4 filesystem is mounted and performs an online expansion safely while the operating system remains fully active.

Step 5: Verify the New Filesystem Size

Confirm that the new storage space is available by checking the disk space again:

df -hT /

The output should now reflect the increased total capacity of your active ext4 partition.
