How to Install Hugo on Ubuntu

Installing Hugo on an Ubuntu development machine is a fast and straightforward process that can be accomplished in multiple ways, depending on whether you need the standard or the extended version. This guide outlines the most effective methods to get Hugo running on Ubuntu, covering the official APT package manager, Snap packages, and installing the latest release directly via the Debian package from GitHub.

Prerequisites

Before beginning, ensure you have access to a non-root user account with sudo privileges and a functional terminal window.

Method 1: Install Using Snap (Recommended for Extended Version)

Using Snap is often the easiest way to install the latest extended edition of Hugo, which includes support for Sass/SCSS compilation required by many modern themes.

  1. Update your system's package list:

    sudo apt update

  2. Install Hugo via Snap:

    sudo snap install hugo

  3. Verify the installation:

    hugo version

Method 2: Install via GitHub Debian Package (.deb)

If you prefer native packages without Snap, download the pre-compiled .deb binary directly from the official Hugo releases page.

  1. Check your system architecture:

    dpkg --print-architecture

    (Most modern machines will return amd64 or arm64.)

  2. Download the latest release: Replace the version number below with the latest release available from the official Hugo GitHub repository:

    wget https://github.com/gohugoio/hugo/releases/download/v0.125.0/hugo_extended_0.125.0_linux-amd64.deb

  3. Install the package:

    sudo dpkg -i hugo_extended_0.125.0_linux-amd64.deb

  4. Resolve any missing dependencies (if necessary):

    sudo apt install -f

  5. Verify the installation:

    hugo version

Method 3: Install via Ubuntu APT Repository

Ubuntu includes Hugo in its default package repositories. While this is the simplest method, the version provided in the APT repositories may lag behind the latest release and does not include the extended features.

  1. Update package lists:

    sudo apt update

  2. Install Hugo:

    sudo apt install hugo

  3. Verify the installation:

    hugo version

Verifying and Getting Started

Once installed via any of the methods above, confirm Hugo is working properly by running:

hugo version

To initialize your first Hugo project, navigate to your preferred development directory and run:

hugo new site my-new-site

This creates a new Hugo directory structure, ready for theme installation and content generation.
