How to Create a Persistent Dummy Interface on Ubuntu

A dummy network interface is a purely virtual adapter, similar to a loopback interface, commonly used for testing, network routing, and binding internal services to dedicated IP addresses. On modern Ubuntu systems, configuring a dummy interface to persist across system reboots requires loading the dummy kernel module at boot and defining the network parameters using Netplan. This guide walks you through the step-by-step process of setting up and verifying a persistent dummy interface on Ubuntu.

Step 1: Enable the Dummy Kernel Module at Boot

Before Ubuntu can manage a dummy device, the kernel must load the dummy module during startup.

  1. Create a configuration file in /etc/modules-load.d/ to load the module on boot:

    echo "dummy" | sudo tee /etc/modules-load.d/dummy.conf

  2. Load the module into the active kernel immediately without rebooting:

    sudo modprobe dummy

Step 2: Configure the Interface with Netplan

Ubuntu uses Netplan for network configuration. You can declare the dummy interface inside your Netplan YAML configuration files.

  1. Navigate to /etc/netplan/ and inspect existing configuration files:

    ls /etc/netplan/

  2. Create a dedicated configuration file for your virtual interfaces, such as /etc/netplan/99-dummy-interface.yaml:

    sudo nano /etc/netplan/99-dummy-interface.yaml

  3. Add the configuration for your dummy interface (replace dummy0 and 192.168.100.1/24 with your preferred interface name and static IP/subnet):

    network:
  version: 2
  renderer: networkd
  dummies:
    dummy0:
      addresses:
        - 192.168.100.1/24

  4. Save and close the file.

Step 3: Apply the Changes

Apply the new Netplan configuration to create and activate the interface:

sudo netplan apply

Step 4: Verify the Configuration

Verify that the dummy interface is active and has the assigned IP address:

ip addr show dummy0

The output should confirm the dummy0 interface is UP and displays the assigned IP address. The configuration is fully persistent and will automatically reload after system reboots.
