Revert Snap Package to Previous Version in Ubuntu

Ubuntu's Snap package manager automatically handles application updates in the background, but new releases can occasionally introduce bugs or disrupt your workflow. Fortunately, the Snap system retains older revisions of installed packages by default, allowing you to quickly roll back to a working release. This guide outlines how to check existing revisions, revert a package to its previous state, and optionally lock the version to prevent immediate re-updates.

1. View Available Package Revisions

Before reverting, check the currently installed and previous revisions of the application. Open your terminal and run:

snap list --all <package_name>

Replace <package_name> with the name of the software (for example, snap list --all vlc). The output will display the active version along with disabled older revisions, including their unique revision numbers.

2. Revert to the Immediately Preceding Version

If you only need to roll back to the version that was active right before the latest automatic update, use the revert command:

sudo snap revert <package_name>

Snap will roll back the application binary and restore the user data associated with that prior revision.

3. Revert to a Specific Revision Number

If multiple revisions are retained on your system and you need to target an older release rather than the immediate predecessor, specify the revision number identified in step 1:

sudo snap revert <package_name> --revision <revision_number>

For example:

sudo snap revert vlc --revision 2344

4. Prevent the Package from Updating Again

By default, Snap will eventually try to update the reverted package again during its regular refresh cycles. To prevent the application from automatically updating to the problematic version, place a hold on it:

sudo snap refresh --hold <package_name>

To hold the package for a specific duration, such as 72 hours, specify the time limit:

sudo snap refresh --hold=72h <package_name>

When a bug fix is released and you are ready to resume automatic updates, unhold the package using:

sudo snap refresh --unhold <package_name>
