Configure lm-sensors for CPU Temperature on Ubuntu

Monitoring CPU thermal metrics is critical for maintaining server health and preventing thermal throttling or hardware damage. This guide demonstrates how to install, configure, and fine-tune lm-sensors on an Ubuntu server. Following these steps will allow the operating system to detect onboard sensor chips, load the required kernel drivers, and accurately report individual CPU core temperatures from the command line.

1. Install lm-sensors

First, update your local package index and install the lm-sensors package using apt:

sudo apt update
sudo apt install lm-sensors -y

2. Detect Hardware Sensors

Once installed, run the interactive sensor detection utility. This tool probes your system hardware to identify thermal and voltage sensors on the motherboard and CPU.

sudo sensors-detect

During execution, the prompt will ask several times if it should scan specific hardware buses (such as I2C or ISA).

  • In most production environments, answering YES (or pressing Enter to accept defaults) to all safe prompts is recommended.
  • At the final prompt, it will ask: "Do you want to add these lines to /etc/modules automatically?" Answer yes so the system automatically loads the appropriate kernel modules at boot.

3. Load the Detected Kernel Modules

To start monitoring temperatures immediately without rebooting the server, load the newly configured kernel modules into memory:

sudo systemctl restart systemd-modules-load.service

Depending on your CPU architecture, you can also load the primary monitoring driver manually:

  • For Intel CPUs: 
    sudo modprobe coretemp
  • For AMD CPUs: 
    sudo modprobe k10temp

4. Read the Temperatures

To view your current CPU temperatures, execute:

sensors

The output will display the detected hardware and temperatures for each core (e.g., Core 0, Core 1) along with high and critical thermal thresholds:

coretemp-isa-0000
Adapter: ISA adapter
Package id 0:  +42.0°C  (high = +80.0°C, crit = +100.0°C)
Core 0:        +39.0°C  (high = +80.0°C, crit = +100.0°C)
Core 1:        +41.0°C  (high = +80.0°C, crit = +100.0°C)

5. Adjusting Sensor Accuracy and Labels (Optional)

If sensor readings show misleading labels or require an offset to match manufacturer-verified temperatures, create a custom configuration file:

  1. Create a custom configuration file in the /etc/sensors.d/ directory:

    sudo nano /etc/sensors.d/cpu-custom.conf

  2. Add custom labels or offset adjustments using your chip's identifier (found in the output of the sensors command):

    chip "coretemp-isa-*"
    label temp2 "CPU Package"
    label temp3 "CPU Core 0"
    label temp4 "CPU Core 1"
    # Example: Add a +2°C offset if the diode reads low
    # compute temp3 @+2, @-2

  3. Save the file and reload the sensors configuration:

    sudo sensors -s

To continuously monitor temperatures in real time, run:

watch -n 1 sensors
