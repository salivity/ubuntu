How to Boot an Older Kernel by Default in Ubuntu

Booting into an older Linux kernel in Ubuntu is often necessary when a recent kernel update causes system instability, driver conflicts, or hardware incompatibilities. This guide explains how to identify your installed kernels, modify the GRUB bootloader configuration file (/etc/default/grub) to set a specific older kernel as the permanent default, and apply those changes safely across system reboots.

Step 1: Find the Exact Name of Your Target Kernel

To set a default kernel, GRUB requires the exact string identifier or index of the kernel entry.

  1. Open your terminal (Ctrl+Alt+T).
  2. Run the following command to display the menu entries from your GRUB configuration file:
grep -E "submenu|menuentry" /boot/grub/grub.cfg
  1. Look through the output for lines containing gnulinux-advanced-... and gnulinux-...-generic. You need two pieces of information:
    • The top-level menu entry (usually "Advanced options for Ubuntu").
    • The specific kernel entry (for example, "Ubuntu, with Linux 5.15.0-88-generic").

Note down the full hierarchy path. For example: Advanced options for Ubuntu>Ubuntu, with Linux 5.15.0-88-generic

Step 2: Edit the GRUB Configuration File

  1. Open the /etc/default/grub configuration file in a text editor with root privileges:
sudo nano /etc/default/grub
  1. Locate the line that defines GRUB_DEFAULT. By default, it looks like this:
GRUB_DEFAULT=0
  1. Replace 0 with the exact menu path you identified in Step 1, enclosed in double quotes:
GRUB_DEFAULT="Advanced options for Ubuntu>Ubuntu, with Linux 5.15.0-88-generic"

Note: Using the full string name instead of numerical indexes (like "1>2") ensures that your selection remains accurate even if new kernels are installed later.

  1. Save the file and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 3: Update GRUB Settings

Modifying /etc/default/grub does not change the boot behavior immediately. You must generate the final GRUB boot file for the changes to take effect.

Run the following command:

sudo update-grub

The output will confirm that the configuration file was successfully generated.

Step 4: Reboot and Verify

  1. Restart your machine:
sudo reboot
  1. Once the system has booted back up, open the terminal and verify the active kernel version:
uname -r

The output should display the older kernel version specified in your configuration file.
