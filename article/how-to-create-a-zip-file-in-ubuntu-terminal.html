How to Create a ZIP File in Ubuntu Terminal

Creating a compressed ZIP archive using the Ubuntu terminal is a fast and efficient way to bundle and shrink files or directories. This guide provides a straightforward walkthrough on installing the zip utility, executing basic commands to compress files and folders, and applying password protection to your archives directly from the command line.

Step 1: Install the ZIP Utility

Ubuntu does not always come with the zip tool installed by default. Open your terminal (Ctrl + Alt + T) and run the following commands to update your package list and install the utility:

sudo apt update
sudo apt install zip unzip

Step 2: Create a ZIP Archive with Files

To compress one or more individual files into a single ZIP archive, use the basic zip command followed by the desired output file name and the target files:

zip archive_name.zip file1.txt file2.txt file3.png

Replace archive_name.zip with your preferred archive name and specify the files you want to include.

Step 3: Compress an Entire Directory Recursively

To zip an entire folder along with all of its subdirectories and files, use the -r (recursive) option:

zip -r archive_name.zip path/to/directory

For example, to compress a folder named documents located in your current working directory:

zip -r documents_backup.zip documents/

Step 4: Create a Password-Protected ZIP File

If you need to encrypt your compressed file, add the -e flag to prompt for a password during the creation process:

zip -e secure_archive.zip file1.txt file2.txt

To encrypt an entire directory recursively, combine the options:

zip -er secure_directory.zip path/to/directory

You will be asked to enter and confirm a password. The files within the archive cannot be extracted without entering this password.

Step 5: Verify the Contents of a ZIP Archive

To view the contents of a ZIP file without extracting it, use the unzip command with the -l option:

unzip -l archive_name.zip
