How to Set Up an OpenLDAP Server on Ubuntu

OpenLDAP is a powerful, open-source implementation of the Lightweight Directory Access Protocol used for centralized authentication and directory management. This guide provides a step-by-step walkthrough for installing, configuring, and testing an OpenLDAP server on an Ubuntu system, enabling you to efficiently manage user credentials and network resources from a single location.

Step 1: Update System Packages

Before installing new software, ensure your Ubuntu system package index is up to date.

sudo apt update && sudo apt upgrade -y

Step 2: Install OpenLDAP and LDAP Utilities

Install slapd (the Standalone LDAP Daemon) along with ldap-utils (command-line tools for working with LDAP).

sudo apt install slapd ldap-utils -y

During installation, you will be prompted to create an administrator password for the LDAP directory. Enter a strong password and confirm it.

Step 3: Configure the OpenLDAP Server

Execute Ubuntu’s package reconfiguration tool to set up your domain and directory settings.

sudo dpkg-reconfigure slapd

Answer the configuration prompts as follows:

  • Omit OpenLDAP server configuration? Select No.
  • DNS domain name: Enter your preferred domain name (e.g., example.com). This creates the base structure of your directory (e.g., dc=example,dc=com).
  • Organization name: Enter the name of your organization or company (e.g., Example Inc).
  • Administrator password: Enter and confirm your admin password.
  • Database backend: Select MDB (recommended).
  • Do you want the database to be removed when slapd is purged? Select No.
  • Move old database? Select Yes.
  • Allow LDAPv2 protocol? Select No.

Step 4: Verify the OpenLDAP Configuration

Test your OpenLDAP setup by performing an initial search using the ldapsearch command:

sudo ldapsearch -x -b dc=example,dc=com namingContexts

Replace dc=example,dc=com with your configured domain components. If the setup is correct, the command will output your directory’s base DN structure.

Step 5: Configure Organizational Units and Users

To add objects to your directory, create an LDAP Data Interchange Format (LDIF) file.

  1. Create a file named base.ldif:
nano base.ldif
  1. Add the following content to establish basic Organizational Units (OUs) for users and groups:
dn: ou=People,dc=example,dc=com
objectClass: organizationalUnit
ou: People

dn: ou=Groups,dc=example,dc=com
objectClass: organizationalUnit
ou: Groups
  1. Add the entries to your OpenLDAP database:
ldapadd -x -D "cn=admin,dc=example,dc=com" -W -f base.ldif

Enter your admin password when prompted.

Step 6: Configure Firewall Settings

If Uncomplicated Firewall (UFW) is active on your server, allow traffic on the standard LDAP port (389) and secure LDAP port (636):

sudo ufw allow 389/tcp
sudo ufw allow 636/tcp

Your OpenLDAP server is now operational and ready to accept directory objects, client connections, and integration with authentication services.
