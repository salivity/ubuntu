Change Font Scaling with gsettings in Ubuntu

Adjusting the font scaling factor in Ubuntu allows you to resize on-screen text without changing the entire display resolution. This can be accomplished directly from the terminal using the gsettings command-line configuration tool, which modifies GNOME desktop environment settings instantly. This guide covers how to check your current font scale, apply a new scaling factor, and restore default settings.

Checking the Current Font Scale

Before modifying the setting, view the current scaling factor by querying the GNOME interface schema:

gsettings get org.gnome.desktop.interface text-scaling-factor

The default value on a standard Ubuntu installation is 1.0.

Modifying the Font Scaling Factor

To change the font size, use the set command followed by the schema, key, and your desired scaling value. The value is a floating-point number:

gsettings set org.gnome.desktop.interface text-scaling-factor 1.25
  • Increase font size: Use values greater than 1.0 (such as 1.25 for a 25% increase or 1.5 for a 50% increase).
  • Decrease font size: Use values less than 1.0 (such as 0.85 or 0.9).

Changes take effect immediately across all GNOME applications without requiring a reboot or logout.

Resetting to Default

If you want to revert to the system default font size, use the reset command:

gsettings reset org.gnome.desktop.interface text-scaling-factor

This returns the scaling factor back to 1.0.
