How to Configure HTTP Basic Authentication on Ubuntu

Configuring HTTP basic authentication on an Ubuntu web server is a straightforward process used to restrict access to specific pages or entire websites using a username and password. This guide outlines the essential steps to set up basic authentication for both Nginx and Apache web servers on Ubuntu. You will learn how to install the necessary utilities, generate encrypted credential files using the htpasswd tool, update your server configuration files, and apply the changes to secure your web server environment.

Step 1: Install Apache Utilities

Both Nginx and Apache use the .htpasswd file format to store encrypted usernames and passwords. The tool required to create this file is included in the apache2-utils package.

Run the following commands to update your package list and install the package:

sudo apt update
sudo apt install apache2-utils

Step 2: Create the Credentials File

Use the htpasswd utility to create an encrypted password file. The -c flag creates a new file.

Run the following command, replacing username with your desired username:

sudo htpasswd -c /etc/nginx/.htpasswd username

(If using Apache, save the file to /etc/apache2/.htpasswd instead).

You will be prompted to enter and confirm a password. To add additional users in the future, run the same command without the -c flag to avoid overwriting the existing file.

Verify that the file was created and permissions are secured:

sudo chmod 640 /etc/nginx/.htpasswd
sudo chown www-data:www-data /etc/nginx/.htpasswd

Step 3: Configure Your Web Server

Follow the section below corresponding to your installed web server.

Option A: Configure Nginx

  1. Open your Nginx site configuration file (e.g., /etc/nginx/sites-available/default):
sudo nano /etc/nginx/sites-available/default
  1. Add the auth_basic and auth_basic_user_file directives inside the server or specific location block you wish to protect:
server {
    listen 80;
    server_name example.com;

    location / {
        root /var/www/html;
        index index.html;

        # Enable HTTP Basic Authentication
        auth_basic "Restricted Access";
        auth_basic_user_file /etc/nginx/.htpasswd;
    }
}
  1. Save and close the file.

Option B: Configure Apache

  1. Open your Apache virtual host configuration file (e.g., /etc/apache2/sites-available/000-default.conf):
sudo nano /etc/apache2/sites-available/000-default.conf
  1. Add a <Directory> block inside the <VirtualHost> block targeting the directory you want to protect:
<VirtualHost *:80>
    ServerName example.com
    DocumentRoot /var/www/html

    <Directory "/var/www/html">
        AuthType Basic
        AuthName "Restricted Access"
        AuthUserFile /etc/apache2/.htpasswd
        Require valid-user
    </Directory>
</VirtualHost>
  1. Save and close the file.

Step 4: Test and Reload the Web Server

Always test your configuration files for syntax errors before restarting the web server service.

For Nginx:

sudo nginx -t
sudo systemctl reload nginx

For Apache:

sudo apachectl configtest
sudo systemctl reload apache2

Step 5: Verify Authentication

Open a web browser and navigate to your server’s IP address or domain name. A login prompt requesting a username and password will appear. Enter the credentials created in Step 2 to gain access to the site.
