How to Install Cinnamon Desktop on Ubuntu

This article explains how to install the Cinnamon desktop environment on a standard Ubuntu system. Originally developed for Linux Mint, Cinnamon offers a traditional, sleek, and highly customizable desktop layout featuring a familiar bottom panel and application menu. By following the straightforward terminal-based steps below, you will learn how to update your repositories, install the necessary Cinnamon packages, switch desktop sessions at the login screen, and remove the environment if you ever wish to revert.

Step 1: Update Your System

Before installing any new desktop environment, ensure that your existing package lists and installed software are fully up to date. Open a terminal (Ctrl + Alt + T) and run:

sudo apt update && sudo apt upgrade -y

Step 2: Install the Cinnamon Desktop Environment

Ubuntu includes the Cinnamon desktop environment directly within its official universe repositories, meaning no third-party PPAs are required.

To install the complete Cinnamon desktop with all standard utilities and default applications, run:

sudo apt install cinnamon-desktop-environment -y

Note: If you prefer a minimal installation containing only the core desktop components without the extra bundled applications, you can install the base package instead by running sudo apt install cinnamon -y.

Step 3: Log Out and Select the Cinnamon Session

Once the installation completes, you must log out of your current session to switch to Cinnamon:

  1. Click the system menu in the top-right corner of your screen and select Log Out.
  2. On the login screen, click your username.
  3. Click the gear icon located in the bottom-right corner of the display manager.
  4. Select Cinnamon (or Cinnamon (Software Rendering) if you experience graphics driver issues).
  5. Enter your password and log in.

Your system will now load the Cinnamon desktop interface.

Step 4: Customizing Cinnamon (Optional)

You can customize themes, panels, desklets, and applets by opening the System Settings menu within Cinnamon. Under the "Appearance" and "Preferences" sections, you can download community themes, tweak hot corners, and adjust window behavior without affecting your default Ubuntu GNOME settings.

How to Remove Cinnamon

If you decide to revert to Ubuntu's default GNOME desktop environment, log out, switch back to the standard Ubuntu session via the gear icon, and run the following commands in the terminal:

sudo apt purge cinnamon cinnamon-desktop-environment -y
sudo apt autoremove -y

This will completely remove Cinnamon and any unused dependencies associated with it.
