How to Set Up python3-venv on Ubuntu

Setting up an isolated Python environment on Ubuntu prevents dependency conflicts and ensures clean package management across different projects. This guide provides a straightforward walkthrough on installing the python3-venv package, generating an isolated environment, activating it to install dependencies safely, and deactivating it once work is complete.

Step 1: Update System Repositories

Before installing any new packages, refresh your local package index to ensure you download the latest compatible versions.

sudo apt update

Step 2: Install python3-venv

Ubuntu typically ships with Python 3 installed, but the venv module must be installed separately. Run the following command:

sudo apt install python3-venv -y

If you use a specific Python version (for example, Python 3.11), install the version-specific package instead:

sudo apt install python3.11-venv -y

Step 3: Create a Project Directory

Create a dedicated directory for your project and navigate into it:

mkdir ~/my_python_project
cd ~/my_python_project

Step 4: Create the Virtual Environment

Use the venv module to create a virtual environment. Replace myenv with your preferred environment name:

python3 -m venv myenv

This creates a directory named myenv containing a standalone Python interpreter, standard libraries, and support files.

Step 5: Activate the Virtual Environment

To start using the isolated environment, activate it using the source command:

source myenv/bin/activate

Once activated, your terminal prompt will display the environment's name in parentheses, such as (myenv) user@ubuntu:~/my_python_project$.

Step 6: Verify and Install Packages

Check that python and pip point to the virtual environment rather than the system-wide installation:

which python
which pip

You can now install project dependencies without affecting the rest of the operating system:

pip install requests

Step 7: Deactivate the Environment

When you finish working on the project, exit the virtual environment by running:

deactivate

The environment name prefix will disappear, returning your shell to the default system environment.
