Force Gigabit Full Duplex with Ethtool in Ubuntu

Configuring a network interface to operate at full-duplex Gigabit speed using ethtool can resolve link negotiation issues, eliminate packet drops, and stabilize network throughput on Ubuntu. This guide outlines the necessary commands to identify your network interface, verify that Gigabit full-duplex is supported by the hardware, manually enforce 1000 Mbps full-duplex mode using ethtool, and persist these changes across reboots.

Step 1: Install Ethtool and Identify the Network Interface

If ethtool is not already installed on your Ubuntu system, install it via the terminal:

sudo apt update
sudo apt install ethtool -y

Identify the name of your target network interface using the ip command:

ip link show

Locate your interface name (e.g., eth0, enp3s0, or eno1).

Step 2: Verify Gigabit Support

Check the current status and supported link modes of your interface:

sudo ethtool eth0

Replace eth0 with your actual interface name. Under the Supported link modes section, confirm that 1000baseT/Full is listed. Note the current values for Speed, Duplex, and Auto-negotiation.

Step 3: Enforce Gigabit Full-Duplex

To force the interface to 1000 Mbps (Gigabit) and full duplex, run:

sudo ethtool -s eth0 speed 1000 duplex full autoneg off

Note on IEEE 802.3ab standards: The 1000BASE-T Gigabit specification requires auto-negotiation for clock synchronization between endpoints. If the link fails to establish with autoneg off, leave auto-negotiation enabled but restrict the advertised speeds exclusively to Gigabit full-duplex:

sudo ethtool -s eth0 speed 1000 duplex full autoneg on

Alternatively, restrict the advertisement mask to only allow 1000BASE-T/Full:

sudo ethtool -s eth0 advertise 0x020

Step 4: Verify the New Configuration

Check the interface status again to confirm the link is active at the designated parameters:

sudo ethtool eth0

The output should show:

  • Speed: 1000Mb/s
  • Duplex: Full
  • Link detected: yes

Step 5: Make the Configuration Persistent Across Reboots

Changes made via the ethtool command are reset upon reboot. To make them permanent, create a systemd service.

Create a new service file:

sudo nano /etc/systemd/system/ethtool-speed.service

Add the following configuration, replacing eth0 with your interface:

[Unit]
Description=Set Ethtool Gigabit Full Duplex
After=network.target

[Service]
Type=oneshot
ExecStart=/sbin/ethtool -s eth0 speed 1000 duplex full autoneg on
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target

Save the file and exit the editor. Enable the service to run at boot:

sudo systemctl daemon-reload
sudo systemctl enable ethtool-speed.service
