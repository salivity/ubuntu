Ubuntu Kernel Live Patching Without Landscape

Kernel live patching allows system administrators to apply critical security updates to the Linux kernel without rebooting the system. While Canonical offers its own Livepatch service integrated with Canonical Landscape, open-source alternatives like kpatch provide an independent, self-hosted way to patch kernel vulnerabilities on Ubuntu. This guide outlines the step-by-step process to install, build, and apply live patches using kpatch on an Ubuntu system without relying on Landscape or external subscriptions.

Prerequisites

Before starting, ensure your system has the necessary build tools and dependencies installed. You will need a standard Ubuntu installation with sudo access, along with the kernel build dependencies.

Run the following command to update your package lists and install the required tools:

sudo apt update
sudo apt install -y build-essential libelf-dev ccache git bison flex libssl-dev libudev-dev libpci-dev libiberty-dev openssl pkg-config

You also need to install the kernel debugging symbols (dbgsym) for your currently running kernel. Add the debug repository to your system:

echo "deb http://ddebs.ubuntu.com $(lsb_release -cs) main restricted universe multiverse" | sudo tee /etc/apt/sources.list.d/ddebs.list
echo "deb http://ddebs.ubuntu.com $(lsb_release -cs)-updates main restricted universe multiverse" | sudo tee -a /etc/apt/sources.list.d/ddebs.list

# Import the debug archive key
sudo apt-key adv --keyserver keyserver.ubuntu.com --recv-keys F2EDC64545E26DF43C28425E6B15AB9170030AD1

sudo apt update
sudo apt install -y linux-image-$(uname -r)-dbgsym

Step 1: Install Kpatch

kpatch is an open-source framework developed by Red Hat that works on most major Linux distributions, including Ubuntu. To get the latest version, build it directly from source:

git clone https://github.com/dynup/kpatch.git
cd kpatch
make
sudo make install

This installs the kpatch management tool and the kpatch-build utility onto your system.

Step 2: Obtain the Kernel Source Code

To build a patch, kpatch requires the matching source code for your running kernel.

Create a workspace directory and download the source:

mkdir ~/kpatch-workspace
cd ~/kpatch-workspace
apt-get source linux-image-$(uname -r)

Step 3: Create a Kernel Patch

Create a standard unified diff file representing the fix you want to apply to the kernel source. For example, if you are editing a file named net/ipv4/tcp.c, your workflow would look like this:

  1. Copy the source directory to make changes.
  2. Modify the target file in the copied directory.
  3. Generate the patch using diff -u.

Save your patch file as my-kernel-fix.patch inside ~/kpatch-workspace.

Step 4: Build the Live Patch Module

Use kpatch-build to compile the patch into a loadable kernel module. Pass your patch file and specify the kernel version if needed:

kpatch-build -s ~/kpatch-workspace/linux-* my-kernel-fix.patch

kpatch-build compares the original kernel code with the patched version, extracts the changed functions, and compiles a binary kernel patch module (ending in .ko).

Step 5: Apply and Manage the Patch

Once the .ko module is generated, load it into the running kernel using the kpatch CLI:

sudo kpatch load livepatch-my-kernel-fix.ko

Verify that the patch is active:

sudo kpatch list

To make the patch persist across system reboots, install it into the kpatch system registry:

sudo kpatch install livepatch-my-kernel-fix.ko

To unload an active patch from memory without rebooting, run:

sudo kpatch unload livepatch-my-kernel-fix.ko
