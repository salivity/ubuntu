Change Default Systemd Target to Multi-User in Ubuntu

Ubuntu utilizes systemd to manage system initialization and service states through target units, typically defaulting to graphical.target for desktop environments and multi-user.target for headless command-line setups. Changing the default target to multi-user.target disables the display manager on boot, freeing up system memory and CPU resources for server workloads. This guide outlines the straightforward terminal commands required to verify your current configuration, change the default boot target, and apply the changes.

Step 1: Check the Current Default Target

Before making any changes, verify your current boot target by running the following command in the terminal:

systemctl get-default

If your system currently boots into a graphical desktop, the output will return:

graphical.target

Step 2: Set the Default Target to Multi-User

To change the default boot target so that the system boots directly into a command-line interface, execute:

sudo systemctl set-default multi-user.target

This command creates a symbolic link pointing /etc/systemd/system/default.target to /lib/systemd/system/multi-user.target, superseding the system's factory default configuration.

Step 3: Verify the New Configuration

Confirm that the new target has been set correctly:

systemctl get-default

The output should now display:

multi-user.target

Step 4: Apply the Changes

You can apply the changes immediately without restarting by isolating the target:

sudo systemctl isolate multi-user.target

Alternatively, restart the system to test the boot process from scratch:

sudo reboot

How to Revert to Graphical Target

If you ever need to restore the graphical user interface as the default boot target, run:

sudo systemctl set-default graphical.target
