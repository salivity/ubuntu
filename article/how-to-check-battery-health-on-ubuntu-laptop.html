How to Check Battery Health on Ubuntu Laptop

Monitoring your laptop's battery health on Ubuntu helps you track wear over time, estimate remaining lifespan, and diagnose power issues. This guide covers how to quickly check your battery's current capacity, original design capacity, and overall health status using both built-in Ubuntu graphical tools and simple command-line utilities.

Method 1: Check Battery Health Using the Terminal (UPower)

The command-line tool upower comes pre-installed on most Ubuntu installations and provides detailed battery diagnostics.

  1. Open your terminal by pressing Ctrl + Alt + T.

  2. Find your battery device name by running:

    upower -e

    Look for a line ending in battery_BAT0 or battery_BAT1.

  3. Query the battery details (replace BAT0 if your device name differs):

    upower -i /org/freedesktop/UPower/devices/battery_BAT0

  4. Review the relevant output fields:

    • energy-full-design: The factory capacity when the battery was brand new (in Wh).
    • energy-full: The maximum charge capacity your battery can hold right now (in Wh).
    • capacity: The current maximum percentage of the original design capacity remaining.

To calculate your battery health manually:
(energy-full / energy-full-design) × 100 = Health Percentage

Method 2: Read System Files Directly

Linux stores hardware information directly in the system directory, allowing you to view raw battery data without installing extra software.

  1. Open the terminal.
  2. View the maximum capacity design: 
    cat /sys/class/power_supply/BAT0/energy_full_design
  3. View the current maximum full charge capacity: 
    cat /sys/class/power_supply/BAT0/energy_full
  4. View the current charge level percentage: 
    cat /sys/class/power_supply/BAT0/capacity

Note: On some laptop models, energy_full may be listed as charge_full and energy_full_design as charge_full_design.

Method 3: Use the acpi Command

The acpi utility is a lightweight command-line tool that displays concise battery statistics.

  1. Install acpi: 
    sudo apt update
sudo apt install acpi
  2. Run the command with the information flag: 
    acpi -bi
  3. The output will display the current charge state along with the design capacity and last full capacity percentage.

Method 4: Check Battery Health via GUI (GNOME Power Statistics)

If you prefer a graphical user interface, Ubuntu includes a detailed power statistics viewer.

  1. Install Power Statistics if it is not already available: 
    sudo apt install gnome-power-manager
  2. Open your Application menu, search for Power Statistics, and open it.
  3. Select Laptop battery from the left sidebar.
  4. View the Details tab to check:
    • Energy when full: Current max capacity.
    • Energy (design): Original factory capacity.
    • Capacity: Overall health percentage.
