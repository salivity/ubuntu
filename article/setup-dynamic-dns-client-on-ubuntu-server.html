Setup Dynamic DNS Client on Ubuntu Server

Setting up a Dynamic DNS (DDNS) client on an Ubuntu home server enables reliable remote access to home-hosted services even when an Internet Service Provider changes the public IP address. This article covers the step-by-step process of installing ddclient on Ubuntu, configuring it with a DDNS provider, and running it as a background service to automatically update IP address changes in real time.

Prerequisites

Before starting, ensure the following are available: * An Ubuntu server running and connected to the home network. * Sudo privileges on the server. * An active account with a Dynamic DNS provider (such as No-IP, DynDNS, DuckDNS, or Cloudflare) along with a created hostname.

Step 1: Install DDclient

ddclient is a popular, lightweight Perl client used to update dynamic DNS entries for accounts on many dynamic DNS services.

Open a terminal and run the following commands to update the package index and install ddclient:

sudo apt update
sudo apt install ddclient libjson-any-perl

During installation, a text-based wizard may prompt for provider details. You can press Enter to skip through these prompts, as the configuration file will be edited manually in the next step.

Step 2: Configure DDclient

Open the main configuration file in a text editor:

sudo nano /etc/ddclient.conf

Delete any existing text and replace it with a configuration tailored to your provider. Below is a standard example configured for a generic Dynamic DNS service (e.g., No-IP):

# Configuration for DDclient
daemon=300
syslog=yes
pid=/var/run/ddclient.pid
ssl=yes
use=web, web=checkip.dyndns.com/

# Provider Details
protocol=dyndns2
server=ip1.dynupdate.no-ip.com
login=your_ddns_username
password='your_ddns_password'
yourdomain.ddns.net

Key configuration options explained: * daemon=300: Checks for IP changes every 300 seconds (5 minutes). * use=web: Obtains the public IP address by querying an external IP-checking webpage. * protocol, server, login, password: Credentials and server details provided by your DDNS provider. * yourdomain.ddns.net: The domain name assigned to your home server.

Save the file and exit the editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

Step 3: Test the Configuration

Run ddclient manually in debug mode to verify that credentials and settings are correct:

sudo ddclient -daemon=0 -debug -verbose

If the connection is successful, the output will display a SUCCESS message indicating that the hostname was updated or is currently up to date with the server’s public IP address.

Step 4: Enable and Start the Service

Once the configuration test passes, enable ddclient to run automatically as a system daemon on boot.

Start the service:

sudo systemctl start ddclient

Enable it to launch on boot:

sudo systemctl enable ddclient

Verify that the service is running properly:

sudo systemctl status ddclient

The output should indicate that the service is active and running. The Ubuntu home server will now automatically inform the DDNS provider whenever the public IP address changes.
