Purpose of /etc/network/interfaces in Legacy Ubuntu

The /etc/network/interfaces file served as the primary configuration file for network interfaces in legacy Ubuntu releases prior to the introduction of Netplan in version 17.10. Managed by the ifupdown system package, this text-based configuration file allowed system administrators to define how local network cards, loopback addresses, wireless adapters, and virtual bridges were initialized, assigned IP addresses, and brought online during the system boot process.

Key Responsibilities of the File

  1. Interface Initialization The file specifies which network interfaces should start automatically at boot using the auto directive (e.g., auto eth0) or when hardware events occur using the allow-hotplug directive.

  2. IP Address Configuration It defines whether an interface receives an IP address dynamically or statically:

    • DHCP Configuration: Automates IP assignment using iface eth0 inet dhcp.
    • Static IP Configuration: Manages fixed network settings manually, specifying parameters such as address, netmask, gateway, and dns-nameservers.

  3. Routing and Gateway Management It sets default gateways and custom routes directly associated with specific interfaces to dictate how network traffic exits the system.

  4. Execution of Network Scripts Administrators could configure pre-up, up, down, and post-down hooks. These directives ran specific commands or custom scripts immediately before or after an interface was brought up or down.

Typical Syntax Example

A standard static IP configuration inside /etc/network/interfaces looked like this:

auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4

Transition to Netplan

In Ubuntu 17.10 and later releases (including 18.04 LTS onwards), Canonical replaced /etc/network/interfaces with Netplan, a YAML-based network abstraction system. Netplan generates backend configurations for systemd-networkd or NetworkManager, modernizing network administration across desktop, server, and cloud deployments.
