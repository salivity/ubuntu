How to Configure XRDP with GNOME on Ubuntu

This article provides a complete step-by-step guide on configuring the default GNOME desktop environment to run smoothly over an RDP connection using xrdp on Ubuntu. By following this walkthrough, you will learn how to install the required packages, adjust the desktop session startup scripts, eliminate common black screen issues, and bypass repetitive authentication prompts for a seamless remote access experience.

1. Install XRDP

Open your terminal and update your package lists, then install the xrdp package:

sudo apt update
sudo apt install xrdp -y

Enable and start the service so that it runs automatically on system boot:

sudo systemctl enable --now xrdp

2. Configure Permissions for the XRDP User

To ensure xrdp can read the SSL certificate key created during installation, add the xrdp user to the ssl-cert group:

sudo adduser xrdp ssl-cert

3. Configure the GNOME Desktop Startup Script

To prevent the common issue where connecting results in a black screen, you must configure the system to launch the GNOME desktop properly upon login.

Open /etc/xrdp/startwm.sh in a text editor:

sudo nano /etc/xrdp/startwm.sh

Add the following environment variables above the existing test -x /etc/X11/Xsession lines at the bottom of the file:

export GNOME_SHELL_SESSION_MODE=ubuntu
export XDG_CURRENT_DESKTOP=ubuntu:GNOME
export XDG_CONFIG_DIRS=/etc/xdg/xdg-ubuntu:/etc/xdg

Save and exit the file.

Alternatively, if you want users to log in to GNOME automatically without system-wide file modifications, each user can create an ~/.xsessionrc file in their home directory:

cat <<EOF > ~/.xsessionrc
export GNOME_SHELL_SESSION_MODE=ubuntu
export XDG_CURRENT_DESKTOP=ubuntu:GNOME
export XDG_CONFIG_DIRS=/etc/xdg/xdg-ubuntu:/etc/xdg
EOF

4. Fix Polkit Authentication Prompts

When connecting via remote desktop, GNOME frequently displays “Authentication Required” popups for color management and network settings. You can bypass these by creating a Polkit configuration rule.

Create a new configuration file:

sudo nano /etc/polkit-1/localauthority/50-local.d/45-allow-colord.pkla

Paste the following content into the file:

[Allow Colord all Users]
Identity=unix-user:*
Action=org.freedesktop.color-manager.create-device;org.freedesktop.color-manager.create-profile;org.freedesktop.color-manager.delete-device;org.freedesktop.color-manager.delete-profile;org.freedesktop.color-manager.modify-device;org.freedesktop.color-manager.modify-profile
ResultAny=no
ResultInactive=no
ResultActive=yes

Save and close the file.

5. Manage Local GNOME Sessions

Ubuntu does not natively support running two concurrent active sessions for the same user account. If you are logged into GNOME physically on the host machine, log out before attempting to connect over XRDP. An active local session will cause the remote desktop connection to fail or disconnect instantly.

6. Configure Firewall (Optional)

If Ubuntu Uncomplicated Firewall (UFW) is active, open port 3389 to allow incoming remote desktop traffic:

sudo ufw allow 3389/tcp

7. Restart the XRDP Service

Apply all configuration changes by restarting the XRDP service:

sudo systemctl restart xrdp

You can now use any standard Remote Desktop Client (such as Windows Remote Desktop Connection or Remmina) to connect to your Ubuntu machine’s IP address. Select the Xorg option at the login screen and enter your Ubuntu credentials.
