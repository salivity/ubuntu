How to Display User and Group ID in Ubuntu

In Ubuntu, verifying user identity and access permissions often requires checking account identifiers and group affiliations. This article explains how to display your current active user ID (UID) and group ID (GID) memberships using the primary command-line utility, id, along with its most practical options for filtering the output.

The Primary Command: id

The standard command to display the active user ID and all associated group IDs in Ubuntu is id. When executed without any arguments, it returns the details of the currently logged-in user session:

id

Example Output:

uid=1000(john) gid=1000(john) groups=1000(john),4(adm),24(cdrom),27(sudo),30(dip),46(plugdev),110(lxd)

Output Breakdown:

  • uid: Displays the numeric User ID and the associated username in parentheses.
  • gid: Displays the primary numeric Group ID and the primary group name in parentheses.
  • groups: Lists all secondary (supplementary) group IDs and group names that the user belongs to.

Useful Flags for Filtering Output

If you need specific values—such as when writing bash scripts or performing quick checks—the id command provides several flags:

  • Print User ID Only:

    id -u

    Add -n to print the name instead of the number: id -un

  • Print Primary Group ID Only:

    id -g

    Add -n to print the primary group name instead of the number: id -gn

  • Print All Group IDs (Supplementary Included):

    id -G

    Add -n to print all group names instead of numeric IDs: id -Gn

  • Display Real IDs Instead of Effective IDs: When running processes with elevated privileges (like sudo or setuid binaries), use the -r flag to print the real ID instead of the effective ID:

    id -ru

Checking Another User's IDs

To view the user and group information for a different user on the system, pass their username as an argument:

id username

Alternative Quick Commands

Ubuntu also includes specialized single-purpose commands:

  • whoami: Displays only the current active username.
  • groups: Displays the active user's primary and supplementary group names without numeric IDs.
