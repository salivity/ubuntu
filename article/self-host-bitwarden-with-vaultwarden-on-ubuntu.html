Self-Host Bitwarden with Vaultwarden on Ubuntu

This guide explains how to deploy and configure a private, lightweight Bitwarden-compatible password manager using Vaultwarden on Ubuntu. You will learn how to install Docker, launch Vaultwarden via Docker Compose, set up an Nginx reverse proxy, secure your instance with free Let's Encrypt SSL/TLS certificates, and configure essential security settings for production use.

Prerequisites

Before beginning, ensure you have:

  • An Ubuntu server (22.04 LTS or 24.04 LTS recommended) with a non-root sudo user.
  • A registered domain or subdomain with an A record pointing to your server's public IP address.
  • Ports 80 and 443 open in your firewall.

Step 1: Install Docker and Docker Compose

Update your system packages and install Docker and the Docker Compose plugin:

sudo apt update && sudo apt upgrade -y
sudo apt install -y ca-certificates curl gnupg lsb-release

# Add Docker's official GPG key
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

# Add Docker repository
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Install Docker packages
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# Enable and start Docker
sudo systemctl enable --now docker

Step 2: Deploy Vaultwarden

Create a dedicated directory to store the configuration and persistent data:

mkdir -p ~/vaultwarden && cd ~/vaultwarden

Create a docker-compose.yml file:

nano docker-compose.yml

Paste the following configuration:

services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: always
    environment:
      - WEBSOCKET_ENABLED=true  # Enables real-time syncing
      - SIGNUPS_ALLOWED=true    # Set to false after creating your account
    volumes:
      - ./vw-data:/data
    ports:
      - "127.0.0.1:8080:80"
      - "127.0.0.1:3012:3012"

Save and exit (Ctrl+O, Enter, Ctrl+X). Start the container:

docker compose up -d

Step 3: Install and Configure Nginx

Vaultwarden requires HTTPS to function across all clients and browser extensions. Use Nginx as a reverse proxy to terminate SSL.

Install Nginx:

sudo apt install -y nginx

Create a server configuration file for your domain (replace vault.example.com with your domain):

sudo nano /etc/nginx/sites-available/vaultwarden

Add the following block:

server {
    listen 80;
    server_name vault.example.com;

    client_max_body_size 128M;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /notifications/hub {
        proxy_pass http://127.0.0.1:3012;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /notifications/hub/negotiate {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable the site configuration and test Nginx:

sudo ln -s /etc/nginx/sites-available/vaultwarden /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

Step 4: Obtain an SSL Certificate

Use Certbot to generate and install Let's Encrypt certificates:

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d vault.example.com

Follow the prompts to complete the validation. Certbot will update the Nginx configuration automatically to enforce HTTPS.

Step 5: Initial Access and Hardening

  1. Open your web browser and navigate to https://vault.example.com.
  2. Click Create Account and register your primary administrative account.
  3. Once registered, lock down the server to prevent unauthorized registrations.

Open docker-compose.yml again:

cd ~/vaultwarden
nano docker-compose.yml

Change the signups parameter:

- SIGNUPS_ALLOWED=false

Apply the changes:

docker compose up -d

Your self-hosted Vaultwarden server is now fully configured. You can connect your official Bitwarden mobile apps and browser extensions by setting the custom server URL to https://vault.example.com.
