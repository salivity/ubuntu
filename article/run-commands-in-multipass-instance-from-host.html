Run Commands in Multipass Instance from Host

This article explains how to run shell commands inside a Canonical Multipass Ubuntu virtual machine directly from your host system's terminal without initiating an interactive SSH session. By using the built-in multipass exec command, developers and system administrators can automate tasks, deploy scripts, and manage virtual instances seamlessly from their local command line or automated workflows.

The multipass exec Command

The standard method to run commands in a Multipass instance from the host terminal is the multipass exec command.

The basic syntax is:

multipass exec <instance-name> -- <command>

The double-dash (--) is a standard delimiter used to separate Multipass options from the actual command and arguments you wish to run inside the guest operating system.

Basic Usage Examples

1. Check System Information

To verify the operating system details of an instance named primary, run:

multipass exec primary -- lsb_release -a

2. Run Commands with Superuser Privileges

The default user inside a Multipass instance has passwordless sudo privileges. To update package lists or perform administrative actions, prefix your target command with sudo:

multipass exec primary -- sudo apt update

3. Check Disk Usage

You can run any standard Linux utility directly:

multipass exec primary -- df -h

Running Complex or Chained Commands

When executing complex commands that include pipes (|), redirections (>, <), or logical operators (&&), the host shell may attempt to interpret them before passing them to Multipass.

To ensure the command string is evaluated entirely inside the Ubuntu instance, pass the commands through bash -c wrapped in single quotes:

multipass exec primary -- bash -c "sudo apt update && sudo apt upgrade -y"

Similarly, piping inside the instance requires the same structure:

multipass exec primary -- bash -c "cat /var/log/syslog | grep -i error"

Running Scripts and Passing Input

You can pass local scripts or data from the host machine into the instance using standard input redirection:

multipass exec primary -- bash < local_script.sh

In this case, the host shell reads local_script.sh and streams its contents into the standard input of a bash shell running inside the specified Multipass instance.
