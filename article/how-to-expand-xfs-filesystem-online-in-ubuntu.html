How to Expand XFS Filesystem Online in Ubuntu

This guide explains how to increase the size of an XFS filesystem on Ubuntu while the system remains fully online and operational. XFS natively supports online growth, allowing administrators to allocate more storage to a mounted volume without unmounting it or causing service downtime. The process involves expanding the underlying disk or partition first, followed by resizing the filesystem using the native xfs_growfs utility.

Step 1: Identify the Disk and Mount Point

Before expanding, check the current disk layout and mount points using the lsblk and df commands:

lsblk
df -hT

Locate the target filesystem, its mount point (e.g., / or /data), and verify that the Type is listed as xfs.

Step 2: Expand the Underlying Storage

Before you can expand the filesystem, the storage layer underneath it must be enlarged:

  • For Cloud/Virtual Disks with Partitions: If you resized a virtual disk (such as on AWS EBS, Azure, or VMware), install and use growpart to expand the partition:

    sudo apt update && sudo apt install -y cloud-guest-utils
sudo growpart /dev/sda 1

    (Replace /dev/sda with your disk name and 1 with the partition number.)

  • For LVM Volumes: If your XFS filesystem is on a Logical Volume, extend the logical volume to consume the free space in the volume group:

    sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv

    (Replace the path with your actual logical volume path.)

Step 3: Expand the XFS Filesystem

Unlike other filesystems like ext4, XFS must be expanded while mounted using the xfs_growfs command, and it requires the mount point as the target argument rather than the block device path.

Run the following command to expand the filesystem to the maximum available space:

sudo xfs_growfs /mount/point

Replace /mount/point with the actual directory where the volume is mounted (for example, / or /mnt/data).

Step 4: Verify the New Size

Confirm that the filesystem has expanded successfully by running:

df -h /mount/point

The output will display the updated total size and available space, confirming the online expansion is complete.
