How to Remove and Disable Snap in Ubuntu

This guide explains how to completely uninstall the Snap package manager, purge the snapd background service, remove leftover system files, and block Ubuntu from automatically reinstalling Snap packages in the future.

1. View and Remove Installed Snaps

Before removing the daemon itself, you must remove all currently installed Snap packages. List them using:

snap list

Remove each package listed. Ensure you remove user applications first, followed by system layers like gtk-common-themes, gnome-3-xx, coreXX, bare, and finally snapd:

sudo snap remove --purge <package-name>

Repeat this until snap list displays only the snapd base package (or no packages at all), then remove snapd:

sudo snap remove --purge snapd

2. Stop and Disable the Snap Services

Stop and mask the snapd systemd units to prevent background sockets from starting again:

sudo systemctl stop snapd.service snapd.socket snapd.seeded.service
sudo systemctl disable snapd.service snapd.socket snapd.seeded.service
sudo systemctl mask snapd.service snapd.socket snapd.seeded.service

3. Purge the snapd Package

Remove snapd along with its configuration files using apt purge:

sudo apt purge snapd -y
sudo apt autoremove --purge -y

4. Remove Leftover Directories

Delete remaining Snap directories and caches from your system and home directory:

sudo rm -rf /snap /var/snap /var/lib/snapd /var/cache/snapd
rm -rf ~/snap

5. Prevent Ubuntu from Reinstalling Snap

Ubuntu may reinstall snapd automatically when installing specific packages (such as Chromium or Firefox) via APT. To prevent this, create an APT preference file that blocks the package:

sudo tee /etc/apt/preferences.d/nosnap.pref <<EOF
Package: snapd
Pin: release a=*
Pin-Priority: -10
EOF

Update your package lists to apply the new pinning rule:

sudo apt update

Snap is now completely removed, disabled, and barred from automatic reinstallation on your Ubuntu system.
