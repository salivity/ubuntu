How to Monitor Real-Time Network Traffic on Ubuntu

Monitoring real-time network traffic on Ubuntu is essential for diagnosing bandwidth bottlenecks, detecting security anomalies, and managing overall system performance. This article covers the most effective command-line tools available for live network monitoring on Ubuntu, focusing on iftop, nload, and bmon, complete with installation steps and basic usage commands.

Top Command: iftop

The primary command for monitoring live network traffic by bandwidth usage per connection is iftop. It functions similarly to top, but instead of tracking CPU usage, it listens to network traffic on a selected interface and displays a real-time table of current bandwidth usage between pairs of hosts.

Installing and Running iftop

iftop is available in the standard Ubuntu repositories. Install it using apt:

sudo apt update
sudo apt install iftop

To run iftop on your default interface, execute:

sudo iftop

To monitor a specific network interface (such as eth0 or wlan0), use the -i flag:

sudo iftop -i eth0

Key Keyboard Controls in iftop

  • h: Toggles the help display.
  • n: Toggles DNS resolution (displays IP addresses instead of hostnames for faster loading).
  • p: Toggles port display.
  • q: Exits the utility.

Alternative Real-Time Commands

1. nload

If you prefer a visual representation of incoming and outgoing traffic separately, nload provides ASCII-based real-time graphs for network interfaces.

  • Install: sudo apt install nload
  • Run: nload

nload allows you to switch between interfaces using the left and right arrow keys and displays current, average, minimum, and maximum network throughput.

2. bmon

bmon (Bandwidth Monitor) is a debugging and capture tool that provides detailed network statistics and graphs in an interactive interface.

  • Install: sudo apt install bmon
  • Run: bmon

3. iptraf-ng

iptraf-ng is an interactive IP network monitoring utility that provides detailed connection statistics, including TCP/UDP packet counts, interface activity, and protocol breakdowns.

  • Install: sudo apt install iptraf-ng
  • Run: sudo iptraf-ng

Summary of Recommendations

  • Use iftop to identify which specific IP addresses or ports are consuming your bandwidth.
  • Use nload for a clean, graphical overview of total upload and download speeds.
  • Use iptraf-ng for comprehensive protocol and connection analysis.
