Install Rust on Ubuntu Using Rustup

This guide provides a straightforward walkthrough on how to install the latest version of the Rust programming language compiler on Ubuntu using rustup. By following these steps, you will install the official Rust toolchain installer, configure your shell environment, and verify that both the compiler (rustc) and package manager (cargo) are ready for development.

Step 1: Update Packages and Install Prerequisites

Before installing Rust, ensure your system packages are up to date and that you have curl and essential build tools installed. The build tools are required to compile Rust packages and link C-compatible libraries.

Open your terminal and run:

sudo apt update && sudo apt install -y curl build-essential

Step 2: Download and Run the Rustup Installer

The recommended way to install Rust is through rustup, which manages Rust versions and associated tools. Download and execute the official installation script with the following command:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

During the execution, the installer will display the planned installation paths and prompt you to choose an installation option. In most cases, the default configuration is recommended. Type 1 and press Enter to proceed with the standard installation.

Step 3: Configure Your Shell Environment

The installer places the Rust binaries—such as rustc, cargo, and rustup—into the ~/.cargo/bin directory. To make these commands available in your current terminal session, load the environment configuration by running:

source "$HOME/.cargo/env"

For future terminal sessions, this configuration is automatically added to your profile (such as ~/.bashrc or ~/.profile).

Step 4: Verify the Installation

Confirm that the Rust compiler and its package manager were installed successfully by checking their version numbers:

rustc --version
cargo --version

If the commands return the latest version numbers, the installation is complete.

Step 5: Updating Rust in the Future

Because rustup manages the toolchain independently of Ubuntu's apt package manager, you can update Rust to the latest stable release at any time by running:

rustup update
