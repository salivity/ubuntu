How to Install InfluxDB on Ubuntu

This guide provides a straightforward walkthrough on how to install the InfluxDB time-series database on an Ubuntu system. You will learn how to configure the official InfluxData repository, import the required GPG authentication key, execute the installation command using the APT package manager, and verify that the database service is up and running.

1. Update the System Packages

Before adding new repositories, ensure your local package index is up to date:

sudo apt update && sudo apt upgrade -y

Install the necessary dependencies to handle HTTPS repositories:

sudo apt install -y curl gpg lsb-release

2. Add the InfluxData Repository

InfluxDB is not available in the default Ubuntu repositories with the latest features, so you must add the official InfluxData repository and its GPG key.

Import the GPG key:

curl -fsSL https://repos.influxdata.com/influxdata-archive_compat.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/influxdata-archive_compat.gpg

Add the stable repository to your APT sources list:

echo "deb [signed-by=/etc/apt/trusted.gpg.d/influxdata-archive_compat.gpg] https://repos.influxdata.com/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/influxdata.list

3. Install InfluxDB

Update your APT package list to include the newly added InfluxData packages:

sudo apt update

The command used to install the InfluxDB time-series database on Ubuntu is:

sudo apt install influxdb2 -y

(Note: For legacy version 1.x, the command is sudo apt install influxdb -y)

To install the InfluxDB command-line client (CLI), run:

sudo apt install influxdb2-cli -y

4. Start and Enable the InfluxDB Service

Once the installation is complete, start the InfluxDB service and enable it to automatically start at system boot:

sudo systemctl enable --now influxdb

5. Verify the Service Status

Confirm that InfluxDB is running properly with the following command:

sudo systemctl status influxdb

If the service is running, the output will display active (running). By default, InfluxDB v2 listens on port 8086. You can now access the database web UI by navigating to http://your-server-ip:8086 in your web browser.
