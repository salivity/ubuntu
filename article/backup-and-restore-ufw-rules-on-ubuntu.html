Backup and Restore UFW Rules on Ubuntu

Backing up and restoring Uncomplicated Firewall (UFW) rules on Ubuntu is an essential task to safeguard network security configurations prior to system updates, migrations, or troubleshooting. UFW stores its runtime policies and persistent definitions in standard text files located within the /etc/ufw/ directory. This guide provides a direct, step-by-step procedure to export these configuration files into a backup archive and restore them to an active firewall state.

How UFW Stores Configuration

UFW maintains firewall states across system reboots using configuration files in /etc/ufw/. The most critical files include:

  • user.rules: Contains user-defined IPv4 rules.
  • user6.rules: Contains user-defined IPv6 rules.
  • before.rules / before6.rules: Rules evaluated before user rules (e.g., NAT, loopback traffic).
  • after.rules / after6.rules: Rules evaluated after user rules.
  • ufw.conf: Holds the default state (enabled/disabled) and logging level.

Step 1: Backing Up UFW Rules

The most reliable backup method is creating a compressed archive of the entire /etc/ufw configuration directory.

  1. Open your terminal.

  2. Run the following command to create a timestamped tar archive:

    sudo tar -czvf ufw-backup-$(date +%F).tar.gz -C /etc/ufw .

  3. Verify that the archive was created properly:

    tar -tzvf ufw-backup-*.tar.gz

  4. Transfer this .tar.gz file to an external drive or remote machine for safe storage.

Step 2: Restoring UFW Rules

To restore the firewall rules on the same machine or apply them to a newly installed Ubuntu server:

  1. Copy the backup file (ufw-backup-YYYY-MM-DD.tar.gz) to the target machine.

  2. Ensure UFW is installed on the target machine:

    sudo apt update && sudo apt install ufw -y

  3. Temporarily disable UFW to avoid network disruption or conflicts during the restore:

    sudo ufw disable

  4. Extract the backup archive directly into /etc/ufw/:

    sudo tar -xzvf ufw-backup-*.tar.gz -C /etc/ufw/

  5. Ensure file permissions remain secure so only root can modify the rules:

    sudo chown -R root:root /etc/ufw
sudo chmod 640 /etc/ufw/*.rules

  6. Enable and reload UFW to apply the restored configurations:

    sudo ufw enable
sudo ufw reload

Step 3: Verifying the Restoration

Once the reload is complete, check that all rules have loaded correctly by querying the firewall status:

sudo ufw status verbose

For a numbered view to confirm matching positions:

sudo ufw status numbered

The output should mirror the exact state and policies from the time the backup was taken.
