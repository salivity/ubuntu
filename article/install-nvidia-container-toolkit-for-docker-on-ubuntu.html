Install NVIDIA Container Toolkit for Docker on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring the NVIDIA Container Toolkit on an Ubuntu system. By completing these steps, you will configure Docker to communicate with your host system's NVIDIA drivers, allowing containers to access physical GPU resources for machine learning, rendering, or compute-heavy workloads.

Prerequisites

Before beginning, ensure that your system meets the following requirements:

  • Ubuntu 20.04, 22.04, or 24.04 installed.
  • Supported NVIDIA GPU hardware with appropriate proprietary NVIDIA drivers installed (verify by running nvidia-smi on the host).
  • Docker Engine installed and running.

Step 1: Configure the Production Repository

Add the NVIDIA Container Toolkit package repository and its GPG key to your system's package manager:

curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg \
  && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
    sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
    sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

Step 2: Update Package Lists and Install

Update your local package lists to include the newly added repository, then install the toolkit packages:

sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit

Step 3: Configure the Docker Runtime

Configure Docker to register the NVIDIA Container Runtime by using the nvidia-ctk command:

sudo nvidia-ctk runtime configure --runtime=docker

This command modifies the /etc/docker/daemon.json file to make the NVIDIA driver runtime available to Docker containers.

Step 4: Restart the Docker Daemon

Apply the configuration changes by restarting the Docker service:

sudo systemctl restart docker

Step 5: Verify the Installation

Confirm that Docker can access the host GPU by running a minimal NVIDIA CUDA container:

sudo docker run --rm --gpus all nvidia/cuda:12.0.0-base-ubuntu22.04 nvidia-smi

If the installation was successful, the output will display the familiar nvidia-smi table showing your host GPU model, driver version, and CUDA version directly from inside the container.
