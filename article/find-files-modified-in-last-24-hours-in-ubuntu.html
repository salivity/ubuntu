Find Files Modified in Last 24 Hours in Ubuntu

This guide demonstrates how to use the find utility in Ubuntu to quickly locate files modified within the last 24 hours. By leveraging time-based evaluation flags such as -mtime and -mmin, system administrators and users can track recent changes, monitor log updates, or recover recently edited files directly from the command line.

The Basic Command

To search for files modified within the last 24 hours in a specific directory, run:

find /path/to/search -type f -mtime -1
  • Replace /path/to/search with the directory you want to scan (use . for the current directory).
  • -type f restricts the results to regular files, excluding directories.
  • -mtime -1 instructs find to look for files modified strictly less than 24 hours ago.

Searching by Exact Minutes

While -mtime -1 checks for changes within the last 24-hour cycle, the -mmin option allows you to specify time in minutes for precise filtering:

find /path/to/search -type f -mmin -1440

Because 24 hours equals 1,440 minutes, -mmin -1440 achieves the exact same time cutoff down to the minute.

Common Practical Examples

Search the Current Working Directory

To find all recently edited files in your current working location:

find . -type f -mtime -1

Search System Directories (Requiring Root Privileges)

When scanning directories such as /etc or /var/log, prepend sudo to avoid "Permission denied" errors:

sudo find /var/log -type f -mtime -1

Display File Details Along with the Search

To view modification dates, file sizes, and permissions alongside the filenames, append -ls:

find . -type f -mtime -1 -ls

Alternatively, pass the results to ls -lh using -exec:

find . -type f -mtime -1 -exec ls -lh {} +

Summary of Flags

  • -mtime: Evaluates file modification time in increments of 24-hour days.
  • -mmin: Evaluates file modification time in minutes.
  • Minus sign (-): Indicates "less than" the specified duration (e.g., -1 means less than 24 hours ago).
  • Plus sign (+): Indicates "greater than" the specified duration (e.g., +1 means older than 24 hours).
