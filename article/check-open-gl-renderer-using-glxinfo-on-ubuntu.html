Check OpenGL Renderer Using glxinfo on Ubuntu

This guide demonstrates how to check your current OpenGL rendering engine and GPU information on Ubuntu using the glxinfo command-line utility. By filtering the output of this diagnostic tool, you can quickly identify the active graphics hardware, driver vendor, and supported OpenGL version running on your system.

Installing glxinfo

The glxinfo utility is part of the mesa-utils package. If it is not already installed on your Ubuntu system, open your terminal and run:

sudo apt update
sudo apt install mesa-utils

Viewing OpenGL Rendering Engine Details

To display the current OpenGL renderer, run:

glxinfo | grep "OpenGL renderer"

This returns a single line identifying the active graphics processing unit (GPU) or software rasterizer handling OpenGL rendering (for example, OpenGL renderer string: Mesa Intel(R) UHD Graphics (CML GT2) or an NVIDIA/AMD device string).

Viewing Comprehensive OpenGL Details

To see the rendering engine alongside the vendor, version, and shading language version, use an extended regular expression with grep:

glxinfo | grep -E "OpenGL (vendor|renderer|version|shading language version)"

The output provides four key details:

  • OpenGL vendor string: The organization or company providing the driver (e.g., Intel, NVIDIA, or AMD).
  • OpenGL renderer string: The specific GPU model or rendering engine in use.
  • OpenGL version string: The highest core OpenGL API version supported by the current driver.
  • OpenGL shading language version string: The supported GLSL version for shaders.
