Monitor Ubuntu CPU and Memory with Grafana

This guide explains how to build a custom Grafana dashboard to track CPU and memory metrics on an Ubuntu server. By using Prometheus Node Exporter to gather system metrics and Prometheus as a time-series database, you will learn how to configure data collection, write the appropriate PromQL queries, and design clear visualization panels inside Grafana.

Prerequisites

Ensure you have Grafana and Prometheus installed and running. If Prometheus is not yet installed on your Ubuntu system, install it alongside Node Exporter to expose hardware metrics.

Step 1: Install Node Exporter on Ubuntu

Node Exporter collects machine-level metrics like CPU and memory usage.

  1. Open your Ubuntu terminal and install the package: 
    sudo apt update
sudo apt install prometheus-node-exporter -y
  2. Enable and start the service: 
    sudo systemctl enable --now prometheus-node-exporter
  3. Verify that metrics are exposing locally on port 9100: 
    curl http://localhost:9100/metrics

Step 2: Configure Prometheus to Scrape Node Exporter

Prometheus must be configured to scrape the metrics from Node Exporter.

  1. Open /etc/prometheus/prometheus.yml in a text editor: 
    sudo nano /etc/prometheus/prometheus.yml
  2. Add the Node Exporter target under scrape_configs: 
    - job_name: 'ubuntu_node'
  static_configs:
    - targets: ['localhost:9100']
  3. Restart Prometheus to apply changes: 
    sudo systemctl restart prometheus

Step 3: Add Prometheus as a Grafana Data Source

  1. Log into your Grafana web interface (default: http://<your-server-ip>:3000).
  2. Navigate to Connections > Data Sources > Add data source.
  3. Select Prometheus.
  4. Set the Prometheus server URL (typically http://localhost:9090).
  5. Scroll to the bottom and click Save & Test.

Step 4: Create the Custom Dashboard

  1. In Grafana, click the Dashboards menu and select New > New Dashboard.
  2. Click Add visualization and select your Prometheus data source.

Step 5: Build the CPU Usage Panel

To monitor real-time CPU utilization, calculate the percentage of time the CPU is not idle:

  1. In the Metric query field, enter the following PromQL query: 
    100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
  2. In the right-hand panel settings:
    • Title: Set to CPU Usage.
    • Graph styles: Choose Time series or Gauge.
    • Standard options > Unit: Select Misc > Percent (0-100).
    • Min / Max: Set Min to 0 and Max to 100.
  3. Click Apply in the top-right corner.

Step 6: Build the Memory Usage Panel

To monitor RAM consumption accurately, compare available memory against total memory:

  1. Click Add > Visualization to create a second panel.
  2. Enter the following PromQL query for percentage of memory used: 
    (1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100
  3. Alternatively, to monitor absolute memory usage in bytes, use: 
    node_memory_MemTotal_bytes - node_memory_MemAvailable_bytes
  4. In the right-hand settings:
    • Title: Set to Memory Usage.
    • Standard options > Unit:
      • If using the percentage query, select Misc > Percent (0-100).
      • If using the absolute query, select Data (IEC) > Bytes.
  5. Click Apply.

Step 7: Save the Dashboard

  1. Arrange and resize the panels on the grid by dragging the edges.
  2. Click the Save dashboard disk icon in the top-right toolbar.
  3. Enter a name, such as Ubuntu System Performance, and choose a folder.
  4. Click Save to finish.
