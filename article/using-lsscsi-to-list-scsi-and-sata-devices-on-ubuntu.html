Using lsscsi to List SCSI and SATA Devices on Ubuntu

The lsscsi command in Ubuntu provides a quick, human-readable overview of all SCSI and SATA storage devices attached to a system. By querying the Linux kernel's sysfs filesystem, it strips away the complexity of raw system paths and presents storage hardware—including hard drives, solid-state drives, and optical drives—in an organized, tabular layout. This article explains the primary function of lsscsi, why it applies to modern SATA drives, how to interpret its output, and the most useful flags for storage administration.

The Core Purpose of lsscsi

The main objective of lsscsi is to map out the relationship between physical storage hardware, the SCSI subsystem, and corresponding Linux device nodes (such as /dev/sda). While modern drives largely use SATA, SAS, or NVMe protocols, the Linux kernel manages both parallel SCSI and SATA devices under the same SCSI subsystem via the libata driver layer. Consequently, the operating system treats SATA controllers as SCSI host adapters, making lsscsi an essential tool for identifying both native SCSI devices and modern SATA drives.

Installation

On Ubuntu systems, lsscsi is not always pre-installed by default, but it resides in the standard universe repositories. You can install it using the following command:

sudo apt update
sudo apt install lsscsi

Standard Output and Interpretation

Running lsscsi without any arguments displays all attached target devices:

[0:0:0:0]    disk    ATA      Crucial_CT500MX5 023   /dev/sda 
[1:0:0:0]    cd/dvd  HL-DT-ST DVDRAM GH24NSC0  RN00  /dev/sr0

The output is broken down into distinct columns:

  • SCSI Addressing ([H:C:T:L]): Displays the Host adapter number, Channel (bus) number, Target ID, and Logical Unit Number (LUN).
  • Device Type: Identifies whether the hardware is a disk, cd/dvd, tape, or other storage medium.
  • Vendor & Model: Shows the manufacturer name, model designation, and firmware revision string reported by the drive.
  • Device Node: Points directly to the /dev path used for partitioning, formatting, and mounting the storage.

Useful Command Flags

Storage administrators frequently use flags with lsscsi to gather deeper diagnostic details:

  • -s (Human-Readable Sizes): Appends disk capacities to the output, making it easier to match physical drives with specific capacities. 
    lsscsi -s
  • -t (Transport Information): Displays the underlying connection protocol (such as sata:, sas:, or fc: for Fibre Channel) along with transport-specific identifiers. 
    lsscsi -t
  • -k (Kernel Device Names): Replaces or supplements device paths with sysfs kernel names, which helps in tracing specific hardware errors logged in dmesg. 
    lsscsi -k

By correlating hardware addresses, transport protocols, and block device names into a single view, lsscsi simplifies storage troubleshooting, drive swapping, and system verification on Ubuntu.
