Configure GRE Tunnel Between Two Ubuntu Routers

A Generic Routing Encapsulation (GRE) tunnel encapsulates a wide variety of network-layer protocols inside virtual point-to-point links over an existing IP internetwork. This guide outlines the exact process for establishing a secure, persistent point-to-point GRE tunnel between two Ubuntu routers using modern Netplan configurations as well as standard iproute2 runtime commands.

Environment Setup

Assume two Ubuntu routers with public static IP addresses and dedicated private tunnel IP addresses:

  • Router A:
    • Public IP: 203.0.113.1
    • Tunnel IP: 10.0.0.1/30
    • Internal Subnet: 192.168.10.0/24
  • Router B:
    • Public IP: 198.51.100.1
    • Tunnel IP: 10.0.0.2/30
    • Internal Subnet: 192.168.20.0/24

Step 1: Enable IPv4 Forwarding

Both routers must have IP forwarding enabled to route packets through the tunnel.

  1. Open /etc/sysctl.conf on both routers: 
    sudo nano /etc/sysctl.conf
  2. Uncomment or add the following line: 
    net.ipv4.ip_forward=1
  3. Apply the changes immediately: 
    sudo sysctl -p

Step 2: Configure Persistent Tunnel via Netplan

Modern Ubuntu installations use Netplan for network management. This ensures the tunnel persists across reboots.

On Router A:

Create a new Netplan file, for example /etc/netplan/60-gre-tunnel.yaml:

network:
  version: 2
  tunnels:
    gre1:
      mode: gre
      local: 203.0.113.1
      remote: 198.51.100.1
      addresses:
        - 10.0.0.1/30
      routes:
        - to: 192.168.20.0/24
          via: 10.0.0.2

On Router B:

Create /etc/netplan/60-gre-tunnel.yaml:

network:
  version: 2
  tunnels:
    gre1:
      mode: gre
      local: 198.51.100.1
      remote: 203.0.113.1
      addresses:
        - 10.0.0.2/30
      routes:
        - to: 192.168.10.0/24
          via: 10.0.0.1

Apply Configurations:

Run this command on both servers to activate the interface:

sudo netplan apply

Alternative: Ephemeral Setup via CLI (Temporary)

If you need to test the tunnel without altering Netplan files, use the iproute2 suite.

On Router A:

sudo ip tunnel add gre1 mode gre remote 198.51.100.1 local 203.0.113.1 ttl 255
sudo ip addr add 10.0.0.1/30 dev gre1
sudo ip link set gre1 up
sudo ip route add 192.168.20.0/24 via 10.0.0.2 dev gre1

On Router B:

sudo ip tunnel add gre1 mode gre remote 203.0.113.1 local 198.51.100.1 ttl 255
sudo ip addr add 10.0.0.2/30 dev gre1
sudo ip link set gre1 up
sudo ip route add 192.168.10.0/24 via 10.0.0.1 dev gre1

Step 3: Firewall Configuration

Ensure your firewall permits GRE traffic (IP protocol 47).

Using UFW on both routers:

sudo ufw allow in proto gre from <REMOTE_PUBLIC_IP> to any

Using iptables directly:

sudo iptables -A INPUT -p gre -s <REMOTE_PUBLIC_IP> -j ACCEPT

Step 4: Verification

  1. Verify Interface Status: 
    ip addr show gre1
  2. Ping the Remote Tunnel Endpoint: From Router A: 
    ping -c 4 10.0.0.2
  3. Trace Route Between Subnets: Verify routing from a device behind Router A to a device behind Router B: 
    traceroute 192.168.20.10
