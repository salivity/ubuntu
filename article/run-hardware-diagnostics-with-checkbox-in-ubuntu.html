Run Hardware Diagnostics with Checkbox in Ubuntu

This guide explains how to install, configure, and run comprehensive hardware diagnostics on Ubuntu systems using Canonical's native Checkbox utility. Checkbox provides automated and interactive testing suites that evaluate critical components including the processor, memory, graphics, storage drives, and network interfaces. By following the steps below, you will learn how to initiate the tool via the command-line interface, select appropriate test suites, execute hardware checks, and export detailed diagnostic reports for system validation or troubleshooting.

Installing Checkbox

Checkbox is available as a Snap package and through Ubuntu's standard package repositories. The Snap version is recommended by Canonical to ensure access to the latest hardware definitions and diagnostic scripts.

To install the Checkbox suite via Snap with the required system permissions, open your terminal and run:

sudo snap install checkbox --classic

If you prefer using the APT package manager on supported LTS releases, install the terminal client using:

sudo apt update
sudo apt install checkbox-ng

Launching the Diagnostic Interface

Because hardware diagnostics require direct communication with system firmware and physical controllers, you must launch Checkbox with administrative privileges.

Start the interactive terminal interface:

sudo checkbox-cli

Upon launching, Checkbox initializes its test provider modules and presents a terminal-based user interface (TUI).

Selecting Test Suites

Once inside the interface, Checkbox presents various test suites depending on your machine type (desktop, server, or laptop):

  1. Choose a Test Plan: Use the arrow keys to navigate the menu. Select a comprehensive plan such as System Testing or Ubuntu Core Hardware Testing.
  2. Select Specific Subsystems: If you only need to diagnose specific components, deselect the global suite and individually mark modules such as:
    • Memory (RAM): Checks allocation and stress performance.
    • Storage (Disk/NVMe): Checks SMART data, read/write speeds, and block health.
    • CPU: Verifies instruction sets, thermal throttling, and multi-core stability.
    • Networking: Tests connectivity, throughput, and controller states.
    • Graphics/Audio: Verifies hardware acceleration and peripheral outputs.
  3. Confirm Selection: Press Enter or select Start Testing to proceed.

Executing the Tests

Checkbox runs two categories of tests:

  • Automated Tests: These run in the background without user intervention. The tool probes sysfs, reads hardware registers, inspects kernel logs (dmesg), and executes benchmark stress loops.
  • Interactive Tests: These require physical user input. Checkbox will prompt you to perform actions such as plugging in a USB drive, listening for audio tones, pressing specific keys, or verifying visual patterns on the display. Follow the on-screen prompts and select Pass or Fail based on the result.

You can skip any interactive test that does not apply to your hardware configuration by selecting Skip.

Exporting and Reviewing the Diagnostic Report

After all tests complete, Checkbox compiles a comprehensive summary showing:

  • Passed: Hardware components operating within defined specifications.
  • Failed: Subsystems that threw kernel errors, failed read/write passes, or did not respond.
  • Skipped: Tests bypassed due to missing peripherals or manual skips.

Checkbox will prompt you to save the test results. Choose your preferred output format:

  • HTML: Recommended for local viewing through any web browser.
  • JSON/XML: Useful for parsing results into automated monitoring systems.
  • Tarball: Packages all log outputs, system specifications, and test results into an archive.

To review an exported HTML report, open the generated file path in your browser:

xdg-open /path/to/checkbox-report.html

Inspect the Failed section to identify malfunctioning hardware, kernel panics, or missing proprietary drivers.
