Show Full SSL Certificate Chain in Ubuntu Terminal

This guide demonstrates how to retrieve and inspect the entire SSL/TLS certificate chain of a remote web server using the Ubuntu terminal. By executing a single OpenSSL command, you can view the leaf, intermediate, and root certificates, verify the certificate trust path, and diagnose common SSL configuration errors without relying on a graphical web browser.

The OpenSSL Command

Ubuntu includes the OpenSSL toolkit by default. To display the complete certificate chain returned by a remote server, run the following command:

openssl s_client -showcerts -servername example.com -connect example.com:443 < /dev/null

Replace example.com with the actual target domain name or IP address.

Command Breakdown

  • s_client: Implements a generic SSL/TLS client that establishes a direct cryptographic connection to the remote host.
  • -showcerts: Forces OpenSSL to print all certificates provided by the server in PEM format, rather than only displaying the leaf (server) certificate.
  • -servername example.com: Enables Server Name Indication (SNI). This informs the remote server which domain name you are trying to reach, which is critical for servers hosting multiple SSL-enabled domains on a single IP address.
  • -connect example.com:443: Defines the target host and port number (port 443 is the standard port for HTTPS).
  • < /dev/null: Sends an End of File (EOF) signal immediately after the connection handshakes, preventing the command from remaining open and hanging in your terminal.

How to Read the Output

The output begins with details about the established connection and then lists the certificates in hierarchical order:

  1. Certificate Hierarchy (Depth Markers): Near the top, you will see a section labeled Certificate chain. Each certificate is numbered by depth:
    • depth=0: The server (leaf) certificate.
    • depth=1 (and higher): The intermediate Certificate Authority (CA) certificates.
    • Top depth: The Root CA certificate (if provided by the server).
  2. PEM Blocks: Each certificate will be displayed sequentially between -----BEGIN CERTIFICATE----- and -----END CERTIFICATE----- tags.

Saving and Decoding the Chain

To save the certificates to a file for auditing or offline analysis, pipe the command output:

openssl s_client -showcerts -servername example.com -connect example.com:443 < /dev/null > cert_chain.pem

To parse individual certificate human-readable details (such as validity dates and subject alternative names), pass the output to the x509 command:

openssl s_client -servername example.com -connect example.com:443 < /dev/null | openssl x509 -noout -text
