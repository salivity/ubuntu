How to Screenshot a Specific Window Using Scrot in Ubuntu

This guide explains how to use scrot (SCReen SHOT), a command-line utility, to capture screenshots of a specific window in Ubuntu. You will learn how to install scrot, capture active or interactively selected windows, set delay timers, and save your screenshot files directly to custom locations.

Install Scrot

Open your terminal (Ctrl+Alt+T) and run the following command to install scrot:

sudo apt update && sudo apt install scrot

Capture the Currently Focused Window

To capture the window that is currently active, use the -u (focused) flag:

scrot -u

By default, the screenshot is saved in your current working directory with a timestamped filename.

Capture a Window Interactively

To select a specific window by clicking on it with your mouse, use the -s (select) flag:

scrot -s

After executing the command, click on the target window to take the screenshot.

Add a Countdown Delay

Adding a delay gives you time to switch to the desired window before the image is captured. Use the -d flag for the delay in seconds and -c to show a countdown in the terminal:

scrot -u -d 5 -c

This waits 5 seconds, displaying a countdown, and then captures the currently focused window.

Specify a Custom Output Path and Filename

To save the screenshot to a specific folder or with a custom filename, add the path to the end of the command:

scrot -u ~/Pictures/specific_window.png
