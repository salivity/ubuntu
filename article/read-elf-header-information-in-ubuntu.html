Read ELF Header Information in Ubuntu

To read the ELF (Executable and Linkable Format) header information of a binary file in Ubuntu, the primary command-line utility used is readelf with the -h flag. This tool displays essential metadata embedded within binary files, such as the target architecture, file class, entry point address, and byte ordering, without executing the binary itself. This article details how to use readelf along with alternative methods to inspect binary headers in Ubuntu.

Primary Method: Using the readelf Command

The readelf command is part of the GNU binutils package and is designed specifically to analyze ELF format files.

To display the ELF header, open your terminal and run:

readelf -h <filename>

Example

To inspect the header of the standard ls executable:

readelf -h /bin/ls

Key Output Fields Explained

  • Magic: A series of bytes that identifies the file as an ELF binary (7f 45 4c 46).
  • Class: Indicates whether the binary is built for 32-bit (ELF32) or 64-bit (ELF64) systems.
  • Data: Shows the byte ordering (e.g., 2's complement, little endian).
  • Type: Specifies file type, such as EXEC (Executable), DYN (Shared object/Position-Independent Executable), or REL (Relocatable file).
  • Machine: Indicates the target CPU architecture (e.g., Advanced Micro Devices x86-64, ARM).
  • Entry point address: The memory address where program execution begins.

Alternative Commands

If readelf is unavailable, you can use these alternative commands to view binary header metadata:

1. Using objdump

The objdump utility displays information from binary files using the -f flag to view header contents:

objdump -f <filename>

2. Using file

The file command provides a concise summary of the binary, including architecture and ELF class:

file <filename>

Prerequisites and Installation

The readelf utility comes pre-installed on most Ubuntu systems. If the command is missing, install the binutils package using:

sudo apt update
sudo apt install binutils
