Sign Kernel Modules with MOK on Ubuntu Secure Boot

UEFI Secure Boot prevents unauthorized code execution by verifying digital signatures before loading kernel modules into memory. On Ubuntu systems, custom compiled kernel modules will fail to load unless they are signed by a trusted cryptographic key. This guide walks you through creating a Machine Owner Key (MOK), enrolling it into the UEFI firmware using Ubuntu's mokutil utility, and signing your custom .ko kernel module so it loads seamlessly without compromising system security.

1. Install Required Tools

Before generating keys and signing modules, install the necessary cryptographic and build utilities:

sudo apt update
sudo apt install openssl mokutil sbsigntool linux-headers-$(uname -r)

2. Generate a Machine Owner Key (MOK)

Create a dedicated directory to store your keys. Ensure appropriate permissions are set so the private key remains secure.

mkdir -p ~/mok-keys
cd ~/mok-keys
chmod 700 ~/mok-keys

Create an OpenSSL configuration file named mokconfig.cnf:

[ req ]
default_bits = 4096
distinguished_name = req_distinguished_name
prompt = no
x509_extensions = myexts

[ req_distinguished_name ]
CN = Custom Module Signing Key

[ myexts ]
basicConstraints=critical,CA:FALSE
keyUsage=digitalSignature
subjectKeyIdentifier=hash
authorityKeyIdentifier=keyid

Generate the key pair (private key and public X.509 certificate):

openssl req -x509 -new -nodes -utf8 -sha256 -days 3650 -batch -config mokconfig.cnf -outform DER -out MOK.der -keyout MOK.priv

3. Enroll the Key into the UEFI Firmware

Use mokutil to register the public key (MOK.der) with the Shim bootloader:

sudo mokutil --import MOK.der

You will be prompted to create a temporary password. Remember this password, as you must enter it during the next system reboot.

4. Reboot and Confirm Enrollment

Restart the computer:

sudo reboot

During boot, the UEFI Shim loader will display the blue "Perform MOK management" screen:

  1. Select Enroll MOK.
  2. Select View key 0 to confirm it is your key, then select Continue.
  3. Select Yes when prompted to enroll the key.
  4. Enter the temporary password you created in step 3.
  5. Select Reboot.

Once the system boots back into Ubuntu, verify that the key is active:

mokutil --list-enrolled | grep "Custom Module Signing Key"

5. Sign the Compiled Kernel Module

Ubuntu provides a dedicated signing utility called sign-file within the kernel headers directory. Use this tool along with your private key and public certificate to sign your compiled .ko file.

Run the following command, replacing /path/to/module.ko with the path to your module:

sudo /usr/src/linux-headers-$(uname -r)/scripts/sign-file sha256 ~/mok-keys/MOK.priv ~/mok-keys/MOK.der /path/to/module.ko

6. Verify and Load the Module

Check the module details to verify that the cryptographic signature block is attached:

modinfo /path/to/module.ko | grep -E "signer|sig_key|sig_hashalgo"

You should see your key's Common Name listed under the signer field. Finally, load the module into the running kernel:

sudo insmod /path/to/module.ko

Confirm that the module loaded without triggering Secure Boot rejection by checking the kernel log:

sudo dmesg | tail
