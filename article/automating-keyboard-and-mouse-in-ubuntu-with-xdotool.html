Automating Keyboard and Mouse in Ubuntu with Xdotool

The primary purpose of xdotool in Ubuntu running the X11 display server is to programmatically simulate keyboard input, mouse activity, and window management tasks. It acts as a command-line utility that allows users and developers to automate repetitive user interface actions, generate custom keyboard macros, and script complex GUI interactions without physical user intervention.

Core Functions of xdotool

1. Keyboard Automation

xdotool can emulate individual key presses, key combinations, and entire sequences of text typing.

  • Simulating Key Presses: You can trigger specific keys like Return, Tab, or shortcut combinations like Ctrl+C.
  • Text Injection: It can type long strings of text directly into active fields, useful for auto-filling forms or executing shell commands inside terminal windows.

2. Mouse Control

The tool allows full programmatic control over mouse behavior based on screen coordinates or relative positions.

  • Cursor Movement: Move the cursor to specific X and Y coordinates on the screen.
  • Clicking and Scrolling: Simulate left, right, or middle mouse clicks, as well as mouse wheel scrolling.
  • Drag and Drop: Program mouse button press and release events to move desktop elements.

3. Window Management

Beyond simple input simulation, xdotool interacts directly with X11 windows.

  • Finding Windows: Search for open applications by window title, class, or process ID (PID).
  • Focusing and Activating: Bring specific windows to the foreground before sending input commands.
  • Resizing and Moving: Adjust window dimensions and positions dynamically through scripts.

Common Use Cases in Ubuntu X11

  • Task Automation: Creating Bash scripts to handle repetitive daily workflows, such as opening applications and navigating menus automatically.
  • Software Testing: Testing graphical user interfaces (GUIs) by simulating real user interactions to ensure applications behave as expected.
  • Custom Hotkeys: Mapping complex multi-step actions to single keyboard shortcuts using Ubuntu's built-in keyboard settings combined with xdotool scripts.
  • Kiosk and Display Systems: Controlling unattended digital displays or kiosk setups by periodically sending keystrokes or refresh commands.

Important Considerations

  • X11 Dependency: xdotool relies specifically on the X11 display protocol capabilities. While it works seamlessly on Ubuntu systems running X11 (or via XWayland), it does not natively support pure Wayland sessions.
  • Timing: Scripts often require deliberate delay commands (using sleep or the --delay flag in xdotool) to ensure applications have enough time to render or process input before the next command executes.
