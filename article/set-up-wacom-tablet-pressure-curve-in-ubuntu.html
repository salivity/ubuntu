Set Up Wacom Tablet Pressure Curve in Ubuntu

Adjusting the pressure sensitivity curve of a Wacom tablet on Ubuntu allows digital artists to achieve precise stroke weights and responsiveness tailored to their drawing style. This guide covers how to calibrate pressure response using Ubuntu's built-in GNOME Settings for basic adjustments, as well as using the OpenTabletDriver GUI and application-level tools for detailed, visual bezier-curve customization.

Method 1: Adjusting Tip Feel via Native Ubuntu Settings

Ubuntu includes built-in support for Wacom devices via the GNOME Control Center. While it does not display a full bezier-curve graph, it provides a straightforward slider to control the pressure curve threshold from soft to firm.

  1. Open Settings from the Ubuntu application menu.
  2. Scroll down the left sidebar and select Wacom Tablet.
  3. Select your connected tablet from the list.
  4. Click on the Stylus (or Pen) section.
  5. Locate the Tip Feel slider.
    • Move the slider toward Soft to trigger maximum pressure with lighter touches.
    • Move the slider toward Firm if you have a heavy hand and want to prevent reaching full brush size too quickly.
  6. Use the Test Settings scratchpad area on the screen to draw sample strokes and test the responsiveness in real time.

Method 2: Custom Bezier Curves with OpenTabletDriver GUI

For an exact, graphical pressure curve editor with movable control points, OpenTabletDriver provides a full-featured graphical interface for Linux.

  1. Download and install OpenTabletDriver and its GUI package (opentabletdriver or .deb packages from its official repository).
  2. Launch OpenTabletDriver from your application launcher.
  3. Select your active stylus profile from the top tabs.
  4. Go to the Pen or Advanced tab to locate the Pressure settings.
  5. Enable custom pressure settings and click the Curve editor.
  6. Drag the control points on the graph to shape the input-versus-output response (e.g., an S-curve for fine control at low pressure and high pressure, or an exponential curve for light strokes).
  7. Click Apply to lock in your custom curve globally across your system.

Method 3: In-Application Curve Configuration (Krita / GIMP)

If you only need a customized pressure curve for specific artwork software, you can configure it directly inside applications like Krita without modifying system-wide settings.

  1. Open your creative software (e.g., Krita).
  2. Navigate to Settings > Configure Krita > Tablet Settings.
  3. Under the Tablet Pressure Curve section, click and drag the control points on the graphical grid to shape the curve.
  4. Use the built-in testing canvas to confirm the response before clicking OK.
