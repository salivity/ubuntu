Mount LVM Logical Volume from Raw Disk Image in Ubuntu

This guide provides a straightforward method to mount an LVM (Logical Volume Manager) partition directly from a raw disk image (.img or .raw) in Ubuntu. By associating the raw image with a loop device that scans for partition tables, you can discover, activate, and mount the underlying logical volumes to your filesystem without modifying the original host partition structure.

Prerequisites

Ensure you have the required LVM tools installed:

sudo apt update
sudo apt install lvm2

Step 1: Attach the Image to a Loop Device

Use losetup with the -P flag to automatically scan and create partition nodes for the attached image:

sudo losetup -Pf /path/to/disk_image.img

To find which loop device was assigned, run:

losetup -a

Assume the output identifies the device as /dev/loop0.

Step 2: Scan for LVM Structures

Scan the system to detect the Physical Volumes (PV) and Volume Groups (VG) located inside the newly attached image:

sudo pvscan
sudo vgscan

The output will display the discovered Volume Group name (e.g., vg_guest).

Step 3: Activate the Volume Group

Activate all logical volumes within the identified volume group:

sudo vgchange -ay <volume_group_name>

Replace <volume_group_name> with the actual name discovered in Step 2.

To list the specific logical volumes available to mount:

sudo lvs

The volumes will now be accessible at /dev/<volume_group_name>/<logical_volume_name> or /dev/mapper/<volume_group_name>-<logical_volume_name>.

Step 4: Mount the Logical Volume

Create a mount point and mount the logical volume:

sudo mkdir -p /mnt/image_lv
sudo mount /dev/<volume_group_name>/<logical_volume_name> /mnt/image_lv

You can now access the files inside /mnt/image_lv.

Step 5: Clean Up and Detach

Once you have finished working with the files, safely unmount and detach the image:

  1. Unmount the filesystem:

    sudo umount /mnt/image_lv

  2. Deactivate the Volume Group:

    sudo vgchange -an <volume_group_name>

  3. Detach the loop device:

    sudo losetup -d /dev/loop0
