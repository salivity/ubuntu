How to Set Up RAID Array Using mdadm in Ubuntu

Setting up a Redundant Array of Independent Disks (RAID) in Ubuntu enhances storage performance, data redundancy, or both, depending on the chosen RAID level. This guide provides a straightforward walk-through for installing the mdadm utility, identifying your storage drives, building a RAID array, formatting it with a filesystem, and configuring the system to automatically mount the array upon boot.

Step 1: Install mdadm

Update your package list and install the mdadm management tool:

sudo apt update
sudo apt install mdadm -y

Step 2: Prepare the Storage Drives

Identify the drives you intend to use for the RAID array. Run:

lsblk

Locate your target drives (for example, /dev/sdb and /dev/sdc). Ensure these drives do not contain important data, as the creation process will erase existing files.

Step 3: Create the RAID Array

Use mdadm to build the array. Replace /dev/md0 with your preferred array name, --level=1 with your desired RAID level (e.g., 0, 1, 5, 6, 10), and specify your drives:

sudo mdadm --create --verbose /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc

Monitor the progress of the array creation with:

cat /proc/mdstat

Step 4: Create and Mount the Filesystem

Format the new RAID device with the ext4 filesystem:

sudo mkfs.ext4 -F /dev/md0

Create a mount point directory and mount the array:

sudo mkdir -p /mnt/raid1
sudo mount /dev/md0 /mnt/raid1

Step 5: Save the RAID Configuration

To ensure the RAID array reassembles automatically across system reboots, save the active configuration to mdadm.conf:

sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf

Update the initial RAM file system so the array details are available during early boot:

sudo update-initramfs -u

Step 6: Configure Automatic Mounting on Boot

Find the Universally Unique Identifier (UUID) of your new RAID filesystem:

sudo blkid /dev/md0

Copy the UUID value. Open /etc/fstab in a text editor:

sudo nano /etc/fstab

Add the following line to the end of the file, replacing YOUR-UUID-HERE with your actual UUID:

UUID=YOUR-UUID-HERE /mnt/raid1 ext4 defaults 0 0

Save and exit. Test the configuration to verify there are no errors:

sudo mount -a
