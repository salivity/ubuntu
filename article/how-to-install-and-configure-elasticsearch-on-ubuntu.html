How to Install and Configure Elasticsearch on Ubuntu

This guide provides a straightforward tutorial on installing and configuring the Elasticsearch search engine on an Ubuntu server. You will learn how to add the official Elastic package repository, install the software using the APT package manager, update critical configuration settings in the elasticsearch.yml file, and manage the system service to get your search engine running securely.

Prerequisites

Before starting, ensure you have an Ubuntu system (20.04 LTS or newer) with a user account that has sudo privileges, along with curl and apt-transport-https installed.

Update your system package index:

sudo apt update && sudo apt upgrade -y
sudo apt install apt-transport-https ca-certificates curl gnupg -y

Step 1: Add the Elastic GPG Key and Repository

Elasticsearch is not available in the default Ubuntu repositories. You must add the official Elastic repository to access the latest version.

Import the official Elastic GPG key to verify package signatures:

curl -fsSL https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg

Next, add the Elastic repository to your system’s sources list:

echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list

Step 2: Install Elasticsearch

Update your local package lists to include the newly added repository, then run the installation command:

sudo apt update
sudo apt install elasticsearch -y

During installation, the terminal will display generated security credentials, including the password for the default elastic superuser and an enrollment token. Save these credentials in a secure location.

Step 3: Configure Elasticsearch

The main configuration file is located at /etc/elasticsearch/elasticsearch.yml. Open it with a text editor:

sudo nano /etc/elasticsearch/elasticsearch.yml

Modify the following key parameters based on your requirements:

  • Cluster Name: Set a descriptive name for your cluster.

    cluster.name: my-application-cluster

  • Node Name: Name your individual node.

    node.name: node-1

  • Network Host: By default, Elasticsearch binds to localhost. If you need external applications to access it, change this to your server’s private IP address or 0.0.0.0 for all interfaces.

    network.host: 127.0.0.1

  • HTTP Port: The default port is 9200. You can uncomment this line to explicitly set it:

    http.port: 9200

Save the file and exit the editor (in nano, press CTRL+O, ENTER, then CTRL+X).

Step 4: Start and Enable the Elasticsearch Service

Elasticsearch does not start automatically after installation. Use systemctl to enable it to run at boot and start the service immediately:

sudo systemctl daemon-reload
sudo systemctl enable elasticsearch
sudo systemctl start elasticsearch

To verify that the service is running properly, check its status:

sudo systemctl status elasticsearch

Step 5: Test the Installation

Test the connection to Elasticsearch by sending an HTTP request to port 9200 using curl. Since Elasticsearch 8.x enables TLS by default, perform a secure request using the CA certificate created during installation:

curl --cacert /etc/elasticsearch/certs/http_ca.crt -u elastic https://localhost:9200

Enter the password generated during the installation when prompted. If successful, you will receive a JSON response containing version and cluster information.
