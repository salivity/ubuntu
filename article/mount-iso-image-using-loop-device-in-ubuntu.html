Mount ISO Image Using Loop Device in Ubuntu

This article explains how to mount a virtual CD/DVD ISO image in Ubuntu using the command-line loop device. You will learn how to create a dedicated mount point, attach the ISO file using the mount command with loop options, browse the files, and cleanly unmount the image when finished.

Step 1: Create a Mount Point Directory

Before mounting the ISO image, you need an empty directory to serve as the mount point. Open your terminal and create a directory (for example, /mnt/iso):

sudo mkdir -p /mnt/iso

Step 2: Mount the ISO Image

Use the mount command with the -o loop option to attach the ISO file to the directory you created. Replace /path/to/image.iso with the actual path to your ISO file:

sudo mount -o loop /path/to/image.iso /mnt/iso

The system will typically display a message stating that the device is mounted read-only, which is standard behavior for CD/DVD optical images.

Step 3: Access the Files

Once mounted, you can view and access the contents of the ISO image just like any standard directory:

ls -l /mnt/iso

You can also navigate to /mnt/iso in the Ubuntu graphical file manager to view or copy files.

Step 4: Unmount the ISO Image

When you are finished using the files, release the loop device by unmounting the directory:

sudo umount /mnt/iso

Ensure your terminal or file manager is not currently inside the /mnt/iso directory when running the command, as this will cause a "device is busy" error. If desired, you can safely remove the temporary directory afterward using sudo rmdir /mnt/iso.
