How to Create an Alias in Bashrc on Ubuntu

Creating aliases in Ubuntu allows you to replace long, complex terminal commands with memorable, short shortcuts. This guide covers how to locate and edit the hidden .bashrc configuration file in your home directory, format your alias syntax properly, reload the environment to apply changes immediately, and verify that your new command works as expected.

Step 1: Open the .bashrc File

The .bashrc file runs automatically every time you launch a new interactive Bash session. Open this file in your terminal using a text editor such as nano:

nano ~/.bashrc

Step 2: Define Your Alias

Scroll to the bottom of the file (or to the section marked # some more ls aliases). Add your custom alias using the following standard syntax:

alias your_shortcut='original_long_command'

Note: Ensure there are no spaces around the = sign, and enclose the target command within single quotes.

Common Examples:

  • System Update Shortcut: 
    alias update='sudo apt update && sudo apt upgrade -y'
  • Detailed File Listing: 
    alias ll='ls -alFh'
  • Quick Directory Navigation: 
    alias ..='cd ..'

Step 3: Save and Exit

If you are using nano:

  1. Press Ctrl + O and hit Enter to save the file.
  2. Press Ctrl + X to exit the editor.

Step 4: Reload the .bashrc File

Aliases added to .bashrc do not take effect automatically in your current terminal session. To apply the modifications immediately without restarting the terminal, execute:

source ~/.bashrc

Step 5: Test the Alias

Type your new shortcut into the terminal and press Enter. For instance, typing update will now run sudo apt update && sudo apt upgrade -y.

To verify that your alias is active or to view what command it maps to, run:

alias update

If you ever wish to remove an alias, open ~/.bashrc, delete or comment out the line with a #, save the file, and run source ~/.bashrc again.
