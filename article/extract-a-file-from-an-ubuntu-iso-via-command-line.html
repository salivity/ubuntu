Extract a File from an Ubuntu ISO via Command Line

Extracting a specific file from a standard Ubuntu ISO image using the command line does not require unpacking the entire archive or burning it to a drive. Depending on the tools installed on your system, you can pull a single file directly using archive utilities like 7z, the ISO-specific tool xorriso, or by temporarily mounting the image to your filesystem. This guide outlines the most efficient command-line methods to locate and extract precisely the files you need.

Method 1: Using 7-Zip (7z)

The 7-Zip utility can read ISO formats directly and extract individual files without needing administrative (root) permissions.

  1. Install p7zip-full if it is not already available:

    sudo apt update && sudo apt install p7zip-full

  2. List the contents of the ISO to find the exact file path:

    7z l ubuntu-22.04-desktop-amd64.iso

  3. Extract the target file to your current directory:

    7z e ubuntu-22.04-desktop-amd64.iso casper/vmlinuz

    Replace casper/vmlinuz with the relative path of the file you want to extract.

Method 2: Mounting the ISO via Loop Device

This method uses native Linux utilities and requires no third-party packages, though it does require sudo privileges.

  1. Create a temporary mount point:

    mkdir -p /tmp/iso_mount

  2. Mount the ISO as a read-only loop device:

    sudo mount -o loop,ro ubuntu-22.04-desktop-amd64.iso /tmp/iso_mount

  3. Copy the desired file to your destination directory:

    cp /tmp/iso_mount/casper/initrd .

  4. Unmount the ISO and clean up the directory:

    sudo umount /tmp/iso_mount
rmdir /tmp/iso_mount

Method 3: Using xorriso

xorriso is a dedicated tool for working with Rock Ridge and ISO 9660 filesystems without mounting.

  1. Install xorriso:

    sudo apt update && sudo apt install xorriso

  2. Extract the specific file directly using osirrox:

    xorriso -osirrox on -indev ubuntu-22.04-desktop-amd64.iso -extract /casper/vmlinuz ./vmlinuz
