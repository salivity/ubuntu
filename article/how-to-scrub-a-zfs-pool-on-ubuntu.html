How to Scrub a ZFS Pool on Ubuntu

Scrubbing a ZFS pool is an essential maintenance task on Ubuntu that reads all data blocks across the pool to detect silent data corruption, commonly known as bit rot, and automatically repairs errors using parity or mirror copies. This guide outlines the step-by-step process for initiating a manual scrub, monitoring its progress, managing the operation, and automating the process via systemd or cron to maintain long-term data integrity.

What is a ZFS Scrub?

A ZFS scrub validates all checksums stored within a pool. Unlike a standard filesystem check (fsck), a scrub runs while the pool is online and actively mounted, ensuring zero downtime for your services. If a checksum mismatch is detected, ZFS automatically attempts to repair the corrupted block using redundant copies from mirrored or RAID-Z drives.

Step 1: Identify Your ZFS Pool

Before running a scrub, identify the name and current state of your pool by opening a terminal and running:

zpool status

Note the name of the pool you wish to verify (for example, tank or rpool).

Step 2: Start the Scrub Operation

Initiate the scrub using the zpool scrub command followed by your pool's name. Superuser privileges are required:

sudo zpool scrub <pool_name>

Replace <pool_name> with your actual pool name. The command returns immediately to the prompt because the scrub executes as a background process.

Step 3: Monitor Scrub Progress

To view the progress, scan rate, estimated completion time, and any repaired errors, run:

zpool status <pool_name>

Under the scan line, the output will display details such as:

  • The amount of data scanned and repaired.
  • The scrubbing speed and percentage completed.
  • The estimated time remaining.

Once the scrub completes, the scan section updates to show the date and time of completion, along with a tally of any repaired errors.

Step 4: Pause or Stop a Scrub (Optional)

Because scrubbing causes significant disk I/O, you may need to pause or cancel it during high-load periods.

To pause a scrub:

sudo zpool scrub -p <pool_name>

To resume a paused scrub, run the original scrub command again:

sudo zpool scrub <pool_name>

To cancel and stop the scrub entirely:

sudo zpool scrub -s <pool_name>

Step 5: Automate Regular Scrubs

Ubuntu installations with the zfsutils-linux package include automated scrub configurations by default.

To verify that the automated systemd scrub timer is active, run:

systemctl list-timers | grep zfs

If it is inactive, enable the built-in systemd timer:

sudo systemctl enable --now zfs-scrub.timer

Alternatively, you can configure a monthly cron job by creating a file in /etc/cron.monthly/zfs-scrub:

#!/bin/sh
zpool scrub <pool_name>

Ensure the script is executable:

sudo chmod +x /etc/cron.monthly/zfs-scrub

Scheduling regular scrubs once every two to four weeks ensures continuous protection against data degradation without manual intervention.
