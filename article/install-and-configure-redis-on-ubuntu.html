Install and Configure Redis on Ubuntu

This guide provides a step-by-step walkthrough for installing, configuring, and securing the Redis in-memory data store on an Ubuntu system. You will learn how to update your local package index, install Redis using the default package manager, adjust key configuration settings for system integration and security, and verify that the database service is functioning properly.

Step 1: Update Package Index and Install Redis

Before installing Redis, update your local APT package repository index to ensure you access the latest package versions.

sudo apt update
sudo apt install redis-server -y

Step 2: Configure Redis for Systemd Integration

By default, Redis does not use a system service manager to supervise its process. Configuring Redis to use systemd allows Ubuntu to control and monitor the service reliably.

  1. Open the Redis configuration file in a text editor:
sudo nano /etc/redis/redis.conf
  1. Locate the supervised directive inside the file. By default, it is set to no:
supervised no
  1. Change the value to systemd:
supervised systemd
  1. Save the file and exit the editor.

Step 3: Secure Redis with a Password (Recommended)

Redis is configured by default to accept connections only from localhost (127.0.0.1). Setting an authentication password adds a necessary layer of security for stored data.

  1. Open the configuration file:
sudo nano /etc/redis/redis.conf
  1. Scroll to the SECURITY section, find the # requirepass line, uncomment it by removing #, and set a strong password:
requirepass your_strong_password_here
  1. Save and close the file.

Step 4: Restart and Enable the Redis Service

Apply the configuration changes by restarting the Redis service, then enable it to start automatically on system boot.

sudo systemctl restart redis-server
sudo systemctl enable redis-server

Verify that the service is running correctly:

sudo systemctl status redis-server

Step 5: Test Redis Functionality

Confirm that the installation and configuration succeeded using the Redis command-line interface tool.

  1. Open the Redis CLI:
redis-cli
  1. Authenticate if you set a password in Step 3:
auth your_strong_password_here
  1. Run the ping test:
ping

Redis will return PONG if it is functioning properly.

  1. Test data persistence with basic key-value operations:
set testkey "Redis installation successful"
get testkey

The console will return "Redis installation successful". Type exit to close the command prompt.
