How to Report Bugs in Ubuntu Using Launchpad

Reporting bugs in Ubuntu helps developers fix issues and improve system stability for millions of users. This guide explains how to create a Launchpad account, use the built-in ubuntu-bug diagnostic tool to collect necessary system logs, submit clear bug reports, and track your reported issues through resolution.

Step 1: Create a Launchpad Account

Launchpad is the central platform used by Ubuntu for tracking bugs, translation, and code hosting. To report an issue, you must first create an account on the Launchpad website using an Ubuntu One single sign-on profile.

Step 2: Use the ubuntu-bug Command

Ubuntu provides an automated tool called Apport that automatically attaches relevant system information, log files, and software version details to your bug report. This is the mandatory and most effective way to report bugs.

  1. Open your terminal (Ctrl+Alt+T).
  2. Run the command tailored to your situation:
    • For a specific package: Type ubuntu-bug <package-name> (e.g., ubuntu-bug firefox).
    • For a system crash: If a program recently crashed, run ubuntu-bug /var/crash/_filename_.crash.
    • For a running application: Type ubuntu-bug and click on the problem window.

Step 3: Complete the Submission on Launchpad

Once ubuntu-bug finishes gathering technical details, it automatically opens a web browser window pointing to Launchpad.

  1. Check for Duplicates: Launchpad will display a list of similar reports. Read through them to ensure your bug hasn't already been reported. If a duplicate exists, click "This bug affects me too" on that report rather than filing a new one.
  2. Write a Clear Summary: Create a short, specific title that describes the problem (e.g., "NetworkManager loses Wi-Fi connection after system sleep on ThinkPad X1").
  3. Describe the Issue: Include the exact steps to reproduce the bug, what you expected to happen, and what actually occurred.

Step 4: Track and Respond to Requests

After submitting, Ubuntu triagers and developers may ask for additional details or tests.

  • Add updated logs: If requested, update an existing bug report from your terminal by running apport-collect <bug-number>.
  • Monitor status: Watch for status updates via email notifications or directly on your Launchpad dashboard until the bug is marked as Fix Released.
