Autostart KVM Virtual Machines on Ubuntu Boot

Configuring an Ubuntu KVM host to launch specific virtual machines automatically upon system boot ensures that essential services recover without manual intervention after a reboot or power outage. This guide covers how to enable the virtualization management daemon, use the virsh command-line utility to mark specific domains for autostart, verify their operational status, and manage safe shutdowns using the built-in libvirt-guests service.

1. Enable the Libvirt Service

Before configuring individual virtual machines (VMs), ensure the virtualization service is enabled to launch at system startup.

Open a terminal on your Ubuntu host and run:

sudo systemctl enable libvirtd
sudo systemctl start libvirtd

2. Identify the Target Virtual Machines

To manage autostart, locate the exact names of the virtual machines defined on your host:

virsh list --all

Note the names of the VMs you want to start automatically from the output list.

3. Configure the VM to Autostart

Run the virsh autostart command followed by the name of the target virtual machine:

virsh autostart <vm-name>

Replace <vm-name> with the actual name of your virtual machine.

This command creates a symbolic link to the VM's XML configuration file inside /etc/libvirt/qemu/autostart/.

4. Verify Autostart Configuration

To confirm that the virtual machine has been successfully configured to boot with the host, run:

virsh list --autostart

Alternatively, check the domain details for a specific VM:

virsh dominfo <vm-name> | grep Autostart

The output should display:

Autostart:      enable

5. Disable Autostart (Optional)

If you need to stop a virtual machine from starting automatically in the future, disable the setting with the --disable flag:

virsh autostart --disable <vm-name>

This removes the symbolic link from /etc/libvirt/qemu/autostart/ without modifying the virtual machine's underlying disk image or base configuration.

6. Configure Graceful Shutdown on Host Reboot

To prevent data corruption, configure the host to gracefully shut down or suspend running guests when the Ubuntu system restarts.

  1. Open the libvirt-guests configuration file:

    sudo nano /etc/default/libvirt-guests

  2. Locate and adjust the following parameters:

    • ON_BOOT=start (starts all autostart-enabled guests)
    • ON_SHUTDOWN=shutdown (sends a graceful ACPI shutdown signal instead of suspending)
    • SHUTDOWN_TIMEOUT=300 (time in seconds to wait for guests to shut down)

  3. Save the file and enable the service:

    sudo systemctl enable libvirt-guests
sudo systemctl start libvirt-guests
