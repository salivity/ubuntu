Run Node.js Apps in the Background with PM2 on Ubuntu

Running a Node.js application permanently in production requires a process manager to keep it alive during crashes and system reboots. This guide demonstrates how to install PM2, start your Node.js application in the background, configure it to automatically launch on server restarts, and manage your processes efficiently on an Ubuntu server.

Prerequisites

Ensure you have Node.js and NPM installed on your Ubuntu system. You can verify your installation by running:

node -v
npm -v

If Node.js is not yet installed, update your package index and install it via the NodeSource repository or Ubuntu's package manager before proceeding.

Step 1: Install PM2 Globally

PM2 is a production process manager for Node.js applications with a built-in load balancer. Install it globally using npm:

sudo npm install pm2 -g

Verify that the installation was successful:

pm2 -v

Step 2: Start Your Application with PM2

Navigate to your application's directory:

cd /path/to/your/app

Start your application using the pm2 start command. Replace app.js with your entry file and set an identifiable name with the --name flag:

pm2 start app.js --name "my-app"

Once executed, PM2 automatically detaches the process and runs it in the background, displaying a status table indicating the app's ID, status, CPU, and memory usage.

Step 3: Configure PM2 to Start on System Boot

To ensure your application runs permanently, even after an unexpected crash or server reboot, configure PM2's startup script.

Generate the startup configuration script:

pm2 startup systemd

PM2 will output a specific command that looks similar to this:

sudo env PATH=$PATH:/usr/bin /usr/lib/node_modules/pm2/bin/pm2 startup systemd -u your_username --hp /home/your_username

Copy and run the exact command generated in your terminal to enable the systemd service.

Step 4: Save the Running Process List

After enabling the startup hook, save the current PM2 process list so that PM2 remembers which applications to launch upon boot:

pm2 save

Your application is now configured to run permanently in the background.

Essential PM2 Commands for Process Management

Use the following commands to monitor and manage your application:

  • View running processes: 
    pm2 list
  • View real-time logs: 
    pm2 logs my-app
  • Restart an application: 
    pm2 restart my-app
  • Reload an application with zero downtime: 
    pm2 reload my-app
  • Stop a running application: 
    pm2 stop my-app
  • Access the terminal dashboard: 
    pm2 monit
