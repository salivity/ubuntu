Replace Disk to Expand ZFS Mirror Pool on Ubuntu

Expanding the storage capacity of a ZFS mirror pool on Ubuntu involves replacing each smaller drive with a larger one, one drive at a time. Because a mirror's capacity is constrained by its smallest drive, the pool will only reflect the new, expanded capacity once every drive in the vdev has been replaced and resilvered. This guide outlines the exact commands and steps needed to take a drive offline, swap in the larger drive, resilver the mirror, and expand the pool to use the new space.

Step 1: Identify Your Pool and Disks

Before making physical changes, inspect your pool configuration and identify the persistent drive identifiers. Using predictable IDs avoids accidental data loss.

  1. Check your pool status: 
    sudo zpool status
  2. Note the pool name (e.g., tank) and the drive names. In Ubuntu, it is best practice to use IDs located in /dev/disk/by-id/: 
    ls -l /dev/disk/by-id/

Step 2: Enable Pool Auto-Expansion

To have ZFS automatically resize the pool once all drives are upgraded, enable the autoexpand property:

sudo zpool set autoexpand=on <pool_name>

Step 3: Offline the First Disk

Select the first drive you plan to replace and take it offline within ZFS:

sudo zpool offline <pool_name> <old_disk_id>

Verify that the drive is offline:

sudo zpool status <pool_name>

Step 4: Physically Swap the Drive

  1. If your system supports hot-swapping, remove the offline drive and insert the new, larger drive.
  2. If your hardware does not support hot-swapping, shut down the system cleanly, replace the physical drive, and boot Ubuntu back up.
  3. Locate the device ID of the newly inserted drive: 
    ls -l /dev/disk/by-id/

Step 5: Replace the Drive and Resilver

Instruct ZFS to replace the old drive with the newly inserted drive:

sudo zpool replace <pool_name> <old_disk_id> /dev/disk/by-id/<new_disk_id>

ZFS will start resilvering (copying data to the new drive). Monitor the progress:

sudo zpool status <pool_name>

Wait until the resilvering process finishes completely. The status output will state that the scan is complete and no errors were found.

Step 6: Repeat the Process for the Remaining Mirror Disk(s)

A ZFS mirror will remain at the original size until all disks in the mirror are replaced. Repeat Steps 3 through 5 for the second drive (and any subsequent drives if running a 3-way mirror):

  1. Offline the second smaller disk.
  2. Physically replace it with the new larger disk.
  3. Run sudo zpool replace <pool_name> <second_old_disk_id> /dev/disk/by-id/<second_new_disk_id>.
  4. Wait for the resilvering process to finish completely.

Step 7: Verify and Force Expansion (If Needed)

If autoexpand=on was set, the pool should automatically increase its usable space once the final disk finishes resilvering. Verify the new capacity:

sudo zpool list <pool_name>

If the pool size did not expand automatically, trigger an expansion manually by running:

sudo zpool online -e <pool_name> /dev/disk/by-id/<new_disk_id>

Run this command for each new disk in the mirror if necessary. Verify the new available storage with zpool list and zfs list.
