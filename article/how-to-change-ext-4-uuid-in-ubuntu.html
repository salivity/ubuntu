How to Change ext4 UUID in Ubuntu

This article explains how to change the Universally Unique Identifier (UUID) of an ext4 filesystem block device in Ubuntu. Changing a UUID is essential when cloning drives or resolving filesystem collisions, and it can be accomplished safely using the native tune2fs utility after unmounting the targeted device.

1. Identify the Block Device

First, locate the partition and view its current UUID using the lsblk or blkid command:

lsblk -f

Identify the target partition name (for example, /dev/sdb1).

2. Unmount the Partition

A filesystem cannot have its UUID modified while in use. If the partition is mounted, unmount it:

sudo umount /dev/sdb1

3. Change the UUID

The primary command used to alter an ext4 UUID is tune2fs.

To generate and apply a new random UUID automatically, run:

sudo tune2fs -U random /dev/sdb1

Alternatively, if you want to assign a specific UUID, you can generate one with uuidgen and pass it directly:

sudo tune2fs -U <your-generated-uuid> /dev/sdb1

4. Verify the New UUID

Confirm the update was applied successfully by inspecting the block device again:

sudo blkid /dev/sdb1

5. Update /etc/fstab (If Applicable)

If the partition is configured to mount automatically at boot via its UUID, open /etc/fstab and replace the old UUID with the newly generated one:

sudo nano /etc/fstab

Save the file and remount the filesystem:

sudo mount -a
