How to Test Network Connectivity in Ubuntu Using Ping

Testing network connectivity in Ubuntu is primarily done using the ping command-line utility. This built-in tool sends ICMP (Internet Control Message Protocol) ECHO_REQUEST packets to a specified IP address or domain name to verify if a remote host is reachable and to measure round-trip response times. Understanding how to use the ping command helps system administrators and users quickly diagnose connection issues, monitor latency, and verify local network status.

The Basic Ping Command

To test network connectivity in Ubuntu, open the terminal (Ctrl + Alt + T) and run the ping command followed by an IP address or domain name.

ping google.com

Or using an IP address:

ping 8.8.8.8

In Ubuntu and other Linux distributions, the ping command will run continuously until you manually stop it. Press Ctrl + C to terminate the process and display the summary statistics.

Useful Ping Options and Examples

Limit the Number of Pings

To send a specific number of ECHO_REQUEST packets and automatically stop, use the -c flag followed by the desired count.

ping -c 4 google.com

Change the Interval Between Packets

By default, ping waits one second between sending each packet. You can modify this interval using the -i flag.

ping -i 2 google.com

Set a Timeout Limit

To stop sending pings after a specific duration (in seconds), regardless of how many packets have been sent or received, use the -w flag.

ping -w 10 google.com

Ping IPv6 Addresses

To explicitly test IPv6 connectivity, use the -6 option or the ping6 command.

ping -6 google.com

Understanding the Ping Output

When you run a ping test, each line of output provides details about the network response:

  • bytes from: Indicates the target host responded and shows the packet size.
  • icmp_seq: The sequence number of the packet sent.
  • ttl: Time to Live, which prevents packets from circulating endlessly.
  • time: The round-trip response time measured in milliseconds (ms).

The summary printed at the end shows packet transmission statistics, including total packets sent, received, percentage of packet loss, and average round-trip times.

Troubleshooting Common Issues

  • Destination Host Unreachable: Indicates your computer cannot find a route to the target network. Check your local IP address and network gateway.
  • Request Timed Out / 100% Packet Loss: Means the target host is offline, experiencing heavy network congestion, or a firewall is blocking ICMP packets.
  • Ping: Command Not Found: If the utility is missing on a minimal Ubuntu installation, install it via sudo apt update && sudo apt install iputils-ping.
