How to View APT Package History in Ubuntu

Tracking software changes is an essential part of maintaining an Ubuntu system, whether for troubleshooting issues, auditing system state, or rolling back unintended updates. This article outlines the specific commands used to view the history of package installations, upgrades, and removals managed by the APT package manager.

The Primary Command: Viewing the APT History Log

The APT package manager automatically logs all high-level operations in the /var/log/apt/history.log file. You can view the most recent installations, upgrades, and removals using the less command:

less /var/log/apt/history.log

To view the log directly in your terminal, use cat:

cat /var/log/apt/history.log

Understanding the Log Structure

Each logged transaction contains a structured block of information:

  • Start-Date: The timestamp when the operation began.
  • Commandline: The exact command executed (e.g., apt install nginx).
  • Requested-By: The user who invoked the command.
  • Install: A list of packages that were installed, including automatically installed dependencies.
  • Remove / Purge: A list of packages that were removed.
  • Upgrade: Packages updated to newer versions.
  • End-Date: The timestamp when the operation finished.

Viewing Older or Rotated History Logs

Log rotation automatically archives older entries into compressed files. To search across both current and archived APT logs, use zcat or zgrep:

zcat /var/log/apt/history.log.*.gz | less

Filtering for Specific Operations

If you only want to see specific actions, such as which packages were installed, filter the log using grep:

grep -E "Commandline|Install:|Remove:" /var/log/apt/history.log

Alternative: Low-Level DPKG Logs

For lower-level details handled by the underlying Debian package manager, inspect /var/log/dpkg.log:

grep " install " /var/log/dpkg.log
grep " remove " /var/log/dpkg.log
