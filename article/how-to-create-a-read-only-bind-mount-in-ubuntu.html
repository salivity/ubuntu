How to Create a Read-Only Bind Mount in Ubuntu

This article explains how to create a read-only bind mount of a directory in Ubuntu, allowing you to replicate an existing directory structure in a secondary location while strictly preventing modifications to the underlying files. You will learn the exact terminal commands required to establish a read-only bind mount, how to verify its status, and how to make the mount persistent across system reboots using the file systems table (/etc/fstab).

The Command for a Read-Only Bind Mount

In modern versions of Ubuntu, you can create a read-only bind mount using a single mount command:

sudo mount -o bind,ro /path/to/source /path/to/destination

The Two-Step Method (Legacy/Fallback)

Historically, the Linux kernel did not allow setting the read-only flag simultaneously with the initial bind operation. If you are using an older environment or your mount command does not enforce the read-only attribute in a single execution, use the standard two-step method:

  1. Create the bind mount:

    sudo mount --bind /path/to/source /path/to/destination

  2. Remount the target as read-only:

    sudo mount -o remount,ro,bind /path/to/destination

Verifying the Read-Only Status

To confirm that the destination directory is active and strictly read-only, use the findmnt command:

findmnt /path/to/destination

Look for ro in the OPTIONS column of the output.

You can also test write permissions by attempting to create a file in the mounted directory:

touch /path/to/destination/testfile

If configured correctly, the terminal will return:

touch: cannot touch '/path/to/destination/testfile': Read-only file system

Making the Bind Mount Persistent

Standard mounts do not survive a system reboot. To make a read-only bind mount permanent, append an entry to /etc/fstab.

  1. Open /etc/fstab with root privileges:

    sudo nano /etc/fstab

  2. Add the following line at the end of the file:

    /path/to/source /path/to/destination none bind,ro 0 0

  3. Test the configuration without rebooting:

    sudo mount -a

Unmounting the Directory

When the bind mount is no longer needed, detach it using the umount command:

sudo umount /path/to/destination
