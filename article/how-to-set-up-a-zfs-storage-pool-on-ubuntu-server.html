How to Set Up a ZFS Storage Pool on Ubuntu Server

Setting up a ZFS storage pool on an Ubuntu server provides advanced data protection, high performance, and flexible volume management through built-in software RAID capabilities. This guide covers the essential steps to prepare your system, install the necessary zfsutils-linux package, identify your drive identifiers, create your first storage pool using common configurations like mirroring or RAIDZ, and verify that your new pool is running properly.

Step 1: Install ZFS Utilities

Before creating a storage pool, install the ZFS user-space utilities on your Ubuntu server. Open your terminal and run:

sudo apt update
sudo apt install zfsutils-linux -y

Verify the installation by checking the ZFS version:

zfs --version

Step 2: Identify Disks for the Pool

Locate the drives you plan to include in your ZFS pool. Using persistent device IDs is recommended to avoid drive letter swapping upon reboot.

List all available block devices:

lsblk

View unique disk IDs:

ls -l /dev/disk/by-id/

Identify the disk identifiers you want to use (for example, /dev/disk/by-id/ata-WDC_WD20EFZX...).

Step 3: Create the ZFS Storage Pool

ZFS pools (zpools) can be created in several layouts depending on your balance of storage capacity, performance, and redundancy.

Option A: RAID 0 (Stripe - High performance, no redundancy)

sudo zpool create mypool /dev/sdb /dev/sdc

Option B: RAID 1 (Mirror - Requires at least 2 drives)

sudo zpool create mypool mirror /dev/sdb /dev/sdc

Option C: RAIDZ1 (Single Parity - Requires at least 3 drives)

sudo zpool create mypool raidz1 /dev/sdb /dev/sdc /dev/sdd

Note: Replace mypool with your desired pool name and drive paths with your actual device names or IDs.

Step 4: Verify Pool Status and Mounting

ZFS automatically mounts the new pool at /mypool upon creation. To verify that the pool is active and healthy, check its status:

sudo zpool status

To display total capacity, available space, and current mount points:

zfs list

Step 5: Enable Compression (Recommended)

ZFS supports inline compression, which saves disk space and can improve disk read/write performance. Enable lz4 compression on your pool with:

sudo zfs set compression=lz4 mypool

Verify that compression is active:

zfs get compression mypool
