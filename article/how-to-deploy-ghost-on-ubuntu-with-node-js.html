How to Deploy Ghost on Ubuntu with Node.js

This guide walks through the complete process of deploying a production-ready Ghost blogging platform on an Ubuntu server using Node.js. You will learn how to prepare your Ubuntu environment, install necessary dependencies including Nginx, MySQL, and Node.js, and finalize your installation using the official Ghost-CLI tool with automated SSL encryption.

Step 1: Update the Server

Connect to your Ubuntu server via SSH using a non-root user with sudo privileges. Update the package index and upgrade installed packages:

sudo apt update && sudo apt upgrade -y

Step 2: Install Nginx and MySQL

Ghost requires Nginx as a reverse proxy and MySQL for production data storage. Install both packages:

sudo apt install nginx mysql-server -y

Configure your firewall to allow HTTP and HTTPS traffic:

sudo ufw allow 'Nginx Full'

Secure the MySQL installation:

sudo mysql_secure_installation

Set a root password and choose Y for the remaining security prompts.

Step 3: Install Node.js

Ghost requires an active Long Term Support (LTS) version of Node.js. Install Node.js 18 via the NodeSource repository:

curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

Verify that Node.js and npm are installed correctly:

node -v
npm -v

Step 4: Install Ghost-CLI

The Ghost-CLI tool simplifies the setup, maintenance, and updating of Ghost instances. Install it globally via npm:

sudo npm install ghost-cli@latest -g

Step 5: Prepare the Installation Directory

Create a dedicated directory for your Ghost installation and assign proper permissions to your non-root user:

sudo mkdir -p /var/www/ghost
sudo chown $USER:$USER /var/www/ghost
sudo chmod 775 /var/www/ghost

Step 6: Install Ghost

Navigate to the directory and initiate the automated installation:

cd /var/www/ghost
ghost install

During installation, the CLI will ask for configuration details:

  1. Blog URL: Enter your domain name using HTTPS (e.g., https://example.com).
  2. MySQL hostname: Press Enter to default to localhost.
  3. MySQL username / password: Enter your MySQL root credentials, or a dedicated database user.
  4. Ghost database name: Press Enter to use the default name.
  5. Set up Ghost MySQL user?: Type yes to create a dedicated user for Ghost.
  6. Set up Nginx?: Type yes to automatically generate the reverse proxy configuration.
  7. Set up SSL?: Type yes to automatically generate a free Let's Encrypt SSL certificate (requires an email address).
  8. Set up systemd?: Type yes so Ghost starts automatically on system reboots.
  9. Start Ghost?: Type yes to start the application.

Step 7: Complete Setup

Once the process finishes, navigate to https://yourdomain.com/ghost in your web browser to create your administrator account and access the Ghost dashboard.
