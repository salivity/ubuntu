How to Clear DNS Cache in Ubuntu

This guide explains how to clear the local DNS cache managed by systemd-resolved on a modern Ubuntu desktop. Whether you are troubleshooting website connectivity issues, verifying domain name record migrations, or resetting stale network settings, flushing the resolver cache forces your operating system to fetch fresh DNS records directly from your upstream nameservers instead of serving outdated local data.

Step 1: Check Current Cache Statistics

Before flushing the cache, you can view the current DNS cache size and statistics to verify that the local resolver is active. Open your terminal and run:

resolvectl statistics

Look at the Cache section in the output. It displays the current cache size, along with cache hits and misses.

Step 2: Flush the DNS Cache

On modern Ubuntu releases (Ubuntu 20.04 LTS and newer), the primary tool used to control systemd-resolved is resolvectl. To immediately flush the local DNS cache, execute:

sudo resolvectl flush-caches

This command runs silently if executed successfully.

(Note: On older Ubuntu versions such as 18.04, the equivalent command is sudo systemd-resolve --flush-caches.)

Step 3: Verify the Cache Has Been Cleared

To confirm that the cache has been emptied, run the statistics command once more:

resolvectl statistics

Under the Cache section, Current Cache Size should now display 0.

Alternative: Restart systemd-resolved

If flushing the cache does not resolve your issue, you can completely restart the resolver daemon. This resets all runtime state and empties the cache automatically:

sudo systemctl restart systemd-resolved
