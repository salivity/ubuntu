Deploy AKS Cluster with Ubuntu Underlying OS

Deploying an Azure Kubernetes Service (AKS) cluster with an Ubuntu host operating system provides a reliable, secure, and familiar Linux foundation for containerized workloads. Ubuntu is currently the default Linux distribution for AKS node pools, but explicitly specifying the OS ensures consistency across environments and automation pipelines. This guide provides direct, step-by-step methods to deploy an AKS cluster with Ubuntu nodes using the Azure CLI and Terraform, as well as how to verify the operating system once provisioned.

Prerequisites

Ensure the following tools are installed and configured:

  • Azure CLI (version 2.45.0 or later)
  • kubectl for interacting with the Kubernetes cluster
  • An active Azure subscription with sufficient quota

Deploy an AKS Cluster with Ubuntu via Azure CLI

To create an AKS cluster running Ubuntu, set the --os-sku parameter to Ubuntu. This configures the node pool with the LTS version of Ubuntu validated for AKS (typically Ubuntu 22.04).

  1. Create an Azure Resource Group:

    az group create --name myResourceGroup --location eastus

  2. Create the AKS Cluster:

    az aks create \
  --resource-group myResourceGroup \
  --name myUbuntuCluster \
  --node-count 3 \
  --os-sku Ubuntu \
  --generate-ssh-keys

Add an Ubuntu Node Pool to an Existing Cluster

If you have an existing AKS cluster and want to add a dedicated Ubuntu-based node pool, run:

az aks nodepool add \
  --resource-group myResourceGroup \
  --cluster-name myUbuntuCluster \
  --name ubuntupool \
  --node-count 2 \
  --os-sku Ubuntu

Deploy Using Terraform

If deploying via Infrastructure as Code (IaC), specify "Ubuntu" in the os_sku attribute inside the default_node_pool block of your azurerm_kubernetes_cluster resource:

resource "azurerm_kubernetes_cluster" "aks" {
  name                = "myUbuntuCluster"
  location            = "East US"
  resource_group_name = "myResourceGroup"
  dns_prefix          = "ubuntuaks"

  default_node_pool {
    name       = "default"
    node_count = 3
    vm_size    = "Standard_D2s_v3"
    os_sku     = "Ubuntu"
  }

  identity {
    type = "SystemAssigned"
  }
}

Verify the Node Operating System

  1. Connect to the Cluster:

    az aks get-credentials --resource-group myResourceGroup --name myUbuntuCluster

  2. Check the Node OS Details:

    kubectl get nodes -o wide

The OS-IMAGE column in the terminal output will display the running OS, such as Ubuntu 22.04.x LTS.
