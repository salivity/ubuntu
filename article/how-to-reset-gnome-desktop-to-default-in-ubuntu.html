How to Reset GNOME Desktop to Default in Ubuntu

Resetting the GNOME desktop environment in Ubuntu restores all user customizations—including panel layouts, themes, desktop icons, wall papers, and keyboard shortcuts—back to their original factory default settings. This process is an efficient troubleshooting step for fixing misconfigured settings, broken desktop extensions, or visual glitches without needing to reinstall the entire operating system.

Resetting GNOME Desktop via Terminal

The fastest and most complete method to reset your GNOME settings is using the dconf command line tool.

Step 1: Open the Terminal

Press Ctrl + Alt + T on your keyboard to open a terminal window.

Step 2: Run the Dconf Reset Command

Enter the following command and press Enter:

dconf reset -f /org/gnome/

This command forcibly (-f) resets all configuration keys stored under the /org/gnome/ directory back to their initial default values.

Step 3: Apply the Changes

To ensure all visual elements update properly, save any open work and log out of your system:

  1. Click the system status menu in the top-right corner of your screen.
  2. Select Log Out.
  3. Log back into your account.

Targeted Resets for Specific Desktop Elements

If you only want to reset specific parts of your GNOME desktop rather than everything, use the targeted commands below.

Reset Ubuntu Dock Settings

To restore default dock positioning, app pins, and icon sizes:

dconf reset -f /org/gnome/shell/extensions/dash-to-dock/

Reset Custom Keyboard Shortcuts

To revert all custom keyboard shortcuts back to system defaults:

dconf reset -f /org/gnome/desktop/wm/keybindings/

Reset Interface Themes and Fonts

To reset system fonts, icons, cursor themes, and interface styles:

dconf reset -f /org/gnome/desktop/interface/

Full Reset by Clearing Dconf Database Files

If the standard reset command does not resolve your desktop issues, you can delete the local user configuration database entirely.

  1. Open your terminal (Ctrl + Alt + T).

  2. Delete the user dconf database file:

    rm -rf ~/.config/dconf/user

  3. Reboot your system to allow Ubuntu to generate a completely clean configuration database:

    sudo reboot
