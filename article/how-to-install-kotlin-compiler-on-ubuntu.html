How to Install Kotlin Compiler on Ubuntu

This guide explains how to install the standalone Kotlin compiler on an Ubuntu system using native command-line tools. You will learn the exact command required to install the compiler, the necessary Java prerequisites, how to verify the installation, and how to compile a basic Kotlin application.

Prerequisites

Kotlin runs on the Java Virtual Machine (JVM). Before installing the Kotlin compiler, ensure that you have the Java Development Kit (JDK) installed on your system.

Run the following command to update your package index and install the default OpenJDK:

sudo apt update
sudo apt install default-jdk

Verify that Java is installed correctly:

java -version

Install the Kotlin Compiler

The native and recommended method to install the Kotlin compiler (kotlinc) directly on modern Ubuntu systems without third-party script managers is through Canonical's Snap package manager, which comes pre-installed on Ubuntu.

Run the following command to install the Kotlin compiler:

sudo snap install --classic kotlin

The --classic flag is required because the compiler needs access to system files outside the standard snap confinement to compile code properly.

Verify the Installation

After the installation completes, verify that the Kotlin compiler is accessible in your environment:

kotlinc -version

The output will display the installed Kotlin compiler version.

Compiling and Running a Kotlin Program

To test the installation, create a simple Kotlin file named hello.kt:

fun main() {
    println("Hello, Ubuntu!")
}

Compile the program into an executable JAR file using kotlinc:

kotlinc hello.kt -include-runtime -d hello.jar

The -include-runtime flag makes the resulting JAR file standalone by packaging the Kotlin runtime library with it.

Run the compiled application using Java:

java -jar hello.jar

The terminal will print:

Hello, Ubuntu!
