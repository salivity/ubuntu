How to Manage Logical Volumes Using LVM in Ubuntu

Logical Volume Manager (LVM) is a powerful storage management tool in Ubuntu that provides greater flexibility than traditional disk partitioning. It allows you to combine multiple physical hard drives into a unified storage space, create dynamic partitions, and resize volumes on the fly without interrupting system operations. This article covers the core components of LVM—Physical Volumes (PV), Volume Groups (VG), and Logical Volumes (LV)—and provides direct, step-by-step instructions for creating, expanding, shrinking, and deleting logical volumes on your Ubuntu system.

Key Concepts of LVM

  • Physical Volume (PV): The underlying raw disk or partition (e.g., /dev/sdb or /dev/sdb1) initialized for LVM use.
  • Volume Group (VG): A storage pool created by combining one or more Physical Volumes.
  • Logical Volume (LV): A flexible partition created within a Volume Group, which is formatted with a filesystem and mounted for user storage.

Step 1: Install LVM2 Package

LVM tools are usually installed by default on Ubuntu. If they are missing, install them using:

sudo apt update
sudo apt install lvm2

Step 2: Create Physical Volumes (PV)

Initialize a raw drive or partition as an LVM Physical Volume.

sudo pvcreate /dev/sdb

To display existing Physical Volumes:

sudo pvs

Step 3: Create a Volume Group (VG)

Combine one or more Physical Volumes into a single Volume Group named vg_storage.

sudo vgcreate vg_storage /dev/sdb

To view Volume Group details:

sudo vgs

Step 4: Create and Format a Logical Volume (LV)

Create a 10GB Logical Volume named lv_data inside the vg_storage Volume Group:

sudo lvcreate -L 10G -n lv_data vg_storage

To use all remaining free space in the Volume Group instead of a fixed size:

sudo lvcreate -l 100%FREE -n lv_data vg_storage

Format the new Logical Volume with the Ext4 filesystem:

sudo mkfs.ext4 /dev/vg_storage/lv_data

Mount the volume to a directory:

sudo mkdir -p /mnt/data
sudo mount /dev/vg_storage/lv_data /mnt/data

Step 5: Extend a Logical Volume

To increase the size of an existing Logical Volume by 5GB, run:

sudo lvextend -L +5G /dev/vg_storage/lv_data

Resize the filesystem so the operating system recognizes the additional space:

sudo resize2fs /dev/vg_storage/lv_data

To extend the volume and filesystem simultaneously in a single command:

sudo lvextend -r -L +5G /dev/vg_storage/lv_data

Step 6: Reduce a Logical Volume

Note: Always back up data and unmount the filesystem before shrinking a volume to prevent data loss.

Unmount the volume:

sudo umount /mnt/data

Check the filesystem for errors:

sudo e2fsck -f /dev/vg_storage/lv_data

Reduce the filesystem and Logical Volume size (e.g., reducing to 8GB total):

sudo lvreduce -r -L 8G /dev/vg_storage/lv_data

Remount the volume:

sudo mount /dev/vg_storage/lv_data /mnt/data

Step 7: Remove LVM Components

To cleanly remove LVM structures, perform the actions in reverse order:

  1. Unmount the filesystem: 
    sudo umount /mnt/data
  2. Remove the Logical Volume: 
    sudo lvremove /dev/vg_storage/lv_data
  3. Remove the Volume Group: 
    sudo vgremove vg_storage
  4. Remove the Physical Volume label: 
    sudo pvremove /dev/sdb
