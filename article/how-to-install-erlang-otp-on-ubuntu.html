How to Install Erlang/OTP on Ubuntu

This article provides a direct guide to installing and configuring the Erlang/OTP environment on an Ubuntu system using the command line. You will learn the primary commands needed to update your package repositories, install the complete Erlang suite, and verify your installation through the interactive shell.

Update the System Repositories

Before installing any new packages, refresh your local package index to ensure you retrieve the latest available versions from the Ubuntu repositories. Run the following command:

sudo apt update && sudo apt upgrade -y

Install the Erlang/OTP Environment

The primary command used to install the complete Erlang/OTP runtime environment on Ubuntu is:

sudo apt install erlang

This meta-package installs the Erlang emulator, standard libraries, compiler, and supporting development tools.

If you require the complete toolchain, including development headers and manual pages, run:

sudo apt install erlang-dev erlang-manpages erlang-base-hipe

Verify the Installation

To confirm that Erlang/OTP is installed and working correctly, check the installed version:

erl -eval 'erlang:display(erlang:system_info(otp_release)), halt().'  -noshell

You can also start the interactive Erlang shell (Eshell) by typing:

erl

When successful, this command displays the OTP version and drops you into the Erlang prompt (1>). To exit the shell, enter q(). or press Ctrl + C twice.
