Manual LUKS Encryption Setup on Ubuntu Server

This article provides a step-by-step walkthrough for manually configuring Linux Unified Key Setup (LUKS) full disk encryption during an Ubuntu Server installation. By bypassing automatic guided partitioning and using the native Subiquity installer's custom storage layout, you will learn how to partition the physical drive, initialize an encrypted LUKS container, and assign the proper system mount points to ensure your data remains secure at rest.

Step 1: Boot and Access Custom Storage

  1. Boot the target machine using official Ubuntu Server installation media.
  2. Complete the initial setup screens (Language, Keyboard Layout, and Network Connections).
  3. Continue past the proxy and mirror configurations until you reach the Guided Storage Configuration screen.
  4. Select Custom storage layout instead of the guided options, then select Done.

Step 2: Create the Unencrypted Boot Partitions

A system using full disk encryption still requires unencrypted partitions so the motherboard firmware and bootloader can initialize the kernel.

  1. Locate your target storage drive under the Available Devices list.
  2. Select the free space on the drive and choose Add GPT Partition.
  3. Create the EFI System Partition:
    • Size: 1G (or 1024M)
    • Format: fat32
    • Mount: /boot/efi
  4. Select the remaining free space and create the Boot partition:
    • Size: 2G (or 2048M)
    • Format: ext4
    • Mount: /boot

Step 3: Create the Encrypted LUKS Container

  1. Select the remaining unallocated free space on the target drive and choose Add GPT Partition.
  2. Leave the Size blank to use all remaining space.
  3. In the Format dropdown, select Create Encrypted Volume (LUKS).
  4. Fill in the encryption parameters:
    • Name: Enter an identifier for the decrypted device mapper (e.g., dm_crypt-0).
    • Passphrase: Enter a strong passphrase.
    • Confirm Passphrase: Re-enter the passphrase.
  5. Save the configuration. The installer will create the raw partition and immediately present the mapped, decrypted container in the storage list.

Step 4: Configure the Root Filesystem

Once the LUKS volume is created, define where the operating system files will reside inside the encrypted boundary.

  1. Navigate to the newly mapped encrypted device listed under storage (typically displayed with the label you provided, such as dm_crypt-0).
  2. Select the encrypted device and choose Create Partition (or format it directly, depending on whether you are using raw partitions or Logical Volume Management [LVM]).
  3. Configure the root partition:
    • Size: Leave blank to fill the entire encrypted volume, or designate a specific size if you plan to create separate volumes for swap or home directories.
    • Format: ext4
    • Mount: /
  4. Confirm the partition settings.

Step 5: Review and Complete Installation

  1. Review the configured file tree in the storage summary. Ensure the following hierarchy is correct:
    • /boot/efi is assigned to the unencrypted FAT32 partition.
    • /boot is assigned to the unencrypted ext4 partition.
    • / is assigned to the filesystem located inside the encrypted container.
  2. Select Done and confirm the prompt warning that existing data will be overwritten.
  3. Complete the remaining profile setup (username, server name, SSH keys).
  4. Allow the installation process to finish, then reboot the machine.

Upon reboot, GRUB will load from the unencrypted boot partition and prompt you for your LUKS passphrase before unlocking the root filesystem and loading the operating system.
