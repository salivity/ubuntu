Remove Empty Directories Recursively in Ubuntu

To permanently remove empty directories recursively in Ubuntu, the standard and most efficient tool is the find command combined with the -type d, -empty, and -delete flags. This method safely scans your target folder structure, identifies any directories containing no files or subdirectories, and deletes them permanently without affecting any directories that contain data.

The Standard Command

To delete all empty directories in your current working directory and all of its subdirectories, open your terminal and run:

find . -type d -empty -delete

If you want to run this command on a specific folder path rather than your current directory, replace the dot (.) with the absolute or relative path to that directory:

find /path/to/target_directory -type d -empty -delete

Command Breakdown

  • find: The built-in Linux utility used to search for files and directories.
  • /path/to/target_directory: Specifies the starting directory for the recursive search.
  • -type d: Restricts the search results exclusively to directories (folders).
  • -empty: Filters the search to only match directories that are completely empty.
  • -delete: Permanently removes all matched empty directories. When -delete is used, GNU find automatically processes the directory tree in depth-first order (-depth), ensuring that nested chains of empty directories are completely removed in a single execution.

Previewing Directories Before Deletion

Because the -delete action removes folders permanently without moving them to the Trash, it is recommended to preview which directories will be removed before running the deletion command.

To view a list of empty directories without deleting them, run the command without the -delete flag:

find /path/to/target_directory -type d -empty

Review the output list. If you are satisfied with the results, run the full command containing -delete to perform the removal.

Alternative Method: Using rmdir with find

If you prefer using the dedicated directory-removal tool rmdir, you can pipe the output of find to xargs:

find /path/to/target_directory -type d -empty -print0 | xargs -0 rmdir -p

The -p flag tells rmdir to remove parent directories if they also become empty after their child subdirectories are deleted. However, using find ... -delete remains the simplest and safest option on Ubuntu.
