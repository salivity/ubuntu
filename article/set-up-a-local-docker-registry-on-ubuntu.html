Set Up a Local Docker Registry on Ubuntu

Setting up a local registry allows you to host, manage, and distribute private container images within your local network without relying on external cloud providers. This guide walks through installing Docker on Ubuntu, deploying the official Registry 2.0 container, configuring persistent storage, and verifying the setup by tagging, pushing, and pulling images locally.

Step 1: Install Docker on Ubuntu

Ensure your package index is updated and Docker is installed on your Ubuntu server:

sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker

To run Docker commands without root privileges, add your user to the docker group:

sudo usermod -aG docker $USER
newgrp docker

Step 2: Run the Local Registry Container

Docker provides an official image named registry to handle image distribution. Run the registry container on port 5000 and attach a host volume to persist image data:

docker run -d \
  -p 5000:5000 \
  --restart=always \
  --name local-registry \
  -v /var/lib/registry:/var/lib/registry \
  registry:2

This command runs the container in detached mode, restarts it automatically across system reboots, and maps container storage to /var/lib/registry on the Ubuntu host.

Step 3: Tag and Push an Image to the Registry

To test the registry, download a public image from Docker Hub, tag it with your local registry address, and push it.

  1. Pull an image:

    docker pull alpine:latest

  2. Tag the image pointing to your local registry:

    docker tag alpine:latest localhost:5000/my-alpine:latest

  3. Push the image to the local registry:

    docker push localhost:5000/my-alpine:latest

Step 4: Verify the Image in Your Registry

Remove the local images from your host to ensure subsequent pulls fetch directly from your private registry:

docker rmi alpine:latest localhost:5000/my-alpine:latest

Now, pull the image back from your local registry:

docker pull localhost:5000/my-alpine:latest

Verify the image is present on your system:

docker images

Step 5: Enable Network Access (Insecure Registry Configuration)

By default, Docker enforces HTTPS connections for remote registries. If other machines on your local network need to access this registry via HTTP (e.g., using the host's IP address 192.168.1.100), configure the Docker daemon on each client machine.

  1. Open or create /etc/docker/daemon.json:

    sudo nano /etc/docker/daemon.json

  2. Add the insecure registry entry:

    {
  "insecure-registries": ["192.168.1.100:5000"]
}

  3. Restart the Docker service:

    sudo systemctl restart docker

Client machines can now push and pull images using 192.168.1.100:5000/image-name:tag. For production environments, configure TLS certificates using Let's Encrypt or an internal Certificate Authority instead of using an insecure registry.
