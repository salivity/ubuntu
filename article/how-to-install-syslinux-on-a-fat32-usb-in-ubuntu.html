How to Install Syslinux on a FAT32 USB in Ubuntu

This guide provides a straightforward process for installing and configuring the Syslinux bootloader on a FAT32-formatted USB drive using an Ubuntu system. You will learn how to prepare the USB drive, install the necessary software packages, write the Master Boot Record (MBR), install Syslinux to the target partition, and construct a functional configuration file.

Step 1: Install Required Packages

Open your terminal in Ubuntu and update your package lists, then install syslinux and mtools:

sudo apt update
sudo apt install syslinux syslinux-common mtools

Step 2: Identify and Prepare the USB Drive

  1. Plug in your USB drive and list the connected block devices to identify its disk identifier (e.g., /dev/sdX) and partition (e.g., /dev/sdX1):
lsblk

Replace sdX and sdX1 with your actual device identifier in all subsequent commands.

  1. Unmount any automatically mounted partitions on the USB drive:
sudo umount /dev/sdX1
  1. Format the partition to FAT32 if it is not already formatted:
sudo mkfs.vfat -F 32 -n "SYSLINUX_USB" /dev/sdX1
  1. Set the boot flag on the USB drive partition using parted:
sudo parted /dev/sdX set 1 boot on

Step 3: Write MBR Code to the USB Drive

To make the USB drive bootable by BIOS systems, write the Syslinux MBR file to the main drive (not the partition):

sudo dd bs=440 count=1 conv=notrunc if=/usr/lib/syslinux/mbr/mbr.bin of=/dev/sdX

Note: If mbr.bin is located elsewhere on your Ubuntu version, you can locate it using find /usr/lib/syslinux -name mbr.bin.

Step 4: Install Syslinux to the Partition

Install the Syslinux bootloader files directly onto the FAT32 partition:

sudo syslinux --install /dev/sdX1

This writes the ldlinux.sys (or ldlinux.c32) file to the root of the partition.

Step 5: Configure Syslinux

  1. Mount the USB partition to a temporary directory:
sudo mkdir -p /mnt/usb
sudo mount /dev/sdX1 /mnt/usb
  1. Create and open a new configuration file named syslinux.cfg in the root of the USB drive:
sudo nano /mnt/usb/syslinux.cfg
  1. Add a basic boot menu configuration. Below is a minimal working template:
DEFAULT linux
PROMPT 1
TIMEOUT 50

LABEL linux
    MENU LABEL Boot Linux
    KERNEL /vmlinuz
    INITRD /initrd.img
    APPEND root=/dev/sda1 rw quiet
  1. Place your desired Linux kernel (vmlinuz) and initial RAM disk (initrd.img) files into the root directory of /mnt/usb/ (or adjust the paths in syslinux.cfg to match your directory structure).

Step 6: Unmount the USB Drive

Save and exit the text editor, then safely unmount the partition:

sudo umount /mnt/usb

Your FAT32 USB drive is now configured with the Syslinux bootloader and ready to boot.
