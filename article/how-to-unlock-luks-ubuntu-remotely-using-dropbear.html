How to Unlock LUKS Ubuntu Remotely Using Dropbear

This guide explains how to configure Dropbear SSH within the Ubuntu initial ramdisk (initramfs) to remotely unlock a Full Disk Encryption (LUKS) setup. By embedding a lightweight SSH daemon and basic networking into the boot environment, administrators can securely access headless servers over the network during early boot, supply the encryption passphrase, and allow the operating system to finish starting up without requiring physical access or KVM-over-IP hardware.

1. Install Dropbear in initramfs

Log in to your Ubuntu server as root (or use sudo) and install the Dropbear package designed for the initramfs environment:

sudo apt update
sudo apt install dropbear-initramfs

2. Add an Authorized SSH Key

Dropbear inside initramfs does not read keys from user home directories; it requires dedicated public keys configured explicitly for the boot phase.

Open or create the authorized keys file for Dropbear:

sudo nano /etc/dropbear/initramfs/authorized_keys

Paste your local machine's public SSH key (e.g., the contents of ~/.ssh/id_rsa.pub or ~/.ssh/id_ed25519.pub) into this file. Save and exit.

Set appropriate permissions:

sudo chmod 600 /etc/dropbear/initramfs/authorized_keys

3. Configure Dropbear Port and Options

It is recommended to run Dropbear on a custom port to avoid host key mismatch warnings with your primary OpenSSH daemon once the OS loads.

Open the Dropbear configuration file:

sudo nano /etc/dropbear/initramfs/dropbear.conf

Add or adjust the DROPBEAR_OPTIONS variable:

DROPBEAR_OPTIONS="-p 2222 -s -j -k -I 60"
  • -p 2222: Listens on port 2222 instead of the default port 22.
  • -s: Disables password authentication (keys only).
  • -j -k: Disables port forwarding.
  • -I 60: Sets an idle timeout of 60 seconds.

4. Configure Early Boot Networking

If your network relies on DHCP, the system generally configures the network automatically. If you require a static IP address during boot, edit /etc/initramfs-tools/initramfs.conf:

sudo nano /etc/initramfs-tools/initramfs.conf

Append the static IP configuration string using the following syntax:

IP=<client-ip>::<gateway-ip>:<netmask>:<hostname>:<device>:off

Example:

IP=192.168.1.50::192.168.1.1:255.255.255.0:ubuntu-server:eth0:off

5. Update the initramfs Image

Apply the new Dropbear configuration and network settings to the active boot image:

sudo update-initramfs -u -k all

Verify that the process completes without errors.

6. Test Remote Decryption

Reboot the server to test the configuration:

sudo reboot

From your client machine, connect via SSH on the configured port once the machine reaches the initramfs stage:

ssh -p 2222 root@<server-ip>

Upon logging in, run the built-in unlock command:

cryptroot-unlock

Enter your LUKS passphrase when prompted. Once decrypted, the Dropbear connection will close automatically, and Ubuntu will continue its normal boot process, handing network and service control over to systemd and OpenSSH.
