Read Raw SMBIOS DMI Table Data in Ubuntu

This article explains how to access and export raw SMBIOS (System Management BIOS) and DMI (Desktop Management Interface) table data directly from your motherboard in Ubuntu. You will learn the specific commands required to dump this binary data to a file using native utilities as well as how to read it directly from the Linux kernel sysfs interface.

To extract the raw, undecoded SMBIOS/DMI table data in Ubuntu, the standard command used is dmidecode with the --dump-bin option. Because accessing hardware tables requires elevated privileges, you must execute the command with sudo.

Run the following command in your terminal to save the raw binary SMBIOS table to a file:

sudo dmidecode --dump-bin smbios_raw.bin

This command queries the system firmware, captures the raw DMI table structure before decoding, and outputs it directly into the file named smbios_raw.bin in your current working directory.

Alternative Method: Reading Directly via sysfs

Modern Ubuntu installations expose the raw SMBIOS tables directly through the kernel's sysfs filesystem. You can view or copy the raw binary data without executing dmidecode by accessing the /sys/firmware/dmi/tables/ path.

To copy the raw DMI table to a binary file:

sudo cp /sys/firmware/dmi/tables/DMI raw_dmi.bin

To view the raw binary stream directly in your terminal using a hex editor, run:

sudo hexdump -C /sys/firmware/dmi/tables/DMI

or

sudo xxd /sys/firmware/dmi/tables/DMI

The /sys/firmware/dmi/tables/ directory contains two primary files:

  • DMI: The raw table containing the hardware component records.
  • smbios_entry_point: The entry point structure containing the table addresses, length, and SMBIOS version information.
