Configure ZFS ARC Maximum Size in Ubuntu

This guide explains how to limit the maximum size of the ZFS Adaptive Replacement Cache (ARC) on Ubuntu. By default, OpenZFS on Linux can consume up to 50% of your system's physical memory for caching, which can lead to memory pressure for other services. Below, you will find straightforward instructions to calculate the appropriate cache size, apply the limit temporarily for immediate effect, and make the configuration persistent across reboots.

Step 1: Calculate the Desired ARC Size

The ZFS ARC size parameter (zfs_arc_max) is defined in bytes. To determine your desired memory limit, multiply the number of gigabytes by \(1024^3\) (1,073,741,824).

Common sizes in bytes:

  • 2 GB: 2147483648
  • 4 GB: 4294967296
  • 8 GB: 8589934592
  • 16 GB: 17179869184

Step 2: Check Current ARC Usage and Limits

You can view the current maximum ARC setting (c_max) and current cache size (c) using the /proc filesystem:

grep -E "c_min|c_max|size" /proc/spl/kstat/zfs/arcstats

Alternatively, run arcstat to see real-time cache statistics:

arcstat

Step 3: Apply the Limit Temporarily (Runtime)

To change the ARC maximum limit immediately without rebooting, write the new byte value directly into the ZFS kernel module parameter:

echo 4294967296 | sudo tee /sys/module/zfs/parameters/zfs_arc_max

(Replace 4294967296 with your chosen value in bytes.)

This command takes effect instantly, and ZFS will begin releasing excess memory if the current cache exceeds this threshold. However, this change will be lost upon reboot.

Step 4: Make the Configuration Permanent

To ensure the new limit persists across system reboots, configure the ZFS module options via modprobe.d.

  1. Create or edit the ZFS configuration file:
sudo nano /etc/modprobe.d/zfs.conf
  1. Add the following line to define the maximum limit:
options zfs zfs_arc_max=4294967296

(Replace 4294967296 with your preferred value.)

  1. Save the file and exit the editor (in nano, press CTRL+O, Enter, then CTRL+X).

  2. Update your initramfs image to ensure the setting applies early during the boot process:

sudo update-initramfs -u -k all

Step 5: Verify the Persistent Setting

To confirm that the setting is applied correctly, check the value directly from the module parameter:

cat /sys/module/zfs/parameters/zfs_arc_max

The output should match the exact number of bytes specified in your configuration.
