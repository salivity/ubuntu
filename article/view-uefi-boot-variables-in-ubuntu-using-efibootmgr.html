View UEFI Boot Variables in Ubuntu Using efibootmgr

Managing UEFI boot entries in Ubuntu is straightforward using the built-in userspace utility efibootmgr. This guide explains how to view your system's UEFI boot variables, displays the exact commands needed to inspect both standard and verbose boot data, and covers how to interpret the output directly from your Ubuntu terminal.

The Command to View UEFI Boot Variables

To display the current UEFI boot configuration and variables, open your terminal and run:

sudo efibootmgr

Running efibootmgr without additional flags provides a summary of the active boot order, the current boot device, and a list of configured boot entries.

Viewing Detailed (Verbose) Boot Variables

To see the complete UEFI boot variables—including file paths, disk UUIDs, and loader partitions—use the verbose flag (-v or --verbose):

sudo efibootmgr -v

This command outputs the raw and full path information associated with each boot variable stored in NVRAM.

Understanding the Output

When you run sudo efibootmgr -v, the output displays several key variables:

  • BootCurrent: The identifier of the boot entry used to load the currently running operating system (e.g., 0001).
  • Timeout: The number of seconds the UEFI firmware waits for user input before loading the default entry.
  • BootOrder: A comma-separated list defining the priority sequence the firmware follows when attempting to boot an entry (e.g., 0001,0000,0002).
  • BootNext: (Optional) Specifies an entry to be booted exclusively on the next restart.
  • BootXXXX: Each individual boot variable (such as Boot0001* ubuntu), followed by the hardware device path (PCI, HD partition UUID) and the EFI binary path (such as \EFI\ubuntu\shimx64.efi). The asterisk (*) indicates an active/enabled entry.

Requirements

To use this tool successfully:

  1. Your Ubuntu system must be booted in UEFI mode, not Legacy BIOS mode.
  2. If efibootmgr is not installed on your system, install it via APT:
sudo apt update && sudo apt install efibootmgr
