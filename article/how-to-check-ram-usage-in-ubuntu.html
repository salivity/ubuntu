How to Check RAM Usage in Ubuntu

Monitoring system memory is essential for maintaining optimal Linux performance. In Ubuntu, the primary command to display current memory usage and available RAM is free, most commonly used with the -h flag for human-readable formatting. This article explains how to use the free command, breaks down its output, and covers alternative terminal utilities like top, htop, and /proc/meminfo to check your memory status.

The Primary Command: free -h

To view your current memory usage, open your terminal (Ctrl+Alt+T) and run the following command:

free -h

The -h option stands for "human-readable," converting raw bytes into megabytes (M) or gigabytes (G).

Understanding the Output

Running free -h produces a table with columns detailing your system's memory:

  • total: The total amount of installed RAM on your system.
  • used: The amount of RAM currently in use by active processes.
  • free: Memory that is completely unused.
  • shared: Memory used mostly by tmpfs (file system stored in RAM).
  • buff/cache: Memory used by the Linux kernel for buffers and page cache. This memory can be reclaimed instantly if applications require it.
  • available: An estimate of how much memory is available to start new applications without using swap space. This is the key number to look at for available RAM.

The output also displays details for Swap, which is space on your hard drive used when physical RAM is full.

Alternative Commands for Checking RAM in Ubuntu

While free -h is the standard tool, other commands provide real-time or more detailed information.

1. top

The top command provides a real-time dynamic view of a running system, including total, free, and used memory at the top of the interface.

top

Press Q to exit.

2. htop

htop is an interactive process viewer that displays memory usage in visual color bars. If it is not installed, you can install it using:

sudo apt update && sudo apt install htop

To run it:

htop

Press F10 to exit.

3. cat /proc/meminfo

For raw, low-level memory data directly from the Linux kernel, read the /proc/meminfo virtual file:

cat /proc/meminfo

This output displays exhaustive statistics, including detailed breakdowns of cached memory, swap usage, and committed memory.
