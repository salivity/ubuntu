Enable Ubuntu Studio Controls for Low Latency Audio

Ubuntu Studio Controls provides a centralized interface for configuring real-time audio on Linux, allowing users to minimize latency and prevent audio dropouts (xruns). This guide outlines the steps to install the software, grant necessary real-time system permissions, configure the JACK audio engine, and optimize CPU settings to achieve stable, low-latency audio processing.

1. Install Studio Controls

If you are not using a full Ubuntu Studio installation, install the control utility and the low-latency kernel meta-packages via the terminal:

sudo apt update
sudo apt install studio-controls linux-lowlatency

2. Enable Real-Time Audio Permissions

Your user account must belong to the audio group to utilize real-time scheduling privileges:

sudo usermod -a -G audio $USER

Log out and log back in, or restart your system, to apply the group changes.

3. Launch Studio Controls

Open your application launcher and search for Studio Controls (or run studio-controls in a terminal). The utility manages the interaction between the JACK audio server, PulseAudio, and ALSA.

4. Configure Audio Devices and Latency

Inside the Studio Controls interface, configure the primary settings under the main tab:

  • Jack Master Device: Select your primary USB or internal audio interface.
  • Sample Rate: Set this to 48000 Hz (or 44100 Hz, depending on your project requirements).
  • Buffer Size (Frames): Lower numbers reduce latency but require more CPU power:
    • 64 or 128 frames: Ultra-low latency, ideal for live monitoring of MIDI or virtual instruments (around 1.3ms to 2.6ms).
    • 256 frames: Safe, low-latency baseline for tracking and recording without dropouts.
  • Periods: Set to 2 for onboard and PCI/PCIe cards, or 3 for USB interfaces to maintain stability.

5. Adjust CPU and System Settings

To prevent CPU frequency scaling from causing buffer underruns:

  1. Locate the CPU Governor option inside Studio Controls.
  2. Change the setting to Performance. This forces your processor cores to run at their maximum clock speed rather than throttling down during quiet passages.
  3. Ensure Enable JACK is switched to On.

6. Apply Changes and Verify

Click Apply Audio Settings to restart the JACK audio engine with the new configuration.

To confirm that the low-latency settings are operational, launch a digital audio workstation (such as Ardour, Carla, or Reaper) and verify that the audio driver is set to JACK. Check the DAW's status bar to confirm the reported round-trip latency and monitor for any xrun notifications while playing audio.
