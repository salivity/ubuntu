Install GNOME Extensions via Browser on Ubuntu

This guide explains how to install and manage GNOME Shell extensions directly from your web browser on Ubuntu. By setting up the native host connector and your browser's integration add-on, you can browse, toggle, configure, and remove desktop extensions seamlessly using the official GNOME extensions repository.

Step 1: Install the Native Host Connector

Your web browser needs a native connector package to communicate with your desktop environment.

Open your terminal and run the following commands:

sudo apt update
sudo apt install gnome-browser-connector

Note: On older Ubuntu releases (prior to 22.10), run sudo apt install chrome-gnome-shell instead.

Step 2: Install the Browser Extension

Open your preferred web browser (Google Chrome, Firefox, Brave, or Microsoft Edge) and navigate to the official repository:

extensions.gnome.org

  1. A banner will appear at the top of the webpage stating that the browser extension is missing.
  2. Click the link that says: "Click here to install browser extension".
  3. Confirm the installation prompt in your browser to add the GNOME Shell integration extension.

(Note for Ubuntu's default Snap version of Firefox: If the connector fails to communicate due to Snap sandboxing, install the extension using Google Chrome, a Chromium deb package, or the standalone GNOME Extensions desktop application).

Step 3: Install GNOME Extensions

Once the connector and browser add-on are installed, you can add extensions:

  1. Refresh the extensions.gnome.org webpage.
  2. Search for or select an extension you want to install (such as Dash to Dock or User Themes).
  3. On the extension page, switch the toggle switch from OFF to ON.
  4. A desktop prompt will appear asking to confirm. Click Install.

The extension will download, install, and activate immediately without requiring a system reboot.

Step 4: Manage Installed Extensions

You can manage your extensions directly from the browser:

  1. Go to extensions.gnome.org and click the Installed Extensions tab in the top navigation bar.
  2. Toggle On/Off: Use the slider next to any extension to temporarily enable or disable it.
  3. Configure: Click the wrench/gear icon to open the preferences window for extensions that support customization.
  4. Update: Click the green arrow icon if an update is available for an extension.
  5. Uninstall: Click the red "X" icon to remove an extension from your system completely.
