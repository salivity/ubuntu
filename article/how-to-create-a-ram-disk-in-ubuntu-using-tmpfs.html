How to Create a RAM Disk in Ubuntu Using tmpfs

Setting up a RAM disk using tmpfs in Ubuntu allows you to allocate a portion of your system’s memory to store temporary files, delivering significantly faster read and write speeds compared to traditional SSDs or HDDs. This guide covers how tmpfs works, how to create a temporary RAM disk for immediate use, and how to configure your /etc/fstab file to make the RAM disk permanent across system reboots.

What is tmpfs?

tmpfs is a temporary file storage facility in Linux that keeps files in volatile memory (RAM). Because RAM is vastly faster than physical storage drives, using tmpfs for temporary files, cache directories, or compilation tasks improves application responsiveness and reduces read/write wear on your drive. Keep in mind that any data saved in a RAM disk is lost when the system powers off or reboots.

Step 1: Check Available RAM

Before allocating memory to a RAM disk, check how much free memory your system has available. Open your terminal and run:

free -h

Look at the Available column to determine how much RAM you can safely dedicate without causing the system to run out of memory.

Step 2: Create a Mount Directory

Create a directory where your RAM disk will be mounted. For example, to create a folder named ramdisk inside /mnt:

sudo mkdir -p /mnt/ramdisk

Step 3: Mount the RAM Disk (Temporary)

You can mount a tmpfs RAM disk immediately using the mount command. The following command mounts a 2 GB RAM disk to /mnt/ramdisk:

sudo mount -t tmpfs -o size=2G tmpfs /mnt/ramdisk

You can adjust size=2G to your preferred limit (e.g., 512M for megabytes or 4G for gigabytes). If you do not specify a size limit, tmpfs defaults to using up to 50% of your total physical RAM by default, though it only consumes memory as files are added.

To verify that the RAM disk is active, run:

df -h /mnt/ramdisk

Step 4: Configure Permanent RAM Disk (Optional)

RAM disks created with the mount command disappear after a reboot. To make the RAM disk persistent across system restarts, add an entry to your /etc/fstab file.

  1. Open /etc/fstab in a text editor:

    sudo nano /etc/fstab

  2. Add the following line at the bottom of the file:

    tmpfs /mnt/ramdisk tmpfs defaults,size=2G 0 0

  3. Save the file and exit the editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

  4. Test the configuration without restarting by mounting all entries in fstab:

    sudo mount -a

If no errors appear, your RAM disk will now automatically mount every time Ubuntu boots.

Step 5: Unmounting the RAM Disk

If you ever need to remove the RAM disk, ensure no processes are using files inside the directory, then run:

sudo umount /mnt/ramdisk

If you configured the RAM disk in /etc/fstab, remove or comment out the corresponding line to prevent it from mounting on the next boot.
