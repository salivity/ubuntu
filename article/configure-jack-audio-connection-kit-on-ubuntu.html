Configure JACK Audio Connection Kit on Ubuntu

This guide provides a comprehensive walkthrough for configuring the JACK Audio Connection Kit on an Ubuntu multimedia production workstation. You will learn how to install JACK2, grant real-time system privileges to your user account to eliminate buffer underruns, configure optimal latency and hardware parameters using Qjackctl, and ensure compatibility with existing system audio.

Step 1: Install JACK2 and Qjackctl

Open a terminal and install the JACK2 package along with Qjackctl, a graphical user interface for managing the JACK server:

sudo apt update
sudo apt install jackd2 qjackctl

During installation, a configuration prompt will ask: "Enable realtime process priority?" Select Yes. This automatically configures limits for memory locking and scheduling priority required for low-latency audio processing.

Step 2: Grant User Real-Time Audio Permissions

Your user account must belong to the audio group to use real-time scheduling.

  1. Add your current user to the audio group: 
    sudo usermod -aG audio $USER
  2. Verify that /etc/security/limits.d/audio.conf contains the following lines: 
    @audio   -  rtprio     95
@audio   -  memlock    unlimited
  3. Log out and log back in (or reboot) for these group and permission changes to take effect.

Step 3: Handle Audio Server Bridges

Ubuntu systems use PulseAudio or PipeWire for desktop sound, which can conflict with JACK when accessing hardware directly.

  • For PipeWire (Ubuntu 22.10 and newer): PipeWire often handles JACK applications natively. If you wish to use the native PipeWire JACK replacement without running the standalone JACK daemon, install: 
    sudo apt install pipewire-audio-client-libraries
    Run applications via pw-jack <application-name> or configure PipeWire directly.
  • For PulseAudio (Ubuntu 20.04/22.04 LTS): To route standard desktop audio through JACK, install the PulseAudio-JACK bridge: 
    sudo apt install pulseaudio-module-jack

Step 4: Configure Audio Parameters in Qjackctl

Launch Qjackctl from your application menu or by running qjackctl in the terminal.

  1. Click the Setup button on the right side of the control panel.
  2. In the Settings tab:
    • Driver: Set to alsa.
    • Realtime: Ensure this checkbox is enabled.
    • Interface: Click the > symbol and select your dedicated audio interface rather than the default motherboard soundcard.
    • Sample Rate: Set to 48000 (standard for video) or 44100 (standard for music).
    • Frames/Period: This controls latency. Start with 256 or 128. Lower values (such as 64) decrease latency but increase CPU load, potentially causing audio dropouts (Xruns).
    • Periods/Buffer: Set to 2 for USB devices or onboard cards, or 3 if using certain internal/PCI interfaces.
  3. In the Misc tab, check Start JACK audio server on application startup and Enable system tray icon.
  4. Click OK to save settings.

Step 5: Start and Test the Server

  1. Click Start in the main Qjackctl window.
  2. Observe the status display:
    • The status should display Started.
    • The RT indicator should be blinking or lit, confirming real-time operation.
    • Note the calculated latency in milliseconds at the bottom right (aim for under 10 ms for live monitoring).
  3. Click the Graph button to view, connect, and route inputs and outputs between hardware channels, Digital Audio Workstations (DAWs), and software synthesizers.
  4. Monitor the Xrun counter. If the counter increments frequently during playback or recording, open Setup and increase the Frames/Period setting to stabilize the audio stream.
