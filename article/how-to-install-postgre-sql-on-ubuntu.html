How to Install PostgreSQL on Ubuntu

PostgreSQL is a powerful, open-source relational database management system widely used for enterprise applications and software development. This guide provides a straightforward walk-through for installing the PostgreSQL database server on Ubuntu using the default APT package repository, verifying the service, and accessing the database prompt for basic management.

Step 1: Update the Package Index

Before installing any new software, update your local package list to ensure you download the latest available versions:

sudo apt update

Step 2: Install PostgreSQL

Install PostgreSQL along with the postgresql-contrib package, which provides additional tools and enhanced capabilities:

sudo apt install postgresql postgresql-contrib -y

Step 3: Check PostgreSQL Service Status

The PostgreSQL service starts automatically upon installation. Verify that the service is active and running:

sudo systemctl status postgresql

You should see an output indicating the service is active (running).

Step 4: Access the PostgreSQL Shell

PostgreSQL creates a default Linux user named postgres to manage database operations. You can access the PostgreSQL prompt (psql) using this account.

Run the following command to log in as the postgres user directly:

sudo -u postgres psql

Once inside the prompt, you can run SQL queries or administrative tasks. To exit the PostgreSQL prompt, run:

\q

Step 5: Configure Remote Access (Optional)

By default, PostgreSQL only accepts connections from localhost. If you need to access your database from a remote server, update your firewall to allow traffic on default port 5432:

sudo ufw allow 5432/tcp

PostgreSQL is now fully installed and operational on your Ubuntu system.
