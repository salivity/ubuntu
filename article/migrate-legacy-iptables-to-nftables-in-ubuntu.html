Migrate Legacy iptables to nftables in Ubuntu

Transitioning from the legacy iptables utility to nftables enhances firewall performance, simplifies rule syntax, and unifies IPv4 and IPv6 management on Ubuntu. This guide provides a straightforward, step-by-step process for converting your existing iptables rules to nftables using built-in translation tools, applying the new configuration, and enabling the nftables system service.

Prerequisites

Before starting, ensure you have administrative (sudo) access to your Ubuntu system and that your current iptables firewall rules are active and up to date.

Step 1: Install nftables

Ubuntu systems usually include the necessary translation tools by default, but you must ensure nftables is installed.

sudo apt update
sudo apt install nftables

Step 2: Export Existing iptables Rules

Export your current active IPv4 and IPv6 legacy rules to a file so they can be translated.

sudo iptables-save > iptables-legacy.rules
sudo ip6tables-save > ip6tables-legacy.rules

Step 3: Translate Legacy Rules to nftables Syntax

Ubuntu includes automated conversion tools (iptables-restore-translate and ip6tables-restore-translate) that convert saved iptables rules into nftables format.

  1. Translate IPv4 rules:

    iptables-restore-translate -f iptables-legacy.rules > ruleset.nft

  2. Translate and append IPv6 rules (if applicable):

    ip6tables-restore-translate -f ip6tables-legacy.rules >> ruleset.nft

Open ruleset.nft in a text editor to inspect the output and ensure the syntax matches your intended firewall logic.

Step 4: Load and Test the New nftables Ruleset

Clear any default rules in memory and load your newly translated ruleset:

sudo nft flush ruleset
sudo nft -f ruleset.nft

Verify that the rules are active:

sudo nft list ruleset

Step 5: Make the nftables Configuration Permanent

To ensure your firewall rules persist after a reboot, move your translated rules into the main nftables configuration file.

  1. Overwrite the default configuration file:

    sudo cp ruleset.nft /etc/nftables.conf

  2. Enable and start the nftables systemd service:

    sudo systemctl enable nftables
sudo systemctl start nftables

Step 6: Disable Legacy iptables Services

To prevent conflicts, disable any active legacy firewall management tools or persistent software such as iptables-persistent or ufw if you are managing nftables directly.

sudo systemctl stop iptables-persistent 2>/dev/null
sudo systemctl disable iptables-persistent 2>/dev/null
sudo ufw disable 2>/dev/null

Alternatively, Ubuntu allows you to point the iptables command-line interface directly to the nftables backend using system alternatives:

sudo update-alternatives --set iptables /usr/sbin/iptables-nft
sudo update-alternatives --set ip6tables /usr/sbin/ip6tables-nft

Step 7: Verify System Status

Reboot your system or restart the service to confirm that nftables loads automatically on startup:

sudo systemctl status nftables
sudo nft list ruleset
