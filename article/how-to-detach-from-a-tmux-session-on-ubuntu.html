How to Detach from a Tmux Session on Ubuntu

Detaching from a tmux session allows background tasks, long-running scripts, and server processes to keep running on Ubuntu even after you close your terminal or disconnect from an SSH session. This guide provides the exact keyboard shortcuts and commands needed to safely detach from an active tmux session and resume it later.

Detach Using Keyboard Shortcuts

The most common way to detach from a tmux session without stopping your running programs is via the default prefix key combination:

  1. Press Ctrl + b simultaneously, then release both keys.
  2. Immediately press d.

Once pressed, tmux will exit back to your regular terminal prompt, displaying a message such as [detached (from session 0)]. Your processes inside that session will continue executing uninterrupted.

Detach Using the Command Line

If you prefer using terminal commands instead of key combinations, you can detach directly from within the tmux window by running:

tmux detach

Alternatively, tmux detach-client performs the same action.

Detach a Specific Session from the Outside

If you have multiple sessions running or are operating from a different terminal window on the same machine, you can detach a specific session remotely:

  1. View all active sessions: 
    tmux ls
  2. Detach the target session: 
    tmux detach -s session_name

How to Reattach to Your Session

When you are ready to return to your running session, use the following commands from your Ubuntu terminal:

  • To reattach to the most recent session: 
    tmux attach
  • To reattach to a specific named session: 
    tmux attach -t session_name

(Note: tmux a can be used as shorthand for tmux attach.)
