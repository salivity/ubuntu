Schedule Ubuntu to Wake Up Automatically with rtcwake

This article explains how to use the built-in rtcwake utility on Ubuntu to put your computer into a suspended or powered-off state and automatically wake it up at a specified time. By leveraging your computer's Real-Time Clock (RTC), rtcwake allows you to conserve power while ensuring your system is online for scheduled tasks, backups, or daily start times.

Understanding the rtcwake Command

The rtcwake utility requires superuser privileges to access the system's hardware clock. The basic syntax is:

sudo rtcwake [options] -m [mode] -s [seconds] | -t [timestamp]

The key flags include:

  • -m (mode): Defines the power-saving state the machine enters.
  • -s (seconds): Sets the alarm to wake the system after a specific number of seconds relative to the current time.
  • -t (timestamp): Sets the alarm to wake the system at a specific date and time, represented as a Unix epoch timestamp.

Supported Power Modes

You can specify different suspend modes using the -m switch:

  • mem: Suspend to RAM (Sleep mode). This offers the quickest resume time and is the most widely supported.
  • disk: Hibernate to disk. Power is completely cut, and memory state is saved to the swap space.
  • off: Complete ACPI shutdown (Power off). Note that your motherboard's BIOS/UEFI must support RTC wake-from-power-off for this mode to work.
  • no: Does not put the computer to sleep. It only sets the RTC alarm, which is useful if you want to shut down or suspend the system through another method later.

Wake Up After a Relative Duration

To put your system into suspend-to-RAM mode and have it automatically wake up after a set duration, use the -s flag followed by the number of seconds.

For example, to sleep immediately and wake up after 2 hours (7,200 seconds):

sudo rtcwake -m mem -s 7200

Wake Up at a Specific Date and Time

To specify an exact date and time, combine rtcwake with the date command using the -t option. The date command converts your human-readable time format into a Unix epoch timestamp.

To suspend the system and wake up tomorrow at 07:00 AM:

sudo rtcwake -m mem -t $(date -d "tomorrow 07:00" +%s)

To schedule a wake-up for a specific calendar date and time (e.g., December 25 at 08:30 AM):

sudo rtcwake -m mem -t $(date -d "2026-12-25 08:30:00" +%s)

To fully power off the machine and wake it up at 06:00 AM the next day:

sudo rtcwake -m off -t $(date -d "tomorrow 06:00" +%s)

Automating rtcwake with Cron

You can automate recurring wake alarms by combining rtcwake with the root user's cron daemon.

  1. Open the root crontab:
sudo crontab -e
  1. Add a rule to set the RTC alarm daily. For instance, to ensure the system is armed to wake up every weekday at 08:00 AM without putting it to sleep immediately, run rtcwake with the -m no flag:
0 23 * * 0-4 /usr/sbin/rtcwake -m no -t $(date -d "tomorrow 08:00" +\%s)

Note: In crontab entries, the percent sign (%) must be escaped with a backslash (\%).

Checking and Canceling Active Alarms

To verify that an alarm has been registered in the hardware clock, check the RTC system status:

cat /proc/driver/rtc

Look for the alrm_time and alrm_date fields to confirm the scheduled wake time.

If you need to cancel a pending wake-up alarm before it triggers, use the -u or --dry-run modes, or disable it directly using:

sudo rtcwake -m disable
