How to Install BigBlueButton on Ubuntu Server

This article provides a complete walkthrough for installing the BigBlueButton open-source web conferencing system on a dedicated Ubuntu server. It covers essential system requirements, network preparation, running the official automated installation script with SSL encryption, and verifying that all services are operational. Following these steps ensures a secure, high-performance deployment ready for online teaching, meetings, and collaboration.

Prerequisites

Before beginning the installation, ensure your server meets the official minimum specifications:

  • Operating System: Clean installation of Ubuntu 20.04 LTS 64-bit (minimal install, dedicated server recommended).
  • Hardware: Minimum 8 CPU cores, 16 GB of RAM, and at least 50 GB of free disk space (500 GB+ recommended if recording sessions).
  • Networking: A dedicated public IPv4 address.
  • DNS: A Fully Qualified Domain Name (FQDN), such as bbb.yourdomain.com, pointing via an A Record to the server's IP address.
  • Ports: Ensure ports 80/TCP and 443/TCP (HTTP/HTTPS) and UDP ports 16384–32768 (WebRTC audio/video) are not blocked by host-level firewalls.

Step 1: Server Preparation and Locale Check

Connect to your server via SSH as the root user:

ssh root@your_server_ip

Update your package repositories and upgrade existing packages:

apt update && apt upgrade -y

BigBlueButton requires the server locale to be set to en_US.UTF-8. Verify and set this using:

locale-gen en_US.UTF-8
update-locale LANG=en_US.UTF-8

Reboot the server if kernel updates were applied during the upgrade:

reboot

Step 2: Configure the Firewall

If you are using Uncomplicated Firewall (UFW), open the necessary ports for web traffic, SSH, and WebRTC streaming:

ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 16384:32768/udp
ufw enable

Step 3: Run the BigBlueButton Installation Script

The recommended method to install BigBlueButton is via the official bbb-install.sh shell script. This script automatically configures package repositories, downloads dependencies, sets up systemd services, and provisions a Let's Encrypt SSL certificate.

Execute the following command, replacing bbb.yourdomain.com with your configured domain name and admin@yourdomain.com with your administrative email address:

wget -qO- https://raw.githubusercontent.com/bigbluebutton/bbb-install-manifest/master/bbb-install.sh | bash -s -- -v focal-270 -s bbb.yourdomain.com -e admin@yourdomain.com -g

Flag breakdown:

  • -v focal-270: Specifies the latest stable release for Ubuntu 20.04 (Focal).
  • -s: Sets the FQDN for the server.
  • -e: Provides an email address for Let's Encrypt renewal notifications.
  • -g: Automatically installs Greenlight, the web-based front-end user interface.

The installation script may take 15 to 30 minutes depending on your internet connection and CPU performance.

Step 4: Verify the Installation

Once the script completes, check the health of all BigBlueButton services by running:

bbb-conf --check

The output will list configuration settings and warn of any potential network, configuration, or certificate errors. If configured correctly, all core processes will show as active.

You can restart and test all services at any time using:

bbb-conf --restart

Step 5: Create an Administrator Account

If you installed the Greenlight front-end using the -g flag, navigate to the Greenlight directory to generate an administrator account:

cd ~/greenlight-v3
docker compose exec app bundle exec rake admin:create

The terminal will output the generated administrative email and temporary password.

Step 6: Access the Web Interface

Open a web browser and navigate to https://bbb.yourdomain.com. Log in using the administrative credentials generated in Step 5. From the administrative dashboard, you can adjust site settings, create meeting rooms, and invite users to join conferences.
