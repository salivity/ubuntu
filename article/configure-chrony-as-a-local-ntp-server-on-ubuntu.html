Configure Chrony as a Local NTP Server on Ubuntu

This guide explains how to configure Chrony to serve as a local Network Time Protocol (NTP) server for other machines on an Ubuntu network. You will learn how to install the package, edit the configuration file to accept local network queries, configure firewall rules to permit NTP traffic, and verify that connected clients can successfully synchronize their system clocks.

Step 1: Install Chrony

Ensure your package index is updated, then install Chrony using the APT package manager:

sudo apt update
sudo apt install chrony -y

Once installed, Chrony runs automatically as a systemd service named chrony (or chronyd).

Step 2: Configure Chrony to Serve Local Clients

By default, Chrony acts only as an NTP client. To allow it to serve time to other devices on your local network, you must modify /etc/chrony/chrony.conf.

Open the file in a text editor:

sudo nano /etc/chrony/chrony.conf

1. Allow Network Subnets

Locate the allow directive section. Add an allow rule specifying the IP subnet of your local network:

allow 192.168.1.0/24

(Replace 192.168.1.0/24 with your network's actual IP range and subnet mask.)

2. Configure Fallback Serving (Optional)

If your Ubuntu server loses its internet connection, it should ideally continue to serve time to local machines based on its own hardware clock. Uncomment or add the local stratum directive:

local stratum 10

This tells Chrony to advertise itself as a stratum 10 time server if it loses contact with upstream NTP servers.

Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

Step 3: Restart and Enable the Chrony Service

Apply the configuration changes by restarting the Chrony service:

sudo systemctl restart chrony
sudo systemctl enable chrony

Step 4: Open Firewall Port for NTP

NTP operates over UDP port 123. If you have the Uncomplicated Firewall (UFW) active on Ubuntu, allow inbound UDP traffic on port 123:

sudo ufw allow 123/udp
sudo ufw reload

If you prefer to restrict access strictly to your local subnet via UFW, run:

sudo ufw allow from 192.168.1.0/24 to any port 123 proto udp

Step 5: Verify the Server Configuration

Check that Chrony is listening on UDP port 123 across all interfaces:

sudo ss -ulpn | grep :123

Check the status of your upstream time sources to ensure your server is properly synchronized:

chronyc sources
chronyc tracking

To see which client IP addresses have requested time synchronization from your Chrony server, run:

sudo chronyc clients

Step 6: Configure Client Devices

On other devices connected to your local network, configure their NTP settings (such as /etc/chrony/chrony.conf or /etc/systemd/timesyncd.conf on Linux) to point to the IP address of your Ubuntu Chrony server:

server 192.168.1.100 iburst

(Replace 192.168.1.100 with the static IP address of your Ubuntu time server.)
