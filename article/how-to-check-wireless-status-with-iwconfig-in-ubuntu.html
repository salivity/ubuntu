How to Check Wireless Status with iwconfig in Ubuntu

Managing wireless network interfaces in Ubuntu often requires checking their configuration, connection status, and signal strength. This article explains how to use the iwconfig command in the Ubuntu terminal to display all available wireless network interfaces and inspect their current operational status.

The Command to Display Wireless Interfaces

To display all wireless network interfaces and their status, open your terminal (Ctrl+Alt+T) and run the following command:

iwconfig

Alternatively, if your system requires elevated permissions to view certain interface details, run:

sudo iwconfig

When executed without any additional arguments, iwconfig scans all network devices on your system and displays detailed statistics for active wireless interfaces while ignoring non-wireless interfaces (such as eth0 or lo, which will show "no wireless extensions").

Displaying Status for a Specific Interface

If you want to view the status of a specific wireless interface, append the interface name (e.g., wlan0 or wlp2s0) to the command:

iwconfig wlan0

Understanding the Output Details

Running iwconfig provides several key pieces of information about your wireless connection:

  • IEEE 802.11: Indicates the wireless protocol version used by the interface.
  • ESSID: Displays the name of the Wi-Fi network you are currently connected to.
  • Mode: Shows the operating mode of the device (e.g., Managed, Ad-Hoc, Master).
  • Access Point: Lists the MAC address of the connected wireless router or access point.
  • Bit Rate: Shows the current data transfer speed.
  • Tx-Power: Displays the transmission power of the wireless card.
  • Link Quality & Signal Level: Provides real-time metrics on the connection strength and quality.

Installing iwconfig (If Missing)

In newer releases of Ubuntu, iwconfig may be deprecated in favor of iw. If the command is not found on your system, install it by installing the wireless-tools package:

sudo apt update
sudo apt install wireless-tools
