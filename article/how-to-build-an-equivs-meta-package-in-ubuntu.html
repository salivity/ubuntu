How to Build an Equivs Meta-Package in Ubuntu

This article provides a step-by-step guide on creating custom meta-packages using the equivs utility in Ubuntu. You will learn how to generate a control file, define package metadata, build a dummy .deb package, and install it to satisfy package manager dependencies for software installed outside of standard APT repositories.

1. Install the Equivs Utility

The equivs package provides tools to create empty or custom Debian packages that register with APT. Open a terminal and install it using:

sudo apt update
sudo apt install equivs

2. Generate a Control File Template

equivs uses a control file containing package metadata to build the .deb file. Generate a starter template using the equivs-control command followed by your chosen file name:

equivs-control custom-package.control

This creates a plain-text file populated with commented fields and defaults.

3. Configure the Control File

Open the generated file in a text editor:

nano custom-package.control

Uncomment and edit the necessary fields. At minimum, define the package name and what dependencies it satisfies:

  • Package: The name of your custom meta-package (e.g., my-custom-java).
  • Version: A version number (e.g., 1.0).
  • Provides: The real package name(s) that your package replaces or satisfies (e.g., default-jre, openjdk-17-jre).
  • Architecture: Set to all for architecture-independent packages.
  • Description: A short summary explaining the package's purpose.

Example minimal configuration:

Section: misc
Priority: optional
Standards-Version: 3.9.2

Package: local-java-override
Version: 17.0
Provides: default-jre, java-runtime
Architecture: all
Description: Custom meta-package to satisfy Java runtime requirements.
 This package registers a manually installed JRE with APT.

Save and exit the editor.

4. Build the Meta-Package

Compile the control file into a binary .deb package using equivs-build:

equivs-build custom-package.control

This command parses the control file and generates a Debian archive in the current directory (for example, local-java-override_17.0_all.deb).

5. Install the Package

Install the generated .deb package using apt so that local dependency caches update automatically:

sudo apt install ./local-java-override_17.0_all.deb

6. Verify the Dependencies

Verify that the package manager recognizes the meta-package:

apt-cache show local-java-override

You can now install software requiring the satisfied dependencies without APT attempting to pull in redundant system packages. To remove the dummy package in the future, run sudo apt remove local-java-override.
