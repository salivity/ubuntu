What Is the /boot Directory in Ubuntu?

The /boot directory in the Ubuntu filesystem hierarchy holds all the critical files required to start and load the Linux operating system. It stores the Linux kernel, the initial RAM disk image (initrd), and configuration files for the GRUB bootloader. Without the contents of this directory, Ubuntu cannot complete its boot sequence and hand control over to the operating system.

Key Files Inside the /boot Directory

The /boot directory contains several essential components that execute sequentially during system startup:

  • vmlinuz: This is the compressed, executable Linux kernel itself. When you power on your machine, the bootloader loads this file into memory to run the operating system.
  • initrd.img or initramfs: The Initial RAM Disk image is a temporary root filesystem loaded into memory during boot. It contains necessary drivers and scripts required to mount the actual root filesystem (/) where the rest of Ubuntu resides.
  • grub/: This subdirectory contains configuration files, modules, and themes for the GRUB (Grand Unified Bootloader) bootloader. The primary configuration file, grub.cfg, defines the boot menu options and kernel parameters.
  • System.map: A lookup table containing kernel symbol references, which assists in debugging kernel oopses or crashes.
  • config-*: Files that store the specific configuration settings used when the corresponding Linux kernel was compiled.

Storage and Partitioning Considerations

In standard Ubuntu installations, /boot can exist directly on the main root (/) filesystem partition or as a dedicated separate partition.

Using a separate partition for /boot is common in scenarios involving whole-disk encryption (LUKS), LVM (Logical Volume Manager), or complex RAID setups. A dedicated partition ensures that the system bootloader can read the necessary kernel files even if the primary storage partition is encrypted or unreadable by the basic system BIOS/UEFI.

Maintenance and Disk Space Management

Because Ubuntu frequently updates its kernel to provide security patches and hardware support, new kernel versions are regularly saved to the /boot directory.

  • Space Limitations: If /boot resides on a small dedicated partition, it can eventually fill up as old kernel versions accumulate.
  • System Upgrades: A full /boot directory will prevent package managers like apt from installing new updates or upgrading the system.
  • Cleanup: Ubuntu automatically handles the removal of unused kernels in modern releases, but users can manually free space using commands such as sudo apt autoremove.
