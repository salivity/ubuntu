How to View UUIDs of Block Devices in Ubuntu

Universally Unique Identifiers (UUIDs) are crucial for reliably identifying storage drives in Ubuntu, especially when configuring drive mounts in the system's /etc/fstab file. This guide details the exact commands used to quickly list and view the UUIDs of all block devices connected to your Ubuntu system.

Using the blkid Command

The standard command to view the UUIDs of all block devices in Ubuntu is blkid. Because it requires root privileges to read metadata from all storage devices, you must run it with sudo:

sudo blkid

This command prints a complete list of all block devices along with their assigned UUID, filesystem type (TYPE), and volume label (LABEL).

View UUID for a Specific Device

To target a single partition or drive, append the device path to the command:

sudo blkid /dev/sda1

Using the lsblk Command

An alternative, easy-to-read command that does not require sudo privileges is lsblk paired with the -f (filesystem) flag:

lsblk -f

This outputs a clear tree structure displaying each device name, filesystem type, volume label, UUID, and current mount point.

Listing the by-uuid Directory

You can also inspect the Linux device directory directly. Ubuntu creates symbolic links mapping every UUID to its corresponding device node inside /dev/disk/by-uuid/:

ls -l /dev/disk/by-uuid

This displays every active UUID alongside the specific partition it points to.
