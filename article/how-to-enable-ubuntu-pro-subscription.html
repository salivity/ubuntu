How to Enable Ubuntu Pro Subscription

Ubuntu Pro provides extended security maintenance, compliance management, and live kernel patching for Ubuntu systems, remaining free for personal use on up to five machines. Enabling an Ubuntu Pro subscription on your machine is a straightforward process that requires a free Canonical account to retrieve your personal token, followed by running a simple command in the terminal or configuring the system settings via the graphical user interface. This guide outlines the exact steps needed to attach your system and activate Ubuntu Pro services quickly.

Step 1: Retrieve Your Ubuntu Pro Token

To attach a machine, you must first get your unique token from Canonical:

  1. Visit the official Ubuntu Pro website (ubuntu.com/pro) and sign in or create a free Canonical account.
  2. Access your account dashboard to view your free personal token.

Step 2: Enable Ubuntu Pro via Terminal

The command-line interface is the fastest method to enable Ubuntu Pro across server and desktop installations.

  1. Open your terminal (Ctrl+Alt+T).

  2. Update the system package list and ensure the Ubuntu Pro client is up to date:

    sudo apt update && sudo apt install ubuntu-pro-client

  3. Attach your system using your token:

    sudo pro attach YOUR_TOKEN_HERE

    (Replace YOUR_TOKEN_HERE with the token from your dashboard).

  4. Verify that your subscription is active and view enabled services:

    pro status

Step 3: Enable Ubuntu Pro via Desktop GUI

If you are using Ubuntu Desktop, you can complete the process through the graphical interface:

  1. Open the Software & Updates application from your menu.
  2. Click on the Ubuntu Pro tab.
  3. Select Enable Ubuntu Pro.
  4. Enter your token manually, or use the provided magic code to register the device through your browser.
  5. Click Confirm to save the changes.

Managing Ubuntu Pro Services

Once attached, services such as Extended Security Maintenance for Infrastructure (esm-infra) and Applications (esm-apps) are enabled by default. Additional services can be enabled or disabled as needed:

  • Enable Kernel Livepatch: sudo pro enable livepatch
  • Enable FIPS Compliance Modules: sudo pro enable fips
  • Disable a Service: sudo pro disable <service_name>
  • Detach System from Account: sudo pro detach
