How to Change Default SSH Port in Ubuntu

Changing the default SSH port (22) on Ubuntu enhances your server's security by significantly reducing the volume of automated brute-force attacks. This step-by-step guide walks you through editing the SSH configuration file, updating your firewall rules to allow traffic on the new port, and restarting the SSH service to apply the changes without losing access to your server.

Step 1: Open the SSH Configuration File

Access your Ubuntu server via SSH and open the primary SSH daemon configuration file using a text editor with root privileges:

sudo nano /etc/ssh/sshd_config

Step 2: Modify the Port Number

  1. Locate the line that specifies the port. By default, it usually looks like #Port 22 or Port 22.
  2. Remove the comment symbol (#) if present.
  3. Change 22 to your preferred custom port number (for example, 2222 or a high-numbered port between 1024 and 65535 that is not used by another service).
Port 2222

Save the file and exit the editor (in Nano, press Ctrl+O, Enter to save, and Ctrl+X to exit).

Step 3: Update the Firewall (UFW)

Before restarting the SSH service, you must allow incoming traffic on your new port through the Uncomplicated Firewall (UFW) to prevent getting locked out.

  1. Allow traffic on the new port: 
    sudo ufw allow 2222/tcp
  2. Reload the firewall to apply the changes: 
    sudo ufw reload

Step 4: Restart the SSH Daemon

Apply the changes by restarting the SSH service.

For standard Ubuntu installations:

sudo systemctl restart ssh

Note for Ubuntu 22.04 LTS and newer: SSH may use systemd socket activation. If the port change does not take effect immediately, update the socket configuration or run:

sudo systemctl daemon-reload
sudo systemctl restart ssh.socket

Step 5: Test the New Configuration

Do not close your current terminal session. Open a new terminal window on your local machine and test the connection using the new port number:

ssh -p 2222 username@your_server_ip

If you connect successfully, you can safely close the old session. You can also remove the old firewall rule for port 22:

sudo ufw delete allow 22/tcp
