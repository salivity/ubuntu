How to Inspect Kernel Module Parameters Using modinfo

This guide explains how to inspect the configurable parameters of Linux kernel modules in Ubuntu using the modinfo command. By using specific flags, you can quickly list available parameters, their descriptions, and their accepted data types directly from the module file, as well as locate the currently active values on a running system.

Displaying Available Parameters with modinfo

To inspect the available parameters for a specific kernel module, use the modinfo command combined with the -p (or --parameters) flag:

modinfo -p <module_name>

Replace <module_name> with the name of the module you want to examine.

For example, to view the parameters for the standard Intel Wi-Fi module (iwlwifi), run:

modinfo -p iwlwifi

The output displays each parameter name followed by its expected data type (such as int, uint, or bool) and a brief description of what the setting controls:

power_save:enable-global power save (default: true) (bool)
power_level:default power level (1-5, 0 = default) (int)
11n_disable:disable 11n functionality, 1=disable, 2=disable aggregations (uint)

If you omit the -p flag and run modinfo <module_name>, the utility will output the entire metadata record for the module, including its filename, license, author, aliases, dependencies, and parameters labeled under the parm: fields.

Inspecting Parameters on Currently Loaded Modules

The modinfo -p command reads the module file directly from /lib/modules/$(uname -r)/ to show what parameters can be set, but it does not display the values currently active in the running kernel.

To check which modules are currently loaded in Ubuntu, first run:

lsmod | grep <module_name>

Once confirmed that the module is loaded, view the active runtime value of its parameters through the sysfs virtual filesystem located at /sys/module/:

cat /sys/module/<module_name>/parameters/<parameter_name>

To list all current parameter values for a loaded module at once, run:

sudo grep -H '' /sys/module/<module_name>/parameters/*
