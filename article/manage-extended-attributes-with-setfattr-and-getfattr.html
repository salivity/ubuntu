Manage Extended Attributes with setfattr and getfattr

Extended file attributes (xattrs) in Ubuntu allow users and applications to associate arbitrary metadata with files and directories beyond standard permissions and timestamps. This guide explains how to install the required user-space utilities and use the setfattr and getfattr commands to write, view, and remove custom attributes within the standard Linux user namespace.

Prerequisites and Installation

Extended attributes are supported natively by common Linux filesystems like ext4, Btrfs, and XFS. To work with these attributes from the terminal, install the attr package:

sudo apt update
sudo apt install attr

Understanding Namespaces

Extended attribute names must be prefixed with a valid namespace: user, trusted, system, or security. For standard user-defined metadata on regular files, always use the user. namespace. Note that the filesystem must be mounted with user attribute support (default on modern Ubuntu systems).

Setting Attributes with setfattr

The setfattr command modifies or creates an extended attribute. Use the -n flag to define the attribute name and -v to assign its value.

To assign a key named user.description with a text value to a file:

setfattr -n user.description -v "Confidential Financial Report" report.pdf

To assign an empty or flag-like attribute without a value:

setfattr -n user.reviewed report.pdf

Reading Attributes with getfattr

The getfattr command displays the extended attributes associated with a file.

To read the value of a specific attribute, specify its name using the -n flag:

getfattr -n user.description report.pdf

To list all attributes and their assigned values for a file, use the -d (dump) flag:

getfattr -d report.pdf

By default, getfattr suppresses the namespace prefix in the output. If you want to view raw, full attribute names, include the -e text option or combine flags:

getfattr -d -m "^user\\." report.pdf

(The -m option matches attribute names using a regular expression. Passing . or ^user\\. ensures hidden or standard attributes are displayed).

Removing Attributes

To delete an extended attribute from a file, use setfattr with the -x flag followed by the attribute name:

setfattr -x user.description report.pdf

Verify the deletion by running getfattr -d report.pdf. If no other attributes remain, the command produces no output.

Recursive Operations

Both utilities support the -R flag to process entire directory trees recursively.

To assign an attribute to all files in a folder:

setfattr -R -n user.project -v "Alpha" ./project_files/

To inspect attributes across all files in a directory:

getfattr -R -d ./project_files/
