Install Ubuntu Budgie Desktop via Terminal

This guide provides a straightforward walkthrough for installing the Ubuntu Budgie desktop environment on an existing Ubuntu installation using the terminal. By following these steps, you will update your system repositories, install the necessary Budgie packages, configure the display manager, and switch to your new desktop interface without needing to reinstall your operating system.

Step 1: Update Your System

Before installing any new desktop environment, ensure that your existing packages and repository lists are fully up to date. Open your terminal and execute:

sudo apt update && sudo apt upgrade -y

Step 2: Install the Budgie Desktop Package

Ubuntu provides two main package options for the Budgie desktop:

  • Full Desktop Experience (Recommended): This package includes the complete Ubuntu Budgie flavor experience, along with default applications, themes, and applets.
sudo apt install ubuntu-budgie-desktop -y
  • Minimal Desktop Experience: If you only want the core Budgie desktop shell without the additional recommended applications, install the base package:
sudo apt install budgie-desktop -y

Step 3: Configure the Display Manager

During the installation of ubuntu-budgie-desktop, a configuration prompt will appear in the terminal asking you to select a default display manager (the login screen):

  1. Use the arrow keys to highlight your preferred option:
    • lightdm: The default display manager for Ubuntu Budgie, optimized for the Budgie interface.
    • gdm3: The default display manager for standard Ubuntu (GNOME).
  2. Press Enter to confirm your selection.

Step 4: Reboot the System

Once the installation process completes, restart your computer to apply the changes and initialize the new display manager:

sudo reboot

Step 5: Log in to the Budgie Desktop

  1. On the login screen, click on your username.
  2. Click the gear icon (session selector) located near the password field or at the bottom/top corner of the screen.
  3. Select Budgie Desktop from the list of available sessions.
  4. Enter your password and log in to begin using the Budgie interface.
