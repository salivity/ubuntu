Configure LightDM Greeter in Ubuntu MATE

Configuring the LightDM greeter in Ubuntu MATE allows you to personalize your login screen's appearance, choose custom wallpapers, modify themes, and adjust access settings. This guide explains how to customize the login screen using both the official graphical configuration tool and direct manual edits to configuration files.

Method 1: Using the Graphical Interface

Ubuntu MATE utilizes the Slick Greeter alongside LightDM by default and provides a dedicated graphical utility called Login Window (lightdm-settings) to manage it.

  1. Open the MATE menu, navigate to System > Administration, and select Login Window. Alternatively, press Alt + F2, type pkexec lightdm-settings, and press Enter.
  2. Authenticate using your administrative password.
  3. Use the tabs within the settings window to customize the greeter:
    • Appearance: Change the background wallpaper, set a solid background color, and choose your preferred GTK theme and icon set.
    • Users: Toggle options to show or hide the user list, enable guest sessions, or hide specific user accounts.
    • Settings: Configure accessibility features, display monitors, and indicators such as the clock and battery status.
  4. Close the application. Changes take effect automatically on your next logout or reboot.

Method 2: Manual Configuration via the Terminal

If you prefer using the terminal or are managing headless or automated deployments, edit the configuration files directly.

  1. Open a terminal and edit the Slick Greeter configuration file using a text editor with root privileges:

    sudo nano /etc/lightdm/slick-greeter.conf

  2. Under the [Greeter] section, specify your preferred settings. If the file is blank, add the section header and the directives you want to set:

    [Greeter]
background=/usr/share/backgrounds/mate/desktop/Ubuntu-Mate-Cold.png
draw-user-backgrounds=false
theme-name=Yaru-MATE-Dark
icon-theme-name=Yaru-MATE-Dark
font-name=Ubuntu 11
show-hostname=true

  3. Save the file and exit the editor (in nano, press Ctrl + O, then Enter, followed by Ctrl + X).

Testing Your Configuration

You can preview your changes without logging out by running the greeter in test mode:

slick-greeter --test-mode

Close the test window once verified. The new configuration will be active the next time the LightDM display manager initializes.
