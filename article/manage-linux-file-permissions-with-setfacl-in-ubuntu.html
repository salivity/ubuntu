Manage Linux File Permissions with setfacl in Ubuntu

Standard Linux file permissions limit access control to a single owner, a single group, and all other users, which often proves too rigid for complex environments. Access Control Lists (ACLs) provide a more granular security model, allowing administrators to grant specific permissions to multiple arbitrary users or groups on a single file or directory. In Ubuntu, this level of access is managed primarily with the setfacl command, complemented by getfacl for viewing existing rules.

Prerequisites

Ensure the ACL utility package is installed on your Ubuntu system by running:

sudo apt update
sudo apt install acl

Basic Syntax of setfacl

The setfacl command alters the ACL of one or more files or directories. The fundamental syntax is:

setfacl [options] rules files

The most common option is -m (modify), which adds or updates ACL entries without erasing existing ones.

Granting Permissions to Specific Users

To assign read and write permissions to a specific user on a file without changing the file's primary ownership, use the u: (user) tag:

setfacl -m u:developer:rw project.txt

This grants the user developer read and write access to project.txt.

Granting Permissions to Groups

To assign read, write, and execute permissions to a specific group, use the g: (group) tag:

setfacl -m g:qa-team:rwx /var/www/html

Viewing Configured ACLs

Files with active ACL entries display a plus sign (+) at the end of their permission string when listed with ls -l. To inspect the detailed permissions, use the getfacl command:

getfacl project.txt

The output reveals the file's owner, group, standard permissions, and any specific ACL rules assigned to additional users and groups.

Setting Default Directory Permissions

When collaborating within directories, you can define default ACLs using the -d flag. Default ACLs automatically apply to any new files or subdirectories created within that directory:

setfacl -d -m g:qa-team:rwx /var/www/html

Any new item created in /var/www/html will automatically inherit rwx permissions for the qa-team group.

Removing ACL Permissions

To remove a specific rule for an individual user or group, use the -x option:

setfacl -x u:developer project.txt

To remove all extended ACL entries and revert the target back to standard Linux file permissions, use the -b (remove all) option:

setfacl -b project.txt
