How to Configure Ubuntu as a Network Router

Configuring an Ubuntu system to act as a network router allows you to route traffic between different network segments, share an internet connection, and manage local network services. This guide covers setting up dual network interfaces, enabling IPv4 packet forwarding, configuring IP masquerading using NAT, and setting up a DHCP service to automatically assign IP addresses to local client devices.

1. Network Interface Setup

To act as a router, the Ubuntu system requires at least two physical or virtual network interfaces:

  • WAN Interface (eth0): Connected to the internet or upstream router.
  • LAN Interface (eth1): Connected to the internal local network.

Configure your interfaces using Netplan. Edit your Netplan configuration file located in /etc/netplan/:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: true
    eth1:
      dhcp4: no
      addresses:
        - 192.168.1.1/24

Apply the configuration:

sudo netplan apply

2. Enable IPv4 Packet Forwarding

By default, Ubuntu blocks traffic forwarding between network interfaces. To enable routing, turn on IPv4 forwarding.

Open /etc/sysctl.conf in a text editor:

sudo nano /etc/sysctl.conf

Uncomment or add the following line:

net.ipv4.ip_forward=1

Save the file and apply the changes immediately:

sudo sysctl -p

3. Configure Network Address Translation (NAT)

NAT allows devices on the internal network (LAN) to access the external network (WAN) using the router's IP address.

Use iptables to set up IP masquerading on your WAN interface (eth0):

sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables -A FORWARD -i eth1 -o eth0 -j ACCEPT
sudo iptables -A FORWARD -i eth0 -o eth1 -m state --state RELATED,ESTABLISHED -j ACCEPT

To ensure these rules persist after a system reboot, install iptables-persistent:

sudo apt update
sudo apt install iptables-persistent
sudo netfilter-persistent save

4. Install and Configure DHCP Server

To automatically assign IP addresses and gateway settings to LAN clients, install dnsmasq.

sudo apt install dnsmasq

Backup the default configuration file and create a new one:

sudo mv /etc/dnsmasq.conf /etc/dnsmasq.conf.bak
sudo nano /etc/dnsmasq.conf

Add the following configuration:

interface=eth1
dhcp-range=192.168.1.50,192.168.1.150,255.255.255.0,24h
dhcp-option=option:router,192.168.1.1
dhcp-option=option:dns-server,1.1.1.1,8.8.8.8

Restart the dnsmasq service to apply the configuration:

sudo systemctl restart dnsmasq

5. Verification

Connect a client machine to the LAN port (eth1). The client should receive an IP address in the 192.168.1.50–192.168.1.150 range, with 192.168.1.1 configured as its default gateway, and successfully route internet traffic through the Ubuntu router.
