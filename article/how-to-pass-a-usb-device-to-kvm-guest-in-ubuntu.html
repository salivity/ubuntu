How to Pass a USB Device to KVM Guest in Ubuntu

Passing a physical USB device from an Ubuntu host directly to a KVM (Kernel-based Virtual Machine) guest enables the virtual environment to interact natively with external hardware, such as flash drives, security dongles, or webcams. This guide covers how to identify your host USB device's hardware identifiers and attach it to your virtual machine using either the command line (virsh) or the graphical interface (virt-manager).

Step 1: Identify the USB Device on the Host

Before attaching the device, you must locate its Vendor ID and Product ID on the Ubuntu host.

  1. Plug the USB device into your Ubuntu host.
  2. Open a terminal and run: 
    lsusb
  3. Locate your device in the output list. The output will look similar to this: 
    Bus 001 Device 004: ID 0781:5583 SanDisk Corp. Ultra Fit
  4. Note the hexadecimal pair following ID. In this example:
    • Vendor ID: 0781
    • Product ID: 5583

Step 2: Create the Device XML File

KVM uses XML definitions to configure devices attached to virtual machines.

  1. Create a new XML file on your host: 
    nano usb-device.xml
  2. Paste the following configuration, replacing the vendor and product values with your device's IDs: 
    <hostdev mode='subsystem' type='usb' managed='yes'>
  <source>
    <vendor id='0x0781'/>
    <product id='0x5583'/>
  </source>
</hostdev>
    (Note: Prefix both IDs with 0x to designate them as hexadecimal numbers).
  3. Save and close the file (Ctrl+O, Enter, Ctrl+X).

Step 3: Attach the USB Device to the Guest

You can attach the device either permanently or temporarily to a running or stopped guest.

  1. Find the exact name of your virtual machine:

    virsh list --all

  2. To attach live (temporary, until guest reboot):

    virsh attach-device <vm-name> usb-device.xml --current

  3. To attach permanently (persists across reboots):

    virsh attach-device <vm-name> usb-device.xml --persistent

Alternative Method: Using Virtual Machine Manager (GUI)

If you prefer using a graphical interface instead of the command line:

  1. Launch Virtual Machine Manager (virt-manager).
  2. Open the target virtual machine and click the Show virtual hardware details (lightbulb) icon.
  3. Click Add Hardware at the bottom left.
  4. Select USB Host Device from the left-hand menu.
  5. Choose your physical USB device from the list of detected devices.
  6. Click Finish.

Step 4: Verify the USB Device in the Guest

  1. Log in to the guest operating system.
  2. Verify that the system sees the device:
    • Linux Guest: Run lsusb to confirm the device appears in the guest terminal.
    • Windows Guest: Open Device Manager and check under Universal Serial Bus controllers or Disk drives.

How to Detach the USB Device

To safely disconnect the passed-through USB device from the guest:

  • Remove temporarily (live):

    virsh detach-device <vm-name> usb-device.xml --current

  • Remove permanently:

    virsh detach-device <vm-name> usb-device.xml --persistent
