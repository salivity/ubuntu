How to Create a Custom Ubuntu ISO Using Cubic

Creating a custom Ubuntu ISO allows you to pre-install specific software packages, update kernels, remove unwanted applications, and configure system settings before deployment. This guide walks you through using Cubic (Custom Ubuntu ISO Creator), a graphical chroot environment wizard, to extract an official Ubuntu image, customize its file system and configuration via the command line, and repackage it into a bootable ISO ready for USB burning or virtual machine deployment.

Step 1: Install Cubic on Ubuntu

Cubic is maintained in an official Personal Package Archive (PPA). To install it on your host Ubuntu system, open a terminal and run the following commands:

sudo apt-add-repository universe
sudo apt-add-repository ppa:cubic-wizard/release
sudo apt update
sudo apt install --no-install-recommends cubic

Step 2: Set Up a Project Directory

  1. Launch Cubic from your application menu or by running cubic in the terminal.
  2. Choose a new, empty directory to serve as your project workspace. This folder will store the extracted ISO files, customizations, and the final generated image. Ensure your host system has at least 20–30 GB of free disk space.
  3. Click Next.

Step 3: Select the Base ISO

  1. Under the Original ISO section, browse and select the official Ubuntu desktop or server ISO file you want to customize.
  2. Cubic will automatically extract the image metadata and populate details such as the release name, version, and architecture.
  3. Under the Custom ISO section, modify the volume ID, release name, or file name if you wish to distinguish your custom build from the stock release.
  4. Click Next to allow Cubic to extract the compressed file system.

Step 4: Customize the Environment (Chroot Terminal)

Once extraction completes, Cubic presents a root virtual command-line environment (chroot). Any commands executed here directly modify the target operating system.

  • Update package repositories:

    apt update && apt upgrade -y

  • Install required applications:

    apt install -y git curl vlc build-essential

  • Remove unnecessary software:

    apt purge -y thunderbird libreoffice*
apt autoremove -y

  • Add files and assets: You can drag and drop custom files (such as wallpapers, scripts, or configuration files) from your host desktop directly into the Cubic window. Move them to target directories like /etc/skel/ to set default configurations for new user profiles.

Once all terminal customizations are complete, click Next.

Step 5: Configure Packages for Removal and Boot Kernel

  1. Packages for Removal: Cubic identifies packages that can be flagged for removal automatically when a user selects a "Minimal Installation" during the Ubuntu setup process. Adjust these flags as needed, then click Next.
  2. Boot Kernel: Select the default Linux kernel to boot the ISO. If you installed a newer or specific kernel during the chroot step, select it here. Click Next.

Step 6: Choose Compression and Generate the ISO

  1. Select a compression algorithm for the SquashFS file system:
    • gzip: Faster generation time, slightly larger ISO size.
    • xz: Slower generation time, highest compression ratio (recommended for smaller ISO sizes).
    • lz4 / zstd: Balances fast decompression during boot with good compression rates.
  2. Click Generate. Cubic will package the file system, generate the checksums, and create the final .iso image inside your project folder.
  3. Once completed, review the details on the completion screen, then click Finish to exit or delete temporary project files.

Your custom bootable Ubuntu ISO is now ready. You can test it inside a virtual machine such as VirtualBox or write it to a USB drive using tools like dd, Rufus, or Balena Etcher.
