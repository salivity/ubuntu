Gracefully Shut Down KVM Virtual Machine Using Virsh

Managing virtual machines on an Ubuntu KVM host requires reliable methods to power down instances without risking data corruption or filesystem damage. This guide covers the exact command required to initiate a graceful shutdown using the virsh command-line utility, explains how the guest operating system handles the request, and provides key troubleshooting tips when a guest fails to respond.

The Graceful Shutdown Command

To gracefully shut down a running KVM virtual machine, use the virsh shutdown command followed by the domain name or ID:

virsh shutdown <vm_name>

Replace <vm_name> with the name or numeric ID of your virtual machine. For example, to gracefully shut down a VM named web-server:

virsh shutdown web-server

Locating Your Virtual Machine Name

If you are unsure of the exact name of the domain, list all currently running instances on your Ubuntu host by running:

virsh list

To view all VMs regardless of their current power state, append the --all flag:

virsh list --all

How Graceful Shutdown Works

The virsh shutdown command sends an ACPI shutdown signal to the guest operating system, equivalent to momentarily pressing the physical power button on a hardware server. The guest OS receives this event, initiates its internal shutdown routines, stops services cleanly, flushes disk caches, and safely unmounts filesystems before powering off.

For this mechanism to function, the guest operating system must have ACPI support enabled. On Linux guests without desktop environments, you may need to ensure the ACPI daemon is installed and active:

sudo apt install acpid
sudo systemctl enable --now acpid

Using the QEMU Guest Agent

If ACPI events are blocked or unresponsive, you can execute a graceful shutdown via the QEMU Guest Agent. First, ensure the qemu-guest-agent package is installed and running inside the virtual machine. Then, instruct virsh to issue the shutdown command via the agent:

virsh shutdown <vm_name> --mode agent

Monitoring the Shutdown Process

Because a graceful shutdown allows services time to stop, the process is not instantaneous. You can monitor the VM's status until it transitions to shut off:

virsh domstate <vm_name>

Graceful vs. Forced Shutdown

Do not confuse virsh shutdown with virsh destroy. While virsh shutdown cleanly terminates processes, virsh destroy immediately cuts power to the virtual machine, which can lead to filesystem corruption and data loss. Reserve virsh destroy only for situations where a guest is entirely frozen and fails to respond to standard ACPI or agent shutdown signals.
