Clone Git Repo with SSH Config on Ubuntu

Cloning a Git repository using a specific SSH key configured in your ~/.ssh/config file on Ubuntu is accomplished by replacing the default remote hostname in the Git clone command with the custom host alias defined in your SSH configuration. This approach instructs SSH to automatically route the connection through the designated identity file without requiring inline SSH parameters or manual authentication switches.

The Clone Command

To clone the repository using an alias from your SSH configuration, run:

git clone git@<HostAlias>:<username>/<repository>.git

If the User git directive is already defined within your SSH configuration block, you can also use:

git clone <HostAlias>:<username>/<repository>.git

Step-by-Step Configuration and Usage

1. Configure ~/.ssh/config

Open or create your SSH configuration file on Ubuntu:

nano ~/.ssh/config

Add an entry specifying a unique Host alias, the real server domain (HostName), the default user, and the absolute path to your target private key (IdentityFile):

Host work-github
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes
  • Host: The shorthand alias used in Git commands.
  • HostName: The actual server address (e.g., github.com or gitlab.com).
  • User: Set to git for repository operations.
  • IdentityFile: Path to the dedicated private key.
  • IdentitiesOnly yes: Ensures SSH only offers the explicitly defined key.

2. Set Appropriate File Permissions

Ensure the SSH directory and configuration files have the correct security permissions:

chmod 700 ~/.ssh
chmod 600 ~/.ssh/config
chmod 600 ~/.ssh/id_ed25519_work

3. Execute the Clone Command

Instead of the standard URL (git@github.com:username/repository.git), substitute github.com with your defined alias (work-github):

git clone git@work-github:username/repository.git

Git reads the work-github alias, loads the settings from ~/.ssh/config, and completes the clone operation utilizing the designated SSH key.
