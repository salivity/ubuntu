Display LVM Physical Volume Details in Ubuntu

This article explains how to display detailed information about all physical volumes managed by Logical Volume Manager (LVM) in Ubuntu. You will learn the primary command used to view comprehensive physical volume attributes, along with alternative commands for quick summary views.

The Primary Command: pvdisplay

The primary command used to display detailed information about all LVM physical volumes in Ubuntu is pvdisplay.

To run the command with the necessary administrative privileges, open your terminal and execute:

sudo pvdisplay

What pvdisplay Shows

When executed without any arguments, pvdisplay outputs a detailed list for every physical volume configured on your system. The output includes:

  • PV Name: The device path (e.g., /dev/sda1 or /dev/nvme0n1p2).
  • VG Name: The name of the Volume Group the physical volume belongs to.
  • PV Size: The total size of the physical volume.
  • Allocatable: Indicates if space on the volume can be allocated to logical volumes.
  • PE Size: The Physical Extent size.
  • Total / Free PE: The total and unallocated physical extents available.
  • PV UUID: The unique identifier for the physical volume.

If you want to view details for a specific physical volume rather than all of them, append the device path to the command:

sudo pvdisplay /dev/sda1

Alternative LVM Display Commands

Depending on how you want the information presented, LVM provides two other helpful commands:

1. Concise Summary: pvs

If you prefer a short, tabular summary instead of a detailed multi-line output, use the pvs command:

sudo pvs

This prints a clean table displaying the PV name, associated Volume Group (VG), format, attributes, total size, and free space.

2. Scanning Physical Volumes: pvscan

To scan all system disk drives for LVM physical volumes and display a consolidated list, use:

sudo pvscan

This is particularly useful for verifying that Ubuntu detects all underlying physical drives assigned to LVM.
