How to Set Up a Local Ubuntu Repository Mirror

Setting up a local package repository mirror for Ubuntu allows administrators to conserve internet bandwidth, drastically speed up software updates, and maintain software distribution across isolated networks. This guide explains how to build a fully functional local Ubuntu mirror using apt-mirror, serve the files using an HTTP web server, and configure client machines to pull packages from your local server.

Prerequisites

Before starting, ensure your system meets the following requirements: * A server running Ubuntu with root or sudo access. * A stable internet connection for the initial repository download. * Sufficient storage space (typically 150 GB to 300+ GB per Ubuntu release, depending on the architectures and components selected). * A web server installed, such as Apache or Nginx.

Step 1: Install apt-mirror and Nginx

Install the apt-mirror tool to handle downloading packages from the official Ubuntu servers, alongside Nginx to serve the mirror to your local network.

sudo apt update
sudo apt install apt-mirror nginx -y

Step 2: Configure apt-mirror

The configuration file defines where local files are stored, which Ubuntu releases to clone, and which architectures to target.

  1. Open the configuration file in a text editor:
sudo nano /etc/apt/mirror.list
  1. Modify the configuration settings. Set your target base path and specify the Ubuntu repositories you need (replace noble or jammy with your target release):
############# config ##################
#
set base_path    /var/spool/apt-mirror
#
set mirror_path  $base_path/mirror
set skel_path    $base_path/skel
set var_path     $base_path/var
set cleanscript $var_path/clean.sh
set defaultarch  amd64
set postmirror_script $var_path/postmirror.sh
set run_postmirror 0
set nthreads     20
set _tilde 0
#
############# end config ##############

# Ubuntu Main Repositories
deb http://archive.ubuntu.com/ubuntu noble main restricted universe multiverse
deb http://archive.ubuntu.com/ubuntu noble-updates main restricted universe multiverse
deb http://archive.ubuntu.com/ubuntu noble-security main restricted universe multiverse

# Clean up older packages
clean http://archive.ubuntu.com/ubuntu
  1. Save and close the file.

Step 3: Download the Repository Packages

Run apt-mirror to start mirroring the specified repositories. The initial synchronization will take time depending on your network speed.

sudo apt-mirror

If the synchronization process is interrupted, running sudo apt-mirror again will resume the download where it left off.

Step 4: Configure the Web Server to Serve the Mirror

Expose the downloaded mirror directory over HTTP so client machines can access it.

  1. Create a symbolic link from your mirror directory to the web server root:
sudo ln -s /var/spool/apt-mirror/mirror/archive.ubuntu.com/ubuntu /var/www/html/ubuntu
  1. Ensure Nginx is running and enabled on boot:
sudo systemctl enable --now nginx

You can verify access by visiting http://<your-server-ip>/ubuntu in a web browser.

Step 5: Automate Repository Updates

To keep your local mirror updated automatically, add a cron job that executes apt-mirror on a daily schedule.

  1. Open the system crontab:
sudo crontab -e
  1. Add the following line to run the update every day at midnight:
0 0 * * * /usr/bin/apt-mirror > /var/spool/apt-mirror/var/cron.log 2>&1

Step 6: Configure Client Machines

To make client systems pull updates from your local mirror instead of official servers, update their APT sources list.

  1. On the client machine, backup the existing sources file:
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
  1. Edit /etc/apt/sources.list to point to your local mirror IP or hostname (replace 192.168.1.100 with your mirror server’s IP address):
deb http://192.168.1.100/ubuntu noble main restricted universe multiverse
deb http://192.168.1.100/ubuntu noble-updates main restricted universe multiverse
deb http://192.168.1.100/ubuntu noble-security main restricted universe multiverse
  1. Update the package database on the client machine:
sudo apt update

The client machine is now configured to install and update software directly from your local repository mirror.
