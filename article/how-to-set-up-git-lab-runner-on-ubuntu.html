How to Set Up GitLab Runner on Ubuntu

This guide provides a straightforward walkthrough for installing, configuring, and registering a local GitLab Runner on an Ubuntu server. By following these steps, you will install the GitLab Runner package, configure Docker as the execution environment, and connect the runner to your GitLab instance so it can automatically execute your CI/CD pipelines.

Step 1: Update the System and Install Docker

Before installing GitLab Runner, update your system repository index and install Docker, which is the most versatile and commonly used executor for running pipeline jobs in isolated containers.

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl apt-transport-https ca-certificates gnupg lsb-release docker.io

Start and enable the Docker service to ensure it runs automatically on system boot:

sudo systemctl enable --now docker

Step 2: Add the Official GitLab Runner Repository

Add the official GitLab repository to your Ubuntu package manager to ensure you install the latest supported version of the runner.

Download and run the repository setup script:

curl -L "https://packages.gitlab.com/install/repositories/runner/gitlab-runner/script.deb.sh" | sudo bash

Step 3: Install GitLab Runner

Once the repository is added, install the GitLab Runner package using apt:

sudo apt install -y gitlab-runner

Ensure the runner service is active and running:

sudo systemctl status gitlab-runner

Step 4: Obtain Your Registration Token

To link the runner to your project or group, retrieve your registration token from GitLab:

  1. Navigate to your GitLab repository or group.
  2. In the left sidebar, go to Settings > CI/CD.
  3. Expand the Runners section.
  4. Under Project runners or Group runners, find the registration token and instance URL (or generate a new runner authentication token if using modern GitLab versions).

Step 5: Register the Runner

Run the registration command to connect your local server to GitLab:

sudo gitlab-runner register

During the interactive prompt, provide the required details:

  • GitLab instance URL: Enter your GitLab URL (e.g., https://gitlab.com/ or your self-hosted URL).
  • Registration token: Paste the token obtained in Step 4.
  • Runner description: Enter a name for the runner (e.g., ubuntu-local-runner).
  • Tags: Enter comma-separated tags (e.g., ubuntu, docker, local) to target specific jobs.
  • Maintenance note: Optional; leave blank or enter a brief note.
  • Executor: Enter docker.
  • Default Docker image: Enter a default image, such as alpine:latest or ubuntu:latest.

Step 6: Verify Runner Operation

Verify that the runner is properly registered and operational:

sudo gitlab-runner verify

Return to your GitLab UI under Settings > CI/CD > Runners. You should now see your newly registered runner listed with a green circle indicating it is active and ready to accept CI/CD jobs.
