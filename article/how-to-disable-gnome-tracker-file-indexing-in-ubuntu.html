How to Disable GNOME Tracker File Indexing in Ubuntu

High CPU usage in Ubuntu is often caused by GNOME Tracker, a background service that indexes files for quick desktop searches. While useful for instant file lookup, it can heavily consume CPU and RAM, leading to system lag—especially on older hardware or large storage drives. This guide provides a direct, step-by-step walkthrough to permanently disable the GNOME Tracker service, stop its background processes, and delete existing cache files to free up system resources.

Method 1: Disable GNOME Tracker via Terminal (Recommended)

Modern Ubuntu releases (Ubuntu 21.04, 22.04, 24.04, and newer) use GNOME Tracker 3 (tracker-miner-fs-3). Masking the background services via systemctl stops them from starting automatically upon boot.

Step 1: Stop and Mask the Tracker Services

Open your terminal (Ctrl + Alt + T) and run the following commands:

systemctl --user mask tracker-miner-fs-3.service tracker-extract-3.service tracker-writeback-3.service tracker-miner-rss-3.service
systemctl --user stop tracker-miner-fs-3.service tracker-extract-3.service tracker-writeback-3.service tracker-miner-rss-3.service

Note for older Ubuntu versions (Ubuntu 20.04 and earlier): Use tracker-miner-fs.service and tracker-store.service instead.

Step 2: Reset and Clear Tracker Cache

To remove existing index files and stop any running background processes immediately, execute:

tracker3 reset -s -r

Step 3: Verify the Services Are Disabled

Check the status of the tracker miner to ensure it is masked and inactive:

systemctl --user status tracker-miner-fs-3.service

The output should show Loaded: masked and Active: inactive (dead).

Method 2: Disable File Indexing via Graphical Settings

If you prefer using the graphical user interface, you can turn off indexing through the system settings.

  1. Open Settings from the application menu.
  2. Navigate to Search in the sidebar.
  3. Select Search Locations at the top of the window.
  4. Toggle off Automatic Indexing.
  5. Remove all folders from the list of indexed locations.

How to Re-enable GNOME Tracker

If you ever need to restore file indexing in the future, unmask and start the services again by running:

systemctl --user unmask tracker-miner-fs-3.service tracker-extract-3.service tracker-writeback-3.service tracker-miner-rss-3.service
systemctl --user start tracker-miner-fs-3.service
