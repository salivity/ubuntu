What is update-alternatives in Ubuntu?

The update-alternatives system in Ubuntu is a command-line tool designed to manage multiple versions of software applications and commands on a single system. It allows administrators and users to specify default programs for general tasks—such as selecting between different versions of Java, Python, or text editors—without breaking system dependencies or creating hardcoded paths. This article covers the primary role of update-alternatives, how it functions behind the scenes, and basic commands for managing default software configurations.

Core Role of the update-alternatives System

Ubuntu frequently hosts multiple programs that fulfill the same basic function. For instance, editor could refer to nano, vim, or gedit, while java might refer to OpenJDK 11, OpenJDK 17, or Oracle Java.

The primary roles of update-alternatives include:

  • Default Application Management: It establishes system-wide default choices for generic commands.
  • Seamless Version Switching: It allows users to switch between different installed versions of a compiler, runtime, or utility without uninstalling other versions.
  • Preventing Package Conflicts: It resolves conflicts by ensuring different software packages providing the same functional binary can coexist peacefully on the filesystem.

How update-alternatives Works

Instead of placing direct binaries or static files in standard directories like /usr/bin, Ubuntu uses a system of symbolic links (symlinks) managed by update-alternatives.

The process operates through a three-tier symlink structure:

  1. Generic Name: The command you run in the terminal (e.g., /usr/bin/java).
  2. Alternative Link: A central symlink stored in the directory /etc/alternatives/ (e.g., /etc/alternatives/java).
  3. Real Binary: The actual executable file located in its specific directory (e.g., /usr/lib/jvm/java-17-openjdk-amd64/bin/java).

When you execute a command, /usr/bin/command points to /etc/alternatives/command, which points to the chosen executable. Changing the default selection simply updates the symlink inside /etc/alternatives/.

Common Usage and Commands

The update-alternatives utility offers simple commands to view, configure, and add software alternatives.

Displaying and Changing Defaults

To select a default application from an interactive menu, use the --config option followed by the group name:

sudo update-alternatives --config java

This presents a numbered list of installed choices, indicating the current automatic and manual selections. Entering the selection number changes the active default instantly.

To view all available choices for a command without making changes:

update-alternatives --list java

Adding a New Alternative

If software is installed manually or outside the default APT package manager, it can be added to the alternatives system using the --install option:

sudo update-alternatives --install /usr/bin/python python /usr/bin/python3.10 1

The syntax requires four parameters: 1. Link: The master symlink location (e.g., /usr/bin/python). 2. Name: The group name in the alternatives directory (e.g., python). 3. Path: The absolute path to the real binary (e.g., /usr/bin/python3.10). 4. Priority: An integer indicating priority; higher numbers are chosen automatically if the system is in automatic mode.

Automatic vs. Manual Mode

  • Automatic Mode: The system automatically chooses the alternative with the highest priority setting installed on the machine.
  • Manual Mode: The administrator explicitly selects a preferred version, overriding priority settings until switched back to automatic mode.

To set an alternative back to automatic mode, use:

sudo update-alternatives --auto java
