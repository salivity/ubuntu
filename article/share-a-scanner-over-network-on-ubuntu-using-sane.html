Share a Scanner Over Network on Ubuntu Using SANE

This guide explains how to configure the SANE (Scanner Access Now Easy) backend on an Ubuntu system to share a locally attached USB scanner across a local area network. By configuring the SANE daemon (saned), granting network subnet access, and enabling the systemd network socket, other computers on your network can access and control the physical scanner as if it were connected directly to them.

Step 1: Install SANE and Verify Scanner Detection

Ensure your Ubuntu system is up to date and has the required SANE packages installed:

sudo apt update
sudo apt install sane sane-utils

Connect your USB scanner to the Ubuntu machine and power it on. Verify that the operating system detects the scanner:

scanimage -L

If the scanner is properly recognized, the output will display the device model and backend name (e.g., device 'genesys:libusb:001:004' is a Canon LiDE...).

Step 2: Configure Network Access in saned.conf

Edit the SANE daemon configuration file to specify which network clients are permitted to access the scanner:

sudo nano /etc/sane.d/saned.conf

Scroll to the bottom of the file and add the IP address range of your local network. For example, to allow all devices on a 192.168.1.x subnet:

192.168.1.0/24

Alternatively, you can specify individual IP addresses (e.g., 192.168.1.50). Save and close the file.

Step 3: Configure Device Permissions

The saned user must have permission to access the local scanner hardware. Add the saned user to the scanner and lp groups:

sudo usermod -aG scanner,lp saned

Step 4: Enable and Start the SANE Socket

Modern Ubuntu releases manage the saned daemon via systemd sockets, listening on TCP port 6566 and spawning the daemon when a connection is requested.

Enable and start the socket:

sudo systemctl enable saned.socket
sudo systemctl start saned.socket

Confirm that the socket is active and listening:

sudo systemctl status saned.socket

Step 5: Configure the Firewall

If the Uncomplicated Firewall (UFW) is active on your Ubuntu server, open TCP port 6566 to allow incoming scanner requests:

sudo ufw allow 6566/tcp
sudo ufw reload

Step 6: Connect from a Client Machine

On any client machine running Linux with SANE installed, configure the network client backend to find the server:

  1. Open /etc/sane.d/net.conf in a text editor with administrative privileges.
  2. Add the IP address or hostname of the Ubuntu server hosting the scanner:
192.168.1.100
  1. Test the connection from the client machine:
scanimage -L

The output should list the shared network scanner prefixed with net:. You can now scan documents from the client machine using tools such as Document Scanner (Simple Scan), XSane, or command-line utilities.
