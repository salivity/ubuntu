Sync Directories on Ubuntu Servers Using Syncthing

This guide explains how to establish continuous, secure, peer-to-peer directory synchronization between two Ubuntu servers using the open-source utility Syncthing. You will learn how to install Syncthing from its official repository, configure it to run automatically in the background via systemd, connect the two servers using unique Device IDs, and set up a bidirectional shared folder without relying on third-party cloud storage.

Prerequisites

  • Two servers running Ubuntu (e.g., 20.04, 22.04, or 24.04).
  • A standard user account with sudo privileges on both systems.
  • Ports 22000/tcp and 22000/udp open for synchronization traffic.

Step 1: Install Syncthing on Both Servers

Execute the following commands on both Ubuntu machines to add the official Syncthing repository and install the package.

  1. Install prerequisite utilities:

    sudo apt update
sudo apt install -y curl apt-transport-https

  2. Download the Syncthing PGP release key:

    sudo mkdir -p /etc/apt/keyrings
sudo curl -L -o /etc/apt/keyrings/syncthing-archive-keyring.gpg https://syncthing.net/release-key.gpg

  3. Add the official Syncthing repository:

    echo "deb [signed-by=/etc/apt/keyrings/syncthing-archive-keyring.gpg] https://apt.syncthing.net/ syncthing stable" | sudo tee /etc/apt/sources.list.d/syncthing.list

  4. Update package lists and install Syncthing:

    sudo apt update
sudo apt install -y syncthing

Step 2: Configure and Start the Systemd Service

Syncthing includes a systemd service file configured to run per user. Replace username with your actual non-root Ubuntu username on both servers:

sudo systemctl enable syncthing@username.service
sudo systemctl start syncthing@username.service

Verify that the service is running:

sudo systemctl status syncthing@username.service

Step 3: Configure Firewall Rules

Syncthing requires port 22000 for peer-to-peer data transfer and local discovery ports. If UFW is active, run the following on both machines:

sudo ufw allow 22000/tcp
sudo ufw allow 22000/udp
sudo ufw reload

Step 4: Access the Syncthing Web GUI via SSH Tunnel

By default, the Syncthing Web UI binds strictly to 127.0.0.1:8384 for security. To securely view the interface on headless servers, create an SSH tunnel from your local machine.

Run this command from your local terminal for Server 1:

ssh -L 9901:127.0.0.1:8384 username@server1_ip

Open a second local terminal window and establish a tunnel for Server 2:

ssh -L 9902:127.0.0.1:8384 username@server2_ip

Open your local browser to access both interfaces:

  • Server 1: http://localhost:9901
  • Server 2: http://localhost:9902

Set a GUI administrator username and password on each instance under Actions > Settings > GUI.

Step 5: Connect the Two Servers

  1. On Server 1, click Actions > Show ID and copy the long identification string.
  2. In the GUI of Server 2, navigate to the Remote Devices section on the bottom right and click Add Remote Device.
  3. Paste the Device ID from Server 1 into the Device ID field, assign it a recognizable name, and click Save.
  4. Return to the Server 1 interface. Within a few seconds, a prompt will appear requesting permission to pair with Server 2. Click Add Device to confirm the bidirectional link.

Step 6: Create and Sync a Directory

  1. On Server 1, select Add Folder under the Folders column.
  2. Under the General tab:
    • Enter a Folder Label (e.g., Shared-Data).
    • Specify the Folder Path (e.g., /home/username/shared_data).
  3. Switch to the Sharing tab and check the box next to Server 2.
  4. Click Save.
  5. Switch to the Web GUI of Server 2. A notification will indicate that Server 1 wants to share a folder.
  6. Click Add, specify the directory path on Server 2 where you want the synced files stored, and click Save.

The two servers will now scan their respective directories, establish a peer-to-peer connection, and continuously sync any created, modified, or deleted files.
