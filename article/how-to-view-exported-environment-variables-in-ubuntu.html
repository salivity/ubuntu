How to View Exported Environment Variables in Ubuntu

Managing environment variables is a fundamental aspect of configuring and troubleshooting applications in Ubuntu. This article covers the primary commands used to list all exported environment variables in your current terminal session, including printenv, env, and export -p, as well as how to search through them efficiently using filters.

To view all exported environment variables in a standard Ubuntu shell session, the standard command is printenv. Running this command without any options prints a complete list of every exported variable currently active in your shell:

printenv

Alternatively, you can use the env command. While env is primarily used to run commands in a custom environment, executing it on its own displays all exported variables just like printenv:

env

If you need to see variables formatted as executable export statements, use the export command with the -p flag:

export -p

This displays the exported variables formatted as shell commands, making it easy to see both the variable names and their assigned values.

Because the output list is often long, you can pipe the output into less to scroll through the variables page by page:

printenv | less

To search for a specific exported variable, pass its name directly to printenv or filter the output with grep:

printenv PATH

or

printenv | grep USER
