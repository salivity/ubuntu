How to View Wi-Fi Statistics Using iw in Ubuntu

This article provides a quick guide on how to view detailed Wi-Fi connection statistics in Ubuntu using the iw command-line tool. By using the standard wireless utility, you can easily inspect link status, signal strength, transmit bitrates, connected access point details, and operating frequencies directly from your terminal.

The Command for Detailed Wi-Fi Link Statistics

The primary command to view detailed Wi-Fi connection statistics for an active link using iw is:

sudo iw dev <interface> link

Replace <interface> with the name of your wireless network adapter (such as wlan0 or wlp3s0).

How to Check Your Wi-Fi Statistics Step-by-Step

1. Identify Your Wireless Interface Name

If you do not know your wireless interface name, list all available wireless devices by running:

iw dev

Look for the line starting with Interface. For example, your interface might be named wlan0 or wlp2s0.

2. Execute the Link Command

Once you know your interface name, run the link command to fetch active connection metrics:

sudo iw dev wlan0 link

3. Analyze the Command Output

The command returns comprehensive data about your current wireless link:

  • Connected to: The MAC address (BSSID) of the Access Point.
  • SSID: The name of the Wi-Fi network you are connected to.
  • freq: The current operating frequency in MHz (e.g., 5180 MHz for 5 GHz Wi-Fi).
  • RX/TX bytes: Total bytes received and transmitted over the link.
  • signal: The current signal strength expressed in dBm (e.g., -50 dBm). Values closer to 0 represent a stronger signal.
  • tx bitrate: The current transmission rate, including channel width, Modulation and Coding Scheme (MCS) index, and theoretical throughput speed.

Viewing Advanced Station Statistics

For even deeper connection metrics—such as packet loss, retransmits, inactive time, and signal strength per antenna chain—use the station dump command:

sudo iw dev wlan0 station dump

This output provides low-level diagnostic data useful for troubleshooting unstable Wi-Fi connections or monitoring real-time network performance on Ubuntu.
