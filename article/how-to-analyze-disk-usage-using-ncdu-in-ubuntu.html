How to Analyze Disk Usage Using ncdu in Ubuntu

This article provides a quick guide on how to install and use NCurses Disk Usage (ncdu) in Ubuntu to efficiently analyze and manage your system's storage. You will learn how to scan directories, navigate the interactive text-based interface, identify large files, and remove unnecessary data directly from the terminal.

Step 1: Install ncdu on Ubuntu

The ncdu utility is available in the standard Ubuntu repositories. Open your terminal and run the following commands to install it:

sudo apt update
sudo apt install ncdu -y

Step 2: Run ncdu to Analyze Disk Usage

To analyze the current working directory, simply run:

ncdu

To analyze the entire root filesystem, run ncdu with elevated privileges targeting the root directory (/):

sudo ncdu /

Note: Running as sudo ensures that ncdu has permission to read all system files and directories.

To analyze a specific directory (such as /var or /home), append the path:

ncdu /var/log

Step 3: Navigate the ncdu Interface

Once the scan completes, ncdu displays a sorted list of files and directories from largest to smallest.

Use the following keyboard shortcuts to interact with the interface:

  • Up / Down Arrow Keys (or k / j): Move the selection up and down.
  • Right Arrow / Enter: Open the selected directory.
  • Left Arrow: Go back to the parent directory.
  • d: Delete the selected file or directory (a prompt will ask for confirmation).
  • i: Display detailed information about the selected item (full path, size, disk usage, modify time).
  • g: Toggle between displaying percentage, graph, or both for size visualization.
  • c: Toggle the display of child item counts.
  • q: Quit ncdu.

Useful ncdu Command Options

  • Exclude other filesystems: To prevent ncdu from scanning mounted network drives or external media, use the -x flag: 
    sudo ncdu -x /
  • Export scan results: You can save the scan data to a file for later analysis: 
    ncdu -o scan_results.txt /
  • Import scan results: To view previously exported scan data: 
    ncdu -f scan_results.txt
  • Exclude specific directories: Skip folders you do not want to scan using the --exclude flag: 
    ncdu --exclude /proc --exclude /sys /
