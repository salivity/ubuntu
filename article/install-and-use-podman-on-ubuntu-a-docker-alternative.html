Install and Use Podman on Ubuntu: A Docker Alternative

This guide explains how to install and use Podman on Ubuntu as a rootless, daemonless alternative to Docker. You will learn the commands required to install Podman from official repositories, configure basic container settings, and manage containers using familiar Docker-compatible syntax.

What is Podman?

Podman (Pod Manager) is an open-source, OCI-compliant container engine developed by Red Hat. Unlike Docker, Podman does not rely on a persistent background daemon (dockerd) to run. Instead, it launches containers directly as child processes of the user. It also enables rootless execution by default, significantly improving host security by preventing root access escalation inside containers.

Step 1: Update the System

Ensure your local package index is up to date before installing new packages:

sudo apt update && sudo apt upgrade -y

Step 2: Install Podman

Podman is available in the official package repositories of Ubuntu 20.10 and newer releases (including 22.04 LTS and 24.04 LTS). Install it directly with apt:

sudo apt install -y podman

Once the installation finishes, verify that Podman is properly installed by checking its version:

podman --version

Step 3: Configure Registries (Optional)

By default, Podman searches through defined registries (such as Docker Hub or Quay.io) when you pull an image. You can configure or verify registry search paths in /etc/containers/registries.conf:

cat /etc/containers/registries.conf

If it is not configured, you can specify fully qualified domain names when pulling images (e.g., docker.io/library/ubuntu).

Step 4: Run Rootless Containers

Podman works without sudo by default. You can search, pull, and run containers directly under your standard user account.

Search for an Image

podman search nginx

Pull an Image

podman pull docker.io/library/nginx

Run a Container

Run an Nginx web server in detached mode mapping host port 8080 to container port 80:

podman run -d --name web-server -p 8080:80 docker.io/library/nginx

Test that the web server is running:

curl http://localhost:8080

Step 5: Managing Containers

Podman mirrors Docker CLI syntax closely. Common commands include:

  • List active containers: 
    podman ps
  • List all containers (running and stopped): 
    podman ps -a
  • View container logs: 
    podman logs web-server
  • Stop a container: 
    podman stop web-server
  • Remove a container: 
    podman rm web-server
  • List local images: 
    podman images
  • Remove an image: 
    podman rmi docker.io/library/nginx

Step 6: Using Podman as a Drop-In Docker Replacement

Because the CLI commands are intentionally identical, you can set an alias to substitute docker with podman:

alias docker=podman

To make this permanent, append the alias to your shell configuration file:

echo "alias docker=podman" >> ~/.bashrc
source ~/.bashrc

You can now execute docker run, docker ps, and other standard workflows powered directly by Podman.
