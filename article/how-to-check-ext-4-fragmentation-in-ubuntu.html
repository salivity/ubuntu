How to Check ext4 Fragmentation in Ubuntu

This article provides a direct guide on how to check the fragmentation level of an ext4 filesystem in Ubuntu. While the ext4 filesystem automatically minimizes fragmentation through pre-allocation and delayed allocation techniques, files can still fragment over time, especially on drives with high input/output workloads or limited free space. By using native Ubuntu command-line utilities, you can quickly analyze fragmentation scores for specific files, directories, or entire mounted partitions without taking the filesystem offline.

The Command: e4defrag

The standard command used to display the fragmentation level of an ext4 filesystem is e4defrag with the -c (check) option. This utility is part of the e2fsprogs package, which comes pre-installed on modern Ubuntu distributions.

Checking a Directory or Entire Partition

To inspect the fragmentation status of a directory, a specific file, or an entire mounted drive, execute the command with sudo:

sudo e4defrag -c /path/to/target

To check an entire partition, pass the mount point as the target (for example, the root / directory or a separate /home partition):

sudo e4defrag -c /

To check a specific directory:

sudo e4defrag -c /home/username/Downloads

Understanding the Output

After scanning the target, e4defrag outputs an analysis summary detailing the total number of files, fragmented files, extents, and a final fragmentation score.

The most important metric is the Fragmentation score:

  • 0 – 30: No defragmentation is needed. The filesystem is in an optimal state.
  • 31 – 55: Slight fragmentation is present. File performance is generally unaffected, but defragmentation can be considered.
  • 56 – 100: Defragmentation is recommended. File access speeds may be degraded due to non-contiguous extents.

The tool concludes its output with a direct recommendation, stating whether defragmentation is necessary.

Resolving Fragmentation

If the check command reports a high fragmentation score, you can defragment the target online while the system is running by omitting the -c flag:

sudo e4defrag /path/to/target

Note: Running defragmentation tools on Solid State Drives (SSDs) is not recommended, as it causes unnecessary write wear and provides negligible performance improvements.
