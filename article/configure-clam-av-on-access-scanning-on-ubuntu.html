Configure ClamAV On-Access Scanning on Ubuntu

This guide explains how to install and configure ClamAV's built-in on-access scanner (clamonacc) to provide real-time malware protection for shares on an Ubuntu file server. By configuring the ClamAV daemon, setting fanotify monitoring paths, tuning kernel parameters, and managing the clamonacc systemd service, you can automatically detect and block malicious files the moment they are written to or accessed on your system.

Step 1: Install ClamAV and the ClamAV Daemon

Update your local package lists and install ClamAV, the daemon, and required system tools:

sudo apt update
sudo apt install clamav clamav-daemon -y

Stop the freshclam service temporarily to download the latest virus signature database manually:

sudo systemctl stop clamav-freshclam
sudo freshclam
sudo systemctl start clamav-freshclam

Step 2: Configure System Limits for Fanotify

ClamAV's on-access scanner relies on the Linux fanotify and inotify kernel subsystems to monitor filesystem events. Servers hosting large directories need higher watch limits.

Open the sysctl configuration file:

sudo nano /etc/sysctl.d/99-clamav.conf

Add the following lines to raise file monitoring and queued event limits:

fs.inotify.max_user_watches = 524288
fs.inotify.max_queued_events = 32768

Apply the changes immediately:

sudo sysctl -p /etc/sysctl.d/99-clamav.conf

Step 3: Configure ClamAV Daemon for On-Access Scanning

Edit the clamd.conf configuration file:

sudo nano /etc/clamav/clamd.conf

Append the following configuration directives at the bottom of the file, replacing /srv/share with the path to your server's shared folder:

# On-Access Scan Settings
OnAccessMaxFileSize 50M
OnAccessIncludePath /srv/share
OnAccessPrevention yes
OnAccessExtraScanning yes
OnAccessExcludeUname clamav
  • OnAccessMaxFileSize: Defines the maximum size of files to scan upon access.
  • OnAccessIncludePath: Specifies the absolute directory to monitor recursively.
  • OnAccessPrevention: Blocks file access until ClamAV finishes scanning and determines the file is clean.
  • OnAccessExtraScanning: Enables alerts on file creation and movement, not just file reads.
  • OnAccessExcludeUname: Prevents the scanner from inspecting files read by the clamav user itself, preventing recursive scan loops.

Restart the ClamAV daemon to apply the configuration:

sudo systemctl restart clamav-daemon

Verify that the daemon is active and running:

sudo systemctl status clamav-daemon

Step 4: Configure and Run the clamonacc Service

The clamonacc binary operates as a separate daemon that communicates with clamd via a local socket. Ubuntu provides a template service for clamonacc that needs to run with root privileges to utilize kernel fanotify hooks.

Create or update the systemd service file:

sudo nano /etc/systemd/system/clamav-clamonacc.service

Insert the following unit definition:

[Unit]
Description=ClamAV On-Access Scanner
Requires=clamav-daemon.service
After=clamav-daemon.service syslog.target network.target

[Service]
Type=simple
User=root
ExecStart=/usr/bin/clamonacc -F --log=/var/log/clamav/clamonacc.log --move=/var/quarantine
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target

Create the quarantine directory and the log file with correct permissions:

sudo mkdir -p /var/quarantine
sudo touch /var/log/clamav/clamonacc.log
sudo chown -R clamav:clamav /var/quarantine /var/log/clamav/clamonacc.log

Reload systemd, enable the service on boot, and start it:

sudo systemctl daemon-reload
sudo systemctl enable --now clamav-clamonacc

Check the service status:

sudo systemctl status clamav-clamonacc

Step 5: Verify Real-Time Protection

Verify that on-access scanning is actively blocking threats by downloading an EICAR anti-malware test file into your monitored path:

cd /srv/share
curl -O https://secure.eicar.org/eicar.com.txt

If OnAccessPrevention is functioning correctly, access to the file will be blocked or the file will be moved to /var/quarantine immediately.

Check the on-access log file to confirm detection:

sudo tail -f /var/log/clamav/clamonacc.log

The log will output an entry confirming that eicar.com.txt was detected as a threat and handled according to your configuration rules.
