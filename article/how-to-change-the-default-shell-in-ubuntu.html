How to Change the Default Shell in Ubuntu

Ubuntu sets Bash as the default command-line shell for user accounts, but you can permanently switch to alternatives like Zsh, Fish, or Dash. This guide explains how to view your available shells and permanently change the login shell for yourself or another user using standard Ubuntu command-line utilities.

Step 1: Find Available Shells

Before changing your shell, ensure the desired shell is installed and listed in the system's approved shells file. Run:

cat /etc/shells

The output displays the full paths of installed shells, such as /bin/bash, /usr/bin/zsh, or /usr/bin/fish. Copy the full path of the shell you want to use.

Step 2: Change the Shell Using chsh

The standard and safest tool to change a user's login shell is chsh (change shell).

For Your Own Account

Run the chsh command with the -s flag followed by the full path of your target shell:

chsh -s /usr/bin/zsh

Enter your account password when prompted.

For Another User Account

To change the shell for a different user, run chsh with sudo and specify the username at the end:

sudo chsh -s /usr/bin/zsh username

Replace username with the actual user's name.

Step 3: Alternative Method Using usermod

System administrators can also update a user's shell using the usermod utility:

sudo usermod --shell /usr/bin/zsh username

This command directly updates the user's shell entry in the /etc/passwd configuration file.

Step 4: Verify the Change

The default shell change takes effect upon your next login. To verify the update:

  1. Log out of your current session and log back in (or close and reopen your terminal window/SSH session).
  2. Check the active shell environment variable:
echo $SHELL

You can also inspect the /etc/passwd file entry directly to confirm the configuration:

grep "^$USER:" /etc/passwd

The output should end with the path to the newly assigned shell.
