How to Customize Plank Dock in Ubuntu Budgie

Customizing the Plank dock in Ubuntu Budgie allows you to tailor your desktop's appearance, optimize screen space, and streamline application launching. This guide covers how to access the hidden preferences menu, adjust visual themes and icon sizes, configure dock behavior and hiding rules, manage built-in docklets, and add or remove pinned applications.

Accessing Plank Preferences

Plank does not display an obvious settings button by default. To open its configuration window:

  1. Hold down the Ctrl key and right-click anywhere on empty space or an icon separator on the Plank dock.
  2. Select Preferences from the context menu.

Alternatively, you can open a terminal and run the following command to launch the settings interface directly:

plank --preferences

Customizing Appearance

Under the Appearance tab, you can modify the visual layout of the dock:

  • Theme: Choose from preinstalled themes such as Default, Matte, or Transparent. Your selection instantly alters the dock's background styling and border color.
  • Position: Choose which edge of your screen hosts the dock: Bottom, Top, Left, or Right.
  • Alignment: Control where the dock aligns on the chosen edge: Fill (stretches across), Start, Center, or End.
  • Icon Size: Adjust the slider to scale icons smaller or larger depending on your screen resolution.
  • Icon Zoom: Enable this toggle to zoom in on icons when your mouse hovers over them, and adjust the scale slider to set the magnification level.

Configuring Dock Behavior

The Behavior tab dictates how Plank interacts with open windows and running applications:

  • Hide Mode:
    • None: The dock remains visible at all times.
    • Intelligent: The dock hides automatically when a maximized or overlapping window covers it.
    • Auto-hide: The dock hides whenever the cursor moves away from it.
    • Dodge Active Window: The dock hides only when the currently focused window overlaps its space.
    • Window Dodge: The dock hides if any window covers it, regardless of focus.
  • Hide/Unhide Delays: Fine-tune the timer in milliseconds to prevent accidental triggers when moving the mouse past the dock edge.
  • Lock Icons: Toggle this on to prevent items from being accidentally moved, dragged off, or deleted from the dock.
  • Restrict to Display: If using multiple monitors, select which screen displays the dock.

Managing Docklets

Plank includes several lightweight widgets called "Docklets." To manage them, go to the Docklets tab in the Preferences window:

  1. Browse the available docklets, which typically include Clippy (clipboard manager), Clock, Desktop (minimize-all shortcut), Trash, and Battery.
  2. Double-click any docklet to immediately add it to your dock, or drag and drop it into your preferred position.
  3. To remove a docklet, drag it off the dock until an "X" or puff of smoke appears, then release the mouse button.

Pinning, Rearranging, and Removing Applications

Managing everyday applications does not require opening the Preferences menu:

  • Pin an App: Launch an application from the Budgie menu. When its icon appears in the dock, right-click it and select Keep in Dock. You can also drag application shortcuts directly from the Budgie application menu onto Plank.
  • Rearrange Icons: Click and drag any icon horizontally (or vertically) to reposition it.
  • Unpin an App: Right-click the application icon on the dock and uncheck Keep in Dock, or click and drag the icon away from the dock into empty desktop space until it dissolves.

Adding Third-Party Themes

To install custom themes:

  1. Download a Plank theme archive from your chosen desktop customization site.
  2. Extract the theme folder.
  3. Open your file manager, press Ctrl + H to reveal hidden files, and navigate to ~/.local/share/plank/themes (create the directory if it does not exist).
  4. Paste the extracted theme folder into this directory.
  5. Reopen Plank Preferences and select your new theme from the Theme dropdown.
