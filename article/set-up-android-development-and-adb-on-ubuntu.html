Set Up Android Development and ADB on Ubuntu

This guide provides a comprehensive, step-by-step walkthrough for configuring a complete Android development environment on Ubuntu. You will learn how to install the required Java Development Kit (JDK), set up Android Studio and the Android SDK, install the Android Debug Bridge (ADB) command-line utilities, configure necessary environment variables, and set up system permissions to debug physical devices via USB.

1. Update the System and Install Dependencies

Open your terminal and ensure your package lists and installed packages are up to date:

sudo apt update && sudo apt upgrade -y

Install the essential 32-bit libraries and core utilities required by the Android SDK and emulators:

sudo apt install -y openjdk-17-jdk libc6:i386 libncurses5:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386

Verify your Java installation:

java -version

2. Install ADB and Fastboot

If you only require the debugging tools without the full IDE, or want standalone CLI access, install the platform tools package directly from the Ubuntu repositories:

sudo apt install -y adb fastboot

Verify the installation:

adb version

3. Install Android Studio

The most straightforward method to install Android Studio on Ubuntu is using the official Snap package:

sudo snap install android-studio --classic

Alternatively, download the official tarball from the Android developer website, extract it to /opt/, and run bin/studio.sh.

Once installed, launch Android Studio:

android-studio

Follow the Setup Wizard to download the latest Android SDK, Android SDK Platform-Tools, and build-essential tools.

4. Configure Environment Variables

To run SDK tools from any terminal session, configure your environment paths. Open your ~/.bashrc file in a text editor:

nano ~/.bashrc

Add the following lines to the end of the file:

export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin

Apply the changes to your current session:

source ~/.bashrc

5. Configure USB Debugging (udev Rules)

Ubuntu requires proper udev rules to recognize physical Android devices connected via USB without root permissions.

Install the community-maintained udev rules package:

sudo apt install -y android-sdk-platform-tools-common

If your device is still not recognized, add a generic rule file:

sudo curl -o /etc/udev/rules.d/51-android.rules https://raw.githubusercontent.com/M0Rf30/android-udev-rules/master/51-android.rules
sudo chmod a+r /etc/udev/rules.d/51-android.rules

Reload the udev service to apply the rules:

sudo udevadm control --reload-rules
sudo systemctl restart udev

6. Enable USB Debugging on Your Device and Verify

  1. On your Android device, navigate to Settings > About Phone and tap Build Number seven times to enable Developer Options.
  2. Go to Settings > System > Developer Options and enable USB Debugging.
  3. Connect your device to your Ubuntu PC with a USB cable.
  4. Restart the ADB server:
adb kill-server
adb start-server
  1. Check for connected devices:
adb devices

A prompt will appear on your Android device screen requesting permission to allow USB debugging from your computer's RSA key fingerprint. Select Always allow from this computer and tap Allow.

Run adb devices again. The output should display your device serial number followed by the state device, indicating that your development environment is fully operational.
