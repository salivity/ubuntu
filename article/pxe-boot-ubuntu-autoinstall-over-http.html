PXE Boot Ubuntu Autoinstall Over HTTP

This article explains how to host and deliver automated Ubuntu installation configuration files to network-booted systems using an HTTP web server. Modern Ubuntu Server releases (20.04 and newer) utilize the Subiquity installer and Cloud-Init to handle hands-off deployments. By configuring a local web server to host user-data and meta-data files and pointing your PXE bootloader to their URL, you can achieve fully unattended, automated operating system installations across your network.

1. Prepare the Autoinstall Files

The Ubuntu installer requires at least two Cloud-Init files: user-data and meta-data.

Create a dedicated directory to store the configuration files:

mkdir -p /var/www/html/autoinstall

Create the user-data file. This file contains the Subiquity configuration directives. It must start with #cloud-config:

#cloud-config
autoinstall:
  version: 1
  locale: en_US.UTF-8
  keyboard:
    layout: us
  identity:
    hostname: ubuntu-server
    username: ubuntu
    password: "$6$rounds=4096$salt$encryptedpasswordstring"
  ssh:
    install-server: true
    authorized-keys:
      - ssh-rsa AAAAB3NzaC1yc2E... user@admin
  storage:
    layout:
      name: direct

Create an empty meta-data file in the same directory:

touch /var/www/html/autoinstall/meta-data

Cloud-Init requires meta-data to exist, even if it contains no directives.

2. Host the Files on an HTTP Server

Install and configure a web server, such as Nginx or Apache, to make these files accessible over your local network.

For Nginx:

sudo apt update
sudo apt install nginx -y

Place the files in /var/www/html/autoinstall/ and verify that proper file permissions are set:

sudo chmod -R 755 /var/www/html/autoinstall

Test access to the files from another machine on the network using curl:

curl http://<SERVER_IP>/autoinstall/user-data

If the file content is returned, the files are ready for PXE delivery.

3. Update the PXE Boot Configuration

To instruct the booting Ubuntu kernel to read the autoinstall files from your HTTP server, supply the autoinstall and ds=nocloud-net kernel arguments in your PXE configuration.

Using GRUB (UEFI PXE)

Add the target URL to the linux line in your grub.cfg:

menuentry "Ubuntu Autoinstall" {
    set gfxpayload=keep
    linux /vmlinuz ip=dhcp url=http://<SERVER_IP>/ubuntu-live-server.iso autoinstall ds=nocloud-net\;s=http://<SERVER_IP>/autoinstall/ ---
    initrd /initrd
}

Note: In GRUB, the semicolon must be escaped with a backslash (\;).

Using iPXE

In your iPXE script, pass the arguments directly via the boot command:

#!ipxe
kernel http://<SERVER_IP>/vmlinuz ip=dhcp url=http://<SERVER_IP>/ubuntu-live-server.iso autoinstall ds=nocloud-net;s=http://<SERVER_IP>/autoinstall/ ---
initrd http://<SERVER_IP>/initrd
boot

Important Path Requirements

The s= parameter specifies the base directory. It must end with a trailing forward slash (/). The Subiquity installer automatically appends user-data and meta-data to this base path when fetching the files.

4. Boot and Validate

Initiate a PXE network boot on the target system. The bootloader will:

  1. Retrieve the kernel (vmlinuz) and initial RAM disk (initrd).
  2. Boot into the live environment and configure the network using DHCP.
  3. Fetch the configuration from http://<SERVER_IP>/autoinstall/user-data and http://<SERVER_IP>/autoinstall/meta-data.
  4. Execute the automated installation based on the rules specified in your user-data file.
