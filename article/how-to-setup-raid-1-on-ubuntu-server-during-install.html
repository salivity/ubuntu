How to Setup RAID 1 on Ubuntu Server During Install

Setting up a RAID 1 mirror array during the Ubuntu Server installation provides real-time data redundancy by mirroring content across two storage drives. This step-by-step guide walks you through navigating the official Ubuntu Server Subiquity installer, configuring custom storage layouts, creating a software RAID 1 array (mdadm), and mapping file system mount points to ensure your server can survive a single disk failure without data loss.

System Requirements and Preparation

Before starting the installation, ensure your system meets the following criteria:

  • Two physical drives of equal capacity (or larger) connected to the system.
  • A bootable USB drive containing the Ubuntu Server ISO.
  • A system configured to boot in UEFI mode (recommended).

Step-by-Step RAID 1 Configuration Guide

Step 1: Reach the Storage Layout Screen

  1. Boot your machine using the Ubuntu Server installation media.
  2. Select your language, keyboard layout, and network settings.
  3. Proceed through the installer until you reach the Guided storage configuration screen.

Step 2: Switch to Custom Storage Layout

  1. On the Guided storage configuration screen, select Custom storage layout.
  2. Select Done to proceed to the main partitioning interface.

Step 3: Prepare the Boot Partitions

Modern UEFI systems require dedicated boot partitions on the physical disks before creating a software RAID array for the operating system.

  1. Locate the first physical disk under the AVAILABLE DEVICES list.
  2. Select the free space on the first disk and choose Add GPT Partition.
  3. Create an EFI System Partition:
    • Size: 1G (or standard 512M)
    • Format: boot (fat32) or EFI System Partition
  4. Repeat the process for the second physical disk to ensure both drives contain a boot partition for redundant booting.

Step 4: Create Partitions for RAID

  1. Select the remaining free space on the first physical disk.
  2. Choose Add GPT Partition.
  3. Leave the Size field blank (to use all available remaining space) and leave the format unformatted, or set it as Leave unformatted.
  4. Repeat this step for the remaining free space on the second physical disk.

Step 5: Create the Software RAID 1 Array

  1. Scroll down to the AVAILABLE DEVICES section and select Create software RAID (md).
  2. In the configuration prompt:
    • Name: Leave as default (e.g., md0) or assign a custom name.
    • RAID Level: Select RAID 1 (mirror).
    • Devices: Select the unformatted partitions created on both drives in Step 4.
  3. Choose Save to initialize the RAID 1 array.

Step 6: Format and Mount the RAID Volume

  1. Locate the newly created RAID device (e.g., md0 or md/0) under the USED DEVICES section.
  2. Select the RAID device and choose Add Partition (or select Format depending on the specific installer sub-menu).
  3. Set the filesystem parameters:
    • Format: ext4
    • Mount: / (root directory)
  4. Select Save.

Step 7: Finalize Installation

  1. Review the final partition layout summary to ensure /boot/efi resides on a physical disk and / resides on the software RAID array.
  2. Select Done, then confirm the operation by selecting Continue.
  3. Complete the remaining steps (entering username, password, SSH options, and system packages).
  4. Once installation completes, remove the installation media and reboot the system into your new software RAID 1 Ubuntu Server installation.
