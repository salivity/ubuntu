How to Verify Ubuntu ISO Checksum GPG Signature

Verifying the GPG signature of an official Ubuntu release checksum file ensures that the downloaded ISO image is genuine, unaltered, and originated directly from Canonical. This guide outlines the step-by-step process of acquiring the official verification files, importing Canonical's official GPG signing keys, and executing the terminal commands required to confirm the cryptographic signature of the checksum file.

Step 1: Download the Verification Files

Alongside the Ubuntu .iso image, you must download the cryptographic checksum file and its detached signature file from the official Ubuntu release mirror. Download the following two files into the same directory as your ISO:

  • SHA256SUMS (contains the expected hash values for the images)
  • SHA256SUMS.gpg (contains the GPG digital signature)

Step 2: Retrieve the Ubuntu Signing Keys

Ubuntu signs its checksum files using dedicated GPG keys managed by Canonical. To verify the signature, import these public keys to your local GPG keyring using the Ubuntu keyserver.

Open a terminal and run:

gpg --keyid-format long --keyserver hkp://keyserver.ubuntu.com --recv-keys 0xD94AA3F0EFE21092 0xC5986B4F1257FA86

These key fingerprints belong to:

  • Ubuntu CD Image Signing Key (2012): 8439 38DF 228D 22F7 B374 2BC0 D94A A3F0 EFE2 1092
  • Ubuntu CD Image Signing Key (Ubuntu QA): CD46 B182 1F54 27CE 0AC8 0009 F118 2E85 4135 2D0E

Step 3: Verify the Checksum File Signature

Navigate to the directory containing both SHA256SUMS and SHA256SUMS.gpg, then run:

gpg --keyid-format long --verify SHA256SUMS.gpg SHA256SUMS

Step 4: Inspect the Output

Review the output returned by GPG:

  1. Successful Verification: Look for the line stating: 
    gpg: Good signature from "Ubuntu Image Signing Service <cdimage@ubuntu.com>"
  2. Key Fingerprint: Confirm that the primary key fingerprint displayed matches the official Canonical keys downloaded in Step 2.
  3. Trust Warning: You may see a warning such as WARNING: This key is not certified with a trusted signature!. This is expected unless you have explicitly configured a local Web of Trust path to the Canonical key; it simply means GPG cannot verify who owns the key through your personal trust network, but the mathematical signature is still valid.

Step 5: Verify the ISO File

Once the SHA256SUMS file is confirmed authentic, test your downloaded ISO against the validated checksum:

sha256sum --ignore-missing -c SHA256SUMS

If the terminal outputs OK next to your ISO file's name, the installation media is fully verified and safe to use.
