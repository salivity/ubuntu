How to Configure IPsec VPN with strongSwan on Ubuntu

Configuring an IPsec VPN using strongSwan on Ubuntu creates a secure, encrypted tunnel for network traffic, ideal for remote workers or connecting distant networks. This guide walks you through the step-by-step process of installing strongSwan, setting up a Public Key Infrastructure (PKI) with X.509 certificates, configuring the VPN server settings, enabling IP forwarding, and starting the IPsec service.

Step 1: Update System Packages and Install strongSwan

First, update your package list and install strongSwan along with its PKI tools and additional plugins.

sudo apt update
sudo apt install strongswan strongswan-pki libcharon-extra-plugins libcharon-ext-auth-plugins -y

Step 2: Create a Certificate Authority (CA)

strongSwan uses certificates to authenticate the server and clients. Begin by creating a directory to store the certificates and generating a private key for the CA.

mkdir -p ~/pki/cacerts ~/pki/certs ~/pki/private
chmod 700 ~/pki

# Generate the CA private key
ipsec pki --gen --type rsa --size 4096 --outform pem > ~/pki/private/ca-key.pem

# Generate the self-signed CA certificate
ipsec pki --self --ca --lifetime 3650 --in ~/pki/private/ca-key.pem --type rsa --dn "CN=VPN CA" --outform pem > ~/pki/cacerts/ca-cert.pem

Step 3: Generate the Server Certificate

Next, create the server's private key and issue a certificate signed by your new CA. Replace your_server_domain_or_IP with your server's actual IP address or domain name.

# Generate server private key
ipsec pki --gen --type rsa --size 4096 --outform pem > ~/pki/private/server-key.pem

# Issue server certificate
ipsec pki --issue --lifetime 1825 \
  --cacert ~/pki/cacerts/ca-cert.pem \
  --cakey ~/pki/private/ca-key.pem \
  --in ~/pki/private/server-key.pem \
  --dn "CN=your_server_domain_or_IP" \
  --san "your_server_domain_or_IP" \
  --flag serverAuth --flag ikeIntermediate \
  --outform pem > ~/pki/certs/server-cert.pem

Copy the generated certificates to the system-wide strongSwan directory:

sudo cp ~/pki/cacerts/ca-cert.pem /etc/ipsec.d/cacerts/
sudo cp ~/pki/certs/server-cert.pem /etc/ipsec.d/certs/
sudo cp ~/pki/private/server-key.pem /etc/ipsec.d/private/

Step 4: Configure strongSwan (ipsec.conf)

Back up the default configuration file and open /etc/ipsec.conf in a text editor.

sudo mv /etc/ipsec.conf /etc/ipsec.conf.bak
sudo nano /etc/ipsec.conf

Add the following configuration:

config setup
    charondebug="ike 1, knl 1, cfg 0"
    uniqueids=no

conn %default
    keyexchange=ikev2
    ike=aes256-sha256-modp3072!
    esp=aes256-sha256!
    dpdaction=clear
    dpddelay=300s
    rekey=no

conn ikev2-vpn
    auto=add
    compress=no
    type=tunnel
    left=%any
    leftid=@your_server_domain_or_IP
    leftcert=server-cert.pem
    leftsendcert=always
    leftsubnet=0.0.0.0/0
    right=%any
    rightid=%any
    rightauth=eap-mschapv2
    rightsourceip=10.10.10.0/24
    rightdns=8.8.8.8,8.8.4.4
    eap_identity=%identity

Step 5: Configure Authentication (ipsec.secrets)

Edit the /etc/ipsec.secrets file to link the server private key and define user credentials for client connections.

sudo nano /etc/ipsec.secrets

Add the server private key reference and user credentials:

: RSA server-key.pem
vpnuser : EAP "YourSecurePasswordHere"

Step 6: Enable Packet Forwarding and Firewall NAT

To allow connected clients to route traffic through the server, enable IPv4 packet forwarding.

sudo nano /etc/sysctl.conf

Uncomment or add this line:

net.ipv4.ip_forward=1

Apply the changes:

sudo sysctl -p

Configure UFW (Uncomplicated Firewall) to allow IPsec traffic and handle NAT routing:

sudo ufw allow 500/udp
sudo ufw allow 4500/udp

Identify your public network interface using ip route show default (e.g., eth0), then edit /etc/ufw/before.rules:

sudo nano /etc/ufw/before.rules

Add the following lines at the top of the file before the *filter block (replace eth0 with your actual network interface):

*nat
:POSTROUTING ACCEPT [0:0]
-A POSTROUTING -s 10.10.10.0/24 -o eth0 -j MASQUERADE
COMMIT

Restart UFW to apply the rules:

sudo ufw disable
sudo ufw enable

Step 7: Restart strongSwan Service

Restart strongSwan to load all new configurations and certificates:

sudo systemctl restart strongswan-starter
sudo systemctl enable strongswan-starter

Verify that the service is active and running:

sudo ipsec status
