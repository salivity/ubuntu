Expand QCOW2 Virtual Disk Size in Ubuntu KVM

Expanding a QCOW2 virtual disk image for an Ubuntu KVM guest involves two phases: resizing the underlying .qcow2 image file on the host machine using qemu-img, and then extending the partition and filesystem from within the Ubuntu guest. This guide covers how to safely increase the virtual storage capacity on the host and apply those changes to standard partitions or LVM volumes inside the guest system.

Step 1: Shut Down the Virtual Machine

Before modifying the virtual disk, power down the virtual machine to prevent data corruption:

sudo virsh shutdown <vm-name>

Verify that the VM has stopped:

sudo virsh domstate <vm-name>

Step 2: Resize the QCOW2 Image on the Host

Identify the full path to your VM's .qcow2 file. Use the qemu-img command to add the desired amount of storage (for example, adding 20 gigabytes):

sudo qemu-img resize /path/to/disk.qcow2 +20G

You can confirm the new virtual size with:

sudo qemu-img info /path/to/disk.qcow2

Step 3: Start the Guest Virtual Machine

Boot the VM back up and log into your Ubuntu system:

sudo virsh start <vm-name>

Step 4: Identify the Target Partition in the Guest

Inside the Ubuntu guest, list your block devices to confirm the virtual disk size increase and check the partition layout:

lsblk

You will see that the parent disk (typically /dev/vda or /dev/sda) reflects the new capacity, while the child partitions remain the old size.

Step 5: Expand the Partition

Install the cloud-guest-utils package, which contains the growpart tool:

sudo apt update && sudo apt install -y cloud-guest-utils

Run growpart to expand the target partition. Replace /dev/vda and 1 with your corresponding drive and partition number (note the space between the device and partition number):

sudo growpart /dev/vda 1

Step 6: Expand the Filesystem

Option A: Standard ext4 Filesystem

If your partition uses the standard ext4 filesystem, run:

sudo resize2fs /dev/vda1

Option B: XFS Filesystem

If your partition is formatted with XFS, expand it by targeting the mount point (e.g., /):

sudo xfs_growfs /

Option C: LVM (Logical Volume Manager)

If your Ubuntu installation uses LVM:

  1. Resize the Physical Volume: 
    sudo pvresize /dev/vda3
  2. Extend the Logical Volume to use all available space: 
    sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
  3. Resize the filesystem: 
    sudo resize2fs /dev/ubuntu-vg/ubuntu-lv

Step 7: Verify the New Disk Space

Confirm that the expanded capacity is active and recognized by the operating system:

df -h
