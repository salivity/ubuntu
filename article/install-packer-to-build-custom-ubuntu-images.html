Install Packer to Build Custom Ubuntu Images

Automating the creation of custom machine images streamlines infrastructure deployment across cloud and on-premises environments. This guide walks you through the step-by-step process of installing HashiCorp Packer on an Ubuntu system, enabling you to build automated, reproducible, and standardized Ubuntu machine images using code.

Step 1: Update Your System and Install Prerequisites

Ensure your local system package list is up to date and that the required utility packages for managing repositories and keys over HTTPS are installed.

sudo apt-get update
sudo apt-get install -y gnupg software-properties-common curl

Step 2: Add the HashiCorp GPG Key

To ensure the integrity of the downloaded packages, add the official HashiCorp GPG key to your system's keyring:

curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg

Step 3: Add the Official HashiCorp Repository

Add the HashiCorp APT repository to your package sources list. This command uses your system's release codename dynamically to configure the correct repository:

echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list

Step 4: Install Packer

Update the package index to include the packages from the newly added HashiCorp repository, then install Packer:

sudo apt-get update
sudo apt-get install -y packer

Step 5: Verify the Installation

Confirm that Packer has been successfully installed and is available in your system path by checking its version:

packer --version

If the installation succeeded, the terminal will display the installed version number.

Using Packer to Automate Custom Ubuntu Images

With Packer installed, you can automate custom Ubuntu images using HashiCorp Configuration Language (HCL). The core workflow involves:

  1. Defining a Template: Create a .pkr.hcl file that specifies your target platform (such as AWS, Azure, GCP, or local hypervisors like QEMU/VirtualBox) and base Ubuntu ISO or source image.
  2. Adding Provisioners: Define shell scripts, Ansible playbooks, or file transfers inside the template to install packages, apply security baselines, and configure application dependencies on top of the base image.
  3. Initializing Plugins: Run packer init <filename>.pkr.hcl to install any required platform plugins.
  4. Validating the Configuration: Run packer validate <filename>.pkr.hcl to ensure proper syntax and structure.
  5. Building the Image: Execute packer build <filename>.pkr.hcl to automatically launch an instance, apply your configurations, capture the custom image, and clean up temporary resources.
