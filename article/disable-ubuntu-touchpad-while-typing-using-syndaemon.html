Disable Ubuntu Touchpad While Typing Using Syndaemon

Accidental palm touches on a laptop touchpad can cause the cursor to jump and interrupt your typing workflow in Ubuntu. The syndaemon utility solves this problem by monitoring keyboard activity and temporarily disabling the touchpad while you type. This guide explains how to use syndaemon from the terminal, customize its delay settings, and set it up to run automatically every time your system starts.

How Syndaemon Works

syndaemon is a background program for systems using the Synaptics touchpad driver. It detects keypresses and disables touchpad input for a specified duration after the last key is pressed.

The Basic Command Structure

To start syndaemon, open your terminal (Ctrl+Alt+T) and run the following command:

syndaemon -i 1 -k -d

Explanation of Command Options:

  • -i 1: Specifies the idle time in seconds. In this case, the touchpad remains disabled for 1 second after you stop typing. You can change this to a lower value like 0.5 for faster re-activation.
  • -k: Ignores modifier keys (such as Ctrl, Alt, or Shift) so that keyboard shortcuts do not trigger the touchpad lock.
  • -d: Runs the command in the background as a daemon process, returning control to your terminal.

If you want to disable tapping and scrolling only, rather than all touchpad movements, add the -t flag:

syndaemon -i 0.8 -t -k -d

How to Run Syndaemon Automatically at Startup

To ensure touchpad palm rejection works every time you log into Ubuntu, add syndaemon to your Startup Applications.

  1. Open the application launcher and search for Startup Applications.
  2. Click Add to create a new startup entry.
  3. Fill out the fields as follows:
    • Name: Disable Touchpad While Typing
    • Command: syndaemon -i 0.7 -k -d
    • Comment: Disables touchpad for 0.7 seconds after keypresses.
  4. Click Add and close the window.

How to Stop or Kill Syndaemon

If you need to stop the background process or adjust its settings, terminate the running instance using killall:

killall syndaemon

After killing the process, you can rerun the command with updated time parameters to find the delay setting that best fits your typing speed.
