How to Schedule a One-Time Task with at in Ubuntu

The at command in Ubuntu is a command-line utility used to schedule one-time background tasks to run at a specific time in the future. Unlike cron, which is intended for recurring schedules, at executes a command or script once and then removes it from the queue. This guide covers how to install the at package, schedule one-time commands, specify custom execution times, and manage your scheduled job queue.

Installing the at Command in Ubuntu

The at utility is not always installed by default on Ubuntu systems. To install it along with its daemon (atd), run the following commands in your terminal:

sudo apt update
sudo apt install at

Ensure the service is active and set to start automatically on boot:

sudo systemctl enable --now atd

How to Use the at Command

To schedule a task, pass the target time as an argument to the at command. This opens an interactive prompt where you can enter the commands you wish to execute.

Basic Syntax

at [time]

Press Ctrl + D to save the job and exit the interactive shell prompt.

Scheduling Tasks via the Interactive Shell

To run an update script at 4:30 PM:

at 16:30

Upon running the command, enter your script or commands:

warning: commands will be executed using /bin/sh
at> bash /home/user/backup.sh
at> <EOT> (pressed Ctrl + D)

Scheduling Tasks in a Single Line

You can bypass the interactive prompt by piping a command directly into at:

echo "sh /home/user/script.sh" | at 14:30

Or by referencing a script file directly:

at 14:30 -f /home/user/script.sh

Common Time Formats

The at utility accepts various flexible time specifications:

  • Specific time today or tomorrow: at 08:30 AM or at 23:15
  • Relative time: at now + 10 minutes, at now + 2 hours, at now + 3 days
  • Exact dates: at 10:00 AM Jul 25 or at 4:00 PM 12/31/2024
  • Keywords: at noon, at midnight, at teatime (4:00 PM)

Viewing and Managing Scheduled Tasks

View Queued Jobs

To list all pending one-time tasks for the current user, use the atq command or at -l:

atq

Output example:

3   Thu Jul 25 10:00:00 2024 a user

The first number (3) represents the unique Job ID.

View the Contents of a Scheduled Job

To view the commands associated with a specific Job ID:

at -c [job_id]

Remove a Scheduled Job

To cancel and delete a scheduled task, use the atrm command followed by the Job ID:

atrm 3
