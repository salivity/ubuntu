How to Scan a Local Network with arp-scan on Ubuntu

This guide demonstrates how to use arp-scan on an Ubuntu system to discover every active device connected to your local network segment. Unlike traditional ICMP ping sweeps, arp-scan sends raw Address Resolution Protocol (ARP) packets at the Data Link layer (Layer 2), allowing it to detect devices even if they have firewalls configured to drop standard ping requests. Below, you will find the exact steps to install the tool, identify your network interface, execute the scan, and read the resulting device list.

1. Install arp-scan

The arp-scan package is available in the default Ubuntu universe repositories. Open a terminal and run the following commands to update your package index and install the software:

sudo apt update
sudo apt install arp-scan -y

2. Identify Your Network Interface

ARP requests are restricted to the local broadcast domain, meaning you must specify which network adapter to scan through. List your available network interfaces by executing:

ip link

Look for your active network interface in the output. Common names include eth0, enp3s0 for wired Ethernet connections, or wlan0, wlp2s0 for Wi-Fi adapters.

3. Scan the Local Subnet

The simplest and most effective way to discover all connected devices is using the --localnet (or -l) parameter. This flag automatically derives the IP address and subnet mask from your chosen network interface and scans the entire valid range.

Run the scan using sudo, as generating raw ARP packets requires root privileges:

sudo arp-scan --interface=eth0 --localnet

Replace eth0 with the interface name you identified in the previous step.

If you only have one active network adapter, you can run the command without the --interface flag, and arp-scan will automatically pick the lowest-numbered active interface:

sudo arp-scan --localnet

4. Scan a Specific IP Range or Subnet

If you only want to scan a designated subnet or a subset of IP addresses rather than the entire local network, replace the --localnet flag with a CIDR notation block or an IP range:

sudo arp-scan --interface=eth0 192.168.1.0/24

To target a specific range of addresses:

sudo arp-scan --interface=eth0 192.168.1.50-192.168.1.100

5. Interpret the Results

Once the scan completes, arp-scan displays a report in three columns:

  • IP Address: The network layer address assigned to the device.
  • MAC Address: The unique hardware address of the device's network card.
  • Vendor String: The manufacturer of the network interface card, determined by matching the MAC address Organizationally Unique Identifier (OUI) against the local database.

The final summary line displays the total number of packets sent, the duration of the scan, and the total number of responsive hosts found on the segment.
