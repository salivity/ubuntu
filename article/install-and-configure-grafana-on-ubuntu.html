Install and Configure Grafana on Ubuntu

This guide provides a straightforward overview of installing and configuring the Grafana visualization tool on an Ubuntu server. You will learn how to add the official Grafana repository, install the package using the APT package manager, manage the systemd service, adjust firewall settings, and complete the initial web interface setup.

Prerequisites

  • An Ubuntu server (20.04 or 22.04 recommended)
  • A user account with sudo privileges

Step 1: Install Required Dependencies

Update your local package index and install the necessary helper packages:

sudo apt update
sudo apt install -y apt-transport-https software-properties-common wget

Step 2: Add the Grafana GPG Key and Repository

Import the official Grafana GPG key to verify the package authenticity:

sudo mkdir -p /etc/apt/keyrings/
wget -q -O - https://apt.grafana.com/gpg.key | gpg --dearmor | sudo tee /etc/apt/keyrings/grafana.gpg > /dev/null

Next, add the stable Grafana repository to your APT sources:

echo "deb [signed-by=/etc/apt/keyrings/grafana.gpg] https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list

Step 3: Install Grafana

Update your package list to include the newly added repository, then install Grafana:

sudo apt update
sudo apt install -y grafana

Step 4: Start and Enable the Grafana Service

Start the Grafana service and configure it to launch automatically upon system boot:

sudo systemctl start grafana-server
sudo systemctl enable grafana-server

Verify that the service is running properly:

sudo systemctl status grafana-server

Step 5: Configure the Firewall

Grafana runs on port 3000 by default. If UFW firewall is enabled on your Ubuntu server, allow incoming traffic on port 3000:

sudo ufw allow 3000/tcp
sudo ufw reload

Step 6: Access the Grafana Web Interface

  1. Open your web browser and navigate to http://your_server_ip:3000.
  2. Log in using the default credentials:
    • Username: admin
    • Password: admin
  3. Prompts will immediately ask you to set a new, secure password.

Step 7: Basic Configuration Settings (Optional)

Grafana's primary configuration file is located at /etc/grafana/grafana.ini.

To modify settings such as the HTTP port, domain name, or database configuration, open the file in a text editor:

sudo nano /etc/grafana/grafana.ini

Common modifications include:

  • HTTP Port: Change http_port = 3000 under the [server] block to your preferred port.
  • Domain: Change domain = localhost to your server's domain name or public IP.

If you make any changes to grafana.ini, restart the service to apply them:

sudo systemctl restart grafana-server
