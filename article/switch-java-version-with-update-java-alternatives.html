Switch Java Version with update-java-alternatives

This article explains how to change the active Java Development Kit (JDK) or Java Runtime Environment (JRE) version in Ubuntu using the update-java-alternatives tool. You will learn the exact syntax to identify all installed Java versions on your system, execute the switch command, and verify that the system-wide Java path points to your desired version.

Step 1: List Installed Java Environments

Before switching versions, you must view the exact name of the installed Java packages registered with the system. Run the following command in your terminal:

update-java-alternatives --list

This output displays the installed Java environments in three columns: the package alias, priority number, and the path to the installation directory. For example:

java-1.11.0-openjdk-amd64      1111       /usr/lib/jvm/java-1.11.0-openjdk-amd64
java-1.17.0-openjdk-amd64      1711       /usr/lib/jvm/java-1.17.0-openjdk-amd64

Step 2: Switch the Active Java Version

The command to switch the active Java environment version using update-java-alternatives is --set (or -s), followed by the exact name of the target Java alternative from the list.

Run the command with administrative privileges:

sudo update-java-alternatives --set <name>

For example, to switch your active environment to OpenJDK 17 using the alias from the previous list:

sudo update-java-alternatives --set java-1.17.0-openjdk-amd64

Unlike configuring individual binaries with update-alternatives, update-java-alternatives simultaneously updates symbolic links for all associated Java executables, including java, javac, javadoc, and jar.

Step 3: Verify the Changes

Verify that the active Java version has been updated across your system by checking the runtime and compiler versions:

java -version
javac -version

The output will reflect the new default Java version you selected.
