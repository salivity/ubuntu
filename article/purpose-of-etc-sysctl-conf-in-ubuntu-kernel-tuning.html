Purpose of /etc/sysctl.conf in Ubuntu Kernel Tuning

The /etc/sysctl.conf file in Ubuntu serves as a centralized configuration file for tweaking Linux kernel parameters at runtime. It allows system administrators to adjust settings related to network performance, memory management, file systems, and system security persistently across reboots. By modifying this file, users can optimize server performance and enhance system security without needing to recompile the kernel or reconfigure parameters manually on every system startup.

Understanding /etc/sysctl.conf

The Linux kernel exposes various configurable settings through a virtual filesystem located at /proc/sys/. While you can change these parameters temporarily using the sysctl command or by writing directly to files within /proc/sys/, those changes revert to default values when the system restarts.

The /etc/sysctl.conf file acts as a permanent configuration store. During the boot process, Ubuntu reads /etc/sysctl.conf (along with supplemental files in /etc/sysctl.d/) and automatically applies the specified key-value pairs to the running kernel.

Primary Functions and Use Cases

Modifying /etc/sysctl.conf allows you to tailor the operating system to specific workloads, such as web hosting, database management, or network routing.

Network Performance and Security

  • Enable IP Forwarding: Essential for system configurations operating as routers, gateways, or Docker hosts. net.ipv4.ip_forward = 1
  • SYN Flood Protection: Enhances defense against denial-of-service (DoS) attacks by turning on TCP SYN cookies. net.ipv4.tcp_syncookies = 1
  • Disable Packet Redirects: Improves network security by ignoring ICMP redirect packets. net.ipv4.conf.all.accept_redirects = 0

Memory Management

  • Adjust Swappiness (vm.swappiness): Controls how aggressively the kernel moves memory pages into swap space. Lowering this value (for example, to 10) forces the system to keep application data in RAM longer, reducing disk I/O bottlenecks.
  • Manage Dirty Memory (vm.dirty_ratio): Controls the percentage of system memory that can hold unwritten disk blocks before forcing a write to disk.

System Hardening

  • Restrict Access to Kernel Logs: Prevents non-root users from viewing the dmesg buffer. kernel.dmesg_restrict = 1
  • Address Space Layout Randomization (ASLR): Ensures memory locations of program components are randomized to mitigate buffer overflow exploits. kernel.randomize_va_space = 2

Applying Changes to /etc/sysctl.conf

To update kernel parameters, follow these steps:

  1. Open the file in a text editor with superuser privileges: 
    sudo nano /etc/sysctl.conf
  2. Append or update the parameters using the parameter = value format.
  3. Save the file and exit.
  4. Load the changes into the active kernel immediately without rebooting: 
    sudo sysctl -p
