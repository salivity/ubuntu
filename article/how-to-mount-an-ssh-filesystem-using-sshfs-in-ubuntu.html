How to Mount an SSH Filesystem Using SSHFS in Ubuntu

This article provides a straightforward guide on how to install and use SSHFS (SSH Filesystem) to securely mount a remote directory onto your local Ubuntu system over an SSH connection. You will learn the commands required to install the necessary packages, create a local mount point, establish the SSHFS connection, verify the mounted filesystem, and safely unmount it when finished.

Prerequisites

Before starting, ensure you have: * An active Ubuntu system (local). * SSH access to a remote server with a valid username, IP address (or domain), and password/SSH key.

Step 1: Install SSHFS

Open your terminal and update your package list, then install the sshfs package using apt:

sudo apt update
sudo apt install sshfs

Step 2: Create a Local Mount Point

Create a directory on your local Ubuntu machine where the remote directory will be mounted:

mkdir -p ~/remote_mount

Step 3: Mount the Remote Filesystem

To mount the remote directory, use the sshfs command followed by the remote user, server address, remote path, and local mount point.

Using Password Authentication

sshfs username@remote_host:/path/to/remote/dir ~/remote_mount

Replace username with your remote SSH username, remote_host with the IP address or domain of the remote server, /path/to/remote/dir with the directory path on the remote server, and ~/remote_mount with your local folder path. You will be prompted to enter your SSH password.

Using SSH Key Authentication

If your server uses an SSH key for authentication, specify the key path using the -o IdentityFile option:

sshfs -o IdentityFile=~/.ssh/id_rsa username@remote_host:/path/to/remote/dir ~/remote_mount

Step 4: Verify the Mount

You can verify that the remote directory is successfully mounted by listing the contents of your local mount directory:

ls -la ~/remote_mount

Alternatively, check the active mounts with the df command:

df -h T | grep sshfs

Step 5: Unmount the SSH Filesystem

When you are done working with the remote files, unmount the filesystem using the fusermount command:

fusermount -u ~/remote_mount
