How to Install Boto3 for Ansible on Ubuntu

This article explains how to install the AWS boto3 Python library on Ubuntu to enable Ansible's AWS modules and collections. You will learn the direct commands required to install boto3 using Ubuntu's package manager and Python's package installer, along with verification steps to ensure Ansible can communicate with Amazon Web Services.

Prerequisites

Ansible relies on the AWS SDK for Python (boto3 and botocore) to manage AWS infrastructure. These libraries must be installed on the Ubuntu control node (or target host executing the tasks locally) under the same Python environment that Ansible uses.

Method 1: Install via APT (Recommended for System Python)

The cleanest and most stable command to install boto3 system-wide on modern Ubuntu releases (such as Ubuntu 22.04 and 24.04) without conflicting with PEP 668 constraints is using apt:

sudo apt update && sudo apt install -y python3-boto3

This installs both boto3 and its required dependency, botocore, from official Ubuntu repositories.

Method 2: Install via Pip

If you run Ansible inside a Python virtual environment or manage Python packages via pip, run the following command:

pip3 install boto3 botocore

If you are on Ubuntu 23.04 or later and not using a virtual environment, pip requires the --break-system-packages flag to modify system libraries:

pip3 install boto3 botocore --break-system-packages

Verify the Installation

To verify that boto3 is properly installed and accessible to Python, run:

python3 -c "import boto3; print(boto3.__version__)"

To ensure Ansible uses the specific Python interpreter containing boto3, set the interpreter path in your inventory file or ansible.cfg:

[all:vars]
ansible_python_interpreter=/usr/bin/python3
