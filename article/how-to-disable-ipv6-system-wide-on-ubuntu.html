How to Disable IPv6 System-Wide on Ubuntu

Disabling IPv6 on an Ubuntu machine can resolve specific networking conflicts, improve connection speeds on IPv4-only networks, and simplify firewall management. This article provides a clear, step-by-step guide on how to permanently disable IPv6 system-wide using the sysctl configuration or through the GRUB bootloader.

Method 1: Disable IPv6 Using Sysctl (Recommended)

Modifying the sysctl kernel parameters is the safest and standard way to turn off IPv6.

Step 1: Open the Sysctl Configuration File

Open your terminal and edit the /etc/sysctl.conf file with administrative privileges:

sudo nano /etc/sysctl.conf

Step 2: Add IPv6 Disable Lines

Scroll to the bottom of the file and insert the following lines:

net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv6.conf.lo.disable_ipv6 = 1

Save the file (Ctrl + O, then press Enter) and exit the editor (Ctrl + X).

Step 3: Apply the Changes

Load the new settings immediately without rebooting:

sudo sysctl -p

Method 2: Disable IPv6 via GRUB Bootloader

If you want to ensure IPv6 is completely disabled at the kernel level during boot, you can modify the GRUB configuration.

Step 1: Open the GRUB Configuration File

Run the following command in your terminal:

sudo nano /etc/default/grub

Step 2: Modify Kernel Command Line

Locate the lines GRUB_CMDLINE_LINUX_DEFAULT and GRUB_CMDLINE_LINUX, then append ipv6.disable=1 to their parameter lists.

Example:

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash ipv6.disable=1"
GRUB_CMDLINE_LINUX="ipv6.disable=1"

Save and exit the file.

Step 3: Update GRUB and Reboot

Apply the changes to GRUB and restart your system:

sudo update-grub
sudo reboot

Verify IPv6 is Disabled

To confirm that IPv6 has been successfully disabled system-wide, run the following command:

ip a

If IPv6 is disabled, you will not see any inet6 entries in the command output. Alternatively, check the sysctl status directly:

cat /proc/sys/net/ipv6/conf/all/disable_ipv6

An output of 1 confirms that IPv6 is disabled.
