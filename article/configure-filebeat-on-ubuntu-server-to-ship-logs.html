Configure Filebeat on Ubuntu Server to Ship Logs

This guide outlines the step-by-step process for installing, configuring, and running Filebeat on an Ubuntu server to automatically harvest and ship system or application logs to Elasticsearch or Logstash.

Step 1: Install Filebeat

Import the Elastic signing key and add the official Elastic package repository to your system:

  1. Download and install the public signing key:

    wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elastic-keyring.gpg

  2. Save the repository definition:

    echo "deb [signed-by=/usr/share/keyrings/elastic-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list

  3. Update package indexes and install Filebeat:

    sudo apt-get update && sudo apt-get install filebeat

Step 2: Configure Log Inputs

Open the main Filebeat configuration file:

sudo nano /etc/filebeat/filebeat.yml

Locate the filebeat.inputs section. Set enabled to true and specify the file paths of the logs you want to collect:

filebeat.inputs:
- type: log
  enabled: true
  paths:
    - /var/log/*.log
    - /var/log/syslog
    - /var/log/auth.log

Step 3: Configure Output Destination

Scroll to the output section in /etc/filebeat/filebeat.yml to specify where logs should be sent. Configure either Elasticsearch or Logstash (only one output should be active at a time).

Route directly to Elasticsearch:

output.elasticsearch:
  hosts: ["https://<YOUR_ELASTICSEARCH_IP>:9200"]
  username: "elastic"
  password: "<YOUR_PASSWORD>"

Route to Logstash:

output.logstash:
  hosts: ["<YOUR_LOGSTASH_IP>:5044"]

Save and close the file.

Step 4: Enable Pre-Built Modules (Optional)

Filebeat provides modules with default configurations and dashboards for common technologies. To collect default Ubuntu system and authentication logs, enable the system module:

sudo filebeat modules enable system

Step 5: Test and Start Filebeat

  1. Test the configuration for syntax errors:

    sudo filebeat test config

  2. Verify connectivity to the designated output:

    sudo filebeat test output

  3. Enable Filebeat to launch on system boot and start the service:

    sudo systemctl enable --now filebeat

  4. Confirm that the service is running correctly:

    sudo systemctl status filebeat
