Setup Squid Transparent Proxy with iptables on Ubuntu

A transparent proxy intercepts standard client network requests at the gateway level, directing traffic through a caching or filtering service without requiring manual proxy configuration on individual client devices. This guide details how to install Squid, configure it for transparent interception mode, enable IP forwarding, and define iptables redirection rules on an Ubuntu server acting as a network gateway.

Step 1: Install Squid

Update the local package index and install the Squid package using the APT package manager:

sudo apt update
sudo apt install squid -y

Ensure the Squid service is running and enabled on boot:

sudo systemctl enable --now squid

Step 2: Configure Squid for Interception

Open the main Squid configuration file using a text editor:

sudo nano /etc/squid/squid.conf

Locate the http_port directive. By default, Squid listens on port 3128. Add a dedicated intercept port alongside the default port, and define an access control list (ACL) for your local network:

# Define your local network subnet
acl localnet src 192.168.1.0/24

# Allow access from local network
http_access allow localnet
http_access allow localhost
http_access deny all

# Default forward proxy port
http_port 3128

# Intercept port for transparent traffic
http_port 3129 intercept

Save the file and test the configuration syntax:

sudo squid -k parse

If no errors are returned, restart the Squid service:

sudo systemctl restart squid

Step 3: Enable IPv4 Packet Forwarding

To allow the Ubuntu machine to route traffic from internal clients to the internet, enable packet forwarding in the kernel.

Edit /etc/sysctl.conf:

sudo nano /etc/sysctl.conf

Uncomment or add the following line:

net.ipv4.ip_forward = 1

Apply the changes immediately:

sudo sysctl -p

Step 4: Configure iptables Redirection

Traffic arriving from the internal network destined for standard HTTP port 80 must be redirected to Squid's interception port (3129).

Assume the internal network interface connected to the LAN is eth1 and the external WAN interface is eth0. Run the following commands:

# Redirect HTTP traffic to Squid interception port
sudo iptables -t nat -A PREROUTING -i eth1 -p tcp --dport 80 -j REDIRECT --to-port 3129

# Enable NAT masquerading for WAN traffic
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE

# Allow established connections and forwarded traffic
sudo iptables -A FORWARD -i eth1 -o eth0 -j ACCEPT
sudo iptables -A FORWARD -i eth0 -o eth1 -m state --state RELATED,ESTABLISHED -j ACCEPT

Step 5: Make iptables Rules Persistent

By default, iptables rules are lost after a reboot. Install the persistence utility to save them permanently:

sudo apt install iptables-persistent -y
sudo netfilter-persistent save

Step 6: Verify the Setup

  1. Configure a client machine on the local subnet to use the Ubuntu server's LAN IP address as its default gateway.
  2. From the client, browse to any non-HTTPS website (http://example.com).
  3. Monitor Squid's access log on the Ubuntu server in real time:
sudo tail -f /var/log/squid/access.log

HTTP requests from the client should appear in the log file without any proxy settings configured on the client device.
