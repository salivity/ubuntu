How to USB Tether Smartphone Internet to Ubuntu

Sharing your smartphone's cellular data with an Ubuntu computer via a USB cable provides a stable, fast, and reliable internet connection when Wi-Fi is unavailable. This guide explains how to easily set up USB tethering on both Android and iOS devices to connect seamlessly to an Ubuntu system without requiring third-party software.

Setting Up USB Tethering on Android

  1. Connect the Cable: Plug your Android phone into your Ubuntu computer using a functional USB data cable.
  2. Open Settings: On your Android device, go to Settings.
  3. Navigate to Network Settings: Tap on Network & internet, Connections, or Wireless & Networks (the menu name varies by manufacturer).
  4. Enable Tethering: Select Hotspot & tethering and switch the toggle on for USB tethering.
  5. Verify Connection: Ubuntu will automatically detect the phone as a new wired ethernet interface. Look for the wired network icon in the top-right corner of your Ubuntu desktop to confirm the connection is active.

Setting Up USB Tethering on iPhone (iOS)

  1. Connect the Cable: Attach your iPhone to the Ubuntu machine using a Lightning or USB-C cable.
  2. Trust the Computer: Unlocking your iPhone screen will display a prompt asking to Trust This Computer?. Tap Trust and enter your device passcode.
  3. Enable Personal Hotspot: On your iPhone, open Settings > Personal Hotspot (or Settings > Cellular > Personal Hotspot).
  4. Allow Connection: Turn on Allow Others to Join.
  5. Verify Connection: Ubuntu includes native support for iOS network devices via usbmuxd. Your system will automatically establish a network connection within a few seconds.

Troubleshooting Tips

  • Check Cable Quality: Ensure you are using a data-transfer cable, as charging-only cables will not broadcast a network interface.
  • Network Settings in Ubuntu: If the internet does not automatically connect, open Settings > Network in Ubuntu, and check if an Ethernet device (such as usb0 or enp0s20f0u1) is listed and active.
  • Restart Network Services: If connection fails, open a terminal in Ubuntu and restart the network manager by running: 
    sudo systemctl restart NetworkManager
