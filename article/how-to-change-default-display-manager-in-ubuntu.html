How to Change Default Display Manager in Ubuntu

Changing the default login manager—also known as a display manager—in Ubuntu allows you to customize your graphical login screen and potentially improve system performance. Whether you want to switch from the default GDM3 to a lighter alternative like LightDM or SDDM, the process is straightforward and can be completed directly from the terminal using built-in package management tools. This guide covers how to install a new display manager, configure it as your default, and apply the changes.

Step 1: Install a New Display Manager

Before changing your default display manager, install the alternative you wish to use. Open your terminal (Ctrl+Alt+T) and run the command for your preferred manager:

  • For LightDM: sudo apt update && sudo apt install lightdm

  • For SDDM: sudo apt update && sudo apt install sddm

  • For GDM3 (Ubuntu Default): sudo apt update && sudo apt install gdm3

During installation, a configuration prompt may appear automatically asking you to choose a default. If it appears, select your manager and press Enter. If it does not appear, continue to Step 2.

Step 2: Reconfigure the Display Manager

If you already have multiple display managers installed, or if the prompt did not pop up during installation, manually open the selection menu by running:

sudo dpkg-reconfigure gdm3

(Note: You can substitute gdm3 with lightdm or sddm in this command; it opens the same selection interface.)

Step 3: Select Your Preferred Login Manager

  1. Read the informational prompt in the terminal window and press Enter.
  2. Use the arrow keys to highlight your desired display manager (e.g., gdm3, lightdm, or sddm).
  3. Press Enter to confirm your selection.

Step 4: Apply the Changes

Reboot your computer to apply the changes and launch the new login screen:

sudo reboot

Alternatively, you can restart the display service immediately without rebooting (ensure you save all open work first, as this will restart your graphical session):

sudo systemctl restart display-manager
