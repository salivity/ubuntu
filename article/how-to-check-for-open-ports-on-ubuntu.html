How to Check for Open Ports on Ubuntu

Checking for open ports on an Ubuntu machine is a critical task for system administration, network troubleshooting, and security auditing. Open ports indicate active services listening for incoming network traffic, which can present potential security vectors if left unmonitored. This guide covers the most efficient built-in commands and third-party tools—including ss, netstat, lsof, nmap, and ufw—to help you identify open, listening, and active ports on your Ubuntu system.

Method 1: Use the ss Command

The ss (socket statistics) tool is the modern, faster replacement for the legacy netstat utility. It comes pre-installed on almost all modern Ubuntu releases.

To view all open and listening TCP and UDP ports along with their corresponding processes, run:

sudo ss -tulpn

Command Flags Breakdown:

  • -t: Display TCP sockets.
  • -u: Display UDP sockets.
  • -l: Show listening sockets only.
  • -p: Show the process name and PID using the socket.
  • -n: Show numerical addresses and port numbers instead of resolving service names.

Look at the Local Address:Port column in the output to identify which ports are open and listening.

Method 2: Use the netstat Command

While netstat is considered deprecated in favor of ss, many users still prefer its traditional output formatting. If netstat is not installed on your system, you can install it via the net-tools package:

sudo apt update
sudo apt install net-tools

To list open ports using netstat:

sudo netstat -tulpn

The output will display active internet connections, showing the protocol (TCP/UDP), local address, port number, and the specific program listening on each port.

Method 3: Use the lsof Command

The lsof (list open files) command treats network sockets as files. It is particularly useful when you want to see which specific application or binary is binding to a port.

To display all open network ports and listening connections:

sudo lsof -i -P -n | grep LISTEN

Command Flags Breakdown:

  • -i: Restricts the output to network files/connections.
  • -P: Inhibits the conversion of port numbers to port names for faster output.
  • -n: Inhibits the conversion of network numbers to host names.
  • grep LISTEN: Filters the output to display only ports that are currently listening for incoming connections.

Method 4: Use nmap for Local Scanning

nmap is a powerful network exploration tool and security scanner. Scanning localhost using nmap gives a complete overview of open ports from a network perspective.

First, install nmap:

sudo apt update
sudo apt install nmap

Then, scan open ports on your local machine:

sudo nmap -sT -O localhost

To scan both TCP and UDP open ports, run:

sudo nmap -sTU localhost

Method 5: Check Open Ports via UFW Firewall

Ubuntu uses UFW (Uncomplicated Firewall) as its default firewall management tool. Checking your UFW status shows which ports are explicitly allowed to receive incoming traffic through the firewall.

Run the following command to check UFW status:

sudo ufw status verbose

If UFW is active, the output will list all rules along with allowed incoming ports (e.g., 22/tcp ALLOW IN, 80/tcp ALLOW IN). Note that a port might be open in the OS service layer (visible in ss), but blocked from external access if UFW is active and does not have an explicit rule for that port.
