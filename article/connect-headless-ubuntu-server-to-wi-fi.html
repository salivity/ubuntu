Connect Headless Ubuntu Server to Wi-Fi

Setting up a headless Ubuntu server to connect to a Wi-Fi network requires configuring Netplan, Ubuntu's default network management utility. Since a headless server lacks a graphical user interface, all network settings must be adjusted through the command-line interface by editing a YAML configuration file. This guide covers how to identify your wireless interface, configure your Wi-Fi credentials in Netplan, and apply the settings to establish a network connection.

Step 1: Identify Your Wireless Interface Name

Before configuring the network, you need the exact name of your wireless network interface.

  1. Run the following command: 
    ip link
  2. Look for an interface starting with wl, such as wlan0 or wlp2s0. Note down this name for the configuration step.

If the interface is down, you can bring it up temporarily to ensure it is recognized:

sudo ip link set wlan0 up

Step 2: Locate the Netplan Configuration File

Netplan configuration files are stored in the /etc/netplan/ directory.

  1. List the existing configuration files: 
    ls /etc/netplan/
  2. You will see a file with a .yaml extension, such as 01-netcfg.yaml, 50-cloud-init.yaml, or 00-installer-config.yaml.

If no file exists, you can create a new one:

sudo nano /etc/netplan/01-netcfg.yaml

Step 3: Edit the Netplan Configuration File

Open the configuration file in a text editor:

sudo nano /etc/netplan/01-netcfg.yaml

Add or modify the configuration to include your Wi-Fi details. Ensure proper YAML indentation (use spaces, not tabs):

network:
  version: 2
  renderer: networkd
  wifis:
    wlan0:
      dhcp4: true
      optional: true
      access-points:
        "YOUR_WIFI_SSID":
          password: "YOUR_WIFI_PASSWORD"
  • Replace wlan0 with your actual wireless interface name.
  • Replace YOUR_WIFI_SSID with your Wi-Fi network name (keep the quotation marks).
  • Replace YOUR_WIFI_PASSWORD with your Wi-Fi password (keep the quotation marks).

Save the file and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 4: Test and Apply the Configuration

  1. Test the new configuration for syntax errors without applying it permanently:

    sudo netplan try

    If there are no errors, press Enter to accept the changes.

  2. Apply the configuration:

    sudo netplan apply

Step 5: Verify the Wi-Fi Connection

  1. Check if an IP address has been assigned to your wireless interface: 
    ip a show wlan0
  2. Test internet connectivity by pinging an external server: 
    ping -c 4 8.8.8.8

Once connected, your headless Ubuntu server will automatically connect to the specified Wi-Fi network upon booting.
