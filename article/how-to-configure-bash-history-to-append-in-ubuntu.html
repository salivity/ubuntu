How to Configure Bash History to Append in Ubuntu

Configuring Bash history to append rather than overwrite ensures that commands executed across multiple terminal sessions in Ubuntu are preserved without data loss. By default, closing a terminal session can overwrite command history from other concurrent sessions. This article provides a straightforward guide to modifying your user configuration file to enable the histappend setting and immediately save command history.

Step 1: Open the .bashrc File

The default configuration for your Bash shell is stored in the hidden .bashrc file located in your home directory. Open this file in your preferred terminal text editor:

nano ~/.bashrc

Step 2: Enable the histappend Shell Option

Scroll through the file to check if the histappend setting is already present. In many default Ubuntu installations, this line is present but may need verification.

If it is not already present, add the following line to the end of the file:

shopt -s histappend

This shell option explicitly instructs Bash to append new session history entries to the .bashrc_history file upon closing, rather than replacing the existing file content.

Step 3: Write Commands Immediately (Recommended)

By default, Bash only appends history when a terminal session closes. If a terminal crashes or is forcefully terminated, the history from that session is lost. Additionally, open terminal sessions will not see commands run in other active windows.

To force Bash to save every command to the history file immediately after execution, add the following line to your .bashrc file:

PROMPT_COMMAND="history -a; $PROMPT_COMMAND"
  • history -a appends the current session’s new history lines to the history file instantly.

Step 4: Adjust History Size Limits (Optional)

To store a larger volume of commands, ensure your history file limits are set appropriately. Locate or add these variables in .bashrc and adjust their values as needed:

HISTSIZE=10000
HISTFILESIZE=20000
  • HISTSIZE: The number of commands remembered in the current memory buffer.
  • HISTFILESIZE: The maximum number of lines stored in the history file on disk.

Step 5: Save and Apply Changes

  1. If using nano, save the file by pressing Ctrl + O, hit Enter, and exit with Ctrl + X.
  2. Apply the updated configuration to your current terminal session by running:
source ~/.bashrc

Any new terminal windows opened will automatically inherit these settings. Command history will now append continuously without overwriting entries from parallel or past sessions.
