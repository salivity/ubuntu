Enable IP Packet Forwarding in Ubuntu Sysctl

This guide explains how to permanently enable network packet forwarding on an Ubuntu system using the sysctl configuration. By default, Linux disables packet forwarding for security reasons, preventing the system from acting as a router or gateway. Modifying the persistent sysctl settings ensures that IPv4 and IPv6 traffic routing remains active even after system reboots.

Step 1: Check Current Forwarding Status

Before making changes, verify whether packet forwarding is currently active on your system. Run:

sysctl net.ipv4.ip_forward

If the output is net.ipv4.ip_forward = 0, forwarding is disabled. A value of 1 indicates it is already active.

Step 2: Edit the Sysctl Configuration File

To make packet forwarding permanent across reboots, you must edit the kernel parameters. Open /etc/sysctl.conf in a text editor with root privileges:

sudo nano /etc/sysctl.conf

Alternatively, you can create a dedicated configuration file in /etc/sysctl.d/ (e.g., /etc/sysctl.d/99-ip-forward.conf), which is recommended for modern Ubuntu versions.

Step 3: Enable IP Forwarding Directives

Search for the following line in /etc/sysctl.conf:

#net.ipv4.ip_forward=1

Uncomment it by removing the # symbol at the beginning of the line:

net.ipv4.ip_forward=1

If you also need to route IPv6 packets, locate and uncomment the IPv6 forwarding directive:

net.ipv6.conf.all.forwarding=1

Save the file and exit the editor (in nano, press Ctrl+O, Enter, and then Ctrl+X).

Step 4: Apply the Changes

Apply the modified configuration immediately without restarting the server by running:

sudo sysctl -p

If you placed the configuration inside a custom file in /etc/sysctl.d/, load it using:

sudo sysctl --system

Step 5: Verify the Configuration

Confirm that packet forwarding is now enabled:

sysctl net.ipv4.ip_forward

The output should confirm:

net.ipv4.ip_forward = 1

For IPv6, verify with:

sysctl net.ipv6.conf.all.forwarding

The output should return 1. Network packet forwarding is now permanently configured on your Ubuntu machine.
