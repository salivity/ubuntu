How to Configure Traffic Shaping Using tc in Ubuntu

Traffic shaping in Ubuntu allows system administrators to control network bandwidth, limit traffic rates, and prioritize specific network packets using the built-in tc (Traffic Control) utility. This guide outlines the step-by-step process of identifying your network interface, applying rate limits using Token Bucket Filter (TBF) and Hierarchical Token Bucket (HTB) algorithms, verifying active rules, and clearing configurations when finished.

Step 1: Identify Your Network Interface

Before applying traffic control rules, identify the active network interface name on your system.

Run the following command:

ip link show

Note the interface name you wish to shape (e.g., eth0, enp3s0, or wlan0).

Step 2: Configure Simple Rate Limiting using TBF

The Token Bucket Filter (TBF) is ideal for simply slowing down an interface to a specific bandwidth rate.

To limit the egress (outgoing) bandwidth of eth0 to 1 Megabit per second, execute:

sudo tc qdisc add dev eth0 root tbf rate 1mbit burst 32kbit latency 400ms
  • dev eth0: Specifies the targeted network interface.
  • root: Attaches the queueing discipline (qdisc) to the root of the interface.
  • tbf: Specifies the Token Bucket Filter algorithm.
  • rate 1mbit: Sets the maximum sustained bandwidth limit.
  • burst 32kbit: Specifies the maximum amount of data allowed to pass in a single burst.
  • latency 400ms: Sets the maximum duration packets are queued before being dropped.

Step 3: Configure Advanced Bandwidth Allocation using HTB

For more complex traffic shaping where bandwidth needs to be partitioned or allowed to burst up to a ceiling, use the Hierarchical Token Bucket (HTB).

  1. Create the root qdisc:
sudo tc qdisc add dev eth0 root handle 1: htb default 10
  1. Create a parent class with total bandwidth:
sudo tc class add dev eth0 parent 1: classid 1:1 htb rate 10mbit
  1. Create a subclass with restricted limits:
sudo tc class add dev eth0 parent 1:1 classid 1:10 htb rate 2mbit ceil 4mbit
  • rate 2mbit: The guaranteed bandwidth for this class.
  • ceil 4mbit: The maximum bandwidth this class can borrow if idle bandwidth is available.

Step 4: Verify Active Traffic Shaping Rules

To view all active traffic shaping rules and queueing disciplines on a specific interface:

tc qdisc show dev eth0

To display detailed statistics, including dropped packets and current throughput:

tc -s qdisc show dev eth0

Step 5: Remove Traffic Control Rules

Traffic shaping rules applied via tc remain active until the system reboots or until they are manually removed. To clear all traffic control rules from an interface, delete the root qdisc:

sudo tc qdisc del dev eth0 root
