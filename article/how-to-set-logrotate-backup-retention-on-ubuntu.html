How to Set Logrotate Backup Retention on Ubuntu

Managing log file storage is critical for maintaining server performance and preventing hard drives from filling up. On Ubuntu, the logrotate utility automates the compression, removal, and rotation of log files. This guide explains how to configure logrotate to keep an exact number of old log backups using the rotate directive, covering both global and application-specific settings, as well as how to test your configuration.

Understanding the Rotate Directive

The number of rotated log files preserved on your system is controlled by the rotate directive. When a log file is rotated, logrotate creates a new archive and increments the number of existing archives. If the number of archives exceeds the value defined by rotate, the oldest archive is permanently deleted.

For example:

  • rotate 7 keeps 7 historical log files.
  • rotate 0 deletes old versions immediately without saving any backups.

Step 1: Locate the Configuration File

Logrotate configurations are managed in two places:

  1. Global Configuration: /etc/logrotate.conf handles system-wide defaults.
  2. Application Configurations: /etc/logrotate.d/ contains individual configuration files for installed services (such as Nginx, Apache, or UFW).

To change retention for a specific service, edit its file in /etc/logrotate.d/. To change the system default, edit /etc/logrotate.conf.

Step 2: Configure the Retention Count

Open the target configuration file using a text editor with root privileges:

sudo nano /etc/logrotate.d/rsyslog

Locate the log block you want to modify. Add or change the frequency (e.g., daily, weekly, monthly) and set the rotate count to your desired number of backups.

Example configuration:

/var/log/syslog
{
    rotate 14
    daily
    missingok
    notifempty
    compress
    delaycompress
    postrotate
        /usr/lib/rsyslog/rsyslog-rotate
    endscript
}

In this example:

  • daily rotates the log once per day.
  • rotate 14 preserves the last 14 days of logs before removing older entries.
  • compress compresses older logs (typically with gzip) to save disk space.

Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

Step 3: Test Your Configuration

Always verify your changes using a dry run. The -d (debug) flag simulates rotation without making actual changes or deleting logs:

sudo logrotate -d /etc/logrotate.d/rsyslog

Review the output to ensure logrotate parses the syntax correctly and indicates that it will keep the designated number of archives.

To force an immediate rotation and apply the changes, run:

sudo logrotate -f /etc/logrotate.d/rsyslog
