How to Set Up an FTP Server Using vsftpd on Ubuntu

Setting up a secure File Transfer Protocol (FTP) server on Ubuntu is a straightforward process using Very Secure FTP Daemon (vsftpd). This guide covers the complete installation and configuration workflow for vsftpd on Ubuntu, including updating system packages, configuring firewall access, creating dedicated user directories, enforcing security settings, and securing connections with SSL/TLS encryption.

Step 1: Update System Packages and Install vsftpd

Begin by updating the local package index and installing the vsftpd package from the official Ubuntu repositories:

sudo apt update
sudo apt install vsftpd

After installation finishes, verify that the vsftpd service is running:

sudo systemctl status vsftpd

If the service is not active, start and enable it to launch automatically at boot:

sudo systemctl start vsftpd
sudo systemctl enable vsftpd

Step 2: Configure the UFW Firewall

Allow FTP traffic through the Uncomplicated Firewall (UFW). You must open standard FTP ports along with a range for passive mode traffic.

sudo ufw allow 20/tcp
sudo ufw allow 21/tcp
sudo ufw allow 40000:50000/tcp
sudo ufw reload

Step 3: Create a Dedicated FTP User and Directory

Create a dedicated user account specifically for FTP connections:

sudo adduser ftpuser

Follow the prompts to set a strong password. Next, set up the directory structure and ownership to isolate the user within their home directory:

sudo mkdir -p /home/ftpuser/ftp/upload
sudo chown nobody:nogroup /home/ftpuser/ftp
sudo chmod a-w /home/ftpuser/ftp
sudo chown ftpuser:ftpuser /home/ftpuser/ftp/upload

This configuration ensures the top-level FTP directory is read-only for security, while the upload sub-folder allows writing files.

Step 4: Configure vsftpd Settings

Back up the original configuration file before making changes:

sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.bak

Open /etc/vsftpd.conf in a text editor:

sudo nano /etc/vsftpd.conf

Modify or add the following directives to configure write permissions, user isolation (chroot jail), and passive mode settings:

listen=YES
listen_ipv6=NO
anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES
user_sub_token=$USER
local_root=/home/$USER/ftp
pasv_min_port=40000
pasv_max_port=50000
userlist_enable=YES
userlist_file=/etc/vsftpd.userlist
userlist_deny=NO

Save and close the file. Then, add your new user to the allowed user list:

echo "ftpuser" | sudo tee -a /etc/vsftpd.userlist

Step 5: Secure Transmissions with SSL/TLS (FTPS)

To protect credentials and data transfers from eavesdropping, configure explicit TLS encryption. Generate a self-signed certificate:

sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/vsftpd.pem -out /etc/ssl/certs/vsftpd.pem

Reopen /etc/vsftpd.conf:

sudo nano /etc/vsftpd.conf

Append the following SSL settings to the end of the file:

rsa_cert_file=/etc/ssl/certs/vsftpd.pem
rsa_private_key_file=/etc/ssl/private/vsftpd.pem
ssl_enable=YES
allow_anon_ssl=NO
force_local_data_ssl=YES
force_local_logins_ssl=YES
ssl_tlsv1=YES
ssl_sslv2=NO
ssl_sslv3=NO
require_ssl_reuse=NO
ssl_ciphers=HIGH

Save and close the configuration file.

Step 6: Restart vsftpd and Test the Connection

Restart the vsftpd daemon to apply all changes:

sudo systemctl restart vsftpd

Test the FTP server connection using an FTP client such as FileZilla or the command-line client:

  1. Host: your_server_ip
  2. Protocol: FTP - File Transfer Protocol
  3. Encryption: Require explicit FTP over TLS
  4. User: ftpuser
  5. Password: your_password

Upon connecting, accept the SSL certificate prompt. You will be restricted to the /home/ftpuser/ftp directory and can successfully upload files into the upload folder.
