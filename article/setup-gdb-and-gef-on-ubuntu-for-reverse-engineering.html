Setup GDB and GEF on Ubuntu for Reverse Engineering

This guide provides a step-by-step walkthrough for installing and configuring the GNU Debugger (GDB) alongside the GDB Enhanced Features (GEF) extension on an Ubuntu system. By integrating GEF into GDB, security researchers and reverse engineers gain access to a dynamic architecture-aware interface, advanced memory inspection capabilities, and streamlined exploit-development tools that make analyzing compiled binaries much more efficient.

Step 1: Update the System and Install Dependencies

Before installing GEF, ensure your system packages are up to date and that GDB, Python 3, and basic network utilities are installed. Run the following command in the terminal:

sudo apt update && sudo apt install -y gdb python3 python3-pip git curl

GEF relies on Python 3 integration inside GDB, which is supported by default in modern Ubuntu releases.

Step 2: Download and Install GEF

The recommended method to install GEF is via its automated installation script, which downloads the latest script and links it to your GDB configuration file (~/.gdbinit).

Execute the installation script using curl:

bash -c "$(curl -fsSL https://gef.blah.cat/sh)"

Alternatively, if you prefer manual installation or do not have curl:

wget -O ~/.gdbinit-gef.py -q https://gef.blah.cat/py
echo "source ~/.gdbinit-gef.py" >> ~/.gdbinit

This ensures that every time GDB starts, GEF initializes automatically.

Step 3: Verify the Installation

To verify that GEF is properly integrated, open GDB:

gdb -q

You should see the GEF banner and a prompt that displays gef> instead of the default (gdb). Type gef and press Enter to view the version and command overview. Type quit to exit.

Step 4: Key GEF Commands for Reverse Engineering

GEF alters the standard debugging workflow by providing a split-context view and commands specifically tailored for binary analysis:

  • context: Prints the primary dashboard, displaying registers, the stack, memory contents, and disassembled instructions at the instruction pointer.
  • checksec: Checks binary mitigation settings, identifying whether NX (No-Execute), PIE (Position Independent Executable), Stack Canaries, or RELRO (Relocation Read-Only) are enabled.
  • vmmap: Displays the virtual memory map of the debugged process, including permissions (read, write, execute) for each segment.
  • pattern create <length> and pattern search <value>: Generates cyclic patterns and calculates buffer overflow offsets without external tools.
  • telescope <address>: Dereferences memory addresses recursively, resolving pointers, strings, and symbols in a readable tree format.
  • entry-break: Sets a temporary breakpoint directly at the program's real entry point rather than standard library initialization routines.

Step 5: Updating GEF

To keep GEF updated with the latest architecture support and bug fixes, launch GDB and run the internal update command:

gef> gef update
