How to Set Up SSH Keys on Ubuntu Server

Setting up SSH key-based authentication on an Ubuntu server enhances security by replacing vulnerable password logins with cryptographic key pairs. This guide walks you through generating a public and private key pair on your local machine, uploading the public key to your Ubuntu server, verifying the connection, and optionally disabling password authentication to fully secure your system.

Step 1: Generate an SSH Key Pair on Your Local Machine

Before configuring the server, you need to generate a key pair on your local computer (Linux, macOS, or Windows using PowerShell/Git Bash).

Open your local terminal and run the following command:

ssh-keygen -t ed25519 -C "your_email@example.com"

If your system does not support Ed25519, you can use RSA instead:

ssh-keygen -t rsa -b 4090
  1. Press Enter to save the key to the default location (~/.ssh/id_ed25519).
  2. Enter a secure passphrase when prompted (recommended), or press Enter twice to skip it.

This process creates two files: * Private key: id_ed25519 (Keep this safe and secret on your local machine). * Public key: id_ed25519.pub (This will be uploaded to your server).

Step 2: Upload the Public Key to the Ubuntu Server

The easiest way to copy your public key to the Ubuntu server is using the ssh-copy-id tool.

Run the following command in your local terminal:

ssh-copy-id username@your_server_ip

Replace username with your server’s user account and your_server_ip with your actual server IP address. Enter your server user’s password when prompted.

Alternative Manual Method

If ssh-copy-id is unavailable, run this command to copy the key manually:

cat ~/.ssh/id_ed25519.pub | ssh username@your_server_ip "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Step 3: Test Key-Based Authentication

Once the key is uploaded, verify that you can log in without typing your server password:

ssh username@your_server_ip

If you configured a passphrase for your key, enter it now. If successful, you will be logged directly into your Ubuntu server.

Step 4: Disable Password Authentication (Optional)

To maximize security, disable password-based logins so that only users with authorized SSH keys can access the server.

  1. Open the SSH configuration file on your Ubuntu server:
sudo nano /etc/ssh/sshd_config
  1. Locate the following line and change its value to no:
PasswordAuthentication no
  1. Ensure PubkeyAuthentication is set to yes:
PubkeyAuthentication yes

  1. Save and close the file (Press Ctrl+O, Enter, then Ctrl+X).

  2. Restart the SSH service to apply the changes:

sudo systemctl restart ssh

Your Ubuntu server is now secured with SSH key-based authentication.
