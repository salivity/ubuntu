How to Install and Configure Postfix on Ubuntu

This guide provides a straightforward overview of installing and configuring the Postfix Mail Transfer Agent (MTA) on an Ubuntu server. Postfix is a powerful, open-source application used to route and deliver email. By following this guide, you will learn how to update your server packages, install Postfix via the standard Ubuntu repositories, adjust key parameters in the main configuration file, and test mail delivery to ensure your server can successfully send outbound emails.

Step 1: Update Server Packages and Set Hostname

Before installing Postfix, ensure your package index is up to date and your system has a Fully Qualified Domain Name (FQDN) set as its hostname.

sudo apt update
sudo apt upgrade -y

Check your system hostname using:

hostname -f

If it does not return a proper domain name (e.g., mail.example.com), set it by running:

sudo hostnamectl set-hostname mail.example.com

Step 2: Install Postfix

Install Postfix and the mailutils package (which provides useful tools for testing email) using apt:

sudo apt install postfix mailutils -y

During installation, a interactive prompt will appear:

  1. General type of mail configuration: Select Internet Site.
  2. System mail name: Enter your base domain name (e.g., example.com), which will be used as the default sender address for system-generated emails.

Step 3: Configure Postfix

The main configuration file for Postfix is located at /etc/postfix/main.cf. Back up the original file before making edits:

sudo cp /etc/postfix/main.cf /etc/postfix/main.cf.bak

Open the file in a text editor:

sudo nano /etc/postfix/main.cf

Locate and adjust the following directives to match your setup:

  • myhostname: Set this to your FQDN (e.g., mail.example.com).
  • alias_maps / alias_database: Ensure this points to hash:/etc/aliases.
  • mydestination: List the domains this server accepts mail for, such as $myhostname, example.com, localhost.example.com, localhost.
  • mynetworks: Restrict this to trusted networks only to prevent unauthorized relaying. Ensure it includes 127.0.0.0/8 [::1]/128.
  • inet_interfaces: Set to all to listen on all network interfaces, or loopback-only if you only want local applications to send emails.
  • home_mailbox: Add home_mailbox = Maildir/ at the bottom of the file to use the Maildir format instead of standard Mbox files.

Save and close the file.

Step 4: Map System Users (Optional)

To map system users to custom email addresses, edit the aliases file:

sudo nano /etc/aliases

Example mapping:

postmaster: root
root: user@example.com

Apply the new alias mappings by running:

sudo newaliases

Step 5: Restart and Enable Postfix

Apply all configuration changes by restarting the Postfix service:

sudo systemctl restart postfix
sudo systemctl enable postfix

Verify that Postfix is running:

sudo systemctl status postfix

Step 6: Test Email Delivery

Send a test email using the mail command to verify outbound routing:

echo "This is a test body." | mail -s "Test Email Subject" recipient@example.com

Monitor the system logs to troubleshoot or verify delivery success:

sudo tail -f /var/log/mail.log

If configured correctly, the log file will show a status=sent message indicating that Postfix handed off the message for delivery.
