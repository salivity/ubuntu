Load Kernel Modules at Boot with modules-load.d

Loading a custom kernel module automatically at boot in Ubuntu is handled by the systemd-modules-load.service daemon, which reads static configuration files from /etc/modules-load.d/. This guide explains how to install a compiled kernel module into the system tree, register it within /etc/modules-load.d/, and verify that it loads correctly on system startup.

Step 1: Install the Module into the Kernel Tree

Before systemd can load your module at boot, the module file (.ko) must exist inside the module directory for your currently running kernel version so that modprobe can locate it.

  1. Copy your compiled .ko file to the kernel's extra modules directory:

    sudo mkdir -p /lib/modules/$(uname -r)/extra
sudo cp your_module_name.ko /lib/modules/$(uname -r)/extra/

  2. Update the module dependency database:

    sudo depmod -a

  3. Test that the module loads manually without errors:

    sudo modprobe your_module_name

Step 2: Create a Configuration File in /etc/modules-load.d/

The systemd-modules-load.service searches /etc/modules-load.d/ for files ending in .conf. Each file contains a newline-separated list of kernel module names to load.

  1. Create a new configuration file (for example, custom-modules.conf):

    sudo nano /etc/modules-load.d/custom-modules.conf

  2. Add the exact name of your module (without the .ko extension):

    your_module_name

  3. Save and close the file.

Step 3: Handle Module Parameters (Optional)

The files in /etc/modules-load.d/ only accept module names; they do not accept module parameters. If your custom module requires options passed to it during initialization:

  1. Create a file in /etc/modprobe.d/:

    sudo nano /etc/modprobe.d/your_module_name.conf

  2. Specify the parameters using the options directive:

    options your_module_name parameter_name=value

Step 4: Verify the Configuration

You can verify the configuration without rebooting by restarting the systemd-modules-load service:

sudo systemctl restart systemd-modules-load

Check the status of the service to ensure it processed the configuration without failure:

sudo systemctl status systemd-modules-load

Finally, confirm that your module is loaded in memory:

lsmod | grep your_module_name

Upon subsequent reboots, Ubuntu will now automatically load the designated kernel module during early user-space initialization.
