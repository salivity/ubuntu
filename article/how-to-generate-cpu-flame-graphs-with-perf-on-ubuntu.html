How to Generate CPU Flame Graphs with Perf on Ubuntu

This guide outlines the complete process for profiling system performance and generating an interactive CPU flame graph on Ubuntu using the Linux perf tool and Brendan Gregg's FlameGraph toolkit. You will learn how to install the required kernel profiling packages, capture on-CPU stack traces over a specified duration or for a specific process, collapse the collected call stacks, and render the final visualization as a standard SVG file.

Step 1: Install Required Dependencies

Ensure your system is up to date and install the appropriate linux-tools package matching your active kernel version, along with git to download the FlameGraph scripts:

sudo apt update
sudo apt install -y linux-tools-common linux-tools-generic linux-tools-$(uname -r) git

Step 2: Clone the FlameGraph Repository

Clone the FlameGraph repository from GitHub to access the Perl scripts needed to convert raw perf output into an SVG:

git clone https://github.com/brendangregg/FlameGraph.git

Step 3: Capture CPU Profile Data

Use perf record to sample call stacks across all CPUs. By default, profiling requires sudo privileges.

To record system-wide CPU activity for 30 seconds at a sampling frequency of 99 Hertz:

sudo perf record -F 99 -a -g -- sleep 30
  • -F 99: Samples at 99 Hz (samples per second), avoiding lockstep sampling with periodic system clocks.
  • -a: Captures all CPU cores.
  • -g: Records call graphs (stack traces) using frame pointers.
  • -- sleep 30: Defines the profiling duration (30 seconds).

Alternatively, to profile a specific Process ID (PID) until terminated:

sudo perf record -F 99 -p <PID> -g

Step 4: Convert and Collapse the Profile Data

The data recorded by perf is written to a binary file named perf.data. Extract the human-readable trace data using perf script, then collapse the multi-line stack traces into single lines using stackcollapse-perf.pl:

perf script > out.perf
./FlameGraph/stackcollapse-perf.pl out.perf > out.folded

Step 5: Generate the Flame Graph SVG

Render the collapsed stack data into an interactive SVG graphic using flamegraph.pl:

./FlameGraph/flamegraph.pl out.folded > cpu-flamegraph.svg

You can also run the entire pipeline in a single chained command to save disk space and avoid intermediate files:

perf script | ./FlameGraph/stackcollapse-perf.pl | ./FlameGraph/flamegraph.pl > cpu-flamegraph.svg

Step 6: View the Flame Graph

Transfer cpu-flamegraph.svg to your local machine or open it directly in any web browser:

xdg-open cpu-flamegraph.svg

In the resulting SVG, the horizontal axis spans the sample population, with wider blocks indicating functions consuming more CPU cycles. The vertical axis represents the call stack depth, from the parent function at the bottom to child functions at the top. You can click any frame to zoom in on specific call paths.
