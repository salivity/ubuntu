View Large Text Files with Less in Ubuntu Terminal

Viewing large text files in Ubuntu can quickly overwhelm system memory if opened with standard text editors or printed entirely to the screen with cat. The less command solves this by acting as a terminal pager that loads only the displayed portion of a file, allowing you to read files of any size efficiently. This guide covers how to open large files, navigate through them page by page, search for text, and exit the utility cleanly.

Opening a File

To open a file with the less pager, open your terminal and pass the file path as an argument:

less filename.txt

Unlike basic utilities, less does not wait to read the entire file before starting, ensuring instant access even with multi-gigabyte log files.

Page-by-Page Navigation

Once the file is open, use the following keyboard shortcuts to move through the content:

  • Next Page: Press Space or Page Down (or Ctrl + F) to move forward one full screen.
  • Previous Page: Press b or Page Up (or Ctrl + B) to move backward one full screen.
  • Half Page Down: Press d to scroll down half a window.
  • Half Page Up: Press u to scroll up half a window.
  • Line by Line: Use the Down Arrow (or j) to advance one line, and the Up Arrow (or k) to go back one line.

Jumping to File Positions

To move quickly across large distances in the document:

  • Go to the Beginning: Press g or Home.
  • Go to the End: Press G or End.
  • Go to a Specific Line: Type the target line number and press g (for example, 150g jumps directly to line 150).

Searching Content

Searching in less is fast and behaves similarly to the vi editor:

  1. Search Forward: Type / followed by your search term and press Enter.
  2. Search Backward: Type ? followed by your search term and press Enter.
  3. Next Match: Press n to move to the next occurrence in the search direction.
  4. Previous Match: Press N to move to the previous occurrence.

Useful Command-Line Flags

You can customize how less presents data by adding flags when launching it:

  • Show Line Numbers: 
    less -N filename.txt
  • Case-Insensitive Search: 
    less -I filename.txt
  • Wrap Long Lines: 
    less -S filename.txt
    (The -S flag truncates long lines instead of wrapping them, allowing horizontal scrolling via the Left and Right arrow keys).

Exiting the Pager

To close the file and return to your standard Ubuntu shell prompt at any time, press q.
