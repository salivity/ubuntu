How to Set Up a FreeRADIUS Server on Ubuntu

Setting up a Remote Authentication Dial-In User Service (RADIUS) server provides centralized authentication, authorization, and accounting for network access. This guide outlines the complete process of installing and configuring a FreeRADIUS server on an Ubuntu operating system. You will learn how to update system repositories, install the necessary FreeRADIUS packages, define authorized network clients, create user credentials, and verify the setup using built-in testing utilities.

Prerequisites

Before beginning the installation, ensure you have:

  • An active Ubuntu server installation (20.04 LTS or 22.04 LTS recommended).
  • A user account with sudo administrative privileges.
  • Basic familiarity with the Linux command line.

Step 1: Update System Packages

Start by updating the local package index to ensure you download the latest available software versions.

sudo apt update && sudo apt upgrade -y

Step 2: Install FreeRADIUS Packages

Install the core FreeRADIUS service alongside freeradius-utils, which contains testing tools like radtest.

sudo apt install freeradius freeradius-utils -y

Once installed, the FreeRADIUS service starts automatically. You can check its status using:

sudo systemctl status freeradius

Step 3: Configure a RADIUS Client

RADIUS clients are network devices (such as Wi-Fi access points, switches, or routers) that request authentication from the server. Define these devices in the clients.conf file.

  1. Open the configuration file:
sudo nano /etc/freeradius/3.0/clients.conf
  1. Scroll to the end of the file and add a entry for your client device or local network:
client local_network {
    ipaddr      = 192.168.1.0/24
    secret      = YourStrongSharedSecretKey
    shortname   = office-network
}
  • ipaddr: The IP address or subnet of the client device.
  • secret: A strong passphrase shared between the RADIUS server and the client device.
  • shortname: An alias used for identification in log files.
  1. Save and close the file (Ctrl+O, Enter, Ctrl+X).

Step 4: Create a RADIUS User Account

User credentials stored directly on the RADIUS server are managed within the users file.

  1. Open the users file:
sudo nano /etc/freeradius/3.0/users
  1. Add a test user definition to the top of the file:
"testuser" Cleartext-Password := "Password123"
  1. Save and close the file.

Step 5: Test the Configuration in Debug Mode

Before running FreeRADIUS in production, run it in debug mode to ensure there are no syntax errors and to view real-time authentication requests.

  1. Stop the active FreeRADIUS service:
sudo systemctl stop freeradius
  1. Start the server manually in debug mode:
sudo freeradius -X

Look for the line Ready to process requests at the end of the output, indicating the server is running properly.

  1. Open a second terminal window on your server and send a test authentication request using radtest:
radtest testuser Password123 127.0.0.1 0 testing123

(Note: testing123 is the default shared secret for localhost pre-configured in FreeRADIUS.)

  1. If successful, the test terminal will output Received Access-Accept, and the debug terminal will show detailed processing steps.

  2. Press Ctrl+C in the first terminal to exit debug mode.

Step 6: Start and Enable the FreeRADIUS Service

Once testing confirms the setup is functional, start the standard daemon service and set it to run on boot.

sudo systemctl start freeradius
sudo systemctl enable freeradius

Step 7: Configure Firewall Rules

If UFW (Uncomplicated Firewall) is enabled on your Ubuntu server, open the standard UDP ports required for RADIUS traffic:

sudo ufw allow 1812/udp
sudo ufw allow 1813/udp
sudo ufw reload
  • Port 1812: Used for RADIUS Authentication and Authorization.
  • Port 1813: Used for RADIUS Accounting.
