Securely Wipe Free Space on ext4 in Ubuntu

When you delete a file on an ext4 partition, the operating system simply unlinks the file metadata, leaving the actual raw data on the disk until it is eventually overwritten. This article outlines the most effective and reliable methods to securely overwrite and erase that unallocated free space on an ext4 filesystem in Ubuntu using command-line tools like sfill, zerofree, and the standard dd utility.

Method 1: Using sfill (Recommended for Mounted Drives)

The sfill utility is part of the secure-delete toolkit, designed specifically to wipe unused space on mounted storage devices.

  1. Install the package:

    sudo apt update
sudo apt install secure-delete

  2. Run sfill on your mount point: Replace / with the mount point of your target ext4 partition.

    sudo sfill -z -v -l -l /
    • -z: Performs a final overwrite with zeros to hide the wipe process.
    • -v: Enables verbose mode so you can track progress.
    • -l -l: Reduces the number of overwriting passes to two, significantly speeding up the process while maintaining strong security (default is 38 passes).

Method 2: Using dd (Native Method without Extra Packages)

If you do not want to install extra software, you can fill the free space with a single temporary file filled with zeros or random data, and then remove it.

  1. Create a zero-filled file to fill available space: Navigate to the directory mounted to your ext4 drive and run:

    cat /dev/zero > /path/to/mountpoint/temp_zero.bin

    Note: This command will run until the disk is completely full and output an error: cat: write error: No space left on device. This is expected behavior.

  2. Flush the disk buffer and delete the file:

    sync
rm /path/to/mountpoint/temp_zero.bin

To overwrite the free space with random data instead of zeros, substitute /dev/zero with /dev/urandom.

Method 3: Using zerofree (Best for Read-Only Partitions and VMs)

The zerofree utility specifically scans ext4 filesystems and fills unallocated blocks with zeros. It only works on partitions mounted in read-only mode or completely unmounted.

  1. Install zerofree:

    sudo apt install zerofree

  2. Unmount or remount the partition as read-only:

    sudo mount -o remount,ro /dev/sdXN

    (Replace /dev/sdXN with your actual partition identifier, e.g., /dev/sda2)

  3. Run zerofree:

    sudo zerofree -v /dev/sdXN

  4. Remount as read-write when complete:

    sudo mount -o remount,rw /dev/sdXN

Important Note for Solid-State Drives (SSDs)

If your ext4 partition is on an SSD or NVMe drive, traditional free-space wiping causes unnecessary write wear and may not overwrite all data due to wear-leveling algorithms. For modern solid-state storage, rely on the TRIM command instead:

sudo fstrim -v /

This notifies the drive's controller to immediately purge deleted blocks internally.
