Capture PCAP Files Using TShark on Ubuntu

Capturing network traffic on a headless server or command-line environment is essential for troubleshooting network issues, analyzing performance, and conducting security audits. This article explains how to install TShark—the terminal-based version of Wireshark—on Ubuntu, identify network interfaces, and record network packets directly into a .pcap file for later inspection and analysis in tools like Wireshark.

1. Install TShark on Ubuntu

Update your package index and install TShark using the APT package manager:

sudo apt update
sudo apt install tshark -y

During installation, a prompt will ask whether non-superusers should be able to capture packets. Selecting Yes allows members of the wireshark group to capture packets without sudo privileges. If you select No, you will need to run capture commands with sudo.

2. Identify the Network Interface

Before starting a capture, identify the network interface transmitting the traffic you want to record:

tshark -D

This command outputs a numbered list of available interfaces (such as eth0, ens33, or wlan0). Note the name or number of the target interface.

3. Capture Packets to a PCAP File

To start recording traffic to a file, use the -i flag to specify the interface and the -w flag to write output to a file with the .pcap extension:

sudo tshark -i eth0 -w /tmp/network_trace.pcap

Press Ctrl+C at any time to stop capturing. TShark will save the captured packets to the specified path.

4. Apply Common Capture Modifiers

You can customize the capture process using additional flags to control file size and capture duration:

  • Limit by Packet Count (-c): Automatically stop recording after capturing a set number of packets.

    sudo tshark -i eth0 -c 500 -w capture_limit.pcap

  • Apply a Capture Filter (-f): Record only specific traffic using Berkeley Packet Filter (BPF) syntax to keep the file size manageable.

    sudo tshark -i eth0 -f "tcp port 80 or tcp port 443" -w web_traffic.pcap

  • Limit by Duration (-a duration:seconds): Stop capturing after a defined period.

    sudo tshark -i eth0 -a duration:60 -w one_minute_capture.pcap

  • Create Ring Buffers (-b): Split large captures across multiple rotating files based on file size or time intervals to avoid filling the disk.

    sudo tshark -i eth0 -b filesize:10240 -b files:5 -w rotating_trace.pcap

    (This keeps up to 5 files of 10 MB each, overwriting the oldest when full).

5. Verify the Captured File

Confirm the contents of your capture directly from the command line using the -r (read) flag:

tshark -r /tmp/network_trace.pcap

You can now transfer the generated .pcap file to another machine via SCP or SFTP to perform in-depth graphical analysis using Wireshark.
