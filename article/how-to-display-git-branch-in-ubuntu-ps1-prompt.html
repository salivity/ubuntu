How to Display Git Branch in Ubuntu PS1 Prompt

Displaying the active Git branch in your Ubuntu terminal prompt provides instant visual feedback on your working environment, helping prevent accidental commits to the wrong branch. This guide explains how to customize your Bash shell prompt (PS1) variable in Ubuntu to automatically show the current Git branch whenever you navigate into a Git repository.

Step 1: Open Your Bash Configuration File

To make persistent changes to your shell prompt, you need to edit the ~/.bashrc file located in your home directory. Open it using a text editor like nano:

nano ~/.bashrc

Step 2: Add a Function to Parse the Git Branch

Scroll to the bottom of the file and add a custom Bash function that extracts the current branch name from Git.

parse_git_branch() {
     git branch 2> /dev/null | sed -e '/^[^*]/d' -e 's/* \(.*\)/ (\1)/'
}

This function runs git branch, filters out unselected branches, and formats the active branch name inside parentheses. If you are not inside a Git repository, it outputs nothing.

Step 3: Modify the PS1 Variable

Below the function in ~/.bashrc, locate your existing PS1 definition or append a new custom PS1 variable.

To display the username, hostname, current directory, and green-colored Git branch, add the following line:

export PS1="\u@\h:\w\[\033[32m\]\$(parse_git_branch)\[\033[00m\]\$ "

Breakdown of the PS1 Prompt Elements:

  • \u: Current username
  • \h: Short hostname
  • \w: Current working directory
  • \[\033[32m\]: Sets the text color to green for the Git branch
  • \$(parse_git_branch): Calls the function to display the branch name
  • \[\033[00m\]: Resets text color back to default
  • \$: Displays $ for regular users or # for root

Step 4: Save and Apply Changes

  1. In nano, save the file by pressing Ctrl + O, then press Enter.
  2. Exit the editor by pressing Ctrl + X.
  3. Apply the updated configuration to your current terminal session:
source ~/.bashrc

Step 5: Test the Configuration

Navigate to any Git repository on your system:

cd /path/to/your/git-repository

Your prompt will now display the current active branch next to your working directory, such as user@ubuntu:~/project (main)$. Leaving the repository directory will automatically hide the branch label.
