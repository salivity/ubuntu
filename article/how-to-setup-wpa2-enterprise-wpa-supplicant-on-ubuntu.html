How to Setup WPA2 Enterprise wpa_supplicant on Ubuntu

Connecting Ubuntu to a secured WPA2 Enterprise network requires configuring the wpa_supplicant daemon to handle 802.1X authentication. This guide provides a direct, step-by-step walkthrough on installing wpa_supplicant, creating a standard configuration file for Enterprise credentials, and running the service to successfully establish a network connection.

Step 1: Install wpa_supplicant

While wpa_supplicant is installed by default on most Ubuntu desktop and server distributions, you can ensure it is installed and up to date by running:

sudo apt update
sudo apt install wpasupplicant

Step 2: Identify Your Wireless Interface Name

Find the name of your wireless network interface using ip link or iw:

ip link show

Look for an interface that typically starts with wlan or wlp (for example, wlan0 or wlp2s0). Note this name for subsequent commands.

Step 3: Create the WPA2 Enterprise Configuration File

WPA2 Enterprise networks generally use EAP-PEAP with MSCHAPv2 authentication. Create a new configuration file in a secure location, such as /etc/wpa_supplicant/wpa_supplicant-enterprise.conf:

sudo nano /etc/wpa_supplicant/wpa_supplicant-enterprise.conf

Add the following configuration, replacing the placeholders with your network details:

ctrl_interface=/run/wpa_supplicant
update_config=1

network={
    ssid="YOUR_ENTERPRISE_SSID"
    key_mgmt=WPA-EAP
    eap=PEAP
    identity="YOUR_USERNAME"
    password="YOUR_PASSWORD"
    phase2="auth=MSCHAPV2"
    # Optional: Path to root CA certificate if required by your network
    # ca_cert="/etc/ssl/certs/ca-certificates.crt"
}

Save and exit the file (Ctrl+O, Enter, Ctrl+X in nano).

Step 4: Secure the Configuration File

Since the configuration file contains plaintext credentials, restrict its permissions so only root can read it:

sudo chmod 600 /etc/wpa_supplicant/wpa_supplicant-enterprise.conf

Step 5: Start wpa_supplicant

Test the connection by starting wpa_supplicant in the foreground with your wireless interface:

sudo wpa_supplicant -i wlan0 -c /etc/wpa_supplicant/wpa_supplicant-enterprise.conf

(Replace wlan0 with your actual wireless interface name).

If the terminal output indicates a successful connection (CTRL-EVENT-CONNECTED), stop the command with Ctrl+C and run it in the background by adding the -B flag:

sudo wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant/wpa_supplicant-enterprise.conf

Step 6: Acquire an IP Address

Once authenticated, request an IP address from the network's DHCP server using dhclient:

sudo dhclient wlan0

Verify your connection by checking your assigned IP address:

ip addr show wlan0
