Manage System Services with sysv-rc-conf in Ubuntu

sysv-rc-conf is a powerful, text-based terminal utility designed to manage System V init scripts and runlevel services in older Ubuntu and Debian-based distributions. It provides a simple menu-driven interface that allows system administrators to easily view, enable, or disable services across various runlevels without manually modifying symbolic links in /etc/rc*.d/ directories. This guide covers how to install, launch, and effectively use sysv-rc-conf to control your background system processes.

Installing sysv-rc-conf

Because sysv-rc-conf is built for older SysV init systems, you may need to enable the universe repository on older Ubuntu releases before installing it.

Run the following commands to update your package index and install the tool:

sudo apt-get update
sudo apt-get install sysv-rc-conf

Launching the Interface

To manage system services, launch sysv-rc-conf with root permissions using sudo:

sudo sysv-rc-conf

This opens an ncurses-based terminal interface listing services vertically on the left and runlevels (numbered 1 through 5, along with 0, 6, and S) horizontally across the top.

Navigating and Managing Services in the GUI

Within the interactive terminal screen, use the following controls:

  • Navigation: Use the Arrow Keys (Up, Down, Left, Right) to move the cursor between services and runlevels.
  • Page Navigation: Press Page Up or Page Down to scroll through the service list quickly.
  • Enable/Disable Service: Position the cursor over a square for a specific runlevel and press the Spacebar. An [X] indicates the service starts at that runlevel; an empty space [ ] means it is disabled.
  • Start or Stop Immediately:
    • Highlight a service and press + or = to start the service immediately.
    • Highlight a service and press - to stop the service immediately.
  • Quit: Press q or Ctrl + C to save your changes and exit the program.

Using sysv-rc-conf from the Command Line

If you prefer to manage services using direct commands rather than the interactive interface, sysv-rc-conf supports command-line flags.

Viewing Service Status

To list all services and their configured runlevels:

sudo sysv-rc-conf --list

To check a specific service (for example, apache2):

sudo sysv-rc-conf --list apache2

Enabling or Disabling Services

To enable a service across its default runlevels:

sudo sysv-rc-conf apache2 on

To disable a service completely across all runlevels:

sudo sysv-rc-conf apache2 off

To enable or disable a service for specific runlevels only (e.g., enable apache2 for runlevels 2, 3, 4, and 5):

sudo sysv-rc-conf --level 2345 apache2 on

Common Runlevels Quick Reference

  • 0: System Halt / Shutdown
  • 1: Single-User Mode (Maintenance)
  • 2–5: Multi-User Modes (Standard operation with or without GUI depending on configuration)
  • 6: System Reboot
