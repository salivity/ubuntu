Install and Configure OpenSSH Server on Ubuntu

Setting up an OpenSSH server on a fresh Ubuntu installation allows you to securely access and manage your system remotely via the Secure Shell (SSH) protocol. This guide covers the complete step-by-step process of installing the OpenSSH package, enabling the service, configuring firewall rules, and modifying key settings to enhance server security.

Step 1: Update System Packages

Before installing new software, update your package list to ensure you receive the latest versions and security patches.

sudo apt update && sudo apt upgrade -y

Step 2: Install OpenSSH Server

Ubuntu includes the OpenSSH server package in its standard repositories. Install it using the following command:

sudo apt install openssh-server -y

Step 3: Verify OpenSSH Status

Once the installation completes, the SSH service starts automatically. Check its status to confirm it is running:

sudo systemctl status ssh

If the service is active, you will see active (running) in the output. If it is not running, start it and set it to launch at boot using:

sudo systemctl enable --now ssh

Step 4: Configure UFW Firewall

If you have the Uncomplicated Firewall (UFW) enabled, you must allow incoming SSH connections.

Allow standard SSH traffic:

sudo ufw allow ssh

Or allow traffic on specific TCP port 22:

sudo ufw allow 22/tcp

Enable the firewall if it is currently disabled, and reload the rules:

sudo ufw enable
sudo ufw status

Step 5: Configure OpenSSH Settings

You can customize the OpenSSH server configuration by editing the /etc/ssh/sshd_config file.

First, create a backup of the original configuration file:

sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak

Open the configuration file in a text editor:

sudo nano /etc/ssh/sshd_config

Consider adjusting the following security options:

  • Change Default SSH Port: Locate #Port 22, uncomment it, and change it to a non-standard port (e.g., Port 2222) to reduce automated attacks.
  • Disable Root Login: Locate PermitRootLogin and set it to no to prevent direct SSH access for the root user: 
    PermitRootLogin no
  • Limit Maximum Auth Tries: Set the maximum password attempts to prevent brute-force attacks: 
    MaxAuthTries 3

Save and exit the file (press CTRL+O, ENTER, then CTRL+X).

Step 6: Apply Changes

Test the configuration file for syntax errors before restarting the service:

sudo sshd -t

If no output is returned, the syntax is correct. Restart the OpenSSH service to apply your configuration changes:

sudo systemctl restart ssh

Step 7: Connect to the SSH Server

To connect to your Ubuntu machine from a remote computer, use the following SSH command syntax:

ssh username@server_ip_address

If you changed the default port in Step 5, specify the port number using the -p flag:

ssh -p 2222 username@server_ip_address
