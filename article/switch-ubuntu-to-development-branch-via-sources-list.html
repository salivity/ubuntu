Switch Ubuntu to Development Branch via sources.list

Switching an existing Ubuntu installation to the active development branch allows developers and advanced users to test upcoming features, updated kernels, and the latest software stacks before the next official release. This guide outlines the manual process of updating the APT package repository files—specifically pointing the system release codename to the devel branch—followed by upgrading installed packages directly through the command line.

Step 1: Back Up Current Repository Configurations

Before making manual changes to your system repository lists, create a backup copy of your current configuration to easily revert changes if necessary.

sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

Note for Ubuntu 24.04 LTS and newer: Newer releases use the deb822 format located at /etc/apt/sources.list.d/ubuntu.sources. If your system utilizes this file instead of the legacy sources.list, back it up with:

sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak

Step 2: Edit the Repository Configuration

Open your repository configuration file in a terminal-based text editor with root privileges.

For traditional sources.list:

sudo nano /etc/apt/sources.list

Locate all instances of your current release codename (such as jammy, focal, or noble) and replace them with devel.

Alternatively, you can replace all occurrences automatically using sed:

sudo sed -i 's/<current_codename>/devel/g' /etc/apt/sources.list

(Replace <current_codename> with your active release, e.g., noble)

If your system uses /etc/apt/sources.list.d/ubuntu.sources, open that file:

sudo nano /etc/apt/sources.list.d/ubuntu.sources

Find the line beginning with Suites: and change the listed codenames to point to devel, devel-updates, devel-security, and devel-backports:

Suites: devel devel-updates devel-backports devel-security

Save the file and exit the text editor (in Nano, press Ctrl + O, Enter, then Ctrl + X).

Step 3: Refresh Package Indexes

Update your system's package index files to fetch the package lists from the development repositories.

sudo apt update

Review the terminal output to ensure that all repositories fetch successfully without 404 or authentication errors.

Step 4: Perform the Distribution Upgrade

Run a full distribution upgrade. This command handles changing dependencies, installing new packages, and removing obsolete packages as required by the development branch.

sudo apt full-upgrade

Review the list of packages to be upgraded, removed, or installed, then confirm the prompt by typing Y and pressing Enter.

Step 5: Reboot and Verify

Once the upgrade process finishes, restart the machine to boot into the newly installed kernel and core libraries.

sudo reboot

After rebooting, verify that your system is actively tracking the development branch:

lsb_release -a

The output should reflect the current development codename and version status.
