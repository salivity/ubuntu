How to Set Up a PXE Boot Server for Ubuntu

Setting up a PXE (Preboot Execution Environment) boot server allows you to install Ubuntu on multiple machines over a local network without using physical installation media like USB drives or DVDs. This guide walks you through configuring the core components—a DHCP server, a TFTP server, an HTTP web server, and the Ubuntu boot files—to create an automated, network-based installation environment.

Prerequisites

  • An existing server running Ubuntu to act as the PXE host.
  • A static IP address assigned to the PXE server (for this guide, we will use 192.168.1.50).
  • A network switch connecting the server and target client machines.

Step 1: Install Required Services

Install dnsmasq (which handles DHCP and TFTP) and nginx (to host the Ubuntu installation files over HTTP).

sudo apt update
sudo apt install -y dnsmasq nginx pxelinux syslinux-common

Step 2: Configure Dnsmasq for DHCP and TFTP

  1. Backup the original dnsmasq configuration:

    sudo mv /etc/dnsmasq.conf /etc/dnsmasq.conf.bak

  2. Create a new configuration file:

    sudo nano /etc/dnsmasq.conf

  3. Paste the following configuration, adjusting the IP ranges to match your network subnet:

    interface=eth0
bind-interfaces
dhcp-range=192.168.1.100,192.168.1.200,24h
dhcp-option=option:router,192.168.1.1
dhcp-option=option:dns-server,192.168.1.1

# TFTP Server Settings
enable-tftp
tftp-root=/var/lib/tftpboot

# Bootloader Location
dhcp-boot=pxelinux.0

  4. Restart the dnsmasq service:

    sudo systemctl restart dnsmasq

Step 3: Populate TFTP Directory with Bootloaders

Copy the required SYSLINUX files into the TFTP root directory.

sudo mkdir -p /var/lib/tftpboot/pxelinux.cfg
sudo cp /usr/lib/PXELINUX/pxelinux.0 /var/lib/tftpboot/
sudo cp /usr/lib/syslinux/modules/bios/{ldlinux.c32,menu.c32,vesamenu.c32,libutil.c32} /var/lib/tftpboot/

Step 4: Download and Mount the Ubuntu ISO

  1. Download the desired Ubuntu ISO (e.g., Ubuntu 22.04 LTS Live Server):

    cd ~
wget https://releases.ubuntu.com/22.04/ubuntu-22.04.3-live-server-amd64.iso

  2. Create a mount directory and mount the ISO:

    sudo mkdir -p /mnt/ubuntu
sudo mount -o loop ubuntu-22.04.3-live-server-amd64.iso /mnt/ubuntu

  3. Copy the kernel (vmlinuz) and initial RAM disk (initrd) files to the TFTP server:

    sudo mkdir -p /var/lib/tftpboot/ubuntu
sudo cp /mnt/ubuntu/casper/vmlinuz /var/lib/tftpboot/ubuntu/
sudo cp /mnt/ubuntu/casper/initrd /var/lib/tftpboot/ubuntu/

  4. Copy the entire ISO content to the Nginx web root directory to serve installation assets:

    sudo mkdir -p /var/www/html/ubuntu
sudo cp -r /mnt/ubuntu/* /var/www/html/ubuntu/

Step 5: Configure the PXE Boot Menu

Create a PXE default menu configuration file to tell client machines where to load the kernel and installer files.

sudo nano /var/lib/tftpboot/pxelinux.cfg/default

Add the following content:

DEFAULT vesamenu.c32
PROMPT 0
TIMEOUT 300
ONTIMEOUT ubuntu

MENU TITLE PXE Boot Menu

LABEL ubuntu
  MENU LABEL Install Ubuntu 22.04 Server
  KERNEL ubuntu/vmlinuz
  INITRD ubuntu/initrd
  APPEND root=/dev/ram0 ramdisk_size=1500000 ip=dhcp url=http://192.168.1.50/ubuntu/ubuntu-22.04.3-live-server-amd64.iso

Step 6: Set Permissions and Restart Services

Ensure all web and TFTP directories have correct access permissions and restart the relevant services.

sudo chmod -R 755 /var/lib/tftpboot
sudo systemctl restart dnsmasq
sudo systemctl restart nginx

Step 7: Boot the Target Machine

  1. Connect the target computer to the same network as your PXE server.
  2. Power on the machine and access the BIOS/UEFI settings.
  3. Enable Network Boot (PXE) and set network booting as the primary boot priority.
  4. Save and restart. The client machine will acquire an IP address, display the PXE menu, and launch the Ubuntu installer automatically.
