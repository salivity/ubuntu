How to Set Up a Mastodon Server on Ubuntu

Setting up a Mastodon instance allows you to host an independent, federated social media node on the Fediverse using your own domain. This step-by-step guide outlines the complete process of installing and configuring a production-ready Mastodon server on an Ubuntu machine. You will learn how to prepare the operating system, install system dependencies, configure PostgreSQL and Redis, install the Mastodon codebase, configure Nginx with SSL encryption, and manage background system services.

1. Prerequisites and System Preparation

Before beginning, ensure you have an Ubuntu 22.04 or 24.04 server with at least 2 vCPUs and 4 GB of RAM, a non-root user with sudo privileges, and a fully qualified domain name (FQDN) pointed via DNS A/AAAA records to your server's IP address.

Update the base system and install the required utility packages:

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget gnupg apt-transport-https lsb-release ca-certificates

2. Install System Dependencies

Mastodon requires Node.js, Ruby, PostgreSQL, Redis, and build essentials.

Node.js and Yarn

Add the NodeSource repository for Node.js (v20 LTS) and enable corepack for Yarn:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo corepack enable

System Libraries and Build Tools

Install compilation tools, ImageMagick, and libraries needed for media processing:

sudo apt install -y \
  git-core g++ libpq-dev libxml2-dev libxslt1-dev file \
  ffmpeg imagemagick libidn11-dev libprotobuf-dev protobuf-compiler \
  pkg-config gcc autoconf bison build-essential libssl-dev libyaml-dev \
  libreadline6-dev zlib1g-dev libncurses5-dev libffi-dev libgdbm-dev

PostgreSQL and Redis

Install and enable PostgreSQL and Redis:

sudo apt install -y postgresql postgresql-contrib redis-server redis-tools
sudo systemctl enable --now redis-server postgresql

Configure PostgreSQL to create a user for Mastodon:

sudo -u postgres psql -c "CREATE USER mastodon CREATEDB;"

3. Create the Mastodon System User and Install Ruby

Create a dedicated system user named mastodon with no shell login privileges:

sudo adduser --disabled-login mastodon

Switch to the mastodon user:

sudo su - mastodon

Install rbenv and ruby-build to manage the Ruby version:

git clone https://github.com/rbenv/rbenv.git ~/.rbenv
echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init -)"' >> ~/.bashrc
source ~/.bashrc

git clone https://github.com/rbenv/ruby-build.git ~/.rbenv/plugins/ruby-build

Install the Ruby version required by Mastodon (e.g., 3.3.0) and set it globally:

rbenv install 3.3.0
rbenv global 3.3.0
gem install bundler --no-document

4. Download and Configure Mastodon

Clone the latest stable release of the Mastodon repository:

git clone https://github.com/mastodon/mastodon.git live
cd live
git checkout $(git tag -l | grep -v 'rc[0-9]*$' | sort -V | tail -n 1)

Install Ruby gems and JavaScript packages:

bundle config deployment 'true'
bundle config without 'development test'
bundle install -j$(nproc)
yarn install --pure-lockfile

Run the interactive setup wizard:

RAILS_ENV=production bundle exec rake mastodon:setup

Follow the interactive prompts:

  • Enter your domain name.
  • Configure single-user or multi-user mode.
  • Leave PostgreSQL and Redis connection details as default (localhost/ident-based authentication).
  • Provide an active SMTP mail server configuration for transactional account emails.
  • Allow the script to create the database schema and compile the web assets.
  • Create your initial administrator account when prompted.

Exit back to your sudo user:

exit

5. Configure Nginx and SSL

Install Nginx and Certbot:

sudo apt install -y nginx certbot python3-certbot-nginx

Copy the Nginx configuration template provided by Mastodon:

sudo cp /home/mastodon/live/dist/nginx.conf /etc/nginx/sites-available/mastodon
sudo ln -s /etc/nginx/sites-available/mastodon /etc/nginx/sites-enabled/

Open /etc/nginx/sites-available/mastodon in a text editor:

sudo nano /etc/nginx/sites-available/mastodon

Locate server_name example.com; and replace example.com with your actual domain name.

Obtain an SSL certificate using Certbot:

sudo certbot --nginx -d yourdomain.com

Reload Nginx to apply the configuration:

sudo nginx -t && sudo systemctl reload nginx

6. Set Up Systemd Services

Copy the systemd unit files from the Mastodon directory:

sudo cp /home/mastodon/live/dist/mastodon*.service /etc/systemd/system/

Reload the systemd daemon, then enable and start all three Mastodon services:

sudo systemctl daemon-reload
sudo systemctl enable --now mastodon-web mastodon-sidekiq mastodon-streaming

Your Mastodon instance is now running. Navigate to your domain in a web browser to log in with the administrator credentials generated during setup.
