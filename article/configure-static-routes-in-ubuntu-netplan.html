Configure Static Routes in Ubuntu Netplan

Configuring a static route in Ubuntu using Netplan involves editing a YAML file located in the /etc/netplan/ directory, defining the target network and gateway under the appropriate network interface, and applying the new configuration. Netplan simplifies network management by using structured YAML definitions, allowing administrators to easily add persistent routes that survive system reboots. This guide provides a direct, step-by-step walk-through to successfully create and verify static routes on your Ubuntu system.

Step 1: Identify Your Network Interface and Config File

First, list the existing Netplan configuration files:

ls /etc/netplan/

Files usually end in .yaml, such as 01-netcfg.yaml or 50-cloud-init.yaml.

Next, identify the active network interface name using the ip command:

ip link show

Note the name of the interface you want to route traffic through (e.g., eth0 or enp3s0).

Step 2: Edit the Netplan Configuration File

Open the configuration file in a text editor with root privileges:

sudo nano /etc/netplan/50-cloud-init.yaml

Under your specific network interface, add a routes section. Ensure you follow strict YAML indentation (use spaces, not tabs).

Example configuration:

network:
  version: 2
  renderer: networkd
  ethernets:
    enp3s0:
      addresses:
        - 192.168.1.50/24
      routes:
        - to: 10.10.0.0/16
          via: 192.168.1.1
  • to: The destination network or IP address in CIDR notation (e.g., 10.10.0.0/16).
  • via: The gateway IP address that traffic should pass through to reach the destination.

Step 3: Test and Apply the Changes

Before permanently applying the configuration, test it for syntax errors using netplan try. This command will automatically revert changes if the configuration breaks your connection.

sudo netplan try

If the test is successful, press Enter to accept the configuration. Alternatively, apply the settings directly:

sudo netplan apply

Step 4: Verify the Static Route

To confirm that the static route has been added to the kernel routing table, run:

ip route show

Look for your newly added network destination in the command output to ensure traffic is correctly directed through the specified gateway.
