How to Install and Configure PHP on Ubuntu

This guide provides a quick overview of installing and configuring the PHP scripting language on an Ubuntu Linux system. You will learn how to update your package repository, install PHP along with essential extensions, configure key settings in the php.ini file, and test your installation to ensure PHP works properly with your web server.

Step 1: Update System Packages

Before installing PHP, update your system's package list to ensure you get the latest available versions from the official Ubuntu repository:

sudo apt update && sudo apt upgrade -y

Step 2: Install PHP

To install the default version of PHP available for your Ubuntu release, run the following command:

sudo apt install php -y

Depending on your web server setup, you may need additional integration packages:

  • For Apache Web Server: Install the Apache PHP module: 
    sudo apt install libapache2-mod-php -y
  • For Nginx Web Server: Install PHP-FPM (FastCGI Process Manager): 
    sudo apt install php-fpm -y

Verify that PHP is installed correctly by checking its version:

php -v

Step 3: Install Essential PHP Extensions

Many modern web applications require specific PHP extensions to enable features like database connectivity, encryption, and cURL processing. Install commonly required extensions using:

sudo apt install php-mysql php-curl php-xml php-mbstring php-zip php-gd -y

To see a full list of available PHP modules, run php -m.

Step 4: Configure PHP Settings

PHP behavior is controlled through the php.ini file. Its path depends on the web server setup and the installed PHP version.

Common paths include:

  • CLI (Command Line): /etc/php/8.x/cli/php.ini
  • Apache: /etc/php/8.x/apache2/php.ini
  • Nginx (FPM): /etc/php/8.x/fpm/php.ini

Open the appropriate php.ini file in a text editor (replace 8.x with your specific PHP version):

sudo nano /etc/php/8.x/apache2/php.ini

Locate and adjust the following common directive values to suit your application requirements:

  • memory_limit = 256M (Sets the maximum memory script execution limit)
  • upload_max_filesize = 64M (Sets the maximum allowed size for uploaded files)
  • post_max_size = 64M (Sets the maximum size of POST data permitted)
  • max_execution_time = 300 (Sets the maximum time in seconds a script is allowed to run)

Save your changes and exit the text editor.

Step 5: Restart the Web Server

Apply your configuration changes by restarting the relevant web server service.

For Apache:

sudo systemctl restart apache2

For Nginx (replace 8.x with your PHP-FPM version):

sudo systemctl restart php8.x-fpm
sudo systemctl restart nginx

Step 6: Test the PHP Setup

Create a test file inside your web root directory (typically /var/www/html/) to confirm that your web server correctly processes PHP files:

sudo nano /var/www/html/info.php

Add the following PHP code to the file:

<?php
phpinfo();
?>

Save and close the file. Open a web browser and visit http://your_server_ip/info.php. A page displaying detailed information about your system's PHP configuration should load.

Once verified, remove the test file for security purposes:

sudo rm /var/www/html/info.php
