How to Configure a Wacom Tablet on Ubuntu

Configuring a Wacom drawing tablet on Ubuntu is a straightforward process that can be accomplished using either the graphical user interface (GUI) or the command-line interface (CLI). Ubuntu includes built-in driver support for most Wacom devices through the libwacom and xserver-xorg-input-wacom packages. This article provides a clear, step-by-step guide to configuring pen buttons, pressure sensitivity, and display mapping using both the GNOME Settings application and the powerful xsetwacom command-line tool.

Method 1: Configure Wacom Tablet via Ubuntu GUI

The GUI method is recommended for most users seeking quick adjustments to basic settings like orientation, tracking mode, and button mapping.

Step 1: Access Wacom Settings

  1. Connect your Wacom tablet to your computer via USB or Bluetooth.
  2. Open the Settings application from your application menu.
  3. Scroll down the left sidebar and select Wacom Tablet.

Step 2: Configure Display Mapping

If you use multiple monitors:

  1. Click on the Tablet tab.
  2. Select Map to Monitor.
  3. Choose whether to map the tablet area to All Displays or a specific monitor.
  4. Set the Keep Aspect Ratio toggle to ON to prevent drawing distortion.

Step 3: Customize Pen and Buttons

  1. Switch to the Stylus tab.
  2. Adjust the Tip Pressure Sensitivity slider to match your drawing style.
  3. Use the drop-down menus next to the stylus buttons to assign actions such as Right Click, Middle Click, Back, or Erase.

Method 2: Configure Wacom Tablet via Command Line (CLI)

For advanced customizations, shortcut bindings, or environments running X11, the xsetwacom utility provides complete control over your tablet.

Step 1: Identify Your Tablet Devices

Open a terminal (Ctrl+Alt+T) and run:

xsetwacom --list devices

This output lists your connected components (Stylus, Eraser, Pad, Touch) alongside their unique IDs and names. Example output:

  • Wacom Intuos S Stylus id: 9 type: STYLUS
  • Wacom Intuos S Pad id: 10 type: PAD

Step 2: Map the Tablet to a Specific Monitor

To map the stylus to a specific monitor on a multi-screen setup, find your screen name using xrandr:

xrandr | grep "connected"

Then map the stylus to your desired display (e.g., HDMI-1):

xsetwacom set "Wacom Intuos S Stylus" MapToOutput HDMI-1

Step 3: Remap Stylus and ExpressKey Buttons

To map keyboard shortcuts to the tablet or pen buttons, use the Button command.

  • Set Stylus Button 2 to Right Click:

    xsetwacom set "Wacom Intuos S Stylus" Button 2 3

  • Set ExpressKey Button 1 to Undo (Ctrl + Z):

    xsetwacom set "Wacom Intuos S Pad" Button 1 "key +ctrl z -ctrl"

Step 4: Adjust Pressure Sensitivity

Change the pressure response curve using four control points (x1 y1 x2 y2):

xsetwacom set "Wacom Intuos S Stylus" PressureCurve 0 20 80 100
  • Soft feel: 0 75 25 100
  • Hard feel: 0 10 90 100

Persisting Command Line Settings Across Reboots

Commands executed with xsetwacom reset when the system restarts. To make these settings permanent:

  1. Create a custom shell script: 
    nano ~/.wacom-config.sh
  2. Add your commands to the file: 
    #!/bin/bash
xsetwacom set "Wacom Intuos S Stylus" MapToOutput HDMI-1
xsetwacom set "Wacom Intuos S Pad" Button 1 "key +ctrl z -ctrl"
  3. Save the file (Ctrl+O, Enter) and exit (Ctrl+X).
  4. Make the script executable: 
    chmod +x ~/.wacom-config.sh
  5. Open Startup Applications from your application menu, click Add, set the command path to /home/your-username/.wacom-config.sh, and save.
