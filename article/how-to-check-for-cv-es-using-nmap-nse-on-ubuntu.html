How to Check for CVEs Using Nmap NSE on Ubuntu

This guide demonstrates how to detect known Common Vulnerabilities and Exposures (CVEs) on network-accessible systems using the Nmap Scripting Engine (NSE) on Ubuntu. It covers installing Nmap, locating built-in vulnerability detection scripts, querying specific CVE identifiers, and extending detection capabilities with vulnerability databases like Vulners to audit system security.

Installing Nmap on Ubuntu

Nmap includes the NSE runtime and standard script libraries by default. Ensure the package and its script database are up to date via the standard package manager:

sudo apt update
sudo apt install nmap

To update the local script database index after installation:

sudo nmap --script-updatedb

Locating Built-in CVE Scripts

Nmap stores its NSE scripts in /usr/share/nmap/scripts/. Many scripts are specifically designed to detect known CVEs without exploiting them.

To locate scripts addressing a specific CVE identifier, use grep or find:

# Search for scripts mentioning a specific CVE (e.g., CVE-2020-0796)
grep -l "CVE-2020-0796" /usr/share/nmap/scripts/*.nse

# Search by a known vulnerability name (e.g., Heartbleed)
ls /usr/share/nmap/scripts/*heartbleed*

NSE scripts are categorized by function. The vuln category contains scripts specifically created to identify known vulnerabilities.

Scanning for Specific CVEs

Once the appropriate script name is identified, execute the scan against the target IP address or hostname.

Checking for a Single Known Vulnerability

Specify the exact script name using the --script flag, along with the relevant port to reduce unnecessary network traffic:

nmap -p 445 --script smb-vuln-ms17-010 <target-ip>

Passing CVE Arguments

Certain scripts accept arguments to tailor the detection logic:

nmap -p 80,443 --script http-vuln-cve2017-5638 --script-args uri=/struts2-showcase/ <target-ip>

Running All Vulnerability Scripts

To run the entire suite of built-in vulnerability detection scripts against open services:

nmap -sV --script vuln <target-ip>

The -sV flag enables service version detection, which is necessary for scripts that rely on software version fingerprinting.

Checking CVEs with the Vulners Script

The built-in NSE library covers specific high-profile vulnerabilities, but broader CVE auditing requires querying an external vulnerability database. The vulners script correlates detected software versions against the Vulners database to report matching CVEs.

  1. Ensure service version detection (-sV) is enabled.
  2. Run the vulners script:
nmap -sV --script vulners <target-ip>

To filter results by Common Vulnerability Scoring System (CVSS) score:

nmap -sV --script vulners --script-args mincvss=7.0 <target-ip>

Interpreting the Output

When a check finds a matching vulnerability, Nmap displays a dedicated section under the corresponding port:

  • State: Indicates whether the target is VULNERABLE, LIKELY VULNERABLE, or not affected.
  • IDs: Lists relevant CVE numbers and database identifiers.
  • Risk Factor / CVSS: Displays the severity score assigned to the vulnerability.
  • Description: Summarizes the vulnerability and provides reference URLs for remediation details.

If no vulnerability is detected, the script output is omitted from the scan report unless verbose mode (-v) is enabled.
