How to Record Screen with FFmpeg in Ubuntu

Recording your desktop screen in Ubuntu using FFmpeg is a powerful, lightweight, and customizable way to capture high-quality video without relying on third-party graphical applications. This guide provides the exact terminal command required to capture your Ubuntu desktop, breaks down the key parameters for customizing your recording, and explains how to include system audio.

The Basic Screen Recording Command

To record your entire desktop screen to an MP4 video file, open your terminal (Ctrl + Alt + T) and execute the following command:

ffmpeg -f x11grab -video_size 1920x1080 -framerate 30 -i :0.0 output.mp4

To stop the recording at any point, switch back to the terminal window and press Ctrl + C.

Command Parameter Breakdown

  • -f x11grab: Forces FFmpeg to use the X11 capture device, which grabs screen content from an X11 display server.
  • -video_size 1920x1080: Defines the capture dimensions. You should adjust 1920x1080 to match your actual display resolution.
  • -framerate 30: Sets the recording frame rate to 30 frames per second. You can change this to 60 for smoother footage or 15 to save disk space.
  • -i :0.0: Specifies the input display target. Default primary displays in Ubuntu are typically mapped to :0.0.
  • output.mp4: Defines the output video filename and format.

Identifying Your Screen Resolution

If you need to verify your screen resolution, run the following command:

xrandr | grep '*'

Replace the -video_size value in the recording command with the screen resolution returned by xrandr.

Recording Desktop Screen with Audio

To record your screen while simultaneously capturing system audio via PulseAudio, add the audio parameters:

ffmpeg -f x11grab -video_size 1920x1080 -framerate 30 -i :0.0 -f pulse -i default output.mp4

The added flags -f pulse -i default route your system's default PulseAudio audio stream into the recorded video file.
