How to Use Radare2 on Ubuntu

Radare2 is a versatile, open-source command-line framework for reverse engineering, binary analysis, and debugging. This guide provides a straightforward walk-through for setting up Radare2 on an Ubuntu system and covers the fundamental workflow required to inspect, analyze, and navigate compiled binaries.

Installing Radare2 on Ubuntu

While Ubuntu repositories often include a packaged version of Radare2, building the latest stable version directly from the official Git repository ensures access to the newest features and bug fixes.

Open your terminal and run the following commands to install dependencies and build the tool:

sudo apt update
sudo apt install -y git build-essential
git clone https://github.com/radareorg/radare2
radare2/sys/install.sh

To verify the installation, check the installed version:

r2 -v

Basic Analysis Workflow

Radare2 relies on single-letter and multi-letter mnemonic commands. The standard procedure for analyzing a binary involves loading the file, performing automated analysis, inspecting functions, and examining code.

1. Opening a Binary

Launch Radare2 by passing the target binary as an argument. By default, it opens the binary in read-only mode:

r2 /path/to/binary

To open a binary in read-write mode (for patching), add the -w flag:

r2 -w /path/to/binary

2. Performing Automated Analysis

When a binary is first opened, Radare2 places the user at the command prompt without automatically parsing all structures. To trigger analysis, use the a family of commands:

  • aa: Analyzes symbols and entry points.
  • aaa: Performs deep automated analysis, including functions, flags, references, and basic blocks.

Run the deep analysis:

[0x00001000]> aaa

3. Locating Information and Functions

After analysis, you can inspect the file layout and discovered functions using the i (information) and a (analysis) prefixes:

  • iI: Displays general binary information (architecture, endianness, security mitigations like PIE, Canary, and NX).
  • ii: Lists imported functions and libraries.
  • is: Displays symbols.
  • afl: Lists all identified functions, their virtual addresses, and sizes.

To search for a specific function such as main:

[0x00001000]> afl | grep main

4. Navigating and Seeking

The current offset or address is indicated in the prompt prompt prefix. To change your position within the binary, use the seek command (s):

[0x00001000]> s main

You can also seek to specific hexadecimal addresses:

[0x00001000]> s 0x00001149

5. Disassembling and Viewing Code

Once positioned at a target function or address, view the assembly instructions using the print command (p):

  • pdf: Print Disassembly Function (disassembles the entire function at the current seek position).
  • pd 20: Disassembles the next 20 instructions.
  • px 64: Prints a standard hex dump of 64 bytes.
[0x00001149]> pdf

6. Using the Visual Mode

Radare2 includes an interactive text-based user interface that simplifies code navigation:

  • Press V to enter visual mode.
  • Press p repeatedly inside visual mode to toggle through different views, including the hex view, disassembly view, and function browser.
  • Press V then spacebar to access the interactive ASCII graph view, which renders control-flow graphs for the current function.
  • Use the arrow keys or h, j, k, l to navigate the graph.
  • Press q to exit visual modes and return to the primary command prompt.

Exiting Radare2

To close the session and exit to the standard Ubuntu shell, enter:

[0x00001149]> q
