Import Custom CA Certificate into Ubuntu Trust Store

Importing a custom internal Certificate Authority (CA) into Ubuntu's system-wide trust store allows your system and its command-line utilities to natively validate internal SSL/TLS certificates without throwing security warnings. This guide walks you through the straightforward process of preparing your certificate file, copying it to the appropriate system directory, and updating Ubuntu's CA certificate bundle so all applications recognize your internal authority.

1. Format the Certificate

Ubuntu requires CA certificates to be in PEM format with a .crt extension. If your certificate is in DER format or uses the .cer or .pem extension, you must prepare it accordingly.

To convert a DER-encoded certificate to PEM format:

openssl x509 -inform DER -in internalCA.cer -out internalCA.crt

If your file is already PEM-encoded but has a .pem extension, simply rename it to .crt:

mv internalCA.pem internalCA.crt

2. Copy the Certificate to the System Store

Ubuntu uses the /usr/local/share/ca-certificates/ directory for local and custom root certificates. Create a subdirectory to organize your custom certificates, or copy the file directly:

sudo cp internalCA.crt /usr/local/share/ca-certificates/

Ensure the file permissions allow read access:

sudo chmod 644 /usr/local/share/ca-certificates/internalCA.crt

3. Update the CA Trust Store

Run the update-ca-certificates command to read the directory, generate symbolic links, and append your certificate to /etc/ssl/certs/ca-certificates.crt:

sudo update-ca-certificates

If successful, the console output will display:

Updating certificates in /etc/ssl/certs...
1 added, 0 removed; done.
Running hooks in /etc/ca-certificates/update.d...
done.

4. Verify the Import

Verify that the certificate has been successfully added to the system-wide store by querying the compiled certificate file:

grep -i "Your Certificate Common Name" /etc/ssl/certs/ca-certificates.crt

Alternatively, test a secure connection against an internal service using curl:

curl https://internal.example.com

If configured correctly, the request will complete without displaying SSL certificate problem: unable to get local issuer certificate.
