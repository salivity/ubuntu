How to Install Apache Tomcat on Ubuntu

This guide provides a complete, step-by-step walkthrough for installing and configuring the Apache Tomcat application server on an Ubuntu system. You will learn how to install the required Java OpenJDK environment, create a dedicated system user, download and install the latest Tomcat release, set up a systemd service for automated startup, and configure admin users and firewall access for web-based management.

Step 1: Install Java Development Kit (JDK)

Apache Tomcat requires Java to run. First, update your package index and install OpenJDK:

sudo apt update
sudo apt install openjdk-11-jdk -y

Verify the installation by checking the Java version:

java -version

Step 2: Create a Dedicated Tomcat User

For security reasons, Tomcat should not run as the root user. Create a dedicated user and group to run the service:

sudo useradd -m -U -d /opt/tomcat -s /bin/false tomcat

Step 3: Download and Extract Tomcat

Navigate to the /tmp directory and download the latest version of Apache Tomcat 10 using wget:

cd /tmp
wget https://dlcdn.apache.org/tomcat/tomcat-10/v10.1.19/bin/apache-tomcat-10.1.19.tar.gz

Extract the tarball to the /opt/tomcat directory:

sudo tar -xf apache-tomcat-10.1.19.tar.gz -C /opt/tomcat --strip-components=1

Step 4: Update Permissions

Assign ownership of the installation directory to the tomcat user and group, and grant execution permissions to the scripts in the bin directory:

sudo chown -R tomcat:tomcat /opt/tomcat
sudo chmod -R u+x /opt/tomcat/bin

Step 5: Create a Systemd Service File

To manage Tomcat as a background service, create a new systemd service file:

sudo nano /etc/systemd/system/tomcat.service

Paste the following configuration into the file:

[Unit]
Description=Apache Tomcat Web Application Container
After=network.target

[Service]
Type=forking

User=tomcat
Group=tomcat

Environment="JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64"
Environment="CATALINA_PID=/opt/tomcat/temp/tomcat.pid"
Environment="CATALINA_HOME=/opt/tomcat"
Environment="CATALINA_BASE=/opt/tomcat"
Environment="CATALINA_OPTS=-Xms512M -Xmx1024M -server -XX:+UseParallelGC"
Environment="JAVA_OPTS=-Djava.awt.headless=true -Djava.security.egd=file:/dev/./urandom"

ExecStart=/opt/tomcat/bin/startup.sh
ExecStop=/opt/tomcat/bin/shutdown.sh

[Install]
WantedBy=multi-user.target

Save and close the file. Reload the systemd daemon to register the new service, then start and enable Tomcat:

sudo systemctl daemon-reload
sudo systemctl start tomcat
sudo systemctl enable tomcat

Verify that the service is running:

sudo systemctl status tomcat

Step 6: Configure Firewall

If Uncomplicated Firewall (UFW) is enabled, allow traffic on port 8080:

sudo ufw allow 8080/tcp

Step 7: Configure Tomcat Web Management Interface

To access the Manager and Host Manager web applications, define admin roles and credentials in the tomcat-users.xml file:

sudo nano /opt/tomcat/conf/tomcat-users.xml

Add the following block inside the <tomcat-users> tags, replacing your_password with a secure password:

<role rolename="manager-gui"/>
<role rolename="manager-script"/>
<role rolename="hosts-manager"/>
<role rolename="admin-gui"/>
<user username="admin" password="your_password" roles="manager-gui,manager-script,hosts-manager,admin-gui"/>

Remove IP Restrictions for Remote Access

By default, the Manager and Host Manager interfaces are restricted to local connections. To access them remotely, comment out the IP restriction blocks in their respective context.xml files.

For the Manager App:

sudo nano /opt/tomcat/webapps/manager/META-INF/context.xml

For the Host Manager App:

sudo nano /opt/tomcat/webapps/host-manager/META-INF/context.xml

In both files, comment out the Valve element like this:

<!-- 
  <Valve className="org.apache.catalina.valves.RemoteAddrValve"
         allow="127\.\d+\.\d+\.\d+|::1|0:0:0:0:0:0:0:1" />
-->

Restart Tomcat to apply the configuration changes:

sudo systemctl restart tomcat

You can now test your installation by navigating to http://your_server_ip:8080 in your web browser.
