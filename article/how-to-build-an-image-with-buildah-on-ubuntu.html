How to Build an Image with Buildah on Ubuntu

This article explains how to build Open Container Initiative (OCI) and Docker-compatible container images on an Ubuntu system using Buildah. You will learn the primary command used for building images from a Containerfile or Dockerfile, the basic installation steps for Ubuntu, and an alternative command-line approach to building images without a Dockerfile.

The Primary Build Command

The standard command used to build a container image with Buildah is buildah bud (short for "build-using-dockerfile") or its alias buildah build.

The syntax is:

buildah bud -t <image-name>:<tag> <context-directory>

Alternatively, you can run:

buildah build -t <image-name>:<tag> <context-directory>

By default, Buildah looks for a file named Containerfile or Dockerfile inside the specified context directory.

Installing Buildah on Ubuntu

Buildah is available directly from the standard Ubuntu package repositories (Ubuntu 20.10 and later). Update your package lists and install it with:

sudo apt update
sudo apt install -y buildah

Step-by-Step Build Example

  1. Create a project directory and navigate into it:
mkdir my-app && cd my-app
  1. Create a basic Dockerfile:
FROM ubuntu:22.04
RUN apt-get update && apt-get install -y curl
CMD ["echo", "Hello from Buildah!"]
  1. Execute the build command:
buildah bud -t my-app:latest .

To specify a custom Dockerfile path, use the -f flag:

buildah bud -f /path/to/CustomDockerfile -t my-app:latest .

Building Images Step-by-Step Without a Dockerfile

Buildah also supports building images programmatically directly from the command line without writing a Dockerfile:

  1. Create a working container from a base image:
container=$(buildah from ubuntu:22.04)
  1. Execute commands inside the container:
buildah run $container apt-get update
buildah run $container apt-get install -y curl
buildah config --cmd 'echo "Hello from Buildah!"' $container
  1. Commit the changes to a new image:
buildah commit $container my-app:manual
  1. Clean up the working container:
buildah rm $container

Verifying Built Images

To view the locally built images stored in the local storage, run:

buildah images
