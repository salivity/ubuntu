How to Use NetHogs to Monitor Process Bandwidth in Ubuntu

Monitoring network bandwidth usage per process in Ubuntu allows you to pinpoint exactly which application or system service is consuming your network traffic. Unlike traditional network monitoring tools that show bandwidth usage per network interface or protocol, nethogs groups bandwidth consumption by individual process PID and user. This step-by-step guide covers how to install, run, and effectively use nethogs on an Ubuntu system to troubleshoot high network usage.

What is NetHogs?

nethogs is a small open-source terminal application that breaks down network traffic per process. Instead of showing the total traffic passing through a network card (like iftop) or breaking down traffic by connection (like netstat), it displays real-time uploaded and downloaded data per process PID, making it easy to spot bandwidth-hogging applications.

Installing NetHogs on Ubuntu

nethogs is available directly in the default Ubuntu package repositories.

Open your terminal and run the following commands to update your package list and install nethogs:

sudo apt update
sudo apt install nethogs -y

Running NetHogs

Because nethogs captures raw network packets, it requires root privileges to run.

1. Default Execution

To start monitoring all default active network interfaces, run:

sudo nethogs

2. Monitoring a Specific Interface

If your machine has multiple network interfaces (such as Ethernet and Wi-Fi), you can specify the target interface.

First, list your available network interfaces:

ip addr

Then, pass the interface name (e.g., eth0, wlan0, or enp3s0) to nethogs:

sudo nethogs eth0

3. Monitoring Multiple Interfaces Simultaneously

You can monitor multiple interfaces at once by listing them separated by spaces:

sudo nethogs eth0 wlan0

Reading the NetHogs Display

When nethogs runs, it presents a dynamic table with the following columns:

  • PROGRAM: The process name, PID, and executing user account (e.g., /usr/bin/firefox/12345/root).
  • SENT: The amount of data sent by the process per second.
  • RECEIVED: The amount of data received by the process per second.

At the bottom of the screen, nethogs displays the total combined bandwidth consumption.

NetHogs Interactive Controls

While nethogs is running in your terminal, you can interact with it using keyboard shortcuts:

  • m: Cycle through display units (KB/s, KB, B, MB).
  • r: Sort the list by received traffic (download speed).
  • s: Sort the list by sent traffic (upload speed).
  • q: Quit the application.

Useful NetHogs Command Options

You can modify how nethogs runs by adding flags to the startup command:

  • Set Refresh Delay: Change the update interval in seconds (default is 1 second). To update every 3 seconds:

    sudo nethogs -d 3

  • Tracemode: Run in trace mode to log process traffic sequentially instead of using interactive UI:

    sudo nethogs -t

  • Device-only Mode: Monitor without resolving process names (useful for reducing CPU overhead):

    sudo nethogs -b
