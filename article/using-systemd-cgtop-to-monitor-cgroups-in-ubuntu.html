Using systemd-cgtop to Monitor Cgroups in Ubuntu

systemd-cgtop is a native Linux monitoring utility that displays real-time resource utilization organized by control groups (cgroups). This guide explains how to launch and configure systemd-cgtop on Ubuntu to track CPU, memory, task counts, and I/O consumption across system services, user sessions, and containers.

Launching systemd-cgtop

To monitor all system slices and service cgroups accurately, run systemd-cgtop with administrative privileges:

sudo systemd-cgtop

Once launched, the tool displays an interactive interface similar to standard top, but hierarchically structured by cgroup paths (such as system.slice, user.slice, and specific .service units) instead of individual process IDs (PIDs).

Understanding the Interface Columns

The output is divided into several primary metrics:

  • Control Group: The cgroup path or systemd unit name.
  • Tasks: The total number of processes or threads currently running within that specific control group.
  • %CPU: The percentage of CPU time currently consumed by the group.
  • Memory: The current physical memory (RAM) allocation of the group.
  • Input/s and Output/s: The disk I/O throughput (read and write rates) attributed to the group.

Interactive Sorting Controls

While systemd-cgtop is running, you can change how rows are sorted using single-key shortcuts:

  • C: Sort by CPU usage.
  • M: Sort by memory consumption.
  • I: Sort by I/O write rate.
  • T: Sort by task count.
  • P: Sort alphabetically by cgroup path.
  • + / -: Increase or decrease the update interval.
  • q: Exit the application.

Common Command-Line Options

You can modify the default behavior by passing flags directly to the command:

  • Set the refresh interval: Use -d to specify the delay in seconds between updates. 
    sudo systemd-cgtop -d 5
  • Set default sort order: Use --order= with cpu, memory, io, tasks, or path. 
    sudo systemd-cgtop --order=memory
  • Run a fixed number of iterations: Use -n to limit output updates, which is useful for logging snapshots. 
    sudo systemd-cgtop -n 1
  • Batch mode for scripting: Combine -b (batch mode) with -n to dump clean text to standard output without terminal escape sequences. 
    sudo systemd-cgtop -b -n 1 > cgroup_snapshot.txt
