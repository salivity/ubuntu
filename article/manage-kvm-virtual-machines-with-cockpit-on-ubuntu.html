Manage KVM Virtual Machines with Cockpit on Ubuntu

Managing Kernel-based Virtual Machines (KVM) on Ubuntu does not require complex command-line operations or heavy desktop interfaces. By pairing Ubuntu's native virtualization stack with the Cockpit web console and its cockpit-machines add-on, administrators can deploy, configure, and monitor virtual machines directly from any modern web browser. This guide provides a straightforward walkthrough for installing the necessary KVM and Cockpit packages, accessing the dashboard, and executing standard VM management tasks.

1. Install KVM and Cockpit Machines

Ensure hardware virtualization is enabled in your system BIOS/UEFI. Open a terminal on your Ubuntu server and update your package lists:

sudo apt update

Install the KVM hypervisor, essential management tools, Cockpit, and the Cockpit Machines extension:

sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils cockpit cockpit-machines

2. Enable and Start the Cockpit Service

After installation, start and enable the Cockpit socket so it launches automatically on system boot:

sudo systemctl enable --now cockpit.socket

Verify that the virtualization daemon is also running:

sudo systemctl status libvirtd

If your user account is not root, add your user to the libvirt and kvm groups to manage machines without permission errors:

sudo usermod -aG libvirt,kvm $USER

Note: Log out and log back in for group membership changes to take effect.

3. Access the Web Interface

  1. Open a web browser and navigate to https://<YOUR-SERVER-IP>:9090.
  2. Accept the self-signed SSL certificate warning if prompted.
  3. Log in with your standard Ubuntu system credentials. Check the Reuse my password for privileged tasks box to grant administrative rights.

4. Create a New Virtual Machine

  1. In the left-hand navigation sidebar, click on Virtual Machines.
  2. Click the Create VM button in the upper-right corner.
  3. Configure the machine parameters:
    • Name: Enter a unique identifier for the VM.
    • Installation Type: Choose between an ISO image file, network install (PXE), or cloud image.
    • Source: Provide the path to the ISO file on your server storage.
    • Memory: Allocate RAM (e.g., 2048 MiB or 4096 MiB).
    • Size: Define the virtual disk capacity.
    • Network: Select the default virtual network bridge.
  4. Click Create and Run to boot the installer, or Create and Edit to adjust hardware settings before the first boot.

5. Manage VMs Visually

Within the Virtual Machines dashboard, click on any virtual machine to access its management panel:

  • Console: Access the interactive graphical (VNC) or serial text console directly inside the browser tab to perform operating system installations and troubleshooting.
  • Power Operations: Use the dedicated action buttons to start, shut down, force off, restart, or pause the guest system.
  • Hardware Configuration: Add or remove virtual disks, attach network interfaces, and scale virtual CPU (vCPU) and RAM allocations.
  • Snapshots: Navigate to the Snapshots tab to capture and restore point-in-time states before testing system updates or configuration changes.
  • Usage Metrics: Review real-time resource utilization graphs for CPU, memory, and network throughput directly from the VM overview tab.
