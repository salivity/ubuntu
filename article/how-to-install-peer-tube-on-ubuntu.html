How to Install PeerTube on Ubuntu

This guide provides a direct walkthrough of how to deploy your own PeerTube decentralized video sharing instance on an Ubuntu server. You will learn the necessary prerequisites, how to install system dependencies, and the exact commands required to download, configure, and launch the PeerTube service.

1. Install System Dependencies

PeerTube relies on Node.js, PostgreSQL, Redis, FFmpeg, and Nginx. Update your package lists and install the core dependencies by running:

sudo apt update && sudo apt install -y curl gnupg ffmpeg postgresql postgresql-contrib redis-server nginx certbot python3-certbot-nginx unzip

Next, install Node.js (version 18 or 20) and Yarn:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g yarn

2. Configure PostgreSQL

Create a dedicated database and database user for PeerTube:

sudo -u postgres createuser -P peertube
sudo -u postgres createdb -O peertube peertube_prod
sudo -u postgres psql -c "CREATE EXTENSION pg_trgm;" peertube_prod
sudo -u postgres psql -c "CREATE EXTENSION unaccent;" peertube_prod

3. Create the PeerTube System User and Directories

Create a dedicated peertube user with a home directory:

sudo useradd -m -d /var/www/peertube -s /bin/bash -p '*' peertube
sudo -u peertube mkdir -p /var/www/peertube/config /var/www/peertube/storage /var/www/peertube/versions

4. Download and Install PeerTube

Fetch the latest release version, extract it, and install production dependencies:

VERSION=$(curl -s https://api.github.com/repos/Chocobozzz/PeerTube/releases/latest | grep tag_name | cut -d '"' -f 4)
cd /var/www/peertube/versions
sudo -u peertube wget -q "https://github.com/Chocobozzz/PeerTube/releases/download/${VERSION}/peertube-${VERSION}.zip"
sudo -u peertube unzip -q "peertube-${VERSION}.zip"
sudo -u peertube rm "peertube-${VERSION}.zip"
cd /var/www/peertube
sudo -u peertube ln -s "versions/peertube-${VERSION}" ./peertube-latest
cd ./peertube-latest
sudo -u peertube yarn install --production --pure-lockfile

5. Configure the Instance

Copy the default production configuration template to your configuration directory:

sudo -u peertube cp /var/www/peertube/peertube-latest/config/production.yaml.example /var/www/peertube/config/production.yaml

Edit /var/www/peertube/config/production.yaml using a text editor to set your domain name, PostgreSQL credentials, and administrator email address.

6. Set Up Nginx and Systemd

Copy the systemd service file to manage the PeerTube daemon:

sudo cp /var/www/peertube/peertube-latest/support/systemd/peertube.service /etc/systemd/system/
sudo systemctl daemon-reload

Copy the Nginx template to route web traffic to your application:

sudo cp /var/www/peertube/peertube-latest/support/nginx/peertube /etc/nginx/sites-available/peertube
sudo sed -i 's/${WEBSERVER_HOST}/your-domain.com/g' /etc/nginx/sites-available/peertube
sudo ln -s /etc/nginx/sites-available/peertube /etc/nginx/sites-enabled/

Generate an SSL certificate via Certbot and reload Nginx:

sudo certbot --nginx -d your-domain.com
sudo systemctl restart nginx

7. Start PeerTube

Enable and start the PeerTube service:

sudo systemctl enable --now peertube

Once running, retrieve your generated administrator password directly from the system logs:

sudo journalctl -u peertube | grep "Administrator username" -A 1
