Configure Nginx Layer 4 Load Balancer on Ubuntu

This guide explains how to set up Nginx as a Layer 4 (TCP/UDP) load balancer on Ubuntu. You will learn how to install the required stream module, define backend server pools, configure transport-level routing for both TCP and UDP protocols, and test the configuration to distribute network traffic efficiently.

1. Install Nginx and the Stream Module

Layer 4 load balancing in Nginx requires the ngx_stream_core_module. On Ubuntu, this is packaged separately or included via the dynamic module package.

Update your package index and install Nginx along with the stream module:

sudo apt update
sudo apt install nginx libnginx-mod-stream -y

Verify that the service is running:

sudo systemctl status nginx

2. Configure the Stream Context

Layer 4 proxying operates at the transport layer, meaning configurations must be placed inside the stream {} block rather than the standard http {} block.

Open the main Nginx configuration file:

sudo nano /etc/nginx/nginx.conf

Scroll to the bottom of the file. Ensure that the stream configuration is included by adding the following block outside of any existing http {} block:

stream {
    include /etc/nginx/conf.d/*.stream;
}

Save and exit the file.

3. Create a TCP Load Balancer Configuration

Create a new configuration file for your TCP service (such as a database, SSH, or custom service) in /etc/nginx/conf.d/:

sudo nano /etc/nginx/conf.d/tcp_balancer.stream

Add the following configuration, adjusting IP addresses and ports to match your backend servers:

upstream backend_tcp_servers {
    # Load balancing method: least_conn, hash, or round-robin (default)
    least_conn;

    server 192.168.1.10:3306 max_fails=3 fail_timeout=30s;
    server 192.168.1.11:3306 max_fails=3 fail_timeout=30s;
}

server {
    listen 3306; # Port Nginx listens on
    proxy_pass backend_tcp_servers;
    proxy_timeout 3s;
    proxy_connect_timeout 1s;
}

4. Create a UDP Load Balancer Configuration (Optional)

If you are balancing UDP traffic (such as DNS or Syslog), create another stream configuration file:

sudo nano /etc/nginx/conf.d/udp_balancer.stream

Add the configuration below. The udp parameter must be appended to the listen directive:

upstream backend_udp_servers {
    server 192.168.1.20:53;
    server 192.168.1.21:53;
}

server {
    listen 53 udp;
    proxy_pass backend_udp_servers;
    proxy_timeout 1s;
    proxy_responses 1;
}

5. Validate and Reload Nginx

Always test your configuration syntax before applying changes:

sudo nginx -t

If the test is successful, reload Nginx to apply the new load balancing rules:

sudo systemctl reload nginx

6. Verify Traffic Flow

To verify that Nginx is listening on the configured Layer 4 ports, check active network sockets with ss:

sudo ss -tulpn | grep -E '3306|53'

Send traffic to the Nginx listener port from a remote client to confirm that connections are balanced across your target backend servers.
