How to Install Apache Cassandra on Ubuntu

This guide outlines the step-by-step procedure for installing the Apache Cassandra distributed NoSQL database on an Ubuntu system. It covers preparing the operating system, installing the required Java runtime environment, configuring the official Apache repositories, installing the Cassandra package, and verifying that the database node is running correctly.

Prerequisites

Before proceeding, ensure you have:

  • An Ubuntu 20.04 or 22.04 LTS server.
  • A user account with sudo administrative privileges.
  • At least 2GB of RAM (4GB or more is recommended for stable performance).

Step 1: Install Java OpenJDK

Apache Cassandra is a Java-based application and requires a Java Development Kit (JDK) or Java Runtime Environment (JRE). Cassandra 4.x supports OpenJDK 11.

  1. Update the local package index:

    sudo apt update

  2. Install OpenJDK 11:

    sudo apt install openjdk-11-jdk -y

  3. Verify the Java installation:

    java -version

    The output should confirm the installation of OpenJDK version 11.

Step 2: Install Supporting Dependencies

Install apt-transport-https and curl to enable package retrieval over HTTPS and download repository signing keys:

sudo apt install apt-transport-https curl gnupg -y

Step 3: Add the Apache Cassandra Repository

Ubuntu does not include the latest Cassandra packages in its default repositories. You must add the official Apache repository.

  1. Add the Apache Cassandra repository signing key:

    curl -fsSL https://downloads.apache.org/cassandra/KEYS | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/cassandra.gpg

  2. Add the Cassandra package repository to your sources list (for Cassandra version 4.1.x):

    echo "deb https://debian.cassandra.apache.org 41x main" | sudo tee -a /etc/apt/sources.list.d/cassandra.sources.list

Step 4: Install Cassandra

  1. Refresh the package repository cache to include the newly added repository:

    sudo apt update

  2. Install Apache Cassandra:

    sudo apt install cassandra -y

Once the installation finishes, the Cassandra service will automatically start.

Step 5: Verify the Service Status

Confirm that the Cassandra daemon is active and running:

sudo systemctl status cassandra

You should see output indicating that the service is active (running). To ensure Cassandra starts automatically on system boot:

sudo systemctl enable cassandra

Step 6: Verify Cluster and Node Status

Cassandra provides the nodetool utility to monitor cluster health and node statistics. Check the status of your node:

sudo nodetool status

The output will display the status of the node:

  • UN stands for Up and Normal, indicating that the database is functional and ready to accept connections.

Step 7: Connect via CQLSH

Cassandra includes the Cassandra Query Language shell (cqlsh) for executing database queries and administrative tasks:

cqlsh

Upon connection, the prompt displays the connected cluster name, CQL version, and Cassandra version. Type exit to quit the prompt.
