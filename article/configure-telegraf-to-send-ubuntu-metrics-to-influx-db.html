Configure Telegraf to Send Ubuntu Metrics to InfluxDB

This guide provides a step-by-step walkthrough for collecting Ubuntu system performance data and transmitting it to an InfluxDB instance using the Telegraf agent. You will learn how to install Telegraf on Ubuntu, configure the output plugin for InfluxDB v2, enable default system monitoring inputs, and verify the continuous stream of telemetry metrics.

Step 1: Install Telegraf on Ubuntu

First, update your local package lists, install prerequisite tools, and add the official InfluxData repository.

sudo apt-get update
sudo apt-get install -y wget gnupg software-properties-common

# Add InfluxData GPG key
wget -q https://repos.influxdata.com/influxdata-archive_compat.key
echo '393eadd023e38720281b5a542b8618b6d821a4e8fb6ec3e3f67266492e8c4149 influxdata-archive_compat.key' | sha256sum -c && cat influxdata-archive_compat.key | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/influxdata-archive_compat.gpg > /dev/null
rm -f influxdata-archive_compat.key

# Add the repository to apt sources
echo 'deb [signed-by=/etc/apt/trusted.gpg.d/influxdata-archive_compat.gpg] https://repos.influxdata.com/ubuntu focal stable' | sudo tee /etc/apt/sources.list.d/influxdata.list

# Update package list and install Telegraf
sudo apt-get update
sudo apt-get install -y telegraf

Step 2: Configure the InfluxDB Output Plugin

Telegraf uses /etc/telegraf/telegraf.conf as its primary configuration file. Back up the original file, then open it in your preferred text editor.

sudo cp /etc/telegraf/telegraf.conf /etc/telegraf/telegraf.conf.bak
sudo nano /etc/telegraf/telegraf.conf

Locate or define the [[outputs.influxdb_v2]] section to connect to your InfluxDB v2 instance. Supply your server URL, API token, organization name, and target bucket:

[[outputs.influxdb_v2]]
  urls = ["http://<YOUR_INFLUXDB_HOST>:8086"]
  token = "YOUR_API_TOKEN"
  organization = "YOUR_ORG_NAME"
  bucket = "YOUR_BUCKET_NAME"

Replace the placeholders (urls, token, organization, and bucket) with your actual InfluxDB connection details.

Step 3: Configure System Metrics Inputs

By default, Telegraf includes core input plugins for monitoring host performance. Ensure the following input plugins are enabled in your configuration to capture essential Ubuntu metrics:

# Read metrics about CPU usage
[[inputs.cpu]]
  percpu = true
  totalcpu = true
  collect_cpu_time = false
  report_active = false

# Read metrics about system load & uptime
[[inputs.system]]

# Read metrics about memory usage
[[inputs.mem]]

# Read metrics about disk usage
[[inputs.disk]]
  ignore_fs = ["tmpfs", "devtmpfs", "devfs", "iso9660", "overlay", "aufs", "squashfs"]

# Read metrics about disk IO
[[inputs.diskio]]

# Read metrics about network interfaces
[[inputs.net]]

# Read metrics about processes
[[inputs.processes]]

Step 4: Validate the Configuration

Before starting the daemon, run a single-pass test to ensure Telegraf parses the configuration correctly and outputs the collected metrics to stdout.

telegraf --config /etc/telegraf/telegraf.conf --test

If configured properly, Telegraf will print system metrics (such as CPU, memory, and disk statistics) to the terminal without errors.

Step 5: Start and Enable the Telegraf Service

Once the validation test succeeds, enable Telegraf to run on system boot and start the service immediately.

sudo systemctl enable --now telegraf

Check the status of the service to verify that it is running:

sudo systemctl status telegraf

Your Ubuntu machine is now continuously gathering system metrics and sending them directly to your specified InfluxDB bucket. You can verify incoming data by visiting the Data Explorer interface inside InfluxDB.
