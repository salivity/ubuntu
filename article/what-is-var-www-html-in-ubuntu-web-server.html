What Is /var/www/html in Ubuntu Web Server?

The /var/www/html directory is the default document root folder used by web servers like Apache and Nginx on Ubuntu Linux systems to host and serve web content. When a user requests a website via a web browser using the server’s IP address or domain name, the web server looks into this specific directory to locate and render the requested files, such as HTML pages, stylesheets, scripts, and media.

The Role of /var/www/html

In Linux file systems, /var/www/html acts as the public-facing directory for website content. By default, fresh installations of Apache or Nginx automatically generate a default index.html file inside this folder. This file serves as the landing page, confirming that the web server software is installed correctly and running smoothly.

Understanding the Directory Path Structure

The path /var/www/html is structured logically based on the Filesystem Hierarchy Standard (FHS):

  • /var: Contains variable data files—files whose contents are expected to grow or change continuously during normal system operation, such as logs, databases, and web content.
  • /www: Dedicated to hosting data related to the World Wide Web.
  • /html: The default root directory intended for public HTML files and website assets.

Default File Serving Process

When a browser sends an HTTP request to your server:

  1. The web server (Apache or Nginx) intercepts the incoming connection.
  2. The server checks its configuration files for the primary “Document Root.”
  3. By default, the server points to /var/www/html.
  4. The server looks for an index file (such as index.html or index.php) inside /var/www/html and serves it to the user.

File Ownership and Permissions

By default, the /var/www/html directory is owned by the root user or the web server’s service user, typically www-data on Ubuntu.

To allow non-root users to upload and manage website files without using elevated privileges, administrators often transfer directory ownership to a specific user or group while maintaining proper permission levels:

sudo chown -R $USER:www-data /var/www/html
sudo chmod -R 755 /var/www/html

Using Multiple Websites (Virtual Hosts)

While /var/www/html works well for a single website, web servers on Ubuntu can host multiple domain names using virtual hosts (Apache) or server blocks (Nginx). In these scenarios, administrators often leave /var/www/html as the fallback directory and create new subdirectories inside /var/www/ for individual websites, such as /var/www/example.com/html.
