Monitor Wireless Networks with Aircrack-ng on Ubuntu

This guide covers how to set up and configure the Aircrack-ng suite to monitor nearby wireless networks on Ubuntu. You will learn how to verify your Wi-Fi adapter's capabilities, install the required packages, place your interface into monitor mode, and capture ambient 802.11 frames using airodump-ng.

1. Prerequisites and Adapter Compatibility

Before starting, ensure your external or internal Wi-Fi adapter supports monitor mode and packet injection. Common chipsets that support these features out of the box on Linux include:

  • Atheros (e.g., AR9271)
  • Ralink/MediaTek (e.g., RT3070, RT5370, MT7601U)
  • Realtek (e.g., RTL8812AU – may require manual driver installation)

Connect your Wi-Fi adapter to your Ubuntu machine before proceeding.

2. Install Aircrack-ng

Open your terminal and update your package lists, then install the Aircrack-ng suite from the official Ubuntu repositories:

sudo apt update
sudo apt install aircrack-ng -y

Verify the installation by running:

aircrack-ng --help

3. Identify Your Wireless Interface

Identify the name of your wireless interface using the airmon-ng command:

sudo airmon-ng

Alternatively, you can run:

ip link show

Locate your wireless device in the output (typically named wlan0, wlan1, or an alternative naming scheme like wlp3s0).

4. Kill Conflicting Processes

Network management daemons such as NetworkManager and wpa_supplicant often interfere with monitor mode. Terminate these conflicting processes:

sudo airmon-ng check kill

Note: This command will temporarily disconnect you from any active Wi-Fi connections.

5. Enable Monitor Mode

To switch your wireless interface from standard station (managed) mode to monitor mode, run:

sudo airmon-ng start wlan0

(Replace wlan0 with your actual interface name).

Once enabled, airmon-ng will display the name of the new monitor-enabled interface. It usually appends mon to the original name (for example, wlan0mon).

Verify the change using iwconfig:

iwconfig

Look for the Mode:Monitor status next to your interface name.

6. Monitor Wireless Traffic with Airodump-ng

With the interface set to monitor mode, begin capturing nearby wireless network data:

sudo airodump-ng wlan0mon

(Replace wlan0mon with your newly created monitor interface).

Airodump-ng displays a live-updating screen split into two sections:

  • Upper section: Detected Access Points (BSSID, signal strength/PWR, beacon rate, encryption type, channel, and ESSID/network name).
  • Lower section: Connected client devices (Stations) and the corresponding BSSID they communicate with.

To target a specific channel and write the captured frames to a file for analysis:

sudo airodump-ng -c 6 --bssid 00:11:22:33:44:55 -w capture_output wlan0mon

Press Ctrl + C at any time to stop monitoring.

7. Disable Monitor Mode and Restore Networking

When finished, disable monitor mode to return your adapter to its standard operational state:

sudo airmon-ng stop wlan0mon

Restart your system's network services to restore standard internet access:

sudo systemctl restart NetworkManager
