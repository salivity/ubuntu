Install and Configure Nextcloud on Ubuntu

This step-by-step guide walks you through installing and configuring the Nextcloud private cloud platform on an Ubuntu server. You will learn how to set up the necessary LAMP (Linux, Apache, MySQL, PHP) stack, download and deploy Nextcloud, configure a dedicated database, and secure your installation with an SSL certificate for safe remote access to your personal files.

Prerequisites

Before starting, ensure you have: * An Ubuntu server (22.04 LTS or newer recommended) with a non-root user possessing sudo privileges. * A domain name pointing to your server’s public IP address.

Step 1: Update the System

Update your local package index and upgrade existing software packages to ensure your system is secure and up to date.

sudo apt update && sudo apt upgrade -y

Step 2: Install the LAMP Stack

Nextcloud requires a web server, a database, and PHP to function properly.

  1. Install Apache, MariaDB, and required PHP modules:
sudo apt install apache2 mariadb-server libapache2-mod-php php-gd php-mysql php-curl php-mbstring php-intl php-gmp php-bcmath php-xml php-curl php-zip -y
  1. Enable and start Apache and MariaDB services:
sudo systemctl enable --now apache2
sudo systemctl enable --now mariadb

Step 3: Configure the MariaDB Database

Run the secure installation script to harden your MariaDB deployment:

sudo mysql_secure_installation

Follow the prompts to set a root password, remove anonymous users, disallow root login remotely, and remove the test database.

Next, create a database and user for Nextcloud:

sudo mysql -u root -p

Execute the following SQL commands (replace your_password with a strong password):

CREATE DATABASE nextcloud CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
GRANT ALL ON nextcloud.* TO 'nextclouduser'@'localhost' IDENTIFIED BY 'your_password';
FLUSH PRIVILEGES;
EXIT;

Step 4: Download and Extract Nextcloud

  1. Download the latest version of Nextcloud from the official site:
cd /tmp
wget https://download.nextcloud.com/server/releases/latest.tar.bz2
  1. Extract the archive into the Apache web root folder:
tar -xjvf latest.tar.bz2
sudo mv nextcloud /var/www/
  1. Set the correct directory ownership and permissions for the Apache web user:
sudo chown -R www-data:www-data /var/www/nextcloud
sudo chmod -R 755 /var/www/nextcloud

Step 5: Configure Apache for Nextcloud

Create an Apache virtual host configuration file for Nextcloud.

sudo nano /etc/apache2/sites-available/nextcloud.conf

Add the following configuration (replace your_domain.com with your actual domain):

<VirtualHost *:80>
    ServerAdmin admin@your_domain.com
    DocumentRoot /var/www/nextcloud/
    ServerName your_domain.com

    <Directory /var/www/nextcloud/>
       Options +FollowSymlinks
       AllowOverride All
       Require all granted
          <IfModule mod_dav.c>
            Dav off
          </IfModule>
       SetEnv HOME /var/www/nextcloud
       SetEnv HTTP_HOME /var/www/nextcloud
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
</VirtualHost>

Enable the new site configuration along with the required Apache modules:

sudo a2ensite nextcloud.conf
sudo a2enmod rewrite headers env dir mime
sudo systemctl restart apache2

Step 6: Secure Nextcloud with Let’s Encrypt SSL

To secure your server with HTTPS, install Certbot and acquire an SSL certificate:

sudo apt install certbot python3-certbot-apache -y
sudo certbot --apache -d your_domain.com

Follow the on-screen prompts to complete the SSL setup. Certbot will automatically rewrite your Apache configuration to enforce HTTPS traffic.

Step 7: Complete Nextcloud Web Setup

  1. Open your web browser and navigate to https://your_domain.com.
  2. Create an admin account by entering a username and password.
  3. Under Data folder, leave the default path or specify a custom storage location.
  4. Under Database configuration, select MySQL/MariaDB and enter the details created earlier:
    • Database user: nextclouduser
    • Database password: your_password
    • Database name: nextcloud
    • Host: localhost
  5. Click Install to finish the setup process.
