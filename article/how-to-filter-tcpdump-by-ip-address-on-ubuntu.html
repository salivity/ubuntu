How to Filter tcpdump by IP Address on Ubuntu

Capturing network traffic for a single IP address using tcpdump is an essential skill for diagnosing network issues, monitoring connections, and analyzing security events on Ubuntu. This guide explains how to install the tool, find your network interfaces, and use specific syntax filters to capture traffic originating from, destined to, or exchanged with a designated IP address.

1. Install tcpdump

Most Ubuntu installations include tcpdump by default. If it is not present on your system, update your package index and install it via the terminal:

sudo apt update
sudo apt install tcpdump -y

2. Identify the Target Network Interface

Before running a capture, determine which interface handles the traffic. Run the following command to list available interfaces:

ip link show

Take note of the interface name you want to monitor (for example, eth0 or enp3s0). You can also use any to listen on all active interfaces.

3. Capture Packets for a Specific IP

To capture packets where the specified IP is either the sender or the receiver, use the host directive followed by the target IP address.

sudo tcpdump -i eth0 host 192.168.1.50

To prevent tcpdump from converting IP addresses to hostnames (which can slow down the output and clutter results), add the -n flag:

sudo tcpdump -n -i eth0 host 192.168.1.50

4. Filter by Traffic Direction

If you want to narrow your capture further, specify whether the target IP is the source or the destination.

  • Capture packets sent by the IP (Source):

    sudo tcpdump -n -i eth0 src host 192.168.1.50

  • Capture packets received by the IP (Destination):

    sudo tcpdump -n -i eth0 dst host 192.168.1.50

5. Combine IP Filters with Other Parameters

You can combine IP filters with protocols or port numbers using logical operators like and or or.

  • Filter by IP and Port (e.g., HTTP/Port 80):

    sudo tcpdump -n -i eth0 host 192.168.1.50 and port 80

  • Filter by IP and Protocol (e.g., ICMP/Ping):

    sudo tcpdump -n -i eth0 host 192.168.1.50 and icmp

6. Save the Capture to a File

To analyze the captured data later in tools like Wireshark, write the output to a .pcap file using the -w option:

sudo tcpdump -n -i eth0 host 192.168.1.50 -w ip_capture.pcap

Stop the capture at any time by pressing Ctrl + C.
