How to Set Up Docker Swarm on Ubuntu Server

This guide provides a straightforward walkthrough for setting up Docker Swarm mode and initializing a primary manager node on an Ubuntu server. You will learn how to configure the necessary firewall rules, install the Docker Engine, initialize the Swarm cluster using the correct network interface, and retrieve join tokens for adding future nodes to your infrastructure.

Prerequisites

Before starting, ensure you have:

  • An Ubuntu server (20.04, 22.04, or 24.04 LTS).
  • A user account with sudo privileges.
  • A static internal or public IP address assigned to the server.

Step 1: Install Docker Engine

If Docker is not already installed on your Ubuntu server, update your package index and install Docker CE.

Update the local package index:

sudo apt update && sudo apt upgrade -y

Install the required packages to allow apt to use a repository over HTTPS:

sudo apt install -y ca-certificates curl gnupg lsb-release

Add Docker’s official GPG key:

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

Set up the Docker repository:

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

Install Docker Engine:

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

Ensure Docker starts on boot and is running:

sudo systemctl enable docker
sudo systemctl status docker

Step 2: Configure the Firewall

Docker Swarm requires specific network ports to communicate across nodes in the cluster. If you are using UFW (Uncomplicated Firewall), open the following ports:

  • TCP port 2377: For cluster management communications.
  • TCP and UDP port 7946: For communication among nodes (node discovery).
  • UDP port 4789: For overlay network traffic (container ingress networking).

Run the following commands to open these ports:

sudo ufw allow 2377/tcp
sudo ufw allow 7946/tcp
sudo ufw allow 7946/udp
sudo ufw allow 4789/udp
sudo ufw reload

Step 3: Initialize the Swarm Manager Node

To turn the standalone Docker server into a Swarm manager, run the docker swarm init command.

If your host has multiple network interfaces (such as an internal private IP and an external public IP), explicitly declare the advertise address using the --advertise-addr flag.

Identify your preferred IP address:

ip addr show

Initialize the Swarm manager:

sudo docker swarm init --advertise-addr <YOUR_SERVER_IP>

Replace <YOUR_SERVER_IP> with the actual IP address of your Ubuntu server (for example, 192.168.1.100).

Upon initialization, the terminal will display output confirming the swarm is active, along with a generated command containing a join token for adding worker nodes.

Step 4: Verify the Swarm Status

Verify that Docker Swarm mode is active and that your current server is designated as the manager:

sudo docker node ls

The output will display the hostname, status, availability, and manager status (marked as Leader).

You can also check the broader cluster details by executing:

sudo docker info

Look for the Swarm: active line in the output.

Step 5: Retrieve Join Tokens

If you need to view the command and token required to connect additional machines to the cluster at a later stage, use the following commands:

To retrieve the token for adding worker nodes:

sudo docker swarm join-token worker

To retrieve the token for adding additional manager nodes (for high-availability setups):

sudo docker swarm join-token manager
