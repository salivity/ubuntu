How to Permanently Disable Swap in Ubuntu

Disabling the swap partition in Ubuntu requires turning off active swap memory using terminal commands and editing the system configuration file to ensure the changes persist across system reboots. This step-by-step guide covers how to check your current swap usage, safely turn off active swap space, and update your /etc/fstab file to permanently disable swap on your Ubuntu machine.

Step 1: Check Active Swap Space

Before disabling swap, check if your system currently has active swap space enabled. Open your terminal and run the following command:

sudo swapon --show

Alternatively, you can check system memory usage using:

free -h

If swap is active, you will see output listing your swap partition or swap file along with its size.

Step 2: Disable Swap Temporarily

To immediately turn off all active swap space on your system, execute the following command:

sudo swapoff -a

This command turns off swap for the current session. Running free -h again will show 0B for swap memory. However, swap will automatically re-enable upon the next system reboot unless you modify your system configuration.

Step 3: Disable Swap Permanently via /etc/fstab

To prevent Ubuntu from mounting the swap partition or file automatically at startup, you must edit the file systems table (/etc/fstab).

  1. Open the /etc/fstab file in a text editor with root permissions:
sudo nano /etc/fstab
  1. Locate the line that defines the swap partition or swap file. It typically looks like one of the following:
/swapfile                                 none            swap    sw              0       0

or:

UUID=xxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx none            swap    sw              0       0
  1. Comment out the swap entry by adding a hash symbol (#) at the beginning of the line:
#/swapfile                                none            swap    sw              0       0
  1. Save the file and exit the editor (in nano, press Ctrl + O, then Enter to save, and Ctrl + X to exit).

Step 4: Remove the Swap File (Optional)

If your system uses a swap file (commonly located at /swapfile) rather than a dedicated partition and you want to reclaim disk space, you can safely remove it:

sudo rm /swapfile

Note: Skip this step if your system uses a dedicated swap partition.

Step 5: Verify the Changes

Reboot your Ubuntu system to confirm that swap remains disabled after startup:

sudo reboot

After the system restarts, check the swap status once more:

sudo swapon --show

If the command returns no output, and free -h shows 0B total swap space, you have successfully disabled swap permanently.
