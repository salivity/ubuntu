Install and Configure Memcached on Ubuntu

Memcached is an open-source, high-performance memory object caching system designed to speed up dynamic web applications by reducing database load. This guide provides a clear, step-by-step tutorial on how to install, configure, secure, and verify Memcached on an Ubuntu server to help optimize your application's speed and efficiency.

Step 1: Update the System Package List

Before installing any new software, update your local package index to ensure you pull the latest versions.

sudo apt update

Step 2: Install Memcached

Install Memcached along with libmemcached-tools, which provides useful command-line utilities for managing and debugging Memcached.

sudo apt install memcached libmemcached-tools -y

Once installed, the Memcached service starts automatically. Verify its status with:

sudo systemctl status memcached

Ensure the service is active and enabled to start automatically on system boot:

sudo systemctl enable memcached

Step 3: Configure Memcached

The main configuration file for Memcached is located at /etc/memcached.conf. Open this file using a text editor such as nano:

sudo nano /etc/memcached.conf

Adjust the following key parameters based on your requirements:

  • Memory Allocation (-m): Specifies the maximum amount of RAM dedicated to Memcached in megabytes. For example, to set it to 1024 MB (1 GB): 
    -m 1024
  • IP Address Binding (-l): Defines which IP address Memcached listens to. By default, it binds to 127.0.0.1 (localhost) to prevent external access. Keep it set to local unless your application runs on a separate server: 
    -l 127.0.0.1
  • Port Number (-p): Specifies the port Memcached listens on (default is 11211): 
    -p 11211

Save and close the file after making your changes (in nano, press CTRL + O, ENTER, then CTRL + X).

Restart the service to apply the new configuration:

sudo systemctl restart memcached

Step 4: Configure UFW Firewall (Optional)

If your setup requires remote access to Memcached from a specific web server, you must allow incoming traffic on port 11211 via the Uncomplicated Firewall (UFW).

First, edit /etc/memcached.conf to set -l to your server's internal IP address or 0.0.0.0 (all interfaces), then allow access specifically to your web server's IP address:

sudo ufw allow from <WEB_SERVER_IP> to any port 11211

Replace <WEB_SERVER_IP> with the actual client IP address.

Step 5: Verify Memcached Setup

Check if Memcached is actively listening on the assigned IP and port:

sudo netstat -plunt | grep 11211

You can also test the system stats using the memcstat tool:

memcstat --servers="127.0.0.1"

The command returns details such as server uptime, current item count, and active connections, confirming that Memcached is properly functioning.
