How to Generate a Random Password in Ubuntu Terminal

Generating strong, random passwords directly from the Ubuntu terminal can be accomplished using several built-in utilities and dedicated packages. This guide covers the most effective commands for creating secure passwords in Ubuntu, including native options like openssl and /dev/urandom, as well as specialized tools like pwgen and apg.

Method 1: Using OpenSSL (Pre-installed)

The openssl command is installed by default on almost all Ubuntu systems and offers a quick way to generate cryptographically secure random characters.

Run the following command to generate a base64-encoded random password:

openssl rand -base64 14
  • rand: Specifies the random number generator.
  • -base64: Encodes the output using base64 characters.
  • 14: Specifies the length of the raw bytes (the resulting string will be slightly longer).

Method 2: Using pwgen

pwgen is a dedicated utility designed to generate pronounceable or completely random passwords.

First, install pwgen:

sudo apt update && sudo apt install pwgen

To generate a single, highly secure 16-character password containing letters, numbers, and symbols:

pwgen -s -y 16 1
  • -s: Generates a completely random, non-pronounceable password.
  • -y: Includes at least one special character.
  • 16: Sets the length of the password.
  • 1: Specifies how many passwords to generate.

Method 3: Using /dev/urandom with tr

Ubuntu includes special device files like /dev/urandom that serve as pseudo-random number generators. You can filter this output using the tr command to extract specific character sets.

To generate a 16-character alphanumeric password:

tr -dc A-Za-z0-9 </dev/urandom | head -c 16; echo

To include special characters, add them to the character class:

tr -dc 'A-Za-z0-9!@#$%^&*' </dev/urandom | head -c 16; echo

Method 4: Using GPG

GnuPG (gpg) is pre-installed on Ubuntu and includes a random generator function suitable for creating passwords.

Run the following command:

gpg --gen-random --armor 1 16
  • --gen-random: Generates random bytes (the 1 specifies the quality level: 0, 1, or 2).
  • --armor: Encodes the output as ASCII-armored text.
  • 16: Specifies the number of bytes to generate.

Method 5: Using APG (Automated Password Generator)

apg generates random passwords and can provide phonetic pronunciations to make them easier to remember.

Install apg:

sudo apt install apg

Generate a random password:

apg -a 1 -m 16 -n 1 -M NCL
  • -a 1: Uses the random character generation algorithm.
  • -m 16: Sets the minimum password length to 16.
  • -n 1: Generates one password.
  • -M NCL: Ensures the output uses numbers (N), capital letters (C), and lowercase letters (L).
