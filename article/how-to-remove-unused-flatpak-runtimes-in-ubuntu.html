How to Remove Unused Flatpak Runtimes in Ubuntu

Over time, installing and removing Flatpak applications on Ubuntu can leave behind orphaned runtimes, extensions, and libraries that consume significant disk space. This article explains the exact terminal command needed to locate and delete these unused Flatpak dependencies, along with practical tips to keep your Ubuntu system clean.

The Command to Remove Unused Runtimes

To remove all unused Flatpak runtimes and extensions in Ubuntu, open your terminal and run:

flatpak uninstall --unused

How It Works

When you uninstall a Flatpak application, Flatpak does not automatically delete the shared runtimes (such as GNOME or KDE platform frameworks) that the application relied on. These runtimes are preserved in case other applications require them.

The flatpak uninstall --unused command scans your system for any installed runtimes or extensions that are no longer associated with an active application. Before deleting anything, the command displays a list of the orphaned components and asks for your confirmation to proceed.

Step-by-Step Instructions

  1. Open the Ubuntu terminal by pressing Ctrl + Alt + T.
  2. Run the cleanup command: 
    flatpak uninstall --unused
  3. Review the list of runtimes slated for removal.
  4. Type y and press Enter to confirm and free up the disk space.

If you prefer to bypass the confirmation prompt and delete the unused runtimes automatically, use the -y flag:

flatpak uninstall --unused -y

Checking Installed Runtimes

If you want to view all installed Flatpak runtimes prior to removal, run:

flatpak list --runtime

This displays every runtime, architecture, and branch currently stored on your Ubuntu machine, helping you verify which packages are present before and after running the cleanup command.
