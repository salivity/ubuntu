How to Configure ext4 User Quotas in fstab on Ubuntu

Configuring user quotas on an ext4 filesystem in Ubuntu allows system administrators to limit the amount of disk space and number of files a user can consume. The process involves installing the necessary quota packages, modifying the /etc/fstab file to enable quota flags on the target partition, remounting the filesystem, initializing the quota database files, and defining specific limits for individual users.

Step 1: Install the Quota Package

Before modifying system files, install the standard quota management utilities on Ubuntu. Open a terminal and run:

sudo apt update
sudo apt install quota

Step 2: Edit the /etc/fstab File

To enable quotas on an ext4 filesystem, you must edit the disk configuration file located at /etc/fstab.

  1. Open the file in a text editor with root privileges:

    sudo nano /etc/fstab

  2. Locate the line corresponding to the ext4 partition where you want to enable quotas (for example, / or /home).

  3. Add the usrquota option to the mount options column (the fourth column), separated by a comma from existing options like defaults.

    Example before editing:

    UUID=12345678-1234-1234-1234-123456789abc /home ext4 defaults 0 2

    Example after editing:

    UUID=12345678-1234-1234-1234-123456789abc /home ext4 defaults,usrquota 0 2

  4. Save and close the file.

Step 3: Remount the Filesystem

Apply the new mount options without rebooting by remounting the partition:

sudo mount -o remount /home

Replace /home with the actual mount point you edited in /etc/fstab.

Step 4: Create and Initialize Quota Files

Generate the necessary quota index files (aquota.user) on the filesystem:

sudo quotacheck -cum /home
  • -c: Creates new quota files.
  • -u: Checks for user quotas.
  • -m: Forces a check on a read-write mounted filesystem.

Step 5: Enable Quotas

Turn on the quota system for the specified filesystem:

sudo quotaon -v /home

Step 6: Assign Quotas to Users

To set storage limits for a specific user, open the user’s quota editor:

sudo edquota -u username

This opens a text interface showing block limits (disk space) and inode limits (number of files):

  • soft limit: The limit a user can temporarily exceed for a grace period.
  • hard limit: The absolute maximum limit the user cannot exceed under any circumstances.

Set the desired values in kilobytes for blocks, save, and exit the editor. You can verify the user’s current quota usage with:

sudo quota -vs username
