Configure Network Teaming and Bonding in Ubuntu

Network bonding, also known as network teaming, combines multiple physical network interfaces into a single logical interface to provide link redundancy, fault tolerance, or increased throughput. In modern Ubuntu releases using Netplan, this process involves checking available network interfaces, loading the bonding kernel module, creating a custom YAML configuration file that defines the bond parameters and slave interfaces, and applying the changes using the Netplan CLI tool.

Prerequisites

Before configuring network bonding, ensure you have sudo privileges and at least two physical network interfaces available. You should also ensure the bonding module is loaded into the Linux kernel.

Load the bonding module immediately:

sudo modprobe bonding

To ensure it loads on boot, add bonding to /etc/modules:

echo "bonding" | sudo tee -a /etc/modules

Step 1: Identify Network Interfaces

Run the following command to list all available network interfaces on your system:

ip link show

Note the names of the physical interfaces you intend to combine (for example, enp3s0 and enp4s0).

Step 2: Configure Netplan for Bonding

Ubuntu uses Netplan for network management. Network configuration files are stored in /etc/netplan/.

  1. Locate the existing configuration file: 
    ls /etc/netplan/
  2. Backup the original file: 
    sudo cp /etc/netplan/01-netcfg.yaml /etc/netplan/01-netcfg.yaml.bak
  3. Open the configuration file in a text editor: 
    sudo nano /etc/netplan/01-netcfg.yaml

Replace or update the contents with a bonding configuration. Below is an example configuration using active-backup mode:

network:
  version: 2
  renderer: networkd
  ethernets:
    enp3s0:
      dhcp4: no
    enp4s0:
      dhcp4: no
  bonds:
    bond0:
      interfaces:
        - enp3s0
        - enp4s0
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
      parameters:
        mode: active-backup
        mii-monitor-interval: 100

Common Bonding Modes:

  • active-backup (mode 1): One interface remains active while the other waits in standby.
  • balance-rr (mode 0): Transmits packets in sequential order from the first available slave to the last (Round-Robin).
  • 802.3ad (mode 4): IEEE 802.3ad Dynamic link aggregation (requires a switch that supports LACP).

Step 3: Apply and Test the Configuration

  1. Test the configuration for syntax errors: 
    sudo netplan try
  2. If no errors occur during the test, apply the configuration permanently: 
    sudo netplan apply

Step 4: Verify the Network Bond

To verify that the bonded interface bond0 is active and running:

ip a show dev bond0

To view detailed state information and the status of individual physical interfaces:

cat /proc/net/bonding/bond0

The output displays the active mode, primary interface status, and link state of each assigned physical port.
