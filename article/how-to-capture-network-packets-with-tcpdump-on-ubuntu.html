How to Capture Network Packets with tcpdump on Ubuntu

Capturing network packets on Ubuntu using tcpdump allows system administrators and security professionals to monitor, troubleshoot, and analyze network traffic directly from the command line. This guide covers how to install tcpdump, identify active network interfaces, execute basic packet captures, apply specific filters (such as by IP address, port, or protocol), and save capture data into standard .pcap files for detailed analysis in tools like Wireshark.

1. Install tcpdump on Ubuntu

Most Ubuntu distributions come with tcpdump pre-installed. If it is missing, update your package list and install it using the following commands:

sudo apt update
sudo apt install tcpdump -y

Verify the installation by checking the version:

tcpdump --version

2. Identify Available Network Interfaces

Before capturing traffic, list the available network interfaces on your system:

sudo tcpdump -D

This command outputs a numbered list of active interfaces, such as eth0, wlan0, or lo (loopback).

3. Capture Basic Network Traffic

To start capturing live packets on a specific interface, use the -i flag followed by the interface name:

sudo tcpdump -i eth0

To capture traffic on all available interfaces simultaneously, use any:

sudo tcpdump -i any

To limit the capture to a specific number of packets, use the -c flag:

sudo tcpdump -i eth0 -c 10

4. Filter Traffic for Targeted Analysis

Unfiltered packet captures can generate excessive data. You can filter traffic by IP address, port, or protocol to isolate relevant information.

Filter by Host IP

To capture traffic to or from a specific IP address:

sudo tcpdump -i eth0 host 192.168.1.100

To isolate traffic by source or destination IP:

sudo tcpdump -i eth0 src 192.168.1.100
sudo tcpdump -i eth0 dst 192.168.1.100

Filter by Port

To capture traffic on a specific port (e.g., HTTP port 80 or HTTPS port 443):

sudo tcpdump -i eth0 port 80

Filter by Protocol

To capture packets belonging to a specific protocol (e.g., TCP, UDP, ICMP):

sudo tcpdump -i eth0 icmp

Combine Filters

Combine conditions using logical operators like and, or, and not:

sudo tcpdump -i eth0 src 192.168.1.100 and port 22

5. Save and Read Capture Files

To analyze packet captures later or open them in graphical tools like Wireshark, save the raw data to a .pcap file using the -w flag:

sudo tcpdump -i eth0 -w network_traffic.pcap

To read and display the contents of a saved .pcap file directly in the terminal, use the -r flag:

sudo tcpdump -r network_traffic.pcap
