How to Install Wine on Ubuntu to Run Windows Apps

Running Windows applications on Ubuntu is straightforward thanks to the Wine compatibility layer. This step-by-step guide walks you through enabling 32-bit architecture, adding the official WineHQ repository, installing the latest stable version of Wine, and configuring it to seamlessly launch Windows executable (.exe) files on your Ubuntu system.

Step 1: Enable 32-Bit Architecture

Many Windows applications require 32-bit architecture support. Enable it on your 64-bit Ubuntu system by running:

sudo dpkg --add-architecture i386

Step 2: Add the WineHQ Repository Keys

To ensure you download authentic packages, create the keyring directory and download the official WineHQ GPG key:

sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key

Step 3: Add the WineHQ Repository

Download the appropriate repository source file for your Ubuntu version using the following command:

sudo wget -NP /etc/apt/sources.list.d/ https://dl.winehq.org/wine-builds/ubuntu/dists/$(lsb_release -cs)/winehq-$(lsb_release -cs).sources

Step 4: Install Wine

Update your package database to include the new repository files:

sudo apt update

Next, install the recommended stable release of Wine:

sudo apt install --install-recommends winehq-stable

(Note: If you prefer the latest features over stability, you can replace winehq-stable with winehq-devel or winehq-staging.)

Step 5: Configure the Wine Environment

Once the installation is complete, generate the required Wine configuration files and virtual C: drive directory:

winecfg

Executing this command opens a configuration window and prompts you to install additional dependencies like Mono and Gecko if required. Click Install when prompted, then close the configuration window once it finishes loading.

Step 6: Verify the Installation

Check the installed version of Wine to confirm successful installation:

wine --version

How to Run Windows Applications

To install or execute a Windows program (.exe), navigate to the directory containing the file in your terminal and run:

wine application_name.exe

Alternatively, you can right-click any .exe file in the Ubuntu file manager, select Open With Other Application, and choose Wine Windows Program Loader.
