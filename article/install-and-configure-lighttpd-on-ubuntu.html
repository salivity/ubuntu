Install and Configure Lighttpd on Ubuntu

Lighttpd is a secure, fast, and lightweight web server optimized for high-performance environments with low memory footprints. This guide provides a straightforward tutorial on how to install, configure, and verify the Lighttpd web server on an Ubuntu system, including basic firewall configuration and PHP support setup.

Prerequisites

Before starting, ensure you have an Ubuntu server installed and a user account with sudo privileges.

Step 1: Update System Packages

Update your system’s package repository to ensure you install the latest versions of software.

sudo apt update && sudo apt upgrade -y

Step 2: Install Lighttpd

Lighttpd is available in the default Ubuntu repositories. Install it using the following command:

sudo apt install lighttpd -y

Once installed, the Lighttpd service will start automatically.

Step 3: Verify and Manage the Lighttpd Service

Check if the Lighttpd service is running:

sudo systemctl status lighttpd

To ensure Lighttpd starts automatically upon boot, enable the service:

sudo systemctl enable lighttpd

Useful service management commands: * Stop: sudo systemctl stop lighttpd * Start: sudo systemctl start lighttpd * Restart: sudo systemctl restart lighttpd

Step 4: Configure the Firewall

If you have UFW (Uncomplicated Firewall) enabled, allow traffic on port 80 (HTTP) and port 443 (HTTPS).

sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw reload

Step 5: Test the Installation

Open a web browser and navigate to your server’s IP address:

http://your_server_ip

You should see the default Lighttpd placeholder page confirming the server is working properly.

Step 6: Lighttpd Configuration File Basics

The primary configuration file for Lighttpd is located at /etc/lighttpd/lighttpd.conf. The web root directory where your website files reside is /var/www/html/.

To modify default server settings, open the main configuration file in a text editor:

sudo nano /etc/lighttpd/lighttpd.conf

Key directives inside this file include: * server.document-root: Defines the directory where web pages are stored. * server.port: Specifies the port Lighttpd listens on (default is 80). * server.modules: Lists enabled modules for extended functionality.

Save and exit the file, then restart Lighttpd to apply changes:

sudo systemctl restart lighttpd

Step 7: Enable PHP Support (Optional)

To serve dynamic content, you can enable PHP support via FastCGI.

  1. Install PHP-FPM and FastCGI modules:
sudo apt install php-cgi php-fpm -y
  1. Enable the FastCGI and FastCGI-PHP modules in Lighttpd:
sudo lighty-enable-mod fastcgi
sudo lighty-enable-mod fastcgi-php
  1. Reload the Lighttpd service to apply the module changes:
sudo service lighttpd force-reload
  1. Test PHP processing by creating a test file in the document root:
echo "<?php phpinfo(); ?>" | sudo tee /var/www/html/info.php

Visit http://your_server_ip/info.php in your browser to confirm PHP is functioning correctly. Delete this file after testing for security purposes:

sudo rm /var/www/html/info.php
