How to Align Partitions Using Parted on Ubuntu

Proper partition alignment is essential for maximizing drive performance and prolonging the lifespan of modern solid-state drives (SSDs) and Advanced Format hard disks. Misaligned partitions force the storage controller to perform redundant read-modify-write operations across physical sector boundaries, causing noticeable I/O bottlenecks. This guide explains how to use the GNU Parted utility in Ubuntu to create and verify optimally aligned disk partitions.

Step 1: Identify the Target Disk

Open your terminal and list all connected storage devices to identify the disk you want to partition:

lsblk

Locate the drive's path, such as /dev/sdb or /dev/nvme1n1. Ensure you select the correct device, as modifying partition tables will erase existing data on that disk.

Step 2: Open the Disk in Parted

Start the parted utility using the optimal alignment flag alongside your target disk path:

sudo parted -a optimal /dev/sdb

The -a optimal (or --align optimal) flag instructs Parted to automatically calculate and adhere to the hardware's optimal physical block alignment rules.

Step 3: Create a Partition Table

If you are working with a new or uninitialized disk, create a GUID Partition Table (GPT):

(parted) mklabel gpt

For older systems that require legacy MBR partitioning, use mklabel msdos instead.

Step 4: Create the Aligned Partition

To guarantee that your partition starts on an optimal sector boundary, specify your starting position using mebibytes (MiB) or percentage (%) units rather than raw sectors or bytes. A 1 MiB offset aligns cleanly with 4096-byte sectors and modern SSD page sizes.

To create a single partition spanning the entire drive:

(parted) mkpart primary ext4 1MiB 100%

Alternatively, you can specify 0% as the start point; Parted will automatically adjust the offset to the nearest optimal alignment point (typically 1 MiB / sector 2048):

(parted) mkpart primary ext4 0% 100%

Step 5: Verify Optimal Alignment

Before exiting, verify whether the partition meets optimal alignment parameters using the align-check command followed by the alignment type and the partition number:

(parted) align-check optimal 1

If successful, Parted will return:

1 aligned

If it returns 1 not aligned, the starting boundary was incorrectly specified and must be removed using rm 1 and recreated using the 1MiB start point.

Step 6: Exit Parted

Print the final partition table to review the layout, then exit the program:

(parted) print
(parted) quit

Once Parted closes, the partition is ready to be formatted with your chosen filesystem (such as sudo mkfs.ext4 /dev/sdb1) and mounted for use.
