Create Ubuntu User Without Home Directory

Creating a user account without an associated home directory is a common task in Ubuntu for managing service accounts, system daemons, or restricted users who do not require personal storage space. This guide provides straight-to-the-point methods using standard command-line tools like useradd and adduser to bypass home directory creation quickly and securely.

Method 1: Using the useradd Command

The useradd command is a low-level Linux utility. To explicitly prevent the creation of a home directory, use the -M (or --no-create-home) flag.

To create a standard user without a home directory:

sudo useradd -M username

To create a system user (a dedicated account for services/daemons) without a home directory, add the -r flag:

sudo useradd -r -M username

Assign a password to the new user:

sudo passwd username

Method 2: Using the adduser Command

The adduser command is an interactive, high-level wrapper. By default, adduser creates a home directory, but you can pass the --no-create-home option to disable this behavior.

Run the following command:

sudo adduser --no-create-home username

Follow the terminal prompts to set the password and account information.

Verifying the User Setup

To confirm that the user exists and no home directory was generated:

  1. Check the /home directory for the user folder:

    ls /home/username

    The terminal should return: ls: cannot access '/home/username': No such file or directory.

  2. Inspect the user details in /etc/passwd:

    getent passwd username

    This displays the user configuration. While a default path (like /home/username) may be listed in the file entry, the actual directory does not exist on the disk.
