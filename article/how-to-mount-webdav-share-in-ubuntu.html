How to Mount WebDAV Share in Ubuntu

Mounting a WebDAV share to a local directory in Ubuntu allows you to access and manage remote cloud files as if they were stored on your local hard drive. This guide covers the steps required to install the davfs2 utility, configure user permissions, store login credentials securely, and seamlessly mount your WebDAV storage via the command line or automatically at boot.

Step 1: Install davfs2

Ubuntu uses the davfs2 package to interface with WebDAV resources. Open your terminal and run:

sudo apt update
sudo apt install davfs2 -y

During installation, a configuration prompt will ask whether unprivileged users should be allowed to mount WebDAV shares. Select Yes if you want non-root users to mount the share.

Step 2: Add Your User to the davfs2 Group

To allow a standard user to mount the drive without using sudo, add your user account to the davfs2 group:

sudo usermod -aG davfs2 $USER

Log out and back in, or run newgrp davfs2 for the group changes to take effect.

Step 3: Create a Local Mount Point

Create the directory where you want the WebDAV share to appear on your file system, and assign ownership to your local user:

sudo mkdir -p /mnt/webdav
sudo chown -R $USER:$USER /mnt/webdav

Step 4: Configure Credentials

To avoid entering your password every time you mount the drive, store your credentials in the davfs2 configuration directory.

  1. Create a local .davfs2 directory:
mkdir -p ~/.davfs2
  1. Copy the secrets configuration file to your home directory:
cp /etc/davfs2/secrets ~/.davfs2/secrets
  1. Set strict read/write permissions for security:
chmod 600 ~/.davfs2/secrets
  1. Open the file in a text editor:
nano ~/.davfs2/secrets
  1. Append your WebDAV URL, username, and password at the end of the file:
/mnt/webdav your_username your_password

Save and exit the editor.

Step 5: Mount the WebDAV Share

Manual Mount

To manually mount the WebDAV share, use the following command:

mount -t davfs https://your-webdav-server.com/path /mnt/webdav

Unmount

To disconnect the share when finished:

umount /mnt/webdav

Step 6: Enable Automount (Optional)

To easily mount the share or connect it automatically at startup, add an entry to /etc/fstab.

  1. Open /etc/fstab:
sudo nano /etc/fstab
  1. Add the following line at the bottom of the file:
https://your-webdav-server.com/path /mnt/webdav davfs user,rw,noauto 0 0

(Note: Use auto instead of noauto if you want the share to mount automatically on boot. However, this requires a working network connection at boot time.)

  1. Save and close the file. You can now mount the drive at any time simply by running:
mount /mnt/webdav
