Clear APT Cache in Ubuntu Using apt-get clean

Whenever you install, update, or upgrade software on Ubuntu, the package manager downloads Debian package files (.deb) and stores them in a local cache directory before installation. Over time, these files accumulate and can take up gigabytes of unnecessary disk space. This guide provides a straightforward walk-through on how to check your current cache size, clear the cached files using the apt-get clean command, and understand how it differs from apt-get autoclean.

Understanding the APT Package Cache

When you install a package using apt or apt-get, Ubuntu saves the .deb files to /var/cache/apt/archives/. Even after the installation finishes, these files remain in your storage. While keeping them allows you to reinstall software without re-downloading, most users rarely need this feature and benefit more from reclaiming the disk space.

Step 1: Check the Size of Your APT Cache

Before clearing the cache, you can check how much disk space it is currently consuming. Open your terminal and run the following command:

du -sh /var/cache/apt/archives

This outputs the total space occupied by the cached package files.

Step 2: Clear the APT Cache with apt-get clean

To completely remove all downloaded .deb files from the cache directory, execute:

sudo apt-get clean

(Note: You can also use sudo apt clean, which accomplishes the exact same result).

This command removes everything in /var/cache/apt/archives/ except the partial folder and lock files. It does not uninstall any software from your system; it only deletes the installation files.

Step 3: Verify the Cleared Space

After running the command, verify that the cache has been cleared by checking the directory size again:

du -sh /var/cache/apt/archives

The output should now show a minimal size (typically a few kilobytes).

Difference Between apt-get clean and apt-get autoclean

If you do not want to delete the entire cache, APT provides a selective alternative:

  • sudo apt-get clean: Deletes all cached .deb package files, freeing up the maximum amount of space.
  • sudo apt-get autoclean: Deletes only packages that can no longer be downloaded (i.e., outdated package versions that are no longer in the repositories).

To run autoclean, use:

sudo apt-get autoclean

Running sudo apt-get clean periodically is a safe and effective way to reclaim storage space without impacting system performance or installed applications.
