How to Replace PulseAudio with PipeWire on Ubuntu

PipeWire is a modern multimedia framework that offers lower latency, improved Bluetooth audio codec support, and better resource management compared to the traditional PulseAudio server. Replacing PulseAudio with PipeWire on Ubuntu involves installing the PipeWire packages, configuring the session manager, swapping out the systemd user services, and verifying that your audio server points to PipeWire. This guide provides a straightforward, step-by-step process to complete the transition safely on Ubuntu 22.04 LTS and newer versions.

Step 1: Update Your System

Before installing new packages, ensure your system repository information and installed packages are up to date.

sudo apt update && sudo apt upgrade -y

Step 2: Install PipeWire and WirePlumber

Install PipeWire, its PulseAudio compatibility layer, and WirePlumber (the recommended session manager for PipeWire).

sudo apt install pipewire pipewire-audio-client-libraries pipewire-pulse wireplumber -y

Step 3: Disable PulseAudio Services

To prevent conflicts, disable and mask the existing PulseAudio services so they do not start automatically upon boot.

systemctl --user --now disable pulseaudio.service pulseaudio.socket
systemctl --user mask pulseaudio

Step 4: Enable PipeWire and WirePlumber Services

Enable and start the PipeWire services alongside the WirePlumber session manager for your user account.

systemctl --user --now enable pipewire.socket pipewire-pulse.socket wireplumber.service

Step 5: Restart the System

Reboot your computer to apply the changes and ensure all audio components load with PipeWire as the default driver.

sudo reboot

Step 6: Verify the Installation

After logging back into Ubuntu, verify that PipeWire is actively handling audio output.

Run the following command in your terminal:

pactl info

Look for the Server Name entry in the output. If the setup was successful, it will display:

Server Name: PulseAudio (on PipeWire x.x.x)

If you see on PipeWire in the server name, your system is now successfully using PipeWire as its primary audio engine.
