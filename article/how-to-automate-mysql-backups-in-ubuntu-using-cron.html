How to Automate MySQL Backups in Ubuntu Using Cron

This article provides a straightforward guide to automating MySQL or MariaDB database backups on an Ubuntu server. By combining mysqldump to create database exports and cron to schedule execution, you can establish a reliable, hands-off backup system that protects your data against loss.

Step 1: Create a Backup Directory

First, create a dedicated directory on your server where the database backup files will be stored:

sudo mkdir -p /var/backups/db_backups

Step 2: Create the Backup Script

Create a shell script that handles the database export using mysqldump. Open a new file in your editor:

sudo nano /usr/local/bin/mysql_backup.sh

Paste the following code into the script. Replace your_db_user, your_db_password, and your_db_name with your actual database details:

#!/bin/bash

# Configuration
DB_USER="your_db_user"
DB_PASS="your_db_password"
DB_NAME="your_db_name"
BACKUP_DIR="/var/backups/db_backups"
DATE=$(date +%Y-%m-%d_%H%M%S)

# Perform the backup and compress output
mysqldump -u "$DB_USER" -p"$DB_PASS" "$DB_NAME" | gzip > "$BACKUP_DIR/$DB_NAME-$DATE.sql.gz"

# Delete backups older than 30 days
find "$BACKUP_DIR" -type f -name "*.sql.gz" -mtime +30 -delete

Save and close the file.

Step 3: Set Script Permissions

Make the script executable and restrict access to protect your database credentials:

sudo chmod +x /usr/local/bin/mysql_backup.sh
sudo chmod 700 /usr/local/bin/mysql_backup.sh

Step 4: Test the Script

Execute the script manually once to verify that it generates a backup without errors:

sudo /usr/local/bin/mysql_backup.sh

Check the backup directory to confirm the compressed .sql.gz file exists:

ls -l /var/backups/db_backups

Step 5: Schedule the Automated Execution with Cron

Open the system crontab editor to set up the execution schedule:

sudo crontab -e

Add a line to the bottom of the crontab file to define when the script should run. For example, to run the script every night at 2:00 AM, add:

0 2 * * * /usr/local/bin/mysql_backup.sh

Save and exit the editor. Cron will now automatically execute your backup script daily at the scheduled time.
