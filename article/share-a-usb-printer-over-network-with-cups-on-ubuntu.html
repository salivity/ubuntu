Share a USB Printer Over Network with CUPS on Ubuntu

Transforming an Ubuntu system into a network print server allows any device on your local area network (LAN) to use a shared USB printer. This guide outlines how to install the Common Unix Printing System (CUPS), adjust its configuration to accept remote traffic, add your connected USB printer, and broadcast it securely across your network.

Step 1: Install the CUPS Package

Ensure your package repositories are updated, then install the CUPS daemon and its required utilities:

sudo apt update
sudo apt install cups -y

Start the CUPS service and configure it to launch automatically upon system boot:

sudo systemctl enable --now cups

Step 2: Grant Administrative Rights

To modify printer configurations and access the administrative controls via the CUPS web interface, your system user must belong to the lpadmin group:

sudo usermod -aG lpadmin $USER

Note: Log out and log back in, or run newgrp lpadmin, for this group change to take effect.

Step 3: Configure CUPS for Remote Network Access

By default, CUPS only listens to requests coming from localhost (127.0.0.1). To permit access from other machines on your local network, execute the built-in cupsctl command:

sudo cupsctl --remote-admin --remote-any --share-printers

This command automatically modifies /etc/cups/cupsd.conf to:

  • Listen on port 631 across all network interfaces.
  • Enable the printer-sharing feature globally.
  • Permit remote administrative access to the web interface.

Restart the CUPS service to apply the configuration:

sudo systemctl restart cups

Step 4: Open Firewall Ports

If the Uncomplicated Firewall (UFW) is active on your Ubuntu machine, open port 631 to allow incoming Internet Printing Protocol (IPP) traffic:

sudo ufw allow 631/tcp
sudo ufw reload

Step 5: Connect and Add the USB Printer

  1. Plug your printer into a USB port on the Ubuntu computer and turn the printer on.

  2. Find the Ubuntu machine's local IP address:

    hostname -I

  3. Open a web browser on any computer connected to the same local network and navigate to:

    https://<your-server-ip>:631

    (Bypass any SSL certificate warning; CUPS generates a self-signed certificate by default).

  4. Navigate to the Administration tab at the top of the interface.

  5. Click Add Printer under the Printers section. When prompted, enter your Ubuntu username and password.

  6. Under Local Printers, select your connected USB printer from the list and click Continue.

  7. Provide a name, description, and location for the printer. Crucially, check the box labeled Share This Printer before clicking Continue.

  8. Select the manufacturer and driver for your specific printer model, or upload a vendor-supplied PPD (PostScript Printer Description) file.

  9. Click Add Printer and set your preferred default media options to complete the setup.

Step 6: Connect Client Devices

Once shared, client operating systems on the network can discover the printer:

  • Linux: Open system printer settings; the printer will typically be discovered automatically via mDNS/Avahi. Alternatively, manually add a network printer using the URL: ipp://<your-server-ip>:631/printers/<printer-name>.
  • Windows: Go to Settings > Devices > Printers & scanners > Add a printer or scanner. If it is not automatically discovered, click The printer that I want isn't listed, choose Select a shared printer by name, and input: http://<your-server-ip>:631/printers/<printer-name>.
  • macOS: Open System Settings > Printers & Scanners > Add Printer. Select the network-discovered Bonjour printer or enter the IP address using the IPP protocol.
