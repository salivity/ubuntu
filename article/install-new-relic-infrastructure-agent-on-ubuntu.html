Install New Relic Infrastructure Agent on Ubuntu

This guide provides the exact commands required to install and configure the New Relic infrastructure monitoring agent on an Ubuntu server. Whether you prefer the automated guided installation script provided by New Relic or a manual setup using the standard APT package manager, the following instructions will walk you through the process quickly and efficiently.

Prerequisites

Before beginning, ensure you have:

  • A New Relic account.
  • Your New Relic Ingest License Key.
  • An Ubuntu server with sudo or root privileges.

Option 1: The Guided One-Line Command (Recommended)

New Relic provides an automated installation script that detects your operating system, configures the repository, and installs the infrastructure agent along with any relevant log forwarders.

Run the following command in your terminal, replacing YOUR_API_KEY and YOUR_ACCOUNT_ID with your actual New Relic credentials:

curl -Ls https://download.newrelic.com/install/newrelic-cli/scripts/install.sh | bash && sudo NEW_RELIC_API_KEY=YOUR_API_KEY NEW_RELIC_ACCOUNT_ID=YOUR_ACCOUNT_ID /usr/local/bin/newrelic install

Option 2: Manual Installation via APT

If you prefer using Ubuntu's native package manager without the automated CLI, follow these steps.

1. Set Your License Key

Create or edit the New Relic configuration file and add your license key:

echo "license_key: YOUR_LICENSE_KEY" | sudo tee -a /etc/newrelic-infra.yml

2. Add the New Relic GPG Key

Download and save the official New Relic public GPG key:

curl -fsSL https://download.newrelic.com/infrastructure_agent/gpg/newrelic-infra.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/newrelic-infra.gpg

3. Add the New Relic APT Repository

Add the repository appropriate for your Ubuntu release:

echo "deb https://download.newrelic.com/infrastructure_agent/linux/apt $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/newrelic-infra.list

4. Install the Agent

Update your local package index and install the newrelic-infra package:

sudo apt-get update && sudo apt-get install -y newrelic-infra

Verifying the Agent Status

Once installed, the agent starts automatically. Verify that the service is running with systemd:

sudo systemctl status newrelic-infra

If the agent is inactive, start and enable it to run on boot:

sudo systemctl enable --now newrelic-infra

Within a few minutes of starting the service, your Ubuntu host's metrics will begin appearing in the New Relic Infrastructure UI dashboard.
