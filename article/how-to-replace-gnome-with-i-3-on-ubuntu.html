How to Replace GNOME with i3 on Ubuntu

This guide explains how to completely replace Ubuntu's default GNOME desktop environment with the lightweight, keyboard-driven i3 tiling window manager. By following these steps, you will install the core i3 components, set up essential standalone utilities to maintain system functionality, switch to a minimal display manager, and safely purge GNOME packages to reclaim disk space and system resources.

Step 1: Update System Packages

Ensure your package lists and installed software are fully updated before making structural changes to your desktop environment:

sudo apt update && sudo apt upgrade -y

Step 2: Install i3 and Core Utilities

GNOME bundles many everyday utilities (such as the terminal, network applet, and audio controls). To ensure you retain full control over your system inside i3, install the window manager alongside essential standalone alternatives:

sudo apt install -y i3 i3status i3lock dmenu rofi feh picom lightdm network-manager-gnome pavucontrol xfce4-terminal

Key packages included:

  • i3, i3status, i3lock: The window manager, status bar, and screen locker.
  • dmenu / rofi: Application launchers.
  • feh: Wallpaper manager.
  • picom: Compositor to prevent screen tearing.
  • lightdm: A lightweight display manager to replace GDM.
  • nm-applet (network-manager-gnome): Tray icon for managing Wi-Fi and network connections.
  • pavucontrol: Graphical volume management for PulseAudio/PipeWire.
  • xfce4-terminal: A lightweight terminal that does not depend on the GNOME runtime.

Step 3: Configure LightDM as the Default Display Manager

During the installation of lightdm, a prompt may ask you to choose your default display manager. If it did not appear, run:

sudo dpkg-reconfigure lightdm

Select lightdm from the list using the arrow keys and press Enter.

Step 4: Verify and Test the i3 Session

Before uninstalling GNOME, reboot your computer to confirm that i3 and LightDM are functioning properly:

sudo reboot
  1. At the LightDM login screen, click the session icon (usually in the upper-right corner of the login box).
  2. Select i3 instead of Ubuntu or GNOME.
  3. Log in.
  4. On your first launch, i3 will prompt you to generate a configuration file. Press Enter to accept the default, then choose your preferred modifier key (Win/Super or Alt).

Confirm that your terminal opens (press $mod + Enter) and that you can launch applications via dmenu (press $mod + d).

Step 5: Completely Remove GNOME

Once verified that you can navigate i3 comfortably, open your terminal to remove the GNOME desktop environment, the GDM display manager, and unused dependencies:

sudo apt purge -y ubuntu-desktop ubuntu-desktop-minimal vanilla-gnome-desktop gnome-shell gdm3
sudo apt autoremove --purge -y
sudo apt clean

Note: If you rely on specific GNOME utilities like gnome-calculator or nautilus, reinstall them individually or switch to lightweight alternatives such as galculator and thunar.

Step 6: Configure i3 Autostart

To automatically start essential system applets whenever you log into i3, edit your configuration file:

nano ~/.config/i3/config

Add the following lines to the bottom of the file:

# Start compositor for smooth window rendering
exec_always --no-startup-id picom -b

# Start NetworkManager tray applet
exec --no-startup-id nm-applet

# Start audio volume tray applet (if volumeicon is installed)
exec --no-startup-id volumeicon

# Set wallpaper (replace path with your actual image path)
# exec_always --no-startup-id feh --bg-scale /path/to/wallpaper.jpg

Save the file by pressing Ctrl + O, then exit with Ctrl + X. Reload your i3 configuration immediately by pressing $mod + Shift + r.
