How to Force Unmount a Busy Filesystem in Ubuntu

When attempting to unmount a storage drive or partition in Ubuntu, you may encounter a "target is busy" error indicating that open files or running processes are accessing the mount point. This guide explains how to identify the processes holding a filesystem open, terminate them safely, and forcefully or lazily unmount the filesystem using terminal commands such as umount, fuser, and lsof.

Method 1: Perform a Lazy Unmount

The safest and most reliable way to handle a busy filesystem in Ubuntu is a lazy unmount. A lazy unmount detaches the filesystem from the directory structure immediately and cleans up all references as soon as the drive is no longer busy.

Run the following command, replacing /mnt/point with your actual mount point path:

sudo umount -l /mnt/point
  • -l (lazy): Unmounts the target point instantly, allowing you to use the system without waiting for active processes to finish.

Method 2: Force Unmount (Network Filesystems)

If you are dealing with an unreachable network mount, such as NFS or SSHFS, you can use the force option.

sudo umount -f /mnt/point
  • -f (force): Forces an unmount, primarily designed for unresponding network shares. Note that this flag may not work on local block devices (like USB drives or secondary hard drives) if local processes are actively writing to them.

Method 3: Identify and Kill Blocking Processes

If you prefer to unmount the drive cleanly without lazy options, you can locate the specific processes keeping the directory busy and stop them.

Step 1: Find Active Processes

To view which processes are using the filesystem, use the fuser or lsof command:

sudo fuser -mv /mnt/point

or

sudo lsof +D /mnt/point

These commands list the process IDs (PIDs) and users accessing files within that directory.

Step 2: Terminate the Processes

To automatically kill all processes accessing the mount point, run:

sudo fuser -k -9 -m /mnt/point
  • -k: Kills processes accessing the named file or mount.
  • -9: Sends the SIGKILL signal to force-terminate them immediately.

Step 3: Unmount Normally

Once the blocking processes are closed, unmount the drive normally:

sudo umount /mnt/point
