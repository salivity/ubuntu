How to Prevent Package Upgrades in Ubuntu With apt-mark

In Ubuntu and other Debian-based distributions, running standard system updates can occasionally introduce unwanted configuration changes or software incompatibilities. This guide explains how to use the apt-mark hold command to lock specific packages at their current versions, preventing them from being modified during an apt upgrade. You will also learn how to view all currently held packages and remove the hold when you are ready to install updates again.

Locking a Package with apt-mark hold

To prevent a package from being upgraded, open your terminal and run the apt-mark hold command with superuser privileges, followed by the exact name of the package.

sudo apt-mark hold <package_name>

For example, to prevent the nginx package from upgrading:

sudo apt-mark hold nginx

Once executed, the terminal will confirm:

nginx set on hold.

When you subsequently run sudo apt update and sudo apt upgrade, the APT package manager will skip the specified package, leaving it at its current version even if a newer version is available in the repositories.

Viewing Held Packages

To verify which packages are currently locked on your system, use the showhold option:

apt-mark showhold

This prints a list of all packages currently marked as held. If the list is empty, no packages are blocked from upgrading.

Unlocking a Package with apt-mark unhold

When you are ready to allow the package to update again—such as after verifying that a new version is compatible with your environment—use the unhold command:

sudo apt-mark unhold <package_name>

For example, to allow updates for nginx again:

sudo apt-mark unhold nginx

The system will confirm:

Canceled hold on nginx.

The package is now eligible to be updated during the next sudo apt upgrade run.
