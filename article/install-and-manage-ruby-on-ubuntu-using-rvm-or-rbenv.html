Install and Manage Ruby on Ubuntu Using RVM or rbenv

Managing multiple Ruby versions on an Ubuntu workstation is essential for developing diverse projects without dependency conflicts. This guide outlines how to prepare your Ubuntu system with the necessary build dependencies and provides step-by-step instructions to install, manage, and switch between different Ruby versions using either rbenv or RVM (Ruby Version Manager).

Step 1: Install System Dependencies

Both rbenv and RVM compile Ruby from source. Before installing either tool, update your package list and install the required build dependencies by running:

sudo apt update
sudo apt install -y curl gpg gcc make libssl-dev libreadline-dev zlib1g-dev libyaml-dev libffi-dev

Option A: Managing Ruby Versions with rbenv

rbenv is a lightweight, non-intrusive tool that manages Ruby environments by modifying your shell's PATH.

1. Install rbenv and ruby-build

Clone the rbenv repository and the ruby-build plugin (which provides the rbenv install command) into your home directory:

git clone https://github.com/rbenv/rbenv.git ~/.rbenv
git clone https://github.com/rbenv/ruby-build.git ~/.rbenv/plugins/ruby-build

2. Configure Shell Environment

Add rbenv to your PATH and initialize it by appending the configuration to ~/.bashrc:

echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init - bash)"' >> ~/.bashrc
source ~/.bashrc

Verify the installation:

rbenv -v

3. Install and Select Ruby Versions

List available Ruby versions for installation:

rbenv install -l

Install specific Ruby versions:

rbenv install 3.2.2
rbenv install 3.1.4

Set a default global Ruby version for your entire system:

rbenv global 3.2.2

Set a local Ruby version for a specific project directory:

cd /path/to/project
rbenv local 3.1.4

Verify the active version:

ruby -v

Option B: Managing Ruby Versions with RVM

RVM is a feature-rich version manager that handles Ruby installations and provides isolated package environments called gemsets.

1. Install RVM

Import the official GPG security keys:

gpg --keyserver hkp://keyserver.ubuntu.com --recv-keys 409B6B1796C275462A1703113804BB82D39DC0E3 7D2BAF1CF37B13E2069D14838437D050B9538751

Download and run the RVM installation script:

\curl -sSL https://get.rvm.io | bash -s stable

Load RVM into your current shell session:

source ~/.rvm/scripts/rvm

2. Install and Switch Ruby Versions

List available Ruby versions:

rvm list known

Install your desired Ruby versions:

rvm install 3.2.2
rvm install 3.1.4

Set a default Ruby version across all terminal sessions:

rvm use 3.2.2 --default

Switch to a different version temporarily in your current session:

rvm use 3.1.4

3. Managing Gemsets with RVM

RVM allows you to create isolated gem collections for different applications using the same Ruby version:

rvm use 3.2.2
rvm gemset create myproject
rvm use 3.2.2@myproject

Verify your active Ruby version and gemset:

rvm current
