How to Install and Configure Xmonad on Ubuntu

This guide provides a step-by-step walkthrough for installing and configuring the Xmonad dynamic tiling window manager on Ubuntu. You will learn how to install Xmonad along with its essential dependencies, set up a minimal Haskell configuration file (xmonad.hs), integrate tools like dmenu and XMobar, and launch your Xmonad session directly from the Ubuntu login screen.

Step 1: Install Xmonad and Dependencies

Open your terminal and update your package list. Then, install Xmonad, the Xmonad contrib library, compilation tools, and essential utilities like dmenu (an application launcher) and xmobar (a lightweight status bar).

sudo apt update
sudo apt install xmonad libghc-xmonad-dev libghc-xmonad-contrib-dev dmenu xmobar build-essential

Step 2: Create the Xmonad Configuration Directory

Xmonad requires a directory to store its configuration file. Create the configuration folder in your home directory:

mkdir -p ~/.config/xmonad

Navigate into this directory and create a file named xmonad.hs:

nano ~/.config/xmonad/xmonad.hs

Step 3: Write a Basic xmonad.hs Configuration

Paste the following starter Haskell configuration into your xmonad.hs file. This configures the Super key (Windows key) as the main modifier, sets st or gnome-terminal as the default terminal, and enables layout options from the xmonad-contrib library.

import XMonad
import XMonad.Hooks.DynamicLog
import XMonad.Hooks.ManageDocks
import XMonad.Util.Run(spawnPipe)
import XMonad.Util.EZConfig(additionalKeys)
import System.IO

main = do
    xmproc <- spawnPipe "xmobar ~/.config/xmobar/xmobarrc"
    xmonad $ docks def
        { modMask = mod4Mask -- Set Super/Windows key as the modifier
        , terminal = "gnome-terminal" -- Set default terminal
        , layoutHook = avoidStruts $ layoutHook def
        , manageHook = manageDocks <+> manageHook def
        , logHook = dynamicLogWithPP xmobarPP
                        { ppOutput = hPutStrLn xmproc
                        , ppTitle = xmobarColor "green" "" . shorten 50
                        }
        }

Save and exit the editor (Ctrl+O, Enter, Ctrl+X in nano).

Step 4: Configure XMobar (Status Bar)

Create the configuration directory and file for XMobar:

mkdir -p ~/.config/xmobar
nano ~/.config/xmobar/xmobarrc

Add the following minimal XMobar configuration:

Config { font = "xft:Sans:pixelsize=12"
       , bgColor = "black"
       , fgColor = "grey"
       , position = Top
       , lowerOnStart = True
       , commands = [ Run Cpu ["-L","3","-H","50","--normal","green","--high","red"] 10
                    , Run Memory ["-t","Mem: <usedratio>%"] 10
                    , Run Date "%a %b %_d %Y %H:%M:%S" "date" 10
                    , Run StdinReader
                    ]
       , sepChar = "%"
       , alignSep = "}{"
       , template = "%StdinReader% }{ %cpu% | %memory% | <fc=#ee9a00>%date%</fc>"
       }

Save and exit the file.

Step 5: Compile Xmonad

Recompile Xmonad to check for any syntax errors in your Haskell configuration:

xmonad --recompile

If the command executes without returning errors, your setup is valid.

Step 6: Log into Xmonad

  1. Log out of your current Ubuntu session.
  2. On the Display Manager screen (login screen), click your username.
  3. Click the gear icon located in the bottom right corner of the screen.
  4. Select Xmonad from the list of sessions.
  5. Enter your password and log in.

Essential Keyboard Shortcuts

  • Mod + Shift + Enter: Open the terminal (gnome-terminal)
  • Mod + p: Open dmenu to launch applications
  • Mod + Shift + c: Close the focused window
  • Mod + Space: Cycle through window layouts
  • Mod + j / Mod + k: Move focus to the next/previous window
  • Mod + Shift + j / Mod + Shift + k: Swap the focused window with the next/previous window
  • Mod + q: Recompile and restart Xmonad in-place
  • Mod + Shift + q: Exit Xmonad (log out)
