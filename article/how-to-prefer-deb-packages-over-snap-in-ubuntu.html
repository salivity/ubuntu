How to Prefer Deb Packages Over Snap in Ubuntu

In modern Ubuntu releases, standard APT commands for certain applications (such as Firefox or Chromium) install transitional dummy packages that automatically download and install the Snap version via snapd. This article explains how to configure APT pinning to prioritize native Debian and PPA packages over Ubuntu's transitional Snap packages, prevent Ubuntu from silently installing snapd, and verify your package priorities.

Step 1: Add a Native Debian or PPA Repository

Because Ubuntu’s default repositories only provide transitional stubs for certain packages, you must first ensure you have a repository that provides the native .deb binary (such as an official PPA or external Debian repository).

For example, to get native .deb builds of Firefox, add the official Mozilla Team PPA:

sudo add-apt-repository ppa:mozillateam/ppa

Step 2: Configure APT Pinning for the Target Application

By default, Ubuntu may assign the same or higher priority to its own transitional package over the third-party PPA. To force APT to prefer the native .deb version, assign a higher pin priority to the PPA.

  1. Create a preference file in /etc/apt/preferences.d/:

    sudo nano /etc/apt/preferences.d/mozillateam-ppa

  2. Add the following configuration to ensure packages from this PPA are always preferred:

    Package: firefox*
Pin: release o=LP-PPA-mozillateam
Pin-Priority: 1001

    Setting Pin-Priority: 1001 ensures that APT will always prioritize this source, even if the Ubuntu repository advertises a higher version number.

Step 3: Prevent APT from Installing snapd Automatically

To stop Ubuntu from silently installing snapd as a dependency when a transitional .deb package is triggered, configure a system-wide block on snapd via APT pinning.

  1. Create a dedicated preference file:

    sudo nano /etc/apt/preferences.d/nosnap.pref

  2. Add the following rules:

    Package: snapd
Pin: release *
Pin-Priority: -10

    A negative pin priority prevents APT from installing snapd automatically under any circumstance.

Step 4: Apply Changes and Verify

  1. Update your local package index to apply the new pin priorities:

    sudo apt update

  2. Check the candidate version and origin priority using apt-cache policy:

    apt-cache policy firefox

  3. Look at the output under Candidate. It should point directly to the native PPA version rather than the Ubuntu standard archive.

  4. Install the native package:

    sudo apt install firefox

APT will now pull exclusively from the native Debian package source without invoking snapd.
