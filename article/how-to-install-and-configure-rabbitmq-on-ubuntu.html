How to Install and Configure RabbitMQ on Ubuntu

This guide provides a straightforward tutorial on installing and configuring the RabbitMQ message broker on an Ubuntu system. You will learn how to update system dependencies, install the Erlang runtime and RabbitMQ server, enable the web-based management dashboard, and create an administrative user for secure access.

Prerequisites

Before starting, ensure you have an Ubuntu server (20.04 or 22.04 recommended) with a user account that has sudo privileges and an active internet connection.

Step 1: Update System Repositories

First, update your local package index to ensure you download the latest available packages.

sudo apt update && sudo apt upgrade -y

Step 2: Install Erlang and RabbitMQ

RabbitMQ is built on the Erlang programming language, which must be installed on your system. RabbitMQ is available in the default Ubuntu repositories.

Run the following command to install required dependencies, Erlang, and the RabbitMQ server:

sudo apt install erlang rabbitmq-server -y

Step 3: Manage the RabbitMQ Service

Once the installation is complete, start the RabbitMQ service and enable it to automatically run at system boot.

Start the service:

sudo systemctl start rabbitmq-server

Enable auto-start on boot:

sudo systemctl enable rabbitmq-server

Verify that the service is running properly:

sudo systemctl status rabbitmq-server

Step 4: Enable the RabbitMQ Management Plugin

RabbitMQ comes with a web-based management plugin that allows you to monitor queues, connections, and exchange rates.

Enable the plugin by executing:

sudo rabbitmq-plugins enable rabbitmq_management

After enabling the plugin, adjust ownership permissions so RabbitMQ can access the plugin files properly:

sudo chown -R rabbitmq:rabbitmq /var/lib/rabbitmq/

Step 5: Create a RabbitMQ Administrator User

By default, RabbitMQ creates a guest user with the password guest. This account can only connect from localhost. For remote management and improved security, create a new administrator account.

  1. Add a new user (replace admin_user and strong_password with your credentials):

    sudo rabbitmqctl add_user admin_user strong_password

  2. Assign the administrator tag to your new user:

    sudo rabbitmqctl set_user_tags admin_user administrator

  3. Grant full permissions to your user on the default virtual host (/):

    sudo rabbitmqctl set_permissions -p / admin_user ".*" ".*" ".*"

Step 6: Configure Firewall (UFW)

If you have the UFW firewall enabled on Ubuntu, open the necessary ports:

  • 5672: Default port used by AMQP clients.
  • 15672: Web management dashboard port.

Run the following commands to open these ports:

sudo ufw allow 5672/tcp
sudo ufw allow 15672/tcp

Step 7: Access the Management Web Interface

Open your web browser and navigate to your server's IP address on port 15672:

http://your_server_ip:15672/

Log in using the administrator credentials created in Step 5. You now have a fully functional RabbitMQ message broker running on your Ubuntu server.
