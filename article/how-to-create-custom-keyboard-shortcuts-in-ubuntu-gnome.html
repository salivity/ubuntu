How to Create Custom Keyboard Shortcuts in Ubuntu GNOME

Custom keyboard shortcuts in the Ubuntu GNOME desktop allow you to launch your favorite applications, run custom terminal commands, or execute scripts instantly with a single key combination. By using Ubuntu's built-in settings menu, you can easily bypass navigating through menus and streamline your daily workflow. This guide outlines the exact steps needed to create, configure, and manage your custom keyboard shortcuts in Ubuntu.

Step-by-Step Guide to Adding a Custom Shortcut

1. Open the System Settings

Click the system menu in the top-right corner of your screen (the status area containing network and power icons) and select Settings. Alternatively, press the Super key (Windows key), type "Settings," and hit Enter.

2. Navigate to Keyboard Settings

In the left sidebar of the Settings window, scroll down and select Keyboard.

3. Access Custom Shortcuts

Scroll to the bottom of the Keyboard settings panel until you locate the Keyboard Shortcuts section. Click on View and Customize Shortcuts.

In the window that pops up, scroll down to the bottom of the list and select Custom Shortcuts.

4. Create a New Shortcut

Click the Add Shortcut button (or the + button if you already have existing custom shortcuts).

5. Fill in the Shortcut Details

A prompt will ask you for three fields:

  • Name: A label describing what the shortcut does (e.g., "Launch Text Editor").
  • Command: The exact terminal command or script path required to execute the action (e.g., gedit, firefox, or /home/user/scripts/backup.sh).
  • Shortcut: Click Set Shortcut... and press the combination of keys you want to assign on your keyboard (e.g., Ctrl + Alt + E).

6. Save the Shortcut

Click the Add button in the top-right corner of the window. The custom keyboard shortcut is now active and ready for use.

Editing or Removing a Custom Shortcut

To modify or delete an existing custom shortcut:

  1. Return to Settings > Keyboard > View and Customize Shortcuts > Custom Shortcuts.
  2. Click on the name of the shortcut you wish to change.
  3. Edit the command or press a new key combination to change it, or click the Remove button in the top-right corner to delete it permanently.
