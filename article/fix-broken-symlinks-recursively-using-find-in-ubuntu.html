Fix Broken Symlinks Recursively Using Find in Ubuntu

Broken symbolic links (symlinks) occur when the target file or directory is moved, renamed, or deleted, leading to file system clutter and potential script execution errors. This article demonstrates how to locate, safely remove, and repair broken symlinks recursively across any directory tree in Ubuntu using the built-in find command and complementary terminal utilities.

Finding Broken Symlinks Recursively

Before modifying or deleting files, scan your directory tree to generate a list of all broken symlinks.

Run the following command in your terminal:

find /path/to/directory -xtype l

Replace /path/to/directory with the directory path you wish to search (for example, ~ or /var/www).

Command Breakdown:

  • /path/to/directory: The starting point for the recursive search.
  • -xtype l: Checks the file type of the link’s target. If the target file or directory does not exist, the link is identified as broken and output to the terminal.

An alternative command using the -L (follow symlinks) flag achieves the same result:

find -L /path/to/directory -type l

Deleting Broken Symlinks Recursively

Once you have verified the list of broken symlinks, you can automatically remove them.

Method 1: Using the -delete Flag

The fastest way to remove broken links is adding the -delete flag directly to the find command:

find /path/to/directory -xtype l -delete

Method 2: Using -exec with rm

If your environment does not support -delete, pass the search results to rm:

find /path/to/directory -xtype l -exec rm {} +
  • {} acts as a placeholder for each found link.
  • + groups multiple files together to minimize the number of rm command invocations.

Fixing Broken Symlinks

If you need to repair broken links instead of removing them, you can update their target paths.

Re-pointing Symlinks Manually

To overwrite a broken symlink and point it to a valid target, use ln with the -sf options:

ln -sf /path/to/new_target /path/to/broken_link
  • -s: Specifies symbolic link creation.
  • -f: Forces the command to overwrite the existing destination link.

Managing Symlinks with the symlinks Utility

Ubuntu includes a dedicated command-line tool called symlinks designed to inspect and fix link issues recursively.

  1. Install the package:

    sudo apt update && sudo apt install symlinks

  2. Scan a directory recursively for dangling (broken) links:

    symlinks -r /path/to/directory

  3. Automatically delete all broken links in the directory tree:

    symlinks -rd /path/to/directory
  • -r: Recurses through subdirectories.
  • -d: Removes dangling symlinks.
