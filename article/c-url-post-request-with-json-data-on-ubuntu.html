cURL POST Request with JSON Data on Ubuntu

This guide explains how to send HTTP POST requests containing JSON payloads using the curl command-line tool in Ubuntu. You will learn the fundamental command structure, the necessary headers for transmitting JSON, how to pass raw JSON strings directly in the terminal, and how to load JSON payloads from external files.

The Basic Command Syntax

To send a JSON POST request, you must specify the HTTP method, set the appropriate Content-Type header, and supply the data payload. Open your Ubuntu terminal and use the following structure:

curl -X POST https://api.example.com/endpoint \
     -H "Content-Type: application/json" \
     -d '{"name": "John Doe", "email": "john@example.com"}'

Breakdown of the Options

  • -X POST: Explicitly defines the HTTP request method as POST. While -d defaults to POST automatically in most cases, specifying -X POST ensures clarity.
  • -H "Content-Type: application/json": Adds an HTTP header informing the receiving server that the data being sent in the request body is formatted as JSON.
  • -d '...': Supplies the data payload. Enclosing the JSON payload in single quotes (') allows you to use standard double quotes (") for your JSON keys and string values without needing to escape them.

Sending JSON from a Local File

When working with large or complex JSON payloads, storing the data in a file is more manageable than writing it inline.

  1. Create a JSON file named payload.json:
{
  "title": "New Article",
  "published": true,
  "tags": ["ubuntu", "curl", "json"]
}
  1. Execute the curl command using the @ symbol before the file path in the -d argument:
curl -X POST https://api.example.com/endpoint \
     -H "Content-Type: application/json" \
     -d @payload.json

Viewing Response Headers and Formatting Output

To inspect the HTTP response headers alongside the response body, add the -i flag:

curl -i -X POST https://api.example.com/endpoint \
     -H "Content-Type: application/json" \
     -d '{"status": "active"}'

To format and read the server's JSON response clearly, you can pipe the output into jq (installable on Ubuntu via sudo apt install jq):

curl -s -X POST https://api.example.com/endpoint \
     -H "Content-Type: application/json" \
     -d '{"status": "active"}' | jq .
