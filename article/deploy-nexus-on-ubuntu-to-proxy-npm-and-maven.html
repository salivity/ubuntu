Deploy Nexus on Ubuntu to Proxy npm and Maven

This guide walks you through deploying Sonatype Nexus Repository Manager 3 on an Ubuntu server and configuring it to serve as a caching proxy for both Maven and npm repositories. By hosting an internal proxy, development teams can reduce external bandwidth usage, increase build speeds, and ensure continuous package availability even during upstream outages.

Step 1: Install Prerequisites

Nexus Repository Manager requires the Java Virtual Machine. Install OpenJDK 8 or 11 along with utility packages.

sudo apt update
sudo apt install openjdk-8-jdk wget -y

Verify the installation:

java -version

Step 2: Download and Extract Nexus

Create a dedicated directory and download the latest release of Nexus Repository Manager 3.

cd /opt
sudo wget https://download.sonatype.com/nexus/3/latest-unix.tar.gz
sudo tar -zxvf latest-unix.tar.gz

Rename the extracted directory for easier maintenance and clean up the archive:

sudo mv nexus-3* nexus
sudo rm latest-unix.tar.gz

Step 3: Configure User and Permissions

For security purposes, do not run Nexus as the root user. Create a dedicated nexus service user:

sudo useradd --system --no-create-home nexus
sudo chown -R nexus:nexus /opt/nexus
sudo chown -R nexus:nexus /opt/sonatype-work

Configure Nexus to run as the nexus user:

sudo sed -i 's/#run_as_user=""/run_as_user="nexus"/' /opt/nexus/bin/nexus.rc

Step 4: Configure systemd Service

Create a systemd unit file to manage the Nexus service:

sudo nano /etc/systemd/system/nexus.service

Paste the following configuration:

[Unit]
Description=Nexus Repository Manager
After=network.target

[Service]
Type=forking
LimitNOFILE=65536
ExecStart=/opt/nexus/bin/nexus start
ExecStop=/opt/nexus/bin/nexus stop
User=nexus
Restart=on-abort
TimeoutSec=600

[Install]
WantedBy=multi-user.target

Reload systemd, enable, and start the service:

sudo systemctl daemon-reload
sudo systemctl enable nexus
sudo systemctl start nexus

Nexus can take 2 to 3 minutes to fully initialize. Check the status using:

sudo systemctl status nexus

Step 5: Initial Setup

  1. Open your browser and navigate to http://<your-server-ip>:8081.
  2. Click Sign in in the top right corner.
  3. Retrieve the generated admin password:
sudo cat /opt/sonatype-work/nexus3/admin.password
  1. Complete the setup wizard by resetting your password and choosing whether to enable anonymous access.

Step 6: Configure Maven Proxy

Nexus includes a pre-configured Maven Central proxy repository out of the box (maven-central), but you can verify or create a new one using these steps:

  1. Navigate to Administration (gear icon) > Repository > Repositories.
  2. Click Create repository and select maven2 (proxy).
  3. Set the following fields:
    • Name: maven-proxy
    • Remote storage: https://repo1.maven.org/maven2/
  4. Under Storage, choose default as the Blob store.
  5. Click Create repository.

To use the proxy, update your client machine's ~/.m2/settings.xml file:

<settings>
  <mirrors>
    <mirror>
      <id>nexus-maven-proxy</id>
      <mirrorOf>central</mirrorOf>
      <url>http://<your-server-ip>:8081/repository/maven-proxy/</url>
    </mirror>
  </mirrors>
</settings>

Step 7: Configure npm Proxy

  1. Navigate to Administration (gear icon) > Repository > Repositories.
  2. Click Create repository and select npm (proxy).
  3. Fill in the required details:
    • Name: npm-proxy
    • Remote storage: https://registry.npmjs.org/
  4. Under Storage, choose default as the Blob store.
  5. Click Create repository.

To point your npm client to this proxy repository, run the following command on your local machine:

npm config set registry http://<your-server-ip>:8081/repository/npm-proxy/

Verify the configuration by installing any standard package:

npm install express

The package will download through Nexus and remain cached for future requests.
