How to Monitor Battery Drain Rate with UPower in Ubuntu

This guide explains how to check and monitor your laptop's real-time battery drain rate in watts on Ubuntu using the built-in upower command-line utility. By querying the system's power management service, you can accurately identify power usage, diagnose excessive battery drain, and track how different applications impact your overall energy consumption.

Step 1: Identify Your Battery Device Path

Before monitoring power usage, identify the system path for your primary battery. Run the following command in your terminal:

upower -e | grep 'BAT'

This command lists power devices and filters for the battery. On most laptops, the output will look like this:

/org/freedesktop/UPower/devices/battery_BAT0

Step 2: Check the Current Drain Rate in Watts

To view the current power consumption, display the device details and filter specifically for the energy-rate field.

Run the combined command:

upower -i $(upower -e | grep 'BAT') | grep "energy-rate"

The output will display the current power draw in watts (W):

energy-rate:          12.45 W

When discharging, this value indicates how many watts your system is currently drawing from the battery. When charging, it represents the rate at which power is being supplied to the battery.

Step 3: Monitor Drain Rate Continuously in Real Time

To observe live fluctuations in power draw as you launch or close applications, use the watch command to refresh the reading every second:

watch -n 1 "upower -i \$(upower -e | grep 'BAT') | grep -E 'state|energy-rate|percentage'"

This provides an automatically updating view showing the battery state (discharging or charging), current percentage, and live energy consumption in watts. Press Ctrl + C to exit the monitoring loop.
