How to Fix Ubuntu Bootloader with Boot-Repair Live USB

When an update, dual-boot installation, or drive partition error corrupts the GRUB bootloader, Ubuntu fails to start properly. This guide explains how to restore access to your system by booting into a temporary Ubuntu Live USB session, installing the dedicated Boot-Repair utility, and executing an automated repair of the GRUB bootloader.

Prerequisites

To perform this repair, you need:

  • A working computer to create a bootable Ubuntu USB drive (if you do not already have one).
  • A bootable Ubuntu Live USB.
  • An active internet connection on the target machine (via Wi-Fi or Ethernet) to download the repair packages.

Step 1: Boot into the Live USB

  1. Insert the Ubuntu Live USB into the affected computer.
  2. Turn on the machine and access the boot menu by pressing the appropriate key for your hardware (commonly F12, F11, F10, F2, or Esc).
  3. Select your USB drive from the boot options.
  4. When prompted by the Ubuntu installer, select Try Ubuntu (or Try Ubuntu without installing). Do not choose the install option.

Step 2: Connect to the Internet

Once the live desktop loads:

  1. Click the system menu in the top-right corner.
  2. Connect to your local Wi-Fi network or plug in an Ethernet cable. An active connection is required to fetch the latest GRUB files and the Boot-Repair package.

Step 3: Install the Boot-Repair Utility

Boot-Repair is not included by default in standard Ubuntu live images, so it must be added via its personal package archive (PPA).

  1. Open the Terminal by pressing Ctrl + Alt + T.
  2. Add the Boot-Repair repository by entering: 
    sudo add-apt-repository ppa:yannubuntu/boot-repair
  3. Press Enter when prompted to confirm the addition.
  4. Update your package lists: 
    sudo apt update
  5. Install the Boot-Repair application: 
    sudo apt install -y boot-repair

Step 4: Run the Repair

  1. Launch the utility from the terminal:

    boot-repair

    (Alternatively, search for "Boot Repair" in the application launcher.)

  2. The tool will scan your system's drives and partitions.

  3. Click the Recommended repair button. This option automatically detects your system configuration (UEFI or Legacy BIOS), reinstalls the GRUB bootloader to the correct partition, and rebuilds the boot configuration file (grub.cfg).

  4. If prompted to paste terminal commands during the process, open a new terminal window, copy and paste the displayed commands sequentially, and follow the on-screen prompts carefully.

Step 5: Finish and Reboot

  1. Once the process finishes, Boot-Repair will display a URL (a Pastebin link containing the repair log). Note this URL down for troubleshooting in case the issue persists.
  2. Close Boot-Repair and shut down the computer.
  3. Remove the Live USB drive.
  4. Power the computer back on. The system should now display the GRUB menu or boot directly into Ubuntu.
