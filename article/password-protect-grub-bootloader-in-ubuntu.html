Password Protect GRUB Bootloader in Ubuntu

Securing the GRUB bootloader with a password prevents unauthorized users from modifying boot parameters, accessing recovery mode to bypass root security, or booting unapproved operating systems on your Ubuntu machine. This step-by-step guide covers how to generate an encrypted password, add credentials to the GRUB configuration files, and update the bootloader settings to protect your system.

Step 1: Generate an Encrypted Password

Instead of storing plain text passwords in your system files, generate a hashed password using the GRUB utility.

  1. Open your terminal (Ctrl+Alt+T).
  2. Run the following command: 
    grub-mkpasswd-pbkdf2
  3. Enter your desired password, then re-enter it to confirm.
  4. Highlight and copy the generated hash string starting with grub.pbkdf2.sha512.... You will need this for the configuration file.

Step 2: Add Credentials to GRUB Configuration

Place the user credentials and the generated hash into a custom GRUB configuration file so your settings survive future kernel updates.

  1. Open the /etc/grub.d/40_custom file in a text editor with root privileges:

    sudo nano /etc/grub.d/40_custom

  2. Append the following lines at the end of the file:

    set superusers="root"
password_pbkdf2 root YOUR_COPIED_HASH_HERE

    Replace YOUR_COPIED_HASH_HERE with the actual hash string you copied in Step 1. You can change "root" to another username if preferred.

  3. Save the file and exit the editor (in Nano, press Ctrl+O, hit Enter, then press Ctrl+X).

Step 3: Understand Boot Behaviors

By default, setting a superuser locks down the following actions:

  • Editing boot entries (pressing e at the boot menu).
  • Accessing the GRUB command line interface (pressing c).

Standard booting into Ubuntu will still occur automatically without asking for a password. If you want to require a password even for booting normal entries, open /etc/grub.d/10_linux and remove the --unrestricted parameter from the default menu entry generation lines.

Step 4: Update GRUB Settings

For the changes to take effect, regenerate the main /boot/grub/grub.cfg file.

Run the following command in the terminal:

sudo update-grub

Step 5: Test the Configuration

  1. Restart your system: 
    sudo reboot
  2. Hold Shift (for legacy BIOS) or press Esc (for UEFI) during startup to display the GRUB menu if it does not appear automatically.
  3. Select an entry and press e to attempt editing the boot parameters.
  4. Enter the username (root) and the password you set. Access to the boot editor will only be granted upon entering the correct credentials.
