Connect to Remote Ubuntu Desktop with SPICE

The Simple Protocol for Independent Computing Environments (SPICE) provides a high-performance, low-latency method for accessing a remote desktop environment, featuring automatic resolution adjustment, audio streaming, and clipboard synchronization. This guide covers how to prepare an Ubuntu server with a graphical user interface, configure the SPICE server component, securely tunnel the connection, and access the remote desktop using a SPICE client.

1. Prepare the Ubuntu Server

Ensure your Ubuntu server has a desktop environment and the necessary SPICE integration tools installed.

If your server does not already have a desktop environment, install one along with the SPICE guest agent:

sudo apt update
sudo apt install ubuntu-desktop-minimal spice-vdagent

For a lighter alternative that consumes fewer system resources, you can install XFCE instead:

sudo apt update
sudo apt install xfce4 xfce4-goodies spice-vdagent

The spice-vdagent package enables smooth mouse integration, automatic display resizing to fit your client window, and bidirectional clipboard sharing.

2. Set Up the SPICE Display Server

To share the active X11 display session directly over SPICE, install x11spice:

sudo apt install x11spice

Once installed, start the SPICE server bound to localhost to ensure the session is not exposed unencrypted to the public internet:

x11spice --port=5900 --password="YourSecurePassword" --bind=127.0.0.1

(Note: If your Ubuntu server is running as a virtual machine within KVM/QEMU, you do not need x11spice. Instead, configure the VM's display hardware directly in your hypervisor to use SPICE graphics and listen on localhost or a dedicated bridge.)

3. Create a Secure SSH Tunnel

Because raw SPICE traffic is not encrypted by default, use an SSH tunnel to route the traffic safely from your local machine to the remote server.

Run the following command on your local client machine:

ssh -L 5900:127.0.0.1:5900 username@your-server-ip

Keep this SSH session open while you are connected to the remote desktop.

4. Connect Using a SPICE Client

You need a SPICE-compatible client, such as Virt-Viewer (which includes remote-viewer), installed on your local computer.

  • Ubuntu/Debian Client: sudo apt install virt-viewer
  • Fedora/RHEL Client: sudo dnf install virt-viewer
  • Windows/macOS: Download the installer from the official Virt-Viewer or GNOME project repositories.

Launch the connection to your local forwarded port:

remote-viewer spice://127.0.0.1:5900

When prompted, enter the password configured during the server setup step. The remote Ubuntu graphical desktop will appear in a new window.
