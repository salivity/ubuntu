Manage User Groups and Memberships in Ubuntu Terminal

Managing user groups and memberships in Ubuntu via the terminal is essential for administrative access control and system security. This guide provides a straightforward overview of the essential command-line utilities used to create new groups, add users to existing groups, view group memberships, remove users from groups, and delete obsolete groups.

Creating a New Group

To create a new user group on your system, use the groupadd command followed by the desired group name. You need root privileges to run this command.

sudo groupadd developers

Adding a User to a Group

To add an existing user to a group without removing them from their current secondary groups, use the usermod command with the -a (append) and -G (groups) options.

sudo usermod -aG developers john

Note: The user must log out and log back in for the group membership changes to take effect.

Viewing Groups and User Memberships

There are multiple ways to check group information depending on what details you need.

To list all groups that a specific user belongs to:

groups john

To view detailed user and group ID information for a user:

id john

To list all groups available on the system, view the /etc/group file:

cat /etc/group

To view all users belonging to a specific group, check the entry in the /etc/group file:

grep '^developers:' /etc/group

Removing a User from a Group

To remove a user from a specific group without deleting the user account, use the deluser command or the gpasswd command.

Using deluser:

sudo deluser john developers

Using gpasswd:

sudo gpasswd -d john developers

Deleting a Group

To remove an existing group from the system, use the groupdel command.

sudo groupdel developers

Note: You cannot delete a group if it is the primary group of any existing user. You must change the primary group of those users first.
