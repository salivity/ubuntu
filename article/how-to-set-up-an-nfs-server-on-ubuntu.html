How to Set Up an NFS Server on Ubuntu

Setting up a Network File System (NFS) server on Ubuntu allows you to share directories seamlessly across Linux machines on the same network. This step-by-step guide walks you through installing the required NFS packages, configuring shared directory permissions, updating network exports, adjusting firewall settings, and mounting the share on a client machine for efficient file access.

Step 1: Install the NFS Server Package

Update your local package index and install the NFS kernel server package on the host Ubuntu machine:

sudo apt update
sudo apt install nfs-kernel-server

Step 2: Create the Shared Directory

Create the directory you want to share over the network. You can choose any path; this example uses /var/nfs/general.

sudo mkdir -p /var/nfs/general

Assign ownership to nobody:nogroup so that client users can access the shared folder without permission conflicts:

sudo chown nobody:nogroup /var/nfs/general

Step 3: Configure NFS Exports

Open the NFS configuration file /etc/exports in a text editor:

sudo nano /etc/exports

Add a line defining the directory to share, the client IP address (or network subnet) allowed to connect, and the access options:

/var/nfs/general client_ip(rw,sync,no_subtree_check)

Replace client_ip with the actual IP address of the client machine (e.g., 192.168.1.50) or a subnet range (e.g., 192.168.1.0/24).

Common options include: * rw: Grants read and write permissions. * sync: Writes changes to disk before responding to requests, ensuring data integrity. * no_subtree_check: Prevents subtree checking, which improves reliability and performance.

Save and close the file.

Step 4: Export the Shared Directory and Restart the Service

Apply the changes made to /etc/exports and restart the NFS server:

sudo exportfs -a
sudo systemctl restart nfs-kernel-server

Step 5: Configure Firewall Rules

If Uncomplicated Firewall (UFW) is active on the server, open access for the client machine:

sudo ufw allow from client_ip to any port nfs

Verify the status of the firewall:

sudo ufw status

Step 6: Set Up the Client Machine

Log in to the client Ubuntu machine and install the NFS common package:

sudo apt update
sudo apt install nfs-common

Create a local directory to serve as the mount point for the remote shared folder:

sudo mkdir -p /nfs/general

Mount the remote directory using the server’s IP address:

sudo mount server_ip:/var/nfs/general /nfs/general

Replace server_ip with the IP address of your NFS server.

Step 7: Verify the Connection and Automate Mounting

Verify that the shared folder is mounted correctly:

df -h

To automatically mount the NFS share whenever the client machine boots, open the /etc/fstab file on the client:

sudo nano /etc/fstab

Add the following entry at the end of the file:

server_ip:/var/nfs/general    /nfs/general    nfs    defaults,user,exec,_netdev    0    0

Save and close the file. The NFS share is now fully configured and accessible across your network.
