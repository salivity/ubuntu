How to Set Up a Tmux Split Pane Workflow in Ubuntu

Managing multiple terminal sessions efficiently is crucial for productivity in Linux. This guide demonstrates how to install tmux on Ubuntu, create custom split-pane layouts, navigate between panes seamlessly, and manage your sessions. By mastering these core tmux commands, you can transform a single Ubuntu terminal window into a powerful, multi-pane workspace without relying on a graphical user interface.

Step 1: Install Tmux on Ubuntu

Open your terminal and update your package list, then install tmux using apt:

sudo apt update
sudo apt install tmux -y

Verify the installation by checking the version:

tmux -V

Step 2: Start a Named Tmux Session

Starting a named session makes it easy to identify and reattach to your workspace later.

tmux new -s dev_workspace

You will now see a green status bar at the bottom of your terminal screen, indicating that tmux is active.

Step 3: Split the Terminal into Panes

In tmux, all default keybindings begin with the prefix key combination: Ctrl + b.

  • Split Vertically (Left / Right): Press Ctrl + b, release, and then press % (Shift + 5).
  • Split Horizontally (Top / Bottom): Press Ctrl + b, release, and then press " (Shift + ').

You can repeat these commands inside any active pane to create complex layout grids tailored to your workflow.

Step 4: Navigate Between Panes

To switch focus between active split panes:

  1. Press Ctrl + b.
  2. Press the Up, Down, Left, or Right arrow key corresponding to the pane you want to select.

To jump to the next pane sequentially, press Ctrl + b followed by o.

Step 5: Resize Panes

If a pane requires more screen real estate:

  1. Press Ctrl + b.
  2. Hold down the Ctrl key and press any Arrow key to adjust the border in that direction.

Alternatively, enter command mode by pressing Ctrl + b, typing :, and executing:

resize-pane -D 10   # Resizes down by 10 cells
resize-pane -U 10   # Resizes up by 10 cells
resize-pane -L 10   # Resizes left by 10 cells
resize-pane -R 10   # Resizes right by 10 cells

Step 6: Detach and Reattach Sessions

One of tmux’s biggest advantages is running background processes that persist even if you close the terminal window.

  • Detach from the session: Press Ctrl + b, then press d.

  • List active sessions:

    tmux ls

  • Reattach to your session:

    tmux attach -t dev_workspace

To close an individual pane, simply type exit inside that pane or press Ctrl + d. Once the last pane in a session is closed, the session terminates automatically.
