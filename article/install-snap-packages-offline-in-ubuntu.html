Install Snap Packages Offline in Ubuntu

Installing a snap package on an offline Ubuntu machine requires obtaining both the .snap package file and its corresponding .assert signature file from an internet-connected system. This guide walks you through the straightforward process of downloading these files, transferring them to your air-gapped system, acknowledging the cryptographic assertion, and completing the local installation using the Snap command-line interface.

Step 1: Download the Snap and Assertion Files

On a computer with an active internet connection running Ubuntu (or any Linux distribution with snapd installed), open the terminal and use the snap download command followed by the name of the package you wish to install:

snap download <package-name>

This command downloads two separate files into your current working directory:

  1. <package-name>_<revision>.snap (the actual software package)
  2. <package-name>_<revision>.assert (the cryptographic signature validating the package)

Step 2: Transfer the Files to the Offline System

Copy both the .snap and .assert files to a removable drive (such as a USB flash drive) or use a local transfer protocol to move them to the target offline Ubuntu machine. Place both files in the same directory, such as your user's ~/Downloads or home directory.

Step 3: Acknowledge the Assertion File

Open a terminal on the offline Ubuntu machine, navigate to the directory containing the transferred files, and register the cryptographic assertion with the local system:

sudo snap ack <filename>.assert

Replace <filename>.assert with the exact name of your downloaded assertion file. The snap ack command imports the signature, proving to the local Snap daemon that the package is authentic, untampered with, and published by the authorized developer.

Step 4: Install the Snap Package

Once the assertion is registered, install the application by pointing the snap install command directly to the local .snap file:

sudo snap install <filename>.snap

Replace <filename>.snap with the actual name of your package file. The Snap daemon will verify the .snap file against the previously acknowledged assertion and proceed with the installation without attempting to contact the Snap Store online.

Step 5: Verify the Installation

To confirm that the package was installed correctly, run:

snap list

The output will display your newly installed application along with its version and developer details. You can now launch and use the application normally on your offline machine.
