Set Up Local MLflow Tracking Server on Ubuntu

This guide provides a straightforward walkthrough for setting up a local MLflow tracking server on an Ubuntu machine to log and monitor machine learning experiments. You will learn how to prepare the Ubuntu environment, install MLflow within a dedicated Python virtual environment, configure a persistent backend store using SQLite, launch the server, and log your first test experiment using Python.

Prerequisites and System Preparation

Ensure your package index is updated and that Python 3, pip, and the venv module are installed on your Ubuntu system:

sudo apt update
sudo apt install -y python3 python3-pip python3-venv

Step 1: Create a Dedicated Directory and Virtual Environment

Isolate the MLflow installation from system packages by creating a dedicated directory and virtual environment:

mkdir ~/mlflow-server
cd ~/mlflow-server
python3 -m venv venv
source venv/bin/activate

Step 2: Install MLflow

Install MLflow inside the active virtual environment using pip:

pip install --upgrade pip
pip install mlflow

Step 3: Launch the MLflow Tracking Server

Run the MLflow tracking server by specifying a backend store for metadata and an artifact store for outputs such as models and plots. Using SQLite provides a reliable local relational store:

mlflow server \
    --backend-store-uri sqlite:///mlflow.db \
    --default-artifact-root ./mlruns \
    --host 127.0.0.1 \
    --port 5000
  • --backend-store-uri: Points to a local SQLite database file named mlflow.db to store runs, parameters, and metrics.
  • --default-artifact-root: Defines the local directory where artifacts (models, images, data files) are saved.
  • --host: Set to 127.0.0.1 for local-only access, or 0.0.0.0 to allow connections from other machines on your local network.
  • --port: The port on which the UI and API will listen (default is 5000).

Once started, open a web browser and navigate to http://localhost:5000 to access the MLflow web interface.

Step 4: Run as a Systemd Service (Optional)

To keep the tracking server running in the background and ensure it restarts automatically after a system reboot, configure it as a systemd service.

Create a new service configuration file:

sudo nano /etc/systemd/system/mlflow.service

Add the following configuration, replacing <YOUR_USERNAME> with your actual Ubuntu username:

[Unit]
Description=MLflow Tracking Server
After=network.target

[Service]
User=<YOUR_USERNAME>
WorkingDirectory=/home/<YOUR_USERNAME>/mlflow-server
ExecStart=/home/<YOUR_USERNAME>/mlflow-server/venv/bin/mlflow server \
    --backend-store-uri sqlite:///mlflow.db \
    --default-artifact-root /home/<YOUR_USERNAME>/mlflow-server/mlruns \
    --host 127.0.0.1 \
    --port 5000
Restart=always

[Install]
WantedBy=multi-user.target

Enable and start the service:

sudo systemctl daemon-reload
sudo systemctl enable mlflow
sudo systemctl start mlflow

Check the status to verify it is active:

sudo systemctl status mlflow

Step 5: Log a Test Experiment

Verify that the server tracks runs correctly by running a test script. In a separate terminal or Python environment, install MLflow and execute the following Python code:

import mlflow

# Point tracking URI to the local server
mlflow.set_tracking_uri("http://localhost:5000")

# Set or create an experiment
mlflow.set_experiment("local-server-test")

with mlflow.start_run():
    # Log parameters
    mlflow.log_param("learning_rate", 0.01)
    mlflow.log_param("batch_size", 32)

    # Log metrics
    mlflow.log_metric("accuracy", 0.94)
    mlflow.log_metric("loss", 0.12)

    print("Experiment run logged successfully.")

Refresh the web browser at http://localhost:5000 to confirm that the local-server-test experiment and its logged parameters and metrics appear in the UI.
