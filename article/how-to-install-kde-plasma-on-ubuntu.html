How to Install KDE Plasma on Ubuntu

Installing the KDE Plasma desktop environment on Ubuntu allows users to transform their system's look and feel from the default GNOME interface to a highly customizable, feature-rich alternative. This guide outlines the essential terminal commands required to update your system, install the KDE Plasma desktop package, select your display manager, and switch to your new desktop session.

Step 1: Update Your System Packages

Before installing a new desktop environment, ensure your system's package list and existing software are completely up to date. Open your terminal (Ctrl+Alt+T) and run:

sudo apt update && sudo apt upgrade -y

Step 2: Choose and Install a KDE Package

Ubuntu offers three main metapackages for KDE Plasma depending on how many pre-installed applications you want:

  • kde-plasma-desktop (Minimal): Installs only the core Plasma desktop and essential system utilities. Best for low-resource systems or clean setups.
  • kde-standard (Recommended): Installs the Plasma desktop along with a standard suite of KDE applications like text editors, media players, and web browsers.
  • kde-full (Complete): Installs the complete KDE ecosystem, including every official KDE application and administrative tool.

To install the recommended standard version, run:

sudo apt install kde-standard -y

(Note: Replace kde-standard with kde-plasma-desktop or kde-full if you prefer those options.)

Step 3: Configure the Display Manager

During the installation process, a prompt will appear asking you to choose a default display manager:

  1. gdm3: The default Ubuntu/GNOME display manager.
  2. sddm: The default KDE display manager, which integrates better with Plasma themes.

Use the arrow keys to select sddm, press Tab to highlight OK, and press Enter.

Step 4: Reboot Your System

Once the package installation completes, restart your computer to apply the changes:

sudo reboot

Step 5: Log Into KDE Plasma

  1. On the reboot screen (SDDM or GDM3 login page), select your user account.
  2. Look for the gear icon or session menu option (usually located at the bottom-right or top-right of the screen).
  3. Select Plasma (X11) or Plasma (Wayland) from the session list.
  4. Enter your password and log in.

Your Ubuntu system will now load into the KDE Plasma desktop interface.
