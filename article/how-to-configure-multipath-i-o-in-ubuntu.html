How to Configure Multipath I/O in Ubuntu

Configuring multipath I/O (Input/Output) in Ubuntu provides fault tolerance and load balancing for Storage Area Network (SAN) connections. By aggregating multiple physical paths between the host server and storage arrays into a single logical device, your system maintains continuous data access even if a cable, switch, or host bus adapter (HBA) fails. This guide outlines the essential steps to install the required packages, create the configuration file, manage non-SAN devices, and verify your redundant storage paths.

Step 1: Install Multipath Tools

Open your terminal and update the package list, then install the multipath-tools package:

sudo apt update
sudo apt install multipath-tools

Step 2: Generate the Configuration File

Ubuntu stores multipath configurations in /etc/multipath.conf. By default, this file may not exist. Create a basic configuration file by running:

sudo mpathconf --enable

This command creates /etc/multipath.conf and enables the multipath daemon.

Step 3: Edit /etc/multipath.conf

Open the configuration file in a text editor:

sudo nano /etc/multipath.conf

Ensure the file includes settings to blacklist local drives (like your system OS disk) so that multipath only manages your SAN LUNs.

A standard configuration template looks like this:

defaults {
    user_friendly_names yes
    find_multipaths yes
}

blacklist {
    # Blacklist local internal drives by WWID or device name
    devnode "^(td|hd|scd|pg|elf|sda)$"
}
  • user_friendly_names yes: Assigns clean names like /dev/mapper/mpatha instead of long WWIDs.
  • find_multipaths yes: Only creates a multipath device if more than one path is detected or if it is explicitly listed.

Save and close the file.

Step 4: Restart and Enable the Multipath Daemon

Apply your changes by restarting the multipath service and ensuring it starts on boot:

sudo systemctl restart multipathd
sudo systemctl enable multipathd

Step 5: Verify the Configuration

To check if your SAN paths are recognized and aggregated correctly, run:

sudo multipath -ll

The output will display the active multipath devices, their policy (e.g., active/passive or multibus), and the status of each physical path (e.g., active and ready).

You can also view the mapped logical devices using block location tools:

lsblk

Your SAN storage is now configured with redundant multipath I/O and ready to be partitioned, formatted, or mounted.
