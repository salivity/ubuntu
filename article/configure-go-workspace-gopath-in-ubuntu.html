Configure Go Workspace (GOPATH) in Ubuntu

This guide explains how to properly configure the Go programming language workspace (GOPATH) in an Ubuntu user profile. You will learn how to create your workspace directory structure, define the GOPATH and updated PATH environment variables within your profile configuration file, apply the changes, and verify that the environment is correctly set up for Go development.

Step 1: Create the Workspace Directory

By default, Go uses $HOME/go as the standard workspace, but you can define a custom directory. Open your terminal and create the workspace folder along with its required subdirectories:

mkdir -p $HOME/go/{bin,src,pkg}
  • bin: Contains compiled executable binaries.
  • src: Contains Go source code files organized into packages.
  • pkg: Contains compiled package objects.

Step 2: Open Your Shell Profile

To persist the environment variables across all terminal sessions, you must add them to your shell configuration file. For the default Bash shell in Ubuntu, open ~/.bashrc using a text editor such as nano:

nano ~/.bashrc

(Note: If you use Zsh, edit ~/.zshrc instead).

Step 3: Add the Go Environment Variables

Scroll to the bottom of the file and append the following lines:

export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin

If Go was installed manually into a custom directory (such as /usr/local/go), also ensure the Go binary itself is in your path by adding:

export PATH=$PATH:/usr/local/go/bin

Save the file and exit the editor (in nano, press Ctrl + O, then Enter to save, and Ctrl + X to exit).

Step 4: Apply the Changes

Reload the configuration file to apply the new environment variables to your current session without logging out:

source ~/.bashrc

Step 5: Verify the Configuration

Verify that the GOPATH environment variable has been set correctly:

go env GOPATH

The output should display the absolute path to your chosen workspace (e.g., /home/username/go). You can also confirm the full path by running:

echo $GOPATH

Your Go workspace is now fully configured and ready for development on Ubuntu.
