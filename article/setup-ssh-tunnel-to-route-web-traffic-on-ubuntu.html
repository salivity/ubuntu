Setup SSH Tunnel to Route Web Traffic on Ubuntu

This article explains how to create a secure SSH tunnel to route your local web browsing traffic through a remote Ubuntu server. By using SSH dynamic port forwarding, you can turn your remote server into a private SOCKS5 proxy, encrypting your local internet traffic and masking your true IP address. Below, you will find the exact commands and configuration steps required for your local machine and web browser.

Prerequisites

  • A remote Ubuntu server with SSH access enabled.
  • The server's public IP address and a user account with SSH credentials.
  • A local machine (Linux, macOS, or Windows 10/11) equipped with an SSH client.

Step 1: Establish the SSH Dynamic Tunnel

Dynamic port forwarding sets up an SSH tunnel that acts as a SOCKS proxy. Run the following command in your local terminal:

ssh -D 1080 -C -q -N username@your_remote_ip

Parameters breakdown:

  • -D 1080: Opens a local SOCKS port on 1080.
  • -C: Compresses data to speed up transfer rates.
  • -q: Enables quiet mode to suppress non-fatal messages.
  • -N: Tells SSH not to execute a remote shell command (ideal for port forwarding only).
  • username@your_remote_ip: Replace these with your remote Ubuntu username and server IP.

Keep this terminal window open. If you close it, the tunnel will terminate.

Step 2: Configure Your Web Browser

To route traffic through the tunnel, direct your browser to use the local SOCKS proxy.

Mozilla Firefox (Recommended for application-specific routing)

  1. Open Firefox and navigate to Settings.
  2. Scroll to the bottom and click Settings... under Network Settings.
  3. Select Manual proxy configuration.
  4. In the SOCKS Host field, enter 127.0.0.1 and set the Port to 1080.
  5. Select SOCKS v5.
  6. Check the box labeled Proxy DNS when using SOCKS v5 to prevent DNS leaks.
  7. Click OK to save.

Google Chrome / System-Wide Proxy

Chrome uses your operating system’s proxy settings:

  • macOS: Go to System Settings > Network > Wi-Fi/Ethernet > Details > Proxies. Enable SOCKS Proxy, then set the server to 127.0.0.1 and port to 1080.
  • Windows: Go to Settings > Network & internet > Proxy. Configure a manual proxy server with the address 127.0.0.1 and port 1080.

Step 3: Verify the Tunnel

  1. Open your configured browser and visit a public IP checker such as https://icanhazip.com or https://whatismyipaddress.com.
  2. Confirm that the displayed IP matches your remote Ubuntu server's IP address rather than your local connection's IP.

To close the tunnel, return to your terminal and press Ctrl + C. Remember to turn off the proxy settings in your browser or operating system after terminating the connection.
