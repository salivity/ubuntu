How to Check for Bad Blocks in Ubuntu Terminal

Bad blocks, or bad sectors, are corrupted areas of a hard drive that can no longer reliably store data and often lead to system instability or data loss. In Ubuntu, you can easily diagnose drive health and scan for these corrupted areas directly from the terminal without installing complex software. This guide covers how to identify your drive, perform non-destructive scans using smartctl, run detailed block tests with the badblocks utility, and mark corrupted sectors so your system avoids them using fsck.

Step 1: Identify Your Hard Drive

Before running any scans, you need to find the correct device identifier for your drive (such as /dev/sda or /dev/sdb).

Open your terminal and list all connected storage devices:

lsblk

Alternatively, you can use fdisk:

sudo fdisk -l

Locate your target drive from the list and note its path (e.g., /dev/sdb).

Step 2: Check Drive Health with SMART Tools

The fastest way to check for hardware issues and reallocated sectors is by using smartmontools.

  1. Install the utility:

    sudo apt update && sudo apt install smartmontools -y

  2. Run an overall health test on your drive:

    sudo smartctl -H /dev/sdX

    (Replace /dev/sdX with your drive’s path, e.g., /dev/sdb)

  3. Check detailed SMART attributes, specifically looking for “Reallocated_Sector_Ct” and “Current_Pending_Sector”:

    sudo smartctl -A /dev/sdX

Step 3: Scan for Bad Blocks Using the badblocks Tool

The badblocks command searches a drive for damaged sectors.

Safe Read-Only Scan (Recommended for Drives with Data)

To perform a non-destructive scan that reads through the disk and reports bad sectors:

sudo badblocks -sv /dev/sdX
  • -s: Displays progress.
  • -v: Enables verbose mode (shows detailed findings).

Non-Destructive Read-Write Scan

If you want a deeper test that writes data, reads it back, and restores the original contents without erasing the drive:

sudo badblocks -snv /dev/sdX

Destructive Read-Write Scan (Data Erasure)

To thoroughly test a brand-new or completely wiped drive, run a destructive read-write test. Warning: This will permanently erase all data on the drive.

sudo badblocks -wsv /dev/sdX

Step 4: Output Bad Blocks to a File and Mark Them

If badblocks discovers corrupted sectors, you can save the results to a text file and tell your file system to avoid using those sectors in the future.

  1. Scan the drive and output errors to badsectors.txt:

    sudo badblocks -v /dev/sdX > badsectors.txt

  2. Unmount the target partition before repairing it:

    sudo umount /dev/sdX1

  3. Pass the file to e2fsck to mark the sectors (for ext2/ext3/ext4 file systems):

    sudo e2fsck -l badsectors.txt /dev/sdX1

Alternatively, you can automatically scan and mark bad sectors in one command using e2fsck:

sudo e2fsck -cfpv /dev/sdX1
  • -c: Runs badblocks and adds found bad blocks to the read-only list.
  • -f: Forces a check even if the file system seems clean.
  • -p: Automatically repairs minor issues.
  • -v: Enables verbose output.
