How to Download Files in the Ubuntu Command Line

Downloading files directly through the Ubuntu terminal is a fast and efficient process primarily handled by two powerful command-line utilities: wget and curl. This article provides an overview of how to use both commands to fetch files from the web, rename downloads, and resume interrupted transfers in Ubuntu.

Using the wget Command

The wget tool is the most common command used for downloading files via HTTP, HTTPS, and FTP protocols in Ubuntu. It is designed to work reliably in unstable network environments and can run in the background.

Basic Usage

To download a file to your current directory using its original filename, run:

wget https://example.com/sample.zip

Common Options

  • Save with a custom filename: Use -O followed by the desired name. 
    wget -O new_name.zip https://example.com/sample.zip
  • Resume an interrupted download: Use the -c flag. 
    wget -c https://example.com/largefile.iso
  • Download in the background: Use the -b flag. 
    wget -b https://example.com/file.zip

Using the curl Command

The curl command is a versatile utility used to transfer data to or from a server. By default, curl prints the content of the specified URL to the terminal screen, so you must use flags to save the file locally.

Basic Usage

To download a file and save it using the same filename as on the server, use the -O (uppercase) option:

curl -O https://example.com/sample.zip

Common Options

  • Save with a custom filename: Use -o (lowercase) followed by the new filename. 
    curl -o new_name.zip https://example.com/sample.zip
  • Follow location redirects: Use the -L flag if the URL redirects to another location. 
    curl -L -O https://example.com/redirect-link
  • Resume an interrupted download: Use the -C - flag option. 
    curl -C - -O https://example.com/largefile.iso

Which Tool Should You Use?

  • Use wget if you need a straightforward file downloader that handles recursive downloads or operates in the background automatically.
  • Use curl if you are interacting with APIs, need support for additional protocols, or want to inspect HTTP headers during the download.
