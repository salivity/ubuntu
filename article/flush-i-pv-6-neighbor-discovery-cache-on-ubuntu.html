Flush IPv6 Neighbor Discovery Cache on Ubuntu

This guide explains how to clear the IPv6 Neighbor Discovery (ND) cache on an Ubuntu system. You will learn the standard commands using the modern iproute2 suite to flush entries across all interfaces or target a specific network device, as well as how to inspect the neighbor table before and after the operation.

View the Current IPv6 Neighbor Cache

Before clearing the cache, you can inspect the active IPv6 neighbor entries by running:

ip -6 neigh show

This command lists all resolved IPv6 addresses, their corresponding MAC addresses, the associated interface, and the neighbor state (such as REACHABLE, STALE, or FAILED).

Flush All IPv6 Neighbor Entries

To completely clear the IPv6 Neighbor Discovery cache across all network interfaces, execute the following command with root privileges:

sudo ip -6 neigh flush all

The system will invalidate and remove all current dynamic IPv6 neighbor mappings.

Flush the Cache for a Specific Interface

If you only want to clear entries associated with a particular network interface (for example, eth0 or enp3s0), use the dev option:

sudo ip -6 neigh flush dev <interface_name>

Replace <interface_name> with your actual interface identifier, for example:

sudo ip -6 neigh flush dev eth0

Verify the Cache Has Been Cleared

Run the show command again to confirm that the neighbor entries have been removed:

ip -6 neigh show

If the flush was successful, the command will return an empty output or only display actively regenerating connections.
