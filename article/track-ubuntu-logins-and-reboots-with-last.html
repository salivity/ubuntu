Track Ubuntu Logins and Reboots with last

Monitoring user sessions and system restarts is an essential task for Ubuntu system administrators. The last command queries the /var/log/wtmp file to provide a clear audit trail of past user logins, system boots, and runlevel changes. This guide demonstrates how to use the last command to view login histories, filter events by user or timeframe, and specifically track system reboots and shutdowns.

Basic Usage of the last Command

Running last without any arguments displays a list of all recorded login and logout sessions, ordered from the most recent to the oldest:

last

Each line of output displays the following information:

  • Username: The account that logged in (or reboot for system restart events).
  • TTY/Terminal: The terminal line used (e.g., pts/0 for SSH or tty1 for local console).
  • Host/IP: The remote IP address or hostname from which the connection originated.
  • Timestamp: The date and time the session began.
  • Duration: How long the session lasted or whether the user is still logged in (still logged in).

To prevent the terminal from overflowing, limit the output to a specific number of lines using the -n or -<number> flag:

last -n 10

Tracking System Reboots

Ubuntu logs every system reboot to /var/log/wtmp under the pseudo-user reboot. To view the complete history of system reboots, execute:

last reboot

The output highlights when the system booted up, the kernel version running during the boot, and the duration of uptime before the next restart or crash:

reboot   system boot  5.15.0-88-generic Mon May 20 08:14   still running
reboot   system boot  5.15.0-88-generic Sun May 19 14:22 - 08:10  (17:48)

If an entry ends with crash, the system terminated unexpectedly (such as from a power outage or kernel panic) rather than a clean shutdown.

Tracking System Shutdowns and Runlevels

To see both reboots and system shutdowns, use the -x flag. This option directs last to show system shutdown entries and runlevel changes:

last -x

To view only shutdown events:

last -x shutdown

Filtering Logins by Specific User

To track the login activity of a single account, pass the username as an argument:

last username

For example, to inspect the administrative activity of the root user:

last root

Filtering by Time and Date

The last command supports time-based filtering using the -s (--since) and -t (--until) flags. The format accepts YYYYMMDDHHMMSS, standard dates, or relative words like yesterday or today.

To view all events that occurred since yesterday:

last -s yesterday

To inspect login activity within a specific date range:

last -s "2024-05-01" -t "2024-05-15"

Displaying IP Addresses Instead of Hostnames

By default, last may attempt to resolve remote IP addresses to hostnames. To force last to display the remote IP address, use the -i flag:

last -i

To display the IP address or hostname in the final column instead of the third column, add the -F and -a flags for improved readability:

last -a

Reading Rotated Log Files

The /var/log/wtmp file is automatically rotated periodically by Ubuntu's logrotate service. Older logs are saved as /var/log/wtmp.1 or compressed as .gz archives.

To query an older, rotated file, use the -f flag:

last -f /var/log/wtmp.1
