How to Install TLP on Ubuntu to Maximize Battery Life

This guide provides a step-by-step walkthrough for installing and configuring TLP, an advanced command-line power management tool for Linux, on an Ubuntu laptop. You will learn how to properly prepare your system by removing conflicting power daemons, install the latest version of TLP, adjust key configuration parameters to maximize battery longevity, and verify that the power-saving optimizations are actively running.

Step 1: Remove Conflicting Services

Modern Ubuntu versions come pre-installed with power-profiles-daemon. This service conflicts with TLP's background operations. Before installing TLP, you must disable or uninstall it:

sudo apt remove power-profiles-daemon

Step 2: Install TLP

TLP is available directly from the official Ubuntu repositories. Install TLP alongside the Radio Device Wizard (tlp-rdw) by running:

sudo apt update
sudo apt install tlp tlp-rdw

Step 3: Enable and Start TLP

Once installed, enable TLP so that it automatically runs on system boot, then start the service immediately:

sudo systemctl enable tlp.service
sudo tlp start

TLP runs automatically in the background with optimized default settings that automatically detect whether your device is on AC power or battery.

Step 4: Configure TLP for Maximum Battery Life

While default settings are effective, you can fine-tune TLP to prioritize maximum battery life over performance. Configuration settings are managed in /etc/tlp.conf.

Open the file in a text editor with administrative privileges:

sudo nano /etc/tlp.conf

Locate and adjust the following parameters by removing the # at the beginning of each line to uncomment them:

  • CPU Performance Governors: Force the CPU to run in low-power modes when running on battery:

    CPU_SCALING_GOVERNOR_ON_BAT=powersave
CPU_ENERGY_PERF_POLICY_ON_BAT=power

  • CPU Turbo Boost: Disabling CPU boost on battery significantly reduces power consumption and heat:

    CPU_BOOST_ON_BAT=0

  • PCI Express Active State Power Management (ASPM): Enforce the highest power-saving state for PCIe bus devices:

    PCIE_ASPM_ON_BAT=powersupersave

  • Wi-Fi Power Saving: Enable power-saving mode for wireless cards:

    WIFI_PWR_ON_BAT=on

  • Audio Power Saving: Put audio chipsets into standby after a set number of seconds of inactivity:

    SOUND_POWER_SAVE_ON_BAT=1

Save and exit the file (in nano, press Ctrl + O, Enter, then Ctrl + X).

Step 5: Set Battery Charge Thresholds (Hardware Dependent)

If your laptop supports charge thresholds (such as Lenovo ThinkPads and certain Asus, Dell, or LG models), you can prevent the battery from charging to 100%, which prolongs battery lifespan over time. In /etc/tlp.conf, set:

START_CHARGE_THRESH_BAT0=75
STOP_CHARGE_THRESH_BAT0=80

Step 6: Apply and Verify Changes

Apply the new configurations immediately without rebooting:

sudo tlp start

To verify that TLP is operating correctly and check your system's current power state, run:

sudo tlp-stat -s

To inspect CPU frequency scaling, temperatures, and power profiles, use:

sudo tlp-stat -p

To view battery health and threshold status, use:

sudo tlp-stat -b
