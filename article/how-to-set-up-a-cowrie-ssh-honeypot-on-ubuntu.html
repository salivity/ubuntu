How to Set Up a Cowrie SSH Honeypot on Ubuntu

Setting up an SSH honeypot is an effective way to detect malicious scanning, log brute-force attempts, and analyze attacker behavior without risking your production environment. This guide provides a direct, step-by-step walkthrough for deploying Cowrie—a popular medium- to high-interaction SSH and Telnet honeypot—on an exposed Ubuntu server. You will learn how to relocate your real SSH service to a non-standard port, install Cowrie inside a secure non-root environment, configure traffic forwarding, and analyze captured activity.

Step 1: Change the Default OpenSSH Port

Before installing Cowrie, you must move your legitimate SSH service to a different port so that port 22 is available for the honeypot.

  1. Open the SSH daemon configuration: 
    sudo nano /etc/ssh/sshd_config
  2. Locate the line #Port 22 or Port 22, uncomment it, and change it to an alternate port, such as 22022: 
    Port 22022
  3. Save the file and restart the SSH service: 
    sudo systemctl restart ssh
  4. Confirm you can connect via the new port before closing your current terminal: 
    ssh -p 22022 user@your_server_ip

Step 2: Install System Dependencies

Update the server packages and install the prerequisites required to run Cowrie inside a Python virtual environment:

sudo apt update && sudo apt install -y git python3-virtualenv libssl-dev libffi-dev build-essential python3-dev python3-pip authbind iptables-persistent

Step 3: Create a Dedicated Cowrie User

For security reasons, Cowrie must never be run as root. Create a dedicated system user with no administrative privileges:

sudo adduser --disabled-password --gecos "" cowrie

Step 4: Download and Install Cowrie

Switch to the newly created user and set up Cowrie in its home directory:

sudo su - cowrie
git clone https://github.com/micheloosterhof/cowrie.git
cd cowrie
virtualenv --python=python3 cowrie-env
source cowrie-env/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

Step 5: Configure Cowrie

Create a custom configuration file by copying the default template:

cp etc/cowrie.cfg.dist etc/cowrie.cfg

Open etc/cowrie.cfg with a text editor to customize parameters:

  • Set your honeypot hostname under the [honeypot] section (e.g., hostname = ubuntu-srv).
  • By default, Cowrie listens on port 2222 for SSH and port 2223 for Telnet. Keep these default internal ports unchanged.

Exit back to your administrative user:

exit

Step 6: Route Port 22 Traffic to Cowrie

Because non-root users cannot bind directly to privileged ports below 1024, route inbound traffic from port 22 to Cowrie's port 2222 using iptables:

sudo iptables -t nat -A PREROUTING -p tcp --dport 22 -j REDIRECT --to-port 2222
sudo netfilter-persistent save

Step 7: Launch and Monitor the Honeypot

Switch back to the cowrie user and start the service:

sudo su - cowrie
cd cowrie
source cowrie-env/bin/activate
bin/cowrie start

Verify that the process is running:

bin/cowrie status

To monitor inbound attack attempts in real time, view the Cowrie log file:

tail -f var/log/cowrie/cowrie.log

Any attacker attempting to access port 22 will be directed into Cowrie’s emulated environment, where all keystrokes, downloaded payloads, and credential combinations are recorded in the var/log/cowrie/ and var/lib/cowrie/downloads/ directories.
