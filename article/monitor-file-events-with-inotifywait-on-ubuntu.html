Monitor File Events with inotifywait on Ubuntu

This article explores the purpose and functionality of the inotifywait command-line utility in Ubuntu. You will learn how this tool interfaces with the Linux kernel to monitor file system events in real time, why it replaces inefficient polling methods, and how system administrators and developers use it to trigger automated shell scripts upon detecting file modifications, creations, or deletions.

Understanding inotifywait

inotifywait is a command-line tool provided by the inotify-tools package in Ubuntu. Its primary purpose is to wait for and respond to specific file system events using the Linux kernel’s built-in inotify subsystem. Rather than requiring external programs to repeatedly scan directories to see if files have changed, inotifywait allows the kernel to notify user space instantly when an action occurs.

Key Purposes and Benefits

1. Real-Time Event-Driven Monitoring

Traditional scripts often rely on continuous loops or cron jobs running every minute to detect file changes. This polling approach wastes CPU cycles and introduces a delay between an event occurring and the script noticing it. inotifywait blocks execution until an actual event occurs, consuming virtually no system resources while idle and reacting with millisecond latency.

2. Granular Event Filtering

inotifywait allows users to watch for precise types of file activity rather than generic modifications. Common events include:

  • modify: A watched file or directory was written to.
  • create: A file or directory was created within a watched directory.
  • delete: A file or directory within a watched directory was removed.
  • move / moved_to / moved_from: A file or directory was relocated.
  • attrib: Metadata (permissions, timestamps) was altered.
  • close_write: A file that was opened for writing has been closed (ideal for catching fully written files).

3. Recursive Directory Tracking

With the -r flag, inotifywait can watch entire directory trees, automatically adding newly created subdirectories to the watch list.

Triggering Scripts with inotifywait

The primary implementation pattern for inotifywait involves embedding it into a Bash loop to execute actions automatically.

Installation

To install the tool on Ubuntu, run:

sudo apt update
sudo apt install inotify-tools

Automation Example

By pairing the continuous monitor flag (-m) with a standard shell pipe, incoming events can trigger commands immediately.

#!/bin/bash
TARGET_DIR="/path/to/watch"

inotifywait -m -e close_write,create --format '%w%f' "$TARGET_DIR" | while read NEW_FILE
do
    echo "Processing detected file: $NEW_FILE"
    # Trigger your task here (e.g., upload, backup, convert)
done

Common Use Cases

  • Continuous Backups and Syncing: Automatically initiating an rsync command whenever a document is saved.
  • Automated Development Workflows: Compiling code, running unit tests, or restarting web servers the moment a source file is modified.
  • Security and Auditing: Monitoring sensitive files (such as /etc/shadow or web server roots) and triggering alert emails when unauthorized changes occur.
  • Automated Ingestion Pipelines: Processing, compressing, or moving incoming uploads as soon as they finish transferring to a drop folder.
