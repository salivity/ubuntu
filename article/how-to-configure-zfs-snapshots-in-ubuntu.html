How to Configure ZFS Snapshots in Ubuntu

Configuring ZFS snapshots for data backup in Ubuntu involves installing the ZFS utility package, creating or selecting a ZFS dataset, taking point-in-time snapshots manually using the zfs snapshot command, and optionally automating the process using automated tools like zfs-auto-snapshot or sanoid. ZFS snapshots are instantaneous, space-efficient, read-only copies of your file system that allow you to quickly recover lost data or roll back system changes without significant storage overhead.

Step 1: Install ZFS Utilities

Before managing ZFS datasets and snapshots, install the standard ZFS administration tools on Ubuntu:

sudo apt update
sudo apt install zfsutils-linux

Verify that ZFS is correctly installed by checking the pool status:

zpool status

Step 2: Identify or Create a ZFS Dataset

Snapshots are taken at the dataset level. To list existing ZFS datasets:

zfs list

If you need to create a new dataset for testing or storage:

sudo zfs create pool_name/dataset_name

Replace pool_name with your ZFS pool name and dataset_name with your desired folder directory name.

Step 3: Create a Manual ZFS Snapshot

To create a snapshot, execute the zfs snapshot command followed by the dataset name and a snapshot identifier separated by an @ symbol.

sudo zfs snapshot pool_name/dataset_name@snapshot_label

Example:

sudo zfs snapshot pool_name/dataset_name@backup_2026_03_30

To verify the snapshot was created, list all snapshots:

zfs list -t snapshot

Step 4: Access and Restore Data from Snapshots

Accessing Individual Files

By default, ZFS snapshots are accessible in a hidden .zfs/snapshot directory located at the root of the dataset mount point.

cd /pool_name/dataset_name/.zfs/snapshot/backup_2026_03_30

From here, you can manually copy individual files back to their original locations.

Rolling Back an Entire Dataset

To restore the entire dataset back to the exact state of a specific snapshot, use the zfs rollback command:

sudo zfs rollback pool_name/dataset_name@backup_2026_03_30

Note: Rolling back will destroy all data created on the dataset after the target snapshot was taken.

Step 5: Automate Snapshots for Regular Backups

For hands-free data protection, automate the creation and deletion of routine snapshots using zfs-auto-snapshot.

  1. Install zfs-auto-snapshot:

    sudo apt install zfs-auto-snapshot

  2. By default, zfs-auto-snapshot automatically creates frequent, hourly, daily, weekly, and monthly snapshots for all ZFS datasets.

  3. To disable automatic snapshots for a specific dataset:

    sudo zfs set com.sun:auto-snapshot=false pool_name/dataset_name

  4. To enable automatic snapshots on a specific dataset only:

    sudo zfs set com.sun:auto-snapshot=true pool_name/dataset_name

Step 6: Delete Unneeded Snapshots

To free up space or clear old snapshots manually, use the zfs destroy command:

sudo zfs destroy pool_name/dataset_name@backup_2026_03_30
