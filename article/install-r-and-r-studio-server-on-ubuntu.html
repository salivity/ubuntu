Install R and RStudio Server on Ubuntu

This guide provides a direct walkthrough for setting up the R programming language and RStudio Server on an Ubuntu Linux system. By following these steps, you will configure your system to download the latest stable release of R, install RStudio Server, configure basic access permissions, and connect to the web-based IDE through your internet browser.

Step 1: Update the System and Install Dependencies

Open your terminal and refresh your package index, then install the prerequisite tools needed to add secure repositories and manage packages:

sudo apt update && sudo apt upgrade -y
sudo apt install -y dirmngr gnupg apt-transport-https ca-certificates software-properties-common gdebi-core wget

Step 2: Install the R Base Language

To ensure you receive the most recent version of R, add the official Comprehensive R Archive Network (CRAN) repository key and archive:

# Add the CRAN GPG key
wget -qO- https://cloud.r-project.org/bin/linux/ubuntu/marutter_pubkey.asc | sudo tee -a /etc/apt/trusted.gpg.d/cran_ubuntu_key.asc

# Add the repository for your Ubuntu version
sudo add-apt-repository "deb https://cloud.r-project.org/bin/linux/ubuntu $(lsb_release -cs)-cran40/"

# Update package lists and install R
sudo apt update
sudo apt install -y r-base r-base-dev

Verify that R is installed correctly by checking its version:

R --version

Step 3: Download and Install RStudio Server

Download the latest standard 64-bit .deb package of RStudio Server for Ubuntu and install it using gdebi, which automatically handles missing dependencies:

# Download the package
wget https://download2.rstudio.org/server/jammy/amd64/rstudio-server-2024.04.2-764-amd64.deb

# Install the package
sudo gdebi -n rstudio-server-2024.04.2-764-amd64.deb

# Remove the installer file after completion
rm rstudio-server-2024.04.2-764-amd64.deb

Step 4: Verify the Service Status

Check whether the RStudio Server service is active and running:

sudo systemctl status rstudio-server

If the service is not running, start it and enable it to launch automatically at boot:

sudo systemctl start rstudio-server
sudo systemctl enable rstudio-server

Step 5: Configure the Firewall

RStudio Server communicates on default port 8787. If you are using the Uncomplicated Firewall (UFW), allow traffic on this port:

sudo ufw allow 8787/tcp

Step 6: Access the Web Interface

RStudio Server authenticates users based on the standard Linux user accounts on the server. If you do not have a non-root user account, create one:

sudo adduser ruser

Set a secure password when prompted. Open your web browser and navigate to:

http://<your-server-ip>:8787

Log in using your Linux username and password to start working in the RStudio interface.
