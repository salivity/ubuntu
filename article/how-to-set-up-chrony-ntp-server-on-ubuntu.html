How to Set Up Chrony NTP Server on Ubuntu

Setting up an NTP (Network Time Protocol) server ensures all devices on a local network maintain accurate and synchronized time. This guide provides a step-by-step walkthrough for installing, configuring, and testing a Chrony NTP server on an Ubuntu system, along with instructions for connecting network clients to it.

Step 1: Install Chrony

Open a terminal on your Ubuntu server and update the package list, then install Chrony:

sudo apt update
sudo apt install chrony -y

Enable and start the Chrony service:

sudo systemctl enable --now chrony

Step 2: Configure Chrony as an NTP Server

Open the Chrony configuration file in a text editor:

sudo nano /etc/chrony/chrony.conf

To allow clients on your local network to synchronize their time with this server, locate the #allow directive and uncomment it, replacing the IP address range with your local network subnet. For example:

allow 192.168.1.0/24

If you want the server to serve time even if it loses internet connectivity to upstream NTP pools, add or uncomment the following line:

local stratum 10

Save and close the file (Ctrl+O, Enter, Ctrl+X in Nano).

Restart the Chrony service to apply the changes:

sudo systemctl restart chrony

Step 3: Configure the Firewall

Allow UDP traffic on port 123 through the Uncomplicated Firewall (UFW) so clients can reach the server:

sudo ufw allow 123/udp
sudo ufw reload

Step 4: Verify Server Status

Check if Chrony is tracking reference sources properly:

chronyc tracking

To see the list of upstream NTP servers your Chrony server is syncing with:

chronyc sources

Step 5: Configure Ubuntu Clients

On any client Ubuntu machine that needs to sync with your new server, install Chrony:

sudo apt update
sudo apt install chrony -y

Edit the Chrony configuration file on the client:

sudo nano /etc/chrony/chrony.conf

Comment out the default pool lines by adding a # at the beginning of each line, and add your local Chrony server’s IP address:

server 192.168.1.100 iburst

(Replace 192.168.1.100 with the actual IP address of your Chrony server).

Save the file and restart Chrony on the client:

sudo systemctl restart chrony

Verify that the client is connected to your NTP server:

chronyc sources
