Change Remote Samba Password with smbpasswd

This guide explains how to update a user's SMB/CIFS password on a remote server from an Ubuntu system using the smbpasswd utility. You will learn the exact command syntax, the required parameters, and the basic prerequisites needed to modify credentials over a network connection without directly logging into the remote host.

The smbpasswd Remote Command

To change a remote user's Samba password from Ubuntu, use the smbpasswd command with the -r (remote machine) and -U (username) options:

smbpasswd -r <remote-host> -U <username>

Command Parameters

  • -r <remote-host>: Specifies the remote Samba or Active Directory server. You can provide either the hostname (e.g., samba.example.com) or the server's IP address (e.g., 192.168.1.50).
  • -U <username>: Specifies the account name whose password you want to change. If omitted, smbpasswd defaults to the current local Ubuntu username.

Example Walkthrough

To change the password for a user named jdoe on a remote server located at 192.168.1.100, run:

smbpasswd -r 192.168.1.100 -U jdoe

Once executed, the tool will interactively prompt you for:

  1. Old SMB password: The existing password for the account.
  2. New SMB password: The desired new password.
  3. Retype new SMB password: Confirmation of the new password.

If the authentication succeeds and the remote server's password policy is satisfied, you will receive a confirmation message stating that the password has been changed.

Prerequisites

  • Samba Client Utilities: The smbpasswd command is part of the samba-common-bin package. If it is not installed, install it via: 
    sudo apt update && sudo apt install samba-common-bin -y
  • Network Connectivity: Port 445 (or legacy port 139) must be open and accessible between your Ubuntu machine and the target remote server.
