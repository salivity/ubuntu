How to Manage iptables Rules in Ubuntu

This guide provides a practical walkthrough for managing network firewall rules in Ubuntu using the raw iptables command. You will learn how to view existing rules, add new rules to allow or block specific traffic, delete unwanted rules, and save your configurations so they persist across system reboots.

Understanding iptables Structure

iptables filters network packets based on tables, chains, and targets:

  • Tables: The default and most common table is filter.
  • Chains: Default chains for the filter table are:
    • INPUT: Controls incoming connections to the server.
    • OUTPUT: Controls outgoing connections originating from the server.
    • FORWARD: Controls traffic routed through the server.
  • Targets: The action taken on a packet (e.g., ACCEPT, DROP, REJECT).

Viewing Firewall Rules

To view all active iptables rules with detailed information, run:

sudo iptables -L -v -n
  • -L: Lists the rules.
  • -v: Displays verbose output (byte and packet counters).
  • -n: Displays IP addresses and port numbers in numeric format instead of resolving names.

To display line numbers alongside rules, which makes deleting specific rules easier:

sudo iptables -L --line-numbers

Adding Rules

Use the -A (Append) flag to add a rule to the end of a chain, or the -I (Insert) flag to insert a rule at a specific position.

Allow Loopback Traffic

Always allow traffic on the loopback interface (lo) so local processes can communicate:

sudo iptables -A INPUT -i lo -j ACCEPT

Allow Established and Related Connections

Allow incoming responses to traffic that originated from your system:

sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT

Allow SSH (Port 22)

Prevent locking yourself out of the server by allowing SSH connections:

sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

Allow Web Traffic (Ports 80 and 443)

Allow standard HTTP and HTTPS traffic:

sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

Block a Specific IP Address

To drop all incoming traffic from a specific IP address:

sudo iptables -A INPUT -s 192.168.1.50 -j DROP

Deleting Rules

You can delete rules by specifying their exact parameters or by using their line number.

Delete by Line Number

  1. List the rules with line numbers: 
    sudo iptables -L INPUT --line-numbers
  2. Delete the rule at the desired line number (for example, line 3): 
    sudo iptables -D INPUT 3

Clear All Rules (Flush)

To delete all active rules and start fresh:

sudo iptables -F

Changing Default Chain Policies

By default, chains accept all traffic. To block any incoming traffic that does not explicitly match an ACCEPT rule, set the default INPUT policy to DROP:

sudo iptables -P INPUT DROP

Note: Ensure you have added an SSH allow rule before running this command to avoid getting disconnected.

Making Rules Persistent

Rules created with iptables are stored in memory and reset upon reboot. To make them permanent on Ubuntu, use the iptables-persistent package.

  1. Install the package: 
    sudo apt update
sudo apt install iptables-persistent
  2. Save your current rules at any time with: 
    sudo netfilter-persistent save
