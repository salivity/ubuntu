Install Julia with Official Binaries on Ubuntu

Installing Julia on Ubuntu using the official generic Linux binaries ensures you receive an up-to-date, optimized, and officially supported release rather than an outdated version from default repositories. This guide walks through downloading the latest official Julia tarball, extracting it to a standard directory, creating a system-wide symbolic link, and verifying your installation via the terminal.

Step 1: Update System Packages and Install Prerequisites

Ensure your package list is up to date and that common download tools are installed:

sudo apt update
sudo apt install -y wget tar

Step 2: Download the Official Julia Binary

Determine whether your system is running an x86_64 or ARM architecture. Most modern PCs and cloud instances use 64-bit x86.

Download the latest stable release (for example, Julia 1.10.4 for 64-bit x86) directly using wget:

wget https://julialang-s3.julialang.org/bin/linux/x64/1.10/julia-1.10.4-linux-x86_64.tar.gz

(Note: Replace the version number in the URL if a newer version is available).

Step 3: Extract the Binary to /opt

The /opt directory is standard for installing self-contained software packages on Linux.

  1. Extract the downloaded archive:
tar -xvzf julia-1.10.4-linux-x86_64.tar.gz
  1. Move the extracted directory to /opt:
sudo mv julia-1.10.4 /opt/julia-1.10.4
  1. (Optional) Remove the downloaded .tar.gz archive to free up disk space:
rm julia-1.10.4-linux-x86_64.tar.gz

Step 4: Create a System-Wide Symbolic Link

To run the julia command from any terminal without specifying its full path, create a symlink in /usr/local/bin:

sudo ln -s /opt/julia-1.10.4/bin/julia /usr/local/bin/julia

If you previously installed another version of Julia linked this way, remove the old link first using sudo rm /usr/local/bin/julia.

Step 5: Verify the Installation

Check that Julia is correctly accessible and displays the installed version:

julia --version

You should see output similar to:

julia version 1.10.4

To launch the Julia interactive REPL session, simply run:

julia

Type exit() or press Ctrl + D to exit the REPL.
