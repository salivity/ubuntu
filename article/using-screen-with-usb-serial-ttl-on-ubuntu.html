Using Screen with USB Serial TTL on Ubuntu

This guide explains how to interface with a USB-to-Serial TTL adapter on Ubuntu using the screen terminal emulator. You will learn how to identify the connected serial adapter, configure user permissions to access the hardware, connect to the device using specific baud rates, and properly terminate the session.

1. Install GNU Screen

Ensure screen is installed on your Ubuntu system by running:

sudo apt update
sudo apt install screen

2. Identify the Serial Device Node

Plug your USB-to-Serial TTL adapter into your Ubuntu machine. Most adapters (such as FTDI, CP2102, or CH340 chipsets) register as either /dev/ttyUSB* or /dev/ttyACM*.

Identify the exact port name assigned by the kernel using dmesg:

dmesg | grep -E "ttyUSB|ttyACM"

Alternatively, list the active serial devices:

ls /dev/ttyUSB*

Note the device path (for example, /dev/ttyUSB0).

3. Configure User Permissions

Serial ports on Ubuntu are typically owned by the dialout group. To access the device without root privileges (sudo), add your current user to this group:

sudo usermod -aG dialout $USER

Log out and log back in, or run newgrp dialout in your current terminal to apply the group changes.

4. Connect Using the Screen Command

The syntax for connecting to a serial port with screen requires the device path followed by the baud rate (communication speed):

screen /dev/<port_name> <baud_rate>

For example, to connect to /dev/ttyUSB0 at 115200 baud:

screen /dev/ttyUSB0 115200

Common baud rates for microcontrollers and embedded systems include 9600, 19200, 38400, 57600, and 115200.

5. Exit or Terminate the Screen Session

To disconnect and close the screen session:

  1. Press Ctrl + A.
  2. Press \ (backslash) or K.
  3. Press y when prompted to confirm termination.

To detach from the session while leaving it running in the background, press Ctrl + A, then D. You can reattach to it later by running screen -r.
