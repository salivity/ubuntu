How to Use tzselect on Ubuntu Server

The tzselect utility is a command-line tool on Ubuntu and other Unix-like systems designed to help administrators interactively determine their correct timezone. This article explains the primary purpose of tzselect, how its menu-driven interface works, and the critical distinction between identifying a timezone using this utility and applying it permanently to the entire operating system.

The Purpose of tzselect

On an Ubuntu server, timezones are stored as database files within the /usr/share/zoneinfo directory using the standard "Area/Location" format (such as America/New_York or Europe/London). Because remembering the exact naming conventions for thousands of regional zones can be difficult, tzselect serves as an interactive questionnaire to find the exact timezone string without manually searching system directories.

When executed, tzselect prompts the user through a series of numbered geographic menus:

  1. Continent or Ocean: Displays a top-level list (e.g., Africa, Americas, Asia, Europe).
  2. Country: Narrows the selection to a specific nation within that continent.
  3. Region or City: Prompts for the specific local time region if the country spans multiple time zones.

Once confirmed, the utility prints the resulting timezone specification along with the current time in that zone to verify accuracy.

Scope and Limitations: Temporary vs. Permanent

The most important aspect of tzselect to understand is that it does not modify the system-wide timezone configuration. Instead, it outputs the identified timezone string and instructs the user on how to set the TZ environment variable temporarily for their current shell session:

TZ='America/Chicago'; export TZ

This makes tzselect particularly useful when a user needs to run a specific command or script under a different local time without affecting other users or background services running on the server.

Applying the Selected Timezone System-Wide

Because tzselect merely identifies the timezone rather than persisting it, administrators must use standard Ubuntu utilities to apply the change permanently across the server. Once tzselect provides the correct timezone name, it can be applied system-wide using timedatectl:

sudo timedatectl set-timezone America/Chicago

Alternatively, the sudo dpkg-reconfigure tzdata command provides a similar interactive terminal interface that automatically writes the selection to /etc/timezone and updates the /etc/localtime symlink permanently.
