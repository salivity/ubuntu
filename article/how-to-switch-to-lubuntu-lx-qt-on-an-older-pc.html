How to Switch to Lubuntu LXQt on an Older PC

This article provides a straightforward guide on switching your existing operating system or desktop environment to Lubuntu's lightweight LXQt desktop on an older computer. You will learn the minimal system requirements, the steps to perform a fresh installation from a USB drive, and how to install LXQt directly onto an existing Ubuntu installation to significantly improve performance on aging hardware.

System Requirements for Lubuntu LXQt

Before starting, ensure your older computer meets the basic requirements for modern Lubuntu (LXQt):

  • Processor: 64-bit Pentium 4, Intel Core, or modern AMD processor.
  • RAM: At least 1 GB (2 GB or more is recommended for smooth web browsing).
  • Storage: At least 10 GB of available hard drive space.

Method 1: Fresh Installation (Recommended)

A clean installation is the best way to maximize performance and eliminate background bloatware on older hardware.

  1. Download the ISO: Visit the official Lubuntu website and download the latest Long Term Support (LTS) ISO image.
  2. Create a Bootable USB: Use software such as BalenaEtcher or Rufus to write the downloaded ISO file to a USB drive (at least 4 GB in size).
  3. Boot from USB: Insert the USB into the target computer, restart, and enter the boot menu (usually by pressing F12, F8, F11, or Del during startup). Select the USB drive to boot.
  4. Test the Live Environment: Lubuntu will boot into a live desktop session, allowing you to test Wi-Fi, audio, and display settings without modifying your disk.
  5. Run the Installer: Double-click the "Install Lubuntu" icon on the desktop. Follow the on-screen prompts via the Calamares installer:
    • Select your language, location, and keyboard layout.
    • Under partitioning, select "Erase disk" for a dedicated install, or choose manual partitioning to dual-boot.
    • Create your user account and password.
  6. Complete Installation: Click "Install." Once the process finishes, remove the USB drive and reboot the computer into your new Lubuntu LXQt system.

Method 2: Install LXQt on an Existing Ubuntu Setup

If you already run a standard Ubuntu system and simply want to replace the heavy GNOME desktop with LXQt without reformatting, you can install the metapackage directly.

  1. Open the Terminal: Press Ctrl + Alt + T.
  2. Update Package Lists: 
    sudo apt update && sudo apt upgrade -y
  3. Install the Lubuntu Desktop: Run the following command to install the full Lubuntu desktop suite: 
    sudo apt install lubuntu-desktop
    (Alternatively, to install only the minimal LXQt desktop without Lubuntu's default applications, run sudo apt install lxqt instead).
  4. Configure the Display Manager: During installation, a prompt will ask to choose a default display manager. Select sddm (the default for LXQt) using the arrow keys and press Enter.
  5. Reboot the System: 
    sudo reboot
  6. Select the LXQt Session: At the login screen, click the session dropdown menu (gear or profile icon) and select "Lubuntu" or "LXQt Desktop" before entering your password.

Post-Installation Tweaks for Performance

To extract maximum performance from an older machine running LXQt:

  • Disable Window Effects: Navigate to Preferences > LXQt settings > Window Manager, and switch off unnecessary compositor effects.
  • Manage Autostart Applications: Go to Preferences > LXQt settings > Session Settings > Autostart and uncheck services you do not use to free up memory at boot.
  • Use Lightweight Applications: Stick to the preinstalled lightweight utilities like PCManFM-Qt (file manager), QTerminal, and FeatherPad to keep RAM usage minimal.
