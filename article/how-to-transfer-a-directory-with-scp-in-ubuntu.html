How to Transfer a Directory with SCP in Ubuntu

This guide covers how to securely transfer an entire directory tree between systems using the Secure Copy Protocol (scp) on Ubuntu. You will learn the exact command syntax needed to recursively copy folders, whether transferring data from your local machine to a remote server or pulling directories down from a remote host.

The Recursive SCP Command

To securely copy an entire directory tree using scp, use the -r (recursive) flag. This flag tells scp to traverse all subdirectories and copy their contents sequentially over an encrypted SSH connection.

1. Copy a Local Directory to a Remote Server

To upload a directory from your local Ubuntu machine to a remote machine, run:

scp -r /path/to/local/directory username@remote_host:/path/to/destination/
  • Replace /path/to/local/directory with the absolute or relative path to the folder you want to transfer.
  • Replace username with the SSH user account on the remote system.
  • Replace remote_host with the remote server's IP address or domain name.
  • Replace /path/to/destination/ with the folder where the directory should be placed.

2. Copy a Remote Directory to a Local Machine

To download an entire directory tree from a remote server to your local Ubuntu system, invert the source and destination paths:

scp -r username@remote_host:/path/to/remote/directory /path/to/local/destination/

Recommended Flags for Directory Transfers

You can combine -r with other useful options to optimize the transfer:

  • Preserve File Attributes (-p): Preserves original modification times, access times, and permission modes: 
    scp -rp /path/to/local/directory username@remote_host:/path/to/destination/
  • Custom SSH Port (-P): If your SSH server uses a non-standard port (such as 2222), use an uppercase -P: 
    scp -P 2222 -r /path/to/local/directory username@remote_host:/path/to/destination/
  • Enable Compression (-C): Compresses data during transit to speed up transfers over slower networks: 
    scp -rC /path/to/local/directory username@remote_host:/path/to/destination/
