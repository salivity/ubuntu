Configure BPF Rules to Drop Traffic in Ubuntu

This guide demonstrates how to configure extended Berkeley Packet Filter (eBPF) rules via the eXpress Data Path (XDP) to drop unwanted network traffic efficiently on Ubuntu. By processing and dropping packets at the network driver level before the Linux kernel allocates socket buffers (sk_buff), eBPF/XDP provides ultra-high performance filtering suitable for DDoS mitigation and high-throughput environments.

1. Install Dependencies

To write, compile, and attach eBPF programs, install the required toolchain and development libraries on your Ubuntu system:

sudo apt update
sudo apt install -y clang llvm libbpf-dev gcc-multilib build-essential linux-headers-$(uname -r) iproute2

2. Write the eBPF Packet Filter

Create a C file named xdp_drop.c. This program inspects incoming IPv4 packets and immediately returns XDP_DROP if the traffic matches a defined source IP, bypassing the network stack entirely.

#include <linux/bpf.h>
#include <linux/if_ether.h>
#include <linux/ip.h>
#include <linux/in.h>
#include <bpf/bpf_helpers.h>
#include <bpf/bpf_endian.h>

// Define the IP to block in hex format (e.g., 192.0.2.1 = 0xC0000201)
#define BLOCKED_IP 0xC0000201

SEC("xdp")
int filter_drop(struct xdp_md *ctx) {
    void *data_end = (void *)(long)ctx->data_end;
    void *data = (void *)(long)ctx->data;

    // Check Ethernet header boundaries
    struct ethhdr *eth = data;
    if ((void *)(eth + 1) > data_end)
        return XDP_PASS;

    // Only inspect IPv4 traffic
    if (eth->h_proto != bpf_htons(ETH_P_IP))
        return XDP_PASS;

    // Check IP header boundaries
    struct iphdr *ip = data + sizeof(*eth);
    if ((void *)(ip + 1) > data_end)
        return XDP_PASS;

    // Drop traffic matching the target IP
    if (bpf_ntohl(ip->saddr) == BLOCKED_IP) {
        return XDP_DROP;
    }

    return XDP_PASS;
}

char _license[] SEC("license") = "GPL";

3. Compile the eBPF Program

Compile the code into BPF bytecode using clang:

clang -O2 -target bpf -c xdp_drop.c -o xdp_drop.o

4. Attach the Filter to a Network Interface

Identify your active network interface:

ip link show

Attach the compiled program to the interface (replace eth0 with your actual interface name).

For native driver support (highest performance):

sudo ip link set dev eth0 xdp obj xdp_drop.o sec xdp

If your network card driver does not support native XDP, load it in generic mode:

sudo ip link set dev eth0 xdpgeneric obj xdp_drop.o sec xdp

5. Verify and Test

Verify that the program is attached to the interface:

ip link show dev eth0

The output will include xdp or xdpgeneric along with the program ID. Traffic matching the defined condition will now be discarded with minimal CPU usage.

6. Detach the Filter

To remove the filter and resume normal packet processing, run:

sudo ip link set dev eth0 xdp off

Or, if attached in generic mode:

sudo ip link set dev eth0 xdpgeneric off
