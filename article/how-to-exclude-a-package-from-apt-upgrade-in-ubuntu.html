How to Exclude a Package from Apt Upgrade in Ubuntu

Excluding a specific package from standard APT upgrades in Ubuntu prevents automatic updates from changing or breaking software configurations that require a fixed version. This guide outlines the most effective methods to lock a package version using built-in command-line tools like apt-mark, APT pinning preferences, and dpkg, ensuring your system updates around the specified software without modifying it.

Method 1: Using apt-mark (Recommended)

The simplest and most common way to block a package from being updated is using the apt-mark command. This places the package on “hold.”

Step 1: Hold the Package

Run the following command, replacing <package-name> with the actual name of the package you wish to exclude:

sudo apt-mark hold <package-name>

Step 2: Verify the Hold

To confirm that the package has been successfully placed on hold, list all held packages:

apt-mark showhold

How to Unhold the Package Later

If you decide to allow updates for the package again in the future, remove the hold status with:

sudo apt-mark unhold <package-name>

Method 2: Using APT Pinning

APT pinning offers more granular control by using configuration files. You can set the priority of a specific package to a negative value, which prevents APT from installing updates for it.

Step 1: Create a Preferences File

Create a new configuration file inside the /etc/apt/preferences.d/ directory:

sudo nano /etc/apt/preferences.d/block-<package-name>

Step 2: Add the Pin Rules

Paste the following lines into the file, replacing <package-name> with your package:

Package: <package-name>
Pin: release *
Pin-Priority: -1

Save and exit the file (press Ctrl+O, Enter, then Ctrl+X in nano).

Method 3: Using dpkg

You can also use the underlying Debian package management system (dpkg) to set a package state to hold.

Step 1: Set Package to Hold

echo "<package-name> hold" | sudo dpkg --set-selections

Step 2: Verify the Status

Check the status of the package using dpkg:

dpkg --get-selections | grep <package-name>

Step 3: Remove the Hold

To allow updates again via dpkg:

echo "<package-name> install" | sudo dpkg --set-selections
