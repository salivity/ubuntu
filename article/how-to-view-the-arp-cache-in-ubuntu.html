How to View the ARP Cache in Ubuntu

This article explains how to inspect the Address Resolution Protocol (ARP) cache on an Ubuntu Linux system. You will learn the primary modern command used for checking mapped IP and MAC addresses, as well as the legacy alternative, helping you quickly troubleshoot network connectivity issues.

Using the ip neighbor Command

The modern, standard utility for viewing the ARP cache in current Ubuntu releases is the ip command suite.

To view the ARP table, open your terminal and run:

ip neighbor

You can also use the shorter shorthand version:

ip neigh

Understanding the Output

The command lists all known network neighbors along with their hardware addresses and connection statuses. A typical line of output looks like this:

192.168.1.1 dev enp3s0 lladdr 00:11:22:33:44:55 REACHABLE

  • 192.168.1.1: The IPv4 address of the neighboring network device.
  • dev enp3s0: The local network interface handling the connection.
  • lladdr 00:11:22:33:44:55: The Link Layer Address (MAC address) mapped to the IP.
  • REACHABLE: The entry state (REACHABLE means valid, STALE means the entry needs re-validation, FAILED means resolution failed).

Using the Legacy arp Command

The classic arp tool is another option for viewing ARP table details, though it is considered deprecated in modern Linux distributions.

To display the ARP table using this method, run:

arp -n

The -n flag displays numerical IP addresses instead of attempting to resolve hostnames, speeding up the output.

Installing net-tools

If the arp command is missing from your system, install the net-tools package:

sudo apt update
sudo apt install net-tools

Clearing the ARP Cache

If you need to remove outdated or corrupt entries from the ARP cache, use the flush option:

sudo ip neighbor flush all
