What Is xdg-user-dirs-update in Ubuntu?

The xdg-user-dirs-update command is a core utility in Ubuntu and other Linux distributions that automatically creates, manages, and updates standard user directories—such as Desktop, Downloads, Documents, and Music—within a user's home profile. By aligning with the XDG (Cross-Desktop Group/freedesktop.org) standards, this tool ensures that applications have a consistent, localized way to find and store user-specific media and files upon system login or locale changes.

Core Functions of xdg-user-dirs-update

The primary task of xdg-user-dirs-update is to enforce a standard directory structure inside the ~/ (home) directory. It performs three main tasks:

  1. Directory Creation: If missing, it creates standard folders like Desktop, Downloads, Templates, Public, Documents, Music, Pictures, and Videos.
  2. Localization: It translates folder names according to the user's system language settings (for example, renaming Desktop to Bureau in French).
  3. Configuration Tracking: It writes and maintains location mappings in the ~/.config/user-dirs.dirs file.

How It Operates in User Profiles

When a user logs into Ubuntu, desktop environments (such as GNOME) execute xdg-user-dirs-update automatically during startup via autostart services.

  1. Reads Configuration Defaults: The tool first checks /etc/xdg/user-dirs.defaults to determine default folder names for the system.
  2. Checks Current Locale: It compares the current locale against ~/.config/user-dirs.locale to detect language changes.
  3. Updates Paths: If the language has changed, it updates the directory names and rewrites ~/.config/user-dirs.dirs to point applications to the correct localized paths.

Common Command Usage and Customization

Users and administrators can run xdg-user-dirs-update manually from the terminal to modify user directories or force updates.

Changing a Directory Location

To change the path of a specific default directory, use the --set flag:

xdg-user-dirs-update --set DOWNLOADS ~/MyDownloads

Forcing a Re-evaluation

If system language settings change, running the command manually forces the system to recreate or translate default directories:

xdg-user-dirs-update --force

The Mappings File (user-dirs.dirs)

The result of the command is saved in ~/.config/user-dirs.dirs. Linux applications query this file (or use the XDG library) to automatically open the correct folder when saving files or displaying shortcuts in file managers like Nautilus.

Example content of ~/.config/user-dirs.dirs:

XDG_DESKTOP_DIR="$HOME/Desktop"
XDG_DOWNLOAD_DIR="$HOME/Downloads"
XDG_TEMPLATES_DIR="$HOME/Templates"
XDG_PUBLICSHARE_DIR="$HOME/Public"
XDG_DOCUMENTS_DIR="$HOME/Documents"
XDG_MUSIC_DIR="$HOME/Music"
XDG_PICTURES_DIR="$HOME/Pictures"
XDG_VIDEOS_DIR="$HOME/Videos"

If you disable or remove this tool, applications may revert to dumping files directly into the root of your home folder (~/) or fail to locate proper media folders.
