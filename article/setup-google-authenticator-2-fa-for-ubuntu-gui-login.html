Setup Google Authenticator 2FA for Ubuntu GUI Login

This guide explains how to secure the Ubuntu graphical desktop login screen using two-factor authentication (2FA) via the pam_google_authenticator module. By integrating Time-based One-Time Passwords (TOTP) into the GNOME Display Manager (GDM), you add a critical layer of defense that requires both your standard account password and a verification code from an authenticator app to log in.

Step 1: Install the Google Authenticator PAM Module

Open your terminal and install the PAM Google Authenticator package from the official Ubuntu repositories:

sudo apt update
sudo apt install libpam-google-authenticator -y

Step 2: Generate the 2FA Secret Key

Each user who logs in through the graphical interface must generate a unique secret key. Run the configuration tool in the terminal as the user you wish to configure:

google-authenticator

During the interactive setup:

  1. Make tokens time-based: Press y.
  2. Scan the QR code: A large QR code will appear in the terminal. Open your preferred authenticator app (Google Authenticator, Aegis, Authy, etc.) and scan it. Save the emergency scratch codes printed below the QR code in a safe location.
  3. Update the user configuration file: Press y to write the .google_authenticator file to your home directory.
  4. Disallow multiple uses of the same token: Press y to prevent replay attacks.
  5. Permit window skew: Press n for standard security (allowing only the immediate 30-second window) or y if you experience clock synchronization issues.
  6. Enable rate-limiting: Press y to restrict login attempts to 3 every 30 seconds.

Step 3: Configure GDM to Require 2FA

Ubuntu uses the GNOME Display Manager (GDM) by default. The PAM configuration for graphical password authentication is located in /etc/pam.d/gdm-password.

Before modifying this file, open an alternative terminal (such as a TTY via Ctrl + Alt + F3 or an SSH session) to maintain root access in case of a syntax error.

Open the PAM configuration file in a text editor with administrative privileges:

sudo nano /etc/pam.d/gdm-password

Locate the following line (typically near the top of the auth section):

auth    substack    password-auth

or

@include common-auth

Immediately below the @include common-auth line, add:

auth required pam_google_authenticator.so nullok

Note: The nullok argument permits users who have not yet run the google-authenticator command to log in using only their password. Once you have generated keys for all necessary users, remove nullok to strictly enforce 2FA for every account.

Save the file and exit the editor (Ctrl + O, Enter, then Ctrl + X in nano).

Step 4: Test the Configuration

Lock your screen or log out of your current session:

gnome-screensaver-command -l

(Or choose Log Out from the system menu.)

At the login screen:

  1. Select your username.
  2. Enter your standard Ubuntu account password and press Enter.
  3. A second prompt will appear asking for your Verification code.
  4. Enter the current 6-digit code displayed in your authenticator app and press Enter.

If the credentials are valid, the Ubuntu desktop will load normally.
