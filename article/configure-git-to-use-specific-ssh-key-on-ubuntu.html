Configure Git to Use Specific SSH Key on Ubuntu

Managing multiple Git accounts on an Ubuntu system often requires associating a specific SSH key with a particular repository rather than relying on a global default. This guide provides direct, step-by-step methods to configure Git to use a dedicated SSH key for a repository using the core.sshCommand configuration, the SSH config file, or temporary environment variables.

Step 1: Set Proper Permissions for Your SSH Key

Before configuring Git, ensure your private SSH key has the correct read and write permissions. Open your terminal in Ubuntu and run:

chmod 600 ~/.ssh/your_specific_key

Replace your_specific_key with the actual filename of your private key.

Method 1: Using core.sshCommand (Recommended per Repository)

Git (version 2.10 and newer) allows you to define custom SSH commands on a per-repository basis. This is the simplest and cleanest approach because it does not affect any other repositories or global settings.

  1. Navigate to your local Git repository:

    cd /path/to/your/repository

  2. Run the following command to associate your specific private key:

    git config core.sshCommand "ssh -i ~/.ssh/your_specific_key -F /dev/null"
    • The -i flag specifies the path to your key.
    • The -F /dev/null flag ensures standard configuration files are ignored to avoid conflicts.

  3. Verify the setting:

    git config core.sshCommand

All subsequent Git operations (git pull, git push, git fetch) in this repository will use the designated SSH key.

Method 2: Using the SSH Config File

You can also assign keys based on custom host aliases defined in your user's SSH configuration file.

  1. Open or create the SSH config file:

    nano ~/.ssh/config

  2. Add a host alias entry pointing to your key:

    Host github-custom
    HostName github.com
    User git
    IdentityFile ~/.ssh/your_specific_key
    IdentitiesOnly yes

  3. Save and close the file (Ctrl + O, Enter, Ctrl + X).

  4. Update your repository's remote URL to use the new alias:

    cd /path/to/your/repository
git remote set-url origin git@github-custom:username/repository.git

Replace github.com and username/repository.git with your actual Git host and repository path.

Method 3: Using the GIT_SSH_COMMAND Environment Variable

If you only need to run a one-off command (such as an initial clone) with a specific key, set the GIT_SSH_COMMAND environment variable inline:

GIT_SSH_COMMAND="ssh -i ~/.ssh/your_specific_key" git clone git@github.com:username/repository.git

This applies the specific SSH key exclusively to that single execution.
