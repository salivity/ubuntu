How to Set Up Custom Shell Aliases in Ubuntu

Setting up custom shell aliases in Ubuntu allows you to create short keyboard shortcuts for long or complex command-line instructions. By defining these shortcuts in your shell configuration files, you can significantly reduce typing time, minimize typos, and automate repetitive system administration tasks directly from the terminal.

How Shell Aliases Work

A shell alias maps a custom keyword to a full terminal command. When you type the keyword, the shell expands it into the original command sequence before execution.

While you can set temporary aliases during an active terminal session using the syntax alias shortcut='command', these disappear once you close the window. To make aliases permanent, you must save them in your user profile configuration file.

Step 1: Open the Alias Configuration File

Ubuntu uses the Bash shell by default. While you can add aliases directly to the ~/.bashrc file, the recommended practice is to store them in a separate ~/.bash_aliases file to keep your configuration organized.

Open the file in a terminal text editor such as Nano:

nano ~/.bash_aliases

If the file does not exist yet, this command will create it automatically.

Step 2: Define Your Custom Aliases

Add your aliases using the following syntax:

alias alias_name='actual_command_here'
  • Ensure there are no spaces around the = sign.
  • Enclose the command in single quotes ('...').

Examples of Practical Aliases

# System updates
alias update='sudo apt update && sudo apt upgrade -y'

# Navigation shortcuts
alias ..='cd ..'
alias ...='cd ../..'

# Enhanced file listing
alias ll='ls -la'

# Quick system clean up
alias clean='sudo apt autoremove -y && sudo apt autoclean'

Once you have added your desired aliases, save the file in Nano by pressing Ctrl + O, hitting Enter, and then exiting with Ctrl + X.

Step 3: Apply the Changes

Changes made to ~/.bash_aliases will not take effect automatically in your current terminal session. To apply them immediately, reload your shell configuration file with the source command:

source ~/.bashrc

Alternatively, you can close and reopen the terminal window.

Testing and Removing Aliases

To verify that an alias is working, type its shortcut name in the terminal and press Enter. You can check the exact command assigned to an alias using the type command:

type alias_name

To temporarily remove an alias during your current session, use unalias:

unalias alias_name

To permanently delete an alias, open ~/.bash_aliases, remove the corresponding line, save the file, and run source ~/.bashrc.
