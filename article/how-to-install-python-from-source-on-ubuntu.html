How to Install Python from Source on Ubuntu

Compiling Python from source on Ubuntu allows developers to run specific release versions, customize build flags, and access the latest features without waiting for default package updates. This guide outlines the complete process for preparing your system, fetching the source code, configuring build parameters, and safely installing Python using altinstall so you do not break standard system utilities.

Step 1: Install Required Dependencies

Compiling Python requires native C compilers and various development libraries to enable core modules such as SSL, SQLite, and compression support.

Update your package index and install the required build tools:

sudo apt update
sudo apt install -y build-essential zlib1g-dev libncurses5-dev libgdbm-dev \
libnss3-dev libssl-dev libreadline-dev libffi-dev libsqlite3-dev wget libbz2-dev \
liblzma-dev tk-dev

Step 2: Download the Python Source Code

Navigate to the /tmp directory and download the source tarball for the desired Python version. For demonstration, we will use Python 3.12.4:

cd /tmp
wget https://www.python.org/ftp/python/3.12.4/Python-3.12.4.tgz

Extract the downloaded archive and enter the extracted directory:

tar -xf Python-3.12.4.tgz
cd Python-3.12.4

Step 3: Configure the Build Environment

Run the configure script to evaluate your system's environment and prepare the compilation process. Using the --enable-optimizations flag runs profile-guided optimizations (PGO) to make Python run faster, though it extends build time.

./configure --enable-optimizations

To install Python into a custom directory path instead of /usr/local, add the --prefix flag (for example: ./configure --enable-optimizations --prefix=/opt/python3.12).

Step 4: Compile the Source Code

Build the binaries using the make tool. You can speed up the compilation process by utilizing all available CPU cores using the nproc command:

make -j $(nproc)

Step 5: Install Python Using Altinstall

To prevent overwriting the default Ubuntu system Python binary—which can break system administration tools like apt—install the custom build using altinstall:

sudo make altinstall

This ensures the executable is installed as python3.12 rather than python3 or python.

Step 6: Verify the Installation

Confirm that the custom version of Python and its matching package manager (pip) are correctly installed and accessible:

python3.12 --version
pip3.12 --version

If the terminal returns the expected version number, your custom Python build is ready for use.
