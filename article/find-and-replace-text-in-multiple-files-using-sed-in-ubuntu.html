Find and Replace Text in Multiple Files Using Sed in Ubuntu

Finding and replacing text across multiple files is a routine task for developers and system administrators working in Ubuntu. The sed (stream editor) command, combined with the find command, provides a fast and efficient way to perform bulk text replacements from the terminal. This article covers the standard command syntax for finding and replacing text across multiple files, explains how each parameter works, and provides practical examples for common use cases.

The Basic Command

To find and replace text in multiple files within a directory and its subdirectories, combine find with sed:

find . -type f -exec sed -i 's/old_text/new_text/g' {} +

Command Breakdown

  • find .: Starts searching in the current directory (.). You can replace . with a specific folder path (e.g., /var/www/html).
  • -type f: Restricts the search strictly to regular files, excluding directories.
  • -exec ... {} +: Runs the following command (sed) on all found files simultaneously.
  • sed -i: Tells sed to edit files in-place (overwriting the original files directly).
  • 's/old_text/new_text/g':
    • s stands for substitute.
    • old_text is the string you want to find.
    • new_text is the string you want to insert.
    • g stands for global, meaning it replaces all occurrences in a line, not just the first one.

Practical Examples

1. Replace Text in Specific File Types Only

To target specific file extensions (such as .txt or .html files), use the -name option:

find . -type f -name "*.txt" -exec sed -i 's/http:/https:/g' {} +

2. Case-Insensitive Search and Replace

To match text regardless of uppercase or lowercase letters, add the I flag to the sed expression:

find . -type f -exec sed -i 's/error/warning/gI' {} +

3. Replace Text in Current Directory Only (No Subdirectories)

If you do not need to search through subfolders, you can use sed directly with a shell wildcard:

sed -i 's/old_text/new_text/g' *.conf

4. Create Backups Before Modifying

To safely edit files by saving a original copy with a .bak extension before overwriting:

find . -type f -name "*.txt" -exec sed -i.bak 's/old_text/new_text/g' {} +

Safety Tip: Preview Changes First

Running sed -i permanently modifies your files. To preview the replacements before applying them, omit the -i flag and run:

find . -type f -exec sed -n 's/old_text/new_text/p' {} +

This prints only the modified lines to your terminal screen without changing the actual files.
