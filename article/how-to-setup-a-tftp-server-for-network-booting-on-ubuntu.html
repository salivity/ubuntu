How to Setup a TFTP Server for Network Booting on Ubuntu

Setting up a Trivial File Transfer Protocol (TFTP) server on Ubuntu is an essential step for enabling Preboot Execution Environment (PXE) network booting across a local network. This guide provides a straightforward tutorial on installing the tftpd-hpa package, configuring the server settings, assigning proper directory permissions, and testing the TFTP service to ensure your network clients can successfully fetch bootloader files.

Step 1: Update Packages and Install TFTP Server

Open a terminal and update your system package list, then install the tftpd-hpa server daemon and the tftp-hpa client tool for testing:

sudo apt update
sudo apt install tftpd-hpa tftp-hpa -y

Step 2: Configure the TFTP Daemon

The configuration file for tftpd-hpa is located at /etc/default/tftpd-hpa. Open this file using a text editor:

sudo nano /etc/default/tftpd-hpa

Update the configuration settings as follows:

TFTP_USERNAME="tftp"
TFTP_DIRECTORY="/var/lib/tftpboot"
TFTP_ADDRESS=":69"
TFTP_OPTIONS="--secure"
  • TFTP_DIRECTORY: Defines the root path where boot files and images are stored.
  • TFTP_OPTIONS="--secure": Restricts file access exclusively to the defined TFTP directory path.

Save and close the file.

Step 3: Create the Storage Directory and Set Permissions

Create the designated TFTP root directory and assign ownership to the tftp user along with suitable permissions:

sudo mkdir -p /var/lib/tftpboot
sudo chown -R tftp:tftp /var/lib/tftpboot
sudo chmod -R 777 /var/lib/tftpboot

Step 4: Restart and Enable the Service

Restart the TFTP service to apply the configuration changes and set it to launch automatically on system boot:

sudo systemctl restart tftpd-hpa
sudo systemctl enable tftpd-hpa

Verify that the service is active and running:

sudo systemctl status tftpd-hpa

Step 5: Configure Firewall Rules

If Uncomplicated Firewall (UFW) is running on your server, allow incoming UDP traffic on port 69:

sudo ufw allow 69/udp

Step 6: Test the TFTP Server Setup

To verify that the TFTP server is working correctly, create a test file inside your TFTP directory:

echo "TFTP Server Functional" | sudo tee /var/lib/tftpboot/test.txt

Connect to the TFTP server locally using the client tool to download the file:

cd ~
tftp 127.0.0.1
tftp> get test.txt
tftp> quit

Check the downloaded file content to confirm successful transfer:

cat test.txt

If the terminal displays "TFTP Server Functional", your TFTP server is ready to host PXE boot files, kernel images, and system network installers.
