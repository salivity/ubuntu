Manage Flathub App Permissions Using Flatseal on Ubuntu

Flatpak applications from Flathub run inside isolated sandboxes to enhance system security, but their default access rights can sometimes be overly broad or too restrictive for your daily workflow. Flatseal is a dedicated graphical utility that allows Ubuntu desktop users to view, grant, and revoke permissions for any installed Flatpak application without using terminal commands. This guide explains how to install Flatseal on Ubuntu, navigate its permission categories, and safely adjust access controls for your apps.

Installing Flatseal on Ubuntu

Flatseal itself is distributed as a Flatpak, making installation straightforward via the terminal.

  1. Ensure the Flatpak framework and Flathub repository are enabled on your Ubuntu system: 
    sudo apt update
sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  2. Install Flatseal using the following command: 
    flatpak install flathub com.github.tchx84.Flatseal
  3. Once the installation is complete, launch Flatseal from Ubuntu's Application Grid or by running flatpak run com.github.tchx84.Flatseal.

Navigating the Flatseal Interface

Flatseal features a two-panel interface:

  • Left Panel: Displays all installed Flatpak applications. It also features an All Applications entry at the top, which allows you to define global permission baselines across all Flatpaks.
  • Right Panel: Displays all available permission toggles for the application selected on the left, organized logically into distinct categories.

Modifying Common Permissions

To alter an application's behavior, select the app from the left-hand column and scroll through the right-hand panel to toggle specific permissions on or off.

1. Filesystem Access

Filesystem controls determine what parts of your local storage an app can read and write to:

  • All system files: Grants broad access to the entire root directory (rarely recommended).
  • All user files: Grants access to the entire /home/user folder.
  • Other files: Allows you to specify explicit directory paths (for example, /mnt/data or ~/Projects) by clicking the + (Add) icon.

2. Network Access

  • Network: Toggling this switch off completely cuts off an application's ability to communicate over local networks or the internet. This is useful for offline utilities or media players that do not require online connectivity.

3. Hardware and Devices

  • Device access: Controls access to system devices such as webcams, controllers, and input hardware under /dev.
  • GPU acceleration: Enables or disables direct hardware rendering, useful for troubleshooting graphical glitches in games or rendering tools.

4. Audio and Display

  • Sound: Under the Audio section, toggle access to the PulseAudio/PipeWire sound server to enable or disable audio playback and recording.
  • Windowing System: Under the Display section, you can manage whether an app uses the X11 windowing system, Wayland, or fallback compatibility modes.

Reverting Changes

If adjusting permissions causes an application to crash or behave unexpectedly, Flatseal allows you to restore default settings instantly. Select the affected application and click the Reset button located in the top-right corner of the application window. This action returns all permissions for that specific application to its package defaults.
