How to Verify SHA256 Checksum in Ubuntu

Verifying the integrity of a downloaded file ensures that the data has not been corrupted during transmission or altered by a malicious third party. This guide demonstrates how to calculate the SHA-256 hash of a file using Ubuntu's built-in command-line tools and how to compare the result against the vendor's published hash, both manually and automatically.

Step 1: Open the Terminal and Locate the File

Open your terminal by pressing Ctrl + Alt + T. Use the cd command to navigate to the directory containing your downloaded file. For example, if the file is in your Downloads folder:

cd ~/Downloads

Step 2: Generate the SHA256 Checksum

Ubuntu includes the sha256sum utility by default as part of the core utilities. Run the command followed by the exact filename:

sha256sum filename.iso

Replace filename.iso with the name of your file. The terminal will output a 64-character alphanumeric string followed by the filename:

e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855  filename.iso

Step 3: Compare Against the Published Hash

You can verify the generated hash in two ways:

Method A: Manual Comparison

Compare the generated 64-character string visually with the SHA256 hash provided on the download website. Both strings must match character for character.

Method B: Automated Verification (Recommended)

To eliminate human error, you can instruct sha256sum to check the hash automatically using the --check (or -c) flag.

Run the following command, replacing <PUBLISHED_HASH> with the actual published hash and filename.iso with your file's name (ensure there are two spaces between the hash and the filename):

echo "<PUBLISHED_HASH>  filename.iso" | sha256sum --check

If the file is intact, the terminal will return:

filename.iso: OK

If the hash does not match, it will display:

filename.iso: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match

Verifying with a Provided Checksum File

If the software distributor provides a checksum file (such as SHA256SUMS or checksum.txt), download it into the same directory as the target file and run:

sha256sum -c SHA256SUMS

The tool will read the listed hashes and automatically confirm whether the matching files in the directory pass verification.
