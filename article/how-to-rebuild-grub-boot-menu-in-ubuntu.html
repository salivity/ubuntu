How to Rebuild GRUB Boot Menu in Ubuntu

When you modify the GRUB bootloader configuration file located at /etc/default/grub, changes do not take effect automatically. You must regenerate the main grub.cfg file so that your system applies your new boot settings on the next restart. This guide explains the primary command used to update the GRUB configuration in Ubuntu, how the process works under the hood, and how to verify that your changes took effect properly.

The Primary Command

To rebuild the GRUB boot menu in Ubuntu, open your terminal and run the following command:

sudo update-grub

This command runs with administrative privileges and reads the settings defined in /etc/default/grub along with the helper scripts inside the /etc/grub.d/ directory. It then automatically compiles and overwrites the main configuration file located at /boot/grub/grub.cfg.

The Underlying Alternative

The update-grub command is essentially a Ubuntu-specific wrapper script. If you are working in an environment where update-grub is unavailable or if you prefer to use the standard GNU GRUB utility, execute:

sudo grub-mkconfig -o /boot/grub/grub.cfg

Both commands yield the exact same result: they detect installed Linux kernels, other operating systems, and initramfs images, then update the boot loader configuration accordingly.

Expected Output and Verification

After running the update command, you will see output in the terminal detailing the detection of boot images and other installed systems:

Sourcing file `/etc/default/grub'
Generating grub configuration file ...
Found linux image: /boot/vmlinuz-...
Found initrd image: /boot/initrd.img-...
done

Once the terminal returns done without any syntax errors, your configuration has been successfully rebuilt. You can safely restart your system with sudo reboot to apply the updated boot parameters.
