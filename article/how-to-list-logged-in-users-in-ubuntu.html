How to List Logged-In Users in Ubuntu

Monitoring active user sessions is an essential task for managing system resources and maintaining security on Linux systems. This guide provides a quick overview of the standard terminal commands used to display all users currently logged into an Ubuntu system, including who, w, and users.

The Primary Command: who

The who command is the standard and most commonly used utility to list currently logged-in users. It displays the username, terminal line, login time, and remote host or IP address if applicable.

To run it, open your terminal and type:

who

Useful Options for who:

  • who -H: Includes column headings in the output for easier reading.
  • who -a: Displays detailed session information, including system boot time and run levels.

Detailed Activity Command: w

If you need more information beyond just who is logged in, the w command displays logged-in users alongside details about their current activities and system status.

Run the command:

w

The output includes:

  • Overall system uptime and load averages.
  • Username, TTY line, remote IP address, login time, idle time, and the active process being executed by each user.

Simple Name List Command: users

If you only need a quick list of active usernames without additional session details, use the users command:

users

This outputs a single line containing a space-separated list of usernames for all active sessions.

Systemd Alternative: loginctl

On modern Ubuntu systems running systemd, you can also list active user sessions using the system log manager:

loginctl list-sessions

This command shows session IDs, user IDs (UID), usernames, and the seat assigned to each active session.
