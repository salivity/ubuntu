How to Safely Reboot Ubuntu Using Magic SysRq Keys

When an Ubuntu system becomes completely unresponsive, performing a hard reset by holding down the power button can lead to data loss or filesystem corruption. The Linux kernel includes a built-in safety feature known as the Magic SysRq key combination, which communicates directly with the kernel regardless of the system state. By using the mnemonic sequence REISUB, you can safely close processes, write unsaved data to disk, unmount your drives, and cleanly restart your computer.

Step 1: Enable the Magic SysRq Feature

By default, Ubuntu enables only partial SysRq functionality for security reasons. To ensure full functionality during a system freeze, you must enable it in your system settings.

  1. Open your terminal and check the current SysRq status:

    cat /proc/sys/kernel/sysrq
    • If the output is 1, SysRq is fully enabled.
    • If the output is anything else (such as 176 or 438), full functionality is restricted.

  2. To enable all SysRq functions permanently, open the SysRq configuration file:

    sudo nano /etc/sysctl.d/10-magic-sysrq.conf

  3. Find or add the following line:

    kernel.sysrq = 1

  4. Save the file (Ctrl + O, then Enter) and exit (Ctrl + X).

  5. Apply the changes immediately without restarting:

    sudo sysctl -p /etc/sysctl.d/10-magic-sysrq.conf

Step 2: Perform the REISUB Safe Reboot Sequence

When your computer freezes, press and hold the Alt and Print Screen (SysRq) keys together. While holding these two keys down, slowly type the letters R - E - I - S - U - B, pausing for a few seconds between each keystroke.

Note on keyboard layout: On many keyboards, the Print Screen key serves as the SysRq key. On laptops, you may need to hold the Fn key as well (e.g., Alt + Fn + PrtScn).

The Meaning of the REISUB Sequence

Each letter in the sequence performs a specific, ordered action:

  • R (unRaw): Takes keyboard control away from the X Server/Wayland display server and returns it to the Linux kernel interface.
  • E (tErminate): Sends the SIGTERM signal to all running processes (except init), allowing applications to save state and terminate gracefully.
  • I (kIll): Sends the SIGKILL signal to any remaining processes that failed to terminate after the SIGTERM signal.
  • S (Sync): Flushes all unsaved data from RAM caches onto the hard drive to prevent data loss. (Wait 2–5 seconds after pressing this key to ensure the drives finish writing).
  • U (Umount): Remounts all connected filesystems as read-only. This prevents disk errors and filesystem checks upon rebooting.
  • B (reBoot): Immediately reboots the system safely.

Recommended Timing Between Keys

Do not type the sequence rapidly. Give the kernel time to execute each step:

  1. Hold Alt + SysRq.
  2. Press R, wait 2 seconds.
  3. Press E, wait 2 seconds.
  4. Press I, wait 2 seconds.
  5. Press S, wait 5 seconds (allows disk synchronization to complete).
  6. Press U, wait 3 seconds (allows filesystems to remount as read-only).
  7. Press B. Your system will restart immediately.
