Convert VMDK to QCOW2 with qemu-img on Ubuntu

This article explores the purpose and practical usage of the qemu-img command-line utility on Ubuntu, focusing on converting virtual machine disk images from VMware's VMDK format to KVM's native QCOW2 format. Readers will learn why format conversion is essential for virtualization migration, the architectural advantages of QCOW2 over other formats, and the exact commands required to execute conversions reliably and efficiently.

The Purpose of qemu-img

The qemu-img command is a versatile disk management utility provided by the QEMU package. Its primary purpose is offline virtual disk maintenance, including creating, converting, resizing, checking, and snapshotting disk images. When migrating virtual workloads from proprietary hypervisors like VMware vSphere or Workstation to open-source KVM-based platforms—such as Proxmox VE, OpenStack, or native Libvirt on Ubuntu—qemu-img serves as the core translation engine between incompatible disk formats.

Why Convert VMDK to QCOW2?

  • Native Hypervisor Support: While KVM and QEMU can read VMDK (Virtual Machine Disk) files, performance is degraded because the hypervisor must emulate compatibility layers. QCOW2 (QEMU Copy-On-Write) is the native format for KVM, offering optimal I/O throughput.
  • Storage Optimization: QCOW2 supports thin provisioning and optional compression, allocating physical disk space only as data is written. VMDK files, particularly pre-allocated or split variants, consume excessive disk space unless properly converted.
  • Advanced Features: QCOW2 natively supports copy-on-write snapshots, AES encryption, and backing files for base image reusability, features that are either restricted or incompatible when using VMDK on Linux-based hypervisors.

Installing qemu-img on Ubuntu

The utility is packaged within the qemu-utils package in standard Ubuntu repositories. Install it using the following commands:

sudo apt update
sudo apt install -y qemu-utils

Verify the installation:

qemu-img --version

Performing the Conversion

The syntax for converting an image using qemu-img uses the convert subcommand:

qemu-img convert -f vmdk -O qcow2 -p source_disk.vmdk target_disk.qcow2

Command breakdown:

  • -f vmdk: Specifies the input file format (format). While qemu-img can often autodetect the source format, declaring it explicitly avoids misdetection.
  • -O qcow2: Defines the target output format (Output).
  • -p: Displays a real-time progress bar, useful for tracking large virtual disks.
  • -c (optional): Adds zlib compression to the output file to minimize storage footprints (e.g., qemu-img convert -c -f vmdk -O qcow2 source.vmdk target.qcow2).

Post-Conversion Verification

After conversion completes, verify the integrity and characteristics of the newly generated QCOW2 file using the info command:

qemu-img info target_disk.qcow2

This output displays the virtual size, actual disk footprint, cluster size, and format specifications, ensuring the disk is ready to be attached to a KVM or Libvirt virtual machine.
