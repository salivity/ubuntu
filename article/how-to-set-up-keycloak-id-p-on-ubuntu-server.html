How to Set Up Keycloak IdP on Ubuntu Server

This guide provides a step-by-step walkthrough for deploying Keycloak as a standalone Identity Provider (IdP) on an Ubuntu server. It covers the installation of system prerequisites like Java and PostgreSQL, the initial configuration of the Keycloak Quarkus distribution, setting up a dedicated system service, and accessing the Keycloak administration console to begin managing identities, realms, and single sign-on (SSO) clients.

1. Update the System and Install Java

Keycloak requires a Java Virtual Machine to run. Install the OpenJDK 17 package along with essential utilities.

sudo apt update && sudo apt upgrade -y
sudo apt install openjdk-17-jdk wget curl unzip -y

Verify the installation:

java -version

2. Install and Configure PostgreSQL

While Keycloak includes an embedded database, a production Identity Provider requires a robust relational database such as PostgreSQL.

Install PostgreSQL:

sudo apt install postgresql postgresql-contrib -y

Access the PostgreSQL prompt to create a dedicated user and database for Keycloak:

sudo -u postgres psql

Execute the following SQL queries, replacing secure_password with a strong password:

CREATE DATABASE keycloak;
CREATE USER keycloak WITH ENCRYPTED PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE keycloak TO keycloak;
ALTER DATABASE keycloak OWNER TO keycloak;
\q

3. Create a Keycloak System User and Download Keycloak

For security, run Keycloak under a dedicated non-root user.

sudo useradd -r -m -d /opt/keycloak -s /bin/bash keycloak

Download the latest release archive of Keycloak (Quarkus distribution) and extract it to /opt/keycloak:

cd /tmp
wget https://github.com/keycloak/keycloak/releases/download/24.0.2/keycloak-24.0.2.tar.gz
sudo tar -xvzf keycloak-24.0.2.tar.gz -C /opt/keycloak --strip-components=1
sudo chown -R keycloak:keycloak /opt/keycloak
sudo chmod -R 700 /opt/keycloak

4. Configure Keycloak

Edit the Keycloak configuration file to connect it to the PostgreSQL database and specify hostname settings.

sudo nano /opt/keycloak/conf/keycloak.conf

Update or add the following directives:

# Database configuration
db=postgres
db-username=keycloak
db-password=secure_password
db-url=jdbc:postgresql://localhost:5432/keycloak

# HTTP and Hostname configuration
hostname=auth.example.com
http-enabled=true
http-port=8080

# Production proxy settings (e.g., behind NGINX or reverse proxy)
proxy=edge

Save and exit the file.

5. Build and Optimize Keycloak

Run the build step to apply database drivers and optimized configurations:

sudo -u keycloak /opt/keycloak/bin/kc.sh build

6. Set Up the Initial Administrator Account

Define the administrative credentials before starting the service:

export KEYCLOAK_ADMIN=admin
export KEYCLOAK_ADMIN_PASSWORD=AdminStrongPassword123
sudo -E -u keycloak /opt/keycloak/bin/kc.sh start --optimized

Press Ctrl+C to stop the foreground process once the administrator credentials have been initialized.

7. Create a Systemd Service

Create a systemd service file to manage the Keycloak background process:

sudo nano /etc/systemd/system/keycloak.service

Paste the following configuration:

[Unit]
Description=Keycloak Identity Provider
After=network.target postgresql.service

[Service]
Type=simple
User=keycloak
Group=keycloak
Restart=on-failure
RestartSec=5
WorkingDirectory=/opt/keycloak
ExecStart=/opt/keycloak/bin/kc.sh start --optimized

[Install]
WantedBy=multi-user.target

Reload systemd, enable the service to start at boot, and start Keycloak:

sudo systemctl daemon-reload
sudo systemctl enable --now keycloak

Check the status to ensure the service is running:

sudo systemctl status keycloak

8. Access the Administration Console

Keycloak is now running on port 8080 (or 8443 if using native TLS). Open a web browser and navigate to:

http://<your-server-ip>:8080 or https://auth.example.com

Log in using the administrator credentials created in Step 6. From the administration console, you can create realms, register OpenID Connect (OIDC) or SAML 2.0 clients, configure identity brokering, and manage users.
