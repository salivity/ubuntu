Setup OWASP Juice Shop Using Docker on Ubuntu

OWASP Juice Shop is an intentionally insecure web application widely used for cybersecurity training, penetration testing practice, and CTF challenges. Deploying it via Docker provides an isolated, disposable environment that keeps your host machine safe from vulnerabilities. This guide walks you through the step-by-step process of installing Docker on an Ubuntu system, pulling the official Juice Shop container image, and running the application locally.

Step 1: Install Docker on Ubuntu

Before running the Juice Shop container, ensure your Ubuntu package lists are updated and Docker is installed and running.

Open your terminal and run:

sudo apt update
sudo apt install -y docker.io

Enable and start the Docker service:

sudo systemctl enable --now docker

To run Docker commands without prepending sudo, add your current user to the docker group:

sudo usermod -aG docker $USER

Note: You may need to log out and log back in for the group membership change to take effect.

Step 2: Pull the OWASP Juice Shop Image

Download the official OWASP Juice Shop Docker image from Docker Hub using the following command:

docker pull bkimminich/juice-shop

Step 3: Run the Juice Shop Container

Start the container in detached mode and map the application port to your host machine:

docker run -d --name juice-shop -p 3000:3000 bkimminich/juice-shop
  • -d: Runs the container in the background (detached mode).
  • --name juice-shop: Assigns a readable name to the container.
  • -p 3000:3000: Forwards port 3000 on your host to port 3000 inside the container.

Step 4: Verify Container Status

Check that the container is actively running:

docker ps

The output should show bkimminich/juice-shop running with status Up and port 0.0.0.0:3000->3000/tcp.

Step 5: Access the Application

Open any web browser and navigate to:

http://localhost:3000

If you are running Ubuntu on a remote server or virtual machine, replace localhost with your machine's IP address (e.g., http://<your-server-ip>:3000).

Step 6: Managing the Instance

When you are finished with your session, you can manage the container using standard Docker commands:

  • Stop the container: docker stop juice-shop
  • Restart the container: docker start juice-shop
  • Remove the container: docker rm -f juice-shop
