Test Network Throughput with iperf on Ubuntu Containers

This guide explains how to measure raw network throughput between two Ubuntu containers using the iperf utility. Testing bandwidth between containers helps identify virtualization overhead, bridge misconfigurations, and baseline network limits. Below are the exact commands required to install the tool, configure the server container, and execute the throughput test from the client container.

Step 1: Install iperf on Both Containers

Access each Ubuntu container's shell and install iperf (or iperf3) using the apt package manager:

apt update && apt install -y iperf

(Note: If using iperf3, install it with apt install -y iperf3 and replace the subsequent commands with iperf3.)

Step 2: Determine the Server Container's IP Address

On the container designated as the receiver (server), run:

hostname -I

Note the internal IP address assigned to this container (for example, 172.17.0.2).

Step 3: Start iperf in Server Mode

Run the following command inside the server container to put it in listening mode:

iperf -s

The container will wait for incoming TCP connections on default port 5001.

Step 4: Run the Throughput Test from the Client Container

Switch to the second container (client) and run the client command pointing to the server's IP address:

iperf -c 172.17.0.2

Replace 172.17.0.2 with the actual IP address retrieved in Step 2.

Useful Command Variations

To stress-test the connection or adjust measurement parameters, append these options to the client command:

  • Run parallel streams to maximize throughput: 
    iperf -c 172.17.0.2 -P 4
  • Change the test duration (e.g., 30 seconds): 
    iperf -c 172.17.0.2 -t 30
  • Test UDP bandwidth instead of TCP: 
    iperf -c 172.17.0.2 -u -b 10G

Once the test completes, iperf outputs the transfer size and bandwidth measured in gigabits or megabits per second.
