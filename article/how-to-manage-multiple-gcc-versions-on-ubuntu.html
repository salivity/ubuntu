How to Manage Multiple GCC Versions on Ubuntu

Developers frequently need to compile software using different compiler toolchains to test compatibility, satisfy legacy project constraints, or use modern language features. This guide walks through adding the necessary package repositories, installing multiple versions of the GNU Compiler Collection (GCC and G++) on an Ubuntu machine, and using the update-alternatives system to effortlessly switch between them on demand.

Step 1: Update Repositories and Add the Toolchain PPA

Ubuntu repositories often provide multiple GCC versions, but adding the official Ubuntu Toolchain PPA ensures access to both older and newer versions.

Open a terminal and run:

sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository ppa:ubuntu-toolchain-r/test
sudo apt update

Step 2: Install the Desired GCC and G++ Versions

Install the specific versions you need. For example, to install GCC 11, GCC 12, and GCC 13 along with their corresponding C++ compilers:

sudo apt install gcc-11 g++-11 gcc-12 g++-12 gcc-13 g++-13

Step 3: Configure update-alternatives

Ubuntu uses update-alternatives to manage symbolic links for software that can have multiple versions installed. You must register each GCC and G++ pairing with a specified priority. Higher numbers indicate a higher default priority.

Register GCC 11:

sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-11 110 --slave /usr/bin/g++ g++ /usr/bin/g++-11

Register GCC 12:

sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-12 120 --slave /usr/bin/g++ g++ /usr/bin/g++-12

Register GCC 13:

sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-13 130 --slave /usr/bin/g++ g++ /usr/bin/g++-13

Using the --slave flag ensures that switching the gcc alternative automatically switches g++ to the matching version.

Step 4: Switch Between GCC Versions

To switch the active compiler version interactively, execute:

sudo update-alternatives --config gcc

The terminal will display a list of all configured versions:

  Selection    Path              Priority   Status
------------------------------------------------------------
* 0            /usr/bin/gcc-13   130       auto mode
  1            /usr/bin/gcc-11   110       manual mode
  2            /usr/bin/gcc-12   120       manual mode
  3            /usr/bin/gcc-13   130       manual mode

Press <enter> to keep the current choice[*], or type selection number:

Type the selection number corresponding to the version you wish to use and press Enter.

Step 5: Verify the Active Version

Confirm that the system is referencing the intended compiler versions:

gcc --version
g++ --version

Both outputs should display the version number selected in the previous step.

Step 6: Removing a Version from the Configuration

If you uninstall a compiler version or want to remove it from the alternatives list, run:

sudo update-alternatives --remove gcc /usr/bin/gcc-11
