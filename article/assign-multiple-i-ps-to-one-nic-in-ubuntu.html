Assign Multiple IPs to One NIC in Ubuntu

IP aliasing allows you to bind more than one IP address to a single physical network interface card (NIC), which is ideal for hosting multiple websites, running isolated services, or managing specific network traffic routing. This guide explains how to identify your network interface and configure multiple IP addresses on modern Ubuntu systems using both temporary command-line assignments and permanent configurations via Netplan.

Step 1: Identify Your Network Interface

Before adding IP addresses, determine the logical name of your physical network interface. Open your terminal and run:

ip addr

Locate your active interface. Typically, it will be named something like eth0, enp3s0, or ens33. Note this interface name along with your current IP configuration.

Step 2: Temporary Configuration (Runtime Only)

If you only need an additional IP address for testing or temporary tasks, you can add it directly using the ip tool. This change takes effect immediately but will revert upon system reboot.

  1. Add the secondary IP address:

    sudo ip addr add 192.168.1.150/24 dev eth0

    (Replace 192.168.1.150/24 with your desired IP and subnet, and eth0 with your interface name.)

  2. To remove the temporary IP address later, run:

    sudo ip addr del 192.168.1.150/24 dev eth0

Step 3: Permanent Configuration Using Netplan

Modern Ubuntu installations use Netplan for network configuration. Changes made here persist across reboots.

  1. Navigate to the Netplan directory and list the existing configuration files:

    ls /etc/netplan/

    Common file names include 01-netcfg.yaml, 50-cloud-init.yaml, or 00-installer-config.yaml.

  2. Open the file in a text editor with administrative privileges:

    sudo nano /etc/netplan/01-netcfg.yaml

  3. Locate the addresses section under your network interface. Netplan accepts multiple IPs as a YAML list. Format your file to include the primary and secondary IP addresses:

    network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.100/24
        - 192.168.1.150/24
        - 192.168.1.151/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]

    Note: YAML is sensitive to indentation. Use spaces instead of tabs.

  4. Test and apply the configuration:

    sudo netplan try

    If no errors occur, apply the settings permanently:

    sudo netplan apply

Step 4: Verify the New Configuration

Confirm that the new IP addresses are actively bound to the network card:

ip addr show eth0

You should see each configured IP listed under the inet entries for that interface. Test connectivity by pinging the new IP addresses from another machine on the same network:

ping 192.168.1.150
