View Interfaces and Plugs for an Ubuntu Snap

Snaps in Ubuntu run within isolated sandbox environments and interact with system resources through interfaces composed of plugs and slots. This guide explains the specific command used to view the interfaces and plugs connected to an installed snap, how to interpret the output, and how to query connections across your system.

The Command: snap connections

To view the specific interfaces and plugs connected to an installed snap, run the following command in your terminal:

snap connections <snap-name>

Replace <snap-name> with the name of your installed snap package.

Example

To check the plugs, slots, and interfaces for the Chromium snap, enter:

snap connections chromium

Understanding the Output

The command generates a table containing four columns:

  • Interface: The name of the snap interface being used (such as audio-playback, camera, or network).
  • Plug: The consumer endpoint declared by the snap to request permission for a resource (for example, chromium:camera).
  • Slot: The provider endpoint that grants access to the resource (typically provided by the snapd core runtime, written as :camera). If this column contains a dash (-), the plug is disconnected.
  • Notes: Contextual details about the connection, such as whether it was established automatically or manually.

Viewing All Connections System-Wide

To view every interface connection across all installed snaps on your Ubuntu system, run the command without specifying a package name:

snap connections

Viewing Details for a Specific Interface

If you want to inspect which snaps use a particular interface across the system, use the snap interface command followed by the interface name:

snap interface <interface-name>

For instance, running snap interface network lists all snaps that have plugs or slots associated with the network interface.
