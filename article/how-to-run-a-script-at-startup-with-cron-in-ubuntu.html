How to Run a Script at Startup with Cron in Ubuntu

Running a script automatically when your Ubuntu system boots up is an efficient way to handle background tasks, initialize server applications, or perform routine system checks. This article provides a clear, step-by-step guide on using the @reboot directive within the Ubuntu crontab file to execute any bash or shell script automatically at system startup.

Step 1: Make Your Script Executable

Before scheduling your script in cron, ensure the script file has execution permissions. Open your terminal and run:

chmod +x /path/to/your_script.sh

Replace /path/to/your_script.sh with the actual path to your file.

Step 2: Open the Crontab Editor

Open the cron configuration table for your current user by entering:

crontab -e

Note: If you are opening crontab for the first time, choose an editor (such as nano) from the prompt.

If your script requires root permissions to run, open the system administrator's crontab instead:

sudo crontab -e

Step 3: Add the @reboot Cron Entry

Scroll to the very bottom of the opened file and add a line using the @reboot macro, followed by the absolute path to your script:

@reboot /path/to/your_script.sh

Redirect Output for Logging

Because cron runs in the background, any output generated by your script will not appear on your screen. Redirect both standard output and error messages to a log file for troubleshooting:

@reboot /path/to/your_script.sh >> /path/to/logfile.log 2>&1

Add a Startup Delay (Optional)

If your script relies on network connections or background services (like databases) that need time to initialize during boot, insert a delay command before executing the script:

@reboot sleep 30 && /path/to/your_script.sh >> /path/to/logfile.log 2>&1

Step 4: Save and Exit

  • If using Nano: Press Ctrl + O, hit Enter to confirm, and press Ctrl + X to exit.
  • If using Vim: Press Esc, type :wq, and hit Enter.

Cron automatically applies the changes immediately after saving.

Step 5: Verify the Setup

To confirm that your new startup job is active, list all current cron tasks for your user:

crontab -l

Test the configuration by restarting your Ubuntu system:

sudo reboot
