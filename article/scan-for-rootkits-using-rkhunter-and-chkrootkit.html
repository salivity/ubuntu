Scan for Rootkits Using rkhunter and chkrootkit

Securing an Ubuntu system against hidden vulnerabilities requires reliable detection tools to identify unauthorized modifications and malware. This guide details the essential terminal commands used to install, update, and run scans with both chkrootkit and rkhunter (Rootkit Hunter) to detect rootkits and maintain system integrity.

Scanning with chkrootkit

chkrootkit is a lightweight shell script that checks system binaries for rootkit modifications.

1. Install chkrootkit

Update the package list and install the tool using the APT package manager:

sudo apt update
sudo apt install chkrootkit

2. Run the Scan Command

To perform a complete system scan, run:

sudo chkrootkit

To limit the output and show only suspicious warnings or infected results, add the -q (quiet) flag:

sudo chkrootkit -q

Scanning with rkhunter

rkhunter performs checks on local files against known rootkit signatures, verifies SHA-256 hashes against a baseline, and analyzes system commands for suspicious behavior.

1. Install rkhunter

Install the utility from Ubuntu's repositories:

sudo apt update
sudo apt install rkhunter

2. Update Signatures and Baselines

Before running a scan, update the signature database:

sudo rkhunter --update

Set the initial baseline of your system files so rkhunter knows which configurations are legitimate:

sudo rkhunter --propupd

3. Run the Scan Command

To initiate the scan, execute:

sudo rkhunter --check

By default, the scan pauses after each test section. To automatically proceed through the entire check and display only warnings, use:

sudo rkhunter --check --skip-keypress --report-warnings-only

4. Review Scan Results

Detailed logs are automatically generated and stored for inspection:

sudo less /var/log/rkhunter.log
