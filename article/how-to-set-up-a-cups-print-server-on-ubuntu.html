How to Set Up a CUPS Print Server on Ubuntu

Setting up a print server on Ubuntu using CUPS (Common UNIX Printing System) allows you to share physical printers across your local network with multiple devices, including Linux, Windows, and macOS systems. This guide walks you through installing the CUPS software, configuring network sharing permissions, adjusting firewall rules, and adding a printer through the CUPS web interface.

Step 1: Install CUPS

Open your terminal and update your package lists to ensure you install the latest versions:

sudo apt update

Install CUPS along with its essential utilities:

sudo apt install cups -y

Ensure the CUPS service is running and set to start automatically on system boot:

sudo systemctl start cups
sudo systemctl enable cups

Verify that the service is active:

sudo systemctl status cups

Step 2: Grant Administrative Privileges

To manage printers via the web interface, add your user account to the lpadmin group:

sudo usermod -aG lpadmin $USER

Note: Log out and log back in for the group membership changes to take effect.

Step 3: Configure CUPS for Remote Access

By default, CUPS only accepts connections from localhost. To allow other devices on your local network to access the print server, run the following commands:

Enable printer sharing on the local network:

cupsctl --share-printers

Enable remote administration:

cupsctl --remote-admin

Allow access from any system on your local network:

cupsctl --remote-any

Alternatively, you can manually edit the configuration file at /etc/cups/cupsd.conf to set Port 631 instead of Listen localhost:631 and add Allow @LOCAL inside the <Location />, <Location /admin>, and <Location /admin/conf> directives. Restart the service afterward:

sudo systemctl restart cups

Step 4: Configure Firewall

If Uncomplicated Firewall (UFW) is enabled on your Ubuntu server, open port 631 (the default CUPS port):

sudo ufw allow 631/tcp

Step 5: Add a Printer via the Web Interface

  1. Connect your printer to the Ubuntu server via USB and turn it on.
  2. Open a web browser on any device connected to the same network and navigate to: http://<your-server-ip>:631
  3. Click on the Administration tab at the top.
  4. Click Add Printer (you will be prompted to enter your Ubuntu system username and password).
  5. Select your connected printer from the list of local printers and click Continue.
  6. Enter a Name, Description, and Location for your printer.
  7. Check the box labeled Share This Printer and click Continue.
  8. Select the correct printer brand and driver model from the database, then click Add Printer.
  9. Set the default options (such as paper size) and click Set Default Options.

Step 6: Connect Client Devices

  • Linux: Open system settings, go to Printers, select Add Printer, and enter your server's IP address or let network discovery find the shared CUPS printer.
  • Windows: Go to Settings > Devices > Printers & scanners > Add a printer or scanner. Select "The printer that I want isn't listed", choose Select a shared printer by name, and enter http://<your-server-ip>:631/printers/<printer-name>.
  • macOS: Open System Settings > Printers & Scanners, click Add Printer, select the IP tab, enter your server's IP address, choose IPP (Internet Printing Protocol) as the protocol, and enter printers/<printer-name> in the Queue field.
