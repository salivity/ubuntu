Switch from NVIDIA to Nouveau Drivers on Ubuntu

Switching the Ubuntu graphics stack from proprietary NVIDIA drivers back to the open-source Nouveau driver requires completely removing the proprietary packages, removing kernel blacklists that suppress Nouveau, updating the initial RAM file system, and rebooting the system. This guide provides a direct, step-by-step walkthrough to safely reconfigure your system to use the built-in open-source Nouveau driver.

Step 1: Remove Proprietary NVIDIA Drivers

To allow Nouveau to take over the graphics hardware, you must first uninstall all proprietary NVIDIA kernel modules and userspace packages. Open a terminal and run the following command:

sudo apt-get purge "*nvidia*"
sudo apt-get autoremove
sudo apt-get autoclean

This completely removes all installed NVIDIA binary packages, configuration files, and unused dependencies.

Step 2: Remove the Nouveau Blacklist

When proprietary NVIDIA drivers are installed, Ubuntu automatically creates configuration files in /etc/modprobe.d/ to blacklist the Nouveau driver and prevent it from loading into the Linux kernel. You must remove or modify these entries.

Check for files containing the word "blacklist" and referencing "nouveau":

grep -rn "blacklist nouveau" /etc/modprobe.d/

Common files that blacklist Nouveau include:

  • /etc/modprobe.d/blacklist-nvidia.conf
  • /etc/modprobe.d/nvidia-graphics-drivers.conf
  • /etc/modprobe.d/blacklist.conf

Delete any standalone NVIDIA blacklist configuration files:

sudo rm -f /etc/modprobe.d/blacklist-nvidia.conf
sudo rm -f /etc/modprobe.d/nvidia-graphics-drivers.conf

If blacklist nouveau is located inside /etc/modprobe.d/blacklist.conf, open that file with a text editor:

sudo nano /etc/modprobe.d/blacklist.conf

Find the line that reads blacklist nouveau (and any associated options nouveau modeset=0), delete or comment them out by adding a # at the start of the line, and save the file (Ctrl+O, then Enter, then Ctrl+X).

Step 3: Ensure Mesa Nouveau Packages Are Installed

The open-source driver relies on the Mesa 3D graphics library for OpenGL and hardware acceleration. Verify that the necessary packages are installed:

sudo apt-get install --reinstall xserver-xorg-video-nouveau mesa-va-drivers libdrm-nouveau2

Step 4: Update the Initramfs

The kernel boot configuration must be regenerated to reflect the removal of the blacklist and to ensure that the Nouveau kernel module is included in the initial boot image. Run:

sudo update-initramfs -u

Step 5: Reboot and Verify

Reboot your machine to apply the changes:

sudo reboot

After the system boots to the desktop, verify that the Nouveau driver is actively controlling your graphics hardware:

lspci -k | grep -EA3 'VGA|3D'

Look for the line Kernel driver in use: nouveau. You can also verify that the module is loaded by running:

lsmod | grep nouveau

If nouveau appears in the output, your Ubuntu graphics stack has successfully returned to using the open-source driver.
