How to Change Default Terminal in Ubuntu

Changing the default terminal emulator in Ubuntu allows you to automatically launch your preferred command-line tool, such as Alacritty, Kitty, or Tilix, when using system shortcuts. This guide demonstrates how to set a new default terminal using the native Debian alternatives system (update-alternatives) and how to adjust system keyboard shortcuts to ensure your preferred terminal opens seamlessly.

Step 1: Install Your New Terminal Emulator

Before setting a new default, ensure your desired terminal is installed. For example, if you want to install Tilix or Alacritty, run one of the following commands in your current terminal:

sudo apt update
sudo apt install tilix

or

sudo apt install alacritty

Step 2: Configure the Default Terminal via Command Line

Ubuntu manages default applications through the update-alternatives system. To change the default terminal emulator, follow these steps:

  1. Open your current terminal.
  2. Run the following command:
sudo update-alternatives --config x-terminal-emulator
  1. You will see a list of installed terminal emulators on your system, each assigned a selection number. The current default terminal is marked with an asterisk (*).

Example output:

There are 3 choices for the alternative x-terminal-emulator (providing /usr/bin/x-terminal-emulator).

  Selection    Path                             Priority   Status
------------------------------------------------------------
* 0            /usr/bin/gnome-terminal.wrapper   40        auto mode
  1            /usr/bin/alacritty                50        manual mode
  2            /usr/bin/gnome-terminal.wrapper   40        manual mode
  3            /usr/bin/tilix                    30        manual mode

Press <enter> to keep the current choice[*], or type selection number:
  1. Type the Selection number corresponding to the terminal you wish to use as your default and press Enter.

Step 3: Update Keyboard Shortcuts (If Needed)

In some versions of Ubuntu, pressing Ctrl + Alt + T may still launch GNOME Terminal instead of the newly selected default. To fix this:

  1. Open Settings from your application menu.
  2. Scroll down and select Keyboard.
  3. Click on View and Customize Shortcuts at the bottom of the window.
  4. Select Launchers, then click on Launch terminal.
  5. Clear the shortcut by pressing Backspace.
  6. Navigate back to the main shortcut menu, scroll to the bottom, and select Custom Shortcuts.
  7. Click Add Shortcut (+).
  8. Name the shortcut (e.g., “Custom Terminal”).
  9. In the Command field, enter the binary name of your new terminal (e.g., tilix or alacritty).
  10. Set the shortcut key to Ctrl + Alt + T and click Add.

Verification

To verify that the change was successful, press Ctrl + Alt + T or run the following command to open your newly configured default terminal:

x-terminal-emulator
