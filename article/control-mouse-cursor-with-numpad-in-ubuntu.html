Control Mouse Cursor with Numpad in Ubuntu

Ubuntu includes a built-in accessibility feature called Mouse Keys that allows you to control the screen pointer and perform click actions using the physical numeric keypad. This guide explains how to enable Mouse Keys through the Ubuntu graphical settings interface, toggle it with a keyboard shortcut, and map the numeric keypad keys to mouse movements and clicks.

Enabling Mouse Keys via Settings

  1. Open the Settings application by pressing the Super key (Windows key), typing Settings, and pressing Enter.
  2. From the left sidebar, click on Accessibility.
  3. Scroll down to the Pointing & Clicking section.
  4. Locate the Mouse Keys option and toggle the switch to the ON position.

Enabling Mouse Keys via the Command Line

If you do not have a working mouse to navigate the interface, you can enable Mouse Keys directly using the Terminal:

  1. Press Ctrl + Alt + T to open a terminal window.
  2. Enter the following command and press Enter: 
    gsettings set org.gnome.desktop.a11y.keyboard mousekeys-enable true

To disable the feature later via the terminal, run the same command replacing true with false.

Quick Toggle Shortcut

You can quickly turn Mouse Keys on or off at any time by pressing Shift + Num Lock simultaneously. If this does not work, ensure that accessibility keyboard shortcuts are enabled under Settings > Accessibility > Keyboard Shortcuts.

Numeric Keypad Controls

Once Mouse Keys is active, the numeric keypad operates using the following standard layout:

  • Movement:
    • 8: Up
    • 2: Down
    • 4: Left
    • 6: Right
    • 7: Up and Left
    • 9: Up and Right
    • 1: Down and Left
    • 3: Down and Right
  • Clicking:
    • 5: Click the currently selected mouse button.
    • +: Double-click the currently selected mouse button.
  • Button Selection:
    • / (Slash): Select the left mouse button as primary.
    • * (Asterisk): Select the middle mouse button as primary.
    • - (Minus): Select the right mouse button as primary.
  • Dragging and Dropping:
    • 0: Press and hold the current mouse button (to drag an item).
    • . (Decimal Point): Release the held mouse button (to drop an item).
