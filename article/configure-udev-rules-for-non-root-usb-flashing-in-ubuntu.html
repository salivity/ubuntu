Configure Udev Rules for Non-Root USB Flashing in Ubuntu

By default, Ubuntu restricts raw USB device access to the root user, preventing standard users from uploading firmware or flashing microcontrollers without administrative privileges. This guide demonstrates how to identify your target USB device, generate a custom udev rule to grant the appropriate access permissions, apply the changes immediately, and verify that you can flash firmware without using sudo.

Step 1: Identify the USB Device's Vendor and Product IDs

Connect your device in bootloader or flashing mode and identify its hardware IDs using the terminal:

lsusb

Locate your device in the output. The output will look similar to this:

Bus 001 Device 012: ID 1209:0001 Generic Flashing Device

In the example 1209:0001:

  • 1209 is the Vendor ID (idVendor).
  • 0001 is the Product ID (idProduct).

Step 2: Ensure User Group Membership

Ubuntu often uses the plugdev or dialout group to manage external device access. Add your current user to the plugdev group:

sudo usermod -aG plugdev $USER

Log out and back in, or run newgrp plugdev, to apply the group change to your active session.

Step 3: Create the Custom Udev Rule

Udev rules determine device permissions when hardware is detected. Create a new rules file in /etc/udev/rules.d/:

sudo nano /etc/udev/rules.d/99-usb-flashing.rules

Add a rule referencing your device’s Vendor ID and Product ID. Choose one of the following approaches:

Approach A: Grant Access to the plugdev Group (Recommended)

SUBSYSTEM=="usb", ATTR{idVendor}=="1209", ATTR{idProduct}=="0001", MODE="0660", GROUP="plugdev"

Approach B: Allow Modern Desktop User Access (uaccess)

SUBSYSTEM=="usb", ATTR{idVendor}=="1209", ATTR{idProduct}=="0001", TAG+="uaccess"

Approach C: Broad Access for Development Environments

If you want write access for all local users:

SUBSYSTEM=="usb", ATTR{idVendor}=="1209", ATTR{idProduct}=="0001", MODE="0666"

Note: Replace 1209 and 0001 with your actual device IDs. If your bootloader switches IDs during flashing, you can omit ATTR{idProduct} to apply the rule to all devices from that vendor.

Save and close the file (Ctrl+O, Enter, Ctrl+X in nano).

Step 4: Reload Udev Rules

Reload the udev configuration without rebooting the system:

sudo udevadm control --reload-rules
sudo udevadm trigger

Step 5: Verify Non-Root Permissions

Unplug your USB device and plug it back into your system. Verify permissions by locating the device node under /dev/bus/usb/ or by running your flashing software (such as dfu-util, esptool, or fastboot) directly as a regular user:

dfu-util -l

If configured correctly, the tool will enumerate and flash the device without reporting permission denied errors.
