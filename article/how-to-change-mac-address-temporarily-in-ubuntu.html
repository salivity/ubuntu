How to Change MAC Address Temporarily in Ubuntu

Changing your MAC address temporarily in Ubuntu allows you to spoof your network interface identity for privacy, security testing, or network troubleshooting without altering your system configuration permanently. This guide provides quick, step-by-step instructions using standard terminal commands like ip and the macchanger utility, ensuring that all changes automatically revert to your hardware default after a system reboot.

Step 1: Identify Your Network Interface

Open your terminal (Ctrl+Alt+T) and list your active network interfaces by running:

ip link show

Locate the name of the interface you want to modify (e.g., eth0, wlan0, or enp3s0).

Step 2: Change the MAC Address Using the ip Command

The standard ip tool included in modern Ubuntu releases allows you to change your MAC address directly.

  1. Take the interface offline:

    sudo ip link set dev <interface_name> down

  2. Set the new MAC address: Replace XX:XX:XX:XX:XX:XX with your desired MAC address:

    sudo ip link set dev <interface_name> address XX:XX:XX:XX:XX:XX

  3. Bring the interface back online:

    sudo ip link set dev <interface_name> up

Alternative Method: Using macchanger

macchanger is a specialized utility that simplifies assigning custom or random MAC addresses.

  1. Install macchanger:

    sudo apt update && sudo apt install macchanger

    (Select "No" if prompted to automatically change the MAC address on boot to keep changes strictly temporary).

  2. Take the interface offline:

    sudo ip link set dev <interface_name> down

  3. Assign a random MAC address:

    sudo macchanger -r <interface_name>

    Or assign a specific MAC address:

    sudo macchanger -m XX:XX:XX:XX:XX:XX <interface_name>

  4. Bring the interface back online:

    sudo ip link set dev <interface_name> up

Step 3: Verify the Changes

To confirm the temporary MAC address is active, run:

ip link show <interface_name>

Look for the link/ether line in the output to see your updated MAC address.

To revert to your original hardware address at any time, simply reboot your computer or restart your network manager service.
