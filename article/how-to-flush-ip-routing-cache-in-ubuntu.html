How to Flush IP Routing Cache in Ubuntu

Clearing the IP routing cache in Ubuntu is an essential troubleshooting step when network routes change, gateways are updated, or custom routing tables fail to take effect immediately. This article explains how to properly flush the IP routing cache in Ubuntu using the standard iproute2 command-line utility, along with methods to clear related network caches to ensure all routing changes take effect.

Command to Flush the IP Routing Cache

To flush the routing cache on Ubuntu, open your terminal and run the following command:

sudo ip route flush cache

This command instructs the Linux kernel to clear its cached routing decisions, forcing it to re-evaluate all incoming and outgoing network traffic against the active routing table.

Routing Cache in Modern Ubuntu Releases

In older Linux kernels (prior to version 3.6), the kernel maintained an explicit routing cache. Modern Ubuntu releases use Linux kernels where the static IPv4 routing cache was removed to prevent denial-of-service (DoS) vectors and improve performance.

However, running sudo ip route flush cache remains the correct command on modern Ubuntu systems. It invalidates destination cache entries (DCE) and clears exception tables tied to active network sockets.

Clearing Related Caches

If you are resolving network path issues, flushing the routing cache alone may not be enough. Clearing the ARP (neighbor) cache and local DNS cache ensures all layer-2 and layer-3 paths are refreshed.

Flush the ARP / Neighbor Cache

To clear cached MAC-to-IP address mappings:

sudo ip neigh flush all

Flush the DNS Cache

If your Ubuntu system uses systemd-resolved for local DNS resolution, clear the DNS cache with:

sudo resolvectl flush-caches

Running these commands sequentially provides a complete reset of your local network routing state.
