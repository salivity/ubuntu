How to Check CPU Frequency in Ubuntu

Monitoring your processor's speed is essential for troubleshooting performance issues, verifying overclocking settings, or managing power consumption on Linux. This article outlines the primary terminal commands available in Ubuntu to quickly view your current CPU frequency in real-time, ranging from built-in system tools to specialized utility packages.

1. Using the lscpu Command

The lscpu command gathers CPU architecture information from sysfs and /proc/cpuinfo. You can filter the output specifically for frequency details using grep.

Run the following command in your terminal:

lscpu | grep "MHz"

This will display the current CPU speed alongside the minimum and maximum scaling frequencies supported by your processor.

2. Inspecting /proc/cpuinfo Direct File

The /proc/cpuinfo virtual file contains detailed specs for every individual CPU core on your system. To view the current clock speed of all cores, execute:

cat /proc/cpuinfo | grep "cpu MHz"

If you want to monitor these speeds dynamically as they change under load, combine the command with watch:

watch -n 1 "cat /proc/cpuinfo | grep 'cpu MHz'"

This refreshes the CPU frequency values every second.

3. Using cpufrequtils for Detailed Metrics

For more detailed power management information, you can use the cpufrequtils package, which provides the cpufreq-info command.

First, install the package:

sudo apt update
sudo apt install cpufrequtils

Once installed, run the tool:

cpufreq-info

To view a concise summary of the current frequency and active governor for all cores, use:

cpufreq-info -o

4. Using the lshw Tool

The hardware listing tool lshw provides information regarding your CPU's current operating speed alongside its maximum capability.

Run:

sudo lshw -c cpu | grep -E "capacity|clock"

This command outputs the current clock speed along with the maximum rated capacity of the installed processor.
