How to Check Secure Boot Status in Ubuntu

This guide explains how to quickly check whether UEFI Secure Boot is enabled or disabled on an Ubuntu system using the command line. By using dedicated terminal utilities, you can instantly verify your system's boot security configuration without having to restart your computer and enter the BIOS or UEFI firmware menu.

The Primary Command: mokutil

The most direct and reliable command to check the Secure Boot status in Ubuntu is mokutil.

Open your terminal (press Ctrl + Alt + T) and run the following command:

mokutil --sb-state

The terminal will return one of two clear outputs:

  • SecureBoot enabled: Secure Boot is active and enforcing signature verification.
  • SecureBoot disabled: Secure Boot is turned off in your system's UEFI settings.

If the command is not found, install the mokutil package using the standard package manager:

sudo apt update && sudo apt install mokutil

Alternative Method: Using bootctl

If your system uses systemd-boot or you want broader boot configuration details, you can use the bootctl command:

bootctl status

Scroll through the output to find the line that reads:

  • Secure Boot: enabled
  • Secure Boot: disabled

Alternative Method: Checking Kernel Logs

You can also verify Secure Boot status by inspecting the kernel boot messages using dmesg:

dmesg | grep -i "secure boot"

If Secure Boot is active, you will see an entry such as:

[    0.000000] secureboot: Secure boot enabled

If it is inactive, the log will typically show:

[    0.000000] secureboot: Secure boot disabled
