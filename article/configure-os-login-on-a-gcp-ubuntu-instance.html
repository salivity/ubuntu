Configure OS Login on a GCP Ubuntu Instance

This guide provides a straightforward walkthrough for setting up Google Cloud Platform's (GCP) OS Login feature on an Ubuntu virtual machine. OS Login links Linux user accounts to Google identities, eliminating the need to manually manage static SSH keys in metadata or local files. By completing the steps below, you will enable OS Login via metadata, assign the appropriate Identity and Access Management (IAM) permissions, and connect to your Ubuntu instance securely using standard Google Cloud tooling.

Step 1: Enable OS Login in GCP Metadata

You can enable OS Login across your entire project or target a specific Ubuntu instance.

Option A: Instance-Level (Recommended for Testing)

Run the following command using the Google Cloud SDK (gcloud) to enable OS Login on a single instance:

gcloud compute instances add-metadata INSTANCE_NAME \
    --zone=ZONE \
    --metadata=enable-oslogin=TRUE

Option B: Project-Level

To enable OS Login for all current and future VM instances across the project:

gcloud compute project-info add-metadata \
    --metadata=enable-oslogin=TRUE

Alternatively, you can navigate to the Compute Engine section in the Google Cloud Console, edit your instance or project metadata, and add a custom metadata key named enable-oslogin with the value TRUE.

Step 2: Configure Required IAM Permissions

For a user to log in via OS Login, their Google account must have specific IAM roles assigned at the project or instance level.

  1. Standard User Access (Non-root): Assign the Compute OS Login role:

    • Role: roles/compute.osLogin

  2. Administrator Access (Root/sudo privileges): Assign the Compute OS Admin Login role:

    • Role: roles/compute.osAdminLogin

To grant access using gcloud, execute:

gcloud projects add-iam-policy-binding PROJECT_ID \
    --member="user:USER_EMAIL@example.com" \
    --role="roles/compute.osAdminLogin"

Note: If the instance uses a custom service account, the user also requires the roles/iam.serviceAccountUser role.

Step 3: Verify the Ubuntu Guest Environment

Official GCP Ubuntu images come pre-installed with the Google Compute Engine guest environment, which includes the OS Login daemon. If you are using a standard Ubuntu image, ensure the packages are active:

sudo systemctl status google-oslogin-cache.timer

If you are using a custom or minimal Ubuntu image where the guest environment is missing, install the OS Login package:

sudo apt-get update
sudo apt-get install -y google-compute-engine-oslogin

Step 4: Connect to the Instance

Once metadata and IAM permissions are configured, connect to the instance using the gcloud compute ssh command. The Google Cloud CLI will automatically look up your OS Login profile and authenticate the session:

gcloud compute ssh INSTANCE_NAME --zone=ZONE

Upon successful connection, your Linux username will automatically match the format generated by your Google Workspace or Cloud Identity profile (typically username_domain_com or username).
