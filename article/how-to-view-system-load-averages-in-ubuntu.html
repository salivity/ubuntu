How to View System Load Averages in Ubuntu

Monitoring system performance is essential for maintaining a healthy Linux environment. This guide covers the quickest terminal commands used to check system load averages in Ubuntu, explores interactive real-time monitoring tools, and explains how to properly interpret load average metrics.

The Direct Command: uptime

The fastest command to view the current system load averages in Ubuntu is uptime. Running this command displays the current time, how long the system has been running, the number of logged-in users, and the system load averages.

Open your terminal and execute:

uptime

Example Output:

14:30:15 up 3 days,  4:12,  2 users,  load average: 0.25, 0.18, 0.12

The three numbers at the end represent the system load averages over three distinct time frames:

  • First number (0.25): Average load over the last 1 minute.
  • Second number (0.18): Average load over the last 5 minutes.
  • Third number (0.12): Average load over the last 15 minutes.

Alternative Commands

You can also view system load averages using several other standard Ubuntu utility commands:

1. top

Provides an interactive, real-time list of running processes along with the system load average in the top header line.

top

2. w

Shows who is currently logged into the system and what they are doing, with the system load averages displayed at the top.

w

3. Reading /proc/loadavg

To fetch raw load average data directly from the kernel interface, read the contents of the pseudo-file /proc/loadavg:

cat /proc/loadavg

How to Read Load Average Numbers

System load measures the number of CPU execution threads that are either active or waiting for CPU time.

  • On a single-core CPU: A load average of 1.00 means the CPU is at 100% capacity.
  • On a quad-core CPU: A load average of 4.00 means all four CPU cores are fully utilized.
  • Over 1.00 per core: Indicates that processes are queuing up and waiting for CPU resources.
