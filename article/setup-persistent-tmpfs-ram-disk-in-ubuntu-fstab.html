Setup Persistent tmpfs RAM Disk in Ubuntu fstab

A tmpfs RAM disk allocates a portion of your system's volatile memory for blazing-fast read and write operations. While adding an entry to /etc/fstab ensures the RAM disk mount itself persists across system reboots, the data stored within RAM is lost upon shutdown. This guide demonstrates how to configure a tmpfs RAM disk in Ubuntu's /etc/fstab file and combine it with a simple systemd synchronization service to keep your data persistent across reboots.

Step 1: Create the Mount Point and Backup Directory

You need a directory where the tmpfs will be mounted and a persistent directory on your physical drive to store data between system shutdowns.

Open your terminal and run:

sudo mkdir -p /mnt/ramdisk
sudo mkdir -p /var/ramdisk-backup

Set the appropriate permissions:

sudo chmod 777 /mnt/ramdisk

Step 2: Configure /etc/fstab

Adding the tmpfs configuration to /etc/fstab ensures that the operating system recreates the RAM disk automatically during the boot sequence.

  1. Open the /etc/fstab file in a text editor:

    sudo nano /etc/fstab

  2. Add the following line at the end of the file (adjust size=2G to your desired RAM allocation):

    tmpfs /mnt/ramdisk tmpfs defaults,noatime,mode=1777,size=2G 0 0

  3. Save and exit the editor (Ctrl+O, Enter, then Ctrl+X).

  4. Test and mount the new filesystem immediately:

    sudo mount -a

  5. Verify the mount using df -h:

    df -h /mnt/ramdisk

Step 3: Configure Data Persistence with systemd

Because RAM clears when power is cut, true data persistence requires syncing data to physical storage on shutdown and restoring it to the RAM disk upon boot.

  1. Create a dedicated systemd service file:

    sudo nano /etc/systemd/system/ramdisk-sync.service

  2. Paste the following configuration:

    [Unit]
Description=Sync tmpfs RAM disk to physical storage
DefaultDependencies=no
Before=shutdown.target reboot.target halt.target
RequiresMountsFor=/mnt/ramdisk /var/ramdisk-backup

[Service]
Type=oneshot
RemainAfterExit=true
ExecStart=/usr/bin/rsync -a --delete /var/ramdisk-backup/ /mnt/ramdisk/
ExecStop=/usr/bin/rsync -a --delete /mnt/ramdisk/ /var/ramdisk-backup/

[Install]
WantedBy=multi-user.target

  3. Save and close the file.

  4. Reload systemd, enable the service, and start it:

    sudo systemctl daemon-reload
sudo systemctl enable ramdisk-sync.service
sudo systemctl start ramdisk-sync.service

Step 4: Verify Persistence

  1. Create a test file inside the RAM disk:

    echo "Persistence test" > /mnt/ramdisk/test.txt

  2. Reboot your Ubuntu system:

    sudo reboot

  3. After the reboot completes, inspect the RAM disk directory:

    cat /mnt/ramdisk/test.txt

If the file displays "Persistence test", your tmpfs RAM disk is permanently configured in /etc/fstab and your data is successfully persisted across system reboots.
