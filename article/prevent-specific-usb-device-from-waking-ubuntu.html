Prevent Specific USB Device From Waking Ubuntu

Unwanted system wakeups in Ubuntu are frequently caused by sensitive USB peripherals, such as an optical mouse detecting slight vibrations or a mechanical keyboard. By identifying the specific device's Vendor and Product IDs, you can disable its wake capability using a persistent udev rule, ensuring your system remains suspended until you explicitly choose to wake it.

Step 1: Identify the Problematic USB Device

Open a terminal and run the following command to list all connected USB devices:

lsusb

Look for the device causing the unwanted wakeups. The output will look similar to this:

Bus 001 Device 004: ID 046d:c52b Logitech, Inc. Unifying Receiver
Bus 001 Device 005: ID 1bcf:0005 Sunplus Innovation Technology Gaming Mouse

Note the ID value for your device. It consists of two hexadecimal numbers separated by a colon: the idVendor (e.g., 1bcf) and the idProduct (e.g., 0005).

Step 2: Create a Persistent udev Rule

Settings changed manually in /sys/ reset after a reboot. To make the setting permanent across reboots and unplugging events, create a custom udev rule.

Create and open a new rules file using a text editor with administrative privileges:

sudo nano /etc/udev/rules.d/90-disable-usb-wake.rules

Add the following single line to the file, replacing YOUR_VENDOR_ID and YOUR_PRODUCT_ID with the values you found in Step 1:

ACTION=="add", SUBSYSTEM=="usb", ATTR{idVendor}=="YOUR_VENDOR_ID", ATTR{idProduct}=="YOUR_PRODUCT_ID", ATTR{power/wakeup}="disabled"

For example, using the mouse from Step 1:

ACTION=="add", SUBSYSTEM=="usb", ATTR{idVendor}=="1bcf", ATTR{idProduct}=="0005", ATTR{power/wakeup}="disabled"

Save the file and exit the editor (in nano, press Ctrl+O, Enter, and then Ctrl+X).

Step 3: Reload udev Rules

Apply the new configuration immediately without rebooting by reloading the udev daemon and triggering the rules:

sudo udevadm control --reload-rules
sudo udevadm trigger

Alternatively, unplug the USB device and plug it back into the port.

Step 4: Verify the Setting

To confirm that the device can no longer wake the system, locate its power/wakeup file and check its status. Run:

grep . /sys/bus/usb/devices/*/power/wakeup

Find the entry corresponding to your device's bus address; the value should now read disabled. Put your Ubuntu system into suspension to confirm that interacting with the configured device no longer wakes the computer.
