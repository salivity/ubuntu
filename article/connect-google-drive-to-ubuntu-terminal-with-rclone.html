Connect Google Drive to Ubuntu Terminal with Rclone

This guide provides a practical walkthrough for interacting with Google Drive APIs directly from the Ubuntu terminal using rclone. By following these steps, you will learn how to install rclone, configure secure API access to your Google Drive account, and execute core file operations such as uploading, downloading, syncing, and listing remote files without needing a graphical desktop interface.

1. Install Rclone on Ubuntu

Update your package index and install rclone directly from the official repositories, or use the official installation script to get the latest release.

sudo apt update
sudo apt install rclone -y

To verify the installation:

rclone version

2. Configure the Google Drive Remote

Rclone uses an interactive configuration wizard to generate credentials and store API authorization tokens.

Launch the configuration tool:

rclone config

Follow the prompts sequentially:

  1. Type n and press Enter to create a new remote.
  2. Enter a name for the remote, such as gdrive.
  3. Locate the number for Google Drive (or type drive) and press Enter.
  4. Leave client_id and client_secret blank to use default credentials, or supply your own from the Google Cloud Console for better performance and quota control.
  5. Select the access scope: choose option 1 (drive) for full access to your files.
  6. Press Enter to accept default values for service_account_file and advanced configuration (n).
  7. Authenticate:
    • If running on an Ubuntu desktop with a browser: Type y for auto-config. A browser window will open automatically asking you to log into Google and grant access.
    • If running on a headless Ubuntu server (SSH): Type n for auto-config. Rclone will instruct you to run rclone authorize "drive" on a local computer with a browser, generate a verification code, and paste that token back into the Ubuntu terminal.
  8. When asked to configure as a team drive, select n (unless using Google Workspace Shared Drives).
  9. Confirm the configuration by typing y, then type q to quit the wizard.

3. Verify the Connection

Check that rclone can successfully query the Google Drive API by listing the directories located at the root of your drive:

rclone lsd gdrive:

To list all files in a specific folder:

rclone ls gdrive:FolderName

4. Common File Management Commands

Interact with files via standard CLI conventions by referencing your remote name followed by a colon (gdrive:).

Upload Files or Directories

To copy a local directory to Google Drive without deleting destination files:

rclone copy /path/to/local/data gdrive:BackupFolder

Download Files

To download a directory from Google Drive to your local machine:

rclone copy gdrive:BackupFolder /path/to/local/data

Synchronize Directories

To make the destination match the source directory identically (note that this deletes destination files that do not exist in the source):

rclone sync /path/to/local/data gdrive:BackupFolder

Check File Differences

To compare your local directory against Google Drive without transferring files:

rclone check /path/to/local/data gdrive:BackupFolder

5. Mount Google Drive as a Local Folder (Optional)

You can mount your remote storage directly into the Ubuntu filesystem using FUSE:

sudo apt install fuse3 -y
mkdir -p ~/mnt/gdrive
rclone mount gdrive: ~/mnt/gdrive --vfs-cache-mode full --daemon

This command mounts the remote drive in the background, allowing you to access remote cloud files using standard Linux commands such as cd, cp, and cat. To unmount, run:

fusermount -u ~/mnt/gdrive
