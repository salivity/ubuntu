Install and Use Nmap to Scan Ports on Ubuntu

This guide demonstrates how to install the Nmap network scanner on an Ubuntu terminal and use it to discover open ports and active services on target systems. By following these steps, you will update your package repository, install the official Nmap package, and run practical scanning commands ranging from basic port queries to advanced service and operating system detection.

Installing Nmap on Ubuntu

Nmap is available in the default Ubuntu repositories. Open your terminal and follow these steps to install it:

  1. Update your local package list:

    sudo apt update

  2. Install Nmap:

    sudo apt install nmap -y

  3. Verify the installation by checking the installed version:

    nmap --version

Discovering Open Ports

Once installed, you can scan IP addresses, hostnames, or entire subnets. Always ensure you have authorization before scanning networks that do not belong to you.

1. Basic Scan

By default, Nmap scans the 1,000 most common TCP ports for a given host:

nmap 192.168.1.1

You can replace the IP address with a domain name:

nmap example.com

2. Scanning Specific Ports

To target individual ports or ranges, use the -p flag:

  • Scan a single port: 
    nmap -p 80 192.168.1.1
  • Scan multiple specific ports: 
    nmap -p 22,80,443 192.168.1.1
  • Scan a port range: 
    nmap -p 1-1024 192.168.1.1
  • Scan all 65,535 TCP ports: 
    nmap -p- 192.168.1.1

3. Detecting Service Versions

To discover which software applications and versions are listening on open ports, add the -sV flag:

nmap -sV 192.168.1.1

4. Running a TCP SYN (Stealth) Scan

A SYN scan (-sS) sends SYN packets without completing the full TCP handshake. It is fast, unobtrusive, and requires superuser privileges:

sudo nmap -sS 192.168.1.1

5. Comprehensive (Aggressive) Scan

The -A flag enables operating system detection, version scanning, script scanning, and traceroute in a single execution:

sudo nmap -A 192.168.1.1

6. Scanning an Entire Subnet

To detect active hosts and open ports across an entire local network, specify the CIDR subnet notation:

nmap 192.168.1.0/24

Saving Scan Results

To export scan results for documentation or analysis, use the -oN flag for standard text format:

nmap -oN scan_results.txt 192.168.1.1

For XML output suitable for security tools, use -oX:

nmap -oX scan_results.xml 192.168.1.1
