Configure Unity 3D via Unity Hub on Ubuntu

This guide covers the complete workflow for setting up the Unity 3D game engine on Ubuntu using the official Unity Hub management tool. You will learn how to add the official Unity repository, install Unity Hub via the terminal, activate a license, install an LTS version of the Unity Editor, and add essential build modules to begin game development on Linux.

Step 1: Add the Unity Hub Repository

Unity provides an official Debian/Ubuntu repository for Unity Hub. Open your terminal and add the public signing key and repository to your system:

  1. Import the Unity GPG key:

    wget -qO - https://hub.unity3d.com/linux/keys/public | gpg --dearmor | sudo tee /usr/share/keyrings/Unity_Technologies_ApS.gpg > /dev/null

  2. Add the repository to your sources list:

    sudo sh -c 'echo "deb [signed-by=/usr/share/keyrings/Unity_Technologies_ApS.gpg] https://hub.unity3d.com/linux/repos/deb stable main" > /etc/apt/sources.list.d/unityhub.list'

  3. Update the package index:

    sudo apt update

Step 2: Install Unity Hub

Install the Unity Hub application using the standard package manager:

sudo apt install unityhub -y

Once installation completes, launch the application from your application menu or by running unityhub in the terminal.

Step 3: Sign In and Activate a License

Before downloading the editor, Unity Hub requires authentication and license activation:

  1. Launch Unity Hub.
  2. Click Sign In in the top-left corner and log in with your Unity ID credentials (or create an account if you do not have one).
  3. Click the Gear icon (Preferences) in the top-right corner.
  4. Select Licenses from the left-hand menu.
  5. Click Add License, select Get a free personal license (or activate a Pro/Enterprise serial number), and accept the terms of service.

Step 4: Install the Unity Editor

  1. Return to the main window and select the Installs tab on the left sidebar.
  2. Click the Install Editor button.
  3. Select an official release. It is recommended to choose the latest LTS (Long Term Support) version for stability.
  4. Click Install.

Step 5: Configure Build Support and Modules

During or after the editor installation prompt, select the platform modules required for your projects:

  • Linux Build Support (IL2CPP / Mono): Required for building standalone Linux binaries.
  • Android / WebGL / Windows Build Support: Select any additional target platforms you plan to deploy to.
  • Documentation: Offline access to Unity API documentation.

Click Continue, accept any license agreements for third-party components (such as Android SDK/NDK), and allow the installation to complete.

Step 6: Verify and Configure System Dependencies

To ensure the editor runs without graphics or compilation issues, ensure your system has proper graphics drivers and essential libraries:

sudo apt install build-essential clang libglu1-mesa -y

For systems with NVIDIA GPUs, ensure proprietary drivers are installed via the Additional Drivers utility in Ubuntu.

Step 7: Create a New Project

  1. Click on the Projects tab in Unity Hub.
  2. Click New Project.
  3. Select an editor version and project template (such as 2D Core, 3D Core, or Universal Render Pipeline).
  4. Assign a project name, choose a local directory on your filesystem, and click Create project.

The Unity Editor will initialize and launch your configured Linux development environment.
