How to Initialize an LXD Storage Pool on Ubuntu

Initializing a new LXD storage pool on an Ubuntu server allows you to efficiently manage space, isolate container data, and leverage advanced storage drivers like ZFS, Btrfs, LVM, or standard directory storage. This guide provides a straightforward walkthrough on checking your current LXD setup, selecting the right storage driver, and using the LXD Command Line Interface (CLI) to create, verify, and assign a new storage pool to your containers.

Prerequisites

Before creating a storage pool, ensure you have:

  • An Ubuntu server with LXD installed and initialized (lxd init).
  • Sudo or root privileges on the server.

Step 1: View Existing Storage Pools

To check the currently available storage pools on your LXD server, run:

lxc storage list

This output displays the name, driver, source, and usage status of your existing pools.

Step 2: Create a New LXD Storage Pool

Use the lxc storage create command to initialize a new pool. The basic syntax is:

lxc storage create <pool-name> <driver> [options]

Option A: Create a Directory-Based Storage Pool

Directory storage works on any filesystem without requiring extra disks or dedicated partitions.

lxc storage create my-dir-pool dir

Option B: Create a Loop-Backed ZFS Storage Pool

If you want to use ZFS features (like snapshots and fast cloning) without a dedicated block device, LXD can create a loop file automatically:

lxc storage create my-zfs-pool zfs size=20GiB

Option C: Create a Storage Pool on a Dedicated Block Device (ZFS / LVM / Btrfs)

If you have a dedicated unused partition or disk (e.g., /dev/sdb), pass it as the source:

lxc storage create my-lvm-pool lvm source=/dev/sdb

Step 3: Verify the New Storage Pool

To confirm that your storage pool was initialized successfully and view its details, execute:

lxc storage show <pool-name>

For example:

lxc storage show my-dir-pool

You can also list all pools again to verify its status:

lxc storage list

Step 4: Using the New Storage Pool

Once created, you can launch new containers directly onto your new storage pool using the -s (or --storage) flag:

lxc launch ubuntu:24.04 my-container -s my-dir-pool

To set the new storage pool as the default pool for the default profile:

lxc profile device add default root disk path=/ pool=my-dir-pool
