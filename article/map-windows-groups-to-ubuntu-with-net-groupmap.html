Map Windows Groups to Ubuntu with net groupmap

In a heterogeneous network environment managed by Samba, mapping Windows security groups to local Ubuntu POSIX groups ensures consistent access control and permissions across platforms. This guide provides a straightforward walkthrough on using Samba's net groupmap utility on Ubuntu to associate Windows NT groups with local Linux groups, covering preparation, execution, verification, and maintenance.

Prerequisites

Before mapping groups, ensure that Samba is installed and running on your Ubuntu system, and that you have administrative privileges. You also need an existing local Linux group to act as the target.

To create a new local Ubuntu group if needed, run:

sudo groupadd winadmins

Adding a Group Mapping

The net groupmap add command binds a Windows NT group to a corresponding Ubuntu system group. You can define the group as a domain group (type=d) or a local group (type=l).

To map a Windows domain group named "Domain Admins" to the local Ubuntu group "winadmins", execute:

sudo net groupmap add ntgroup="Domain Admins" unixgroup="winadmins" type=d

Parameters explained:

  • ntgroup: The name of the Windows NT group you want to map.
  • unixgroup: The target local group existing on your Ubuntu system.
  • type: Specifies the group scope. Use d for a Domain group, l for a Local group, or b for Built-in.

If mapping by group name fails or if you require precise targeting via Windows Security Identifiers (SIDs), map using the SID directly:

sudo net groupmap add sid=S-1-5-21-XXXXXXXXXX-XXXXXXXXXX-XXXXXXXXXX-512 unixgroup="winadmins" type=d

Verifying the Configuration

To verify that the mapping was successful and is recognized by Samba, list all active group mappings:

sudo net groupmap list

The output will display entries showing the Windows group name, the corresponding SID, and the linked Unix group:

Domain Admins (S-1-5-21-XXXXXXXXXX-XXXXXXXXXX-XXXXXXXXXX-512) -> winadmins

Modifying and Removing Mappings

If you need to change the local Ubuntu group linked to a Windows group, use the modify subcommand:

sudo net groupmap modify ntgroup="Domain Admins" unixgroup="newgroup"

To delete an existing group mapping entirely, use the delete subcommand:

sudo net groupmap delete ntgroup="Domain Admins"
