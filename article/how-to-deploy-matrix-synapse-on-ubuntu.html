How to Deploy Matrix Synapse on Ubuntu

This guide provides a step-by-step walkthrough for deploying a self-hosted Matrix Synapse chat server on an Ubuntu system. You will learn how to configure the necessary dependencies, set up a production-ready PostgreSQL database, install the official Matrix Synapse package, secure your traffic with an Nginx reverse proxy and Let's Encrypt SSL, and register your first administrator account.

1. Prerequisites

Before starting, ensure you have:

  • A server running Ubuntu 22.04 or 24.04 LTS.
  • A fully qualified domain name (FQDN) with an A record pointing to your server's IP address (e.g., matrix.example.com).
  • Non-root user access with sudo privileges.
  • Ports 80, 443, and 8448 open in your firewall.

2. Update System and Install Dependencies

Update the local package index and install the required utility packages:

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget apt-transport-https lsb-release gnupg2

3. Install and Configure PostgreSQL

Synapse uses SQLite by default, but PostgreSQL is required for production environments.

Install PostgreSQL:

sudo apt install -y postgresql postgresql-contrib

Switch to the postgres user and create the database and user for Synapse:

sudo -u postgres psql

Execute the following SQL commands (replace your_secure_password with a strong password):

CREATE USER synapse WITH PASSWORD 'your_secure_password';
CREATE DATABASE synapse WITH OWNER synapse ENCODING 'UTF8' LC_COLLATE = 'C' LC_CTYPE = 'C' TEMPLATE template0;
\q

4. Install Matrix Synapse

Add the official Matrix repository to your package manager:

sudo mkdir -pv /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/matrix-org-archive-keyring.gpg https://packages.matrix.org/debian/matrix-org-archive-keyring.gpg
echo "deb [signed-by=/etc/apt/keyrings/matrix-org-archive-keyring.gpg] https://packages.matrix.org/debian/ $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/matrix-org.list

Update your package lists and install Synapse:

sudo apt update
sudo apt install -y matrix-synapse-py3

During installation, a prompt will ask for your server name. Enter your domain name (e.g., example.com or matrix.example.com). Choose whether to send anonymous statistics when prompted.

5. Configure Synapse for PostgreSQL

Edit the Synapse configuration file:

sudo nano /etc/matrix-synapse/homeserver.yaml

Locate the database section and comment out or remove the SQLite configuration:

# Remove or comment out:
# database:
#   name: sqlite3
#   args:
#     database: /var/lib/matrix-synapse/homeserver.db

Add the PostgreSQL connection configuration:

database:
  name: psycopg2
  args:
    user: synapse
    password: your_secure_password
    database: synapse
    host: localhost
    cp_min: 5
    cp_max: 10

Verify that the bind_addresses setting under the HTTP listener contains 127.0.0.1 so Synapse listens locally behind your reverse proxy:

port: 8008
tls: false
type: http
x_forwarded: true
bind_addresses: ['127.0.0.1']

Save and exit the file, then restart Synapse to apply changes:

sudo systemctl restart matrix-synapse
sudo systemctl enable matrix-synapse

6. Configure Nginx Reverse Proxy with SSL

Install Nginx and Certbot:

sudo apt install -y nginx certbot python3-certbot-nginx

Obtain an SSL certificate from Let's Encrypt:

sudo certbot --nginx -d matrix.example.com

Create a new Nginx server configuration:

sudo nano /etc/nginx/sites-available/matrix

Insert the following configuration, replacing matrix.example.com with your domain:

server {
    listen 80;
    server_name matrix.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    listen 8448 ssl http2;
    listen [::]:8448 ssl http2;
    server_name matrix.example.com;

    ssl_certificate /etc/letsencrypt/live/matrix.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/matrix.example.com/privkey.pem;

    client_max_body_size 50M;

    location ~ ^(/_matrix|/_synapse/client) {
        proxy_pass http://127.0.0.1:8008;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Host $host;
    }
}

Enable the configuration and reload Nginx:

sudo ln -s /etc/nginx/sites-available/matrix /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

7. Create an Admin User

Register your initial admin account using the built-in Synapse script:

register_new_matrix_user -c /etc/matrix-synapse/homeserver.yaml http://127.0.0.1:8008

Follow the prompts to enter a username, choose a password, and grant administrator permissions when prompted (Make admin [no]: yes).

Once complete, your Matrix Synapse server is fully operational. You can connect to it using any Matrix client, such as Element, by setting the homeserver URL to https://matrix.example.com.
