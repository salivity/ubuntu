How to Purge a PPA and Downgrade Packages in Ubuntu

When you add a Personal Package Archive (PPA) to Ubuntu, it often installs newer or experimental versions of software packages over the stock versions provided by the official distribution. Removing a PPA using standard management commands only deletes the repository link, leaving the upgraded packages installed on your system. This guide demonstrates how to use ppa-purge to safely remove a PPA, clean up its repository files, and automatically downgrade all affected packages back to the default versions available in the official Ubuntu repositories.

Why Use ppa-purge?

Using add-apt-repository --remove or deleting a PPA from your software sources only stops future updates from that PPA. It does not uninstall the packages installed from it, nor does it revert upgraded system packages to their original versions.

ppa-purge solves this problem by:

  1. Disabling the specified PPA repository.
  2. Checking every package installed from that PPA.
  3. Downgrading those packages to the latest versions present in your active, official Ubuntu repositories.

Step 1: Install ppa-purge

ppa-purge is available in the official Ubuntu universe repository. Open your terminal and run the following commands to install it:

sudo apt update
sudo apt install ppa-purge

Step 2: Identify the Target PPA

To purge a PPA, you need its exact name. If you do not remember the full name of the PPA you want to remove, list all PPAs currently added to your system by checking the /etc/apt/sources.list.d/ directory:

ls /etc/apt/sources.list.d/

Look for files ending in .list or .sources that correspond to the PPA name (for example, graphics-drivers-ubuntu-ppa-lunar.list).

Step 3: Purge the PPA and Downgrade Packages

Once you have the PPA name, run ppa-purge followed by the PPA identifier using the ppa:owner/name format:

sudo ppa-purge ppa:owner/ppa-name

Example:

To remove the Graphics Drivers PPA and downgrade all graphics drivers back to official Ubuntu versions, run:

sudo ppa-purge ppa:graphics-drivers/ppa

What Happens During the Process:

  1. ppa-purge fetches the package list from the specified PPA.
  2. It cross-references installed packages against official repositories.
  3. It prompts you to confirm the removal and downgrade process.
  4. Press Y and hit Enter to allow the system to download the older stock packages and replace the PPA versions.

Alternative Syntax Options

If you added a PPA using a full URL instead of the ppa: shorthand, you can specify the line directly with the -o flag:

sudo ppa-purge -o ppa-owner-name -p ppa-name

If you are removing a PPA that was added for a different Ubuntu release branch, specify the release code name using the -d flag:

sudo ppa-purge -d jammy ppa:owner/ppa-name

Step 4: Verify the Downgrade

After the process finishes, update your local package index to ensure everything is synchronized:

sudo apt update

You can verify that a specific package was successfully downgraded by checking its installed version with apt policy:

apt policy package-name

The output should show that the installed version matches the version provided by the main Ubuntu repository rather than the PPA.
