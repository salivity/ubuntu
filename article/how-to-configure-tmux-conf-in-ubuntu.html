How to Configure tmux.conf in Ubuntu

Configuring a custom .tmux.conf file in Ubuntu allows you to personalize your tmux terminal multiplexer by changing default keybindings, enabling mouse support, customizing the status bar, and improving workflow efficiency. This guide covers the step-by-step process of installing tmux, creating the configuration file in your home directory, adding essential settings, and reloading the configuration without restarting your terminal session.

Step 1: Install tmux

Ensure tmux is installed on your Ubuntu system by running the following commands in your terminal:

sudo apt update
sudo apt install tmux

Step 2: Create the .tmux.conf File

The configuration file for tmux resides in your home directory. Create or open the file using a text editor like Nano:

nano ~/.tmux.conf

Step 3: Add Custom Configurations

Paste your desired custom settings into the file. Here are some commonly used configurations:

# Change the prefix key from Ctrl+b to Ctrl+a
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# Enable mouse support (clickable windows, panes, and resizable panes)
set -g mouse on

# Start window and pane numbering at 1 instead of 0
set -g base-index 1
setw -g pane-base-index 1

# Split panes using | and - instead of % and "
bind | split-window -h
bind - split-window -v
unbind '"'
unbind %

# Reload configuration shortcut
bind r source-file ~/.tmux.conf \; display "Configuration Reloaded!"

Save and exit the editor in Nano by pressing Ctrl + O, Enter, and then Ctrl + X.

Step 4: Apply the Changes

To apply the new settings to an active tmux session, use one of the following methods:

  1. From inside an active tmux session: Press Ctrl + a (or Ctrl + b if you did not change the prefix), type :, then enter:

    source-file ~/.tmux.conf

    If you included the reload shortcut from Step 3, simply press Ctrl + a followed by r.

  2. From the Ubuntu terminal outside tmux:

    tmux source-file ~/.tmux.conf

Your custom configuration is now active for all current and future tmux sessions.
