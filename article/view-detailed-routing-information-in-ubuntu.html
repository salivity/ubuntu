View Detailed Routing Information in Ubuntu

Viewing detailed routing information in Ubuntu is a fundamental task for network administration and troubleshooting. Modern Ubuntu distributions primarily use the ip route command from the iproute2 package to display and manage the kernel routing table, though legacy utilities like netstat and route can also be used. This guide explains how to use these commands to inspect your network routes, view detailed statistics, and trace specific IP destinations.

The Primary Command: ip route

The standard and most powerful command to view routing information in modern Ubuntu versions is ip route.

To display the basic IPv4 routing table, open your terminal and run:

ip route

or

ip route show

Displaying Detailed Routing Statistics

To view detailed statistics about network routes, including packet counts and byte transfers, use the -s (stats) flag:

ip -s route

Viewing IPv6 Routing Information

If your network utilizes IPv6, you can view the detailed IPv6 routing table by specifying the -6 flag:

ip -6 route

Checking All Routing Tables

Ubuntu uses multiple routing tables behind the scenes. To view entries from all routing tables (including local and broadcast routes), run:

ip route show table all

Viewing the Route to a Specific Destination

If you need detailed routing details for reaching a specific IP address or domain, use the ip route get command. This simulates a packet lookup and outputs the exact interface, gateway, and source IP used for that target.

ip route get 8.8.8.8

Example Output: 8.8.8.8 via 192.168.1.1 dev eth0 src 192.168.1.50 uid 1000

Legacy Alternatives

While ip route is the modern standard, older utilities from the net-tools package can still be used if installed.

Using netstat

To view the routing table in a numerical format without resolving hostnames:

netstat -rn

Using route

To display the routing table using the traditional route command:

route -n
