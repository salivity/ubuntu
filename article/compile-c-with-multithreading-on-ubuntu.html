Compile C++ with Multithreading on Ubuntu

This guide covers the necessary command and flags to compile C++ programs with multithreading support on Ubuntu. You will learn how to properly invoke the GNU C++ Compiler (GCC/g++) to link the required thread libraries, prevent common runtime and link-time errors, and use modern C++ concurrency features effectively from the command line.

The Compilation Command

To compile a multithreaded C++ program on Ubuntu using g++, use the -pthread flag along with a C++ standard flag of C++11 or newer:

g++ -std=c++17 -pthread main.cpp -o main

Breakdown of the Command Flags

  • g++: The standard GNU C++ compiler package included with the build-essential bundle on Ubuntu.
  • -pthread: This is the critical flag for multithreading. It defines the necessary preprocessor macros required for threading and links the system's POSIX thread library (libpthread) at the linking stage. It is preferred over -lpthread because it configures both the compiler preprocessor and the linker flags.
  • -std=c++17: Specifies the C++ language standard. The standard library's <thread> header was introduced in C++11, so any version including -std=c++11, -std=c++14, -std=c++17, or -std=c++20 will work.
  • main.cpp: The source code file containing your multithreaded implementation.
  • -o main: Specifies the name of the generated executable binary file.

Prerequisites on Ubuntu

Ensure you have the C++ compiler installed on your system. If g++ is not present, install it via the terminal:

sudo apt update
sudo apt install build-essential

Example Usage

Consider a basic multithreaded source file named example.cpp:

#include <iostream>
#include <thread>

void task() {
    std::cout << "Thread executing...\n";
}

int main() {
    std::thread t(task);
    t.join();
    return 0;
}

Compile and run the program with the following terminal commands:

g++ -std=c++17 -pthread example.cpp -o example
./example

Omitting the -pthread flag when compiling C++ code that utilizes <thread> or POSIX threads will typically result in a compile-time link error or a runtime std::system_error indicating that the operation is not permitted. Always include -pthread when working with threads on Linux systems.
