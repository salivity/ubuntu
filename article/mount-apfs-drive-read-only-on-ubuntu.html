Mount APFS Drive Read-Only on Ubuntu

Mounting an Apple File System (APFS) formatted storage device in Ubuntu requires third-party utilities because the Linux kernel does not include native read support for APFS out of the box. By using apfs-fuse, an open-source FUSE driver, you can securely access your macOS files in a read-only state, eliminating the risk of data corruption while retrieving documents, media, or backups.

Step 1: Install Required Dependencies

Update your package index and install the necessary build tools, libraries, and FUSE development packages:

sudo apt update
sudo apt install build-essential cmake git libfuse3-dev libbz2-dev libz-dev -y

Step 2: Download and Compile apfs-fuse

Clone the apfs-fuse repository from GitHub along with its submodules, then compile the software:

git clone --recursive https://github.com/sgan81/apfs-fuse.git
cd apfs-fuse
mkdir build
cd build
cmake ..
make
sudo make install

Step 3: Identify the APFS Partition

Connect the APFS drive to your system and locate its device identifier using lsblk:

lsblk -f

Look for the partition labeled with apfs (for example, /dev/sdb2 or /dev/nvme0n1p2). Note the exact device path.

Step 4: Create a Mount Point

Create a directory where the files will be accessible:

sudo mkdir -p /media/apfs_drive

Step 5: Mount the APFS Drive

Mount the partition to your designated directory. The driver runs read-only by default:

sudo apfs-fuse /dev/sdb2 /media/apfs_drive

Note: Replace /dev/sdb2 with your actual device identifier.

If your drive contains multiple APFS volumes within a single container, you can list them or mount a specific volume number using the -v flag:

sudo apfs-fuse -v 0 /dev/sdb2 /media/apfs_drive

You can now navigate to /media/apfs_drive using your file manager or terminal to read and copy files.

Step 6: Unmount the Drive

Once you finish accessing your data, safely unmount the drive using fusermount or umount:

sudo umount /media/apfs_drive
